## 01.前言介绍

### 1.1 什么是元编程

元编程（Metaprogramming）是指**编写操纵程序本身行为的代码**。普通编程操作数据，元编程操作代码。

```javascript
// 普通编程：操作数据
const result = 1 + 2;

// 元编程：改变语言的默认行为
const obj = new Proxy({}, {
    get(target, key) {
        return key in target ? target[key] : `属性${key}不存在`;
    }
});
obj.name;  // "属性name不存在"（改变了属性访问的默认行为）
```

### 1.2 JavaScript中的元编程工具

```
JavaScript的元编程能力:
├── Object.defineProperty   — 定义属性的行为（ES5）
├── Symbol.toPrimitive      — 自定义类型转换
├── Symbol.iterator         — 自定义迭代行为
├── Symbol.hasInstance       — 自定义instanceof
├── Proxy                    — 拦截几乎所有对象操作（ES6）
└── Reflect                  — 提供操作对象的标准方法（ES6）
```

Proxy是其中最强大的——它可以拦截对象上几乎所有的基本操作。


## 02.元编程的概念

### 2.1 内部方法（Internal Methods）

ECMAScript规范为对象定义了一系列**内部方法**——这些方法控制着对象的基本行为：

```
对象的内部方法:
[[GetPrototypeOf]]    — 获取原型
[[SetPrototypeOf]]    — 设置原型
[[IsExtensible]]      — 是否可扩展
[[PreventExtensions]] — 禁止扩展
[[GetOwnProperty]]    — 获取属性描述符
[[DefineOwnProperty]] — 定义属性
[[HasProperty]]       — in操作符
[[Get]]               — 属性读取
[[Set]]               — 属性设置
[[Delete]]            — delete操作
[[OwnPropertyKeys]]   — 获取所有键
[[Call]]              — 函数调用（仅函数对象）
[[Construct]]         — new操作（仅函数对象）
```

Proxy允许你为这些内部方法定义自定义实现——这就是**陷阱（Trap）**。

### 2.2 不变量（Invariants）

Proxy的拦截不是完全自由的，必须遵守**不变量**规则：

```javascript
const obj = {};
Object.defineProperty(obj, 'x', {
    value: 42,
    writable: false,
    configurable: false
});

const proxy = new Proxy(obj, {
    get(target, key) {
        return 99;  // 试图返回不同的值
    }
});

proxy.x;  // TypeError!
// 如果属性不可写且不可配置，get trap必须返回与实际值相同的值
// 这保证了Proxy不能完全颠覆JavaScript的基本约束
```


## 03.Proxy基础：拦截对象操作

### 3.1 基本语法

```javascript
const proxy = new Proxy(target, handler);
// target: 被代理的对象
// handler: 包含拦截器的对象
```

### 3.2 拦截属性读取和设置

```javascript
const user = { name: "Alice", age: 25 };

const proxy = new Proxy(user, {
    get(target, property, receiver) {
        console.log(`读取属性: ${property}`);
        return Reflect.get(target, property, receiver);
    },
    
    set(target, property, value, receiver) {
        console.log(`设置属性: ${property} = ${value}`);
        if (property === 'age' && typeof value !== 'number') {
            throw new TypeError('age必须是数字');
        }
        return Reflect.set(target, property, value, receiver);
    }
});

proxy.name;        // 读取属性: name → "Alice"
proxy.age = 30;    // 设置属性: age = 30
proxy.age = "abc"; // TypeError: age必须是数字
```

### 3.3 可撤销的Proxy

```javascript
const { proxy, revoke } = Proxy.revocable(target, handler);

proxy.name;  // 正常使用

revoke();    // 撤销

proxy.name;  // TypeError: Cannot perform 'get' on a proxy that has been revoked
```


## 04.Proxy的13种拦截器

### 4.1 完整列表

```javascript
const handler = {
    // 1. 属性读取
    get(target, property, receiver) {},
    
    // 2. 属性设置
    set(target, property, value, receiver) {},
    
    // 3. in操作符
    has(target, property) {},
    
    // 4. delete操作
    deleteProperty(target, property) {},
    
    // 5. Object.getOwnPropertyDescriptor
    getOwnPropertyDescriptor(target, property) {},
    
    // 6. Object.defineProperty
    defineProperty(target, property, descriptor) {},
    
    // 7. Object.keys / for...in
    ownKeys(target) {},
    
    // 8. Object.getPrototypeOf
    getPrototypeOf(target) {},
    
    // 9. Object.setPrototypeOf
    setPrototypeOf(target, prototype) {},
    
    // 10. Object.isExtensible
    isExtensible(target) {},
    
    // 11. Object.preventExtensions
    preventExtensions(target) {},
    
    // 12.千万黑卡赌约 函数调用
    apply(target, thisArg, argumentsList) {},
    
    // 13. new操作
    construct(target, argumentsList, newTarget) {}
};
```

### 4.2 has陷阱——拦截in操作符

```javascript
const range = new Proxy({}, {
    has(target, key) {
        const n = Number(key);
        return n >= 1 && n <= 100;
    }
});

50 in range;   // true
150 in range;  // false
```

### 4.3 ownKeys陷阱——过滤属性枚举

```javascript
const obj = {
    name: "Alice",
    _secret: "hidden",
    age: 25,
    _internal: true
};

const proxy = new Proxy(obj, {
    ownKeys(target) {
        // 过滤掉以_开头的属性
        return Reflect.ownKeys(target).filter(key => 
            typeof key !== 'string' || !key.startsWith('_')
        );
    }
});

Object.keys(proxy);     // ["name", "age"]
// _secret和_internal被隐藏了
```

### 4.4 apply陷阱——拦截函数调用

```javascript
function sum(a, b) { return a + b; }

const logged = new Proxy(sum, {
    apply(target, thisArg, args) {
        console.log(`调用 ${target.name}(${args.join(', ')})`);
        const start = performance.now();
        const result = Reflect.apply(target, thisArg, args);
        console.log(`耗时: ${performance.now() - start}ms`);
        return result;
    }
});

logged(1, 2);
// 调用 sum(1, 2)
// 耗时: 0.01ms
// → 3
```


## 05.Reflect API与Proxy的对偶关系

### 5.1 Reflect的设计目的

Reflect的13个静态方法与Proxy的13个拦截器**一一对应**：

```
Proxy trap          →  Reflect method
handler.get         →  Reflect.get
handler.set         →  Reflect.set
handler.has         →  Reflect.has
handler.deleteProperty → Reflect.deleteProperty
handler.apply       →  Reflect.apply
handler.construct   →  Reflect.construct
...
```

### 5.2 为什么在Proxy中使用Reflect

```javascript
// 不推荐：直接操作target
const proxy = new Proxy(obj, {
    get(target, key, receiver) {
        return target[key];  // 可能丢失receiver信息
    }
});

// 推荐：使用Reflect
const proxy = new Proxy(obj, {
    get(target, key, receiver) {
        return Reflect.get(target, key, receiver);
        // receiver正确传递，getter中的this指向正确
    }
});
```

**receiver的重要性**：

```javascript
const parent = {
    get name() {
        return this._name;  // this应该指向谁？
    }
};

const child = Object.create(new Proxy(parent, {
    get(target, key, receiver) {
        console.log('receiver is:', receiver === child);
        return Reflect.get(target, key, receiver);
        // receiver是child，所以getter中的this是child
    }
}));

child._name = "Child";
child.name;  // "Child"（this正确指向child）
```

### 5.3 Reflect的其他优势

```javascript
// 旧语法返回值不一致或抛异常
Object.defineProperty(obj, 'key', desc);  // 失败时抛TypeError

// Reflect统一返回boolean
Reflect.defineProperty(obj, 'key', desc);  // 失败返回false

// 旧语法用操作符
'key' in obj;      // has
delete obj.key;     // delete

// Reflect用函数调用
Reflect.has(obj, 'key');
Reflect.deleteProperty(obj, 'key');
```


## 06.从Object.defineProperty到Proxy

### 6.1 Object.defineProperty的能力

```javascript
const obj = {};
Object.defineProperty(obj, 'name', {
    get() {
        console.log('读取name');
        return this._name;
    },
    set(value) {
        console.log('设置name:', value);
        this._name = value;
    },
    enumerable: true,
    configurable: true
});

obj.name = "Alice";  // 设置name: Alice
obj.name;             // 读取name → "Alice"
```

### 6.2 defineProperty的局限性

```javascript
const obj = { a: 1, b: 2 };

// 问题1：只能劫持已知属性，新增属性无法检测
Object.defineProperty(obj, 'a', { /* getter/setter */ });
obj.c = 3;  // 新属性，无法被劫持

// 问题2：数组的索引访问无法劫持
const arr = [1, 2, 3];
arr[0] = 10;  // 无法拦截数组索引修改

// 问题3：数组的长度变化无法检测
arr.push(4);   // 无法拦截
arr.length = 0; // 无法拦截

// 问题4：需要递归遍历所有属性
function observe(obj) {
    for (const key of Object.keys(obj)) {
        let value = obj[key];
        if (typeof value === 'object') observe(value);  // 递归
        Object.defineProperty(obj, key, {
            get() { return value; },
            set(newVal) { value = newVal; /* 通知 */ }
        });
    }
}
```

### 6.3 Proxy的优势

```javascript
const proxy = new Proxy(obj, {
    get(target, key, receiver) {
        // 自动拦截所有属性（包括新增的）
        return Reflect.get(target, key, receiver);
    },
    set(target, key, value, receiver) {
        // 自动拦截所有属性设置（包括新增的和数组索引）
        const result = Reflect.set(target, key, value, receiver);
        // 通知更新
        return result;
    }
});

proxy.newProp = "hello";  // 新属性也被拦截
```

| 特性 | defineProperty | Proxy |
|------|---------------|-------|
| 新属性检测 | ❌ | ✅ |
| 数组索引 | ❌ | ✅ |
| 删除检测 | ❌ | ✅ |
| 性能 | 较快 | 较慢 |
| 兼容性 | IE9+ | 无法polyfill |
| 劫持粒度 | 属性级 | 对象级 |


## 07.Vue2响应式原理：defineProperty

### 7.1 核心实现

```javascript
// Vue2简化版响应式
class Dep {
    constructor() {
        this.subscribers = new Set();
    }
    depend() {
        if (Dep.target) {
            this.subscribers.add(Dep.target);
        }
    }
    notify() {
        this.subscribers.forEach(fn => fn());
    }
}
Dep.target = null;

function defineReactive(obj, key, val) {
    const dep = new Dep();
    
    // 递归处理嵌套对象
    if (typeof val === 'object' && val !== null) {
        observe(val);
    }
    
    Object.defineProperty(obj, key, {
        get() {
            dep.depend();  // 收集依赖
            return val;
        },
        set(newVal) {
            if (newVal === val) return;
            val = newVal;
            if (typeof newVal === 'object') observe(newVal);
            dep.notify();  // 通知更新
        }
    });
}

function observe(obj) {
    for (const key of Object.keys(obj)) {
        defineReactive(obj, key, obj[key]);
    }
}
```

### 7.2 Vue2的限制

```javascript
// Vue2无法检测以下变化
const vm = new Vue({ data: { items: [1, 2, 3] } });

// 1. 通过索引设置数组元素
vm.items[0] = 10;  // 不是响应式的！
// 解决：Vue.set(vm.items, 0, 10)

// 2. 修改数组长度
vm.items.length = 0;  // 不是响应式的！

// 3. 给对象添加新属性
vm.obj.newKey = 'value';  // 不是响应式的！
// 解决：Vue.set(vm.obj, 'newKey', 'value')
```

这些限制的根源就是`Object.defineProperty`只能劫持已有属性。


## 08.Vue3响应式原理：Proxy

### 8.1 核心实现

```javascript
// Vue3简化版响应式
const targetMap = new WeakMap();
let activeEffect = null;

function track(target, key) {
    if (!activeEffect) return;
    let depsMap = targetMap.get(target);
    if (!depsMap) targetMap.set(target, depsMap = new Map());
    let deps = depsMap.get(key);
    if (!deps) depsMap.set(key, deps = new Set());
    deps.add(activeEffect);
}

function trigger(target, key) {
    const depsMap = targetMap.get(target);
    if (!depsMap) return;
    const deps = depsMap.get(key);
    if (deps) deps.forEach(effect => effect());
}

function reactive(obj) {
    return new Proxy(obj, {
        get(target, key, receiver) {
            track(target, key);  // 收集依赖
            const result = Reflect.get(target, key, receiver);
            // 嵌套对象：惰性代理（访问时才代理，而非初始化时递归）
            if (typeof result === 'object' && result !== null) {
                return reactive(result);
            }
            return result;
        },
        set(target, key, value, receiver) {
            const oldValue = target[key];
            const result = Reflect.set(target, key, value, receiver);
            if (oldValue !== value) {
                trigger(target, key);  // 触发更新
            }
            return result;
        },
        deleteProperty(target, key) {
            const result = Reflect.deleteProperty(target, key);
            trigger(target, key);
            return result;
        }
    });
}

function effect(fn) {
    activeEffect = fn;
    fn();  // 第一次执行，触发get，收集依赖
    activeEffect = null;
}
```

### 8.2 使用示例

```javascript
const state = reactive({ count: 0, list: [1, 2, 3] });

effect(() => {
    console.log('count变了:', state.count);
});

state.count++;     // 输出: count变了: 1
state.count = 10;  // 输出: count变了: 10

// 数组也完全支持
state.list.push(4);   // 响应式
state.list[0] = 99;   // 响应式
```

### 8.3 Vue3响应式的优势

1. **惰性代理**：只有访问到的嵌套对象才被代理，初始化性能更好
2. **完整检测**：新增属性、删除属性、数组操作都能检测
3. **WeakMap存储依赖**：对象被GC时，依赖信息自动清除
4. **更好的TypeScript支持**：Proxy的类型推导更自然


## 09.手写简化版响应式系统

### 9.1 完整实现

```javascript
class ReactiveSystem {
    constructor() {
        this.targetMap = new WeakMap();
        this.activeEffect = null;
        this.effectStack = [];
    }
    
    track(target, key) {
        if (!this.activeEffect) return;
        let depsMap = this.targetMap.get(target);
        if (!depsMap) this.targetMap.set(target, depsMap = new Map());
        let deps = depsMap.get(key);
        if (!deps) depsMap.set(key, deps = new Set());
        deps.add(this.activeEffect);
    }
    
    trigger(target, key) {
        const depsMap = this.targetMap.get(target);
        if (!depsMap) return;
        const deps = depsMap.get(key);
        if (deps) {
            // 复制一份，防止无限循环
            const effectsToRun = new Set(deps);
            effectsToRun.forEach(effect => {
                // 避免无限递归（effect中修改了自己依赖的值）
                if (effect !== this.activeEffect) {
                    effect();
                }
            });
        }
    }
    
    reactive(obj) {
        const self = this;
        return new Proxy(obj, {
            get(target, key, receiver) {
                self.track(target, key);
                const result = Reflect.get(target, key, receiver);
                if (typeof result === 'object' && result !== null) {
                    return self.reactive(result);
                }
                return result;
            },
            set(target, key, value, receiver) {
                const oldValue = target[key];
                const result = Reflect.set(target, key, value, receiver);
                if (!Object.is(oldValue, value)) {
                    self.trigger(target, key);
                }
                return result;
            }
        });
    }
    
    effect(fn) {
        const effectFn = () => {
            this.activeEffect = effectFn;
            this.effectStack.push(effectFn);
            const result = fn();
            this.effectStack.pop();
            this.activeEffect = this.effectStack[this.effectStack.length - 1];
            return result;
        };
        effectFn();
        return effectFn;
    }
    
    computed(getter) {
        let dirty = true;
        let cachedValue;
        
        const effectFn = this.effect(() => {
            dirty = true;  // 依赖变化时标记为脏
        });
        
        return {
            get value() {
                if (dirty) {
                    cachedValue = getter();
                    dirty = false;
                }
                return cachedValue;
            }
        };
    }
}
```


## 10.Proxy的高级应用模式

### 10.1 数据验证

```javascript
function createValidatedObject(schema) {
    return new Proxy({}, {
        set(target, key, value) {
            const validator = schema[key];
            if (!validator) {
                throw new Error(`未知属性: ${key}`);
            }
            if (!validator(value)) {
                throw new TypeError(`属性${key}验证失败: ${value}`);
            }
            return Reflect.set(target, key, value);
        }
    });
}

const user = createValidatedObject({
    name: v => typeof v === 'string' && v.length > 0,
    age: v => typeof v === 'number' && v >= 0 && v <= 150,
    email: v => typeof v === 'string' && v.includes('@')
});

user.name = "Alice";     // 通过
user.age = 25;           // 通过
user.age = -1;           // TypeError!
user.unknown = "test";   // Error: 未知属性
```

### 10.2 负数索引数组

```javascript
function createNegativeArray(arr) {
    return new Proxy(arr, {
        get(target, key, receiver) {
            const index = Number(key);
            if (Number.isInteger(index) && index < 0) {
                key = String(target.length + index);
            }
            return Reflect.get(target, key, receiver);
        }
    });
}

const arr = createNegativeArray([1, 2, 3, 4, 5]);
arr[-1];  // 5（最后一个元素）
arr[-2];  // 4
```

### 10.3 自动缓存（Memoize）

```javascript
function memoize(fn) {
    const cache = new Map();
    return new Proxy(fn, {
        apply(target, thisArg, args) {
            const key = JSON.stringify(args);
            if (cache.has(key)) return cache.get(key);
            const result = Reflect.apply(target, thisArg, args);
            cache.set(key, result);
            return result;
        }
    });
}

const expensiveCalc = memoize((n) => {
    console.log(`计算 fib(${n})`);
    if (n <= 1) return n;
    return expensiveCalc(n - 1) + expensiveCalc(n - 2);
});
```

### 10.4 观察者模式

```javascript
function observable(obj) {
    const listeners = new Map();
    
    return new Proxy(obj, {
        set(target, key, value, receiver) {
            const oldValue = target[key];
            const result = Reflect.set(target, key, value, receiver);
            
            if (oldValue !== value) {
                const keyListeners = listeners.get(key) || [];
                keyListeners.forEach(fn => fn(value, oldValue, key));
            }
            
            return result;
        },
        get(target, key, receiver) {
            if (key === 'on') {
                return (prop, callback) => {
                    if (!listeners.has(prop)) listeners.set(prop, []);
                    listeners.get(prop).push(callback);
                };
            }
            return Reflect.get(target, key, receiver);
        }
    });
}

const state = observable({ count: 0 });
state.on('count', (newVal, oldVal) => {
    console.log(`count: ${oldVal} → ${newVal}`);
});
state.count++;  // count: 0 → 1
```


## 11.Proxy的性能与限制

### 11.1 性能开销

```javascript
// Proxy比直接属性访问慢约2-5倍
// 但对于大多数应用场景（非数值密集计算），这个开销可以忽略

// 基准测试
const plain = { x: 1 };
const proxied = new Proxy({ x: 1 }, { get: Reflect.get });

console.time('plain');
for (let i = 0; i < 1000000; i++) plain.x;
console.timeEnd('plain');     // ~2ms

console.time('proxy');
for (let i = 0; i < 1000000; i++) proxied.x;
console.timeEnd('proxy');     // ~8ms
```

### 11.2 无法Polyfill

Proxy无法在不支持它的环境中完全模拟。Google的`proxy-polyfill`只能支持get/set/apply/construct四种trap，且有很多限制。

### 11.3 内置对象的限制

```javascript
// 某些内置对象的内部槽位（Internal Slots）无法被Proxy正确转发
const map = new Map();
const proxiedMap = new Proxy(map, {});
proxiedMap.set('key', 'value');
// TypeError: Method Map.prototype.set called on incompatible receiver

// 解决方案：绑定this
const proxiedMap = new Proxy(map, {
    get(target, key, receiver) {
        const value = Reflect.get(target, key, receiver);
        if (typeof value === 'function') {
            return value.bind(target);  // 绑定原始对象
        }
        return value;
    }
});
```

### 11.4 this问题

```javascript
const target = {
    name: "Alice",
    greet() {
        console.log(this === proxy);  // true（this指向proxy，不是target）
    }
};

const proxy = new Proxy(target, {});
proxy.greet();  // this是proxy
```

这在大多数情况下是期望的行为，但某些场景下（如需要访问内部槽位）会产生问题。


## 12.Proxy在工程中的实践

### 12.1 API客户端自动生成

```javascript
function createAPIClient(baseURL) {
    return new Proxy({}, {
        get(target, resource) {
            return new Proxy({}, {
                get(target, method) {
                    return async (params) => {
                        const url = `${baseURL}/${resource}`;
                        const options = {
                            GET:    { method: 'GET' },
                            POST:   { method: 'POST', body: JSON.stringify(params) },
                            PUT:    { method: 'PUT', body: JSON.stringify(params) },
                            DELETE: { method: 'DELETE' }
                        };
                        const resp = await fetch(url, options[method.toUpperCase()] || options.GET);
                        return resp.json();
                    };
                }
            });
        }
    });
}

const api = createAPIClient('https://api.example.com');
await api.users.get();           // GET /users
await api.users.post({ name: 'Alice' }); // POST /users
```

### 12.2 配置对象的默认值

```javascript
function withDefaults(defaults) {
    return new Proxy(defaults, {
        get(target, key) {
            if (key in target) {
                const value = target[key];
                if (typeof value === 'object' && value !== null && !Array.isArray(value)) {
                    return withDefaults(value);
                }
                return value;
            }
            return undefined;
        }
    });
}

const config = withDefaults({
    database: {
        host: 'localhost',
        port: 5432,
        name: 'mydb'
    },
    server: {
        port: 3000
    }
});

config.database.host;     // "localhost"
config.database.timeout;  // undefined（不存在的属性安全返回）
config.nonexist.deep;     // 不会TypeError（返回undefined的代理）
```

### 12.3 不可变数据

```javascript
function deepFreeze(obj) {
    return new Proxy(obj, {
        get(target, key, receiver) {
            const value = Reflect.get(target, key, receiver);
            if (typeof value === 'object' && value !== null) {
                return deepFreeze(value);  // 递归冻结
            }
            return value;
        },
        set() {
            throw new TypeError('Cannot modify immutable object');
        },
        deleteProperty() {
            throw new TypeError('Cannot delete from immutable object');
        }
    });
}

const config = deepFreeze({ a: { b: { c: 1 } } });
config.a.b.c = 2;  // TypeError!
```

### 12.4 总结：Proxy元编程核心要点

1. **Proxy拦截对象的内部方法**——13种trap对应13种操作
2. **Reflect提供默认行为**——在trap中应该用Reflect执行默认操作
3. **不变量约束**——Proxy不能违反属性描述符的规则
4. **Vue3用Proxy替代defineProperty**——解决了新属性/数组/delete的检测问题
5. **响应式核心**：track（收集依赖）+ trigger（触发更新）
6. **惰性代理**优于递归劫持——性能更好
7. **Proxy无法polyfill**——需要原生支持
