## 01.需求说明

实现一个最简单的学生成绩管理系统，支持以下命令：

```
1. 增加学生
2. 查询学生（按学号）
3. 修改成绩
4. 删除学生
5. 列出所有学生（按成绩降序）
0. 退出
```

数据全部放在内存（map）中，关闭程序数据丢失——文件持久化将在**案例 02** 中加上。

## 03.数据结构设计

```go
type Student struct {
    ID    int
    Name  string
    Score float64
}

// 全局存储
var students = make(map[int]Student)
```

> ⚠️ 真实工程不会用全局变量，但本案例的目标是"练语法"。第 02、03 案例会改用 struct 封装。

## 04.菜单循环骨架

伪代码：

```go
for {
    fmt.Println("--- 学生成绩系统 ---")
    fmt.Println("1. 增加 2. 查询 3. 修改 4. 删除 5. 列出 0. 退出")
    var choice int
    fmt.Scan(&choice)
    switch choice {
    case 1: addStudent()
    case 2: queryStudent()
    // ...
    case 0: return
    default: fmt.Println("无效选择")
    }
}
```

> **本案例完整代码、增删改查实现、排序输出、错误处理细节将在卷二定稿阶段补全。**

## 08.项目总结

- 整体结构：单 main + 全局 map
- 核心原理：CLI 程序的"读取 → 分支 → 执行"循环
- 优点：代码极简，3 小时内能跑起来
- 缺点：全局变量、无持久化、并发不安全

---

## 09.技术思考

1. 为什么我用 `map[int]Student` 而不是 `[]Student`？（O(1) 查找）
2. `fmt.Scan` 与 `bufio.Scanner` 的差别？（前者按空白分隔，后者按行）
3. 如果学号重复怎么办？（map 天然去重，但 score 会被覆盖）
