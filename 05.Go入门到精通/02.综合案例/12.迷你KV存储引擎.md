## 03.迭代 1：MVP 单机内存 KV（占位）

```go
// store/store.go
type Store struct {
    data map[string][]byte
}

func New() *Store { return &Store{data: make(map[string][]byte)} }
func (s *Store) Get(k string) ([]byte, bool) { v, ok := s.data[k]; return v, ok }
func (s *Store) Set(k string, v []byte)      { s.data[k] = v }
func (s *Store) Del(k string)                { delete(s.data, k) }
```

> **本案例完整代码、6 个迭代的所有实现细节、性能基准、与 Redis 对比将在卷二定稿阶段补全。**
