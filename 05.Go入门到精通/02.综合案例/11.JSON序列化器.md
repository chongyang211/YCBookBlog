## 01.需求说明
- `Marshal(v any) ([]byte, error)`
- `Unmarshal(data []byte, v any) error`
- 支持 struct / map / slice / 基础类型 / 指针
- 支持 `json:` Tag

## 03.编码器（占位）

func Marshal(v any) ([]byte, error) {
    var buf bytes.Buffer
    err := encode(&buf, reflect.ValueOf(v))
