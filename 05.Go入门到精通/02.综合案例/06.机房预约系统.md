## 01.需求说明
- 三种身份登录：学生、教师、管理员
- 学生申请预约（机房 + 时段 + 人数）
- 教师审核预约（通过 / 拒绝）
- 管理员管理账号、机房、重置数据

## 02.项目结构（多包）

## 08.项目总结
- 学会用包拆分模块（models / services / data）
- 学会用 JSON 文件做"小型多表"数据库

## 09.技术思考
1. 多个 JSON 文件之间如何保持一致性？事务怎么模拟？
2. 如果用户数据变多，单 JSON 文件加载慢，怎么改？
3. 把这个系统改成 HTTP API 服务要做哪些工作？

## 10.延伸挑战
1. 把 JSON 改用 SQLite，对比代码变化
2. 把 CLI 改用 `cobra` / `spf13/viper` 配置
3. 加上"教师审核未处理预警"功能（每 N 秒检查）
