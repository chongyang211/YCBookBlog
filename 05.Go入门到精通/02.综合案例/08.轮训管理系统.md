## 01.需求说明
- 注册多个任务，每个任务配执行频率（5s / 1min / 1h）
- 主循环按时间触发任务
- 支持 ctrl+c 优雅退出（先停 Ticker，再等任务完成）

## 03.Task 接口与策略（占位）
```go
type Task interface {
    Name() string
    Run(ctx context.Context) error
}

// 策略 1：函数式
type FuncTask struct {
    name string
    fn   func(ctx context.Context) error
}
```

> **本案例完整代码、cron 表达式解析、context 取消传播将在卷二定稿阶段补全。**
