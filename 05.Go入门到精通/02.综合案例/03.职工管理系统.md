## 01.需求说明
公司分三类人员：
- 员工：完成经理交给的任务
- 经理：完成老板交给的任务，分配任务给员工
- 老板：管理整个公司

操作：增加员工、显示信息、删除员工、修改信息、按岗位排序、清空、保存到文件、读取文件。

## 03.Worker 接口设计（占位）
```go
type Worker interface {
    ShowInfo()
    GetDeptName() string
}

// 三个实现
type Employee struct { ID int; Name string; DeptID int }
type Manager  struct { ID int; Name string; DeptID int }
type Boss     struct { ID int; Name string; DeptID int }

func (e *Employee) ShowInfo() { ... }
func (m *Manager)  ShowInfo() { ... }
func (b *Boss)     ShowInfo() { ... }
```

> **本案例完整代码、接口序列化的"类型标签"技巧将在卷二定稿阶段补全。**

## 07.项目总结
- 学会"小接口 + 多实现"的 Go 风格
- 学会接口序列化时的"类型标签"问题（JSON 不能直接保存 interface）

## 08.技术思考
1. 为什么 Go 没有继承？组合方案是否能完美替代？
2. JSON 反序列化 `[]Worker` 如何识别每个元素的具体类型？
3. 如果新增"实习生"类型，要改几处代码？
