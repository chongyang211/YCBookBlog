## 00.案例元信息

| 项目 | 内容 |
|---|---|
| 难度 | ⭐⭐ |
| 预估时长 | 4 小时 |
| 前置章节 | 卷一第 1-11 章 + 第 15 章 |
| 主题领域 | CLI 工具 + 文件 IO + JSON 持久化 |
| 最终产物 | `gotodo` 二进制（macOS / Linux / Windows 通用），可 `go install` |
| 0 第三方库 | ✅（仅 stdlib） |

**功能列表**：
- `gotodo add "买牛奶" --tag shopping --due 2026-06-01`
- `gotodo list [--filter done|todo --tag X]`
- `gotodo done 3` / `gotodo rm 3` / `gotodo edit 3 "新内容"`
- 数据持久化到 `~/.gotodo.json`，**原子写入**（写临时文件 + rename）
- 彩色输出（用 ANSI 转义码，不引入第三方库）
