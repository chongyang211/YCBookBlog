
# 第 8 章 指针与逃逸

> Go 的指针是"安全的指针"：可以取址、可以解引用，但**不能算术**。Go 的逃逸分析帮你决定变量在栈还是堆。
> 关键词：`&` / `*`、不能 `p++`、`new(T)` vs `&T{}`、栈逃逸到堆、`-gcflags="-m"`

## 8.13 Go 新手陷阱 Top 5（占位预览）

1. ❌ `var p *int; *p = 1` → nil 指针解引用 panic
2. ❌ 以为大对象传值会复制，于是滥用指针接收者 → 实际逃逸了，反而慢
3. ❌ 在循环里 `&v`（`for _, v := range s { ps = append(ps, &v) }`）→ Go 1.22 前所有指针指向同一个 v
4. ❌ 把 `*int` 当 `int *` 用（`*p++` 期望指针自增）→ 实际是值自增
5. ❌ 用 `unsafe.Pointer` 强转后假定布局 → 编译器不保证字段顺序
