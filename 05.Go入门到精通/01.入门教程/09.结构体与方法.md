## 9.1 本章学习目标

- ✅ 能根据"是否修改接收者 / 接收者大小 / 一致性"三条规则决定值 vs 指针接收者
- ✅ 能用嵌入字段实现"组合"而非继承
- ✅ 能写 struct Tag 配合 `encoding/json`
- ✅ 知道 struct 何时可比较

> **本章正文将在卷一定稿阶段补全。**

## 9.11 Go 新手陷阱 Top 5（占位预览）

1. ❌ 一个 struct 上方法混用值接收者和指针接收者 → 接口实现规则混乱
2. ❌ 给值接收者方法传 `*T` 调用 → 自动取值，但若 `*T` 是 nil 会 panic
3. ❌ 把 mutex 嵌入 struct 后值传递 → 锁被复制，并发安全失效
4. ❌ 期望 `struct{ s []int } == struct{ s []int }` → 含 slice 字段不可比较，编译错
5. ❌ 嵌入字段同名导致歧义而不显式选 → 编译错或行为难预测
