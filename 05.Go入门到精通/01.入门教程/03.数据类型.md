## 3.12 Go 新手陷阱 Top 5（占位预览）

1. ❌ `len(s)` 把字符串当字符数 → 实际是字节数，UTF-8 中文每字符 3 字节
2. ❌ 浮点比较 `a == b` → 必须 `math.Abs(a-b) < epsilon`
3. ❌ 用 `int` 存哈希值 → 32 位机和 64 位机宽度不同，应 `int64`
4. ❌ `string([]byte{0xFF, 0xFE})` 拼出来的字符串不是 UTF-8 → 跨包传递可能出错
5. ❌ 用 `reflect.DeepEqual` 比较 NaN → NaN != NaN，永远 `false`
