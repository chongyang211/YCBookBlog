## 6.8 Go 新手陷阱 Top 5（占位预览）

1. ❌ 写 `if (cond)` 多了括号 → Go 不要括号（虽然不报错）
2. ❌ `switch x { case 1: dosth(); case 2: ... }` 写完 case 1 还期望穿透到 case 2 → 不会，要 `fallthrough`
3. ❌ Go 1.21 及之前的循环变量陷阱（详见 1.5.7 节）
4. ❌ 用 `break` 跳出嵌套循环 → 只跳出一层，要用标签
5. ❌ `range` 遍历 map 期望顺序稳定 → Go 故意随机，依赖顺序的代码必错
