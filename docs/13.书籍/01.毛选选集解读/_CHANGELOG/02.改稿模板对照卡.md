# 改稿模板对照卡

> 打开这份文档 + 07 或 08 篇原文 + 待改的目标篇，三窗对照，逐章重写。
>
> 全书 54 篇共用一套骨架、共用一套语气、共用一套人物。

## 1. 章节骨架对照（12 章标准版）

```
┌─────────────────────────────────────────────────────────────┐
│ frontmatter                                                 │
│   title / date / permalink / categories / tags / author     │
├─────────────────────────────────────────────────────────────┤
│ 一句话主标题（80-120 字，讲清"这一篇解决什么问题"）         │
├─────────────────────────────────────────────────────────────┤
│ 目录（无 #### 目录介绍标题，让 ## 章节名自成目录）          │
├─────────────────────────────────────────────────────────────┤
│ ## 01. 一个真实场景                              300-500 字 │
│    ├─ 时间 + 地点 + 人物 + 对话（有具体日期最佳）          │
│    ├─ 冲突点在第 2-3 段抛出                                 │
│    └─ 末尾一句话过渡到"这一篇要解决的问题"                 │
├─────────────────────────────────────────────────────────────┤
│ ## 02. 市面误读之辨                              600-800 字 │
│    ├─ 列 2-3 派流行说法                                    │
│    ├─ 说清各自"偏在哪里"（不要"完全错"，要"偏在哪"）       │
│    └─ 引出"我们准备怎么讲"的悬念                           │
├─────────────────────────────────────────────────────────────┤
│ ## 03. 三层独家主张                              800-1000 字│
│    ├─ 主张一（一句话金句 + 简短论证）                      │
│    ├─ 主张二（同上）                                        │
│    └─ 主张三（同上）                                        │
│    这三个主张必须与全书其他篇的主张不重复                  │
├─────────────────────────────────────────────────────────────┤
│ ## 04. 历史现场溯源                              600-800 字 │
│    ├─ 毛主席讲这句话的年份 / 地点 / 场合                   │
│    ├─ 当时的形势与危机                                     │
│    └─ 他为什么必须讲、讲给谁听                             │
├─────────────────────────────────────────────────────────────┤
│ ## 05. 原文四维精读                              900-1100 字│
│    引 2-3 段原文，每段做四维分析：                          │
│      · 字眼：哪个词是关键                                  │
│      · 现场：当时具体在讲什么事                            │
│      · 张力：这句话与前后文的对立/递进                     │
│      · 反共识：与今天流行说法的差异                        │
├─────────────────────────────────────────────────────────────┤
│ ## 06. 核心体系拆解                              900-1100 字│
│    ├─ 独家方法论骨架（配 1 张表 或 1 段代码块示意图）      │
│    └─ 骨架的每一个节点用一段话讲透                         │
├─────────────────────────────────────────────────────────────┤
│ ## 07. 落地方法与工具                            900-1100 字│
│    ├─ 3-5 个可操作动作                                     │
│    ├─ 每个动作配"我在什么场景下用过"的具体片段             │
│    └─ 每个动作用一个动词开头（复盘 / 拆解 / 追问 / 记录）  │
├─────────────────────────────────────────────────────────────┤
│ ## 08. 历史示范案例                              600-800 字 │
│    毛主席自己怎么用这一套的一个案例：                       │
│      · 案例背景                                             │
│      · 他怎么做的                                          │
│      · 结果是什么                                          │
│      · 抽出与本篇方法论的对应关系                          │
├─────────────────────────────────────────────────────────────┤
│ ## 09. 商业切片一则                              700-900 字 │
│    近代或当代商业世界的一个案例（**必须从案例分工表领用**）│
│      · 公司/人物背景                                       │
│      · 关键动作                                             │
│      · 结果与启示                                          │
│      · 与本篇方法论的对应关系                              │
├─────────────────────────────────────────────────────────────┤
│ ## 10. 三个常见陷阱                              500-700 字 │
│    符合本模块反面人物类型的三个陷阱：                       │
│      · 陷阱一：（症状 → 后果 → 破解）                       │
│      · 陷阱二                                              │
│      · 陷阱三                                              │
├─────────────────────────────────────────────────────────────┤
│ ## 11. 三年认知复利                              500-700 字 │
│    ├─ 第一年：我看到什么/做到什么                          │
│    ├─ 第二年：我尝到什么/受挫什么                          │
│    └─ 第三年：我明白什么/身边人怎么看我                    │
├─────────────────────────────────────────────────────────────┤
│ ## 12. 收束三句金言 + 一个反问                   200-300 字 │
│    ├─ 金句一（可独立成海报）                               │
│    ├─ 金句二                                                │
│    ├─ 金句三                                                │
│    └─ 反问一句（逼读者当场做一件事）                       │
└─────────────────────────────────────────────────────────────┘

字数总和：7500-9000 字（含 frontmatter）
```

## 2. 章节名命名规范

**统一样式**：`## NN. 标题`（NN 为两位数字，标题不超过 9 个字，不含 emoji）

**允许的章节名池**（每篇从池里选，或用相近的自造名）：

| 章序 | 允许标题 |
|:--:|---|
| 01 | 真实场景 / 一次翻车 / 一次卡壳 / 那次深夜 / 那场会议 |
| 02 | 市面误读 / 常见误解 / 流行说法之辨 |
| 03 | 三层独家主张 / 我们的三条判断 / 与众不同的三点 |
| 04 | 历史现场 / 那年那地那人 / 讲话时的中国 |
| 05 | 原文四维精读 / 精读四维 / 字眼、现场、张力、反共识 |
| 06 | 核心体系 / 骨架拆解 / 方法论骨架 |
| 07 | 落地方法 / 五个动作 / 工具箱 |
| 08 | 历史示范 / 毛主席怎么用 / 井冈山那一战 |
| 09 | 商业切片 / 当代印证 / 一个案例 |
| 10 | 三个陷阱 / 三种翻车 / 三个反面 |
| 11 | 三年复利 / 三年之约 / 三年后的你 |
| 12 | 三句金言 / 收束三句 / 一句问你 |

**禁用**：`一图流` `硬核干货` `底层逻辑大揭秘` `万字长文` `保姆级`

## 3. 语气标准（07/08 参照）

以 07 篇《辩证思维矛盾论法》和 08 篇《科学方法实践论法》为语气基准，全书统一到这种气质：

**允许的语气特征：**
- 直呼"你"、偶尔"我们"，不称"读者"
- 每章至少 1 处使用短句（3-5 字）
- 每章至少 1 处引用真实数据（不夸张、不魔幻）
- 每章至少 1 处对话或人物动作
- 每章允许 1-2 处小反问（"你说说，这一步该不该跳？"）

**禁止的语气特征：**
- 排比句连排 3 个以上
- 全段加粗
- 每句话结尾都是"！"
- 用"我要告诉你的是……"这类预告式开头
- 全篇没有一个具体人物名字

## 4. 交叉引用格式

**同书内引用其他篇**：正文里可用两种方式

方式一（简短引用）：
> 关于"矛盾方法论"的定义，本书 2.1 篇（《辩证思维矛盾论法》）已经讲透，此处不再展开。

方式二（脚注跳转，前端可实现）：
> 这一步的调查方法在实操上有讲究[^1]。
>
> [^1]: 详见本书 2.3 篇《调查观念》§07。

**引用毛选原文**：统一格式

```markdown
> 「原文」——毛泽东，《文章名》，写作年份，人民出版社《毛泽东选集》第 X 卷第 Y 页
```

## 5. 一篇改稿的具体计时法

对一篇原本 ~12000 字、模板不齐、有重复的稿子，改造耗时参考：

| 步骤 | 耗时 | 产出 |
|---|:--:|---|
| 1. 通读一遍原稿，标注要保留段落 | 20 分钟 | 心里有全景 |
| 2. 骨架对齐（缺章补、多章并） | 30 分钟 | 12 章框架搭好 |
| 3. 去重（对照分工表，删/改边界外内容） | 40 分钟 | 独家边界清晰 |
| 4. 领案例（§09 商业切片） | 15 分钟 | 表里勾一格 |
| 5. 逐章重写 | 3-4 小时 | 出版级文字 |
| 6. 语言刮油（模板句/禁用词/加粗密度） | 30 分钟 | AI 味归零 |
| 7. 元信息 + 交叉引用 | 15 分钟 | 元数据合规 |
| 8. 打勾验收 14 项 | 10 分钟 | 完稿 |

**总计：5-6 小时 / 篇**。54 篇（含 07/08 保留），扣掉 41/48/51/54 的重活估算，全书打磨预计 **300-350 小时**。按每天 4 小时投入，约 **75-88 天**。

## 6. 一份改稿工作台样例

推荐工作台环境：

```
+---------------------------+---------------------------+
|   目标篇 (待改)           |   07 或 08 篇 (基准)     |
|                           |                           |
|                           |                           |
+---------------------------+---------------------------+
|   00.改造总方案.md        |   01.现状诊断表.md       |
|                           |                           |
+---------------------------+---------------------------+
|   附录 B · 一句话定位表   |   案例分工表 (§5.2)      |
+---------------------------+---------------------------+
```

四份文档同时打开，改一篇不迷路。

## 附：一份"改完之后"自查提问

改完一篇，问自己 8 个问题。全部答"是"，才算完稿：

1. 这一篇跟其他 53 篇任何一篇比较，我能一句话说清"独家讲什么"吗？
2. 开篇场景有没有具体日期、地点、对话？
3. §05 里的原文引用，是不是"字眼—现场—张力—反共识"四维都做到了？
4. §09 的商业切片，是不是分工表里刚领的、其他篇没用过的？
5. 全篇没有出现禁用词（硬核、底层逻辑、干货、一图流）？
6. 加粗密度是不是每 500 字不超过 3 处？
7. 有没有至少 1 处引用其他篇章，让读者感觉到主线？
8. §12 的三句金言，能不能独立成海报，从任何一句反推到这整篇的立论？

**8 个"是"，出版级完稿。**
