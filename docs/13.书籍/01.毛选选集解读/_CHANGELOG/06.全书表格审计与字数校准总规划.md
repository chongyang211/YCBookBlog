## 二、两条独立战线

### 战线 A：表格审计（清除违规表格）

**判定框架**（复用 05 号方案的三条硬标准）：
1. 对照维度 ≥ 3 列
2. 每格文字 ≤ 8 字
3. 散文化后会真丢信息

**任一不满足 → 改散文 or 删除**

**改造上限**：每篇保留表格 **≤ 4 张**。

### 战线 B：字数校准

- **超量篇** → 表格瘦身 + 长句收紧
- **严重偏少篇** → 补充"历史现场 / 三层原因 / 现代职场 / 生活映射"四类内容
- **目标区间** 7500-9000 字正文（对应 9000-11500 字符）

两条战线在**表格重灾区**是重叠的：删表 = 瘦身；轻量区/零表区偏少的篇章则纯扩写。

## 四、执行流程（每篇统一 SOP）

1. **读原文** → 逐张表过三条硬标准
2. **列改造清单**：保留 X 张 / 改散文 Y 张 / 删 Z 张
3. **执行 replace_in_file 或 write_to_file 重写**
4. **wc -m 校验字符数** 落入 9000-11500 区间
5. **read_lints 校验零错误**
6. **抽查一段**：读后感是否比原表更顺滑
