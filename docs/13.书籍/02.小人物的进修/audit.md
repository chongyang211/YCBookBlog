## 六、模板雷同点（P3 拆解要点）

抽样发现 55 篇正文大多按"**九段套**"堆叠，读多易疲劳。P3 阶段按 **A/B/C 三模板轮换**：

**九段套（现状）**：
```
本章目标 → 什么是 XX → 为什么用 → 步骤/结构 → 01.看真实案例 → 表格 → 
课后作业思考下 → 图示 → 常见误区
```

**A 故事型**（用于 01/02/05/22/40/56/57 等偏叙事章）：故事—反思—点题—方法—回响

**B 方法工具型**（用于 23-38 等方法论章）：一句话定义—场景—步骤—案例—模板—踩坑

**C 能力修炼型**（用于 41-55 等能力章）：能力画像—自测—训练路径—里程碑—复用

**动作**：P3 时按分类给每章打标签，删除该模板不需要的段落头，避免全书都出现"01.看真实案例"这种标签堆。

### 表格使用规约（P3/P4 全书统一）

> **用户明确要求**：正文中不要用表格罗列"踩坑—表现—破解""里程碑—表现—周期"这类**软性说明信息**。改用**段落文字**表达，语气更接近作者口吻，也更符合书面阅读的连贯性。

**允许保留表格的场景**（本身就是"矩阵/对比/结构"知识，属于教学目标）：
- 决策矩阵、评分表、SWOT/RACI/BCG 等**方法本身就是矩阵**的展示
- 状态对比表（如 49 章"真专注/假专注/碎片专注"、53 章"质疑 vs 抬杠"）
- 首讲章的核心结构总览（如 26 MECE、30 PDCA）

**禁止使用表格的场景**（改成文字段落）：
- 踩坑清单：改成"**第一个是…；第二个是…**"的段落
- 能力里程碑：改成"**L1 …大约前 X 周；L2 …；L3 …**"的段落
- 训练清单：改成 Day 1 / Day 2 的行内叙述或数字列表
- 常见误区、易错点、注意事项

**允许的清单形式**：
- 数字列表（1. 2. 3.）——用于**流程/步骤/评审项**（如 53 章"5 问 1 反例"、54 章"5 步流程"）
- 无序列表（-）——仅用于短标签罗列，不用于展开说明

**P3 已完成本条对 49–54 六篇的执行**：踩坑表 / 里程碑表已全部改为段落文字；数字列表清单予以保留。
