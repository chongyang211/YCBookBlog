## 01.命名规范

| 类型 | 规范 | 示例 |
|:-----|:-----|:-----|
| 模块/文件 | snake_case | `user_service`, `db_connection` |
| 类型/结构体/枚举 | CamelCase | `HttpClient`, `UserRepository` |
| trait | CamelCase | `Display`, `FromStr`, `Iterator` |
| 函数/方法 | snake_case | `get_user()`, `parse_config` |
| 常量/静态 | SCREAMING_SNAKE | `MAX_RETRIES`, `DEFAULT_PORT` |
| 变量 | snake_case | `user_count`, `file_path` |

## 02.所有权与借用

```rust
// ✅ 优先借用而非获取所有权
fn process(data: &[u8]) -> usize {  // 借用：不影响调用方
    data.len()
}

// ✅ 需要修改时用可变借用
fn update(config: &mut Config) {
    config.timeout = 30;
}

// ✅ 明确所有权转移
fn consume(data: Vec<u8>) {  // 获取所有权
    // data 在此函数结束时被释放
}

// ❌ 避免不必要的 clone
// let copy = data.clone();  // 除非确实需要独立副本

// ✅ 借用规则：
//   1. 同时只能有一个可变借用，或多个不可变借用
//   2. 借用不能超过所有者的生命周期
```

## 03.错误处理

```rust
// ✅ Result 而非 panic
fn parse(s: &str) -> Result<i32, ParseIntError> {
    s.parse()
}

// ✅ ? 操作符传播错误
fn read_config() -> Result<Config, Error> {
    let content = std::fs::read_to_string("config.toml")?;
    let config: Config = toml::from_str(&content)?;
    Ok(config)
}

// ✅ 自定义错误类型（推荐 thiserror）
#[derive(Debug, thiserror::Error)]
pub enum AppError {
    #[error("IO error: {0}")]
    Io(#[from] std::io::Error),
    #[error("Config error: {0}")]
    Config(String),
    #[error("Not found: {0}")]
    NotFound(String),
}

// ✅ Option 处理
let user = find_user(id).ok_or(AppError::NotFound("user".into()))?;
```

## 04.模式匹配

```rust
// ✅ match 穷举
let status = match code {
    200..=299 => Status::Success,
    400..=499 => Status::ClientError,
    500..=599 => Status::ServerError,
    _ => Status::Unknown,
};

// ✅ if let 单分支
if let Some(user) = find_user(id) {
    println!("{}", user.name);
}

// ✅ let-else 提前返回（Rust 1.65+）
let Some(config) = read_config() else {
    return Err(AppError::Config("missing config".into()));
};

// ✅ while let 循环
while let Some(item) = iter.next() {
    process(item);
}
```

## 05.模块组织

```rust
// 模块声明
mod api;
mod db;
mod models;
mod service;

// 公开接口（re-export）
pub use api::Client;
pub use models::User;
pub use service::UserService;

// 可见性：默认私有，按需 pub
pub struct PublicType { ... }
struct PrivateType { ... }  // 仅在当前模块可见
```

## 06.常用宏与 derive

```rust
// ✅ derive 自动实现标准 trait
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct User {
    pub id: i64,
    pub name: String,
    pub email: Option<String>,
}

// ✅ 构造宏
let v = vec![1, 2, 3];
let msg = format!("Hello, {}!", name);

// ✅ todo! / unimplemented! 占位
fn unfinished() -> i32 {
    todo!("还没实现")
}
```

## 07.测试规范

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_add() {
        assert_eq!(add(2, 3), 5);
    }

    #[test]
    fn test_parse_error() {
        let result = parse("abc");
        assert!(result.is_err());
    }

    // ✅ 测试 panic
    #[test]
    #[should_panic(expected = "division by zero")]
    fn test_divide_by_zero() {
        divide(1, 0);
    }

    // ✅ 异步测试
    #[tokio::test]
    async fn test_async() {
        let data = fetch().await.unwrap();
        assert!(!data.is_empty());
    }
}
```

## 08.常见反模式

| 反模式 | 问题 | 改进 |
|:-------|:-----|:-----|
| 过多 `.clone()` | 性能、语义不清 | 借用或重新设计所有权 |
| 不必要的 `unwrap()` | 崩溃风险 | `?` 或 `match` |
| `unsafe` 滥用 | 内存安全风险 | 优先安全 Rust |
| 过长的函数 | 难以维护 | 40 行内拆分 |
| 全局可变状态 | 并发问题 | 封装 + 同步 |

## 09.工具链

```bash
# 推荐使用

```

## 10.代码审查清单

```markdown
## 所有权
- [ ] 无不必要的 .clone()
- [ ] 借用/所有权转移语义正确
- [ ] 无生命周期标注缺失导致的编译错误迹象
- [ ] 无 unsafe 块（除非有充分理由 + 安全注释）

## 错误处理
- [ ] 用 Result 而非 panic
- [ ] 无裸 unwrap()（除非逻辑上不可能失败 + 注释说明）
- [ ] 用 ? 传播错误
- [ ] 自定义错误类型语义清晰

## 模式匹配
- [ ] match 穷举所有分支
- [ ] 单分支用 if let
- [ ] let-else 提前返回

## 测试
- [ ] 核心逻辑有单元测试
- [ ] 覆盖正常和异常路径
```
