# Python 代码规范

基于 [PEP 8](https://peps.python.org/pep-0008/) 和 [Google Python Style Guide](https://google.github.io/styleguide/pyguide.html)。

## 一、命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 模块/包 | 小写 + 下划线 | `my_module`, `data_utils` |
| 类 | 大驼峰 | `MyClass`, `DataProcessor` |
| 函数/方法 | 小写 + 下划线 | `get_user()`, `calculate_total` |
| 变量 | 小写 + 下划线 | `user_count`, `max_retries` |
| 常量 | 全大写 + 下划线 | `MAX_SIZE`, `DEFAULT_TIMEOUT` |
| 私有成员 | 单下划线前缀 | `_internal_method`, `_private_var` |
| 魔术方法 | 双下划线前后 | `__init__`, `__str__` |

```python
# good
class UserProfile:
    MAX_NAME_LENGTH = 50
    
    def __init__(self, user_id: int):
        self._id = user_id
        self.name: str = ""

    def get_display_name(self) -> str:
        return self.name or f"User_{self._id}"
```

## 二、代码格式

```python
# 缩进：4 个空格
def long_function_name(
    var_one: int,
    var_two: str,
    var_three: float,
) -> dict:
    result = {
        "one": var_one,
        "two": var_two,
    }
    return result

# 行长度：最多 120 字符
# 空行：类之间 2 空行，方法之间 1 空行
# import 顺序：标准库 → 第三方 → 本地
import os
import sys
from typing import Optional

import requests
from flask import Flask

from myapp.utils import helper
```

## 三、类型注解

```python
from typing import Optional, List, Dict, Union

# 函数注解
def find_user(user_id: int) -> Optional[Dict[str, str]]:
    """查找用户，找不到返回 None"""
    ...

# 变量注解
users: List[str] = []
config: Dict[str, Union[str, int]] = {}

# 类属性注解
class DataStore:
    cache: Dict[str, bytes]
    max_size: int = 1024 * 1024
    
    def __init__(self) -> None:
        self.cache = {}
```

## 四、字符串与文档

```python
# 优先使用 f-string
name = "World"
msg = f"Hello, {name}!"

# 多行字符串
query = """
    SELECT id, name, email
    FROM users
    WHERE active = 1
    ORDER BY name
"""

# Docstring（三引号）
def calculate(price: float, tax: float = 0.1) -> float:
    """计算含税价格。
    
    Args:
        price: 原始价格
        tax: 税率，默认 0.1
        
    Returns:
        含税总价
    """
    return price * (1 + tax)
```

## 五、比较与条件

```python
# 与 None 比较用 is
if user is None:
    return

if data is not None:
    process(data)

# 空序列判断
if not items:        # 而非 len(items) == 0
    return []

# 布尔值直接判断
if is_active:        # 而非 is_active == True
    ...

# 三目运算符
status = "active" if user.is_active else "inactive"
```

## 六、异常处理

```python
# 捕获具体异常
try:
    result = api.call()
except ConnectionError as e:
    logger.error(f"API 连接失败: {e}")
    raise
except ValueError:
    return default_value
finally:
    cleanup()

# 自定义异常
class ValidationError(Exception):
    """数据校验异常"""
    def __init__(self, field: str, msg: str):
        self.field = field
        super().__init__(f"{field}: {msg}")
```

## 七、列表/字典推导

```python
# 列表推导
squares = [x * x for x in range(10)]
active_users = [u for u in users if u.is_active]

# 字典推导
name_map = {u.id: u.name for u in users}

# 生成器表达式（大数据量时用）
total = sum(x * x for x in big_dataset)
```

## 八、上下文管理器

```python
# 文件操作
with open("data.json", "r") as f:
    content = f.read()

# 自定义上下文管理器
from contextlib import contextmanager

@contextmanager
def timer(name: str):
    start = time.time()
    yield
    elapsed = time.time() - start
    print(f"{name}: {elapsed:.2f}s")

with timer("计算"):
    heavy_computation()
```

## 九、常见反模式

```python
# ❌ 可变默认参数
def add_item(item, items=[]):
    items.append(item)
    return items

# ✅ 正确做法
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

# ❌ 循环中拼接字符串
result = ""
for s in strings:
    result += s

# ✅ 使用 join
result = "".join(strings)
```
