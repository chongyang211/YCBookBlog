# Go 代码规范

基于 [Effective Go](https://go.dev/doc/effective_go) 和 [Uber Go Style Guide](https://github.com/uber-go/guide)。

## 一、命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 包名 | 小写，单数，无下划线 | `http`, `json`, `user` |
| 导出标识符 | 大写开头 | `User`, `GetName()` |
| 私有标识符 | 小写开头 | `user`, `parseData()` |
| 接口 | 单方法接口加 `er` | `Reader`, `Closer` |
| 变量 | 驼峰法 | `userCount`, `maxRetry` |
| 常量 | 驼峰法 | `MaxSize`, `DefaultPort` |
| 缩写 | 全大写或全小写 | `HTTPClient`, `urlPath` |

```go
// good
package user

type Service struct {
    repo Repository
}

func (s *Service) GetByID(id int64) (*User, error) {
    return s.repo.FindByID(id)
}

// 接口命名
type Reader interface {
    Read(p []byte) (n int, err error)
}
```

## 二、代码格式

Go 有官方格式化工具，直接用即可：

```bash
# 格式化
go fmt ./...
goimports -w .

# 代码检查
go vet ./...
golangci-lint run
```

```go
// 分组导入
import (
    "context"
    "fmt"
    
    "github.com/pkg/errors"
    
    "myproject/internal/config"
)

// 结构体字段对齐（go vet 会检查）
type User struct {
    ID        int64     `json:"id"`
    Name      string    `json:"name"`
    CreatedAt time.Time `json:"created_at"`
}
```

## 三、错误处理

```go
// ✅ 始终检查错误
result, err := doSomething()
if err != nil {
    return fmt.Errorf("doSomething: %w", err)
}

// ✅ 包装错误，保留上下文
if err := validate(user); err != nil {
    return fmt.Errorf("validating user %d: %w", user.ID, err)
}

// ✅ 仅记录一次错误
data, err := fetchData()
if err != nil {
    log.Printf("fetchData failed: %v", err)  // 这里记日志
    return err                                // 上层不应再记
}

// ❌ 忽略错误
_ = json.Unmarshal(data, &v)  // 除非有充分理由
```

## 四、并发模式

```go
// ✅ sync.WaitGroup
var wg sync.WaitGroup
for _, url := range urls {
    wg.Add(1)
    go func(u string) {
        defer wg.Done()
        fetch(u)
    }(url)
}
wg.Wait()

// ✅ context 传递取消信号
func Process(ctx context.Context, input string) error {
    select {
    case <-ctx.Done():
        return ctx.Err()
    case result := <-doWork(input):
        return handle(result)
    }
}

// ✅ channel 关闭由发送方负责
ch := make(chan int)
go func() {
    defer close(ch)
    for _, v := range data {
        ch <- v
    }
}()
```

## 五、零值利用

```go
// ✅ 零值就是有用的初始值
var buf bytes.Buffer       // 可直接 Write
var mu sync.Mutex          // 可直接 Lock/Unlock
var wg sync.WaitGroup      // 可直接 Add/Wait

// ✅ 切片空值判 nil 而非 len
if users == nil {
    users = make([]User, 0)
}
```

## 六、defer 使用

```go
// ✅ 资源释放
f, err := os.Open("file.txt")
if err != nil {
    return err
}
defer f.Close()

// ✅ 注意 defer 参数求值时机
func trace(name string) func() {
    start := time.Now()
    return func() {
        log.Printf("%s took %v", name, time.Since(start))
    }
}
defer trace("query")()  // 注意 () 调用

// ❌ 循环中 defer 导致资源泄漏
for _, f := range files {
    fd, _ := os.Open(f)
    defer fd.Close()  // 全部延迟到函数结束
}

// ✅ 循环中用闭包
for _, f := range files {
    func() {
        fd, _ := os.Open(f)
        defer fd.Close()
        process(fd)
    }()
}
```

## 七、测试规范

```go
// 表驱动测试
func TestAdd(t *testing.T) {
    tests := []struct {
        name string
        a, b int
        want int
    }{
        {"正数", 1, 2, 3},
        {"零", 0, 0, 0},
        {"负数", -1, 1, 0},
    }
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            if got := Add(tt.a, tt.b); got != tt.want {
                t.Errorf("Add() = %v, want %v", got, tt.want)
            }
        })
    }
}

// testify 断言
func TestUser(t *testing.T) {
    u := NewUser("name")
    assert.NotNil(t, u)
    assert.Equal(t, "name", u.Name)
}
```

## 八、包组织

```go
// 按功能分层，避免循环依赖
myapp/
├── cmd/          // 入口
├── internal/
│   ├── handler/  // HTTP handler
│   ├── service/  // 业务逻辑
│   ├── repo/     // 数据访问
│   └── model/    // 数据模型
├── pkg/          // 可公开的库
└── go.mod
```
