## 为什么选择 CloudBase

CloudBase（腾讯云开发）提供免费的静态网站托管，支持自定义域名、自动 HTTPS、CDN 加速。适合个人博客等静态站点。

## 部署步骤

### 1. 安装 CLI 工具

```bash
npm i -g @cloudbase/cli
```

### 2. 登录授权

```bash
tcb login
```

浏览器会自动弹出授权页面，确认即可。

### 3. 部署

进入项目根目录，先构建：

```bash
npm run build
```

然后部署 `docs/.vuepress/dist/` 目录：

```bash
tcb hosting deploy ./docs/.vuepress/dist/ ./ -e yc-1g9e44gm9bde451e
```

| 参数 | 说明 |
|------|------|
| `./docs/.vuepress/dist/` | 构建产物目录 |
| `./` | 部署到云端根目录 |
| `-e yc-1g9e44gm9bde451e` | 环境 ID |

### 4. 访问

部署完成后，通过以下地址访问：

- **自定义域名**：[yccoding.com](https://yccoding.com)
- **默认域名**：`yc-1g9e44gm9bde451e-1258362742.tcloudbaseapp.com`

## 一键脚本

在 `package.json` 中添加部署脚本：

```json
"scripts": {
  "deploy": "npm run build && tcb hosting deploy ./docs/.vuepress/dist/ ./ -e yc-1g9e44gm9bde451e"
}
```

以后只需一条命令：

```bash
npm run deploy
```

## 注意事项

1. 确保 `tcb login` 已完成，否则部署会失败
2. 自定义域名需在 CloudBase 控制台绑定并配置 DNS
3. 首次部署后 CDN 有缓存，如未立即生效可稍等或手动刷新
