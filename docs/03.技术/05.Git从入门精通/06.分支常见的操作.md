## 04.修改本地和远程分支

假设你想将本地分支 `feature/old` 重命名为 `feature/new`，并同步到远程仓库：

1. 重命名本地分支：使用 `git branch -m` 命令可以重命名本地分支。
    ```bash
    git branch -m feature/old feature/new
    ```
2. 删除远程旧分支：在重命名本地分支后，远程仓库中的旧分支仍然存在。你需要先删除远程旧分支。
   ```bash
   git push origin --delete feature/old
   ```
3. 推送新分支到远程仓库：将本地重命名后的分支推送到远程仓库。
   ```bash
   git push origin feature/new
   ```
4. 更新本地分支与远程分支的关联：如果本地分支之前已经与远程分支关联，重命名后需要更新关联关系。
   ```bash
   git branch --set-upstream-to=origin/feature/new feature/new
   ```
