## 01.git开发技巧

1. 同一个分支多个人开发，提交前一定先pull --rebase，再push
2. feature分支开发，每天rebase一次develop最新的提交，方便减少冲突
3. 两个分支合并时，如feature合并入develop，可以merge，这样可以保留一个需求的开发支线记录
