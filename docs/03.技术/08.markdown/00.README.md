# Markdown 写作指南

从基础语法到高效写作，覆盖 Markdown 所有常用技巧的完整教程系列。

## 学习路线

```
第1篇（30min）→ 第2篇（45min）→ 第3篇（1h）→ 第4篇（30min）
   基础语法         高级语法         实战工具         写作心得
```

| 编号 | 文章 | 核心内容 | 建议时长 |
|------|------|----------|----------|
| 01 | 基础语法应用 | 标题/文本/列表/链接/图片/代码块/引用/表格 | 30 min |
| 02 | 高级语法应用 | HTML嵌入/脚注/数学公式/图表/Emoji | 45 min |
| 03 | 实战与工具篇 | 排版规范/编辑器/格式转换/自动化工具/写作建议 | 60 min |
| 04 | 我的写作之路 | 写作理念/方法论/坚持策略 | 30 min |

## 快速入门

```markdown
# 一级标题
## 二级标题

**粗体** *斜体* `代码`

- 无序列表
1. 有序列表

[链接](url)
![图片](url)

> 引用文字

| 表头1 | 表头2 |
|-------|-------|
| 单元格 | 单元格 |
```

## 核心心法

1. **"写"比"写得好"更重要** - 先完成，再完美
2. **一篇文章只讲一件事** - 聚焦核心，不贪多
3. **代码 + 截图 + 说明** - 三者缺一不可
4. **读者视角** - 假设读者什么都不懂，从零开始讲
5. **持续输出** - 每周至少一篇，形成习惯

## 适用人群

- 想系统学习 Markdown 的初学者
- 希望提升技术写作效率的开发者
- 需要规范文档格式的团队
