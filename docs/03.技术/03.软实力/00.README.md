# 软实力系列

> 技术决定下限，软实力决定上限

## 系列导读

代码写得好是一回事，能不能让人听懂、能不能推动决策、能不能带人——这些"软"的东西往往是职业天花板。本系列覆盖写作、沟通、演讲、时间管理、职业规划、影响力建设。
