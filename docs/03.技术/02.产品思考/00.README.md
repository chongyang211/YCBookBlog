# 产品思考系列

> 程序员的产品思维——代码之外，你造的到底是谁用的

## 系列导读

技术方案的价值 = 技术深度 × 用户价值。本系列从需求分析到功能优先级，从MVP策略到数据驱动，帮你建立工程师的产品直觉。
