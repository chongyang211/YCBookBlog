# 开源协议总览：速查 + 选择决策树

## 一、核心三问

任何开源协议本质上都在回答三个问题：

- **能用吗？** —— 可以商用、修改、分发吗？
- **有什么条件？** —— 需要署名、开源、保留协议吗？
- **有什么限制？** —— 专利？商标？传染性？

---

## 二、速查表

| 协议 | 商用 | 修改 | 分发 | 闭源 | 专利 | 署名 | 传染性 |
|------|:----:|:----:|:----:|:----:|:----:|:----:|:------:|
| MIT | ✅ | ✅ | ✅ | ✅ | ❌ | ✅ | 无 |
| Apache 2.0 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | 无 |
| BSD 2-Clause | ✅ | ✅ | ✅ | ✅ | ❌ | ✅ | 无 |
| BSD 3-Clause | ✅ | ✅ | ✅ | ✅ | ❌ | ✅ | 无 |
| GPL 2.0 | ✅ | ✅ | ✅ | ❌ | ❌ | ✅ | ⚠️ 强 |
| GPL 3.0 | ✅ | ✅ | ✅ | ❌ | ✅ | ✅ | ⚠️ 强 |
| LGPL | ✅ | ✅ | ✅ | ✅ | ❌ | ✅ | ⚠️ 弱 |
| MPL 2.0 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ⚠️ 文件级 |
| Unlicense | ✅ | ✅ | ✅ | ✅ | ❌ | ❌ | 无 |

> **传染性**：用了该协议代码，你是否也必须用相同协议开源。强 = 整个项目，弱 = 仅修改部分，文件级 = 仅修改的文件。

---

## 三、一句话总结

| 协议 | 一句话 |
|------|--------|
| MIT | 最宽松，只需署名。React、Vue、jQuery 都在用 |
| Apache 2.0 | MIT + 专利保护 + 商标保护。K8s、Android 在用 |
| BSD 3-Clause | MIT + 禁止用作者名义推广 |
| GPL v3 | 用了就必须全开源。Linux 内核在用 |
| LGPL | GPL 的温和版，动态链接可以闭源 |
| MPL 2.0 | 改了哪个文件，哪个文件开源 |
| Unlicense | 放弃一切权利，进入公共领域 |

---

## 四、选择决策树

```
你的目标是什么？
│
├── 个人小工具，无所谓别人怎么用
│   → MIT（第2章详解）
│
├── 公司项目，需要专利保护
│   → Apache 2.0（第3章详解）
│
├── 希望最大化使用率，不在乎别人闭源商用
│   → MIT、BSD 2-Clause（第2章、第5章）
│
├── 核心产品，不想被竞品闭源复制
│   → GPL v3（第4章详解）
│
├── 基础库，既想保护又想商业可用
│   → LGPL 或 MPL 2.0（第4章、第5章）
│
├── 完全放弃所有权利
│   → Unlicense
│
└── 不确定 → 默认选 MIT
```
