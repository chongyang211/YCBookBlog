# Rust 代码规范

基于 [Rust Style Guide](https://doc.rust-lang.org/nightly/style-guide/) 和 clippy lint。

使用 `rustfmt` 和 `clippy` 自动检查。

## 一、命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 模块 | snake_case | `user_service`, `db_connection` |
| 类型/结构体/枚举 | CamelCase | `HttpClient`, `UserRepository` |
| 函数/方法 | snake_case | `get_user()`, `parse_config` |
| 常量/静态 | SCREAMING_SNAKE | `MAX_RETRIES`, `DEFAULT_PORT` |
| 变量 | snake_case | `user_count`, `file_path` |
| trait | CamelCase | `Display`, `FromStr` |

## 二、所有权与借用

```rust
// ✅ 优先借用而非获取所有权
fn process(data: &[u8]) -> usize {  // 借用
    data.len()
}

// ✅ 需要修改时用可变借用
fn update(config: &mut Config) {
    config.timeout = 30;
}

// ✅ 明确所有权转移
fn consume(data: Vec<u8>) {  // 获取所有权
    // data 在此函数结束时被释放
}

// ❌ 避免不必要的 clone
let copy = data.clone();  // 除非确实需要
```

## 三、错误处理

```rust
// ✅ Result 而非 panic
fn parse(s: &str) -> Result<i32, ParseIntError> {
    s.parse()
}

// ✅ ? 操作符传播错误
fn read_config() -> Result<Config, Error> {
    let content = std::fs::read_to_string("config.toml")?;
    let config: Config = toml::from_str(&content)?;
    Ok(config)
}

// ✅ 自定义错误类型
#[derive(Debug, thiserror::Error)]
pub enum AppError {
    #[error("IO error: {0}")]
    Io(#[from] std::io::Error),
    #[error("Config error: {0}")]
    Config(String),
    #[error("Not found: {0}")]
    NotFound(String),
}
```

## 四、模式匹配

```rust
// ✅ match 穷举
let status = match code {
    200..=299 => Status::Success,
    400..=499 => Status::ClientError,
    500..=599 => Status::ServerError,
    _ => Status::Unknown,
};

// ✅ if let 单分支
if let Some(user) = find_user(id) {
    println!("{}", user.name);
}

// ✅ let else 提前返回
let Some(config) = read_config() else {
    return Err(AppError::Config("missing config".into()));
};
```

## 五、模块组织

```rust
// 模块声明
mod api;
mod db;
mod models;
mod service;

// 公开接口
pub use api::Client;
pub use models::User;
pub use service::UserService;
```

## 六、常用宏

```rust
// ✅ derive 自动实现
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct User {
    pub id: i64,
    pub name: String,
    pub email: Option<String>,
}

// ✅ vec! 宏
let v = vec![1, 2, 3];

// ✅ format! 宏
let msg = format!("Hello, {}!", name);
```

## 七、测试

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_add() {
        assert_eq!(add(2, 3), 5);
    }

    #[test]
    fn test_parse_error() {
        let result = parse("abc");
        assert!(result.is_err());
    }
    
    #[tokio::test]
    async fn test_async() {
        let data = fetch().await.unwrap();
        assert!(!data.is_empty());
    }
}
```
