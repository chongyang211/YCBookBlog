# 00.Kotlin 核心原理专栏总览

> 5 篇文章，每一篇都严格套用 [C++ 专栏写作模板](../../../../11.CodeX/02.Cpp入门到精通/03.专栏博客/61.写作模板.md) 的十章法。
> 与 C++ 专栏的差异在于：**Kotlin 侧沉到 JVM 字节码，而非汇编**。

## 一、选题标准

每一篇选题都必须同时满足以下 3 条：

1. **Kotlin 独有**——Java 没有或语义不同的机制（否则去写 Java 专栏）
2. **有字节码可挖**——能用 `javap -p -v` 或 IntelliJ 反编译看到编译产物差异
3. **有真实事故素材**——线上事故、面试踩坑、开源库 issue 皆可

## 二、5 篇选题全景

| # | 篇名 | 开篇案例（第 1 章埋线） |
|---|---|---|
| 01 | [空安全类型原理](./01.空安全类型原理.md) | 声明成 `String` 的字段为何还能 NPE？平台类型的双面性 |

| 05 | [委托与属性原理](./05.委托与属性原理.md) | `by lazy(NONE)` 偶发 NPE；`Delegates.observable` 泄漏 Fragment |

## 三、十章法结构（必须严守）

```
1. 案例引入        真实线上事故 / 反直觉代码，末尾列 5~7 个疑问
2. 架构概览        一张总图 + 反向论证"为什么这么切"
3~9. 原理拆解      5~7 章，每章 4~9 节，节按"疑惑→论证→结论"三段式
10. 综合案例串讲   回扣第 1 章，逐条回答疑问，升华 3~4 条设计哲学
```

## 四、Kotlin 专属六项要求（覆盖检查表）

每篇写完后自检：

- [ ] 关键点是否给出 JVM 字节码或 IntelliJ 反编译片段？
- [ ] 是否涉及 Kotlin/Native、Kotlin/JS 的实现差异？
- [ ] 是否标注特性在哪个 Kotlin 版本引入或稳定？
- [ ] 声称"零开销"处是否有字节码 diff 佐证？
- [ ] 是否明确指出 Java 互操作侧的陷阱？
- [ ] 涉及并发处是否给出协程 vs 线程对比？
