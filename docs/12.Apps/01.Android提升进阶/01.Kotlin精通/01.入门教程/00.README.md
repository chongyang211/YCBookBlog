# 00.Kotlin 入门教程总览

> 3 篇速通，读完能读懂 Android 项目 80% 的 Kotlin 代码，并写出符合团队风格的实用代码。

## 一、三篇定位

| 篇 | 主题 | 一句话 |
|---|---|---|
| 01 | Kotlin 基础语法 | 变量、类型、空安全、函数、集合、控制流 |
| 02 | 类和对象 | 类系统全景 + 6 种特殊类 + 委托 + 底层原理 |
| 03 | 高阶特性入门 | 扩展函数、Lambda、DSL、协程初识、Java 互操作 |

## 二、每篇通用骨架

仿 `docs/11.CodeX/02.Cpp入门到精通/01.入门教程/09.类和对象.md`：

```
N.1 ~ N.M   知识点讲解（每节含案例）
N.M+1       综合案例与思考
N.M+2       底层原理浅析（仅篇 2、篇 3 有）
N.M+3       训练题 3 道
N.M+4       新手陷阱 Top 5
```

## 三、如何配合原理专栏阅读

- **先入门再原理**：入门篇讲"用法"，原理篇讲"为什么这么设计 + 编译成什么"
- **回读技巧**：读完原理篇 1（空安全）后，再回头看入门篇 1 的 1.3 节，你会看见另一层世界
