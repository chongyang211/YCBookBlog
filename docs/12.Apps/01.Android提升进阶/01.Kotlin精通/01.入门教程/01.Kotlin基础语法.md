## 1.1 Kotlin语言定位

### 1.1.1 Kotlin是什么

Kotlin 由 JetBrains 公司 2011 年立项，2016 年 1.0 发布，2017 年 Google I/O 宣布为 Android 一等公民，2019 年成为 Android 官方首选语言。它是一门**面向 JVM 与多平台**的静态强类型语言，主打「与 Java 100% 互操作 + 语法现代化」。

*[骨架占位：Kotlin 与 Scala、Groovy、Swift 的差别对照]*

### 1.1.2 三大编译目标

- **Kotlin/JVM**：编译为 `.class`，最常见，Android/Server 全线覆盖
- **Kotlin/Native**：编译为原生二进制，iOS、Linux、Windows 皆可
- **Kotlin/JS**：编译为 JavaScript，用于 Web 前端

*[骨架占位：三分支架构图 + 各自使用场景]*

### 1.1.3 与Java对比表

| 特性 | Java | Kotlin |
|---|---|---|
| 空安全 | 运行期 NPE | 编译期禁止 |
| 数据类 | 手写 boilerplate | `data class` 一行 |
| Lambda | Java 8+ | 一等公民 |
| 扩展方法 | 无 | `fun T.xxx()` |
| 协程 | 无 | 语言级支持 |
| 类默认可继承 | 是 | 否（默认 final） |

### 1.1.4 综合案例与思考

*[骨架占位：Hello World 从 Java 迁移到 Kotlin 的第一次真实感受]*

**思考**：为什么 Kotlin 把类默认设成 `final`？这与 Java 15 年后引入的 `sealed` 有什么关系？

## 1.2 变量声明与类型

### 1.2.1 val与var区别

- `val`（value）：**只读引用**，类似 Java `final`，一旦赋值不能重新绑定
- `var`（variable）：可变引用，可以重新赋值

*[骨架占位：val 只是"引用不可变"，不是"对象不可变"——`val list = mutableListOf(1); list.add(2)` 仍然合法]*

### 1.2.2 类型推断规则

*[骨架占位：右侧字面量决定类型；Lambda 类型如何被推断；何时必须显式声明]*

### 1.2.3 基础类型家族

| 分类 | 类型 | 备注 |
|---|---|---|
| 整数 | `Byte/Short/Int/Long` | 无隐式转换 |
| 浮点 | `Float/Double` | |
| 字符 | `Char` | 不是数字 |
| 布尔 | `Boolean` | |
| 字符串 | `String` | 不可变 |

**关键差异**：Kotlin 无自动整型扩宽，`val i: Int = 1; val l: Long = i` 报错，必须 `i.toLong()`。

### 1.2.4 Any与Unit与Nothing

- `Any`：所有非空引用的根，类似 Java `Object`
- `Unit`：无返回值，类似 Java `void`，但 `Unit` 是**真实对象**
- `Nothing`：**永不返回**的类型，`throw` 和 `TODO()` 都返回它，是所有类型的子类型

*[骨架占位：Nothing 在 `when` 分支穷尽性检查中的妙用]*

## 1.3 空安全类型系统

### 1.3.1 T与T可空对比

`String` 与 `String?` 是**两个不同类型**。前者的变量永远不为 null，后者可为 null。这是 Kotlin 最招牌的能力。

```kotlin
val a: String = "hello"     // 永远非空
val b: String? = null       // 可以为空
val c: String = b           // ❌ 编译报错
```

### 1.3.2 安全调用三兄弟

| 运算符 | 含义 | 例子 |
|---|---|---|
| `?.` | 空安全调用 | `s?.length` — s 为 null 时结果为 null |
| `?:` | Elvis 兜底 | `s?.length ?: 0` — s 为 null 时取 0 |
| `!!` | 非空断言 | `s!!.length` — s 为 null 时抛 NPE |

*[骨架占位：`!!` 的正确使用场景 —— 只在"逻辑上不可能为 null"处用作断言]*

### 1.3.3 智能类型转换

```kotlin
fun printLength(s: String?) {
    if (s != null) {
        println(s.length)   // 这里 s 已被智能转换为 String
    }
}
```

*[骨架占位：智能转换的三个失效场景：`var` 且能被并发修改、开放属性、自定义 getter]*

### 1.3.4 综合案例与思考

*[骨架占位：解析一份可能字段缺失的 JSON 配置，全程零 `!!`]*

**思考**：为什么 `let` 常与 `?.` 组合？

## 1.4 函数与Lambda

### 1.4.1 函数声明形式

```kotlin
fun add(a: Int, b: Int): Int {
    return a + b
}
```

*[骨架占位：顶层函数、成员函数、局部函数的差异]*

### 1.4.2 默认与命名参数

```kotlin
fun greet(name: String, greeting: String = "Hello"): String = "$greeting, $name"

greet("Kotlin")                       // Hello, Kotlin
greet(name = "K", greeting = "Hi")    // 命名参数任意顺序
```

**Kotlin 消灭了 Java 的方法重载地狱**——一个默认参数抵得上 N 个 overload。

### 1.4.3 单表达式函数

```kotlin
fun square(x: Int) = x * x     // 返回类型自动推断
```

### 1.4.4 Lambda基础用法

```kotlin
val sum: (Int, Int) -> Int = { a, b -> a + b }
val square: (Int) -> Int = { it * it }   // 单参数时 it 是默认名
```

*[骨架占位：函数类型 `(A, B) -> C` 的语法本质是接口 `Function2<A, B, C>`]*

### 1.4.5 尾随Lambda惯用

```kotlin
list.map { it * 2 }               // 尾随 Lambda
list.filter({ it > 0 })           // 显式括号写法
list.filter { it > 0 }            // 惯用写法
```

**规则**：Lambda 是最后一个参数时，可以移出括号写在花括号里；如果是唯一参数，圆括号可以省略。

## 1.5 流程控制表达式

### 1.5.1 if是表达式

```kotlin
val max = if (a > b) a else b       // if 有返回值
```

Kotlin 里 `if / when / try` 都是**表达式**（能返回值），因此没有三元运算符 `? :` —— 用 `if` 就够。

### 1.5.2 when模式匹配

```kotlin
val text = when (x) {
    0 -> "zero"
    1, 2 -> "one or two"
    in 3..10 -> "small"
    is String -> "a string"
    else -> "other"
}
```

*[骨架占位：`when` 分支穷尽后可省 `else`；`sealed class` 是最佳配合]*

### 1.5.3 区间与for循环

```kotlin
for (i in 1..10) { }              // 闭区间
for (i in 1 until 10) { }         // 半开区间
for (i in 10 downTo 1 step 2) { } // 逆序步长
```

## 1.6 集合与序列

### 1.6.1 只读与可变分家

Kotlin 的 `List` 与 `MutableList` 是**两个接口**——只读接口没有 `add/remove`。

*[骨架占位：只读只是"接口只读"，不是"数据不可变"；不变集合需要 `Collections.unmodifiable` 或第三方库]*

### 1.6.2 集合创建函数

| 函数 | 返回 |
|---|---|
| `listOf(1, 2)` | 只读 `List` |
| `mutableListOf(1, 2)` | `MutableList` |
| `arrayListOf(1, 2)` | `ArrayList` |
| `setOf` / `mapOf` | 对应只读 |
| `mutableSetOf` / `mutableMapOf` | 对应可变 |

### 1.6.3 map与filter链

```kotlin
val evenSquares = (1..10).filter { it % 2 == 0 }.map { it * it }
```

*[骨架占位：常用操作符表：filter/map/flatMap/reduce/fold/groupBy/associate]*

### 1.6.4 序列惰性求值

```kotlin
list.asSequence().filter { it > 0 }.map { it * 2 }.take(3).toList()
```

**规则**：短链、小集合用 `List`；长链、大集合、有 `take/first` 早退时用 `Sequence`。

## 1.10 新手陷阱Top5

| # | 陷阱 | 场景 | 正确姿势 |
|---|---|---|---|
| 1 | `!!` 滥用 | 图省事到处 `!!` | 用 `?.` `?:` 或 `requireNotNull` |
| 2 | `==` 与 `===` 混淆 | `==` 是 `equals`，`===` 才是引用相等 | 记住"两个等号看内容，三个等号看地址" |
| 3 | `Int?` 装箱代价 | 循环里大量可空基本类型 | 尽量用 `Int`，边界层再转 `Int?` |
| 4 | Lambda 捕获 `this` | Fragment 里 Lambda 引用外部 `this` 导致泄漏 | 用 `WeakReference` 或 `viewLifecycleOwner` |
| 5 | `lateinit` vs `by lazy` 混用 | `lateinit` 只能用于 `var` 非空引用类型，`by lazy` 只能用于 `val` | 记住"lateinit 我来赋值，lazy 你来算" |
