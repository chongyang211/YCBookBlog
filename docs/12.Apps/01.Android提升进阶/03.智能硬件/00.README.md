# 智能硬件开发专栏

> **专栏定位**：从 Android 视角深度剖析智能硬件开发的完整知识体系——覆盖有线通信（串口/USB/GPIO）、身份识别（NFC/APDU/韦根/继电器）、影像采集（Camera2/YUV/UVC/人脸识别）、无线通信（BLE/MQTT/RTSP）四大领域，以"案例引入→架构概览→逐层深挖→综合串讲→设计哲学"的深度专栏体例组织。
