# TypeScript入门

> 从类型系统到工程化实践，7篇覆盖 TS 核心知识体系。

## 篇目总览

| # | 名称 | 状态 | 说明 |
|---|---|---|---|
| 01 | TS语言基础 | ✅ | 类型注解、基础类型、数组、函数 |
| 02 | TS接口与对象 | ✅ | interface、class、抽象类、泛型类 |
| 03 | TS高级类型 | ✅ | 联合/交叉/字面量、映射/条件/索引类型、类型断言/保护/推断 |
| 04 | TS泛型编程 | 🆕 | 泛型函数/约束/接口/类、条件类型、infer关键字 |
| 05 | TS模块系统 | ✅ | 导出/导入、命名空间、动态导入、类型声明 |
| 06 | TS实用工具 | ✅ | Partial/Required/Record/Pick/Omit等内置工具类型 |
| 07 | TS工程配置 | 🆕 | tsconfig.json、声明文件(.d.ts)、Webpack/Vite集成 |

## 📅 学习计划表

| 周期 | 重点内容 | 实践项目 | 目标 |
|------|----------|----------|------|
| **第1周** | 基础类型、函数、接口 | 个人记账应用 | 掌握TS基础语法 |
| **第2周** | 类、泛型、模块 | TODO应用增强版 | 理解OOP和模块化 |
| **第3周** | 高级类型、配置 | 工具库开发 | 掌握工程化配置 |
| **第4周** | 类型编程、装饰器 | 状态管理库 | 深入类型系统 |
| **第5-8周** | 框架集成、实战 | 完整项目开发 | 企业级应用能力 |
