# 智能硬件开发专栏

> **专栏定位**：从 Android 视角深度剖析智能硬件开发的完整知识体系——覆盖有线通信（GPIO/串口/USB）、身份识别（NFC/APDU/韦根/继电器）、影像采集（Camera2/YUV/UVC/人脸识别）、IoT（BLE/MQTT/RTSP）四大领域，以"案例引入→架构概览→逐层深挖→综合串讲→设计哲学"的深度专栏体例组织。**精简为 10 篇**。

---

## 专栏路线图（10 篇）

```
01.智能硬件开发全景图              ← 专栏入口，Android五层硬件栈
    │
02.有线通信基础                    ← GPIO + 串口 + USB 三合一
    │
    ├─ 03.NFC与智能卡技术           ← NFC/ISO14443/M1/APDU/CPU卡
    └─ 04.门禁系统实战              ← 韦根/继电器/端到端门禁架构
    │
    ├─ 05.Camera2与图像处理         ← Camera2/YUV/UVC/视觉架构
    └─ 06.人脸识别集成实战          ← 全pipeline/三大SDK对比
    │
    ├─ 07.蓝牙BLE开发实践           ← GATT/连接参数/回调地狱
    └─ 08.IoT与视频流传输           ← MQTT(QoS)/RTSP/H.264/WebRTC
    │
09.网关与稳定性设计                 ← 多协议网关 + 容灾/OTA
    │
10.智能硬件架构回顾                 ← 专栏终章，全景回顾
```

## 篇目摘要

| # | 名称 | 覆盖主题 |
|---|---|---|
| 01 | 智能硬件开发全景图 | Android硬件栈五层模型、通信协议矩阵、SEAndroid权限、JNI桥接 |
| 02 | 有线通信基础 | GPIO(sysfs/proc/JNI)、串口(UART/termios/环形缓冲区/C++与JNI双方案)、USB(协议分层/四种传输模式/Host vs Accessory/零拷贝) |
| 03 | NFC与智能卡技术 | ISO 14443协议栈、M1卡安全缺陷、ISO 7816-4 APDU逐字节解读、智能卡MF/DF/EF文件系统、密钥分散与安全通道 |
| 04 | 门禁系统实战 | 韦根(电气脉冲/26/34位/校验位)、继电器(电磁式vs固态/光耦隔离/超时保护)、刷卡→NFC→APDU→韦根→继电器→云端全链路、离线白名单 |
| 05 | Camera2与图像处理 | Camera2管道模型、YUV采样格式(NV21/I420)/libyuv零拷贝、UVC协议(MJPEG/YUY2/H.264)、双摄像头RGB+IR活体检测 |
| 06 | 人脸识别集成实战 | 检测→对齐→特征提取→比对全pipeline、Face++/虹软/百度三大SDK对比、本地vs云端比对、万级人脸库检索 |
| 07 | 蓝牙BLE开发实践 | GATT数据模型、连接参数(Interval/Latency/Timeout)、MTU协商与吞吐量、Android BLE线程模型与回调地狱解决方案 |
| 08 | IoT与视频流传输 | MQTT核心(QoS 0/1/2/遗嘱消息)、Broker选型(EMQX)、离线消息队列/设备影子、RTSP协议栈、RTP/RTCP、MediaCodec硬编码、WebRTC低延迟 |
| 09 | 网关与稳定性设计 | 四通道融合网关(BLE/WiFi/4G/以太网)、通道failover、USB热插拔防Crash、心跳检测/指数退避重连、固件OTA差分升级、硬件兼容性测试矩阵 |
| 10 | 智能硬件架构回顾 | 全专栏知识地图、三条完整请求链路端到端剖析、设计哲学回扣、边缘AI/UWB/Matter技术演进趋势 |

## 每篇文章的标准结构

```
1. 案例引入（真实生产bug → 5个假设逐条验证 → 7个原理点映射）
2. 架构概览（分层模型ASCII图 → 为什么这么分层的论证）
3~6. 各维度深挖（每节：疑惑→论证→结论）
7. 实战工具（性能基准/调试命令/框架设计）
8. 综合案例串讲（完整链路知识树 + 设计哲学4条 + 速查表）
```
