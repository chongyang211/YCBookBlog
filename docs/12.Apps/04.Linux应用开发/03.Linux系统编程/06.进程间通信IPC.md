### 6.1 案例引入

#### 6.1.1 UI 进程和后台服务通信延迟超过 50ms

某智能家居中控，QML UI 进程需要实时读取后台 Zigbee 网关服务的设备状态。最初使用 TCP localhost socket，发现状态变化的平均延迟 5-15ms，偶发 50ms+。切换到 Unix Domain Socket + SCM_RIGHTS 传递共享内存 fd 后，稳定在 0.5ms 以内。

**同一台设备上的跨进程通信，为什么 TCP 比 Unix Domain Socket 慢 30 倍？** 答案在内核的网络协议栈 vs 本地文件系统路径上。

#### 6.1.2 核心问题

1. 管道 vs 消息队列 vs 共享内存——各自适用什么场景？
2. System V IPC 资源泄露如何预防（`ipcs/ipcrm` 不是长久之计）？
3. 如何在多进程之间安全地共享一块 mmap 内存？
