# Linux 应用开发

> 基于 Qt/QML 技术栈的嵌入式 GUI 应用开发全链路——从 QML 声明式 UI 到 C++ 核心库，再到 Linux 部署运维。

## 专栏定位

```
目标读者：嵌入式 C++ 开发者 / 工业 HMI 开发者 / 从桌面转向嵌入式的 Qt 工程师
技术栈：  C++ × Qt 6.x × QML × CMake × Linux
产出能力：能独立开发、部署、优化运行在 ARM Linux 上的 Qt 图形应用
```

## 学习路线图

```
模块 1：QML 声明式 UI 开发（11 篇）  ← 从零写出嵌入式屏幕上的 UI
   ↓
模块 2：QT 核心库实践（10 篇）       ← 用 C++ 驱动底层能力
   ↓
模块 3：Linux 部署运维（9 篇）       ← 让应用在设备上"活下来"
   ↓
模块 4：综合项目实战                 📝 规划中
```
