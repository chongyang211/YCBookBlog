# 综合项目实战

> 把前五个模块的知识串起来——用三个完整的嵌入式 Qt 项目（车载仪表盘 / 智能家居面板 / 工业 HMI 看板），带你走完 **需求分析 → 架构设计 → 编码实现 → 部署优化** 的全链路。

## 篇目总览

| # | 名称 | 类型 | 说明 |
|---|---|---|---|
| 01 | [深入项目架构设计](https://yccoding.com/pages/linux-proj-arch/) | 🆕 方法 | 需求分析→模块拆分→技术选型→目录规划、多进程 vs 多线程架构决策 |
| 02 | [车载仪表盘项目实战](https://yccoding.com/pages/linux-proj-dashboard/) | 🆕 实战 | QML 仪表 UI、CAN 总线数据接入、实时渲染优化、冷启动 < 2 秒 |
| 03 | [智能家居控制面板](https://yccoding.com/pages/linux-proj-smarthome/) | 🆕 实战 | 触控交互设计、MQTT 协议对接、场景联动逻辑、低功耗 Standby 模式 |
| 04 | [工业 HMI 看板实战](https://yccoding.com/pages/linux-proj-hmi/) | 🆕 实战 | Modbus/OPC UA 协议、实时数据曲线、报警管理、多语言/多分辨率适配 |

## 学习路线图

```
项目架构方法论（01）
      ↓
 ┌────┼────┐
 ↓    ↓     ↓
车载  智能  工业
仪表  家居  HMI
(02)  (03)  (04)

三个项目覆盖嵌入式 Qt 三大核心场景：
实时数据可视化 / 触控交互 / 工业协议
```

## 项目要求

| 特征 | 说明 |
|---|---|
| 技术栈 | C++ × Qt 6.x × QML × CMake × Linux ARM |
| 前置模块 | 模块 01-05 全部学完 |
| 交付标准 | 每个项目有完整代码 + 可烧录镜像 + 性能基准 |
| 硬件平台 | ARM Cortex-A 系列（树莓派 / i.MX 系列 / 全志系列） |
