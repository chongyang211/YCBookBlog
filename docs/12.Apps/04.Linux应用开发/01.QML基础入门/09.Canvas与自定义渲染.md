## 9.1 Canvas 2D 绘制引擎

```qml
Canvas {
    width: 400; height: 300
    onPaint: {
        var ctx = getContext("2d")
        ctx.clearRect(0, 0, width, height)
        ctx.fillStyle = "steelblue"
        ctx.fillRect(20, 20, 100, 50)
        ctx.strokeStyle = "red"
        ctx.lineWidth = 2
        ctx.beginPath(); ctx.moveTo(50, 100); ctx.lineTo(200, 200); ctx.stroke()
    }
    onSpeedChanged: requestPaint()   // 手动触发重绘
}
```

**Canvas 性能**：每次 `requestPaint()` → FBO(离屏缓冲) → 纹理上传 → 渲染线程。比标准 QML 控件慢 3-10×。适合低频更新（图表、波形），不适合高频动画。

## 9.2 QQuickPaintedItem

命令式 QPainter 绘制——适合从 Qt Widget 迁移：

```cpp
class MyChart : public QQuickPaintedItem {
    Q_OBJECT
public:
    void paint(QPainter* painter) override {
        painter->setRenderHint(QPainter::Antialiasing);
        painter->fillRect(rect(), QColor("#1a1a2e"));
        // ... QPainter API
    }
};
```

性能比 Canvas 好（QPainter 是 C++ 路径），但仍走CPU → 纹理上传。

## 9.3 自定义 QQuickItem + QSGNode

```cpp
class FastLine : public QQuickItem {
    Q_OBJECT
protected:
    QSGNode* updatePaintNode(QSGNode* old, UpdatePaintNodeData*) override {
        auto* node = static_cast<QSGGeometryNode*>(old);
        if (!node) {
            node = new QSGGeometryNode();
            node->setGeometry(new QSGGeometry(QSGGeometry::defaultAttributes_Point2D(), m_points.size()));
            node->setMaterial(new QSGFlatColorMaterial());
        }
        node->markDirty(QSGNode::DirtyGeometry);
        return node;
    }
};
```

**零拷贝路径**：数据直接写到 QSGGeometry → Scene Graph 批处理 → GPU。**性能最高**。

## 9.4 实时心电图绘制实战

选用 `QQuickItem + QSGNode` 方案——200Hz 数据不丢帧：

```cpp
// 核心循环
void EKGItem::pushSample(float value) {
    m_buffer.push_back(value);
    if (m_buffer.size() > MAX_POINTS) m_buffer.pop_front();
    update();  // 标记 dirty → 下一帧 Sync 时 updatePaintNode → GPU
}
```

## 9.5 速查表

| 路径 | 性能 | 适合场景 | 代价 |
|---|---|---|---|
| **Canvas** | ★★ | 低频图表 | CPU→纹理上传 |
| **QQuickPaintedItem** | ★★★ | Widget 迁移 | CPU→纹理上传 |
| **QQuickItem + QSGNode** | ★★★★★ | 高频实时渲染 | 开发复杂度最高 |
