## 8.1 案例引入：width 动画导致 60fps→12fps

某工程师在车机仪表盘上用 `NumberAnimation on width` 做进度条动画——结果 60fps 掉到 12fps：

```qml
Rectangle {
    id: bar
    width: 10; height: 30; color: "green"
    NumberAnimation on width { to: 300; duration: 1000; loops: Animation.Infinite }
}
// 问题：width 变化 → 触发整个布局重新计算 → 批处理被打断 → Draw Call 爆炸
```

**修复**——用 `transform: Scale`：

```qml
Rectangle {
    width: 300; height: 30; color: "green"
    transform: Scale { origin.x: 0; xScale: 0.03 }
    NumberAnimation on transform.xScale { to: 1.0; duration: 1000; loops: Animation.Infinite }
}
// Scale 只改变换矩阵 → 不触发布局重算 → 批处理保持 → 稳定 60fps
```

## 8.2 属性动画体系

```qml
// 声明式
NumberAnimation on x { to: 100; duration: 500; easing.type: Easing.InOutQuad }

// 命令式
SequentialAnimation {
    NumberAnimation { target: rect; property: "opacity"; to: 0; duration: 300 }
    NumberAnimation { target: rect; property: "opacity"; to: 1; duration: 300 }
    loops: Animation.Infinite
}

// ParallelAnimation 并行
ParallelAnimation {
    NumberAnimation { target: ball; property: "x"; to: 200; duration: 1000 }
    NumberAnimation { target: ball; property: "y"; to: 200; duration: 1000 }
}
```

**Easing 曲线类型**：`Linear` / `InQuad` / `OutQuad` / `InOutQuad` / `InElastic` / `OutBounce` / `InOutBack` 等 40+ 种。

## 8.3 Behavior 自动动画

```qml
Rectangle {
    Behavior on x { NumberAnimation { duration: 300; easing.type: Easing.OutQuad } }
    Behavior on opacity { NumberAnimation { duration: 200 } }
}
// opacity = 0 → 自动 200ms 渐隐动画，不需要手动启动
```

**Behavior 原理**：拦截 `setProperty` → 不直接写值 → 启动 Animation 从当前值插值到目标值。

## 8.4 State 与 Transition 状态机

```qml
Rectangle {
    id: panel
    states: [
        State { name: "collapsed"; PropertyChanges { target: panel; width: 60; opacity: 0.6 } },
        State { name: "expanded";  PropertyChanges { target: panel; width: 300; opacity: 1.0 } }
    ]
    transitions: [
        Transition {
            from: "collapsed"; to: "expanded"
            NumberAnimation { properties: "width,opacity"; duration: 400; easing.type: Easing.OutCubic }
        }
    ]
}
// panel.state = "expanded" → 自动 400ms 过渡动画
```

## 8.5 GPU 加速 vs CPU 动画

| 属性 | 渲染路径 | FPS 60 可行性 | 原因 |
|---|---|---|---|
| `x/y` | GPU (transform) | ✅ 稳定 | 仅 QSGTransformNode |
| `rotation/scale` | GPU (transform) | ✅ 稳定 | 仅变换矩阵 |
| `opacity` | GPU (opacity node) | ⚠️ 打断批处理 | 每个独立 QSGOpacityNode |
| `width/height` | CPU 重算布局 | ❌ 卡顿 | 触发布局 + 重绘 |
| `color` | GPU (vertex attribute) | ✅ | 顶点属性更新 |

> **铁律**：嵌入式上只动画 `x/y/rotation/scale/opacity`，永远不动 `width/height`。

## 8.6 速查表

| 概念 | 一句话 |
|---|---|
| **NumberAnimation** | 对单个属性插值——to/duration/easing |
| **Behavior** | 自动动画——属性变化时自动触发 |
| **State/Transition** | 声明式状态机——切换状态时自动运行过渡动画 |
| **SequentialAnimation** | 串行动画组 |
| **ParallelAnimation** | 并行动画组 |
| **Easing** | 缓动曲线（40+ 种）——控制插值节奏 |
