## 13.1 嵌入式 GUI 运行环境

```
有桌面环境（X11 / Wayland）          无桌面环境（裸 framebuffer）
┌──────────────────────┐            ┌──────────────────────┐
│ Qt → X11/Wayland     │            │ Qt → DRM/KMS → GPU   │
│   → GPU → 显示器      │            │   → 显示器            │
│ 慢启动（5s+）          │            │ 极快启动（<1s）       │
│ 开发期调试方便        │            │ 生产环境 99% 场景     │
└──────────────────────┘            └──────────────────────┘
```

## 13.2 EGLFS 后端

嵌入式首选——QML 进程**独占**整个屏幕，不走窗口管理器：

```bash
export QT_QPA_PLATFORM=eglfs
export QT_QPA_EGLFS_HIDECURSOR=1
export QT_QPA_EGLFS_PHYSICAL_WIDTH=155
export QT_QPA_EGLFS_PHYSICAL_HEIGHT=86
./myapp
```

**EGLFS 启动流程**：

```
eglGetDisplay(EGL_DEFAULT_DISPLAY)
  → eglInitialize → eglChooseConfig
  → eglCreateWindowSurface(DRM/KMS plane | fbdev)
  → eglMakeCurrent → glDraw* + eglSwapBuffers
```

**特点**：无标题栏/关闭按钮、< 1s 启动、直接读 `/dev/input/event*` 触摸事件。

---

## 13.3 LinuxFB 后端

无 GPU 时的降级方案——CPU 直接写 `/dev/fb0`：

```bash
export QT_QPA_PLATFORM=linuxfb
./myapp
```

**性能**：720p 界面 15~25fps（无 GPU 加速）。适合超低成本设备（STM32MP1）。

---

## 13.4 Wayland 后端

多窗口嵌入式场景（仪表盘 + 中控 + HUD 同时显示）：

```bash
export QT_QPA_PLATFORM=wayland
./myapp
```

## 13.5 速查表

| 后端 | 适用 | 启动 | 性能 | GPU 需求 |
|---|---|---|---|---|
| **EGLFS** | 单屏车机/HMI | < 1s | ★★★★★ | 必须 |
| **LinuxFB** | 廉价无GPU板 | < 1s | ★★ | 不需要 |
| **Wayland** | 多窗口车机 | 2-4s | ★★★★ | 必须 |
