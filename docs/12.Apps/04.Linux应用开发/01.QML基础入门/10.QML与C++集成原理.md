## 10.1 案例引入：setContextProperty 的"幽灵 bug"

某工程师用 `setContextProperty` 注入一个 C++ 对象，QML 侧读写属性 "偶尔不生效"：

```cpp
// ❌ 错误：main.cpp 在 engine.load 之后才 setContextProperty
engine.load("qrc:/main.qml");
engine.rootContext()->setContextProperty("backend", new Backend());
// main.qml 在 load 时已经解析——当时 "backend" 不存在 → 属性读取失败
```

**修复**：

```cpp
engine.rootContext()->setContextProperty("backend", new Backend());  // ← 在 load 之前
engine.load("qrc:/main.qml");
```

## 10.2 Q_PROPERTY 属性暴露

```cpp
class SpeedController : public QObject {
    Q_OBJECT
    Q_PROPERTY(double speed READ speed WRITE setSpeed NOTIFY speedChanged)
public:
    double speed() const { return m_speed; }
    void setSpeed(double v) { if (v != m_speed) { m_speed = v; emit speedChanged(); } }
signals:
    void speedChanged();
private:
    double m_speed = 0;
};
```

```qml
SpeedController {
    id: controller
    onSpeedChanged: console.log("速度: " + speed)
}
```

**Q_PROPERTY 三种通知机制**：

| 机制 | 语法 | 场景 |
|---|---|---|
| `NOTIFY signal` | `NOTIFY speedChanged` | QML 绑定依赖此信号 |
| `CONSTANT` | `CONSTANT` | 值永不改变——无 `NOTIFY` 信号 |
| `MEMBER` | `MEMBER m_speed` | 直接读写成员变量（Qt 6） |

## 10.3 信号与槽跨语言通信

```cpp
// C++ → QML（C++ emit 信号，QML onXxx 响应）
class Backend : public QObject {
    Q_OBJECT
signals:
    void dataReady(QVariantMap data);
};
```

```qml
Backend {
    onDataReady: (data) => console.log(data.temperature)
}
```

```cpp
// QML → C++（QML emit 信号，C++ connect 槽）
QObject* root = engine.rootObjects().first();
auto* btn = root->findChild<QObject*>("submitBtn");
QObject::connect(btn, SIGNAL(clicked()), &backend, SLOT(onSubmit()));
```

## 10.4 类型注册与 QML 插件

```cpp
// 注册为非单例类型——QML 中可以 new
qmlRegisterType<MyChart>("Charts", 1, 0, "LineChart");

// 注册为单例——全局唯一实例
qmlRegisterSingletonType<AppConfig>("App", 1, 0, "Config", [](QQmlEngine*, QJSEngine*) {
    return new AppConfig();
});
```

**Qt 6 推荐**——用宏替代手动注册：

```cpp
class MyChart : public QQuickItem {
    Q_OBJECT
    QML_ELEMENT              // 自动注册
    Q_PROPERTY(...)
};
```

## 10.5 线程安全与生命周期

| 操作 | 线程约束 | 风险 |
|---|---|---|
| `setContextProperty` | 调用线程 → QML 主线程 | 跨线程操作 QObject 不安全 |
| `emit signal` | 任意线程（Qt::AutoConnection） | AutoConnection → 跨线程时排队调用 |
| `invokeMethod` | 必须目标对象所在线程 | 跨线程调用必崩溃 |
| `Q_PROPERTY` 读写 | 属性所在线程 | 多线程写 → 加锁 |

## 10.6 速查表

| 概念 | 一句话 |
|---|---|
| **Q_PROPERTY** | C++ 属性暴露给 QML——READ/WRITE/NOTIFY |
| **Q_INVOKABLE** | C++ 方法暴露给 QML——可被 JS 调用 |
| **setContextProperty** | 将 C++ QObject* 注入 QML 上下文——必须在 engine.load() 之前 |
| **qmlRegisterType** | 注册 C++ 类型为 QML 可实例化的类型 |
| **QML_ELEMENT** | Qt 6 宏——替代手动 qmlRegisterType |
| **AutoConnection** | 跨线程信号槽默认——保证线程安全 |
