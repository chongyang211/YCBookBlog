## 11.1 QSGNode 体系

```
QSGNode ── 所有节点的基类
  ├── QSGTransformNode ── 变换（translate/rotate/scale）
  ├── QSGOpacityNode   ── 透明度
  ├── QSGClipNode      ── 裁剪
  └── QSGGeometryNode  ── 核心绘制节点（顶点 + 材质）
```

## 11.2 自定义 QQuickItem + updatePaintNode

```cpp
class WaveformItem : public QQuickItem {
    Q_OBJECT
protected:
    QSGNode* updatePaintNode(QSGNode* old, UpdatePaintNodeData*) override {
        auto* node = static_cast<QSGGeometryNode*>(old);
        if (!node) {
            node = new QSGGeometryNode();
            auto* geom = new QSGGeometry(QSGGeometry::defaultAttributes_Point2D(), N);
            geom->setDrawingMode(QSGGeometry::DrawLineStrip);
            node->setGeometry(geom);
            node->setFlag(QSGNode::OwnsGeometry);
            auto* mat = new QSGFlatColorMaterial();
            mat->setColor(QColor("#00ff00"));
            node->setMaterial(mat);
            node->setFlag(QSGNode::OwnsMaterial);
        }
        // 更新顶点数据（零拷贝——直接映射到 GPU buffer）
        auto* geom = node->geometry();
        auto* verts = geom->vertexDataAsPoint2D();
        for (int i = 0; i < N; ++i) verts[i].set(i, m_data[i] * 100);
        node->markDirty(QSGNode::DirtyGeometry);
        return node;
    }
};
```

## 11.3 自定义材质与着色器

```cpp
class GlowMaterial : public QSGMaterial {
    QSGMaterialType* type() const override { static QSGMaterialType t; return &t; }
    QSGMaterialShader* createShader(QSGRendererInterface::RenderMode) const override {
        return new GlowShader();
    }
    int compare(const QSGMaterial* other) const override { /* 同材质合并批处理 */ }
};

class GlowShader : public QSGMaterialShader {
    const char* vertexShader() const override { return R"(... gl_Position = mvp * vertex; )"; }
    const char* fragmentShader() const override { return R"(... fragColor = glowColor; )"; }
};
```

## 11.4 零拷贝纹理渲染

摄像头帧 → GPU 纹理 → QML Item——不经过 CPU 拷贝：

```cpp
class CameraItem : public QQuickItem {
    QSGNode* updatePaintNode(QSGNode* old, UpdatePaintNodeData*) override {
        auto* node = static_cast<QSGGeometryNode*>(old);
        if (!node) {
            node = new QSGGeometryNode();
            auto* texture = window()->createTextureFromNativeObject(
                QQuickWindow::NativeObjectTexture, &m_nativeTexHandle, 0, QSize(1920, 1080));
            auto* mat = new QSGTextureMaterial();
            mat->setTexture(texture);
            node->setMaterial(mat);
        }
        return node;
    }
};
// m_nativeTexHandle = GLuint 纹理句柄——摄像头 DMA 直接写入 → 零拷贝到 QML
```

## 11.5 速查表

| 概念 | 一句话 |
|---|---|
| **updatePaintNode** | 每帧 Sync 阶段调用——创建/更新 QSGNode 树 |
| **QSGGeometryNode** | 核心绘制节点——顶点 buffer + 材质 |
| **QSGMaterial** | 材质抽象——着色器 + uniform + 纹理 |
| **OwnsGeometry / OwnsMaterial** | 告诉 Scene Graph 节点负责释放资源 |
| **markDirty** | 标记节点需要更新——触发下一帧重新渲染 |
| **window()->createTextureFromNativeObject** | 零拷贝纹理——外部 GL 纹理直通 QML |
