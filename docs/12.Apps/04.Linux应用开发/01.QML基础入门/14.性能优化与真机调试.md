## 14.1 启动速度优化

**启动耗时分解**：

```
应用总启动时间 1200ms:
├── Qt 库加载          200ms ── 静态链接 → 减到 50ms
├── QML 解析+编译      600ms ── qmlcachegen → 减到 150ms
├── 首帧渲染           400ms ── Splash Screen(预渲染)→ 感知 < 200ms
```

```bash
# qmlcachegen 预编译
qmlcachegen --resource main.qrc -o main.qmlc
# 启动: 1200ms → 700ms
```

```qml
// Splash Screen——启动即显示，掩盖加载时间
Window {
    visible: true
    Rectangle { anchors.fill: parent; color: "black"
        Image { source: "qrc:/splash.png" }  // 预处理的静态图
    }
}
```

## 14.2 渲染性能诊断

```bash
# 批处理可视化——每组同色 batch
export QSG_VISUALIZE=batches

# overdraw 热力图——红色 = 多次重绘
export QSG_VISUALIZE=overdraw

# 脏区域——红色 = 每帧重绘部分
export QSG_VISUALIZE=changes
```

**Qt Quick Profiler**——火焰图定位热点：

```
Qt Creator → Analyze → QML Profiler
├── Painting ← 渲染时间（应 < 16.6ms）
├── Binding  ← 绑定求值时间
├── JavaScript ← V4 执行时间
└── Creating ← 对象创建时间
```

## 14.3 内存优化

```bash
# heaptrack 内存画像
heaptrack ./myapp -platform eglfs
# 报告: 峰值内存 / 泄漏点 / 分配热点

# 图片加载优化
Image {
    sourceSize: Qt.size(200, 200)   // 解码时缩放到目标尺寸
    asynchronous: true               // 异步加载
    cache: false                     // 大图不缓存（ListView delegate）
}
```

```qml
// Loader 懒加载
Loader {
    active: tabBar.currentIndex === 2   // 仅当前 tab 激活
    source: "HeavyPage.qml"
}
```

## 14.4 真机远程调试

```bash
# ARM 板上启动 gdbserver
gdbserver :2345 ./myapp -platform eglfs

# x86 开发机上连接
arm-linux-gnueabihf-gdb ./myapp
(gdb) target remote 192.168.1.100:2345
(gdb) continue
```

**Qt 日志系统**：

```cpp
qInstallMessageHandler([](QtMsgType type, const QMessageLogContext& ctx, const QString& msg) {
    // 写入 /var/log/myapp.log + 串口输出
    QFile f("/var/log/myapp.log");
    f.open(QIODevice::Append);
    f.write((msg + "\n").toUtf8());
});
```
