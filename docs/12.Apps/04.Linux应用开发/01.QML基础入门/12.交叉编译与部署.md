## 12.1 交叉编译原理

```
x86 开发机 (Host)                      ARM 设备 (Target)
┌──────────────────┐                 ┌──────────────────┐
│ gcc → ELF (x86)  │                 │ 需要 ARM ELF     │
│ │                 │                 │                  │
│ └─ × 不能在ARM跑  │                 │ 从 Host 拷贝     │
└──────────────────┘                 └──────────────────┘
         ↓
    arm-linux-gnueabihf-gcc  ← 交叉编译器
         ↓
    生成 ARM ELF → 拷贝到 ARM 板执行
```

**Qt 交叉编译的特殊性**：Qt 使用 moc（元对象编译器）+ rcc（资源编译器）+ qmlcachegen——这些工具运行在 Host 上，但生成的代码编译到 Target。

```cmake
set(CMAKE_SYSTEM_NAME Linux)
set(CMAKE_SYSTEM_PROCESSOR arm)
set(CMAKE_C_COMPILER arm-linux-gnueabihf-gcc)
set(CMAKE_CXX_COMPILER arm-linux-gnueabihf-g++)
set(CMAKE_SYSROOT /path/to/sysroot)    # ARM 根文件系统镜像
set(CMAKE_FIND_ROOT_PATH_MODE_PROGRAM NEVER)   # 程序在 Host 找
set(CMAKE_FIND_ROOT_PATH_MODE_LIBRARY ONLY)    # 库在 Target 找
```

## 12.2 构建交叉编译 Qt

```bash
# ① 下载 Qt 源码
wget https://download.qt.io/official_releases/qt/6.5/6.5.3/single/qt-everywhere-src-6.5.3.tar.xz

# ② 配置交叉编译
./configure \
  -release -opengl es2 -eglfs \
  -device linux-imx6-g++ \
  -device-option CROSS_COMPILE=arm-linux-gnueabihf- \
  -sysroot /home/user/sysroot \
  -prefix /usr/local/qt6-arm

# ③ 编译
make -j$(nproc) && make install
```

**常用 ARM 设备配置**：`linux-rasp-pi4-g++`（Raspberry Pi 4）、`linux-imx8-g++`（i.MX8）、`linux-stm32mp1-g++`（STM32MP1）。

## 12.3 CMake 嵌入式配置

```cmake
cmake_minimum_required(VERSION 3.16)
project(MyApp LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)
find_package(Qt6 REQUIRED COMPONENTS Quick QuickControls2)

qt_add_executable(myapp main.cpp)
qt_add_qml_module(myapp
    URI MyApp
    VERSION 1.0
    QML_FILES main.qml Dashboard.qml
    RESOURCES resources.qrc
)
```

交叉编译：

```bash
cmake -B build-arm \
  -DCMAKE_TOOLCHAIN_FILE=../toolchain-arm.cmake \
  -DQt6_DIR=/usr/local/qt6-arm/lib/cmake/Qt6
cmake --build build-arm -j$(nproc)
```

## 12.4 部署与 OTA

**最小依赖检查**：

```bash
# 在 ARM 板上
ldd ./myapp | grep "not found"    # 检查缺失的 .so
```

**部署文件清单**：

```
/opt/myapp/
├── bin/myapp                      ← 可执行文件
├── qml/                           ← QML 文件 + .qmlc 缓存
├── plugins/platforms/libqeglfs.so ← QPA 插件
├── plugins/imageformats/          ← 图片解码插件
└── lib/                           ← 缺失的 Qt .so
```

**OTA 热更新**：QML 文件 + `.qmlc` 缓存 → 守护进程下载新版本 → 校验 hash → 替换旧文件 → 重启应用。

## 12.5 速查表

| 概念 | 一句话 |
|---|---|
| **arm-linux-gnueabihf-gcc** | ARM 交叉编译器 |
| **sysroot** | ARM 根文件系统镜像——交叉编译时查找头文件和库 |
| **qmlcachegen** | QML 预编译——.qml → .qmlc 字节码 |
| **eglfs** | 嵌入式 QPA 后端——直接写 framebuffer |
| **ldd** | 检查 ARM 板上缺失的 .so |
