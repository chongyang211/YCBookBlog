# 5.7 组件生命周期管理

> 📍 **本篇位置**：第 5 卷 · 交互与系统 · 第 7 篇
> 🎯 **核心矛盾**：**组件什么时候能动、什么时候不能动** —— 屏幕旋转、切后台、低内存回收，OS 在任何时刻都可能挂起或销毁你的界面组件
> 🧭 **设计灵魂**：所有平台的生命周期最终都是 **init → resume → pause → destroy** 四态，唯一差别在于粒度与回调时机的确定性
> 🌐 **跨语言覆盖**：Android(Activity/Fragment/Service) · iOS(UIApplication/UIViewController/UIView) · Web(Page Visibility / bfcache / beforeunload) · 嵌入式 GUI(状态机驱动的唤醒/休眠/销毁)
