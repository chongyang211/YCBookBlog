# 5.8 页面导航与路由设计

> 📍 **本篇位置**：第 5 卷 · 交互与系统 · 第 8 篇
> 🎯 **核心矛盾**：**页面如何组织、如何在页面间流转** —— 栈、图、树三种数据结构就是三种导航世界观
> 🧭 **设计灵魂**：一个"返回上一页"手势背后，是手势识别 → 导航栈回退 → View 销毁 → 窗口回收四层协同；Deep Link 则是从"全链路入口"切入导航的顶层设计
> 🌐 **跨语言覆盖**：Android(NavGraph / FragmentManager / Intent) · iOS(UINavigationController / SwiftUI NavigationStack) · Web(History API / React Router / Vue Router) · 嵌入式(状态机驱动的屏幕切换)
