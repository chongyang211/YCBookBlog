# 5.9 响应式数据绑定设计

> 📍 **本篇位置**：第 5 卷 · 交互与系统 · 第 9 篇
> 🎯 **核心矛盾**：**数据变了，UI 怎么自动跟上** —— 推（数据主动通知） vs 拉（UI 主动 diff），两条路线各有千秋
> 🧭 **设计灵魂**：所有响应式框架本质上是 **依赖追踪 + 变更检测 + 视图更新** 三位一体；差异只在于"追踪发生在编译期还是运行时"
> 🌐 **跨语言覆盖**：Android(LiveData → DataBinding → Compose snapshot) · iOS(KVO → Combine → SwiftUI @Observable) · Web(Vue Proxy → React Fiber → Solid Signals) · 嵌入式(make dirty + invalidRect)
