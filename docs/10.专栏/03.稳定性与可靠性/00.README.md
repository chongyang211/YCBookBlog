> 熔断、限流、容灾、幂等——生产环境不挂机的工程防线

## 学习方法

延续**疑惑→分析→论证→结论**范式：

1. **疑惑**：从线上故障切入（服务雪崩、流量尖刺、数据不一致）
2. **分析**：拆解故障根因，定位是架构问题还是容量问题
3. **论证**：对比多种方案的成本、收益、副作用
4. **结论**：形成可落地的防御体系 Checklist
