# 文本工具

> 编码转换、正则测试、文本对比、字数统计等常用文本处理

## 功能规划

- **编码转换**：URL编码/解码、Base64编解码、Unicode转中文
- **正则测试**：实时正则表达式匹配与替换测试
- **文本对比**：两段文本 diff 高亮对比
- **字数统计**：字符数、行数、字节数统计
- **大小写转换**：全大写/全小写/首字母大写/驼峰命名
