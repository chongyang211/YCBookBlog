# 代码压缩

> JS、CSS、HTML 代码压缩与美化

## 功能规划

- **JavaScript 压缩**：混淆压缩，移除注释和空格
- **CSS 压缩**：合并规则、移除冗余属性
- **HTML 压缩**：移除空白符和注释
- **代码美化**：JS/CSS/HTML 格式化对齐
