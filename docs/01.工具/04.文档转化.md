# 文档转化

> Markdown、HTML、PDF 等常见文档格式互转

## 功能规划

- **Markdown → HTML**：实时预览与导出
- **HTML → Markdown**：网页内容转 Markdown
- **PDF 合并/拆分**：多 PDF 合并、单 PDF 按页拆分
- **文档模板**：常用文档（技术方案、接口文档）模板生成
