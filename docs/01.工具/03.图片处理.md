# 图片处理

> 压缩、格式转换、Base64编解码等在线图片处理

## 功能规划

- **图片压缩**：有损/无损压缩，批量处理
- **格式转换**：PNG⇔JPG⇔WebP⇔SVG 互转
- **尺寸调整**：等比例缩放、指定宽高裁剪
- **Base64编解码**：图片 ↔ Base64 字符串互转
- **取色板**：拾取图片颜色、生成色板
