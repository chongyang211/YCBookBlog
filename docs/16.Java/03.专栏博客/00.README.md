# 专栏笔记总结大全

Java 核心原理深度专栏，自下而上贯穿 **JVM → 容器 → 类型系统 → 字节码 → 并发 → IO/网络 → 设计思想** 七大原理域，共计 **47 篇**。

## 📕 卷一 · JVM 与运行时核心（10 篇）

- ✅ [01.JVM内存模型对象](01.JVM内存模型对象.md)：JVM运行时数据区全景、对象创建过程与内存布局、堆分代设计及逃逸分析
- ✅ [02.类加载双亲委派](02.类加载双亲委派.md)：类的生命五阶段、三层类加载器体系与双亲委派源码原理
- ✅ [03.垃圾回收GC调优](03.垃圾回收GC调优.md)：标记-清除/复制/整理三大算法，Serial到ZGC收集器演进与调优
- ✅ [04.异常与JVM机制](04.异常与JVM机制.md)：异常表字节码结构、栈展开机制、finally代码复制与try-with-resources
- ✅ [05.javap字节码实战](05.javap字节码实战.md)：Class文件结构、操作数栈与局部变量表、四条方法调用指令解读
- ✅ [06.JIT编译优化机制](06.JIT编译优化机制.md)：解释执行到C1/C2/Graal的演进、分层编译与去优化原理
- ✅ [07.JVM诊断工具链条](07.JVM诊断工具链条.md)：jstat/jmap/jstack/jcmd、JFR飞行记录器与Arthas在线诊断实战
- ✅ [08.OOM全景剖析指南](08.OOM全景剖析指南.md)：堆/元空间/直接内存/栈/GC overhead等八大OOM现场排查
- ✅ [09.JVM调优全景图解](09.JVM调优全景图解.md)：堆/GC/JIT/诊断四类参数体系，真实线上调优案例
- ✅ [10.AOT编译原理探析](10.AOT编译原理探析.md)：Native Image与SubstrateVM闭世界假设，与传统JVM的取舍

- ✅ [15.TreeMap红黑树](15.TreeMap红黑树.md)：红黑树五大性质与插入删除调整，跳表对比与选型分析
