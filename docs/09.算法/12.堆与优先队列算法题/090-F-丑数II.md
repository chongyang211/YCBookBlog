# F005 丑数 II

> LeetCode 264 · ⭐⭐ · 多路归并/DP

## 01. 题目

只含质因数 2/3/5 的第 n 个丑数。n=10 → 12。

## 02. 分析

三指针归并：每次取 `min(dp[p2]*2, dp[p3]*3, dp[p5]*5)`，对应指针前移。

## 03. 代码

**Java**：
```java
public int nthUglyNumber(int n) {
    int[] dp=new int[n]; dp[0]=1;
    int p2=0,p3=0,p5=0;
    for(int i=1;i<n;i++){
        int n2=dp[p2]*2, n3=dp[p3]*3, n5=dp[p5]*5;
        dp[i]=Math.min(n2,Math.min(n3,n5));
        if(dp[i]==n2) p2++; if(dp[i]==n3) p3++; if(dp[i]==n5) p5++;
    }
    return dp[n-1];
}
```

**Python**：
```python
def nthUglyNumber(self, n):
    dp=[1]; p2=p3=p5=0
    for _ in range(n-1):
        n2,n3,n5=dp[p2]*2,dp[p3]*3,dp[p5]*5
        nxt=min(n2,n3,n5); dp.append(nxt)
        if nxt==n2: p2+=1
        if nxt==n3: p3+=1
        if nxt==n5: p5+=1
    return dp[-1]
```

**复杂度**：O(N)/O(N)。
