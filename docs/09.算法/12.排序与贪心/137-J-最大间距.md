## J005 最大间距 (164)

桶排序：最大间距 ≥ ceil((max-min)/(n-1))。

```java
public int maximumGap(int[] nums) {
    if(nums.length<2) return 0; int n=nums.length, min=Integer.MAX_VALUE, max=Integer.MIN_VALUE;
    for(int x:nums){ min=Math.min(min,x); max=Math.max(max,x); }
    int gap=Math.max(1,(max-min)/(n-1)), size=(max-min)/gap+1;
    int[] bmin=new int[size], bmax=new int[size]; Arrays.fill(bmin,Integer.MAX_VALUE); Arrays.fill(bmax,Integer.MIN_VALUE);
    for(int x:nums){ int i=(x-min)/gap; bmin[i]=Math.min(bmin[i],x); bmax[i]=Math.max(bmax[i],x); }
    int ans=0, prev=min;
    for(int i=0;i<size;i++){ if(bmin[i]==Integer.MAX_VALUE) continue; ans=Math.max(ans,bmin[i]-prev); prev=bmax[i]; }
    return ans;
}
```

## J007 摆动排序II (324)

```java
public void wiggleSort(int[] nums) { int[] copy=nums.clone(); Arrays.sort(copy); int n=nums.length; for(int i=0,j=(n-1)/2,k=n-1;i<n;i++) nums[i]=i%2==0?copy[j--]:copy[k--]; }
```

## J008 使数组唯一的最小增量 (945)

```java
public int minIncrementForUnique(int[] nums) { Arrays.sort(nums); int moves=0; for(int i=1;i<nums.length;i++){ if(nums[i]<=nums[i-1]){ moves+=nums[i-1]-nums[i]+1; nums[i]=nums[i-1]+1; } } return moves; }
```
