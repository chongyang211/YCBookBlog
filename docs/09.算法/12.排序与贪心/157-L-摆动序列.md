# L009 摆动序列

> LeetCode 376 · ⭐⭐ · 贪心/DP

**Java**：
```java
public int wiggleMaxLength(int[] nums) { if(nums.length<2) return nums.length; int up=1,down=1; for(int i=1;i<nums.length;i++){ if(nums[i]>nums[i-1]) up=down+1; else if(nums[i]<nums[i-1]) down=up+1; } return Math.max(up,down); }
```

**Python**：
```python
def wiggleMaxLength(self, nums): up=down=1; [exec('global up,down;up=down+1' if nums[i]>nums[i-1] else 'down=up+1' if nums[i]<nums[i-1] else '') for i in range(1,len(nums))]; return max(up,down)
```
