## 🎯 工业级 vs 教科书

| 维度 | 教科书 | 工业级 |
|------|--------|--------|
| 容量 | 固定 | 动态扩容 |
| 线程安全 | 不考虑 | Collections.synchronized / Concurrent |
| 性能优化 | 理论值 | 位运算、缓存行、哈希扰动 |
| 边界条件 | 忽略 | null处理、越界、并发修改 |
