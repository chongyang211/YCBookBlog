# G011 除法求值

> LeetCode 399 · ⭐⭐ · 带权并查集

**Java**：
```java
Map<String,String> p=new HashMap<>(); Map<String,Double> w=new HashMap<>();
public double[] calcEquation(List<List<String>> eq, double[] vals, List<List<String>> qs) {
    for(int i=0;i<eq.size();i++){ String a=eq.get(i).get(0),b=eq.get(i).get(1); p.putIfAbsent(a,a); p.putIfAbsent(b,b); w.putIfAbsent(a,1.0); w.putIfAbsent(b,1.0); union(a,b,vals[i]); }
    double[] res=new double[qs.size()];
    for(int i=0;i<qs.size();i++){ String a=qs.get(i).get(0),b=qs.get(i).get(1); res[i]=(p.containsKey(a)&&p.containsKey(b)&&find(a).equals(find(b)))?w.get(a)/w.get(b):-1.0; }
    return res;
}
String find(String x){ if(!p.get(x).equals(x)){ String root=find(p.get(x)); w.put(x,w.get(x)*w.get(p.get(x))); p.put(x,root); } return p.get(x); }
void union(String a,String b,double v){ String ra=find(a),rb=find(b); if(!ra.equals(rb)){ p.put(ra,rb); w.put(ra,v*w.get(b)/w.get(a)); } }
```

**Python**：
```python
def calcEquation(self, eq, vals, qs):
    from collections import defaultdict
    p,w=defaultdict(str),defaultdict(float)
    def find(x):
        if p[x]!=x: r=find(p[x]); w[x]*=w[p[x]]; p[x]=r
        return p[x]
    for (a,b),v in zip(eq,vals):
        if a not in p: p[a]=a; w[a]=1.0
        if b not in p: p[b]=b; w[b]=1.0
        ra,rb=find(a),find(b)
        if ra!=rb: p[ra]=rb; w[ra]=v*w[b]/w[a]
    return [w[a]/w[b] if a in p and b in p and find(a)==find(b) else -1.0 for a,b in qs]
```

**复杂度**：O((N+Q)·α(N))/O(N)。
