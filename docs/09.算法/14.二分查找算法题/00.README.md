> 共 9 题 · ⭐ 2 / ⭐⭐ 5 / ⭐⭐⭐ 2

二分的核心不是模板，是**边界条件**和**单调性判断**。

| 难度 | 篇数 | 代表题型 |
|:--:|:--:|------|
| ⭐ | 2 | 基础二分、搜索插入位置 |
| ⭐⭐ | 5 | 旋转数组搜索、找左右边界 |
| ⭐⭐⭐ | 2 | 两个正序数组中位数、分割数组最大值 |

**核心技巧**：掌握左闭右闭和左闭右开两种写法，旋转数组（114-116）是变形重点。
