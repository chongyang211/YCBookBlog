# x的平方根 (69) / 分割数组最大值 (410)

## 平方根 (二分+牛顿)

```java
public int mySqrt(int x) { if(x<2) return x; int l=1,r=x/2,a=0; while(l<=r){ int m=l+(r-l)/2; if((long)m*m<=x){ a=m; l=m+1; } else r=m-1; } return a; }
// 牛顿法: r=(r+x/r)/2
```

## 分割数组最大值 (二分答案)

二分答案 + 贪心判定。答案在 `[max(nums), sum(nums)]`。

```java
public int splitArray(int[] nums, int k) {
    int l=0, r=0; for(int n:nums){ l=Math.max(l,n); r+=n; }
    while(l<r){ int m=l+(r-l)/2, sum=0, cnt=1;
        for(int n:nums){ if(sum+n>m){ cnt++; sum=0; } sum+=n; }
        if(cnt<=k) r=m; else l=m+1;
    }
    return l;
}
```

**Python**：
```python
def splitArray(self, nums, k):
    def can(mid):
        cnt, s = 1, 0
        for x in nums:
            if s+x > mid: cnt+=1; s=0
            s += x
        return cnt <= k
    l, r = max(nums), sum(nums)
    while l < r:
        m = (l+r)//2
        if can(m): r=m
        else: l=m+1
    return l
```

**二分答案范式**：求最优 → 转化为判定 → 二分逼近。O(NlogSum)。
