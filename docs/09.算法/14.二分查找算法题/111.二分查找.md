## 基础二分 (704)

```java
public int search(int[] nums, int target) {
    int l=0, r=nums.length-1;
    while(l<=r){ int m=l+(r-l)/2; if(nums[m]==target) return m; else if(nums[m]<target) l=m+1; else r=m-1; }
    return -1;
}
```

## 搜索旋转排序数组 (114 / 33)

```java
public int search(int[] nums, int target) {
    int l=0, r=nums.length-1;
    while(l<=r){ int m=l+(r-l)/2; if(nums[m]==target) return m;
        if(nums[l]<=nums[m]){ if(nums[l]<=target&&target<nums[m]) r=m-1; else l=m+1; }
        else{ if(nums[m]<target&&target<=nums[r]) l=m+1; else r=m-1; }
    }
    return -1;
}
```

**核心**：每次迭代至少一半有序。判断 target 是否在有序半段。

## 两个有序数组的中位数 (118 / 4)

较短数组上二分找分割点 `i`，`j=half-i`。满足 `A[i-1]<=B[j] && B[j-1]<=A[i]`。

```java
public double findMedianSortedArrays(int[] A, int[] B) {
    if(A.length>B.length) return findMedianSortedArrays(B,A);
    int m=A.length, n=B.length, half=(m+n+1)/2, l=0,r=m;
    while(l<=r){ int i=l+(r-l)/2, j=half-i;
        int Al=i==0?Integer.MIN_VALUE:A[i-1], Ar=i==m?Integer.MAX_VALUE:A[i];
        int Bl=j==0?Integer.MIN_VALUE:B[j-1], Br=j==n?Integer.MAX_VALUE:B[j];
        if(Al<=Br&&Bl<=Ar) return (m+n)%2==1?Math.max(Al,Bl):(Math.max(Al,Bl)+Math.min(Ar,Br))/2.0;
        if(Al>Br) r=i-1; else l=i+1;
    }
    return 0;
}
```

```java
// 分割数组最大值 二分答案
public int splitArray(int[] nums, int k) { int l=0,r=0; for(int n:nums){ l=Math.max(l,n); r+=n; } while(l<r){ int m=l+(r-l)/2,sum=0,cnt=1; for(int n:nums){ if(sum+n>m){ cnt++; sum=0; } sum+=n; } if(cnt<=k) r=m; else l=m+1; } return l; }
```

**二分查找总结**：`while(l<=r)` + `m=l+(r-l)/2` + 有序判定 → 万变不离其宗。
