# E019 二叉树中的最大路径和

> LeetCode 124 · ⭐⭐⭐ · 后序+贡献值

## 01. 分析

后序遍历。对每个节点计算"单边最大贡献"：`max(0, max(leftGain, rightGain)) + node.val`。同时更新全局最大：`max(ans, leftGain + rightGain + node.val)`。负数贡献取0。

## 02. 代码

**Java**：
```java
int ans = Integer.MIN_VALUE;
public int maxPathSum(TreeNode root) {
    gain(root); return ans;
}
int gain(TreeNode node) {
    if (node == null) return 0;
    int L = Math.max(0, gain(node.left));
    int R = Math.max(0, gain(node.right));
    ans = Math.max(ans, L + R + node.val);
    return Math.max(L, R) + node.val;
}
```

**Python**：
```python
def maxPathSum(self, root):
    self.ans = float('-inf')
    def gain(node):
        if not node: return 0
        L = max(0, gain(node.left))
        R = max(0, gain(node.right))
        self.ans = max(self.ans, L + R + node.val)
        return max(L, R) + node.val
    gain(root)
    return self.ans
```

**C++**：
```cpp
int ans = INT_MIN;
int maxPathSum(TreeNode* root) { gain(root); return ans; }
int gain(TreeNode* node) {
    if (!node) return 0;
    int L = max(0, gain(node->left)), R = max(0, gain(node->right));
    ans = max(ans, L + R + node->val);
    return max(L, R) + node->val;
}
```

**复杂度**：O(N)/O(H)。**相关**：[E009 直径](E009-二叉树的直径.md)
