# H003 在排序数组中查找元素的第一个和最后一个位置

> LeetCode 34 · ⭐⭐ · 左右边界二分

## 01. 题目

`nums = [5,7,7,8,8,10], target = 8` → `[3,4]`

## 02. 分析

找左边界：`nums[m] >= target` 时 `r = m - 1`，记录 ans。
找右边界：`nums[m] <= target` 时 `l = m + 1`，记录 ans。

## 03. 代码

**Java**：
```java
public int[] searchRange(int[] nums, int target) {
    return new int[]{leftBound(nums, target), rightBound(nums, target)};
}
int leftBound(int[] nums, int target) {
    int l = 0, r = nums.length - 1, ans = -1;
    while (l <= r) {
        int m = l + (r - l) / 2;
        if (nums[m] >= target) { r = m - 1; if (nums[m] == target) ans = m; }
        else l = m + 1;
    }
    return ans;
}
int rightBound(int[] nums, int target) {
    int l = 0, r = nums.length - 1, ans = -1;
    while (l <= r) {
        int m = l + (r - l) / 2;
        if (nums[m] <= target) { l = m + 1; if (nums[m] == target) ans = m; }
        else r = m - 1;
    }
    return ans;
}
```

**Python**：
```python
def searchRange(self, nums, target):
    def left():
        l, r, ans = 0, len(nums)-1, -1
        while l <= r:
            m = (l+r)//2
            if nums[m] >= target: r = m-1; ans = m if nums[m]==target else ans
            else: l = m+1
        return ans
    def right():
        l, r, ans = 0, len(nums)-1, -1
        while l <= r:
            m = (l+r)//2
            if nums[m] <= target: l = m+1; ans = m if nums[m]==target else ans
            else: r = m-1
        return ans
    return [left(), right()]
```

**复杂度**：O(logN)/O(1)。
