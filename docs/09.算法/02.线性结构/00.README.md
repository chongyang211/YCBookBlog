## 🎯 数组 vs 链表

| 维度 | 数组 | 链表 |
|------|------|------|
| 内存 | 连续分配 | 离散分配 |
| 随机访问 | O(1) | O(n) |
| 插入/删除 | O(n) | O(1) |
| 缓存友好 | 是 | 否 |
| 扩容 | 需要拷贝 | 不需要 |
