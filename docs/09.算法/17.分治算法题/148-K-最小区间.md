# K008 最小区间

> LeetCode 632 · ⭐⭐⭐ · 多路归并堆

**Java**：
```java
public int[] smallestRange(List<List<Integer>> nums) {
    PriorityQueue<int[]> pq=new PriorityQueue<>((a,b)->a[0]-b[0]);
    int max=Integer.MIN_VALUE,start=0,end=Integer.MAX_VALUE;
    for(int i=0;i<nums.size();i++){ int v=nums.get(i).get(0); pq.offer(new int[]{v,i,0}); max=Math.max(max,v); }
    while(pq.size()==nums.size()){
        int[] c=pq.poll();
        if(max-c[0]<end-start){ start=c[0]; end=max; }
        if(c[2]+1<nums.get(c[1]).size()){ int nxt=nums.get(c[1]).get(c[2]+1); pq.offer(new int[]{nxt,c[1],c[2]+1}); max=Math.max(max,nxt); }
    }
    return new int[]{start,end};
}
```
