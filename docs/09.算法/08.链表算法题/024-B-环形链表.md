# B004 环形链表（Linked List Cycle）

> LeetCode 141 · ⭐ · 快慢指针
>
> Floyd 判圈算法——快慢指针的经典应用。有环必相遇，无环 fast 必到 null。

---

## 01. 题目描述

判断链表是否有环。

**示例**：

```
输入：3→2→0→-4↺ (tail connects to 2)
输出：true
```

---

## 02. 题目分析

```
slow 走 1 步，fast 走 2 步
- 无环：fast 到 null
- 有环：fast 从后面追上 slow（每轮追近 1 步，最多追 N 轮）
```

---

## 03. 代码

**Java**：

```java
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}
```

**Python**：

```python
def hasCycle(self, head: Optional[ListNode]) -> bool:
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast: return True
    return False
```

**复杂度**：时间 O(N)，空间 O(1)。
