# 链表算法题

> 共 15 题 · ⭐ 7 / ⭐⭐ 6 / ⭐⭐⭐ 2

链表是面试必考数据结构，核心技巧：**快慢指针、虚拟头节点、递归反转、归并排序**。

| 难度 | 篇数 | 代表题型 |
|:--:|:--:|------|
| ⭐ | 7 | 反转链表、环形链表、合并有序链表 |
| ⭐⭐ | 6 | LRU缓存、排序链表、重排链表 |
| ⭐⭐⭐ | 2 | K个一组翻转、合并K个升序链表 |

**建议顺序**：先反转（001-003），再快慢指针（004-005），最后归并（011-014）。
