# B005 环形链表 II（找环入口）

> LeetCode 142 · ⭐⭐ · 快慢指针+数学
>
> 判断环 + 找入口。数学证明: `a = c + (n-1)(b+c)`，即 head 到入口 = 相遇点到入口。

---

## 01. 题目描述

返回环的入口节点。若无环返回 null。

---

## 02. 题目分析

设 head 到入口距离 a，入口到相遇点 b，相遇点绕回入口 c。

慢指针路程 = a+b，快指针 = a+b+n(b+c)。
快指针速度是慢指针两倍：2(a+b) = a+b+n(b+c) → a = c + (n-1)(b+c)。

**结论**：从 head 出发的指针和从相遇点出发的指针，以相同速度走，会在入口相遇。

---

## 03. 代码

**Java**：

```java
public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            ListNode p = head;
            while (p != slow) { p = p.next; slow = slow.next; }
            return p;
        }
    }
    return null;
}
```

**Python**：

```python
def detectCycle(self, head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            p = head
            while p != slow:
                p = p.next
                slow = slow.next
            return p
    return None
```

**复杂度**：时间 O(N)，空间 O(1)。
