# 位运算算法题

> 共 10 题 · ⭐ 7 / ⭐⭐ 3

位运算是最高效的计算方式，核心技巧：**异或、n&(n-1)、位移**。

| 难度 | 篇数 | 代表题型 |
|:--:|:--:|------|
| ⭐ | 7 | 只出现一次的数字、2的幂、位1的个数 |
| ⭐⭐ | 3 | 只出现一次II/III、两整数之和 |

**核心技巧**：191 n&(n-1) 消去最低位1，193 异或分组。
