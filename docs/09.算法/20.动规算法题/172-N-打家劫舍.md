# N002 打家劫舍（House Robber）

> LeetCode 198 · ⭐⭐ · 线性DP
>
> 最经典的线性 DP 入门题：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

## 01. 题目

`[1,2,3,1]` → 4（偷 1+3）。不能偷相邻两家。

## 02. 题目分析

### 状态定义

`dp[i]`：前 i 间房能偷到的最大金额。

### 状态转移

$$dp[i] = \max(dp[i-1],\; dp[i-2] + nums[i])$$

含义：第 i 间不偷 = `dp[i-1]`；偷 = `dp[i-2] + nums[i]`。

### 空间压缩

只需记录前两个状态：`prev2` 和 `prev`。

## 03. 代码

**Java**：
```java
public int rob(int[] nums) {
    if (nums.length == 1) return nums[0];
    int prev2 = nums[0], prev = Math.max(nums[0], nums[1]);
    for (int i = 2; i < nums.length; i++) {
        int cur = Math.max(prev, prev2 + nums[i]);
        prev2 = prev; prev = cur;
    }
    return prev;
}
// 更简洁的写法：
public int rob(int[] nums) {
    int prev2 = 0, prev = 0;
    for (int n : nums) {
        int cur = Math.max(prev, prev2 + n);
        prev2 = prev; prev = cur;
    }
    return prev;
}
```

**Python**：
```python
def rob(self, nums):
    prev2 = prev = 0
    for n in nums:
        cur = max(prev, prev2 + n)
        prev2 = prev; prev = cur
    return prev
```

**C++**：
```cpp
int rob(vector<int>& nums) {
    int prev2 = 0, prev = 0;
    for (int n : nums) {
        int cur = max(prev, prev2 + n);
        prev2 = prev; prev = cur;
    }
    return prev;
}
```

**复杂度**：O(N)/O(1)。

---

## 04. 总结

```
DP 三要素：
  状态：dp[i] 前 i 间最大金额
  转移：dp[i] = max(dp[i-1], dp[i-2] + nums[i])
  边界：dp[0]=nums[0], dp[1]=max(nums[0], nums[1])
```
