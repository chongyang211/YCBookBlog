# 丑数II / 重构字符串 / 任务调度器 / IPO

## 090 丑数II (264) 多路归并

```java
public int nthUglyNumber(int n) {
    int[] dp = new int[n]; dp[0] = 1;
    int p2 = 0, p3 = 0, p5 = 0;
    for (int i = 1; i < n; i++) {
        int n2 = dp[p2]*2, n3 = dp[p3]*3, n5 = dp[p5]*5;
        dp[i] = Math.min(n2, Math.min(n3, n5));
        if (dp[i] == n2) p2++; if (dp[i] == n3) p3++; if (dp[i] == n5) p5++;
    }
    return dp[n-1];
}
```

**复杂度**：O(N)/O(N)。

## 093 重构字符串 (767) 最大堆贪心

每次取频率最高的两个字符交替放。

```java
public String reorganizeString(String s) {
    int[] f = new int[26]; for (char c : s.toCharArray()) f[c-'a']++;
    PriorityQueue<int[]> pq = new PriorityQueue<>((a,b)->b[1]-a[1]);
    for (int i = 0; i < 26; i++) if (f[i] > 0) pq.offer(new int[]{i, f[i]});
    StringBuilder sb = new StringBuilder();
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        if (sb.length() == 0 || sb.charAt(sb.length()-1) != cur[0]+'a') {
            sb.append((char)(cur[0]+'a')); if (--cur[1] > 0) pq.offer(cur);
        } else {
            if (pq.isEmpty()) return "";
            int[] nxt = pq.poll(); sb.append((char)(nxt[0]+'a'));
            if (--nxt[1] > 0) pq.offer(nxt); pq.offer(cur);
        }
    }
    return sb.toString();
}
```

## 094 任务调度器 (621) 桶思想

```java
public int leastInterval(char[] tasks, int n) {
    int[] f = new int[26]; for (char c : tasks) f[c-'A']++;
    int maxF = 0, maxCnt = 0;
    for (int x : f) { if (x > maxF) { maxF = x; maxCnt = 1; } else if (x == maxF) maxCnt++; }
    return Math.max(tasks.length, (maxF - 1) * (n + 1) + maxCnt);
}
```

## 095 IPO (502) 贪心+双堆

```java
public int findMaximizedCapital(int k, int w, int[] p, int[] c) {
    int n = p.length; int[][] arr = new int[n][2];
    for (int i = 0; i < n; i++) arr[i] = new int[]{c[i], p[i]};
    Arrays.sort(arr, (a,b) -> a[0] - b[0]);
    PriorityQueue<Integer> pq = new PriorityQueue<>(Collections.reverseOrder());
    int i = 0;
    while (k-- > 0) { while (i < n && arr[i][0] <= w) pq.offer(arr[i++][1]); if (pq.isEmpty()) break; w += pq.poll(); }
    return w;
}
```
