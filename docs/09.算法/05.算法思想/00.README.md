## 🎯 五大范式速查

| 范式 | 核心思想 | 典型应用 |
|------|------|------|
| 分治 | 大问题拆成小问题，递归解决后合并 | 归并排序、快速排序 |
| 贪心 | 每步选当前最优，不回溯 | 区间调度、跳跃游戏 |
| 回溯 | 穷举所有可能，剪枝加速 | 全排列、N皇后 |
| 动态规划 | 记录子问题结果，避免重复计算 | 背包问题、编辑距离 |
| 位运算 | 利用二进制特性高效计算 | 只出现一次的数字 |

## 📐 如何选择算法范式？

```mermaid
flowchart TD
    A[拿到一道题] --> B{能分解成子问题?}
    B -->|是,子问题独立| C[分治]
    B -->|是,子问题重叠| D[动态规划]
    B -->|否| E{需要穷举所有解?}
    E -->|是| F[回溯]
    E -->|否| G{贪心可以解决?}
    G -->|是| H[贪心]
    G -->|否| I[其他:双指针/二分等]
```
