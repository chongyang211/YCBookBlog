# L001 跳跃游戏（Jump Game）

> LeetCode 55 · ⭐⭐ · 贪心
>
> 贪心入门经典题——维护"最远可达位置"。

## 01. 题目

`nums = [2,3,1,1,4]` → true（从0跳到1，再跳到末尾）。

## 02. 题目分析

贪心策略：遍历过程中不断更新 `reach = max(reach, i + nums[i])`。如果 `i > reach`，说明当前位置不可达。

```
nums = [2,3,1,1,4]

i=0: reach=max(0,0+2)=2
i=1: reach=max(2,1+3)=4 ≥ n-1 → true
```

## 03. 代码

**Java**：
```java
public boolean canJump(int[] nums) {
    int reach = 0;
    for (int i = 0; i < nums.length; i++) {
        if (i > reach) return false;
        reach = Math.max(reach, i + nums[i]);
    }
    return true;
}
```

**Python**：
```python
def canJump(self, nums):
    reach = 0
    for i, n in enumerate(nums):
        if i > reach: return False
        reach = max(reach, i + n)
    return True
```

**复杂度**：O(N)/O(1)。
