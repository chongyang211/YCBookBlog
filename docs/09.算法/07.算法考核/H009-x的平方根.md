# H009 x 的平方根

> LeetCode 69 · ⭐ · 二分 / 牛顿迭代

## 01. 题目

计算 x 的算术平方根（只保留整数部分）。x = 8 → 2。

## 02. 题目分析

### 解法一：二分查找

在 `[1, x/2]` 范围内二分查找第一个 `m*m > x` 的位置。

### 解法二：牛顿迭代法

$$x_{n+1} = \frac{1}{2}\left(x_n + \frac{a}{x_n}\right)$$

---

## 03. 代码

**Java**：
```java
// 二分
public int mySqrt(int x) {
    if (x < 2) return x;
    int l = 1, r = x / 2, ans = 0;
    while (l <= r) {
        int m = l + (r - l) / 2;
        if ((long)m * m <= x) { ans = m; l = m + 1; }
        else r = m - 1;
    }
    return ans;
}

// 牛顿法
public int mySqrtNewton(int x) {
    if (x == 0) return 0;
    long r = x;
    while (r * r > x) r = (r + x / r) / 2;
    return (int) r;
}
```

**Python**：
```python
def mySqrt(self, x: int) -> int:
    if x < 2: return x
    l, r, ans = 1, x // 2, 0
    while l <= r:
        m = (l + r) // 2
        if m * m <= x: ans = m; l = m + 1
        else: r = m - 1
    return ans
```

**复杂度**：二分 O(logN)/O(1)，牛顿法 O(logN)收敛极快。
