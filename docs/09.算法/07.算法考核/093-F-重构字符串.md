# F008 重构字符串

> LeetCode 767 · ⭐⭐ · 最大堆贪心

## 01. 题目

重排字符串使相邻字符不同。`"aab"` → `"aba"`。

## 02. 代码

**Java**：
```java
public String reorganizeString(String s) {
    int[] f=new int[26]; for(char c:s.toCharArray()) f[c-'a']++;
    PriorityQueue<int[]> pq=new PriorityQueue<>((a,b)->b[1]-a[1]);
    for(int i=0;i<26;i++) if(f[i]>0) pq.offer(new int[]{i,f[i]});
    StringBuilder sb=new StringBuilder();
    int[] prev={-1,0};
    while(!pq.isEmpty()){
        int[] cur=pq.poll();
        sb.append((char)(cur[0]+'a')); cur[1]--;
        if(prev[1]>0) pq.offer(prev);
        prev=cur;
    }
    return sb.length()==s.length()?sb.toString():"";
}
```

**Python**：
```python
def reorganizeString(self, s):
    from collections import Counter
    import heapq
    f=Counter(s); pq=[(-v,k) for k,v in f.items()]; heapq.heapify(pq)
    res,prev=[],None
    while pq:
        v,k=heapq.heappop(pq); res.append(k)
        if prev: heapq.heappush(pq,prev)
        prev=(v+1,k) if v+1<0 else None
    return ''.join(res) if len(res)==len(s) else ''
```

**复杂度**：O(Nlog26)/O(26)。
