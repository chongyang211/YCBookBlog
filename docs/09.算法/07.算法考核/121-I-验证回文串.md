# I001 验证回文串

> LeetCode 125 · ⭐ · 双指针

## 01. 题目

只考虑字母数字字符，忽略大小写。`"A man, a plan, a canal: Panama"` → true。

## 02. 代码

**Java**：
```java
public boolean isPalindrome(String s) {
    int l=0, r=s.length()-1;
    while(l<r){ while(l<r&&!Character.isLetterOrDigit(s.charAt(l))) l++; while(l<r&&!Character.isLetterOrDigit(s.charAt(r))) r--; if(Character.toLowerCase(s.charAt(l))!=Character.toLowerCase(s.charAt(r))) return false; l++; r--; }
    return true;
}
```

**Python**：
```python
def isPalindrome(self, s): s=''.join(c.lower() for c in s if c.isalnum()); return s==s[::-1]
```

**复杂度**：O(N)/O(1)。
