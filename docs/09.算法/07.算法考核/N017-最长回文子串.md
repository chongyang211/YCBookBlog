## N017 最长回文子串 (5) 中心扩展

```java
public String longestPalindrome(String s) {
    int n=s.length(), start=0, max=0;
    for(int i=0;i<n;i++) {
        int len1=expand(s,i,i), len2=expand(s,i,i+1);
        int len=Math.max(len1,len2);
        if(len>max) { max=len; start=i-(len-1)/2; }
    }
    return s.substring(start,start+max);
}
int expand(String s, int l, int r) {
    while(l>=0&&r<s.length()&&s.charAt(l)==s.charAt(r)) { l--; r++; }
    return r-l-1;
}
```

**Python**：
```python
def longestPalindrome(self, s):
    n=len(s); start=max_len=0
    def expand(l,r):
        while l>=0 and r<len(s) and s[l]==s[r]: l-=1; r+=1
        return r-l-1
    for i in range(n):
        l1=expand(i,i); l2=expand(i,i+1)
        l=max(l1,l2)
        if l>max_len: max_len=l; start=i-(l-1)//2
    return s[start:start+max_len]

def countSubstrings(self, s):
    n,ans=len(s),0
    for i in range(n):
        l=r=i
        while l>=0 and r<n and s[l]==s[r]: ans+=1; l-=1; r+=1
        l,r=i,i+1
        while l>=0 and r<n and s[l]==s[r]: ans+=1; l-=1; r+=1
    return ans
```

## N019 最大正方形 (221)

```java
public int maximalSquare(char[][] matrix) {
    int m=matrix.length,n=matrix[0].length,max=0;
    int[][] dp=new int[m+1][n+1];
    for(int i=1;i<=m;i++)
        for(int j=1;j<=n;j++)
            if(matrix[i-1][j-1]=='1') {
                dp[i][j]=1+Math.min(dp[i-1][j-1], Math.min(dp[i-1][j], dp[i][j-1]));
                max=Math.max(max,dp[i][j]);
            }
    return max*max;
}
```

**复杂度**：回文 O(N²)/O(1)，最大正方形 O(MN)/O(MN)。
