## I002 (392) 双指针

```java
public boolean isSubsequence(String s, String t) { int i=0; for(int j=0;i<s.length()&&j<t.length();j++) if(s.charAt(i)==t.charAt(j)) i++; return i==s.length(); }
```

## I004 (345) 双指针找元音交换

```java
public String reverseVowels(String s) { char[] a=s.toCharArray(); int l=0,r=a.length-1; String v="aeiouAEIOU"; while(l<r){ while(l<r&&v.indexOf(a[l])==-1) l++; while(l<r&&v.indexOf(a[r])==-1) r--; if(l<r){ char t=a[l]; a[l]=a[r]; a[r]=t; l++; r--; } } return new String(a); }
```

## I006 (633)

```java
public boolean judgeSquareSum(int c) { long l=0,r=(long)Math.sqrt(c); while(l<=r){ long s=l*l+r*r; if(s==c) return true; if(s<c) l++; else r--; } return false; }
```

## I007 (986)

```java
public int[][] intervalIntersection(int[][] A, int[][] B) { List<int[]> r=new ArrayList<>(); int i=0,j=0; while(i<A.length&&j<B.length){ int lo=Math.max(A[i][0],B[j][0]), hi=Math.min(A[i][1],B[j][1]); if(lo<=hi) r.add(new int[]{lo,hi}); if(A[i][1]<B[j][1]) i++; else j++; } return r.toArray(new int[r.size()][]); }
```
