# O002 只出现一次的数字 II

> LeetCode 137 · ⭐⭐ · 位统计 / 状态机

## 01. 题目

`[2,2,3,2]` → 3。每个数字出现3次，唯一个出现1次。

## 02. 代码

```java
public int singleNumber(int[] nums) {
    int ones=0, twos=0;
    for(int n:nums) {
        ones = (ones ^ n) & ~twos;
        twos = (twos ^ n) & ~ones;
    }
    return ones;
}
```

**Python**：
```python
def singleNumber(self, nums):
    ones = twos = 0
    for n in nums:
        ones = (ones ^ n) & ~twos
        twos = (twos ^ n) & ~ones
    return ones
```

**复杂度**：O(N)/O(1)。
