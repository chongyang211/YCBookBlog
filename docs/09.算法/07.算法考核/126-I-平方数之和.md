# I006 平方数之和

> LeetCode 633 · ⭐⭐ · 双指针

```java
public boolean judgeSquareSum(int c) { long l=0,r=(long)Math.sqrt(c); while(l<=r){ long s=l*l+r*r; if(s==c) return true; if(s<c) l++; else r--; } return false; }
```
