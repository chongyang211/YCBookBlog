# A012 最大子数组和（Maximum Subarray）

> LeetCode 53 · ⭐⭐ · DP / 分治
>
> Kadane 算法——可能是最短却最有影响力的 DP 公式之一。一道题两种解法，理解"最优子结构"从此开始。

---

## 01. 题目描述

找出具有最大和的连续子数组，返回其最大和。

**示例**：

```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6
```

---

## 02. 题目分析

### 2.1 DP 思路

定义 `dp[i]`：以 `nums[i]` 结尾的最大子数组和。

状态转移：
$$dp[i] = \max(nums[i],\; dp[i-1] + nums[i])$$

含义：要么独自成段，要么接在前面的最大子数组后面。

### 2.2 空间压缩

只需记录前一个 dp 值：

```java
public int maxSubArray(int[] nums) {
    int max = nums[0], cur = nums[0];
    for (int i = 1; i < nums.length; i++) {
        cur = Math.max(nums[i], cur + nums[i]);
        max = Math.max(max, cur);
    }
    return max;
}
```

### 2.3 分治思路

最大子数组要么全在左半、全在右半、或跨越中点。递归计算左右，跨越中点的从中间向两边扩展。时间 O(NlogN)。

## 03. 代码

**Java**：

```java
public int maxSubArray(int[] nums) {
    int max = nums[0], cur = nums[0];
    for (int i = 1; i < nums.length; i++) {
        cur = Math.max(nums[i], cur + nums[i]);
        max = Math.max(max, cur);
    }
    return max;
}
```

**Python**：

```python
def maxSubArray(self, nums: List[int]) -> int:
    max_sum = cur = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)
        max_sum = max(max_sum, cur)
    return max_sum
```

**C++**：

```cpp
int maxSubArray(vector<int>& nums) {
    int ans = nums[0], cur = nums[0];
    for (int i = 1; i < nums.size(); i++) {
        cur = max(nums[i], cur + nums[i]);
        ans = max(ans, cur);
    }
    return ans;
}
```

**复杂度**：DP 时间 O(N) 空间 O(1)；分治 O(NlogN) / O(logN)。
