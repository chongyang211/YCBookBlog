# O001 只出现一次的数字

> LeetCode 136 · ⭐ · 异或

## 01. 题目

`[2,2,1]` → 1。除一个数字外其他都出现两次，找那个唯一的数字。线性时间常数空间。

## 02. 分析

异或三定律：① `a⊕a=0` ② `a⊕0=a` ③交换结合律。所有数异或 = 只出现一次的数。

## 03. 代码

**Java**：
```java
public int singleNumber(int[] nums) { int r=0; for(int n:nums) r^=n; return r; }
```

**Python**：
```python
def singleNumber(self, nums): return reduce(xor, nums)
```

**C++**：
```cpp
int singleNumber(vector<int>& nums) { return accumulate(nums.begin(), nums.end(), 0, bit_xor<>()); }
```

**复杂度**：O(N)/O(1)。
