# M005 组合总和

> LeetCode 39 · ⭐⭐ · 回溯+可重复选取

## 01. 题目

`candidates = [2,3,6,7], target = 7` → `[[2,2,3],[7]]`（元素可无限重复使用）。

## 02. 分析

与子集同框架，区别：①终止条件 `remain == 0` ②下次递归 start 不 +1（可重复选）。

**Java**：
```java
List<List<Integer>> res = new ArrayList<>();
public List<List<Integer>> combinationSum(int[] cand, int target) {
    backtrack(cand, target, 0, new ArrayList<>()); return res;
}
void backtrack(int[] cand, int remain, int start, List<Integer> path) {
    if (remain == 0) { res.add(new ArrayList<>(path)); return; }
    if (remain < 0) return;
    for (int i = start; i < cand.length; i++) {
        path.add(cand[i]); backtrack(cand, remain - cand[i], i, path); path.remove(path.size()-1);
    }
}
```

**Python**：
```python
def combinationSum(self, cand, target):
    res = []
    def dfs(remain, start, path):
        if remain == 0: res.append(path[:]); return
        if remain < 0: return
        for i in range(start, len(cand)):
            path.append(cand[i]); dfs(remain-cand[i], i, path); path.pop()
    dfs(target, 0, [])
    return res
```

**复杂度**：O(N^(T/M))，T=target，M=min(cand)。

**关键**：`backtrack(..., i, ...)` 不+1 表示可重复选。
