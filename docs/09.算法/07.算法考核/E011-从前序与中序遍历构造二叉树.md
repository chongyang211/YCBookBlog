# E011 从前序与中序遍历构造二叉树

> LeetCode 105 · ⭐⭐ · 分治+哈希

## 01. 题目

给定前序遍历和中序遍历数组，构造二叉树。

## 02. 分析

前序第一个是根。HashMap 存中序的值→索引，O(1) 找根位置。递归划分左右区间。

## 03. 代码

**Java**：
```java
Map<Integer, Integer> map = new HashMap<>();
int preIdx = 0;
public TreeNode buildTree(int[] preorder, int[] inorder) {
    for (int i = 0; i < inorder.length; i++) map.put(inorder[i], i);
    return build(preorder, 0, inorder.length - 1);
}
TreeNode build(int[] pre, int inL, int inR) {
    if (inL > inR) return null;
    int val = pre[preIdx++];
    TreeNode root = new TreeNode(val);
    int idx = map.get(val);
    root.left = build(pre, inL, idx - 1);
    root.right = build(pre, idx + 1, inR);
    return root;
}
```

**Python**：
```python
def buildTree(self, preorder, inorder):
    mp = {v: i for i, v in enumerate(inorder)}
    self.pi = 0
    def build(inL, inR):
        if inL > inR: return None
        val = preorder[self.pi]; self.pi += 1
        root = TreeNode(val)
        idx = mp[val]
        root.left = build(inL, idx - 1)
        root.right = build(idx + 1, inR)
        return root
    return build(0, len(inorder) - 1)
```
