# N001 爬楼梯

> LeetCode 70 · ⭐ · 基础DP

**Java**：
```java
public int climbStairs(int n) {
    if(n<=2) return n;
    int a=1,b=2;
    for(int i=3;i<=n;i++) { int c=a+b; a=b; b=c; }
    return b;
}
```

**Python**：
```python
def climbStairs(self, n):
    if n<=2: return n
    a,b=1,2
    for _ in range(3,n+1): a,b=b,a+b
    return b
```

**C++**：
```cpp
int climbStairs(int n) {
    int a=1,b=2;
    if(n==1) return a;
    for(int i=3;i<=n;i++) { int c=a+b; a=b; b=c; }
    return b;
}
```

**复杂度**：O(N)/O(1)。
