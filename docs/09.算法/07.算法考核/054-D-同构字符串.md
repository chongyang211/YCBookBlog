# D004 同构字符串

> LeetCode 205 · ⭐ · 双射映射

## 01. 题目

`s="egg", t="add"` → true。每个字符映射到唯一字符，且不同字符不能映射到同一字符。

## 02. 代码

**Java**：
```java
public boolean isIsomorphic(String s, String t) {
    int[] ms=new int[256], mt=new int[256];
    for(int i=0;i<s.length();i++){
        char a=s.charAt(i), b=t.charAt(i);
        if(ms[a]!=mt[b]) return false;
        ms[a]=mt[b]=i+1;
    }
    return true;
}
```

**Python**：
```python
def isIsomorphic(self, s: str, t: str) -> bool:
    ms, mt = {}, {}
    for a, b in zip(s, t):
        if ms.get(a, b) != b or mt.get(b, a) != a: return False
        ms[a] = b; mt[b] = a
    return True
```

**复杂度**：O(N)/O(1)。**相关**：[D005 单词规律](D005-单词规律.md)
