# I003 反转字符串

> LeetCode 344 · ⭐ · 双指针原地反转

**Java**：
```java
public void reverseString(char[] s) { for(int l=0,r=s.length-1;l<r;l++,r--){ char t=s[l]; s[l]=s[r]; s[r]=t; } }
```

**Python**：
```python
def reverseString(self, s): s.reverse()
```

**复杂度**：O(N)/O(1)。
