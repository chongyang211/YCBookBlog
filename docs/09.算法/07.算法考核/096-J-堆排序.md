# J003 堆排序（Heap Sort）

> 手写必考 · ⭐⭐ · 建堆+调整
>
> O(NlogN) 时间，O(1) 空间，不稳定。适合内存受限场景。

## 01. 题目

手写堆排序。

## 02. 题目分析

两步：①建最大堆（从最后一个非叶节点开始 heapify）；②反复取堆顶（最大值）放数组末尾。

## 03. 代码

**Java**：
```java
void heapSort(int[] nums) {
    int n = nums.length;
    for (int i = n / 2 - 1; i >= 0; i--) heapify(nums, n, i);
    for (int i = n - 1; i > 0; i--) { swap(nums, 0, i); heapify(nums, i, 0); }
}
void heapify(int[] nums, int n, int i) {
    int max = i, l = 2 * i + 1, r = 2 * i + 2;
    if (l < n && nums[l] > nums[max]) max = l;
    if (r < n && nums[r] > nums[max]) max = r;
    if (max != i) { swap(nums, i, max); heapify(nums, n, max); }
}
```

**Python**：
```python
def heap_sort(self, nums):
    def heapify(n, i):
        largest, l, r = i, 2*i+1, 2*i+2
        if l < n and nums[l] > nums[largest]: largest = l
        if r < n and nums[r] > nums[largest]: largest = r
        if largest != i: nums[i], nums[largest] = nums[largest], nums[i]; heapify(n, largest)
    n = len(nums)
    for i in range(n//2-1, -1, -1): heapify(n, i)
    for i in range(n-1, 0, -1): nums[0], nums[i] = nums[i], nums[0]; heapify(i, 0)
```

**复杂度**：O(NlogN)/O(1)，不稳定。

## 三种排序对比

| | 快排 | 归并 | 堆排 |
|------|:---:|:---:|:---:|
| 时间 | O(NlogN) | O(NlogN) | O(NlogN) |
| 空间 | O(logN) | O(N) | O(1) |
| 稳定 | 否 | **是** | 否 |
| 场景 | 通用最快 | 稳定排序/外排 | 内存受限 |
