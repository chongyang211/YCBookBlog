# A010 合并两个有序数组（Merge Sorted Array）

> LeetCode 88 · ⭐ · 逆向双指针
>
> 正向合并需要额外空间，反向合并则原地完成。此题展示了"改变遍历方向"能带来空间优化。

---

## 01. 题目描述

将 `nums2` 合并到 `nums1` 中，`nums1` 长度 m+n，末尾有 n 个 0 作为预留空间。

**示例**：

```
输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出：[1,2,2,3,5,6]
```

---

## 02. 题目分析

### 为什么从后往前？

从前往后填会覆盖 nums1 未处理的元素。从后往前，`tail` 指向 nums1 末尾的空位，永远不会覆盖未处理数据。

```
nums1 = [1,2,3,0,0,0], nums2 = [2,5,6]
         p1=2           p2=2    tail=5

p1 vs p2: 3<6 → nums1[5]=6, p2--,tail--
p1 vs p2: 3<5 → nums1[4]=5, p2--,tail--
p1 vs p2: 3>2 → nums1[3]=3, p1--,tail--
p1 vs p2: 2==2 → nums1[2]=2, p2--,tail--
p1 vs p2: 1<2 → nums1[1]=2, p2--,tail--
p2<0 → 结束

结果：[1,2,2,3,5,6]
```

---

## 03. 代码

**Java**：

```java
public void merge(int[] nums1, int m, int[] nums2, int n) {
    int p1 = m - 1, p2 = n - 1, tail = m + n - 1;
    while (p2 >= 0) {
        if (p1 >= 0 && nums1[p1] > nums2[p2])
            nums1[tail--] = nums1[p1--];
        else
            nums1[tail--] = nums2[p2--];
    }
}
```

**Python**：

```python
def merge(self, nums1: List[int], m: int, nums2: List[int], n: int) -> None:
    p1, p2, tail = m - 1, n - 1, m + n - 1
    while p2 >= 0:
        if p1 >= 0 and nums1[p1] > nums2[p2]:
            nums1[tail] = nums1[p1]; p1 -= 1
        else:
            nums1[tail] = nums2[p2]; p2 -= 1
        tail -= 1
```

**C++**：

```cpp
void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
    int p1 = m - 1, p2 = n - 1, tail = m + n - 1;
    while (p2 >= 0)
        if (p1 >= 0 && nums1[p1] > nums2[p2])
            nums1[tail--] = nums1[p1--];
        else
            nums1[tail--] = nums2[p2--];
}
```

**复杂度**：时间 O(m+n)，空间 O(1)。

## 04. 总结

> 关键启示：当正向操作会覆盖数据时，考虑反向操作。
