# P008 旋转图像

> LeetCode 48 · ⭐⭐ · 矩阵变换：转置+水平翻转

## 01. 题目

原地将 n×n 矩阵顺时针旋转 90°。

## 02. 分析

顺时针90° = 转置 + 水平翻转（每行逆序）。

## 03. 代码

**Java**：
```java
public void rotate(int[][] m) {
    int n=m.length;
    for(int i=0;i<n;i++) for(int j=i+1;j<n;j++) { int t=m[i][j]; m[i][j]=m[j][i]; m[j][i]=t; }
    for(int i=0;i<n;i++) for(int j=0;j<n/2;j++) { int t=m[i][j]; m[i][j]=m[i][n-j-1]; m[i][n-j-1]=t; }
}
```

**Python**：
```python
def rotate(self, m):
    n=len(m)
    for i in range(n):
        for j in range(i+1,n): m[i][j],m[j][i]=m[j][i],m[i][j]
    for i in range(n): m[i].reverse()
```

**复杂度**：O(N²)/O(1)。
