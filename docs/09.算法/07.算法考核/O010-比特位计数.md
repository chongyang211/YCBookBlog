# O010 比特位计数

> LeetCode 338 · ⭐ · DP+位运算

## 01. 题目

对 0≤i≤n 每个数，计算其二进制中1的个数。`n=5` → `[0,1,1,2,1,2]`

## 02. 分析

$$dp[i] = dp[i >> 1] + (i \& 1)$$

## 03. 代码

**Java**：
```java
public int[] countBits(int n) {
    int[] dp=new int[n+1];
    for(int i=1;i<=n;i++) dp[i]=dp[i>>1]+(i&1);
    return dp;
}
```

**Python**：
```python
def countBits(self, n):
    dp=[0]*(n+1)
    for i in range(1,n+1): dp[i]=dp[i>>1]+(i&1)
    return dp
```

**复杂度**：O(N)/O(N)。
