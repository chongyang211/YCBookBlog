# P005 多数元素

> LeetCode 169 · ⭐ · Boyer-Moore 投票算法

## 01. 题目

找出数组中出现次数超过 ⌊n/2⌋ 的元素。`[2,2,1,1,1,2,2]` → 2。

## 02. 分析

Boyer-Moore投票：相消法。不同元素两两抵消，剩余的就是多数元素。

```java
public int majorityElement(int[] nums) {
    int candidate=0, count=0;
    for(int n:nums){ if(count==0) candidate=n; count+=(n==candidate)?1:-1; }
    return candidate;
}
```

**Python**：
```python
def majorityElement(self, nums):
    candidate = count = 0
    for n in nums:
        if count == 0: candidate = n
        count += 1 if n == candidate else -1
    return candidate
```

**复杂度**：O(N)/O(1)。**相关**：[P006 乘积](P006-除自身以外数组的乘积.md)
