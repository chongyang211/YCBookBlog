# D006 快乐数

> LeetCode 202 · ⭐ · 哈希判环

## 01. 题目

不断替换为各位数字平方和。最终变为 1→快乐数，循环→非快乐数。`19` → true。

## 02. 代码

**Java**：
```java
public boolean isHappy(int n) {
    Set<Integer> seen = new HashSet<>();
    while (n != 1 && !seen.contains(n)) { seen.add(n); n = sumOfSquares(n); }
    return n == 1;
}
int sumOfSquares(int n) { int s=0; while(n>0){ int d=n%10; s+=d*d; n/=10; } return s; }
```

**Python**：
```python
def isHappy(self, n):
    seen = set()
    while n != 1 and n not in seen: seen.add(n); n = sum(int(d)**2 for d in str(n))
    return n == 1
```

**复杂度**：O(logN)/O(logN)。
