# N005 不同路径 / N006 不同路径II / N007 最小路径和 / N016 单词拆分

## N005 不同路径 (62)

机器人从左上到右下，m×n网格，只能右/下。

```java
public int uniquePaths(int m, int n) { int[] dp=new int[n]; Arrays.fill(dp,1); for(int i=1;i<m;i++) for(int j=1;j<n;j++) dp[j]+=dp[j-1]; return dp[n-1]; }
```

**Python**：
```python
def uniquePaths(self, m, n): return comb(m+n-2, n-1)
```

## N006 不同路径II (63)

含障碍物。`obstacleGrid[i][j]==1` 则 `dp[j]=0`。

```java
public int uniquePathsWithObstacles(int[][] g) { int m=g.length,n=g[0].length; int[] dp=new int[n]; dp[0]=g[0][0]==0?1:0; for(int i=0;i<m;i++) for(int j=0;j<n;j++){ if(g[i][j]==1) dp[j]=0; else if(j>0) dp[j]+=dp[j-1]; } return dp[n-1]; }
```

## N007 最小路径和 (64)

```java
public int minPathSum(int[][] grid) { int m=grid.length,n=grid[0].length; for(int i=1;i<m;i++) grid[i][0]+=grid[i-1][0]; for(int j=1;j<n;j++) grid[0][j]+=grid[0][j-1]; for(int i=1;i<m;i++) for(int j=1;j<n;j++) grid[i][j]+=Math.min(grid[i-1][j],grid[i][j-1]); return grid[m-1][n-1]; }
```

**Python**：
```python
def minPathSum(self, g): m,n=len(g),len(g[0]); [g[i][0]:=g[i][0]+g[i-1][0] for i in range(1,m)]; return [(g[0][j]:=g[0][j]+g[0][j-1]) for j in range(1,n)] or minPathSum_inner(g)
```

## N016 单词拆分 (139)

```java
public boolean wordBreak(String s, List<String> wordDict) { Set<String> set=new HashSet<>(wordDict); boolean[] dp=new boolean[s.length()+1]; dp[0]=true; for(int i=1;i<=s.length();i++) for(int j=0;j<i;j++) if(dp[j]&&set.contains(s.substring(j,i))){ dp[i]=true; break; } return dp[s.length()]; }
```

**Python**：
```python
def wordBreak(self, s, wordDict):
    wd=set(wordDict); dp=[False]*(len(s)+1); dp[0]=True
    for i in range(1,len(s)+1):
        for j in range(i):
            if dp[j] and s[j:i] in wd: dp[i]=True; break
    return dp[-1]
```

**复杂度**：N005 O(mn)/O(n)，N016 O(N²)/O(N)。
