# N011-N015 背包问题合集

> LeetCode 322/518/416/494/279 · ⭐⭐

## 背包问题通用模板

```
0-1背包：       dp[j]=max(dp[j], dp[j-w]+v)  // 倒序
完全背包：      dp[j]=max(dp[j], dp[j-w]+v)  // 正序
```

## N011 零钱兑换 (322) 完全背包·最少硬币

```java
public int coinChange(int[] coins, int amount) {
    int[] dp=new int[amount+1]; Arrays.fill(dp, amount+1); dp[0]=0;
    for(int coin:coins)
        for(int i=coin;i<=amount;i++) dp[i]=Math.min(dp[i], dp[i-coin]+1);
    return dp[amount]>amount?-1:dp[amount];
}
```

**Python**：
```python
def coinChange(self, coins, amount):
    dp=[amount+1]*(amount+1); dp[0]=0
    for c in coins:
        for i in range(c, amount+1): dp[i]=min(dp[i], dp[i-c]+1)
    return -1 if dp[amount]>amount else dp[amount]
```

## N012 零钱兑换 II (518) 完全背包·组合数

```java
public int change(int amount, int[] coins) {
    int[] dp=new int[amount+1]; dp[0]=1;
    for(int c:coins)
        for(int i=c;i<=amount;i++) dp[i]+=dp[i-c];
    return dp[amount];
}
```

## N013 分割等和子集 (416) 0-1背包

```java
public boolean canPartition(int[] nums) {
    int sum=0; for(int n:nums) sum+=n;
    if(sum%2==1) return false;
    int target=sum/2;
    boolean[] dp=new boolean[target+1]; dp[0]=true;
    for(int n:nums)
        for(int j=target;j>=n;j--) dp[j]|=dp[j-n];
    return dp[target];
}
```

## N014 目标和 (494) 0-1背包变形

```java
public int findTargetSumWays(int[] nums, int target) {
    int sum=0; for(int n:nums) sum+=n;
    if((sum+target)%2==1||sum+target<0) return 0;
    int bag=(sum+target)/2;
    int[] dp=new int[bag+1]; dp[0]=1;
    for(int n:nums) for(int j=bag;j>=n;j--) dp[j]+=dp[j-n];
    return dp[bag];
}
```

## N015 完全平方数 (279) 完全背包

```java
public int numSquares(int n) {
    int[] dp=new int[n+1]; Arrays.fill(dp, n+1); dp[0]=0;
    for(int i=1;i*i<=n;i++)
        for(int j=i*i;j<=n;j++) dp[j]=Math.min(dp[j],dp[j-i*i]+1);
    return dp[n];
}
```

## 背包问题总结

| 问题 | 类型 | 遍历顺序 |
|------|------|---------|
| 分割等和子集 | 0-1 | 外物内背(倒序) |
| 目标和 | 0-1变形 | 同上 |
| 零钱兑换 | 完全·最少 | 外物内背(正序) |
| 零钱兑换II | 完全·组合数 | 同上 |
| 完全平方数 | 完全·最少 | 同上 |

**关键**：组合数用外层硬币，排列数用外层容量。
