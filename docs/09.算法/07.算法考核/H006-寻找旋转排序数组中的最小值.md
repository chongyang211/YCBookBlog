# H006 寻找旋转排序数组中的最小值 / H007 寻找峰值

> LeetCode 153/162 · ⭐⭐ · 二分找拐点/爬坡

## H006 旋转数组最小值 (153)

```java
public int findMin(int[] nums) {
    int l=0, r=nums.length-1;
    while(l<r){ int m=l+(r-l)/2; if(nums[m]>nums[r]) l=m+1; else r=m; }
    return nums[l];
}
```

**复杂度**：O(logN)/O(1)。

## H007 寻找峰值 (162)

峰值：`nums[i] > nums[i-1] && nums[i] > nums[i+1]`（假设 `nums[-1]=nums[n]=-∞`）。

```java
public int findPeakElement(int[] nums) {
    int l=0, r=nums.length-1;
    while(l<r){ int m=l+(r-l)/2; if(nums[m]>nums[m+1]) r=m; else l=m+1; }
    return l;
}
```

**Python**：
```python
def findPeakElement(self, nums):
    l, r = 0, len(nums)-1
    while l < r:
        m = (l+r)//2
        if nums[m] > nums[m+1]: r = m
        else: l = m+1
    return l
```

**复杂度**：O(logN)/O(1)。**关键**：`nums[m] > nums[m+1]` 说明峰值在左半（包含m）。
