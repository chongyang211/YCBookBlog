# P004 字符串相加

> LeetCode 415 · ⭐ · 大数模拟加法

## 01. 题目

`"11"+"123"` → `"134"`。不能使用BigInteger。

## 02. 代码

**Java**：
```java
public String addStrings(String a, String b) {
    StringBuilder sb=new StringBuilder();
    int i=a.length()-1, j=b.length()-1, carry=0;
    while(i>=0||j>=0||carry>0){
        int sum=carry+(i>=0?a.charAt(i--)-'0':0)+(j>=0?b.charAt(j--)-'0':0);
        sb.append(sum%10); carry=sum/10;
    }
    return sb.reverse().toString();
}
```

**Python**：
```python
def addStrings(self, a, b):
    i,j,carry,res=len(a)-1,len(b)-1,0,[]
    while i>=0 or j>=0 or carry:
        s=carry+(ord(a[i])-48 if i>=0 else 0)+(ord(b[j])-48 if j>=0 else 0)
        res.append(str(s%10)); carry=s//10; i-=1; j-=1
    return ''.join(res[::-1])
```

**复杂度**：O(max(m,n))/O(1)。
