# B001 反转链表（Reverse Linked List）

> LeetCode 206 · ⭐ · 指针操作
>
> 链表操作的"Hello World"。迭代和递归两种写法必须烂熟于心。

---

## 01. 题目描述

反转一个单链表。

**示例**：

```
输入：1 → 2 → 3 → 4 → 5 → NULL
输出：5 → 4 → 3 → 2 → 1 → NULL
```

---

## 02. 题目分析

### 解法一：迭代（三指针）

```
prev → curr → next
逐个翻转：curr.next = prev
```

```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;  // 暂存
        curr.next = prev;           // 翻转
        prev = curr;                // 前进
        curr = next;
    }
    return prev;
}
```

### 解法二：递归

```java
public ListNode reverseList(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode newHead = reverseList(head.next);
    head.next.next = head;  // 后一个节点指回自己
    head.next = null;       // 断开原来的指针
    return newHead;
}
```

---

## 03. 代码

**Java**：

```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

**Python**：

```python
def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
    prev, cur = None, head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt
    return prev
```

**C++**：

```cpp
ListNode* reverseList(ListNode* head) {
    ListNode *prev = nullptr, *cur = head;
    while (cur) {
        ListNode *nxt = cur->next;
        cur->next = prev;
        prev = cur;
        cur = nxt;
    }
    return prev;
}
```

**复杂度**：时间 O(N)，空间 O(1)（迭代）/ O(N)（递归栈）。
