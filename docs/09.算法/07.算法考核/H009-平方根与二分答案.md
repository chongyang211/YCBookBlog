# H009 x 的平方根 / H010 分割数组的最大值

> LeetCode 69/410 · ⭐/⭐⭐⭐

## H009

**Java**：
```java
public int mySqrt(int x) {
    if(x<2) return x;
    int l=1, r=x/2, ans=0;
    while(l<=r) { int m=l+(r-l)/2; if((long)m*m<=x) { ans=m; l=m+1; } else r=m-1; }
    return ans;
}
// 牛顿法：r = (r + x/r) / 2
```

## H010 分割数组的最大值（二分答案）

```java
public int splitArray(int[] nums, int k) {
    int l=0, r=0;
    for(int n:nums) { l=Math.max(l,n); r+=n; }
    while(l<r) {
        int m=l+(r-l)/2, sum=0, cnt=1;
        for(int n:nums) { if(sum+n>m) { cnt++; sum=0; } sum+=n; }
        if(cnt<=k) r=m; else l=m+1;
    }
    return l;
}
```

**Python**：
```python
def splitArray(self, nums, k):
    def can(mid):
        cnt, s = 1, 0
        for x in nums:
            if s+x > mid: cnt+=1; s=0
            s+=x
        return cnt <= k
    l, r = max(nums), sum(nums)
    while l < r:
        m = (l+r)//2
        if can(m): r=m
        else: l=m+1
    return l
```

**复杂度**：O(NlogSum)。
