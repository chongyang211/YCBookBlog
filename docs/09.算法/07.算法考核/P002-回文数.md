# P002 回文数

> LeetCode 9 · ⭐ · 反转一半

## 01. 题目

`121` → true。不能转字符串。

## 02. 代码

```java
public boolean isPalindrome(int x) {
    if(x<0||(x%10==0&&x!=0)) return false;
    int r=0; while(x>r){ r=r*10+x%10; x/=10; }
    return x==r||x==r/10;
}
```

**Python**：
```python
def isPalindrome(self, x):
    if x<0 or (x%10==0 and x!=0): return False
    r=0
    while x>r: r=r*10+x%10; x//=10
    return x==r or x==r//10
```

**复杂度**：O(logN)/O(1)。
