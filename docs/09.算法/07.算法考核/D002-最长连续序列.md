# D002 最长连续序列

> LeetCode 128 · ⭐⭐ · 哈希+边界探测

## 01. 题目

`[100,4,200,1,3,2]` → 4 (最长连续序列 `[1,2,3,4]`)，要求 O(N)。

## 02. 分析

关键：只有当一个数是序列起点（`num-1` 不在集合中）时才向后探测。

## 03. 代码

**Java**：
```java
public int longestConsecutive(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int n : nums) set.add(n);
    int max = 0;
    for (int n : set) {
        if (!set.contains(n - 1)) {
            int cur = n, len = 1;
            while (set.contains(cur + 1)) { cur++; len++; }
            max = Math.max(max, len);
        }
    }
    return max;
}
```

**Python**：
```python
def longestConsecutive(self, nums):
    s = set(nums); ans = 0
    for x in s:
        if x - 1 not in s:
            y = x + 1
            while y in s: y += 1
            ans = max(ans, y - x)
    return ans
```

**复杂度**：O(N)/O(N)，每个数最多被访问两次。
