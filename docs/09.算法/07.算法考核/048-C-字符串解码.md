# C013 字符串解码

> LeetCode 394 · ⭐⭐ · 栈辅助
>
> `"3[a2[c]]"` → `"accaccacc"`。用栈处理嵌套：遇到 `]` 弹栈拼接。

## 01. 代码

**Java**：
```java
public String decodeString(String s) {
    Deque<Integer> numStack = new ArrayDeque<>();
    Deque<StringBuilder> strStack = new ArrayDeque<>();
    StringBuilder cur = new StringBuilder();
    int num = 0;
    for (char c : s.toCharArray()) {
        if (Character.isDigit(c)) num = num * 10 + (c - '0');
        else if (c == '[') { numStack.push(num); strStack.push(cur); num = 0; cur = new StringBuilder(); }
        else if (c == ']') {
            int k = numStack.pop();
            StringBuilder prev = strStack.pop();
            for (int i = 0; i < k; i++) prev.append(cur);
            cur = prev;
        }
        else cur.append(c);
    }
    return cur.toString();
}
```

**Python**：
```python
def decodeString(self, s):
    stack, cur_num, cur_str = [], 0, ''
    for c in s:
        if c.isdigit(): cur_num = cur_num * 10 + int(c)
        elif c == '[': stack.append((cur_str, cur_num)); cur_str, cur_num = '', 0
        elif c == ']': prev_str, num = stack.pop(); cur_str = prev_str + cur_str * num
        else: cur_str += c
    return cur_str
```

**复杂度**：时间 O(N·maxK)，空间 O(N)。
