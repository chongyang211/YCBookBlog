# E001 二叉树的前序遍历（Preorder Traversal）

> LeetCode 144 · ⭐ · 递归 / 迭代
>
> 遍历是二叉树一切操作的基础。前序（根→左→右）有三种写法，分别对应不同场景。

---

## 01. 题目描述

给定二叉树的根节点 `root`，返回其节点值的**前序遍历**。

**示例**：

```
输入：root = [1,null,2,3]
输出：[1,2,3]

    1
     \
      2
     /
    3
```

---

## 02. 题目分析：三种写法对比

### 2.1 递归（最简单）

前序遍历本质是 DFS 的特例：

```
访问根 → 递归左子树 → 递归右子树
```

### 2.2 迭代（栈模拟）

用栈模拟递归。注意压栈顺序：**先压右子节点，再压左子节点**（这样左子节点先出栈）。

### 2.3 解法对比

| 解法 | 时间 | 空间 | 适用场景 |
|------|:---:|:---:|------|
| 递归 | O(N) | O(H) | 快速实现、代码简洁 |
| 迭代（栈） | O(N) | O(H) | 避免递归栈溢出 |
| Morris | O(N) | O(1) | 极致空间优化 |

---

## 03. 解法一：递归

```java
public List<Integer> preorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    dfs(root, res);
    return res;
}
void dfs(TreeNode node, List<Integer> res) {
    if (node == null) return;
    res.add(node.val);          // ① 访问根
    dfs(node.left, res);        // ② 遍历左子树
    dfs(node.right, res);       // ③ 遍历右子树
}
```

**Python**：
```python
def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
    res = []
    def dfs(node):
        if not node: return
        res.append(node.val)
        dfs(node.left)
        dfs(node.right)
    dfs(root)
    return res
```

**C++**：
```cpp
vector<int> preorderTraversal(TreeNode* root) {
    vector<int> res;
    function<void(TreeNode*)> dfs = [&](TreeNode* node) {
        if (!node) return;
        res.push_back(node->val);
        dfs(node->left);
        dfs(node->right);
    };
    dfs(root);
    return res;
}
```

**复杂度**：时间 O(N)，空间 O(H)。

## 04. 解法二：迭代（栈模拟递归）

### 4.1 思路

手动维护栈。关键：栈是 LIFO，要保证左子树先处理，就**先把右节点入栈**。

```
初始：栈 = [root]
循环：
  node = 栈.pop()
  访问 node
  if node.right ≠ null: 栈.push(node.right)
  if node.left ≠ null:  栈.push(node.left)
```

### 4.2 代码

**Java**：
```java
public List<Integer> preorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        res.add(node.val);                 // 访问根
        if (node.right != null) stack.push(node.right); // 先右
        if (node.left != null)  stack.push(node.left);  // 后左
    }
    return res;
}
```

**Python**：
```python
def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
    if not root: return []
    stack, res = [root], []
    while stack:
        node = stack.pop()
        res.append(node.val)
        if node.right: stack.append(node.right)
        if node.left:  stack.append(node.left)
    return res
```

**C++**：
```cpp
vector<int> preorderTraversal(TreeNode* root) {
    if (!root) return {};
    vector<int> res;
    stack<TreeNode*> st; st.push(root);
    while (!st.empty()) {
        TreeNode* node = st.top(); st.pop();
        res.push_back(node->val);
        if (node->right) st.push(node->right);
        if (node->left)  st.push(node->left);
    }
    return res;
}
```

**复杂度**：时间 O(N)，空间 O(H)。

## 05. Morris 遍历（O(1) 空间，选读）

利用空闲的右指针，无需额外栈空间。

```java
public List<Integer> preorderMorris(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    TreeNode cur = root;
    while (cur != null) {
        if (cur.left == null) {
            res.add(cur.val);
            cur = cur.right;
        } else {
            TreeNode pre = cur.left;
            while (pre.right != null && pre.right != cur) pre = pre.right;
            if (pre.right == null) {
                res.add(cur.val);        // 前序：第一次遇到就访问
                pre.right = cur;
                cur = cur.left;
            } else {
                pre.right = null;
                cur = cur.right;
            }
        }
    }
    return res;
}
```

## 06. 总结

| 遍历方式 | 访问顺序 | 栈操作要点 |
|---------|---------|-----------|
| 前序 | 根→左→右 | 先压右，后压左 |
| 中序 | 左→根→右 | 一路向左入栈 |
| 后序 | 左→右→根 | 前序(根右左) 反转 |
