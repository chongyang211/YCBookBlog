# A003 最接近的三数之和（3Sum Closest）

> LeetCode 16 · ⭐⭐ · 排序+双指针
>
> 三数之和的孪生题。从"等于 0"变成"最接近 target"，框架不变，只需把判断条件从"相等"改为"更新最近值"。

---

## 01. 题目描述

给定整数数组 `nums` 和目标值 `target`，找出 `nums` 中三个整数使得它们的和与 `target` 最接近。返回这三个数的和。假定每组输入只存在恰好一个解。

**示例**：

```
输入：nums = [-1,2,1,-4], target = 1
输出：2
解释：与 target 最接近的和是 2 (-1 + 2 + 1 = 2)
```

---

## 02. 题目分析

与三数之和相同的排序+双指针框架，区别在于：

| 三数之和 | 最接近的三数之和 |
|---------|---------------|
| `sum == 0` 时记录 | 每次更新 closest |
| 命中后去重 | 不命中也需要更新 closest |
| 命中后可 return | 永远不能提前 return（除非 sum==target） |

### 双指针方向判断

`sum < target` → l++（需要更大）
`sum > target` → r--（需要更小）
`sum == target` → 直接返回

---

## 03. 代码

**Java**：

```java
public int threeSumClosest(int[] nums, int target) {
    Arrays.sort(nums);
    int closest = nums[0] + nums[1] + nums[2];
    int n = nums.length;
    for (int i = 0; i < n - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;
        int l = i + 1, r = n - 1;
        while (l < r) {
            int sum = nums[i] + nums[l] + nums[r];
            if (Math.abs(sum - target) < Math.abs(closest - target))
                closest = sum;
            if (sum < target) l++;
            else if (sum > target) r--;
            else return sum;  // 精确相等，最优解
        }
    }
    return closest;
}
```

**Python**：

```python
def threeSumClosest(self, nums: List[int], target: int) -> int:
    nums.sort()
    closest = nums[0] + nums[1] + nums[2]
    n = len(nums)
    for i in range(n - 2):
        if i > 0 and nums[i] == nums[i - 1]: continue
        l, r = i + 1, n - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if abs(s - target) < abs(closest - target):
                closest = s
            if s < target: l += 1
            elif s > target: r -= 1
            else: return s
    return closest
```

```cpp
            else return s;
        }
    }
    return closest;
}
```

**复杂度**：时间 O(N²)，空间 O(logN)。

## 04. 总结

三数之和系列题的核心框架：

```
排序 → 固定第一个 → 双指针夹逼 → 根据sum决定移动方向
```

变化只在于"判断条件"：
- 15 题：`sum == 0` 记录并去重
- 16 题：用 `abs(sum-target)` 更新最近值
