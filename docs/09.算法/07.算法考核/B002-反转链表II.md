# B002 反转链表 II

> LeetCode 92 · ⭐⭐ · 区间反转
>
> 局部反转。关键技巧：用"穿针引线"法（头插法）在区间内逐个将后续节点插入到 pre 之后。

---

## 01. 题目描述

反转从位置 left 到 right 的链表节点，其余保持不变。1-indexed。

**示例**：

```
输入：1→2→3→4→5, left=2, right=4
输出：1→4→3→2→5
```

---

## 02. 题目分析

### 头插法（穿针引线）

```
dummy → 1 → 2 → 3 → 4 → 5, left=2, right=4

pre=1, cur=2

轮1：nxt=3, cur.next=4, nxt.next=2, pre.next=3
     dummy → 1 → 3 → 2 → 4 → 5

轮2：nxt=4, cur.next=5, nxt.next=3, pre.next=4
     dummy → 1 → 4 → 3 → 2 → 5
```

---

## 03. 代码

**Java**：

```java
public ListNode reverseBetween(ListNode head, int left, int right) {
    ListNode dummy = new ListNode(0, head);
    ListNode pre = dummy;
    for (int i = 1; i < left; i++) pre = pre.next;
    ListNode cur = pre.next;
    for (int i = 0; i < right - left; i++) {
        ListNode nxt = cur.next;
        cur.next = nxt.next;
        nxt.next = pre.next;
        pre.next = nxt;
    }
    return dummy.next;
}
```

**Python**：

```python
def reverseBetween(self, head: Optional[ListNode], left: int, right: int) -> Optional[ListNode]:
    dummy = ListNode(0, head)
    pre = dummy
    for _ in range(left - 1): pre = pre.next
    cur = pre.next
    for _ in range(right - left):
        nxt = cur.next
        cur.next = nxt.next
        nxt.next = pre.next
        pre.next = nxt
    return dummy.next
```

**C++**：

```cpp
ListNode* reverseBetween(ListNode* head, int left, int right) {
    ListNode dummy(0, head), *pre = &dummy;
    for (int i = 1; i < left; i++) pre = pre->next;
    ListNode *cur = pre->next;
    for (int i = 0; i < right - left; i++) {
        ListNode *nxt = cur->next;
        cur->next = nxt->next;
        nxt->next = pre->next;
        pre->next = nxt;
    }
    return dummy.next;
}
```

**复杂度**：时间 O(N)，空间 O(1)。
