# E001-E003 二叉树的遍历（前序/中序/后序）

> LeetCode 144/94/145 · ⭐ · 递归/迭代/Morris
>
> 三种遍历的递归+迭代+Morris 实现，面试必考。

---

## 前序遍历（Preorder: 根→左→右）

**迭代**：栈先压右再压左。

**Java**：
```java
List<Integer> res = new ArrayList<>();
void preorder(TreeNode root) {
    if (root == null) return;
    res.add(root.val); preorder(root.left); preorder(root.right);
}
// 迭代
List<Integer> preorderIter(TreeNode root) {
    List<Integer> ans = new ArrayList<>();
    if (root == null) return ans;
    Deque<TreeNode> stack = new ArrayDeque<>(); stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        ans.add(node.val);
        if (node.right != null) stack.push(node.right);
        if (node.left != null) stack.push(node.left);
    }
    return ans;
}
```

**Python**：
```python
def preorder(root):
    if not root: return []
    stack, ans = [root], []
    while stack:
        node = stack.pop(); ans.append(node.val)
        if node.right: stack.append(node.right)
        if node.left: stack.append(node.left)
    return ans
```

## 中序遍历（Inorder: 左→根→右）

**迭代**：一路向左入栈，弹栈访问后转向右子树。

**Java**：
```java
List<Integer> inorderIter(TreeNode root) {
    List<Integer> ans = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) { stack.push(cur); cur = cur.left; }
        cur = stack.pop(); ans.add(cur.val);
        cur = cur.right;
    }
    return ans;
}
// Morris遍历（O(1)空间）：利用空闲右指针
List<Integer> inorderMorris(TreeNode root) {
    List<Integer> ans = new ArrayList<>();
    TreeNode cur = root;
    while (cur != null) {
        if (cur.left == null) { ans.add(cur.val); cur = cur.right; }
        else {
            TreeNode pre = cur.left;
            while (pre.right != null && pre.right != cur) pre = pre.right;
            if (pre.right == null) { pre.right = cur; cur = cur.left; }
            else { pre.right = null; ans.add(cur.val); cur = cur.right; }
        }
    }
    return ans;
}
```

**Python**：
```python
def inorder(root):
    stack, ans, cur = [], [], root
    while stack or cur:
        while cur: stack.append(cur); cur = cur.left
        cur = stack.pop(); ans.append(cur.val)
        cur = cur.right
    return ans
```

## 后序遍历（Postorder: 左→右→根）

**迭代**：前序"根右左"反转得"左右根"。

**Java**：
```java
List<Integer> postorderIter(TreeNode root) {
    List<Integer> ans = new ArrayList<>();
    if (root == null) return ans;
    Deque<TreeNode> stack = new ArrayDeque<>(); stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop(); ans.add(node.val);
        if (node.left != null) stack.push(node.left);
        if (node.right != null) stack.push(node.right);
    }
    Collections.reverse(ans);
    return ans;
}
```

**Python**：
```python
def postorder(root):
    if not root: return []
    stack, ans = [root], []
    while stack:
        node = stack.pop(); ans.append(node.val)
        if node.left: stack.append(node.left)
        if node.right: stack.append(node.right)
    return ans[::-1]
```

## 三种遍历对比

| 遍历 | 迭代思路 | Morris 空间 |
|------|---------|:---:|
| 前序 | 栈先右后左 | 可行 |
| 中序 | 一路向左 | O(1) |
| 后序 | 前序反转 | 较复杂 |

**复杂度**：O(N)/O(H)（栈深度），Morris O(N)/O(1)。
