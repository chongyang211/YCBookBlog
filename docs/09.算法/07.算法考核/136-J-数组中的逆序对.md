# J004 数组中的逆序对

>  剑指 Offer 51 · ⭐⭐⭐ · 归并统计

**题目**：`[7,5,6,4]` → 5个逆序对

**Java (归并)**：
```java
int cnt = 0;
public int reversePairs(int[] nums) {
    mergeSort(nums, 0, nums.length-1);
    return cnt;
}
void mergeSort(int[] a, int l, int r) {
    if(l>=r) return;
    int m=l+(r-l)/2;
    mergeSort(a,l,m); mergeSort(a,m+1,r);
    merge(a,l,m,r);
}
void merge(int[] a, int l, int m, int r) {
    int[] tmp=new int[r-l+1]; int i=l,j=m+1,k=0;
    while(i<=m && j<=r) {
        if(a[i]<=a[j]) tmp[k++]=a[i++];
        else { tmp[k++]=a[j++]; cnt+=m-i+1; } // 关键！
    }
    while(i<=m) tmp[k++]=a[i++];
    while(j<=r) tmp[k++]=a[j++];
    System.arraycopy(tmp,0,a,l,tmp.length);
}
```

**Python**：
```python
def reversePairs(self, nums):
    self.cnt = 0
    def merge(l, r):
        if l>=r: return
        m=(l+r)//2; merge(l,m); merge(m+1,r)
        i,j,k=l,m+1,0
        tmp=[0]*(r-l+1)
        while i<=m and j<=r:
            if nums[i]<=nums[j]: tmp[k]=nums[i]; i+=1
            else: tmp[k]=nums[j]; j+=1; self.cnt+=m-i+1
            k+=1
        while i<=m: tmp[k]=nums[i]; i+=1; k+=1
        while j<=r: tmp[k]=nums[j]; j+=1; k+=1
        nums[l:r+1]=tmp
    merge(0,len(nums)-1)
    return self.cnt
```

**复杂度**：O(NlogN)/O(N)。
