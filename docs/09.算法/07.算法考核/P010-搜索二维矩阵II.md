# P010 搜索二维矩阵 II

> LeetCode 240 · ⭐⭐ · Z字形搜索

## 01. 题目

矩阵每行每列都升序。搜索 target。O(m+n)。

## 02. 分析

从右上角开始：`target < cur` → 左移；`target > cur` → 下移。

## 03. 代码

**Java**：
```java
public boolean searchMatrix(int[][] m, int t) {
    int r=0, c=m[0].length-1;
    while(r<m.length&&c>=0){ if(m[r][c]==t) return true; if(m[r][c]<t) r++; else c--; }
    return false;
}
```

**Python**：
```python
def searchMatrix(self, m, t):
    r,c=0,len(m[0])-1
    while r<len(m) and c>=0:
        if m[r][c]==t: return True
        if m[r][c]<t: r+=1
        else: c-=1
    return False
```

**复杂度**：O(m+n)/O(1)。
