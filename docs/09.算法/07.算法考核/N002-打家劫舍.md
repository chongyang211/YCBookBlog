# N002-N004 打家劫舍 I/II/III

> LeetCode 198/213/337 · ⭐⭐ · 线性/环形/树形DP

## 打家劫舍 I (198) 线性

```java
public int rob(int[] nums) {
    if(nums.length==1) return nums[0];
    int[] dp = new int[nums.length];
    dp[0]=nums[0]; dp[1]=Math.max(nums[0],nums[1]);
    for(int i=2;i<nums.length;i++) dp[i]=Math.max(dp[i-1],dp[i-2]+nums[i]);
    return dp[nums.length-1];
}
// 空间优化：cur=Math.max(prev, prev2+nums[i])
```

## 打家劫舍 II (213) 环形

首尾相邻 → 做两次线性DP：`rob(nums[0..n-2])` 和 `rob(nums[1..n-1])`，取max。

```java
public int rob(int[] nums) {
    int n=nums.length;
    if(n==1) return nums[0];
    return Math.max(robRange(nums,0,n-2), robRange(nums,1,n-1));
}
int robRange(int[] nums, int l, int r) {
    int prev2=0, prev=0;
    for(int i=l;i<=r;i++) { int cur=Math.max(prev,prev2+nums[i]); prev2=prev; prev=cur; }
    return prev;
}
```

## 打家劫舍 III (337) 树形

```java
public int rob(TreeNode root) {
    int[] res = dfs(root); return Math.max(res[0],res[1]);
}
int[] dfs(TreeNode node) { // [不偷, 偷]
    if(node==null) return new int[]{0,0};
    int[] L=dfs(node.left), R=dfs(node.right);
    int notRob = Math.max(L[0],L[1]) + Math.max(R[0],R[1]);
    int rob = node.val + L[0] + R[0];
    return new int[]{notRob, rob};
}
```

**Python**：
```python
def rob(self, nums):
    if len(nums)==1: return nums[0]
    prev2,prev=0,0
    for n in nums: cur=max(prev,prev2+n); prev2=prev; prev=cur
    return prev
```

**复杂度**：I/II O(N)/O(1)，III O(N)/O(H)。
