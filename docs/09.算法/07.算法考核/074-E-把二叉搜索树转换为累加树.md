# E017 把二叉搜索树转换为累加树

> LeetCode 538 · ⭐⭐ · 逆中序+累加和

## 01. 分析

逆中序（右→根→左）遍历 BST，维护累加和 sum，每个节点值更新为 sum+=node.val。

## 02. 代码

**Java**：
```java
int sum = 0;
public TreeNode convertBST(TreeNode root) {
    if (root == null) return null;
    convertBST(root.right);
    sum += root.val; root.val = sum;
    convertBST(root.left);
    return root;
}
```

**Python**：
```python
def convertBST(self, root):
    self.s = 0
    def dfs(node):
        if not node: return
        dfs(node.right)
        self.s += node.val; node.val = self.s
        dfs(node.left)
    dfs(root)
    return root
```

**复杂度**：O(N)/O(H)。
