# P001 整数反转

> LeetCode 7 · ⭐⭐ · 溢出处理

## 01. 题目

`123` → `321`，`-123` → `-321`。若溢出返回0。

## 02. 分析

每次 `r=r*10+x%10`。溢出判断：`r>MAX/10 || (r==MAX/10 && digit>7)`。

## 03. 代码

**Java**：
```java
public int reverse(int x) {
    int r=0;
    while(x!=0){ if(r>Integer.MAX_VALUE/10||r<Integer.MIN_VALUE/10) return 0; r=r*10+x%10; x/=10; }
    return r;
}
```

**Python**：
```python
def reverse(self, x):
    sign = -1 if x<0 else 1
    r = int(str(abs(x))[::-1]) * sign
    return r if -2**31<=r<=2**31-1 else 0
```

**复杂度**：O(log₁₀N)/O(1)。
