# P003 罗马数字转整数

> LeetCode 13 · ⭐ · 哈希模拟

## 01. 题目

`"LVIII"` → 58 (L=50, V=5, III=3)。小数字在大数字左边则减法，右边则加法。

## 02. 代码

**Java**：
```java
public int romanToInt(String s) {
    Map<Character,Integer> m=new HashMap<>(){{ put('I',1);put('V',5);put('X',10);put('L',50);put('C',100);put('D',500);put('M',1000); }};
    int ans=0;
    for(int i=0;i<s.length();i++){
        int cur=m.get(s.charAt(i));
        if(i+1<s.length()&&cur<m.get(s.charAt(i+1))) ans-=cur;
        else ans+=cur;
    }
    return ans;
}
```

**Python**：
```python
def romanToInt(self, s):
    d={'I':1,'V':5,'X':10,'L':50,'C':100,'D':500,'M':1000}
    return sum(d[c] if d[s[i]]>=d[s[i+1]] else -d[c] for i,c in enumerate(s[:-1])) + d[s[-1]]
```

**复杂度**：O(N)/O(1)。
