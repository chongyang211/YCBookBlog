# 位运算超全合集 (O001-O010)

> LeetCode 136/137/260/231/191/190/201/371/461/338

## 位运算核心技巧

| 操作 | 代码 | 用途 |
|------|------|------|
| 消最低位1 | `n & (n-1)` | 统计1的个数、判2的幂 |
| 取最低位1 | `n & -n` | 分组、树状数组 |
| 异或 | `a ^ b` | 找不同、去重、求和 |

## O001 只出现一次的数字 (136)

```java
public int singleNumber(int[] nums) {
    int res=0; for(int n:nums) res^=n; return res;
}
```

## O002 只出现一次的数字 II (137)

每个数字出现3次，唯一个出现1次。

```java
public int singleNumber(int[] nums) {
    int ones=0,twos=0;
    for(int n:nums) {
        ones=(ones^n)&~twos; twos=(twos^n)&~ones;
    }
    return ones;
}
```

## O003 只出现一次的数字 III (260)

两个数字出现1次，其余2次。

```java
public int[] singleNumber(int[] nums) {
    int xor=0; for(int n:nums) xor^=n;
    int mask=xor&-xor; // 最低位1
    int a=0; for(int n:nums) if((n&mask)!=0) a^=n;
    return new int[]{a, xor^a};
}
```

```java
public boolean isPowerOfTwo(int n) { return n>0 && (n&(n-1))==0; }
```

## O005 位1的个数 (191)

```java
public int hammingWeight(int n) {
    int cnt=0; while(n!=0) { n&=n-1; cnt++; } return cnt;
}
```

## O006 颠倒二进制位 (190)

```java
public int reverseBits(int n) {
    int res=0;
    for(int i=0;i<32;i++) { res=(res<<1)|(n&1); n>>=1; }
    return res;
}
```

## O008 两整数之和 (371)

```java
public int getSum(int a, int b) {
    while(b!=0) { int carry=(a&b)<<1; a^=b; b=carry; }
    return a;
}
```

```java
public int hammingDistance(int x, int y) { return Integer.bitCount(x^y); }
```

## O010 比特位计数 (338)

```java
public int[] countBits(int n) {
    int[] dp=new int[n+1];
    for(int i=1;i<=n;i++) dp[i]=dp[i>>1]+(i&1);
    return dp;
}
```

```python
def getSum(self, a, b):
    mask=0xffffffff
    while b: a,b=(a^b)&mask,((a&b)<<1)&mask
    return a if a<=0x7fffffff else ~(a^mask)
```
