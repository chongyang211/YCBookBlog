## P001 整数反转 (7)

```java
public int reverse(int x) {
    int res=0;
    while(x!=0) {
        if(res>Integer.MAX_VALUE/10||res<Integer.MIN_VALUE/10) return 0;
        res=res*10+x%10; x/=10;
    }
    return res;
}
```

## P002 回文数 (9)

```java
public boolean isPalindrome(int x) {
    if(x<0||(x%10==0&&x!=0)) return false;
    int reversed=0;
    while(x>reversed) { reversed=reversed*10+x%10; x/=10; }
    return x==reversed||x==reversed/10;
}
```

## P003 罗马数字转整数 (13)

```java
public int romanToInt(String s) {
    Map<Character,Integer> m=new HashMap<>(){{ put('I',1);put('V',5);put('X',10);put('L',50);put('C',100);put('D',500);put('M',1000); }};
    int ans=0;
    for(int i=0;i<s.length();i++) {
        int cur=m.get(s.charAt(i));
        if(i+1<s.length()&&cur<m.get(s.charAt(i+1))) ans-=cur;
        else ans+=cur;
    }
    return ans;
}
```

## P005 多数元素 (169) Boyer-Moore

```java
public int majorityElement(int[] nums) {
    int candidate=0, count=0;
    for(int n:nums) {
        if(count==0) candidate=n;
        count+=(n==candidate)?1:-1;
    }
    return candidate;
}
```

## P006 除自身以外数组的乘积 (238)

```java
public int[] productExceptSelf(int[] nums) {
    int n=nums.length;
    int[] res=new int[n]; res[0]=1;
    for(int i=1;i<n;i++) res[i]=res[i-1]*nums[i-1]; // 前缀积
    int right=1;
    for(int i=n-1;i>=0;i--) { res[i]*=right; right*=nums[i]; } // 后缀积
    return res;
}
```

## P007 下一个排列 (31)

```java
public void nextPermutation(int[] nums) {
    int n=nums.length, i=n-2;
    while(i>=0&&nums[i]>=nums[i+1]) i--;
    if(i>=0) { int j=n-1; while(nums[j]<=nums[i]) j--; swap(nums,i,j); }
    reverse(nums,i+1,n-1);
}
void reverse(int[] a, int l, int r) { while(l<r) swap(a,l++,r--); }
void swap(int[] a, int i, int j) { int t=a[i]; a[i]=a[j]; a[j]=t; }
```

## P008 旋转图像 (48)

```java
public void rotate(int[][] matrix) {
    int n=matrix.length;
    for(int i=0;i<n;i++) // 转置
        for(int j=i+1;j<n;j++) { int t=matrix[i][j]; matrix[i][j]=matrix[j][i]; matrix[j][i]=t; }
    for(int i=0;i<n;i++) // 水平翻转
        for(int j=0;j<n/2;j++) { int t=matrix[i][j]; matrix[i][j]=matrix[i][n-j-1]; matrix[i][n-j-1]=t; }
}
```

## P009 螺旋矩阵 (54)

```java
public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> res=new ArrayList<>();
    int t=0,b=matrix.length-1,l=0,r=matrix[0].length-1;
    while(t<=b&&l<=r) {
        for(int j=l;j<=r;j++) res.add(matrix[t][j]); t++;
        for(int i=t;i<=b;i++) res.add(matrix[i][r]); r--;
        if(t<=b) for(int j=r;j>=l;j--) res.add(matrix[b][j]); b--;
        if(l<=r) for(int i=b;i>=t;i--) res.add(matrix[i][l]); l++;
    }
    return res;
}
```

## P010 搜索二维矩阵 II (240)

```java
public boolean searchMatrix(int[][] matrix, int target) {
    int r=0, c=matrix[0].length-1;
    while(r<matrix.length&&c>=0) {
        if(matrix[r][c]==target) return true;
        if(matrix[r][c]<target) r++; else c--;
    }
    return false;
}
```

```python
def nextPermutation(self, nums):
    i=len(nums)-2
    while i>=0 and nums[i]>=nums[i+1]: i-=1
    if i>=0:
        j=len(nums)-1
        while nums[j]<=nums[i]: j-=1
        nums[i],nums[j]=nums[j],nums[i]
    nums[i+1:]=reversed(nums[i+1:])
```

**复杂度**：O(N)或O(N²)/O(1)。
