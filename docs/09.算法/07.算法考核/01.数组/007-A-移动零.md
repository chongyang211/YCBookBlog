# A007 移动零（Move Zeroes）

> LeetCode 283 · ⭐ · 双指针
>
> 原地操作 + 保持相对顺序——双指针的经典入门题。看似简单，写法却有很大的效率差异。

---

## 01. 题目描述

将所有 0 移到数组末尾，同时保持非零元素的相对顺序。必须原地操作，不能拷贝数组。

**示例**：

```
输入：[0,1,0,3,12]
输出：[1,3,12,0,0]
```

---

## 02. 题目分析

### 2.1 双指针思想

| 指针 | 含义 |
|------|------|
| `i` | 遍历指针，扫描每个元素 |
| `j` | 写入指针，指向"下一个非零元素应该放的位置" |

```java
// 交换法（一次遍历）
public void moveZeroes(int[] nums) {
    for (int i = 0, j = 0; i < nums.length; i++) {
        if (nums[i] != 0) {
            int tmp = nums[i];
            nums[i] = nums[j];
            nums[j++] = tmp;
        }
    }
}
```

### 2.2 演变

```
思路1：遇到0就删除、末尾补0 → 数组删除O(N)，总O(N²)
思路2：先把非零按序填到前面，后面统一填0 → O(N)，两次遍历
思路3：交换法，一次遍历 → O(N)，最优
```

## 03. 代码

**Java**：

```java
public void moveZeroes(int[] nums) {
    for (int i = 0, j = 0; i < nums.length; i++)
        if (nums[i] != 0) {
            int tmp = nums[i]; nums[i] = nums[j]; nums[j++] = tmp;
        }
}
```

**Python**：

```python
def moveZeroes(self, nums: List[int]) -> None:
    j = 0
    for i in range(len(nums)):
        if nums[i] != 0:
            nums[i], nums[j] = nums[j], nums[i]
            j += 1
```

**C++**：

```cpp
void moveZeroes(vector<int>& nums) {
    for (int i = 0, j = 0; i < nums.size(); i++)
        if (nums[i] != 0) swap(nums[i], nums[j++]);
}
```

**复杂度**：时间 O(N)，空间 O(1)。
