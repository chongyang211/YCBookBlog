# B012 复制带随机指针的链表

> LeetCode 138 · ⭐⭐ · 哈希映射 / 节点交错
>
> 两种解法：哈希 O(N)/O(N)，节点交错 O(N)/O(1)。后者是链表题的经典炫技。

---

## 01. 题目描述

深拷贝一个链表，每个节点除了 `next` 还有一个 `random` 指针。

---

## 02. 解法对比

| 解法 | 空间 | 思路 |
|------|:---:|------|
| 哈希 | O(N) | `Map<OldNode, NewNode>` 存映射 |
| 节点交错 | O(1) | 每个原节点后插入新节点；设 random 后拆分 |

### 节点交错法

```
原： A → B → C
插入：A → A' → B → B' → C → C'
设random：A'.random = A.random.next
拆分：提取所有'节点
```

---

## 03. 代码（交错法）

**Java**：

```java
public Node copyRandomList(Node head) {
    if (head == null) return null;
    // 1. 插入新节点
    for (Node cur = head; cur != null; cur = cur.next.next) {
        Node clone = new Node(cur.val);
        clone.next = cur.next; cur.next = clone;
    }
    // 2. 设 random
    for (Node cur = head; cur != null; cur = cur.next.next) {
        if (cur.random != null) cur.next.random = cur.random.next;
    }
    // 3. 拆分
    Node newHead = head.next;
    for (Node cur = head; cur != null; cur = cur.next) {
        Node clone = cur.next;
        cur.next = clone.next;
        if (clone.next != null) clone.next = clone.next.next;
    }
    return newHead;
}
```

**复杂度**：O(N) / O(1)。
