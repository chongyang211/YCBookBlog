# L005 用最少数量的箭引爆气球

> LeetCode 452 · ⭐⭐ · 贪心区间

## 01. 题目

`points = [[10,16],[2,8],[1,6],[7,12]]` → 2（x=6和x=11各一箭）。

## 02. 分析

与 L004 同框架，但重叠定义不同：`start > end` 才需要新箭（边界接触也算引爆）。

**Java**：
```java
public int findMinArrowShots(int[][] points) {
    Arrays.sort(points, (a, b) -> Integer.compare(a[1], b[1]));
    int end = points[0][1], arrows = 1;
    for (int i = 1; i < points.length; i++)
        if (points[i][0] > end) { arrows++; end = points[i][1]; }
    return arrows;
}
```

**Python**：
```python
def findMinArrowShots(self, points):
    points.sort(key=lambda x: x[1])
    end, arrows = points[0][1], 1
    for s, e in points[1:]:
        if s > end: arrows += 1; end = e
    return arrows
```

**复杂度**：O(NlogN)/O(1)。**注意**：用 `Integer.compare` 防溢出。
