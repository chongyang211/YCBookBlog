## L003 分发饼干 (455)

public int findContentChildren(int[] g, int[] s) { Arrays.sort(g); Arrays.sort(s); int i=0; for(int j=0;i<g.length&&j<s.length;j++) if(s[j]>=g[i]) i++; return i; }

## L007 划分字母区间 (763)

```java
public List<Integer> partitionLabels(String s) { int[] last=new int[26]; for(int i=0;i<s.length();i++) last[s.charAt(i)-'a']=i; List<Integer> res=new ArrayList<>(); int start=0,end=0; for(int i=0;i<s.length();i++){ end=Math.max(end,last[s.charAt(i)-'a']); if(i==end){ res.add(end-start+1); start=i+1; } } return res; }
```

## L008 加油站 (134)

```java
public int canCompleteCircuit(int[] gas, int[] cost) { int total=0,tank=0,start=0; for(int i=0;i<gas.length;i++){ int diff=gas[i]-cost[i]; total+=diff; tank+=diff; if(tank<0){ start=i+1; tank=0; } } return total>=0?start:-1; }
```

## L009 摆动序列 (376)

```java
public int wiggleMaxLength(int[] nums) { if(nums.length<2) return nums.length; int up=1,down=1; for(int i=1;i<nums.length;i++){ if(nums[i]>nums[i-1]) up=down+1; else if(nums[i]<nums[i-1]) down=up+1; } return Math.max(up,down); }
```
