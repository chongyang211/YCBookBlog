# semaphore 信号量

golang.org/x/sync/semaphore 加权信号量、Acquire/Release 机制、与 Channel 信号量对比、限流实战、连接池控制。

```go
sem := semaphore.NewWeighted(10)
sem.Acquire(ctx, 1)
defer sem.Release(1)
```
