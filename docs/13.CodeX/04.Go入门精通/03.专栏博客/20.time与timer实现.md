# 10.time 与 timer 实现

> `time.Sleep` / `time.After` / `time.Ticker` 看似简单，但背后是 Go runtime 一次大规模重构——从 Go 1.9 的全局四叉堆 + 单线程 timerproc，到 Go 1.10/1.14 的 P 本地四叉堆与 netpoll 协作。本篇拆 timer 数据结构、添加/删除/触发流程、与调度器的耦合。
> 关键词：四叉堆（4-ary heap）、P 本地 timer、`addtimer`/`deltimer`/`adjusttimers`、`runtimer`、`time.Sleep` vs `time.After` 区别、Go 1.23 timer 池化优化
