# 09.性能优化实战

> 一个 P99 800ms 的真实接口，5 步优化到 50ms。每一步的工具、数据、验证。
> 关键词：减少分配、减少 GC、减少锁、减少 syscall、benchmark 驱动

## 优化目标
- 接口：用户中心 `GET /api/profile/:id`
- 起点：P99 = 800ms，CPU 80%
- 终点：P99 = 50ms，CPU 30%
