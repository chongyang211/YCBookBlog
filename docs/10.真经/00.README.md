# 专栏系列

> 跨平台、多语言、深原理——从性能到稳定，从原理到工程

## 系列总览

```
  效率                 根基                 布局                 保障                 交付
┌──────────┐      ┌──────────┐      ┌──────────┐      ┌──────────┐      ┌──────────┐
│ 01.      │──→   │ 02.      │──→   │ 05.      │──→   │ 03.      │──→   │ 04.      │
│ 性能优化  │      │ 编程原理  │      │ 方案设计  │      │ 稳定可靠  │      │ 工程运维  │
│ 实践     │      │          │      │ 思想     │      │          │      │          │
```

| # | 专栏 | 定位 | 核心问题 |
|:--:|------|------|------|
| 01 | 性能优化实践 | 效率 | 系统怎么跑得快？启动/渲染/内存/IO 全链路 |
| 02 | 程序编程原理 | 根基 | 数据/运行时/并发/内存——语言无关的底层规律 |
| 03 | 稳定性与可靠性 | 保障 | 熔断/限流/容灾/幂等——生产环境不出事 |
| 04 | 工程化与运维 | 交付 | CI/CD/容器/监控/日志——代码写好只是第一步 |
| 05 | 方案设计思想 | 布局 | 架构/组件/通信/效能——系统怎么搭 |

## 写作方法论

所有专栏统一采用**疑惑→分析→论证→结论**的科学范式：

- 禁止模糊表述，要求可证伪
- 所有数据有出处，所有对比有基准
- 跨平台对照（Android/iOS/Web/后端），不限于单一技术栈
