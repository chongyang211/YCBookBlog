## 核心方法论

本系列采用 **疑惑→答疑→论证→结果** 的技术演变展示模式：

1. **疑惑**：提出一个真实的技术困惑（如：为什么TCP需要三次握手而不是两次？）
2. **答疑**：给出核心答案（防止历史连接请求的干扰）
3. **论证**：用具体场景和数据证明（网络延迟导致的旧SYN到达场景）
4. **结果**：总结设计演变和最佳实践
