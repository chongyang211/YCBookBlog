# WebSocket 实时通信

> 从 HTTP 轮询到全双工——WebSocket 协议握手、帧格式、心跳保活、实战踩坑

## 功能规划

- **为什么需要 WebSocket**：HTTP 半双工的局限，短轮询/长轮询的代价
- **协议握手**：HTTP Upgrade 机制、101 Switching Protocols、Sec-WebSocket-Key/Accept
- **帧格式详解**：FIN/RSV/Opcode/MASK/Payload、控制帧 vs 数据帧
- **心跳保活**：Ping/Pong 帧、Nginx/负载均衡的超时断开问题
- **实战案例**：聊天室、实时推送、协同编辑的消息设计
