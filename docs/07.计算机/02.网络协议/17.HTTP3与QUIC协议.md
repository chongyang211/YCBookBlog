# HTTP/3 与 QUIC 协议

> 从 TCP 到 UDP——为什么 HTTP/3 要抛弃 TCP、QUIC 如何解决队头阻塞

## 功能规划

- **HTTP/2 的痛点**：TCP 队头阻塞、连接建立慢（TCP+TLS 两次握手）
- **QUIC 设计哲学**：基于 UDP、0-RTT 握手、多路复用无队头阻塞
- **连接迁移**：Connection ID、WiFi↔4G 无感切换
- **QUIC 的拥塞控制**：与 TCP CUBIC/BBR 的对比
- **HTTP/3 现状**：浏览器支持、CDN 部署、升级路径
