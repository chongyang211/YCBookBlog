## 使用原则

1. **即取即用** — 每条脚本含注释，复制即可运行
2. **单一职责** — 一个脚本只做一件事
3. **可配置** — 关键参数用变量声明
4. **跨平台** — 标注兼容性(Linux/macOS/Windows)
