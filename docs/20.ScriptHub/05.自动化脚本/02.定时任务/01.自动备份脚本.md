# 自动备份

数据库(mysql/pg/mongo)定时备份、文件备份(rsync/tar)、远程备份(scp/s3)、保留策略(7天/30天)、备份校验。

```bash
#!/bin/bash
# crontab: 0 2 * * * /path/to/script.sh
set -e
echo '[$(date)] 自动备份 start'
```
