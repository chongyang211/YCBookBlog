# 镜像构建推送

GitHub Actions 构建 Docker 镜像、多阶段构建优化、推送到 Docker Hub/GitHub Container Registry、镜像标签策略。

```yaml
# GitHub Actions Workflow
name: 镜像构建推送
on: [push]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
```
