# 自动测试

自动运行单元测试(pytest/jest)、生成测试报告、覆盖率检查、PR 时自动测试、测试失败阻断合并。

```yaml
# GitHub Actions Workflow
name: 自动测试
on: [push]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
```
