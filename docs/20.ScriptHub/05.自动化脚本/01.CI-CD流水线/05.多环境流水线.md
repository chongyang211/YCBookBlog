# 多环境部署

dev/staging/prod 三环境分离、环境变量管理、审批门禁(environment protection)、蓝绿/滚动发布策略。

```yaml
# GitHub Actions Workflow
name: 多环境部署
on: [push]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
```
