# GitHub自动部署

GitHub Actions workflow 语法、on push 触发、checkout/setup-node 等 action、SSH 免密部署到 VPS、secrets 管理密钥。

```yaml
# GitHub Actions Workflow
name: GitHub自动部署
on: [push]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
```
