# 自动化脚本手册

> 18 个开箱即用的自动化脚本 · 4 大分类

| # | 分类 | 篇数 | 适用场景 |
|:--:|------|:--:|------|
| 01 | CI-CD流水线 | 5 | GitHub Actions / 自动构建 / 部署 / 发布 |
| 02 | 定时任务 | 4 | 备份 / 清理 / 证书 / 健康检查 |
| 03 | 事件触发 | 4 | Webhook / Git Push / 文件变更 / 告警触发 |
| 04 | 一键脚本 | 5 | 环境搭建 / 项目初始化 / 迁移 / 重启 / 回滚 |

## 使用原则

1. **脚本即服务** — 配好参数即可独立运行
2. **幂等设计** — 重复执行不产生副作用
3. **日志输出** — 每次执行记录时间+结果
4. **失败告警** — 异常时通知（钉钉/企业微信/邮件）
