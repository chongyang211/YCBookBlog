# 自动发布

自动打 Tag、自动生成 CHANGELOG、自动发布 Release、自动推送 npm/Docker/PyPI、语义化版本。

```yaml
# GitHub Actions Workflow
name: 自动发布
on: [push]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
```
