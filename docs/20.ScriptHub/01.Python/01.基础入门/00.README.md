# Python 基础入门

> 共 4 篇 · 5596 行 · 26 节 · 102 小节

**从 Hello World 到工程化 Python**——变量→容器→控制流→函数→装饰器→OOP→文件IO→异常→迭代器→生成器，四篇文章覆盖 Python 核心语法的全部知识点。

| 章节 | 核心内容 | 预估学时 |
|------|----------|----------|
| 01 入门与基础类型 | 安装/REPL、数字/字符串/布尔/None、运算符、print/input | 4h |
| 02 序列与集合类型 | 字符串进阶/正则、列表/元组/深浅拷贝、字典/集合/哈希原理 | 5h |
| 03 流程控制与函数 | if/for/while/海象运算符、函数参数全景、LEGB/闭包、lambda、装饰器 | 8h |
| 04 面向对象与工程 | class/继承/魔术方法、模块/包/pip/虚拟环境、文件IO/JSON/CSV、异常、迭代器/生成器 | 8h |

**学习路径**：01 → 02 → 03（§3.1~§3.5 基础部分）→ 04 → 03（§3.6 装饰器进阶，结合第4章 OOP 理解更透）
