# Python 从0到1 学习专栏

> 面向零基础读者，从环境搭建到项目实战，循序渐进掌握 Python。

## 学习路线图

```
零基础 ──→ 语法基础 ──→ 函数/模块 ──→ 面向对象 ──→ 高级特性
                                              │
  项目实战 ←── 数据库 ←── 网络编程 ←── 数据处理 ←──┘
```

---

## 第一阶段：基础入门

### 第1章 · 环境搭建与语言基础

| 编号 | 内容 | 核心要点 |
|------|------|----------|
| 01 | Python 简介与环境安装 | Python 发行版选择、pyenv/conda、IDE 推荐（VS Code / PyCharm） |
| 02 | 第一个 Python 程序 | `print()`、交互式解释器、脚本运行方式、基本调试 |

## 学习建议

| 阶段 | 建议周期 | 关键方法 |
|------|----------|----------|
| 第一阶段（基础） | 2-3 周 | 每学一个知识点就写代码验证，不要只看不练 |
| 第二阶段（核心） | 3-4 周 | 结合 LeetCode 简单题练习，加深对数据结构和算法的理解 |
| 第三阶段（工程） | 3-4 周 | 阅读优秀开源项目源码，学习工程组织方式 |
| 第四阶段（生态） | 4-5 周 | 按需深入，不需要全部精通，用到时查文档即可 |
| 第五阶段（实战） | 持续 | 至少完成 2-3 个项目，代码托管到 GitHub |

> **重要原则**：
> - ✍️ **多写代码**：看十遍不如写一遍
> - 🔍 **读懂报错**：会看 traceback 比会写代码更重要
> - 📖 **查官方文档**：二手资料可能有误，官方文档最权威
> - 🤝 **参与社区**：在 Stack Overflow / GitHub 上提问和贡献
