# 调试与脚本规范

## 一、调试排错

set -x 跟踪执行、set -e 遇错退出、set -u 未定义变量报错、trap 信号捕获、PS4 自定义跟踪前缀、常见错误(got 10)。

```bash
#!/bin/bash
set -euo pipefail
echo '技巧实践'
```

## 二、脚本规范

Google Shell Style Guide、文件头注释模板、函数命名、缩进与换行、引号使用原则、行宽限制、shellcheck 静态检查。

```bash
#!/bin/bash
set -euo pipefail
echo '技巧实践'
```
