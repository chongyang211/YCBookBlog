# 流程控制与函数

## 一、条件判断

if-elif-else-fi、test/`[[]]` 条件测试、字符串/数值/文件判断、`&&` / `||` 短路运算、case 多分支。

```bash
#!/bin/bash
echo 'Hello Shell!'
```

## 二、循环控制

for/while/until 循环、break/continue、循环读取文件、seq 生成序列、循环处理命令输出。

```bash
#!/bin/bash
echo 'Hello Shell!'
```

## 三、函数参数

函数定义/调用、参数传递 `$1/$@`、return 返回值、局部变量 local、函数库引入 source、递归函数。

```bash
#!/bin/bash
echo 'Hello Shell!'
```
