## 学习路径

```
       基础搜索 → 正则进阶 → 上下文控制
             ↘
  grep ←──── grep 实战（日志/代码/配置）
   │
   ├──→ sed（流编辑替换 + 文本批量修改）
   │
   ├──→ awk（格式化 + 统计报表）
   │
   └──→ find+sort（查找 + 整理）

文本处理能力 = grep（搜索） + sed（编辑） + awk（分析）
                 所有场景，一条管道全部搞定
```
