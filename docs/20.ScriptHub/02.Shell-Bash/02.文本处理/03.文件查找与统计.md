# 文件查找与统计

## 一、find 与 xargs

find 按名称/类型/大小/时间搜索、逻辑运算(`-a/-o/!`)、exec 执行命令、xargs 批量处理、`-print0/-0` 处理空格。

```bash
#!/bin/bash
echo 'Hello Shell!'
```

## 二、sort 去重统计

sort 排序(`-n/-r/-k`)、uniq 去重/统计 `-c`、cut 列提取、tr 字符转换、paste 合并、wc 统计行词字。

```bash
#!/bin/bash
echo 'Hello Shell!'
```
