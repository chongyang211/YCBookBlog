# grep 搜索实战

## 一、grep 基础搜索

grep 基本用法、正则基础(`. ^ $ * + ?`)、忽略大小写 `-i`、反向匹配 `-v`、行号 `-n`、递归 `-r`、只显示文件名 `-l`。

```bash
#!/bin/bash
echo 'Hello Shell!'
```

## 二、grep 高级技巧

扩展正则 `-E`、单词边界 `\b`、后向引用、上下文 `-A/-B/-C`、统计 `-c`、二进制文件搜索、多模式 `-e/-f`。

```bash
#!/bin/bash
echo 'Hello Shell!'
```
