# sed 与 awk 编程

```bash
#!/bin/bash
echo 'Hello Shell!'
```

## 二、sed 高级编辑

多点编辑 `-e`、脚本文件 `-f`、保持空间 `h/H/g/G`、标签与跳转、多行处理 `N/P/D`、实战：批量修改配置文件。

```bash
#!/bin/bash
echo 'Hello Shell!'
```

awk 工作模型(记录/字段)、模式-动作结构、NR/NF/FS/OFS、BEGIN/END 块、字段分割、条件过滤。

```bash
#!/bin/bash
echo 'Hello Shell!'
```

```bash
#!/bin/bash
echo 'Hello Shell!'
```
