# ScriptHub 脚本工具箱

实用脚本，即取即用。Python / Shell / Bash 精选收藏。

## 目录

| 编号 | 脚本分类 | 适用场景 |
|------|----------|----------|
| 01 | Python | 数据处理、文件操作、API 调用、自动化任务 |
| 02 | Shell | 系统管理、日志分析、环境配置、进程管理 |
| 03 | Bash | Linux 命令行脚本，与 Shell 互补 |
| 04 | 工具脚本 | 开发辅助：格式化/压缩/加解密/二维码等 |
| 05 | 自动化脚本 | CI/CD / 定时任务 / 批量操作 / 监控 |

## 使用原则

1. **即取即用** - 每条脚本配有注释说明，直接复制运行
2. **单一职责** - 一个脚本只做一件事
3. **可配置** - 关键参数用变量声明，便于修改
4. **跨平台** - 标注兼容性（Linux/macOS/Windows）

> **持续更新**：遇到好用的脚本就收录进来。
