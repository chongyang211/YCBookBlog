# 第六章：C语言 迷你KV存储引擎

本章是综合案例的**第六关·存储引擎设计**——用 C 语言手写一个 Redis 风格的 Key-Value 存储，支持 SET/GET/DEL/EXPIRE/KEYS/SAVE 命令，并通过 AOF 追加日志实现持久化。核心挑战：**哈希索引 + TTL过期 + 文件追加写** 三件套。

> ⚠️ **本关新增"造bug高峰"**：§06 故意只写 AOF、不 fsync → kill -9 → 数据丢失 → 修复。

## 03.内存存储引擎

```c
#include <time.h>

#define MAX_KEY   64
#define MAX_VALUE 256
#define MAX_KEYS  1000

typedef struct {
    char   key[MAX_KEY];
    char   value[MAX_VALUE];
    time_t expireAt;  // 0 = 永不过期
} Entry;

Entry  store[MAX_KEYS];
int    entryCount = 0;

// 查找 key 的索引
int findKey(const char *key) {
    for (int i = 0; i < entryCount; i++) {
        if (strcmp(store[i].key, key) == 0) return i;
    }
    return -1;
}

void setKey(const char *key, const char *value) {
    int idx = findKey(key);
    if (idx != -1) {
        strcpy(store[idx].value, value);
        store[idx].expireAt = 0;
    } else {
        if (entryCount >= MAX_KEYS) { printf("(error) 存储已满\n"); return; }
        strcpy(store[entryCount].key, key);
        strcpy(store[entryCount].value, value);
        store[entryCount].expireAt = 0;
        entryCount++;
    }
    printf("OK\n");
}

const char* getKey(const char *key) {
    int idx = findKey(key);
    if (idx == -1) return NULL;
    // 惰性过期检查
    if (store[idx].expireAt > 0 &&
        time(NULL) >= store[idx].expireAt) {
        delKey(key);  // 惰性删除
        return NULL;
    }
    return store[idx].value;
}

void delKey(const char *key) {
    int idx = findKey(key);
    if (idx == -1) { printf("(integer) 0\n"); return; }
    // 数组删除：将后面元素前移
    for (int i = idx; i < entryCount - 1; i++) {
        store[i] = store[i + 1];
    }
    entryCount--;
    printf("(integer) 1\n");
}

void expireKey(const char *key, int seconds) {
    int idx = findKey(key);
    if (idx == -1) { printf("(integer) 0\n"); return; }
    store[idx].expireAt = time(NULL) + seconds;
    printf("OK\n");
}

void listKeys() {
    time_t now = time(NULL);
    int count = 0;
    for (int i = 0; i < entryCount; i++) {
        if (store[i].expireAt > 0 && now >= store[i].expireAt)
            continue;  // 跳过过期
        printf("%d) \"%s\"\n", ++count, store[i].key);
    }
}
```

🔑 **惰性过期**：只在 `getKey` 和 `listKeys` 时才检查 TTL，而不是起一个后台清理线程。这是 Redis 的经典设计模式——省线程。

## 04.命令解析执行

```c
// 简单的 tokenize（空格切分）
int tokenize(char *line, char tokens[][64]) {
    int n = 0;
    char *tok = strtok(line, " ");
    while (tok && n < 10) {
        strcpy(tokens[n++], tok);
        tok = strtok(NULL, " ");
    }
    return n;
}

// 命令分发
void processCommand(char *line) {
    char tokens[10][64];
    int n = tokenize(line, tokens);
    if (n == 0) return;

    if (strcmp(tokens[0], "SET") == 0 && n >= 3) {
        setKey(tokens[1], tokens[2]);
    } else if (strcmp(tokens[0], "GET") == 0 && n >= 2) {
        const char *v = getKey(tokens[1]);
        printf("%s\n", v ? v : "(nil)");
    } else if (strcmp(tokens[0], "DEL") == 0 && n >= 2) {
        delKey(tokens[1]);
    } else if (strcmp(tokens[0], "EXPIRE") == 0 && n >= 3) {
        expireKey(tokens[1], atoi(tokens[2]));
    } else if (strcmp(tokens[0], "KEYS") == 0) {
        listKeys();
    } else {
        printf("(error) 未知命令: %s\n", tokens[0]);
    }
}
```

## 06.AOF持久化

```
┌─ ⚠️ 造BUG高峰：故意不 fsync → kill → 丢失 ──────────┐
│ SET k 1 → SAVE（不 fsync）→ kill -9 → 重启 → GET k = nil │
│ 修复：每次 write 后 fflush + 启动时加载重放               │
└──────────────────────────────────────────────────────┘
```

```c
FILE *aofFile = NULL;

// 追加写 AOF
void aofWrite(const char *cmd) {
    if (!aofFile) return;
    fprintf(aofFile, "%s\n", cmd);
    fflush(aofFile);  // ⭐ 必须 flush，否则 kill 丢数据
}

// 启动时重放 AOF
void aofReplay() {
    FILE *f = fopen("data.aof", "r");
    if (!f) return;
    char line[512];
    while (fgets(line, sizeof(line), f)) {
        line[strcspn(line, "\n")] = 0;
        processCommand(line);
    }
    fclose(f);
    printf(">>> AOF 重放完成\n");
}

int main() {
    aofFile = fopen("data.aof", "a");
    aofReplay();  // ⭐ 启动时恢复数据

    char line[256];
    while (1) {
        printf("> ");
        if (!fgets(line, sizeof(line), stdin)) break;
        line[strcspn(line, "\n")] = 0;
        if (strcmp(line, "EXIT") == 0) { printf("再见！\n"); break; }
        processCommand(line);
        aofWrite(line);  // ⭐ 每次写命令都追加
    }
    if (aofFile) fclose(aofFile);
    return 0;
}
```

## 07.总结与C++对比

| 维度 | C语言实现 | C++实现 |
|------|-----------|----------|
| **存储** | 固定数组 + 线性查找 O(n) | `unordered_map` O(1) |
| **过期** | `time()` + `difftime` | `std::chrono::steady_clock` |
| **AOF** | `fopen`/`fprintf`/`fflush` | `std::ofstream` RAII |
| **字符串** | `strtok` 切词 | `std::istringstream` |
| **命令分发** | `if-else` 比对 | 命令模式 + 虚函数 |
| **并发** | 无（单线程） | mutex + shared_mutex |

**延伸挑战**：改哈希表实现 O(1) 查找、加后台 TTL 清理线程、加 `INCR`/`DECR` 命令。
