## 01.系统需求

```text
场景：100 张票，3 个售票窗口，10 个顾客同时抢票
要求：不能超卖（卖出的总数 ≤ 100）
技术：pthread 多线程 + mutex 互斥锁 + 条件变量 + 日志
```

### C语言 vs C++ 并发对照

| 概念 | C语言 (pthread) | C++ |
|------|-----------------|-----|
| 线程 | `pthread_create` | `std::thread` |
| 互斥锁 | `pthread_mutex_lock/unlock` | `std::lock_guard` RAII |
| 条件变量 | `pthread_cond_wait/signal` | `cv.wait(lock, lambda)` |
| 原子变量 | 无（手动加锁） | `std::atomic<T>` |
| 休眠 | `usleep` | `std::this_thread::sleep_for` |

## 02.基础框架

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <pthread.h>
#include <unistd.h>
#include <time.h>

// 日志级别
typedef enum { LOG_INFO, LOG_WARN, LOG_ERROR } LogLevel;

// 日志结构体
typedef struct {
    FILE *file;
    pthread_mutex_t mutex;
} Logger;

int logger_init(Logger *l, const char *filename) {
    l->file = fopen(filename, "a");
    if (!l->file) return -1;
    pthread_mutex_init(&l->mutex, NULL);
    return 0;
}

void logger_log(Logger *l, const char *msg, LogLevel level) {
    pthread_mutex_lock(&l->mutex);
    const char *prefix[] = {"[INFO]","[WARN]","[ERROR]"};
    fprintf(l->file, "%s %s\n", prefix[level], msg);
    fflush(l->file);
    printf("%s %s\n", prefix[level], msg);
    pthread_mutex_unlock(&l->mutex);
}
```

## 04.票务核心

```
┌─ ⚠️ 造BUG高峰：先不加 mutex → 超卖 ──────────────┐
│ 100 件库存 + 200 个并发买家 → stock 变成 -3           │
│ 修复：加 pthread_mutex → 零超卖                │
└──────────────────────────────────────────────────────┘
```

### 4.1 BUG版（裸int，无锁）

```c
typedef struct {
    int totalTickets;       // 总票数
    int remainingTickets;   // ⚠️ 裸 int，无保护！
    Logger *logger;
} TicketSystem_BUG;

int sellTicket_BUG(TicketSystem_BUG *ts, int num) {
    if (ts->remainingTickets >= num) {   // ① 检查
        ts->remainingTickets -= num;      // ② 扣减
        return 1;  // ⚠️ ①和②不是原子的！
    }
    return 0;
}
```

🧪 200线程压测：

```text
期望: 卖出 100 件
实际: 卖出 103 件，stock = -3  ← 超卖！
```

**根因**：线程A检查通过 → OS切走 → 线程B也检查通过 → 两个线程都扣减 → 超过库存。

### 4.2 修复版（mutex）

```c
typedef struct {
    int              totalTickets;
    int              remainingTickets;
    pthread_mutex_t  mutex;    // ⭐ 加锁！
    pthread_cond_t   cv;       // 条件变量
    Logger          *logger;
} TicketSystem;

int sellTicket(TicketSystem *ts, int num, const char *who) {
    pthread_mutex_lock(&ts->mutex);
    
    while (ts->remainingTickets < num && ts->remainingTickets > 0) {
        pthread_cond_wait(&ts->cv, &ts->mutex);
    }
    
    if (ts->remainingTickets >= num) {
        ts->remainingTickets -= num;
        pthread_mutex_unlock(&ts->mutex);
        return 1;
    }
    pthread_mutex_unlock(&ts->mutex);
    return 0;
}
```

🧪 再测200线程：卖出恰好100件 ✅

## 05.售票窗口线程

```c
typedef struct {
    char          name[64];
    TicketSystem *ts;
    Logger       *logger;
    volatile int  running;
    int           sold;
    pthread_t     thread;
    pthread_mutex_t soldMutex;
} TicketWindow;

void* window_thread(void *arg) {
    TicketWindow *w = (TicketWindow*)arg;
    unsigned int seed = (unsigned int)time(NULL) ^ (unsigned int)pthread_self();
    
    while (w->running) {
        int n = (rand_r(&seed) % 5) + 1;  // 每次卖 1-5 张
        if (sellTicket(w->ts, n, w->name)) {
            pthread_mutex_lock(&w->soldMutex);
            w->sold += n;
            pthread_mutex_unlock(&w->soldMutex);
            usleep(100000);  // 100ms 出票模拟
        } else {
            break;  // 票卖完了
        }
    }
    return NULL;
}

void window_start(TicketWindow *w) {
    w->running = 1;
    pthread_create(&w->thread, NULL, window_thread, w);
}
```

🔑 **`volatile int running`**：告诉编译器"这个变量可能被其他线程改变，不要优化掉对它的读取"——C语言没有 `std::atomic<bool>`，`volatile` + mutex 是标准替代。

## 06.顾客购票线程

```c
typedef struct {
    char          name[64];
    TicketSystem *ts;
    int           numTickets;
    pthread_t     thread;
} Customer;

void* customer_thread(void *arg) {
    Customer *c = (Customer*)arg;
    if (sellTicket(c->ts, c->numTickets, c->name)) {
        printf("%s 成功购买 %d 张票\n", c->name, c->numTickets);
    } else {
        printf("%s 购票失败（库存不足）\n", c->name);
    }
    return NULL;
}

void customer_buy(Customer *c) {
    pthread_create(&c->thread, NULL, customer_thread, c);
}
```

## 07.监控与VIP

```c
// 动态监控线程：每秒检查库存
void* monitor_thread(void *arg) {
    TicketSystem *ts = (TicketSystem*)arg;
    while (1) {
        sleep(1);
        pthread_mutex_lock(&ts->mutex);
        int r = ts->remainingTickets;
        pthread_mutex_unlock(&ts->mutex);
        if (r < ts->totalTickets / 4) {
            printf("⚠️  库存告急！只剩 %d 张\n", r);
        }
        if (r == 0) break;
    }
    return NULL;
}
```

## 08.总结与C++对比

| 维度 | C语言实现 | C++实现 |
|------|-----------|----------|
| **线程** | `pthread_create` + 函数指针 | `std::thread` + lambda |
| **锁** | `pthread_mutex_lock/unlock` 手动 | `std::lock_guard` RAII |
| **条件变量** | `pthread_cond_wait` + while | `cv.wait(lock, lambda)` |
| **原子变量** | `volatile` + mutex | `std::atomic<int>` 无锁 |
| **错误处理** | 返回值检查 | try-catch 异常 |

**延伸挑战**：加入性能监控、改用 `compare_exchange` 模拟原子操作、对比锁竞争前后的 QPS。
