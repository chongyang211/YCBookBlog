## 01.轮训管理系统

### 1.1 产品需求

主要功能：

1. 可以灵活设置轮询的时间（例如固定间隔、动态调整间隔等）
2. 暴露一个doAction接口，用于执行用户定义的任务
3. 支持启动、停止、暂停、继续等操作
4. 支持任务执行超时监控
5. 支持任务执行结果的记录
6. 支持多线程（轮询在一个线程，任务执行可以在另一个线程）
7. 错误处理

### 1.2 设计核心思路

设计一个Poller结构体，它包含以下主要部分：

- 配置：轮询间隔（可以是固定值，也可以是动态计算的函数）、任务超时时间等
- 状态：运行状态（运行、暂停、停止）
- 线程：轮询线程，用于定时触发任务
- 任务执行：使用独立线程执行任务，避免任务执行时间过长影响下一次轮询
- 超时监控：为任务设置超时时间

**对比C++**：C++使用类、继承、`std::unique_ptr`等面向对象机制。C语言使用结构体+函数指针模拟多态，用`void*`实现通用数据传递。

### 1.3 开发的步骤

1. 定义时间单位枚举和转换工具
2. 定义轮询策略接口（函数指针表）
3. 实现三种具体策略：固定间隔、指数退避、随机间隔
4. 定义任务结果和统计结构
5. 实现轮询器核心，包含启动、停止、暂停、继续等方法
6. 实现任务执行部分，使用独立线程并监控超时
7. 编写示例用法

### 1.4 技术栈说明

| 技术类别 | 具体技术 | 应用场景 |
|---------|---------|---------|
| **并发基础** | pthread_create, pthread_mutex | 线程创建和同步 |
| **条件变量** | pthread_cond_timedwait | 带超时的等待 |
| **函数指针** | 函数指针表（vtable模拟） | 策略模式多态 |
| **时间操作** | clock_gettime, nanosleep | 精确计时 |
| **内存管理** | malloc, free | 动态分配策略对象 |
| **随机数** | rand_r | 随机间隔策略 |

**对比C++**：C++使用`std::function`存储可调用对象，`std::unique_ptr<IPollingStrategy>`实现策略模式。C语言使用函数指针表（手动vtable）模拟虚函数。

### 1.5 核心组件说明

- **PollingStrategy**：轮询策略接口（函数指针表，对应C++抽象基类`IPollingStrategy`）
- **FixedIntervalStrategy**：固定间隔策略（对应C++子类）
- **ExponentialBackoffStrategy**：指数退避策略
- **RandomIntervalStrategy**：随机间隔策略
- **TaskResult**：任务结果结构（对应C++结构体）
- **TaskStatistics**：任务统计系统（对应C++类）
- **Poller**：轮询器核心（对应C++的Poller类）

### 1.6 功能丰富

1. 轮询间隔策略：固定间隔、指数退避、随机间隔等
2. 统计信息：记录任务执行次数、成功次数、失败次数等
3. 暂停/继续：运行时可以暂停和恢复轮询

### 1.7 轮训工作流程

1. 启动后，在轮询线程中循环，直到停止
2. 每次循环开始，检查状态：如果暂停，则等待条件变量；如果停止，则退出
3. 计算下一次轮询需要等待的时间（根据策略）
4. 等待这段时间（使用条件变量等待，可以在暂停或停止时被唤醒）
5. 等待结束后，如果状态是运行，则执行任务
6. 根据任务执行结果，可能调整轮询间隔

```c
// 时间转换为纳秒（对应C++ TimeConverter::toNanoseconds）
long time_to_nanoseconds(long duration, TimeUnit unit) {
    switch (unit) {
        case TIME_NANOSECONDS:  return duration;
        case TIME_MICROSECONDS: return duration * 1000L;
        case TIME_MILLISECONDS: return duration * 1000000L;
        case TIME_SECONDS:      return duration * 1000000000L;
        case TIME_MINUTES:      return duration * 60000000000L;
        default: return duration;
    }
}
```

## 04.轮询策略接口设计

### 4.1 策略接口分析

C++使用抽象基类`IPollingStrategy`和虚函数实现策略模式。C语言没有类和虚函数，使用**函数指针表（vtable）**模拟多态。

核心思路：定义一个结构体，其中包含一组函数指针，每个具体策略实现自己的函数，然后将函数指针赋值给结构体。

### 4.2 轮询策略接口

```c
// 轮询策略接口（函数指针表，对应C++ IPollingStrategy抽象类）
typedef struct PollingStrategy PollingStrategy;

struct PollingStrategy {
    // 获取下一次轮询间隔（纳秒）（对应C++纯虚函数 getNextInterval）
    long (*getNextInterval)(PollingStrategy *self);
    // 重置策略状态（对应C++ reset）
    void (*reset)(PollingStrategy *self);
    // 记录任务成功（对应C++ recordSuccess）
    void (*recordSuccess)(PollingStrategy *self);
    // 记录任务失败（对应C++ recordFailure）
    void (*recordFailure)(PollingStrategy *self);
    // 获取策略配置信息（对应C++ getConfigInfo）
    void (*getConfigInfo)(const PollingStrategy *self, char *buf, int bufSize);
    // 销毁策略（对应C++虚析构函数）
    void (*destroy)(PollingStrategy *self);
    // 策略私有数据（通过void*实现泛型）
    void *data;
};
```

**对比C++**：
- C++的`virtual ~IPollingStrategy() {}`虚析构函数确保派生类正确析构，C语言用`destroy`函数指针手动调用
- C++的纯虚函数`= 0`在C语言中是函数指针，如果未赋值则为NULL
- C++的`this`指针隐式传递，C语言需要显式传递`self`指针
- C++继承关系在编译时确定，C语言的函数指针在运行时绑定

### 4.3 改进建议

1. 线程安全：如果策略在多线程环境中使用，需要加锁保护策略内部状态
2. 扩展性：可以通过添加更多函数指针来增强策略的灵活性
3. 日志记录：可以在策略中添加日志记录功能

## 05.具体策略实现

### 5.1 固定间隔策略

```c
// 固定间隔策略私有数据
typedef struct {
    long interval_ns;
} FixedIntervalData;

// 固定间隔 - 获取下一次间隔
long fixed_get_interval(PollingStrategy *self) {
    FixedIntervalData *d = (FixedIntervalData*)self->data;
    return d->interval_ns;
}

void fixed_reset(PollingStrategy *self) { /* 固定间隔无需重置 */ }
void fixed_record_success(PollingStrategy *self) { /* 无操作 */ }
void fixed_record_failure(PollingStrategy *self) { /* 无操作 */ }

void fixed_get_config(const PollingStrategy *self, char *buf, int bufSize) {
    FixedIntervalData *d = (FixedIntervalData*)self->data;
    snprintf(buf, bufSize, "FixedInterval: %ld ns", d->interval_ns);
}

void fixed_destroy(PollingStrategy *self) {
    free(self->data);
    self->data = NULL;
}

// 创建固定间隔策略（对应C++构造函数）
PollingStrategy* strategy_create_fixed(long interval, TimeUnit unit) {
    PollingStrategy *s = (PollingStrategy*)malloc(sizeof(PollingStrategy));
    FixedIntervalData *d = (FixedIntervalData*)malloc(sizeof(FixedIntervalData));
    d->interval_ns = time_to_nanoseconds(interval, unit);
    s->data = d;
    s->getNextInterval = fixed_get_interval;
    s->reset = fixed_reset;
    s->recordSuccess = fixed_record_success;
    s->recordFailure = fixed_record_failure;
    s->getConfigInfo = fixed_get_config;
    s->destroy = fixed_destroy;
    return s;
}
```

**对比C++**：C++的`FixedIntervalStrategy`通过继承`IPollingStrategy`并重写虚函数实现。C语言通过创建`PollingStrategy`结构体并赋值函数指针实现同样的多态效果，这实际上就是手动实现了C++编译器自动生成的vtable机制。

测试效果：

```c
PollingStrategy *strategy = strategy_create_fixed(1000, TIME_MILLISECONDS);
char info[128];
strategy->getConfigInfo(strategy, info, sizeof(info));
printf("Config: %s\n", info);
printf("Next interval: %ld ns\n", strategy->getNextInterval(strategy));
strategy->destroy(strategy);
free(strategy);
```

### 5.2 指数退避策略

```c
// 指数退避策略私有数据
typedef struct {
    long initial_ns;
    long max_ns;
    long current_ns;
} ExponentialBackoffData;

long exponential_get_interval(PollingStrategy *self) {
    ExponentialBackoffData *d = (ExponentialBackoffData*)self->data;
    long result = d->current_ns;
    // 间隔翻倍，不超过最大值
    long next = d->current_ns * 2;
    d->current_ns = (next < d->max_ns) ? next : d->max_ns;
    return result;
}

void exponential_reset(PollingStrategy *self) {
    ExponentialBackoffData *d = (ExponentialBackoffData*)self->data;
    d->current_ns = d->initial_ns;
}

void exponential_record_success(PollingStrategy *self) {
    exponential_reset(self); // 成功则重置
}

void exponential_record_failure(PollingStrategy *self) { /* 失败不操作，getNextInterval已翻倍 */ }

void exponential_get_config(const PollingStrategy *self, char *buf, int bufSize) {
    ExponentialBackoffData *d = (ExponentialBackoffData*)self->data;
    snprintf(buf, bufSize, "ExponentialBackoff: Initial=%ld ns, Max=%ld ns",
             d->initial_ns, d->max_ns);
}

void exponential_destroy(PollingStrategy *self) {
    free(self->data);
    self->data = NULL;
}

// 创建指数退避策略
PollingStrategy* strategy_create_exponential(long initial, long max, TimeUnit unit) {
    PollingStrategy *s = (PollingStrategy*)malloc(sizeof(PollingStrategy));
    ExponentialBackoffData *d = (ExponentialBackoffData*)malloc(sizeof(ExponentialBackoffData));
    d->initial_ns = time_to_nanoseconds(initial, unit);
    d->max_ns = time_to_nanoseconds(max, unit);
    d->current_ns = d->initial_ns;
    s->data = d;
    s->getNextInterval = exponential_get_interval;
    s->reset = exponential_reset;
    s->recordSuccess = exponential_record_success;
    s->recordFailure = exponential_record_failure;
    s->getConfigInfo = exponential_get_config;
    s->destroy = exponential_destroy;
    return s;
}
```

### 5.3 随机间隔策略

```c
// 随机间隔策略私有数据
typedef struct {
    long min_ns;
    long max_ns;
    unsigned int seed;
} RandomIntervalData;

long random_get_interval(PollingStrategy *self) {
    RandomIntervalData *d = (RandomIntervalData*)self->data;
    // 生成 [min_ns, max_ns] 范围的随机数
    long range = d->max_ns - d->min_ns;
    if (range <= 0) return d->min_ns;
    return d->min_ns + (rand_r(&d->seed) % range);
}

void random_reset(PollingStrategy *self) { /* 无需重置 */ }
void random_record_success(PollingStrategy *self) { /* 无操作 */ }
void random_record_failure(PollingStrategy *self) { /* 无操作 */ }

void random_get_config(const PollingStrategy *self, char *buf, int bufSize) {
    RandomIntervalData *d = (RandomIntervalData*)self->data;
    snprintf(buf, bufSize, "RandomInterval: Min=%ld ns, Max=%ld ns", d->min_ns, d->max_ns);
}

void random_destroy(PollingStrategy *self) {
    free(self->data);
    self->data = NULL;
}

// 创建随机间隔策略
PollingStrategy* strategy_create_random(long min, long max, TimeUnit unit) {
    PollingStrategy *s = (PollingStrategy*)malloc(sizeof(PollingStrategy));
    RandomIntervalData *d = (RandomIntervalData*)malloc(sizeof(RandomIntervalData));
    d->min_ns = time_to_nanoseconds(min, unit);
    d->max_ns = time_to_nanoseconds(max, unit);
    d->seed = (unsigned int)time(NULL);
    s->data = d;
    s->getNextInterval = random_get_interval;
    s->reset = random_reset;
    s->recordSuccess = random_record_success;
    s->recordFailure = random_record_failure;
    s->getConfigInfo = random_get_config;
    s->destroy = random_destroy;
    return s;
}
```

**对比C++**：C++的`std::default_random_engine`和`std::uniform_int_distribution`提供了高质量随机数。C语言的`rand_r`质量较低但足够用于模拟。C++使用`std::random_device()`获取种子，C语言使用`time(NULL)`。

## 06.任务结果与统计

### 6.1 任务结果结构

```c
// 任务结果结构（对应C++ TaskResult）
typedef struct {
    int success;            // 0=失败, 1=成功
    char message[256];      // 结果描述
    time_t timestamp;       // 时间戳
} TaskResult;

// 创建任务结果
TaskResult task_result_create(int success, const char *message) {
    TaskResult result;
    result.success = success;
    strncpy(result.message, message, sizeof(result.message) - 1);
    result.message[sizeof(result.message) - 1] = '\0';
    result.timestamp = time(NULL);
    return result;
}
```

**对比C++**：C++使用`std::chrono::steady_clock::time_point`精确到纳秒，C语言使用`time_t`精确到秒。C++的`std::string`自动管理内存，C语言使用固定大小字符数组。

### 6.2 任务统计系统

```c
// 最近结果队列大小
#define MAX_RECENT_RESULTS 100

typedef struct {
    int total;
    int success;
    int failure;
    TaskResult recentResults[MAX_RECENT_RESULTS];
    int recentCount;
    int recentHead;     // 环形缓冲区头指针
} TaskStatistics;

// 初始化统计
void stats_init(TaskStatistics *stats) {
    stats->total = 0;
    stats->success = 0;
    stats->failure = 0;
    stats->recentCount = 0;
    stats->recentHead = 0;
}
```

**对比C++**：C++使用`std::deque<TaskResult>`动态容器，C语言使用固定大小数组作为环形缓冲区（ring buffer）。

### 6.3 记录任务结果

```c
void stats_record(TaskStatistics *stats, const TaskResult *result) {
    stats->total++;
    if (result->success) {
        stats->success++;
    } else {
        stats->failure++;
    }
    // 环形缓冲区存储最近结果（对应C++ deque的push_back + pop_front）
    int index = stats->recentHead;
    stats->recentResults[index] = *result;
    stats->recentHead = (stats->recentHead + 1) % MAX_RECENT_RESULTS;
    if (stats->recentCount < MAX_RECENT_RESULTS) {
        stats->recentCount++;
    }
}
```

### 6.4 打印统计摘要

```c
void stats_print_summary(const TaskStatistics *stats) {
    printf("=== Task Statistics ===\n");
    printf("Total runs: %d\n", stats->total);
    printf("Success: %d (%.1f%%)\n", stats->success,
           stats->total ? (stats->success * 100.0 / stats->total) : 0.0);
    printf("Failure: %d (%.1f%%)\n", stats->failure,
           stats->total ? (stats->failure * 100.0 / stats->total) : 0.0);
    if (stats->recentCount > 0) {
        printf("\nRecent results (last %d):\n", stats->recentCount);
        for (int i = 0; i < stats->recentCount; i++) {
            int idx = (stats->recentHead - stats->recentCount + i + MAX_RECENT_RESULTS) % MAX_RECENT_RESULTS;
            const TaskResult *res = &stats->recentResults[idx];
            char timeStr[32];
            struct tm *tm_info = localtime(&res->timestamp);
            strftime(timeStr, sizeof(timeStr), "%H:%M:%S", tm_info);
            printf("[%s] %s: %s\n", timeStr,
                   res->success ? "SUCCESS" : "FAILURE", res->message);
        }
    }
}
```

**对比C++**：C++使用`std::chrono`和`std::setfill`/`std::setw`格式化时间，C语言使用`strftime`格式化。

## 07.轮询器核心实现

### 7.1 轮询器核心结构

```c
// 任务函数类型定义（对应C++ std::function<TaskResult()>）
typedef TaskResult (*ActionFunc)(void);

// 轮询器结构体（对应C++ Poller类）
typedef struct {
    PollingStrategy *strategy;      // 轮询策略（对应C++ std::unique_ptr<IPollingStrategy>）
    ActionFunc action;              // 任务函数（对应C++ ActionFunc）
    volatile int running;           // 运行标志（对应C++ std::atomic<bool>）
    int paused;                     // 暂停标志
    pthread_t workerThread;         // 工作线程（对应C++ std::thread）
    pthread_mutex_t mutex;          // 互斥锁
    pthread_cond_t cond;            // 条件变量
    long taskTimeoutNs;             // 任务超时（纳秒）
    TaskStatistics stats;           // 统计信息
} Poller;

// 初始化轮询器（对应C++构造函数）
void poller_init(Poller *poller, PollingStrategy *strategy, ActionFunc action) {
    poller->strategy = strategy;
    poller->action = action;
    poller->running = 0;
    poller->paused = 0;
    poller->taskTimeoutNs = 0;
    pthread_mutex_init(&poller->mutex, NULL);
    pthread_cond_init(&poller->cond, NULL);
    stats_init(&poller->stats);
}

// 销毁轮询器
void poller_destroy(Poller *poller) {
    pthread_mutex_destroy(&poller->mutex);
    pthread_cond_destroy(&poller->cond);
    // 不销毁strategy，由调用者负责
}
```

**对比C++**：C++的`Poller`构造函数使用`std::move`转移策略所有权，C语言使用裸指针，需要调用者管理生命周期。

轮询线程主循环核心逻辑：

```c
// 执行任务（带超时支持）
typedef struct {
    ActionFunc action;
    TaskResult result;
    int done;
    pthread_mutex_t doneMutex;
    pthread_cond_t doneCond;
} TaskExecutor;

void* task_executor_func(void *arg) {
    TaskExecutor *exec = (TaskExecutor*)arg;
    exec->result = exec->action();
    pthread_mutex_lock(&exec->doneMutex);
    exec->done = 1;
    pthread_cond_signal(&exec->doneCond);
    pthread_mutex_unlock(&exec->doneMutex);
    return NULL;
}

// 执行动作（对应C++ Poller::executeAction）
void poller_execute_action(Poller *poller) {
    TaskResult result = task_result_create(0, "Unknown result");
    if (poller->taskTimeoutNs > 0) {
        // 带超时的任务执行（对应C++ std::async + future.wait_for）
        TaskExecutor exec;
        exec.action = poller->action;
        exec.done = 0;
        pthread_mutex_init(&exec.doneMutex, NULL);
        pthread_cond_init(&exec.doneCond, NULL);
        pthread_t taskThread;
        pthread_create(&taskThread, NULL, task_executor_func, &exec);
        // 等待超时
        struct timespec ts;
        clock_gettime(CLOCK_REALTIME, &ts);
        long sec = poller->taskTimeoutNs / 1000000000L;
        long nsec = poller->taskTimeoutNs % 1000000000L;
        ts.tv_sec += sec;
        ts.tv_nsec += nsec;
        if (ts.tv_nsec >= 1000000000L) {
            ts.tv_sec += 1;
            ts.tv_nsec -= 1000000000L;
        }
        pthread_mutex_lock(&exec.doneMutex);
        int timedout = 0;
        while (!exec.done) {
            int rc = pthread_cond_timedwait(&exec.doneCond, &exec.doneMutex, &ts);
            if (rc == ETIMEDOUT) {
                timedout = 1;
                break;
            }
        }
        pthread_mutex_unlock(&exec.doneMutex);
        if (timedout) {
            result = task_result_create(0, "Task timed out");
            pthread_detach(taskThread); // 超时后分离线程
        } else {
            result = exec.result;
            pthread_join(taskThread, NULL);
        }
        pthread_mutex_destroy(&exec.doneMutex);
        pthread_cond_destroy(&exec.doneCond);
    } else {
        // 不带超时的任务执行
        result = poller->action();
    }
    // 记录结果并更新策略
    pthread_mutex_lock(&poller->mutex);
    if (result.success) {
        poller->strategy->recordSuccess(poller->strategy);
    } else {
        poller->strategy->recordFailure(poller->strategy);
    }
    stats_record(&poller->stats, &result);
    pthread_mutex_unlock(&poller->mutex);
    printf("Action executed. Result: %s - %s\n",
           result.success ? "SUCCESS" : "FAILURE", result.message);
}
```

**对比C++**：
- C++使用`std::async(std::launch::async, action_)`创建异步任务，返回`std::future`
- C++使用`future.wait_for(timeout)`等待超时
- C语言需要手动创建线程 + 条件变量 + `pthread_cond_timedwait`实现超时等待
- C语言的实现代码量约多一倍，但逻辑完全等价

### 7.2 启动轮询器

```c
// 轮询线程主循环（对应C++ Poller::run）
void* poller_run(void *arg) {
    Poller *poller = (Poller*)arg;
    while (poller->running) {
        long nextInterval = 0;
        pthread_mutex_lock(&poller->mutex);
        // 计算下一次执行间隔
        nextInterval = poller->strategy->getNextInterval(poller->strategy);
        // 等待间隔时间或被唤醒
        struct timespec ts;
        clock_gettime(CLOCK_REALTIME, &ts);
        long sec = nextInterval / 1000000000L;
        long nsec = nextInterval % 1000000000L;
        ts.tv_sec += sec;
        ts.tv_nsec += nsec;
        if (ts.tv_nsec >= 1000000000L) {
            ts.tv_sec += 1;
            ts.tv_nsec -= 1000000000L;
        }
        // 等待条件：到达间隔时间 或 被唤醒（暂停/停止）
        while (poller->running && !poller->paused) {
            int rc = pthread_cond_timedwait(&poller->cond, &poller->mutex, &ts);
            if (rc == ETIMEDOUT) break; // 到达等待时间
            // 被唤醒，检查状态
        }
        // 检查是否暂停
        if (poller->paused) {
            while (poller->paused && poller->running) {
                pthread_cond_wait(&poller->cond, &poller->mutex);
            }
            pthread_mutex_unlock(&poller->mutex);
            continue;
        }
        // 检查是否停止
        if (!poller->running) {
            pthread_mutex_unlock(&poller->mutex);
            break;
        }
        pthread_mutex_unlock(&poller->mutex);
        // 执行任务
        poller_execute_action(poller);
    }
    return NULL;
}

// 启动轮询器（对应C++ Poller::start）
void poller_start(Poller *poller) {
    if (poller->running) return;
    poller->running = 1;
    pthread_create(&poller->workerThread, NULL, poller_run, poller);
    char info[128];
    poller->strategy->getConfigInfo(poller->strategy, info, sizeof(info));
    printf("Poller started with strategy: %s\n", info);
}
```

## 09.核心组件说明

### 9.1 时间系统

支持多种时间单位（纳秒到分钟），提供精确的时间转换工具。

C语言使用`clock_gettime(CLOCK_REALTIME, &ts)`获取当前时间，`pthread_cond_timedwait`实现带超时的等待。

**对比C++**：C++使用`std::chrono::steady_clock`（单调时钟，不受系统时间调整影响），C语言的`CLOCK_REALTIME`可能受系统时间调整影响，更严谨的实现应使用`CLOCK_MONOTONIC`。

### 9.2 轮询策略系统

通过函数指针表（vtable）实现策略模式多态：

- `PollingStrategy`结构体包含一组函数指针，模拟C++的虚函数表
- 每种具体策略创建时填充对应的函数指针
- 调用时通过函数指针间接调用，实现运行时多态

### 9.3 任务统计系统

使用固定大小数组作为环形缓冲区，替代C++的`std::deque`。环形缓冲区是C语言中常用的数据结构，可以在固定内存空间中实现FIFO队列。

### 9.4 核心轮询器功能

轮询器支持以下操作：启动、停止、暂停、继续、更新策略、手动触发、超时设置、统计打印。

所有操作都是线程安全的，使用互斥锁和条件变量保护共享状态。

## 10.对比C++实现

### 10.1 整体架构对比

| 架构层面 | C语言 | C++ |
|---------|------|-----|
| **代码组织** | 头文件 + 源文件 + 前缀命名 | 命名空间 + 头文件 |
| **多态机制** | 函数指针表（手动vtable） | 虚函数（编译器vtable） |
| **策略接口** | 结构体 + 函数指针 | 抽象基类 + 纯虚函数 |
| **数据封装** | 结构体 + `void*` 私有数据 | 类 + private成员 |
| **生命周期** | init/destroy函数对 | 构造/析构函数（RAII） |

### 10.2 多态实现对比

C++虚函数方式：
```cpp
class IPollingStrategy {
    virtual long getNextInterval() = 0;
    virtual ~IPollingStrategy() {}
};
class FixedIntervalStrategy : public IPollingStrategy {
    long getNextInterval() override { return interval_ns; }
};
// 使用：strategy->getNextInterval()
```

C语言函数指针方式：
```c
struct PollingStrategy {
    long (*getNextInterval)(PollingStrategy *self);
    void (*destroy)(PollingStrategy *self);
    void *data;
};
// 使用：strategy->getNextInterval(strategy)
```

核心区别：C++的`this`指针隐式传递，C语言必须显式传递`self`。C++编译器自动维护vtable，C语言需要手动填充函数指针。

### 10.3 资源管理对比

C++使用RAII和智能指针：
```cpp
std::unique_ptr<IPollingStrategy> strategy_;
// 析构时自动释放
```

C语言需要手动管理：
```c
PollingStrategy *strategy;
// 使用后必须手动释放
strategy->destroy(strategy);
free(strategy);
```

### 10.4 对比C++总结

| 对比维度 | C语言实现 | C++实现 |
|---------|----------|---------|
| **策略模式** | 函数指针表 + `void*`数据 | 抽象基类 + 继承 |
| **虚函数** | 手动函数指针赋值 | 编译器自动vtable |
| **析构函数** | `destroy`函数指针 | `virtual ~Base()` |
| **智能指针** | 无，手动malloc/free | `std::unique_ptr` |
| **条件等待** | `pthread_cond_timedwait` + 手动计算时间 | `cond.wait_until(lock, time_point)` |
| **异步执行** | `pthread_create` + 手动超时 | `std::async` + `future.wait_for` |
| **函数对象** | 函数指针（无闭包） | `std::function` + lambda |
| **时间精度** | `clock_gettime` + `timespec` | `std::chrono` |
| **线程控制** | `pthread_mutex/cond` 手动管理 | `std::mutex/condition_variable` RAII |
| **随机数** | `rand_r` | `std::mt19937` + 分布 |
| **配置信息** | `snprintf`到固定缓冲区 | `std::ostringstream` |
| **命名空间** | 无（用前缀区分） | `namespace` |
| **代码量** | 约多40-60% | 更简洁 |
| **安全性** | 容易遗漏free/unlock | RAII自动管理 |
