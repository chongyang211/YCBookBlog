# cgo与系统调用切换

> cgo 与 syscall 是"Go 协程"与"操作系统线程"的两个交界面。任何阻塞 syscall 都会让 P 与 M 解绑、进而触发新 M 的创建；任何 cgo 调用都会切换到系统栈、并暂时退出 GMP 调度。本篇拆 `entersyscall`/`exitsyscall`、cgo 的栈切换、`runtime.LockOSThread`，并讲清线上常见的"cgo 卡死 / P 耗尽"故障的根因。
> 关键词：`entersyscall` / `exitsyscall` / `entersyscallblock`、cgo 栈切换、g0 栈、`runtime.LockOSThread`、P 解绑、新建 M、cgo 性能开销、信号处理
