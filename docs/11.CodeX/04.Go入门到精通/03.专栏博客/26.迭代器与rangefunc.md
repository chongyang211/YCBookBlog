# 迭代器与rangefunc

> Go 1.22 实验、Go 1.23 稳定的迭代器（`range over func`）是 Go 现代化的两大里程碑之一（另一个是泛型）。本篇讲清 `iter.Seq` / `iter.Seq2` / `iter.Pull` 协议、编译器如何把 `for k, v := range f` 改写为 yield 调用、以及它和 Python/Rust/JS 迭代器的差异。
> 关键词：`iter.Seq[T]`、`iter.Seq2[K,V]`、`iter.Pull`、yield 函数、编译器改写、协程式迭代器、与 Python `__iter__` / Rust `Iterator` / JS Generator 对比
