# errgroup并行控制

golang.org/x/sync/errgroup 并行任务组、错误传播机制、WithContext 取消传播、SetLimit 限并发、与 WaitGroup 对比。

```go
g, ctx := errgroup.WithContext(ctx)
g.Go(func() error { return doWork(ctx) })
g.Wait()
```
