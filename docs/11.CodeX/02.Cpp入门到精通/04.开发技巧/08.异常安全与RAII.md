# 第29章：异常安全与 RAII

## 问题现场

```cpp
void bad_copy() {
    auto* a = new ResourceA();
    auto* b = new ResourceB();  // 如果这里抛异常 → a 泄漏！
    delete b;
    delete a;
}
```

## 根因

C++ 析构函数只在对象生命周期结束时自动调用。裸指针 = 手动管理 = 异常时跳过 delete。

## 异常安全三等级

| 等级 | 含义 | 例子 |
|------|------|------|
| **基本保证** | 不泄漏、状态可析构 | 至少不崩 |
| **强保证** | 要么全做，要么全不做（回滚） | 事务式 |
| **不抛保证** | 绝对不会抛异常 | `noexcept` 标记 |

## 方案对比

| 方案 | 写法 | 等级 | 适用 |
|------|------|------|------|
| RAII | `unique_ptr` 管理资源 | 基本 | 所有资源 |
| Copy-and-Swap | `*this = T(temp)` | 强 | 赋值运算符 |
| Scope Guard | `auto g = finally([&]{cleanup();});` | 基本 | 非资源清理 |
| noexcept | `void f() noexcept` | 不抛 | move/swap/dtor |

```cpp
// ✅ RAII：任何退出路径都自动调析构
void good() {
    auto a = std::make_unique<ResourceA>();
    auto b = std::make_unique<ResourceB>();
    // 即使抛异常，a 和 b 的析构函数都会跑
}
```

## 精简版速查

> **口诀**：所有资源进 `unique_ptr`/`shared_ptr`，析构函数自动保证不泄漏。赋值运算用 Copy-and-Swap。

```cpp
// 资源管理万能公式
auto resource = std::make_unique<T>(args);  // 永不手动 delete
```
