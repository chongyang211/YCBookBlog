# 第21章：ASan 内存三件套

## 问题现场

```cpp
int* p = new int[10];
delete p;  // ❌ 应该 delete[] —— 泄漏 + 未定义行为
p[5] = 42; // ❌ use-after-free
```

普通运行啥都不报，ASan 直接告诉你哪一行、什么错。

## 三种 Sanitizer 一句话

| Sanitizer | 编译选项 | 检测什么 |
|-----------|---------|---------|
| **AddressSanitizer** | `-fsanitize=address` | 越界、use-after-free、double-free、栈溢出 |
| **UndefinedBehavior** | `-fsanitize=undefined` | 除0、null解引用、有符号溢出、类型转换 |
| **ThreadSanitizer** | `-fsanitize=thread` | 数据竞争（data race） |

## ASan 输出解读

```bash
$ g++ -g -fsanitize=address a.cpp && ./a.out
# ==============================================================
# ==12345==ERROR: AddressSanitizer: heap-use-after-free
# READ of size 4 at 0x60400000eff0 thread T0
#     #0 0x4a2b5e in main a.cpp:5    ← ⭐ 直接指出 a.cpp 第5行
# 0x60400000eff0 is located 0 bytes inside of 40-byte region
# freed by thread T0 here:
#     #0 0x4a2a1c in operator delete(void*) 
#     #1 0x4a2b2a in main a.cpp:3     ← 在哪 free 的
```

## 方案对比

| 问题 | 工具 | 命令 |
|------|------|------|
| 越界读写 | ASan | `-fsanitize=address` |
| 泄漏检测 | LSan(ASan内置) | `ASAN_OPTIONS=detect_leaks=1` |
| 数据竞争 | TSan | `-fsanitize=thread` |
| 未定义行为 | UBSan | `-fsanitize=undefined` |
| 内存统计 | ASan | `ASAN_OPTIONS=verbosity=1` |

## 精简版速查

> **口诀**：编译加 `-g -fsanitize=address`，运行就能看到出错文件名+行号。

```bash
g++ -g -fsanitize=address,undefined -o a.out a.cpp && ./a.out
# 输出直接告诉你：什么错，哪个文件第几行
```
