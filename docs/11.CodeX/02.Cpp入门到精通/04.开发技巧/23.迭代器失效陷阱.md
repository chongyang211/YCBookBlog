# 第27章：迭代器失效陷阱

## 问题现场

```cpp
std::vector<int> v = {1, 2, 3, 2, 5};
for (auto it = v.begin(); it != v.end(); ++it) {
    if (*it == 2) v.erase(it);  // ❌ it 失效，++it → 未定义行为
}
```

## 根因

C++ 容器操作会让某些迭代器失效——继续使用 = 野指针。这是 C++ 区别于 GC 语言的核心痛点。

## 失效矩阵

| 容器 | 操作 | 失效范围 |
|------|------|---------|
| `vector/deque` | `push_back` 触发扩容 | **全部** |
| `vector/deque` | `erase`/`pop_back` | 删除点**及之后** |
| `list/map/set` | `erase` | **仅被删元素** |
| `unordered_map` | `insert` 触发 rehash | **全部** |

## 方案对比

| 方案 | 写法 | 复杂度 | 适用 |
|------|------|--------|------|
| **erase返回值** | `it = v.erase(it); else ++it;` | O(n) | 首选 |
| **索引回避** | 从后往前删 `for (int i=n-1;i>=0;--i)` | O(n²) | vector小数据 |
| **remove_if** | `auto e=remove_if(..); v.erase(e,v.end());` | O(n) | 批量删除 |
| **erase_if(C++20)** | `std::erase_if(v, pred);` | O(n) | 最简 |

## 精简版速查

> **口诀**：`it = c.erase(it)` 否则 `++it`；vector 扩容全废，提前 `reserve`。

```cpp
// ✅ 万能安全写法
for (auto it = c.begin(); it != c.end(); ) {
    if (should_remove(*it)) it = c.erase(it);
    else ++it;
}
```
