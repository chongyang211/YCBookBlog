# 第24章：perf 火焰图实战

## 问题现场

"这个服务 CPU 100%，但不知道哪个函数吃的。"——top 只能看进程，看不到函数。

## 根因

Linux `perf` 是内核级的性能分析器，能采样到每个函数的 CPU 占用。配合火焰图工具，一眼找到热点。

## perf 三步法

```bash
# 1. 采样 30 秒（-F 99 = 每秒采样 99 次，够准不过载）
sudo perf record -F 99 -p $(pidof myapp) -g -- sleep 30
# 输出：perf.data（二进制采样数据）

# 2. 生成火焰图
git clone https://github.com/brendangregg/FlameGraph
sudo perf script | ./FlameGraph/stackcollapse-perf.pl | ./FlameGraph/flamegraph.pl > flame.svg

# 3. 浏览器打开 flame.svg → 横向宽度 = CPU 占比，纵向 = 调用深度
```

## 直接看文本报告（不需要火焰图）

```bash
# 最简版：看哪个函数 CPU 最高
sudo perf top -p $(pidof myapp)

# 事后分析版
sudo perf report -i perf.data --stdio | head -20
```

## 方案对比

| 方案 | 工具 | 精度 | 适用 |
|------|------|------|------|
| 查看热点函数 | `perf top -p` | 实时 | 正在线上跑的服务 |
| 事后分析 | `perf record` + `perf report` | 事后 | 离线分析 |
| 可视化 | `perf script` + FlameGraph | 视觉 | 向别人展示 |
| 无 root 权限 | `perf stat` 计数器 | 统计值 | 受限环境 |

## 精简版速查

> **口诀**：`perf top -p pid` 看实时，`perf record` + 火焰图看全貌。

```bash
sudo perf top -p $(pidof myapp)   # 一行看 CPU 热点
sudo perf record -F 99 -p $(pidof myapp) -g -- sleep 30  # 抓30秒
```
