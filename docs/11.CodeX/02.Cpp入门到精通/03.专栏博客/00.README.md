## 📐 设计理念

C++ 与 Java 最大的不同在于：**它没有虚拟机这一层抽象**——直接面对编译器、链接器、CPU 缓存、操作系统内存。所以本专栏的纵深顺着这条路径展开：

> **预处理 → 编译 → 链接 → 运行时 → 操作系统 → 硬件**

每一层都有 C++ 独有的"刀尖在跳舞"的设计。
