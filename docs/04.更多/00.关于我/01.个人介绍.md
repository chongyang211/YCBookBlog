# 个人介绍

我是杨充，一名全栈工程师，也是一名持续写作者。

## 技术之路

十年开发历程，技术栈覆盖 **Android / iOS / C++ / Java / Go / Python / Web 前端** 全链路。从移动端起步，逐步深入到操作系统底层、编译原理、网络协议、CPU 体系结构。始终相信：**"工程师的深度，体现在对底层原理的理解上。"**

目前在 Android 进阶、C++ 从入门到工程精通、性能优化等领域持续深耕，正在筹备《现代 C++ 由浅入深：从入门到工程精通》四卷本的出版。

## 写作之路

编程之外，写作是我最大的兴趣。

**技术写作**：2019 年创建个人博客 **yccoding.com（编程进阶网）**，累计输出 300+ 篇技术文章，涵盖移动开发、C/C++、后端架构、Linux 系统编程、设计模式、性能优化等方向。2024 年起，将博客内容系统化整合为面向出版的技术书籍。

**小说创作**：笔名「糖果拾光」，已创作 20+ 部中长篇小说。写作方法论是对经典的"中国化仿写"——参考世界经典电影/名著的叙事结构和人物弧线，移植到当代中国语境中讲出新故事。如参考《三傻大闹宝莱坞》写《云工大三人行》，参考《看不见的客人》写《书房里的谎言》。

**自媒体内容**：在视频/音频/图文平台运营多个"糖果"系列账号，包括电影解说（糖果电影、糖果说剧）、历史解读（糖果说史）、职场思考（糖心职商）、生活感悟（糖果萌叔）、有声书（糖果说书）。

## 学习理念

- **终身学习**：技术迭代再快，底层知识和认知框架永远保值。
- **输出倒逼输入**：写技术文章和小说，是对知识最彻底的检验。
- **跨界思考**：编程的结构思维对写作有帮助，写作的叙事能力对表达技术方案也很有帮助——两者互相滋养。

## 关于本站

编程进阶网（yccoding.com）汇聚了我十年的技术积累，希望这些内容能为你的技术成长提供一份参考。博客持续更新中，欢迎常来。
