# 博客建站演变史

编程进阶网（yccoding.com）从 2019 年至今的演进。

## 2019 · 起步

离开 CSDN 等平台，搭建独立博客。

- **选型**：VuePress 1.x + vuepress-theme-vdoing
- **内容**：Android 进阶、Java 并发、C++ 基础，约 100 篇
- **部署**：GitHub Pages 免费托管

## 2021-2023 · 成型

- **迁移**：VuePress 2.x + vuepress-theme-vdoing，更好的构建性能与现代 UI
- **域名**：购买 yccoding.com，从 GitHub Pages 迁至 Vercel，国内访问提速
- **CI/CD**：GitHub Actions 自动构建部署，push 即上线
- **SEO**：百度主动推送 + sitemap + 结构化数据
- **内容扩展**：新增 C++ 入门到精通、Linux 系统编程、性能优化专栏，300+ 篇

## 2024-至今 · 深度化

- **书籍化重构**：将 C++ 系列 90+ 篇重新编排为四卷本结构，每篇从数百字扩至 2000+ 行完整章节（案例引入 → 原理剖析 → 工程实践 → 思考题）
- **嵌入式方向**：新增 Linux QML/Qt 应用开发专栏，覆盖 Scene Graph 渲染管线、EGLFS 嵌入式后端、交叉编译部署
- **工具链**：添加 18+ 在线开发工具（JSON / 加解密 / 二维码 / 颜色设计等），全部浏览器端运算
- **性能优化**：首页全静态化渲染，关闭 SSR，`content-visibility` 优化，滚动零 JS 开销

## 建设中的内容

- C++ 四卷本出版准备（《现代 C++ 由浅入深：从入门到工程精通》）
- Linux QML 嵌入式 GUI 应用开发的更多实践案例
- 专栏系列（编程原理 / 性能优化 / 方案设计）的持续深挖
