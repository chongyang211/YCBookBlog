# 开源作品

GitHub：[https://github.com/yangchong211](https://github.com/yangchong211)

## Android 组件库

长期维护的 Android 高频场景组件化方案：

| 组件 | 场景 | 核心能力 |
| ---- | ---- | -------- |
| 视频播放器 | 短视频 / 长视频播放 | 内核切换（IJK / ExoPlayer），手势控制，全屏适配，缓存预加载 |
| 图片选择器 | 相册多选 / 拍照 / 裁剪 | 大图加载优化，权限适配，多主题支持 |
| 状态栏管理 | 沉浸式 / 变色 / 透明 | 兼容 Android 4.4 ~ 14，适配刘海屏 |
| 权限申请 | 动态权限 | 链式调用，拒绝后引导设置页 |
| 工具库 | 通用工具 | App 信息、文件、网络、加解密、SP 封装 |

- 结构化侧边栏（`structuring` 模式）
