# 技术背景与理念

杨充，全栈工程师，编程进阶网（yccoding.com）作者。

## 技术背景

十年开发经验，技术栈覆盖 **C/C++ / Java / Go / Python / JavaScript / TypeScript**，主攻方向：

- **C++ 工程实战**：现代 C++11/14/17/20 全线贯通，并发编程（`std::thread` / `std::jthread` / `shared_mutex`）、STL 源码剖析、编译期优化（`consteval` / `constexpr`）、性能调优（perf / VTune / ASan）
- **Android 性能优化**：启动优化、内存泄漏监控（LeakCanary 源码级定制）、ANR 治理、渲染优化
- **嵌入式 Linux GUI**：Qt 6.x + QML + EGLFS + Scene Graph 渲染管线，面向 ARM Linux 的工业 HMI 开发
- **系统编程**：Linux 进程/线程调度、虚拟内存、信号机制、CoreDump 分析、GDB 调试

## 技术理念

- **原理 > 框架 > 工具**：理解虚拟机怎么分配内存，比记住 Spring 注解更重要
- **输出倒逼输入**：能写清楚的，才是真正理解的
- **可检索的知识才是有用的知识**：建站的初衷——让碎片化学习有结构可循
