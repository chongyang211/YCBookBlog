# 薪资谈判

> 薪酬拆解、报价话术、期权避坑——不谈钱只会让你更不值钱

## 一、薪资谈判的心理建设：你值多少，不是公司说了算

```text
工程师最常见的薪资心态：
  "不好意思开口"、"怕谈崩了"、"公司给了就不错了"

招聘的真相：
  HR 报给你的第一个数，不是你的价值——是他们的预算底线。
  预算区间通常是报价的 15%-30% 往上还有空间。
  你没有在"多要钱"——你只是没让他们用底价买到你。
```

**不谈薪资不代表你谦虚——只代表你允许别人定义你的价值。**

---

## 二、薪酬的完整构成——不是只有月薪

```text
一份 offer 的价值 = 现金 + 股票/期权 + 福利 + 隐形价值

现金：
  □ 月薪 × 发薪月数（12 还是 13 还是更多？）
  □ 年终奖：通常几个月？过去两年实际发了多少？（不是"最多"，是"平均"）
  □ 签字费：一次性给的，用来弥补你放弃的上一家年终奖

股票/期权（RSU/Option）：
  □ 总价值多少？分几年归属？（通常 4 年，每年 25%）
  □ 行权价多少？（期权才需要行权，RSU 是直接给股票）
  □ 公司没上市 → 期权接近于白纸。除非你确信 2 年内能上市

福利：
  □ 公积金比例（5% vs 12% 差很多）
  □ 餐补、房补、交通补——加起来每月可能多 2000-5000
  □ 补充商业保险（有家庭的话很值钱）

隐形价值：
  □ 技术成长——和高手共事比一年差 10 万块月薪更重要
  □ 赛道前景——公司在上升期还是维持期？
  □ 工作强度——时薪 = 年薪 ÷ 年工作小时数。别只看年薪
```

## 三、报价话术——什么时候说、怎么说

### 3.1 什么时候说数字

```text
黄金规则：谁先说数字谁劣势。

HR："你期望的薪资是多少？"

❌ "我期望 30K。" → 如果他们的预算是 35-40K，你亏了
✅ "我还不太了解这个岗位的具体职责和团队情况——能先聊聊吗？
   之后如果我们都觉得合适，薪资可以再谈。"

如果被追问：
✅ "我更关注成长空间和团队，薪资我相信市场会给一个公允的报价。
   不过如果一定要一个范围，基于我对市场的了解，大概在 XX-YY 之间。"
```

### 3.2 拿到 offer 后的谈判

```text
拿到 offer 后你不是在哀求——你是在谈判。他们已经决定要你了。

"非常感谢 offer！我对团队和方向都很感兴趣。
我看了一下整体 package，和我的预期还有一些差距——
如果 base 能到 XX，我就很确定了。"

注意：
  - 不要拿一个你不想去的 offer 来 bluff（万一对方说"那你去那家吧"）
  - 不要说"另一个 offer 给了 XX"——要说"市场水平大概是 XX"
  - 谈判一次，不要反复拉扯。一轮就够了
```

## 四、期权/股票的避坑清单

```text
□ 是期权（Option）还是 RSU？
   → Option：你需要出钱行权，公司不上市就是废纸
   → RSU：直接给股票，上市了就是真金白银

□ 行权价格是多少？最近一轮融资的估值是多少？
   → 如果行权价 ≈ 最近一轮估值的股价——你没有任何折扣

□ 离职后期权多久内必须行权？
   → 标准是 90 天。如果公司给 10 年——加分项

□ 公司最近一轮融资是什么时候？烧钱速度？
   → 上一轮融了 5000 万但只剩 2 个月现金流 → 你拿到的是废纸

□ 口头承诺的期权不作数——必须写在合同里
```

## 五、谈判红线——这些情况直接走

```text
□ "我们薪资保密，不要和同事讨论" → 合法的讨论薪资是受劳动法保护的。
   不让你讨论 = 有人被压价了，怕你知道。

□ "现在低一点，半年后调薪" → 除非写在合同里，否则等于没说。

□ "我们 996 但是给钱多" → 算一下时薪。
   30K × 12 ÷ (12小时/天 × 6天/周 × 50周) = 时薪 100 元
   20K × 12 ÷ (8小时/天 × 5天/周 × 50周) = 时薪 120 元
   你觉得哪个更值？

□ "期权以后会很值钱的" → 期权在变现之前价值 = 0。不要用不确定的期权代替确定的现金。
```

## 六、小结

```text
薪资谈判的三个原则：

1. 不先报价 → 让对方先暴露预算区间。你只说自己对市场水平的了解
2. 算总包不算月薪 → 现金 + 股票 + 公积金 + 福利 + 时薪。别被单一数字迷惑
3. 期权当 0 算 → 确定拿到手的现金才是你的真实薪酬。期权是"如果运气好"的附加项
```

**行动清单**：

- [ ] 计算你现在的真实时薪：年薪 ÷ 实际年工作小时数
- [ ] 下一次面试，练习不说期望薪资——先问岗位职责和团队情况
- [ ] 拿到 offer 后，把所有福利、公积金、股票加一起算一个"真实年收入"
