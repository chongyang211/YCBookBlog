## 17.12 Go 新手陷阱 Top 5（占位预览）

1. ❌ `go.sum` 不提交 → 协作者拿不到正确依赖哈希
2. ❌ 用 `replace` 替换公共依赖到本地 → 提交后协作者编译失败
3. ❌ build tag 写错位置（不在文件最顶部）→ 不生效
4. ❌ 不同模块互相 import 导致循环依赖 → 设计问题
5. ❌ 滥用 internal 包 → 反而让代码难以测试
