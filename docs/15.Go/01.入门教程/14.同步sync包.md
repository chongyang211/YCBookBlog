## 14.1 本章学习目标

- ✅ 能根据"读多/写多""临时/长期"决定用 channel 还是 sync
- ✅ 知道 `Mutex` 不可重入、不可复制
- ✅ 知道 `sync.Pool` 的对象会被 GC 清掉
- ✅ 知道 `sync.Map` 的适用场景（读多写少 + key 集合稳定）

> **本章正文将在卷一定稿阶段补全。**

## 14.13 Go 新手陷阱 Top 5（占位预览）

1. ❌ 把 `sync.Mutex` 嵌入 struct 后值传递 → 锁被复制
2. ❌ `Lock` 后 panic 没 recover → 锁永远不释放
3. ❌ `WaitGroup.Add` 写在 goroutine 内 → 主 goroutine 可能已 Wait 通过
4. ❌ `sync.Pool` 当缓存用 → GC 会清空，缓存不稳定
5. ❌ 用 `sync.Map` 替代普通 map → 大多数场景普通 map + Mutex 更快
