# 并发设计模式

Go 常用并发模式：Pipeline、Fan-in/Fan-out、Worker Pool、Pub/Sub、Or-Done、Tee、Bridge。每种模式的适用场景与代码模板。

```go
// Fan-out: 一个输入分发到多个goroutine
for _, w := range workers { go w.Run(input) }
```
