# log 与 flag 包分析

log 包 Logger/Writer/Prefix 定制、flag 命令行解析、pflag 增强（兼容 POSIX）、slog 结构化日志（Go 1.21+）、zap/zerolog 高性能日志库选型。

```go
log.SetFlags(log.LstdFlags | log.Lshortfile)
```
