# 14.Go 内存模型与 happens-before

> 2022 年 Russ Cox 主导重写了 Go 内存模型文档，把 Go 的内存模型从"我们假装它和 C++11 一样"拉到了"明确定义、可形式化"的层级。本篇拆 happens-before 公理、program order / synchronized order、channel/mutex/atomic 的同步规则，并讲清 race detector 是怎么发现数据竞争的。
> 关键词：happens-before、program order、synchronized order、data race、`-race`、ThreadSanitizer、`sync.atomic`（Go 1.19 类型化）、与 Java/C++11 内存模型对照
