# 第五卷 传递温暖（第 41-48 章）

> **卷旨**：伙伴们把自己赚来的钱投入公益——给孤儿院送暖、给班级买图书、教同学做手工；新同学小宇在大家的帮扶下圆了给妹妹买发卡的心愿，队伍还为乡村小学送去文具，让善意与温暖不断延续。
