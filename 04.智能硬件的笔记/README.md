- 2.1 如何去使用CPU卡：非接触式CPU卡一般都是通过NFC，想用手机去感应身份证有两个前提：一你手机支持NFC功能，二你得知道对操作身份证的指令。
- 2.2 读卡器交互流程是怎样的：通用的步骤是命令发送和数据解析，大概就是，寻卡——>APDU通信——>关闭
- 3.1 读CPU卡流程是怎样的：一般是，选择目录——>选择文件——>取随机数——>认证文件密码——>读数据
- 3.2 写CPU卡流程是怎样的：一般是，选择目录——>选择文件——>取随机数——>认证文件密码——>写数据
- 4.1 如何理解APDU概念：APDU指令数据是在智能卡领域中用于通信的一种数据格式。APDU 指令数据通常用于在读取或写入智能卡时与卡片进行通信。
- 4.2 APDU指令类型有哪些：分为两种类型：命令指令（Command APDU）和响应指令（Response APDU）。命令指令用于向智能卡发送指令，请求执行某种操作；响应指令则是智能卡对命令指令的响应，包含执行结果或返回的数据。
- 4.3 APDU指令结构是怎样的：命令指令包含 CLA（类别）、INS（指令代码）、P1（参数1）、P2（参数2）、LC（数据长度）、Data 等字段；响应指令包含响应状态字（SW1-SW2）和响应数据等字段。

韦根协议，标准如下：

1. 26位韦根模式传输数值范围:0~16777215
2. 32位韦根模式传输数值范围: 0~1073741823
3. 34位韦根模式传输数值范围: 0~4294967295

Mifare 卡的 UID 号是一个 32 位的十六进制卡号。这个是刷卡读卡，uid是是卡片生产商给卡标记的一个物理卡号。

一般卡片，UID 通常为 4 字节（32 位）。比如：C1:84:FA:1E。这种情况是刷卡是读4个字节。

大端模式，地址由小向大增加，而数据从高位往低位放；这和我们的阅读习惯一致。那么对应十六进制是：C184FA1E，转化为十进制是 3246717470，那么他在34位韦根协议范围中。

小端模式，高地址部分权值高，低地址部分权值低。那么对应十六进制是：1EFA84C1，转化为十进制是 519734465，那么他在32位韦根协议范围中。

有些特殊卡，读3个字节。比如用户提到，UID 通常为 3 字节（24 位）。比如：FA:84:C1。这种情况是刷卡是读3个字节。

大端模式，地址由小向大增加，而数据从高位往低位放；这和我们的阅读习惯一致。那么对应十六进制是：FA84C1，转化为十进制是 16417985，那么他在26位韦根协议范围中。

小端模式，高地址部分权值高，低地址部分权值低。那么对应十六进制是：C184FA，转化为十进制是 12682490，那么他在26位韦根协议范围中。

注意：韦根协议，必须保证传输端（设备），到接收端（门禁），协议保持一致。

### **3. 如何转换十六进制数据**
#### **大端序转小端序**
将字节顺序反转即可。例如：
```
大端序：C1 84 FA 1E
小端序：1E FA 84 C1
```

#### **小端序转大端序**
同样将字节顺序反转。例如：
```
小端序：1E FA 84 C1
大端序：C1 84 FA 1E
```

---

### **4. 代码示例（Python）**
以下是实现大端序和小端序转换的 Python 代码：
```python
def hex_to_little_endian(hex_str):
    # 去掉冒号或空格
    hex_str = hex_str.replace(":", "").replace(" ", "")
    # 反转字节顺序
    little_endian = ''.join(reversed([hex_str[i:i+2] for i in range(0, len(hex_str), 2)]))
    return little_endian

def hex_to_big_endian(hex_str):
    # 去掉冒号或空格
    hex_str = hex_str.replace(":", "").replace(" ", "")
    return hex_str

# 示例
big_endian_hex = "C1:84:FA:1E"
little_endian_hex = hex_to_little_endian(big_endian_hex)

print("大端序:", big_endian_hex)
print("小端序:", little_endian_hex)
```

输出：
```
大端序: C1:84:FA:1E
小端序: 1EFA84C1
```

### **总结**
- 大端序和小端序是数据存储的两种方式，区别在于字节的顺序。
- 在读取 M1 卡或 CPU 卡数据时，需要根据规范判断数据的存储顺序。
- 通过反转字节顺序可以实现大端序和小端序的转换。
