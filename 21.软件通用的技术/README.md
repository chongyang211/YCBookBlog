### **2. 使用 SSH 密钥登录**

SSH 支持使用密钥对（公钥和私钥）进行身份验证，比密码更安全。

#### **步骤 1：生成 SSH 密钥对**

在本地计算机上生成 SSH 密钥对：

```bash
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```

- 默认情况下，密钥对会保存在 `~/.ssh/` 目录下，文件名为 `id_rsa`（私钥）和 `id_rsa.pub`（公钥）。

#### **步骤 2：将公钥上传到远程服务器**

将公钥复制到远程服务器的 `~/.ssh/authorized_keys` 文件中：

```bash
ssh-copy-id user@192.168.1.100
```

- 如果 `ssh-copy-id` 不可用，可以手动复制公钥内容并添加到远程服务器的 `~/.ssh/authorized_keys` 文件中。

#### **步骤 3：使用私钥登录**

使用私钥登录远程服务器：

```bash
ssh -i ~/.ssh/id_rsa user@192.168.1.100
```

### **3. 文件传输**

#### **使用 `scp` 传输文件**

- 将本地文件复制到远程服务器：

```bash
scp local_file user@192.168.1.100:/remote/directory
```

- 将远程文件复制到本地：

```bash
scp user@192.168.1.100:/remote/file /local/directory
```

#### **使用 `sftp` 传输文件**

启动 SFTP 会话：

```bash
sftp user@192.168.1.100
```

- 上传文件：

```sftp
put local_file /remote/directory
```

- 下载文件：

```sftp
get /remote/file /local/directory
```

---

### **4. 远程命令执行**

在远程服务器上执行命令，无需登录到远程终端：

```bash
ssh user@192.168.1.100 "command"
```

#### **示例：查看远程服务器的磁盘使用情况**

```bash
ssh user@192.168.1.100 "df -h"
```

---

### **5. 端口转发**

#### **本地端口转发**

将本地端口映射到远程端口：

```bash
ssh -L 本地端口:远程主机:远程端口 user@192.168.1.100
```

#### **示例：将本地的 8080 端口映射到远程的 80 端口**

```bash
ssh -L 8080:localhost:80 user@192.168.1.100
```

- 访问 `localhost:8080` 相当于访问远程服务器的 `80` 端口。

#### **远程端口转发**

将远程端口映射到本地端口：

```bash
ssh -R 远程端口:本地主机:本地端口 user@192.168.1.100
```

---

### **6. 配置 SSH 客户端**

可以通过编辑 `~/.ssh/config` 文件来简化 SSH 连接。

#### **示例配置**

```plaintext
Host myserver
    HostName 192.168.1.100
    User user
    Port 2222
    IdentityFile ~/.ssh/id_rsa
```

- 配置后，可以直接使用以下命令连接：

```bash
ssh myserver
```

## **SSH 的常见问题**

1. **连接超时**：
    - 检查网络是否畅通，远程服务器的 SSH 服务是否正常运行。
    - 检查防火墙是否允许 SSH 端口（默认 22）。

2. **权限问题**：
    - 确保 `~/.ssh/` 目录的权限为 `700`，`~/.ssh/authorized_keys` 文件的权限为 `600`。

3. **密钥登录失败**：
    - 确保公钥已正确添加到远程服务器的 `~/.ssh/authorized_keys` 文件中。
    - 确保私钥文件的权限为 `600`。

---

## **总结**

SSH 是一种强大的工具，用于安全地访问和管理远程计算机。通过掌握 SSH 的基本用法和高级功能（如密钥登录、文件传输、端口转发等），可以显著提高远程工作的效率和安全性。
