## 01.SSH是什么

### 1.1 了解SSH工具

SSH（Secure Shell）** 是一种网络协议，用于在不安全的网络中安全地访问远程计算机或服务器。

它通过加密通信来保护数据传输，防止数据被窃听或篡改。SSH 广泛用于远程登录、文件传输、远程命令执行等场景。

### 1.2 SSH的作用

1. **远程登录**：通过 SSH 可以远程登录到另一台计算机或服务器，就像在本地操作一样。适用于管理远程服务器、虚拟机或云主机。
2. **文件传输**：使用 `scp` 或 `sftp` 工具，可以通过 SSH 安全地传输文件。
3. **远程命令执行**：可以通过 SSH 在远程计算机上执行命令，无需登录到远程终端。
4. **端口转发**：SSH 支持端口转发功能，可以将本地端口映射到远程端口，或者将远程端口映射到本地端口。
5. **安全通信**：SSH 使用加密技术保护数据传输，防止数据被窃听或篡改。

## 02.SSH基本语法

### 2.1 基本语法

```bash
ssh [选项] [用户名@]主机名或IP地址
```

- **用户名**：远程计算机的登录用户名。
- **主机名或IP地址**：远程计算机的主机名或 IP 地址。
- **选项**：常用的选项包括 `-p`（指定端口）、`-i`（指定私钥文件）等。

### 2.2 示例实践

**示例：登录远程服务器**

```bash
ssh user@192.168.1.100
```

- 如果远程服务器的 SSH 端口不是默认的 22，可以使用 `-p` 指定端口：

```bash
ssh -p 2222 user@192.168.1.100
```

## 03.SSH密钥登录

SSH 支持使用密钥对（公钥和私钥）进行身份验证，比密码更安全。

### 3.1 生成SSH密钥对

在本地计算机上生成 SSH 密钥对：

```bash
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```

默认情况下，密钥对会保存在 `~/.ssh/` 目录下，文件名为 `id_rsa`（私钥）和 `id_rsa.pub`（公钥）。

### 3.2 将公钥上传到远程服务器

将公钥复制到远程服务器的 `~/.ssh/authorized_keys` 文件中：

```bash
ssh-copy-id user@192.168.1.100
```

如果 `ssh-copy-id` 不可用，可以手动复制公钥内容并添加到远程服务器的 `~/.ssh/authorized_keys` 文件中。

### 3.3 使用私钥登录

使用私钥登录远程服务器：

```bash
ssh -i ~/.ssh/id_rsa user@192.168.1.100
```

## 04.文件传输
### 4.1 scp传输文件

**使用 `scp` 传输文件**

- 将本地文件复制到远程服务器：

```bash
scp local_file user@192.168.1.100:/remote/directory
```

- 将远程文件复制到本地：

```bash
scp user@192.168.1.100:/remote/file /local/directory
```

### 4.2 sftp传输文件

**使用 `sftp` 传输文件**

启动 SFTP 会话：

```bash
sftp user@192.168.1.100
```

- 上传文件：

```sftp
put local_file /remote/directory
```

- 下载文件：

```sftp
get /remote/file /local/directory
```

## 05.远程命令执行

在远程服务器上执行命令，无需登录到远程终端：

```bash
ssh user@192.168.1.100 "command"
```

**示例：查看远程服务器的磁盘使用情况**

```bash
ssh user@192.168.1.100 "df -h"
```

## 06.端口转发

### 6.1 本地端口转发

将本地端口映射到远程端口：

```bash
ssh -L 本地端口:远程主机:远程端口 user@192.168.1.100
```

**示例：将本地的 8080 端口映射到远程的 80 端口**

```bash
ssh -L 8080:localhost:80 user@192.168.1.100
```

访问 `localhost:8080` 相当于访问远程服务器的 `80` 端口。

### 6.2 远程端口转发

将远程端口映射到本地端口：

```bash
ssh -R 远程端口:本地主机:本地端口 user@192.168.1.100
```

## 07.配置SSH客户端

### 7.1 如何配置SSH

可以通过编辑 `~/.ssh/config` 文件来简化 SSH 连接。**示例配置**

```plaintext
Host myserver
    HostName 192.168.1.100
    User user
    Port 2222
    IdentityFile ~/.ssh/id_rsa
```

配置后，可以直接使用以下命令连接：

```bash
ssh myserver
```
