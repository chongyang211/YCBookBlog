# 03.校园身份预约系统（骨架版）

> 入门教程第 9-12 章的"集合框架全家桶大考"。从 02 的"`Account[]` 对象数组"进化到**集合框架五件套**——`ArrayList` / `HashMap` / `TreeMap` / `LinkedHashMap` / `PriorityQueue`，配合**抽象身份基类**（学生 / 教师 / 管理员）+ Lambda + Comparator 排序。
>
> 📍 **当前文档为骨架版**，详细内容将在后续轮次扩写至 ~110 KB 完整教学文档。
