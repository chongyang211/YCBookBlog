## 01.轮询管理系统

### 1.1 产品需求

主要功能：

1. 可以灵活设置轮询的时间（例如固定间隔、动态调整间隔等）
2. 暴露一个doAction接口，用于执行用户定义的任务
3. 支持启动、停止、暂停、继续等操作
4. 支持任务执行超时监控
5. 支持任务执行结果的回调或记录
6. 支持多线程（轮询在一个线程，任务执行可以在另一个线程）
7. 异常处理

### 1.2 设计核心思路

我们将设计一个Poller类，它包含以下主要部分：

- 配置：轮询间隔（可以是固定值，也可以是动态计算的策略）、任务超时时间等
- 状态：运行状态（运行、暂停、停止）
- 线程：轮询线程，用于定时触发任务
- 任务执行：使用线程池或单独线程执行任务
- 超时监控：使用`Future.get(timeout)`实现任务超时

### 1.3 开发的步骤

1. 定义轮询策略接口和具体实现
2. 定义任务结果类和统计类
3. 实现轮询器类，包含启动、停止、暂停、继续等方法
4. 实现轮询线程函数，使用`wait/notify`控制暂停和停止
5. 实现任务执行部分，使用`ExecutorService`和`Future`
6. 添加统计信息记录
7. 异常处理

### 1.4 技术栈说明

| 技术 | C++对应 | Java实现 |
|-----|---------|---------|
| 线程 | `std::thread` | `Thread` |
| 互斥锁 | `std::mutex` | `synchronized` / `ReentrantLock` |
| 条件变量 | `std::condition_variable` | `Condition` / `wait/notify` |
| 异步任务 | `std::async` + `std::future` | `ExecutorService` + `Future` |
| 原子变量 | `std::atomic<bool>` | `volatile` / `AtomicBoolean` |
| 策略模式 | 纯虚类 + 派生类 | 接口 + 实现类 |
| 时间处理 | `std::chrono` | `TimeUnit` / `System.nanoTime()` |

### 1.5 核心组件说明

- **PollingStrategy**：轮询策略接口，定义间隔计算方法
- **FixedIntervalStrategy**：固定间隔策略
- **ExponentialBackoffStrategy**：指数退避策略
- **RandomIntervalStrategy**：随机间隔策略
- **TaskResult**：任务执行结果封装
- **TaskStatistics**：任务统计
- **Poller**：轮询器核心类

### 1.6 轮询工作流程

1. 启动后，在轮询线程中循环，直到停止
2. 每次循环开始，检查状态：如果暂停，则等待；如果停止，则退出
3. 根据策略计算下一次轮询的等待时间
4. 等待该时间（使用`wait`可被`notify`唤醒）
5. 等待结束后执行任务
6. 根据任务执行结果，调整轮询间隔

## 02.时间单位与工具

### 2.1 时间单位定义

Java自带`java.util.concurrent.TimeUnit`枚举，可以直接使用：

```java
import java.util.concurrent.TimeUnit;

// 直接使用Java内置的TimeUnit
// TimeUnit.NANOSECONDS
// TimeUnit.MICROSECONDS
// TimeUnit.MILLISECONDS
// TimeUnit.SECONDS
// TimeUnit.MINUTES
```

对比C++：C++自定义了`TimeUnit`枚举和`TimeConverter`工具类，Java直接使用`java.util.concurrent.TimeUnit`内置支持，功能更完善。

### 2.2 时间转换工具类

```java
// Java不需要自己实现，TimeUnit自带转换方法
long millis = TimeUnit.SECONDS.toMillis(5);     // 5秒 -> 5000毫秒
long nanos = TimeUnit.MILLISECONDS.toNanos(100); // 100毫秒 -> 100000000纳秒
```

对比C++：C++需要手动实现`toNanoseconds`方法做单位转换，Java的`TimeUnit`内置了`toNanos()`、`toMillis()`、`toSeconds()`等转换方法。

## 03.轮询策略接口设计

### 3.1 策略接口分析

轮询策略接口定义策略行为，然后实现三种策略：固定间隔、指数退避、随机间隔。

### 3.2 轮询策略接口

```java
public interface PollingStrategy {
    // 获取下一次轮询间隔（毫秒）
    long getNextIntervalMs();
    // 重置策略状态
    void reset();
    // 记录任务成功
    void recordSuccess();
    // 记录任务失败
    void recordFailure();
    // 获取策略配置信息
    String getConfigInfo();
}
```

对比C++：C++使用抽象类`IPollingStrategy`（含虚析构函数和纯虚函数），Java使用`interface`接口。Java的接口更简洁，不需要虚析构函数。

## 04.具体策略实现

### 4.1 固定间隔策略

```java
public class FixedIntervalStrategy implements PollingStrategy {
    private final long intervalMs;

    public FixedIntervalStrategy(long interval, TimeUnit unit) {
        this.intervalMs = unit.toMillis(interval);
    }

    @Override
    public long getNextIntervalMs() { return intervalMs; }

    @Override
    public void reset() {}

    @Override
    public void recordSuccess() {}

    @Override
    public void recordFailure() {}

    @Override
    public String getConfigInfo() {
        return "FixedInterval: " + intervalMs + "ms";
    }
}
```

### 4.2 指数退避策略

```java
public class ExponentialBackoffStrategy implements PollingStrategy {
    private final long initialMs;
    private final long maxMs;
    private long currentMs;

    public ExponentialBackoffStrategy(long initial, long max, TimeUnit unit) {
        this.initialMs = unit.toMillis(initial);
        this.maxMs = unit.toMillis(max);
        this.currentMs = this.initialMs;
    }

    @Override
    public long getNextIntervalMs() {
        long result = currentMs;
        currentMs = Math.min(currentMs * 2, maxMs);
        return result;
    }

    @Override
    public void reset() { currentMs = initialMs; }

    @Override
    public void recordSuccess() { reset(); }

    @Override
    public void recordFailure() {}

    @Override
    public String getConfigInfo() {
        return "ExponentialBackoff: Initial=" + initialMs + "ms, Max=" + maxMs + "ms";
    }
}
```

对比C++：C++使用纳秒为单位并自己实现`toNanoseconds`转换，Java使用毫秒并借助`TimeUnit`内置转换。逻辑完全一致。

### 4.3 随机间隔策略

```java
import java.util.Random;

public class RandomIntervalStrategy implements PollingStrategy {
    private final long minMs;
    private final long maxMs;
    private final Random random;

    public RandomIntervalStrategy(long min, long max, TimeUnit unit) {
        this.minMs = unit.toMillis(min);
        this.maxMs = unit.toMillis(max);
        this.random = new Random();
    }

    @Override
    public long getNextIntervalMs() {
        return minMs + (long) (random.nextDouble() * (maxMs - minMs));
    }

    @Override
    public void reset() {}

    @Override
    public void recordSuccess() {}

    @Override
    public void recordFailure() {}

    @Override
    public String getConfigInfo() {
        return "RandomInterval: Min=" + minMs + "ms, Max=" + maxMs + "ms";
    }
}
```

## 05.任务结果与统计

### 5.1 任务结果类

```java
public class TaskResult {
    private boolean success;
    private String message;
    private long timestamp;

    public TaskResult(boolean success, String message) {
        this.success = success;
        this.message = message;
        this.timestamp = System.currentTimeMillis();
    }

    public boolean isSuccess() { return success; }
    public String getMessage() { return message; }
    public long getTimestamp() { return timestamp; }
}
```

对比C++：C++使用`std::chrono::steady_clock::time_point`记录时间戳，Java使用`System.currentTimeMillis()`。

### 5.2 任务统计系统

```java
import java.util.*;

public class TaskStatistics {
    private int total;
    private int success;
    private int failure;
    private final LinkedList<TaskResult> recentResults;

    public TaskStatistics() {
        total = 0;
        success = 0;
        failure = 0;
        recentResults = new LinkedList<>();
    }

    public void recordResult(TaskResult result) {
        total++;
        if (result.isSuccess()) {
            success++;
        } else {
            failure++;
        }
        recentResults.addLast(result);
        if (recentResults.size() > 100) {
            recentResults.removeFirst();
        }
    }

    public void printSummary() {
        System.out.println("=== Task Statistics ===");
        System.out.println("Total runs: " + total);
        System.out.println("Success: " + success + " (" +
                (total > 0 ? (success * 100.0 / total) : 0) + "%)");
        System.out.println("Failure: " + failure + " (" +
                (total > 0 ? (failure * 100.0 / total) : 0) + "%)");
        if (!recentResults.isEmpty()) {
            System.out.println("\nRecent results (last " + recentResults.size() + "):");
            for (TaskResult res : recentResults) {
                System.out.println("[" + new Date(res.getTimestamp()) + "] " +
                        (res.isSuccess() ? "SUCCESS" : "FAILURE") +
                        ": " + res.getMessage());
            }
        }
    }
}
```

对比C++：C++使用`std::deque`保存最近结果，Java使用`LinkedList`。C++需要手动格式化时间戳，Java直接使用`Date`。

## 06.轮询器核心实现

### 6.1 轮询器核心类

```java
import java.util.concurrent.*;
import java.util.function.Supplier;

public class Poller {
    private PollingStrategy strategy;
    private Supplier<TaskResult> action;
    private volatile boolean running;
    private volatile boolean paused;
    private Thread workerThread;
    private final Object lock = new Object();
    private long taskTimeoutMs;
    private TaskStatistics stats;
    private ExecutorService executor;

    public Poller(PollingStrategy strategy, Supplier<TaskResult> action) {
        this.strategy = strategy;
        this.action = action;
        this.running = false;
        this.paused = false;
        this.taskTimeoutMs = 0;
        this.stats = new TaskStatistics();
        this.executor = Executors.newSingleThreadExecutor();
    }
}
```

对比C++：C++使用`std::unique_ptr<IPollingStrategy>`管理策略对象，Java直接持有引用。C++使用`std::function<TaskResult()>`，Java使用`Supplier<TaskResult>`函数式接口。

### 6.2 启动轮询器

```java
public void start() {
    if (running) return;
    running = true;
    workerThread = new Thread(() -> run());
    workerThread.start();
    System.out.println("Poller started with strategy: " + strategy.getConfigInfo());
}

private void run() {
    while (running) {
        long nextInterval;
        synchronized (lock) {
            nextInterval = strategy.getNextIntervalMs();
            // 等待间隔时间，可被唤醒
            long deadline = System.currentTimeMillis() + nextInterval;
            while (running && System.currentTimeMillis() < deadline && !paused) {
                try {
                    long waitTime = deadline - System.currentTimeMillis();
                    if (waitTime > 0) {
                        lock.wait(waitTime);
                    }
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    return;
                }
            }
            // 检查暂停
            while (paused && running) {
                try {
                    lock.wait();
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    return;
                }
            }
            if (!running) break;
        }
        // 执行任务
        executeAction();
    }
}
```

对比C++：C++使用`std::condition_variable` + `wait_until`实现定时等待，Java使用`synchronized` + `wait(timeout)`。两者都支持被唤醒中断等待。

### 6.3 停止轮询器

```java
public void stop() {
    if (!running) return;
    synchronized (lock) {
        running = false;
        paused = false;
        lock.notifyAll();
    }
    try {
        workerThread.join();
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
    }
    executor.shutdown();
    System.out.println("Poller stopped.");
}
```

### 6.4 暂停和继续

```java
public void pause() {
    synchronized (lock) {
        paused = true;
        lock.notifyAll();
    }
    System.out.println("Poller paused.");
}

public void resume() {
    synchronized (lock) {
        paused = false;
        lock.notifyAll();
    }
    System.out.println("Poller resumed.");
}
```

### 6.5 更新轮询策略

```java
public void updateStrategy(PollingStrategy newStrategy) {
    synchronized (lock) {
        this.strategy = newStrategy;
        strategy.reset();
    }
    System.out.println("Strategy updated: " + strategy.getConfigInfo());
}
```

### 6.6 设置任务超时

```java
public void setTaskTimeout(long timeout, TimeUnit unit) {
    this.taskTimeoutMs = unit.toMillis(timeout);
    System.out.println("Task timeout set to: " + taskTimeoutMs + "ms");
}

private void executeAction() {
    long startTime = System.currentTimeMillis();
    TaskResult result;
    try {
        if (taskTimeoutMs > 0) {
            // 带超时的任务执行
            Future<TaskResult> future = executor.submit(() -> action.get());
            try {
                result = future.get(taskTimeoutMs, TimeUnit.MILLISECONDS);
            } catch (TimeoutException e) {
                result = new TaskResult(false, "Task timed out");
                future.cancel(true);
            }
        } else {
            result = action.get();
        }
    } catch (Exception e) {
        result = new TaskResult(false, "Exception: " + e.getMessage());
    }
    long duration = System.currentTimeMillis() - startTime;
    // 记录结果并更新策略
    synchronized (lock) {
        stats.recordResult(result);
        if (result.isSuccess()) {
            strategy.recordSuccess();
        } else {
            strategy.recordFailure();
        }
    }
    System.out.println("Action executed in " + duration + "ms. Result: " +
            (result.isSuccess() ? "SUCCESS" : "FAILURE") + " - " + result.getMessage());
}
```

对比C++：C++使用`std::async(std::launch::async, action_)` + `future.wait_for`实现超时，Java使用`executor.submit()` + `future.get(timeout)`。Java的`Future.cancel(true)`可以中断任务线程，比C++的处理更优雅。

## 07.示例使用场景

### 7.1 示例任务函数

```java
import java.util.concurrent.atomic.AtomicInteger;

// 模拟任务，30%失败率
AtomicInteger counter = new AtomicInteger(0);
Supplier<TaskResult> sampleAction = () -> {
    int count = counter.incrementAndGet();
    try {
        if (count % 10 < 3) {
            Thread.sleep(150);
            return new TaskResult(false, "Simulated failure #" + count);
        }
        Thread.sleep(50);
        return new TaskResult(true, "Operation succeeded #" + count);
    } catch (InterruptedException e) {
        return new TaskResult(false, "Interrupted #" + count);
    }
};
```

### 7.2 创建并启动轮询器

```java
public static void main(String[] args) throws InterruptedException {
    AtomicInteger counter = new AtomicInteger(0);
    Supplier<TaskResult> sampleAction = () -> {
        int count = counter.incrementAndGet();
        try {
            if (count % 10 < 3) {
                Thread.sleep(150);
                return new TaskResult(false, "Simulated failure #" + count);
            }
            Thread.sleep(50);
            return new TaskResult(true, "Operation succeeded #" + count);
        } catch (InterruptedException e) {
            return new TaskResult(false, "Interrupted");
        }
    };

    // 使用固定间隔策略
    Poller poller = new Poller(
            new FixedIntervalStrategy(1, TimeUnit.SECONDS),
            sampleAction
    );

    poller.start();
    Thread.sleep(5000);

    // 暂停
    poller.pause();
    Thread.sleep(2000);

    // 切换策略
    poller.updateStrategy(
            new ExponentialBackoffStrategy(500, 5000, TimeUnit.MILLISECONDS)
    );

    // 继续
    poller.resume();
    Thread.sleep(5000);

    // 停止
    poller.stop();
}
```

## 08.项目总结

### 8.1 对比C++实现

| 对比项 | C++ | Java |
|-------|-----|------|
| 策略接口 | 抽象类 + 纯虚函数 + 虚析构 | `interface`接口 |
| 策略持有 | `std::unique_ptr<IPollingStrategy>` | 直接引用 |
| 任务函数 | `std::function<TaskResult()>` | `Supplier<TaskResult>` |
| 时间单位 | 自定义枚举 + 手动转换 | `java.util.concurrent.TimeUnit` |
| 线程同步 | `std::mutex` + `std::condition_variable` | `synchronized` + `wait/notify` |
| 异步执行 | `std::async` + `std::future` | `ExecutorService` + `Future` |
| 超时处理 | `future.wait_for(duration)` | `future.get(timeout, unit)` |
| 取消任务 | 无法中断正在运行的线程 | `future.cancel(true)`可中断 |
| 原子变量 | `std::atomic<bool>` | `volatile` / `AtomicBoolean` |
| 命名空间 | `namespace PollingSystem` | `package` |
| 线程停止 | 标志位 + `notify_all` | 标志位 + `notifyAll` |
| 资源管理 | RAII + 析构函数 | GC + `shutdown()` |
