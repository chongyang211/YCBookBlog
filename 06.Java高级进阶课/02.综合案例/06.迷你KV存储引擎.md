# 06.迷你 KV 存储引擎（骨架版）🎓

> 入门教程 15 章的"毕业设计"。把前 5 个案例的所有能力合一——**命令模式（继承多态）+ AOF 持久化（IO 流）+ 读写锁（并发）+ 守护线程 TTL（线程）+ 注解扫描命令（反射注解）+ 自实现线程池（08 项目复用）+ 内置单测（JUnit 雏形）**。
>
> 一个项目串完入门 1-15 全章。学完它，你就具备阅读 Redis Java client / HikariCP / Caffeine 等开源项目的能力。
>
