## 01.演讲比赛系统

### 1.1 比赛规则

* 学校举行一场演讲比赛，共有**12个人**参加。**比赛共两轮**，第一轮为淘汰赛，第二轮为决赛。
* 比赛方式：**分组比赛，每组6个人**；选手每次要随机分组，进行比赛
* 每名选手都有对应的**编号**，如 10001 ~ 10012
* 第一轮分为两个小组，每组6个人。整体按照选手编号进行**抽签**后顺序演讲。
* 当小组演讲完后，淘汰组内排名最后的三个选手，**前三名晋级**，进入下一轮的比赛。
* 第二轮为决赛，**前三名胜出**
* 每轮比赛过后需要**显示晋级选手的信息**

### 1.2 程序功能

* 开始演讲比赛：完成整届比赛的流程，每个比赛阶段需要给用户一个提示
* 查看往届记录：查看之前比赛前三名结果，每次比赛都会记录到文件中
* 清空比赛记录：将文件中数据清空
* 退出比赛程序：可以退出当前程序

### 1.3 开发设计步骤

1. 定义选手类，包含编号、姓名、分数等
2. 实现抽签（随机分组）功能
3. 实现比赛过程，包括两轮比赛，每轮比赛后显示晋级选手
4. 记录比赛结果到CSV文件
5. 实现查看往届记录、清空记录的功能

### 1.4 技术栈说明

1. **Java集合框架**：
  - 容器：`ArrayList`、`HashMap`、`TreeMap`
  - 工具：`Collections.shuffle()`、`Collections.sort()`
  - 文件操作：`BufferedWriter`、`BufferedReader`
  - 随机数生成：`Random`
2. **面向对象编程**：
  - 使用类`SpeechManager`封装比赛管理逻辑
  - 使用类`Speaker`存储选手信息
3. **命令行交互**：
  - 使用`Scanner`实现用户输入

### 5.4 初始化创建选手

```java
public void createSpeaker() {
    String nameSeed = "ABCDEFGHIJKL";
    for (int i = 0; i < nameSeed.length(); i++) {
        String name = "选手" + nameSeed.charAt(i);
        Speaker speaker = new Speaker();
        speaker.setName(name);
        speaker.setScore(0, 0);
        speaker.setScore(1, 0);
        int key = i + 10001;
        v1.add(key);
        speakerMap.put(key, speaker);
    }
}
```

对比C++：C++使用`map<int, Speaker>`和`make_pair`，Java使用`HashMap`和`put`方法。Java的`String.charAt()`对应C++的`string[i]`。

## 06.第一轮比赛

### 6.1 抽签

使用`Collections.shuffle()`打乱选手顺序：

```java
public void speechDraw() {
    System.out.println("第 << " + index + " >> 轮比赛选手正在抽签");
    System.out.println("---------------------");
    System.out.println("抽签后演讲顺序如下：");
    if (index == 1) {
        Collections.shuffle(v1);
        for (int id : v1) {
            System.out.print(id + " ");
        }
    } else {
        Collections.shuffle(v2);
        for (int id : v2) {
            System.out.print(id + " ");
        }
    }
    System.out.println();
    System.out.println("---------------------");
}
```

对比C++：C++使用`std::shuffle` + `std::random_device` + `std::mt19937`，Java直接用`Collections.shuffle()`一行搞定。

### 6.2 开始比赛

```java
public void speechContest() {
    System.out.println("------------- 第" + index + "轮正式比赛开始 ------------- ");
    // 临时容器，保存分数和选手编号（按分数降序）
    TreeMap<Double, Integer> groupScore = new TreeMap<>(Collections.reverseOrder());
    int num = 0;
    Random random = new Random();

    ArrayList<Integer> srcList = (index == 1) ? v1 : v2;

    for (int id : srcList) {
        num++;
        // 评委打分：10个评委，每人60~100分
        ArrayList<Double> scores = new ArrayList<>();
        for (int i = 0; i < 10; i++) {
            double score = (random.nextInt(401) + 600) / 10.0;
            scores.add(score);
        }
        // 排序
        Collections.sort(scores, Collections.reverseOrder());
        // 去掉最高分和最低分
        scores.remove(0);
        scores.remove(scores.size() - 1);
        // 计算平均分
        double sum = 0;
        for (double s : scores) {
            sum += s;
        }
        double avg = sum / scores.size();
        speakerMap.get(id).setScore(index - 1, avg);
        groupScore.put(avg, id);

        // 每6人一组
        if (num % 6 == 0) {
            System.out.println("第" + (num / 6) + "小组比赛名次：");
            for (Map.Entry<Double, Integer> entry : groupScore.entrySet()) {
                int eid = entry.getValue();
                System.out.println("编号: " + eid +
                        " 姓名：" + speakerMap.get(eid).getName() +
                        " 成绩：" + speakerMap.get(eid).getScore(index - 1));
            }
            // 取前三名
            int count = 0;
            for (Map.Entry<Double, Integer> entry : groupScore.entrySet()) {
                if (count >= 3) break;
                if (index == 1) {
                    v2.add(entry.getValue());
                } else {
                    victory.add(entry.getValue());
                }
                count++;
            }
            groupScore.clear();
            System.out.println();
        }
    }
    System.out.println("------------- 第" + index + "轮比赛完毕 ------------- ");
}
```

对比C++：C++使用`multimap<double, int, greater<int>>`实现降序排列，Java使用`TreeMap`配合`Collections.reverseOrder()`。C++使用`deque`去掉最高最低分，Java使用`ArrayList`的`remove`方法。

### 7.2 保存分数

```java
public void saveRecord() {
    try (BufferedWriter bw = new BufferedWriter(
            new FileWriter("speech.csv", true))) {  // true表示追加模式
        for (int id : victory) {
            bw.write(id + "," + speakerMap.get(id).getScore(1));
            if (id != victory.get(victory.size() - 1)) {
                bw.write(",");
            }
        }
        bw.newLine();
        System.out.println("记录已经保存");
    } catch (IOException e) {
        System.out.println("保存记录失败：" + e.getMessage());
    }
}
```

对比C++：C++使用`ofstream`配合`ios::out | ios::app`追加模式，Java使用`new FileWriter(filename, true)`的第二个参数`true`表示追加。

## 08.查看记录

### 8.1 读取记录分数

```java
public ArrayList<String> loadRecord() {
    ArrayList<String> records = new ArrayList<>();
    File file = new File("speech.csv");
    if (!file.exists() || file.length() == 0) {
        return records;
    }
    try (BufferedReader br = new BufferedReader(new FileReader(file))) {
        String line;
        while ((line = br.readLine()) != null) {
            if (!line.trim().isEmpty()) {
                records.add(line);
            }
        }
    } catch (IOException e) {
        System.out.println("读取记录失败：" + e.getMessage());
    }
    return records;
}
```

### 8.2 查看记录功能

```java
public void showRecord() {
    ArrayList<String> records = loadRecord();
    if (records.isEmpty()) {
        System.out.println("文件不存在或记录为空！");
        return;
    }
    for (int i = 0; i < records.size(); i++) {
        String[] parts = records.get(i).split(",");
        if (parts.length >= 6) {
            System.out.println("第" + (i + 1) + "届 " +
                    "冠军编号：" + parts[0] + " 得分：" + parts[1] + " " +
                    "亚军编号：" + parts[2] + " 得分：" + parts[3] + " " +
                    "季军编号：" + parts[4] + " 得分：" + parts[5]);
        }
    }
}
```

## 10.项目总结

### 10.1 对比C++实现

| 对比项 | C++ | Java |
|-------|-----|------|
| 随机打乱 | `std::shuffle` + `random_device` + `mt19937` | `Collections.shuffle()` |
| 有序Map | `multimap<double, int, greater<int>>` | `TreeMap` + `reverseOrder()` |
| 随机数 | `rand() % 401 + 600` | `Random.nextInt(401) + 600` |
| 容器遍历 | `iterator` + `begin/end` | 增强for循环 |
| 文件追加 | `ios::out \| ios::app` | `new FileWriter(f, true)` |
| 字符串分割 | `find()` + `substr()` | `String.split(",")` |
| 排序去极值 | `deque` + `sort` + `pop_front/pop_back` | `ArrayList` + `sort` + `remove` |
| 累加求和 | `std::accumulate` | for循环累加 / Stream API |
| 选手存储 | `map<int, Speaker>` | `HashMap<Integer, Speaker>` |
| 文件读取 | `ifstream` + `getline` + 手动解析 | `BufferedReader` + `split` |
