## 01.项目需求和功能

### 1.1 需求介绍

银行账户管理系统，满足基本的功能需求。该系统支持开户、存款、取款、查询余额、转账、保存数据到文件以及从文件读取数据。

### 1.2 功能要求

1. **开户**：创建新账户，输入账户号、姓名和初始余额。
2. **存款**：根据账户号存款，更新账户余额。
3. **取款**：根据账户号取款，更新账户余额。
4. **查询余额**：根据账户号查询当前余额。
5. **转账**：支持从一个账户转账到另一个账户。
6. **保存数据到文件**：将账户数据保存到文件中。
7. **从文件读取数据**：启动时从文件加载账户数据。

### 1.3 设计思路

**面向对象设计**

- **Account 类**：表示一个银行账户，封装了账户号、姓名、余额等属性，以及存款、取款、转账等行为。
- **Bank 类**：管理多个账户，提供开户、存款、取款、查询余额、转账等功能。
- **FileManager 类**：负责将账户数据保存到文件和从文件加载数据，实现了数据的持久化。

**模块化设计**：将系统分为多个模块（类），每个模块负责特定的功能。

**数据持久化**：使用文件存储账户数据，确保程序关闭后数据不会丢失。文件格式为CSV（逗号分隔值），便于读取和解析。

### 1.4 涉及知识点

**面向对象编程（OOP）**

- **封装**：将账户的属性和行为封装在 `Account` 类中，通过private修饰隐藏内部实现细节。
- **继承**：本案例未使用继承，但可以通过继承扩展功能（如不同类型的账户）。

**集合框架**

- **`ArrayList`**：用于存储多个账户，提供动态数组的功能（对应C++的 `std::vector`）。

**文件操作**

- **`BufferedWriter` 和 `BufferedReader`**：用于文件的读写操作（对应C++的 `ofstream/ifstream`）。

**用户输入处理**

- **`Scanner`**：用于从用户输入中获取数据（对应C++的 `cin/getline`）。

**异常处理**

- **try-catch**：在文件操作和数据转换时进行异常捕获（Java的特色，C++中异常处理相对较少使用）。

## 03.录入开户信息

### 3.1 定义账户类

Account类是一个实体类，代表单个账户。包含用户属性数据的封装和单账户操作。

```java
public class Account {
    private String accountNumber; // 账户号
    private String name;          // 姓名
    private double balance;       // 余额

    public Account(String accountNumber, String name, double initialBalance) {
        this.accountNumber = accountNumber;
        this.name = name;
        this.balance = initialBalance;
    }

    public String getAccountNumber() { return accountNumber; }
    public String getName() { return name; }
    public double getBalance() { return balance; }

    // 存款
    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
            System.out.println("存款成功！当前余额: " + balance);
        } else {
            System.out.println("存款金额无效！");
        }
    }

    // 取款
    public void withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
            System.out.println("取款成功！当前余额: " + balance);
        } else {
            System.out.println("取款金额无效或余额不足！");
        }
    }

    // 转账
    public boolean transfer(Account targetAccount, double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
            targetAccount.deposit(amount);
            System.out.println("转账成功！当前余额: " + balance);
            return true;
        } else {
            System.out.println("转账金额无效或余额不足！");
            return false;
        }
    }

    // 显示账户信息
    public void display() {
        System.out.println("账户号: " + accountNumber + ", 姓名: " + name + ", 余额: " + balance);
    }
}
```

**对比C++**：C++版本的构造函数使用 `const std::string&` 避免复制。Java中String本身是不可变的引用类型，传递的是引用，不存在C++中的复制开销问题。

思考：为何Java中不需要像C++那样使用 `const` 修饰参数？

因为Java中所有对象参数传递的都是引用（地址），不会发生对象复制。而 `String` 是不可变类，即使传入方法内部也无法被修改，天然具有"const"的安全性。

### 3.2 定义银行类

Bank类是一个管理类，利用集合来管理所有的用户，控制用户的开户、查找、存款、取款等操作。

```java
import java.util.ArrayList;
import java.util.List;

public class Bank {
    private List<Account> accounts;

    public Bank() {
        this.accounts = new ArrayList<>();
    }

    // 开户
    public void createAccount(String accNumber, String accName, double initialBalance) {
        Account newAccount = new Account(accNumber, accName, initialBalance);
        accounts.add(newAccount);
        System.out.println("开户成功！");
    }

    // 根据账户号查找账户
    public Account findAccount(String accNumber) {
        for (Account account : accounts) {
            if (account.getAccountNumber().equals(accNumber)) {
                return account;
            }
        }
        return null;
    }

    // 存款
    public void deposit(String accNumber, double amount) {
        Account account = findAccount(accNumber);
        if (account != null) {
            account.deposit(amount);
        } else {
            System.out.println("账户不存在！");
        }
    }

    // 取款
    public void withdraw(String accNumber, double amount) {
        Account account = findAccount(accNumber);
        if (account != null) {
            account.withdraw(amount);
        } else {
            System.out.println("账户不存在！");
        }
    }

    // 查询余额
    public void queryBalance(String accNumber) {
        Account account = findAccount(accNumber);
        if (account != null) {
            System.out.println("账户余额: " + account.getBalance());
        } else {
            System.out.println("账户不存在！");
        }
    }

    // 转账
    public void transfer(String fromAccNumber, String toAccNumber, double amount) {
        Account fromAccount = findAccount(fromAccNumber);
        Account toAccount = findAccount(toAccNumber);
        if (fromAccount != null && toAccount != null) {
            fromAccount.transfer(toAccount, amount);
        } else {
            System.out.println("账户不存在！");
        }
    }

    // 显示所有账户
    public void displayAllAccounts() {
        if (accounts.isEmpty()) {
            System.out.println("暂无账户信息");
            return;
        }
        for (Account account : accounts) {
            account.display();
        }
    }

    public List<Account> getAccounts() { return accounts; }
    public void setAccounts(List<Account> accList) { this.accounts = accList; }
}
```

**对比C++**：C++版本中 `findAccount` 返回指针（`Account*`），需要检查空指针。Java版本返回对象引用或 `null`。Java没有指针的概念，但 `null` 检查同样重要，否则会抛出 `NullPointerException`。

思考：为什么Java中不需要区分值语义和指针语义？

因为Java中所有对象变量都是引用，`Account account = findAccount(accNumber)` 获取的就是列表中原对象的引用，通过它调用 `deposit()` 修改的就是原对象。这和C++中必须使用指针才能修改原对象不同。

```java
static void openAccount(Bank bank, Scanner scanner) {
    System.out.print("请输入账户号: ");
    String accNumber = scanner.nextLine();
    // 检查账户号是否已存在
    if (bank.findAccount(accNumber) != null) {

        return;
    }
    System.out.print("请输入姓名: ");
    String name = scanner.nextLine();

    double initialBalance = scanner.nextDouble();
    scanner.nextLine(); // 消耗换行符
    bank.createAccount(accNumber, name, initialBalance);
}
```

**对比C++**：C++中使用 `getline` 读取含空格的字符串，`cin >>` 读取数值。Java中 `scanner.nextLine()` 相当于 `getline`，`scanner.nextDouble()` 相当于 `cin >> double变量`。

### 3.5 数据验证缺失

当前代码没有验证：1.账户号是否已存在（已在3.3中添加）；2.初始余额是否为负数；3.输入格式是否正确

```java
static void openAccount(Bank bank, Scanner scanner) {
    // ... 省略账户号输入
    System.out.print("请输入初始余额: ");
    double initialBalance;
    while (true) {
        try {
            initialBalance = scanner.nextDouble();
            if (initialBalance >= 0) break;
            System.out.print("请输入有效的非负数: ");
        } catch (Exception e) {
            System.out.print("请输入有效的数字: ");
            scanner.next(); // 清除无效输入
        }
    }
    scanner.nextLine(); // 消耗换行符
    bank.createAccount(accNumber, name, initialBalance);
}
```

**对比C++**：C++的错误输入处理使用 `cin.clear()` 和 `cin.ignore()`，Java使用 `try-catch` 捕获异常并用 `scanner.next()` 清除无效输入，Java的异常机制更加规范。

## 05.保存数据文件

### 5.1 保存数据到文件

使用 `BufferedWriter` 将账户数据保存为CSV格式。

```java
import java.io.*;
import java.util.List;

public class FileManager {
    public static void saveToFile(Bank bank, String filename) {
        try (BufferedWriter writer = new BufferedWriter(new FileWriter(filename))) {
            List<Account> accounts = bank.getAccounts();
            for (Account account : accounts) {
                writer.write(account.getAccountNumber() + ","
                        + account.getName() + ","
                        + account.getBalance());
                writer.newLine();
            }
            System.out.println("数据保存成功");
        } catch (IOException e) {
            System.out.println("无法保存文件: " + e.getMessage());
        }
    }
}
```

**对比C++**：C++使用 `ofstream` 并手动调用 `open/close`，需要检查 `is_open()`。Java使用 try-with-resources 语法（`try(resource)`），自动关闭资源，更加安全简洁。这是Java 7引入的特性，相当于C++的RAII。

### 5.2 从文件读取数据

```java
public static void loadFromFile(Bank bank, String filename) {
    try (BufferedReader reader = new BufferedReader(new FileReader(filename))) {
        List<Account> accounts = new java.util.ArrayList<>();
        String line;
        while ((line = reader.readLine()) != null) {
            String[] parts = line.split(",");
            if (parts.length == 3) {
                try {
                    String accNumber = parts[0].trim();
                    String name = parts[1].trim();
                    double balance = Double.parseDouble(parts[2].trim());
                    accounts.add(new Account(accNumber, name, balance));
                    System.out.println("账号: " + accNumber + ", 用户名: " + name + ", 余额: " + balance);
                } catch (NumberFormatException e) {
                    System.err.println("余额解析失败: " + e.getMessage());
                }
            } else {
                System.err.println("解析失败: " + line);
            }
        }
        bank.setAccounts(accounts);
        System.out.println("数据加载成功！");
    } catch (FileNotFoundException e) {
        System.out.println("文件不存在: " + filename);
    } catch (IOException e) {
        System.out.println("无法读取文件: " + e.getMessage());
    }
}
```

**对比C++**：C++版本使用 `istringstream` 解析CSV数据，Java使用 `String.split(",")` 分割字符串，更加简洁直观。Java的异常体系更加完善，可以针对不同异常做不同处理。

### 5.3 存数据潜在问题

1. **数据安全问题**：如果姓名包含逗号，会导致CSV格式错误。可以使用引号包围字段，或使用JSON格式存储。

2. **错误处理**：Java的try-with-resources已经保证了资源的正确关闭，比C++手动close更安全。

3. **编码问题**：Java默认使用UTF-8编码，可以通过 `OutputStreamWriter` 指定编码格式。

```java
try (BufferedWriter writer = new BufferedWriter(
        new OutputStreamWriter(new FileOutputStream(filename), "UTF-8"))) {
    // 写入逻辑
}
```


## 06.项目概括总结

### 6.1 类详细设计

#### 6.1.1 Account 类

**方法**：`deposit`（存款）、`withdraw`（取款）、`transfer`（转账）、`display`（显示信息）

#### 6.1.2 Bank 类

**属性**：`accounts`（`ArrayList<Account>` 存储所有账户）

**方法**：`createAccount`、`findAccount`、`deposit`、`withdraw`、`queryBalance`、`transfer`、`displayAllAccounts`

#### 6.1.3 FileManager 类

**方法**：`saveToFile`（静态方法，保存数据）、`loadFromFile`（静态方法，加载数据）

### 6.2 扩展性设计

- **支持更多账户类型**：可以通过继承 `Account` 类实现不同类型的账户（如储蓄账户 `SavingsAccount`、信用卡账户 `CreditAccount`）。
- **支持更多操作**：可以添加更多功能（如修改账户信息、删除账户、交易记录查询）。
- **支持更多文件格式**：可以使用 `Gson` 或 `Jackson` 库支持JSON格式，或使用JDBC连接数据库。

### 6.3 对比C++实现

| 对比项 | C++版本 | Java版本 |
|--------|---------|---------|
| 容器 | `std::vector<Account>` | `ArrayList<Account>` |
| 查找返回 | `Account*` 指针 | `Account` 引用或null |
| 文件写入 | `ofstream` + 手动open/close | `BufferedWriter` + try-with-resources |
| 文件读取 | `ifstream` + `istringstream` | `BufferedReader` + `String.split()` |
| CSV解析 | `getline(iss, field, ',')` | `line.split(",")` |
| 异常处理 | `try-catch`（较少使用） | `try-catch`（强制使用，checked exception） |
| const保护 | `const std::string&` | 不需要，String不可变 |
| 内存管理 | 手动（栈/堆，需注意生命周期） | 自动GC |
| 参数传递 | 值/引用/指针 | 值（基本类型）/引用（对象） |
