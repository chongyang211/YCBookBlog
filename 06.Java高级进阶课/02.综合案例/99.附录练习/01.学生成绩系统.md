## 01.系统需求

### 1.1 需求介绍

通讯录是一个可以记录亲人、好友信息的工具。本教程主要利用Java来实现一个通讯录管理系统，支持录入、打印、保存、读取、统计、查找、修改、删除联系人信息等功能。

### 1.2 功能要求

代码的主要功能是管理一个通讯录，支持以下操作：

1. **添加联系人**：用户可以输入姓名、性别、年龄、电话和地址，将联系人信息添加到通讯录中。
2. **显示联系人**：显示通讯录中所有联系人的详细信息。
3. **删除联系人**：根据用户输入的姓名，删除指定的联系人。
4. **查找联系人**：根据用户输入的姓名，查找并显示指定联系人的详细信息。
5. **修改联系人**：根据用户输入的姓名，修改指定联系人的信息。
6. **清空联系人**：清空通讯录中的所有联系人。
7. **退出程序**：退出通讯录管理系统。

### 1.3 涉及知识点

1. **类和对象**：使用类定义联系人和通讯录的数据结构，体现面向对象编程思想。
2. **用户输入输出**：使用 `Scanner` 实现与用户的交互。
3. **循环和条件语句**：使用 `while` 循环实现菜单的持续显示和用户选择。使用 `switch-case` 语句根据用户选择调用相应的功能方法。
4. **方法封装**：将每个功能封装成独立的方法，如 `addPerson`、`showPerson`、`deletePerson` 等。
5. **集合框架**：使用 `ArrayList` 动态管理联系人列表，无需像C++那样手动管理数组大小。
6. **字符串处理**：使用 `String` 的 `equals` 方法进行字符串比较（而非C++中的 `==` 运算符）。

### 1.4 核心知识点

1. 提供一个简单易用的联系人管理工具
2. 演示Java基础编程概念的实际应用
3. 展示类、对象、集合、循环、条件判断等核心语法的使用

**对比C++**：C++版本使用结构体和固定数组存储数据，Java版本使用类和 `ArrayList` 动态集合，无需手动管理内存。

### 2.3 主流程开发

系统main方法，while循环在外，系统程序能够持续运行，switch判断语句进行功能选择与方法切换。

思路：根据用户不同的选择，进入不同的功能，可以选择switch分支结构，将整个架构进行搭建。

```java
public static void main(String[] args) {
    AddressBook addressBook = new AddressBook();
    Scanner scanner = new Scanner(System.in);
    while (true) {
        showMenu();
        int select = scanner.nextInt();
        switch (select) {
            case 1:  // 添加联系人
                addressBook.addPerson(scanner);
                break;
            case 2:  // 显示联系人
                addressBook.showPerson();
                break;
            case 3:  // 删除联系人
                addressBook.deletePerson(scanner);
                break;
            case 4:  // 查找联系人
                addressBook.findPerson(scanner);
                break;
            case 5:  // 修改联系人
                addressBook.modifyPerson(scanner);
                break;
            case 6:  // 清空联系人
                addressBook.cleanPerson();
                break;
            case 0:  // 退出通讯录
                System.out.println("欢迎下次使用");
                scanner.close();
                return;
            default:
                break;
        }
    }
}
```

**对比C++**：C++使用 `cin >> select` 读取输入，Java使用 `Scanner.nextInt()`。Java无需手动暂停控制台（不需要 `system("pause")`）。

### 4.1 设计联系人类

联系人信息包括：姓名、性别、年龄、联系电话、家庭住址

`Person` 类用于存储单个联系人的信息。设计如下：

```java
public class Person {
    private String name;    // 姓名
    private int sex;        // 性别：1-男 2-女
    private int age;        // 年龄
    private String phone;   // 电话
    private String address; // 地址

    public Person(String name, int sex, int age, String phone, String address) {
        this.name = name;
        this.sex = sex;
        this.age = age;
        this.phone = phone;
        this.address = address;
    }

    // getter和setter方法
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public int getSex() { return sex; }
    public void setSex(int sex) { this.sex = sex; }
    public int getAge() { return age; }
    public void setAge(int age) { this.age = age; }
    public String getPhone() { return phone; }
    public void setPhone(String phone) { this.phone = phone; }
    public String getAddress() { return address; }
    public void setAddress(String address) { this.address = address; }
}
```

**对比C++**：C++版本使用 `struct`（默认public），Java使用 `class`（默认private）并提供getter/setter。Java的封装性更好，但代码量更多。可以使用Lombok等工具简化。

### 4.2 设计通讯录类

**对比C++**：C++版本使用固定大小数组（`Person personArray[100]`）和 `size` 变量手动管理。Java版本使用 `ArrayList`，自动扩容，无需关心容量限制。

### 4.4 添加联系人方法

思路：通过Scanner获取用户输入的各项信息，创建Person对象后添加到列表中。

```java
public void addPerson(Scanner scanner) {
    System.out.println("请输入姓名：");
    String name = scanner.next();

    System.out.println("请输入性别（1-男 2-女）：");
    int sex;
    while (true) {
        sex = scanner.nextInt();
        if (sex == 1 || sex == 2) {
            break;
        }
        System.out.println("输入性别有误，请重新输入");
    }

    System.out.println("请输入年龄：");
    int age = scanner.nextInt();

    System.out.println("请输入电话：");
    String phone = scanner.next();

    System.out.println("请输入家庭地址：");
    String address = scanner.next();

    Person person = new Person(name, sex, age, phone, address);
    personList.add(person);
    System.out.println("添加用户：" + name + " 成功。用户列表size是：" + personList.size());
}
```

**对比C++**：C++通过指针操作结构体数组 `abs->personArray[abs->size]`，Java直接调用 `list.add()`，代码更简洁，无需手动管理索引。

## 06.删除联系人

功能描述：按照姓名进行删除指定联系人

删除联系人实现步骤：1.封装检测联系人是否存在；2.封装删除联系人方法；3.测试删除联系人功能

### 6.1 联系人是否存在

设计思路：删除联系人前，我们需要先判断用户输入的联系人是否存在，如果存在删除，不存在提示用户没有要删除的联系人

因此我们可以把检测联系人是否存在封装成一个方法，如果存在，返回联系人在列表中的位置，不存在返回-1

```java
private int isExist(String name) {
    for (int i = 0; i < personList.size(); i++) {
        if (personList.get(i).getName().equals(name)) {
            return i;
        }
    }
    return -1;
}
```

**对比C++**：C++使用 `==` 比较字符串（`std::string` 重载了运算符），Java中字符串比较必须使用 `equals()` 方法，不能用 `==`（`==` 比较的是引用地址）。

### 6.2 删除联系人方法

根据用户输入的联系人判断该通讯录中是否有此人。查找到进行删除，并提示删除成功。查不到提示查无此人。

```java
public void deletePerson(Scanner scanner) {
    System.out.println("请输入您要删除的联系人：");
    String name = scanner.next();
    int index = isExist(name);
    if (index == -1) {
        System.out.println("查无此人");
        return;
    }
    personList.remove(index);
    System.out.println("删除成功");
}
```

**对比C++**：C++删除元素需要手动将后续元素前移并减少size，Java的 `ArrayList.remove()` 自动处理所有这些操作，代码更简洁，也不会出现数组越界问题。

### 8.1 修改联系人方法

实现思路：查找用户输入的联系人，如果查找成功进行修改操作，查找失败提示查无此人

```java
public void modifyPerson(Scanner scanner) {
    System.out.println("请输入您要修改的联系人的姓名：");
    String name = scanner.next();
    int index = isExist(name);
    if (index == -1) {
        System.out.println("查无此人");
        return;
    }
    Person person = personList.get(index);

    System.out.println("请输入新姓名：");
    person.setName(scanner.next());

    System.out.println("请输入性别（1-男 2-女）：");
    int sex;
    while (true) {
        sex = scanner.nextInt();
        if (sex == 1 || sex == 2) {
            person.setSex(sex);
            break;
        }
        System.out.println("输入性别有误，请重新输入");
    }

    System.out.println("请输入年龄：");
    person.setAge(scanner.nextInt());

    System.out.println("请输入电话：");
    person.setPhone(scanner.next());

    System.out.println("请输入家庭地址：");
    person.setAddress(scanner.next());

    System.out.println("修改成功");
}
```

**对比C++**：C++版本中修改联系人通过指针直接访问和修改结构体成员。Java版本通过 `get()` 获取对象引用后直接调用setter方法修改。由于Java的引用语义，修改的就是列表中的原对象，无需像C++那样区分值语义和指针语义。

## 10.项目总结分析

### 10.1 代码整体结构

代码分为以下几个部分：

**主类 `AddressBookApp`**：程序的入口，包含 `main` 方法和 `showMenu` 方法。

**`Person` 类**：联系人实体类，封装了联系人的属性和getter/setter方法。

**`AddressBook` 类**：通讯录管理类，封装了所有操作方法：

- `addPerson`：添加联系人。
- `showPerson`：显示所有联系人。
- `deletePerson`：删除联系人。
- `findPerson`：查找联系人。
- `modifyPerson`：修改联系人。
- `cleanPerson`：清空联系人。
- `isExist`：检查联系人是否存在（私有方法）。

### 10.2 代码核心原理

1. **菜单驱动**：通过 `showMenu` 方法显示菜单，用户输入选项后，`switch` 语句根据输入调用相应的功能方法。
2. **联系人管理**：
   - 联系人信息存储在 `ArrayList<Person>` 中，无需手动管理容量。
   - 添加联系人时，创建 `Person` 对象并调用 `list.add()`。
   - 删除联系人时，调用 `list.remove(index)` 即可，底层自动处理元素移动。
   - 查找和修改联系人时，通过遍历列表找到指定联系人。

### 10.3 代码优缺点

**优点**

- **功能完整**：实现了通讯录的基本功能，包括添加、显示、删除、查找、修改和清空。
- **结构清晰**：代码模块化，使用面向对象设计，易于理解和维护。
- **自动内存管理**：使用Java的垃圾回收机制，无需手动释放内存，不会出现C++中的内存泄漏问题。
- **动态扩容**：使用 `ArrayList`，联系人数量不受固定限制。

**缺点**

- **数据存储**：联系人信息存储在内存中，程序退出后数据会丢失。可以考虑使用文件或数据库持久化存储。
- **输入验证不足**：对用户输入的验证不够严格，例如电话号码和地址的格式未做检查。
- **单线程**：系统为单线程运行，无法同时处理多个用户请求。

### 10.4 一些改进建议

1. **数据持久化**：将联系人信息保存到文件或数据库中，确保程序退出后数据不丢失。可以使用Java的序列化或JSON格式。
2. **输入验证**：对用户输入进行更严格的验证，例如检查电话号码是否为数字、地址是否合法等。使用正则表达式进行格式校验。
3. **使用泛型和Stream**：使用Java 8的Stream API简化查找和过滤操作。
4. **异常处理**：添加try-catch处理输入异常，防止用户输入非数字导致程序崩溃。


## 11.项目技术思考

### 11.1 为何要用类封装

这个核心数据AddressBook和Person为何要用类封装，用类封装的好处是什么？

> **1. 使用类封装的好处**

- **(1) 数据封装**：类可以将多个相关的数据成员封装在一起，并通过访问修饰符控制访问权限。例如，`Person` 类将姓名、性别、年龄、电话和地址封装在一起，通过private修饰保护数据安全。
- **(2) 行为绑定**：类不仅可以封装数据，还可以封装操作数据的方法。例如 `AddressBook` 将联系人列表和增删改查操作绑定在一起。
- **(3) 代码复用**：通过继承和组合，可以方便地复用已有代码。
- **(4) 易于扩展**：如果未来需要为 `Person` 添加新的字段（例如邮箱、备注等），只需在类中添加新属性和对应的getter/setter。
- **(5) 类型安全**：Java是强类型语言，类的使用可以在编译期发现类型错误。

### 11.2 对比C++实现

| 对比项 | C++版本 | Java版本 |
|--------|---------|---------|
| 数据结构 | 结构体（struct） | 类（class）+ getter/setter |
| 存储容器 | 固定大小数组（100） | ArrayList（动态扩容） |
| 内存管理 | 手动管理（指针、size） | 自动GC |
| 字符串比较 | `==`（运算符重载） | `equals()` 方法 |
| 用户输入 | `cin >>` | `Scanner.nextInt()` / `Scanner.next()` |
| 删除操作 | 手动移动数组元素 | `list.remove()` 自动处理 |
| 清空操作 | 逻辑清空（size=0） | `list.clear()` 彻底清空 |
| 参数传递 | 指针传递（`AddressBooks *abs`） | 引用传递（Java天然引用语义） |
| 暂停功能 | `system("pause")` / `cin.get()` | 无需暂停 |

Java版本在代码简洁性、内存安全性和可维护性上有明显优势，而C++版本更接近底层，能更好地理解内存管理的本质。
