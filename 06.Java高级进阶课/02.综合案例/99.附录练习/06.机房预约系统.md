## 01.预约系统需求

### 1.1 系统简介

学校现有几个规格不同的机房，由于使用时经常出现"撞车"现象，现开发一套机房预约系统，解决这一问题。

### 1.2 身份简介

分别有三种身份使用该程序

* **学生代表**：申请使用机房
* **教师**：审核学生的预约申请
* **管理员**：给学生、教师创建账号

### 1.3 机房简介

机房总共有3间

* 1号机房 --- 最大容量20人
* 2号机房 --- 最多容量50人
* 3号机房 --- 最多容量100人

### 1.4 申请简介

* 申请的订单每周由管理员负责清空
* 学生可以预约未来一周内的机房使用，预约的日期为周一至周五，预约时需要选择预约时段（上午、下午）
* 教师来审核预约，依据实际情况审核预约通过或者不通过

### 1.5 系统具体需求

* 首先进入登录界面，可选登录身份有：学生代表、老师、管理员、退出
* 每个身份都需要进行验证后，进入子菜单
* 学生具体功能：申请预约、查看自身预约、查看所有预约、取消预约、注销登录
* 教师具体功能：查看所有预约、审核预约、注销登录
* 管理员具体功能：添加账号、查看账号、查看机房信息、清空预约记录、注销登录

## 04.创建身份类

### 4.1 身份的基类

在整个系统中，有三种身份，分别为：学生代表、老师以及管理员。三种身份有其共性也有其特性，因此我们可以将三种身份抽象出一个身份基类**Identity**。

```java
public abstract class Identity {
    protected String name;
    protected String pwd;

    // 操作菜单 - 抽象方法
    public abstract void openMenu();

    public String getName() { return name; }
    public String getPwd() { return pwd; }
}
```

对比C++：C++使用`virtual void openMenu() = 0;`声明纯虚函数，Java使用`abstract`关键字。Java不需要虚析构函数。

        System.out.println("请输入预约日期（1-5，代表周一至周五）：");
        int day = scanner.nextInt();
        System.out.println("请输入预约时段（1-上午，2-下午）：");
        int period = scanner.nextInt();
        System.out.println("请输入预约机房（1-3）：");
        int room = scanner.nextInt();
        // 写入预约文件
        try (BufferedWriter bw = new BufferedWriter(
                new FileWriter("order.txt", true))) {
            // 格式：学号,姓名,日期,时段,机房,状态(1-审核中,2-通过,-1-未通过,0-取消)
            bw.write(id + "," + name + "," + day + "," + period + "," + room + ",1");
            bw.newLine();
            System.out.println("预约成功，审核中！");
        } catch (IOException e) {
            System.out.println("预约失败：" + e.getMessage());
        }
    }

    // 查看我的预约
    public void showMyOrder() {
        try (BufferedReader br = new BufferedReader(new FileReader("order.txt"))) {
            String line;
            boolean found = false;
            while ((line = br.readLine()) != null) {
                String[] parts = line.split(",");
                if (parts.length >= 6 && Integer.parseInt(parts[0]) == id) {
                    found = true;
                    String status = getStatusText(Integer.parseInt(parts[5]));
                    System.out.println("日期：周" + parts[2] +

                            " 机房：" + parts[4] + "号 状态：" + status);
                }
            }
            if (!found) {
                System.out.println("暂无预约记录");
            }
        } catch (FileNotFoundException e) {
            System.out.println("暂无预约记录");
        } catch (IOException e) {
            System.out.println("读取预约失败：" + e.getMessage());
        }
    }

    private String getStatusText(int status) {
        switch (status) {
            case 1: return "审核中";
            case 2: return "已通过";
            case -1: return "未通过";
            case 0: return "已取消";
            default: return "未知";
        }
    }

    // 查看所有预约
    public void showAllOrder() {

    public void cancelOrder(Scanner scanner) {
        System.out.println("请输入要取消的预约序号：");
        showMyOrder();
        // 简化处理：将状态改为0
        OrderUtil.cancelOrder(id, scanner);
    }
}

```java
public static void loginIn(Scanner scanner, String fileName, int type) {
    int id = 0;
    if (type == 1) {
        System.out.println("请输入你的学号：");
        id = scanner.nextInt();
    } else if (type == 2) {
        System.out.println("请输入你的职工号：");
        id = scanner.nextInt();
    }
    System.out.println("请输入用户名：");
    String name = scanner.next();
    System.out.println("请输入密码：");
    String pwd = scanner.next();

    // 从文件验证
    try (BufferedReader br = new BufferedReader(new FileReader(fileName))) {
        String line;
        while ((line = br.readLine()) != null) {
            String[] parts = line.trim().split(" ");
            if (type == 1 && parts.length >= 3) {
                // 学生验证：学号 姓名 密码
                if (Integer.parseInt(parts[0]) == id &&
                        parts[1].equals(name) && parts[2].equals(pwd)) {
                    System.out.println("学生验证登录成功!");
                    Identity person = new Student(id, name, pwd);
                    studentMenu(scanner, (Student) person);
                    return;
                }
            } else if (type == 2 && parts.length >= 3) {
                // 教师验证
                if (Integer.parseInt(parts[0]) == id &&
                        parts[1].equals(name) && parts[2].equals(pwd)) {
                    System.out.println("教师验证登录成功!");
                    Identity person = new Teacher(id, name, pwd);
                    teacherMenu(scanner, (Teacher) person);
                    return;
                }
            } else if (type == 3 && parts.length >= 2) {
                // 管理员验证
                if (parts[0].equals(name) && parts[1].equals(pwd)) {
                    System.out.println("管理员验证登录成功!");
                    Identity person = new Admin(name, pwd);
                    adminMenu(scanner, (Admin) person);
                    return;
                }
            }
        }
    } catch (FileNotFoundException e) {
        System.out.println("文件不存在！");
        return;
    } catch (IOException e) {
        System.out.println("读取文件失败：" + e.getMessage());
        return;
    }
    System.out.println("验证登录失败!");
}
```

public static boolean checkRepeat(int id, int type) {
    String fileName = (type == 1) ? GlobalFile.STUDENT_FILE : GlobalFile.TEACHER_FILE;
    try (BufferedReader br = new BufferedReader(new FileReader(fileName))) {
        String line;
        while ((line = br.readLine()) != null) {
            String[] parts = line.trim().split(" ");
            if (parts.length >= 1 && Integer.parseInt(parts[0]) == id) {
                return true;
            }
        }
    } catch (FileNotFoundException e) {
        return false;
    } catch (IOException e) {
        return false;
    }
    return false;
}

### 7.4 取消预约

```java
public static void cancelOrder(int studentId, Scanner scanner) {
    // 读取所有预约，修改对应状态
    ArrayList<String> lines = new ArrayList<>();
    try (BufferedReader br = new BufferedReader(
            new FileReader(GlobalFile.ORDER_FILE))) {
        String line;
        while ((line = br.readLine()) != null) {
            lines.add(line);
        }
    } catch (IOException e) {
        System.out.println("读取失败");
        return;
    }
    System.out.println("请输入要取消的序号：");
    int index = scanner.nextInt() - 1;
    // 找到该学生的预约并取消
    int count = 0;
    for (int i = 0; i < lines.size(); i++) {
        String[] parts = lines.get(i).split(",");
        if (parts.length >= 6 && Integer.parseInt(parts[0].trim()) == studentId) {
            if (count == index) {
                parts[5] = "0";
                lines.set(i, String.join(",", parts));
                break;
            }
            count++;
        }
    }
    // 写回文件
    try (BufferedWriter bw = new BufferedWriter(
            new FileWriter(GlobalFile.ORDER_FILE))) {
        for (String l : lines) {
            bw.write(l);
            bw.newLine();
        }
        System.out.println("取消成功！");
    } catch (IOException e) {
        System.out.println("取消失败：" + e.getMessage());
    }
}
```

    System.out.println("请输入要审核的预约序号：");
    int index = scanner.nextInt() - 1;
    System.out.println("请输入审核结果（2-通过，-1-不通过）：");
    int result = scanner.nextInt();

    ArrayList<String> lines = new ArrayList<>();
    try (BufferedReader br = new BufferedReader(
            new FileReader(GlobalFile.ORDER_FILE))) {
        String line;
        while ((line = br.readLine()) != null) {
            lines.add(line);
        }
    } catch (IOException e) {
        System.out.println("读取失败");
        return;
    }
    if (index >= 0 && index < lines.size()) {
        String[] parts = lines.get(index).split(",");
        if (parts.length >= 6) {
            parts[5] = String.valueOf(result);
            lines.set(index, String.join(",", parts));
        }
    }
    try (BufferedWriter bw = new BufferedWriter(
            new FileWriter(GlobalFile.ORDER_FILE))) {
        for (String l : lines) {
            bw.write(l);
            bw.newLine();
        }
        System.out.println("审核完成！");
    } catch (IOException e) {
        System.out.println("审核失败：" + e.getMessage());
    }
}
