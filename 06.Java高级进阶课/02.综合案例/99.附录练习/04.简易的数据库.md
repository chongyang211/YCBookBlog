## 1. 数据库系统需求

### 1.1 需求介绍

本项目旨在使用Java实现一个简易的内存数据库系统，帮助学习者理解数据库的基本原理和操作。

该系统支持基本的数据库操作，包括表的创建、数据的增删改查，以及数据的持久化存储。

### 1.2 功能介绍

- **表管理**：支持创建数据表，定义表结构
- **数据操作**：支持插入、删除、更新和查询数据
- **数据类型**：支持整型(int)、浮点型(double)、字符串(String)三种基本数据类型
- **持久化**：支持将数据保存到文件和从文件加载数据
- **类型安全**：使用枚举和Object类型，比C++的void*更安全

### 1.3 核心功能模块

1. **数据结构模块**：定义列、行、表、数据库等核心数据结构
2. **表操作模块**：实现表的创建和管理
3. **数据操作模块**：实现数据的增删改查功能
4. **文件操作模块**：实现数据的持久化存储

### 1.4 功能分析

- **简单易用**：提供直观的API接口，便于理解和使用
- **类型安全**：使用枚举和`Object`类型代替C++的`void*`指针
- **自动内存管理**：Java GC自动管理内存生命周期
- **可扩展性**：模块化设计，便于功能扩展

## 2. 设计核心思路

### 2.1 核心目标

- 实现一个功能完整的简易数据库系统
- 展示面向对象编程在数据库设计中的应用
- 演示Java集合框架和文件I/O操作
- 对比C++实现，体现Java的简洁性和安全性

### 2.2 设计原则

- **单一职责原则**：每个类只负责一个特定的功能
- **封装原则**：隐藏内部实现细节，提供清晰的接口
- **类型安全原则**：使用强类型系统避免类型错误

### 2.3 技术选型

- **编程语言**：Java
- **数据存储**：内存存储 + CSV文件持久化
- **容器类型**：ArrayList
- **文件操作**：BufferedWriter / BufferedReader

### 2.4 主菜单设计

```text
数据库操作菜单：
1. 创建表 (createTable)
2. 插入数据 (insertRow)
3. 删除数据 (deleteRow)
4. 更新数据 (updateRow)
5. 查询表 (queryTable)

```

## 3. 定义数据结构

### 3.1 数据类型枚举

```java
public enum DataType {
    TYPE_INT,       // 整型
    TYPE_DOUBLE,    // 浮点型
    TYPE_STRING     // 字符串型
}
```

对比C++：C++使用`enum DataType { TYPE_INT, TYPE_FLOAT, TYPE_STRING };`，Java使用`enum`类，更加类型安全，可以附带方法。

### 3.2 列定义类

```java
public class Column {
    private String name;    // 列名
    private DataType type;  // 数据类型

    public Column(String name, DataType type) {
        this.name = name;
        this.type = type;
    }

    public String getName() { return name; }
    public DataType getType() { return type; }
}
```

### 3.3 行数据类

```java
import java.util.ArrayList;

public class Row {
    private ArrayList<Object> data;         // 存储实际数据
    private ArrayList<DataType> columnTypes; // 存储每列的数据类型

    public Row() {
        data = new ArrayList<>();
        columnTypes = new ArrayList<>();
    }

    public void addValue(Object value, DataType type) {
        data.add(value);
        columnTypes.add(type);
    }

    public Object getValue(int index) {
        return data.get(index);
    }

    public void setValue(int index, Object value) {
        data.set(index, value);
    }

    public int size() {
        return data.size();
    }
}
```

**对比C++设计说明**：

| 对比项 | C++ | Java |
|-------|-----|------|
| 数据存储 | `std::vector<void*>` | `ArrayList<Object>` |
| 类型转换 | `static_cast<int*>(data[i])` | 自动装箱/拆箱 |
| 内存释放 | 析构函数中手动`delete`每个指针 | GC自动回收 |
| 类型安全 | `void*`缺乏编译时类型检查 | `Object`支持运行时类型检查 |

Java使用`Object`代替C++的`void*`指针，利用自动装箱（Autoboxing）将基本类型封装为对象，避免了C++中手动`new/delete`和`static_cast`的风险。

### 3.4 表结构类

```java
import java.util.ArrayList;

public class Table {
    private String name;                // 表名
    private ArrayList<Column> columns;  // 列定义
    private ArrayList<Row> rows;        // 行数据

    public Table(String name) {
        this.name = name;
        this.columns = new ArrayList<>();
        this.rows = new ArrayList<>();
    }

    public String getName() { return name; }
    public ArrayList<Column> getColumns() { return columns; }
    public ArrayList<Row> getRows() { return rows; }

    public void addColumn(Column column) {
        columns.add(column);
    }

    public void addRow(Row row) {
        rows.add(row);
    }

    public void removeRow(int index) {
        if (index >= 0 && index < rows.size()) {
            rows.remove(index);
        }
    }
}
```

对比C++：C++中`Table`的析构函数需要遍历释放所有`Row*`指针，Java完全不需要。

### 3.5 数据库类

```java
import java.util.ArrayList;

public class Database {
    private ArrayList<Table> tables;

    public Database() {
        tables = new ArrayList<>();
    }

    public ArrayList<Table> getTables() { return tables; }

    // 根据表名查找表
    public Table findTable(String tableName) {
        for (Table table : tables) {
            if (table.getName().equals(tableName)) {
                return table;
            }
        }
        return null;
    }
}
```

层次结构：

```text
Database (数据库层)
  └── Table (表层)
      ├── Column (列定义层)
      └── Row (数据行层)
```

## 4. 核心功能实现

### 4.1 创建表

```java
public void createTable(String tableName, ArrayList<Column> columns) {
    Table table = new Table(tableName);
    for (Column col : columns) {
        table.addColumn(col);
    }
    tables.add(table);
    System.out.println("表 '" + tableName + "' 创建成功！");
}
```

测试创建表：

```java
Database db = new Database();
ArrayList<Column> columns = new ArrayList<>();
columns.add(new Column("ID", DataType.TYPE_INT));
columns.add(new Column("Name", DataType.TYPE_STRING));
columns.add(new Column("Age", DataType.TYPE_INT));
db.createTable("Users", columns);
```

### 4.2 插入行数据

```java
public void insertRow(String tableName, Object... values) {
    Table table = findTable(tableName);
    if (table == null) {
        System.out.println("表 '" + tableName + "' 不存在！");
        return;
    }
    if (values.length != table.getColumns().size()) {
        System.out.println("数据列数与表结构不匹配！");
        return;
    }
    Row row = new Row();
    for (int i = 0; i < table.getColumns().size(); i++) {
        row.addValue(values[i], table.getColumns().get(i).getType());
    }
    table.addRow(row);
    System.out.println("行插入成功！");
}
```

对比C++：C++使用`std::vector<void*>`传递数据，每个元素需要`new int(...)`、`new std::string(...)`手动分配内存。Java使用可变参数`Object...`，基本类型自动装箱，无需手动内存管理。

### 4.3 打印数据

```java
public void printDatabase() {
    if (tables.isEmpty()) {
        System.out.println("数据库为空，没有任何表。");
        return;
    }
    System.out.println("=== 数据库内容 ===");
    System.out.println("共有 " + tables.size() + " 个表：\n");
    for (Table table : tables) {
        System.out.println("表名: " + table.getName());
        // 打印表结构
        System.out.print("列结构: ");
        ArrayList<Column> cols = table.getColumns();
        for (int i = 0; i < cols.size(); i++) {
            System.out.print(cols.get(i).getName() + "(" + cols.get(i).getType() + ")");
            if (i < cols.size() - 1) System.out.print(", ");
        }
        System.out.println();
        System.out.println("数据行数: " + table.getRows().size());
        // 打印数据
        if (!table.getRows().isEmpty()) {
            System.out.println("数据内容:");
            for (Column col : cols) {
                System.out.print(col.getName() + "\t");
            }
            System.out.println();
            for (Column col : cols) {
                System.out.print("--------\t");
            }
            System.out.println();
            for (Row row : table.getRows()) {
                for (int i = 0; i < cols.size(); i++) {
                    System.out.print(row.getValue(i) + "\t");
                }
                System.out.println();
            }
        } else {
            System.out.println("表为空，没有数据。");
        }
        System.out.println("\n------------------------\n");
    }
}
```

对比C++：C++打印数据时需要根据类型做`switch`和`static_cast`转换（如`*(int*)row->data[k]`），Java中`Object`的`toString()`方法会自动处理输出格式。

### 4.4 删除行数据

```java
public void deleteRow(String tableName, int rowIndex) {
    Table table = findTable(tableName);
    if (table == null) {
        System.out.println("表 '" + tableName + "' 不存在！");
        return;
    }
    if (rowIndex >= 0 && rowIndex < table.getRows().size()) {
        table.removeRow(rowIndex);
        System.out.println("行删除成功！");
    } else {
        System.out.println("行索引无效！");
    }
}
```

对比C++：C++需要先`delete rows[rowIndex]`释放内存，再`erase`从容器中移除。Java直接`remove`即可。

### 4.5 更新行数据

```java
public void updateRow(String tableName, int rowIndex, Object... values) {
    Table table = findTable(tableName);
    if (table == null) {
        System.out.println("表 '" + tableName + "' 不存在！");
        return;
    }
    if (rowIndex < 0 || rowIndex >= table.getRows().size()) {
        System.out.println("行索引无效！");
        return;
    }
    Row row = table.getRows().get(rowIndex);
    for (int i = 0; i < table.getColumns().size() && i < values.length; i++) {
        row.setValue(i, values[i]);
    }
    System.out.println("行更新成功！");
}
```

对比C++：C++更新时需要通过`switch`判断类型并做指针转换赋值（如`*(int*)row->data[j] = *(int*)data[j]`），Java直接`setValue`即可。

### 4.6 查询表操作

```java
public void queryTable(String tableName) {
    Table table = findTable(tableName);
    if (table == null) {
        System.out.println("表 '" + tableName + "' 不存在！");
        return;
    }
    System.out.println("表 '" + tableName + "' 数据：");
    // 打印列标题
    for (Column col : table.getColumns()) {
        System.out.print(col.getName() + "\t");
    }
    System.out.println();
    // 打印每行数据
    for (Row row : table.getRows()) {
        for (int i = 0; i < table.getColumns().size(); i++) {
            System.out.print(row.getValue(i) + "\t");
        }
        System.out.println();
    }
}
```

## 5. 文件File操作

### 5.1 保存数据到文件

```java
import java.io.*;

public void saveToFile(String filename) {
    try (BufferedWriter bw = new BufferedWriter(new FileWriter(filename))) {
        // 保存表的数量
        bw.write(String.valueOf(tables.size()));
        bw.newLine();
        for (Table table : tables) {
            // 保存表名
            bw.write(table.getName());
            bw.newLine();
            // 保存列信息
            ArrayList<Column> cols = table.getColumns();
            bw.write(String.valueOf(cols.size()));
            bw.newLine();
            for (Column col : cols) {
                bw.write(col.getName() + "," + col.getType().name());
                bw.newLine();
            }
            // 保存行数据
            ArrayList<Row> rows = table.getRows();
            bw.write(String.valueOf(rows.size()));
            bw.newLine();
            for (Row row : rows) {
                StringBuilder sb = new StringBuilder();
                for (int i = 0; i < cols.size(); i++) {
                    if (i > 0) sb.append(",");
                    sb.append(row.getValue(i).toString());
                }
                bw.write(sb.toString());
                bw.newLine();
            }
        }
        System.out.println("数据库保存成功！");
    } catch (IOException e) {
        System.out.println("保存文件失败：" + e.getMessage());
    }
}
```

对比C++：C++使用二进制格式保存（`ios::binary`），需要手动处理字符串长度、指针转换（如`file.write((char*)&value, sizeof(int))`）。Java使用文本格式保存，代码更简洁、可读性更好。

### 5.2 从文件加载数据

```java
public void loadFromFile(String filename) {
    File file = new File(filename);
    if (!file.exists()) {
        System.out.println("文件 '" + filename + "' 不存在！");
        return;
    }
    try (BufferedReader br = new BufferedReader(new FileReader(filename))) {
        int tableCount = Integer.parseInt(br.readLine().trim());
        for (int i = 0; i < tableCount; i++) {
            String tableName = br.readLine().trim();
            int colCount = Integer.parseInt(br.readLine().trim());
            ArrayList<Column> columns = new ArrayList<>();
            for (int j = 0; j < colCount; j++) {
                String[] parts = br.readLine().trim().split(",");
                columns.add(new Column(parts[0], DataType.valueOf(parts[1])));
            }
            createTable(tableName, columns);
            Table table = findTable(tableName);
            int rowCount = Integer.parseInt(br.readLine().trim());
            for (int j = 0; j < rowCount; j++) {
                String[] values = br.readLine().trim().split(",");
                Row row = new Row();
                for (int k = 0; k < columns.size(); k++) {
                    switch (columns.get(k).getType()) {
                        case TYPE_INT:
                            row.addValue(Integer.parseInt(values[k]), DataType.TYPE_INT);
                            break;
                        case TYPE_DOUBLE:
                            row.addValue(Double.parseDouble(values[k]), DataType.TYPE_DOUBLE);
                            break;
                        case TYPE_STRING:
                            row.addValue(values[k], DataType.TYPE_STRING);
                            break;
                    }
                }
                table.addRow(row);
            }
        }
        System.out.println("数据库加载成功！");
    } catch (IOException e) {
        System.out.println("加载文件失败：" + e.getMessage());
    }
}
```

## 6. 拓展延伸

### 6.1 示例运行流程

```java
public static void main(String[] args) {
    Database db = new Database();

    // 1. 创建表
    ArrayList<Column> columns = new ArrayList<>();
    columns.add(new Column("ID", DataType.TYPE_INT));
    columns.add(new Column("Name", DataType.TYPE_STRING));
    columns.add(new Column("Age", DataType.TYPE_INT));
    db.createTable("Users", columns);

    // 2. 插入数据
    db.insertRow("Users", 1, "Alice", 25);
    db.insertRow("Users", 2, "Bob", 30);

    // 3. 查询表
    db.queryTable("Users");

    // 4. 更新数据
    db.updateRow("Users", 0, 1, "Alice", 26);

    // 5. 保存到文件
    db.saveToFile("database.txt");

    // 6. 从文件加载
    Database newDb = new Database();
    newDb.loadFromFile("database.txt");
    newDb.queryTable("Users");
}
```

## 7. 项目总结

### 7.1 对比C++实现

| 对比项 | C++ | Java |
|-------|-----|------|
| 数据存储 | `void*`指针 + 手动类型转换 | `Object`类 + 自动装箱 |
| 类型转换 | `static_cast<int*>(data[i])` | 自动装箱拆箱 |
| 内存管理 | 析构函数手动`delete`每个指针 | GC自动回收 |
| 文件格式 | 二进制格式`ios::binary` | 文本CSV格式 |
| 文件操作 | `fstream` + `write/read` | `BufferedWriter/Reader` |
| 遍历循环 | `size_t` + 索引遍历 | 增强for循环 |
| 容器 | `std::vector<T*>`指针容器 | `ArrayList<T>`对象容器 |
| 字符串处理 | `char* + new/delete[]` | `String`不可变对象 |
| 枚举 | `enum`普通枚举 | `enum`类枚举 |
| 错误处理 | 返回值检查 | try-catch异常处理 |
