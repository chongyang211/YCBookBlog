# 04.JSON 序列化器与内存数据库（骨架版）

> 入门教程第 14-15 章的"现代 Java 大考"。从 03 的"手写 setXxx 一百遍" 进化到**反射 + 注解自动映射**——`@JsonField` 注解扫描 + `Class.forName` + `Field.set` 实现"零反射框架"。配套**手写 JSON 解析器**（递归下降）+ **泛型 Repository<T>**。

## 05.延伸挑战（3 题）

- 基础：支持 JSON5（注释 / 单引号 / 尾逗号）
