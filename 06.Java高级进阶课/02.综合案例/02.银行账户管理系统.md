# 02.银行账户管理系统（骨架版）

> 入门教程第 7-12 章的"OOP 大考案例"。从 01 的"过程式 Java"进化到 OOP——`class` 封装 + **多态三态**（普通 / VIP / 储蓄账户）+ **自定义异常体系** + CSV 文件持久化。
>
> 📍 **当前文档为骨架版**，详细内容将在后续轮次扩写至 ~70 KB 完整教学文档。

## 01.教学目标

| 章节 | 知识点 | 在本案例的落地点 |
|---|---|---|
| 第 7 章 | 类定义 / 字段 / 构造方法 | `Account` / `VipAccount` / `SavingsAccount` 三类 |
| 第 7 章 | `private` + getter/setter（封装）| 余额 `balance` 私有 + `getBalance()` 公开 |
| 第 7 章 | 构造方法重载 + `this(...)` | `Account(String id, String name)` / `Account(String id, String name, double initBalance)` |
| 第 7 章 | `static` 工厂 + `static int totalAccounts` | `Account.createNew(...)` 自动生成 ID |
| 第 8 章 | `extends` 单继承 | `VipAccount extends Account` / `SavingsAccount extends Account` |
| 第 8 章 | `@Override` + 方法重写 | 三态各自重写 `withdraw()` 实现"取款"差异化逻辑 |
| 第 8 章 | `super(...)` 调父类构造 | VIP 子类构造方法 |
| 第 8 章 | 向上 / 向下转型 + `instanceof` | `Account a = new VipAccount(...)`; `if (a instanceof VipAccount v) v.useVipBenefit()` |
| 第 9 章 | `abstract class` + 抽象方法 | `Account` 改抽象类、`calcInterest()` 抽象方法 |
| 第 9 章 | `interface` + `default` 方法 | `Persistable` 接口（`toCsv()` / `fromCsv(line)`）|
| 第 10 章 | 自定义异常 + 异常体系 | `BankException` 基类 + `InsufficientFundsException` / `AccountNotFoundException` / `InvalidAmountException` |
| 第 10 章 | try-with-resources | 读写 CSV 用 `try (var br = Files.newBufferedReader(...))` |
| 第 12 章 | `Files` / `BufferedReader` / `BufferedWriter` | CSV 持久化 |
