## 01.管理系统需求

### 1.1 需求介绍

职工管理系统可以用来管理公司内所有员工的信息，本教程主要利用Java来实现一个基于多态的职工管理系统。

公司中职工分为三类：普通员工、经理、老板，显示信息时，需要显示职工编号、职工姓名、职工岗位、以及职责。

1. 普通员工职责：完成经理交给的任务
2. 经理职责：完成老板交给的任务，并下发任务给员工
3. 老板职责：管理公司所有事务

### 1.2 功能介绍

管理系统中需要实现的功能如下：

* 退出管理程序：退出当前管理系统
- 增加职工信息：实现批量添加职工功能，将信息录入到文件中，职工信息为：职工编号、姓名、部门编号
- 显示职工信息：显示公司内部所有职工的信息
- 删除离职职工：按照编号删除指定的职工
- 修改职工信息：按照编号修改职工个人信息
- 查找职工信息：按照职工的编号或者职工的姓名进行查找相关的人员信息
- 按照编号排序：按照职工编号，进行排序，排序规则由用户指定
- 清空所有文档：清空文件中记录的所有职工信息（清空前需要再次确认，防止误删）

### 1.3 核心功能模块

**职工管理**：

- 多态创建三种职工类型
- 职责动态绑定（Java方法重写）

**文件系统**：

- 自动保存/加载
- CSV格式存储

**用户界面**：

- 直观菜单系统
- 实时反馈机制

### 1.4 功能分析

职工信息的存储格式：我们将采用文本文件存储，每行存储一个职工的信息，格式为：职工编号,姓名,岗位类型（1表示普通员工，2表示经理，3表示老板）。

### 1.5 设计核心思路

设计思路：

1. 抽象一个Worker基类，包含职工的基本信息（编号、姓名）和显示信息的抽象方法，以及职责的抽象方法。
2. 派生三个子类：Employee（普通员工）、Manager（经理）、Boss（老板），分别实现抽象方法。
3. 管理类WorkerManager，用于管理所有职工，包括增删改查、排序、清空、文件读写等功能。
4. 使用文件存储职工数据，文件名为worker.txt，存储格式为每行一个职工（CSV格式）。

```java
// 职工抽象基类
public abstract class Worker {
    protected int id;       // 职工编号
    protected String name;  // 职工姓名

    public Worker(int id, String name) {
        this.id = id;
        this.name = name;
    }

    public abstract void showInfo();
    // 获取岗位名称 - 抽象方法
```

### 5.6 Java多态原理

```java
public abstract void showInfo();
public abstract String getDeptName();
```

这两个是抽象方法（Abstract Method），Java中用`abstract`关键字声明。

**原因1：实现多态机制**

1. 运行时多态：Java中所有非static、非final、非private方法默认都是虚方法，自动支持多态
2. 动态绑定：通过父类引用调用方法时，会根据实际对象类型调用相应的方法实现

**原因2：强制子类实现**

1. 抽象方法必须在子类中被重写实现
2. 使Worker成为抽象类，无法直接实例化
3. `@Override`注解提供编译期检查，确保正确重写

```java
Worker emp = new Employee(1, "张三");
Worker mgr = new Manager(2, "李四");
Worker boss = new Boss(3, "王五");

// 同样的调用，不同的实现
emp.showInfo();   // 调用Employee.showInfo()
mgr.showInfo();   // 调用Manager.showInfo()
boss.showInfo();  // 调用Boss.showInfo()
```

### 5.7 对比C++虚函数

| 对比项 | C++ | Java |
|-------|-----|------|
| 多态声明 | `virtual`关键字 | 默认支持，`abstract`声明抽象方法 |
| 纯虚函数 | `= 0` | `abstract`关键字 |
| 重写标识 | `override`（可选） | `@Override`注解（推荐） |
| 虚函数表 | 需要手动理解vtable | JVM自动管理方法分派 |
| 虚析构函数 | 必须声明`virtual ~Worker()` | 不需要，GC自动回收 |
| 内存管理 | `new/delete`手动管理 | GC自动管理 |

Java的多态比C++更简洁：不需要`virtual`关键字、不需要虚析构函数、不需要手动管理vtable。

## 06.添加职工

功能描述：批量添加职工，并且保存到文件中。

### 6.1 功能分析

用户在批量创建时，可能会创建不同种类的职工。Java中直接使用`ArrayList`即可，不需要像C++那样手动扩容数组。

### 6.2 增加职工功能

```java
public void addEmp(Scanner scanner) {
    System.out.println("请输入增加职工数量：");
    int addNum = scanner.nextInt();
    if (addNum <= 0) {
        System.out.println("输入有误，请重新输入大于0的数值");
        return;
    }
    for (int i = 0; i < addNum; i++) {
        System.out.println("请输入第 " + (i + 1) + " 个新职工编号：");
        int id = scanner.nextInt();
        System.out.println("请输入第 " + (i + 1) + " 个新职工姓名：");
        String name = scanner.next();
        System.out.println("请选择该职工的岗位：");
        System.out.println("1、普通职工");
        System.out.println("2、经理");
        System.out.println("3、老板");
        int dSelect = scanner.nextInt();
        Worker worker = null;
        switch (dSelect) {
            case 1:
                worker = new Employee(id, name);
                break;
            case 2:
                worker = new Manager(id, name);
                break;
            case 3:
                worker = new Boss(id, name);
                break;
            default:
                System.out.println("输入有误！");
                continue;
        }
        empList.add(worker);
    }
    // 保存到文件
    save();
    System.out.println("成功添加" + addNum + "名新职工！");
}
```

### 6.3 添加职工原理

对比C++的动态数组扩容：

| 对比项 | C++ | Java |
|-------|-----|------|
| 容器 | `Worker**`二级指针 + `new Worker*[size]` | `ArrayList<Worker>` |
| 扩容 | 手动分配新数组、复制、释放旧数组 | `ArrayList`自动扩容 |
| 添加 | `newSpace[index] = worker;` | `empList.add(worker);` |
| 内存释放 | `delete[] this->empArray;` | GC自动回收 |
| 时间复杂度 | O(n)数据迁移 | 均摊O(1) |

Java的`ArrayList`底层也是数组，扩容时也需要复制数据，但这些细节对开发者透明。

### 7.2 保存文件功能

使用try-with-resources自动管理文件资源：

```java
private void save() {
    try (BufferedWriter bw = new BufferedWriter(new FileWriter(FILENAME))) {
        for (Worker worker : empList) {
            int type = 0;
            if (worker instanceof Employee) type = 1;
            else if (worker instanceof Manager) type = 2;
            else if (worker instanceof Boss) type = 3;
            bw.write(worker.getId() + "," + worker.getName() + "," + type);
            bw.newLine();
        }
    } catch (IOException e) {
        System.out.println("保存文件失败：" + e.getMessage());
    }
}
```

对比C++：Java使用`try-with-resources`自动关闭文件流，不需要手动调用`close()`。C++使用`ofstream`需要手动`open/close`。

### 8.3 从文件加载数据

```java
private void loadData() {
    try (BufferedReader br = new BufferedReader(new FileReader(FILENAME))) {
        String line;
        while ((line = br.readLine()) != null) {
            String[] parts = line.split(",");
            if (parts.length < 3) continue;
            int id = Integer.parseInt(parts[0].trim());
            String name = parts[1].trim();
            int type = Integer.parseInt(parts[2].trim());
            Worker worker = null;
            switch (type) {
                case 1:
                    worker = new Employee(id, name);
                    break;
                case 2:
                    worker = new Manager(id, name);
                    break;
                case 3:
                    worker = new Boss(id, name);
                    break;
            }
            if (worker != null) {
                empList.add(worker);
            }
        }
        System.out.println("职工个数为：" + empList.size());
    } catch (IOException e) {
        System.out.println("读取文件失败：" + e.getMessage());
    }
}
```

对比C++：C++使用`ifstream >> id >> name >> deptId`逐个读取，Java使用`BufferedReader.readLine()`读取整行再`split`分割。

### 10.1 职工是否存在

```java
private int isExist(int id) {
    for (int i = 0; i < empList.size(); i++) {
        if (empList.get(i).getId() == id) {
            return i;
        }
    }
    return -1;
}
```

### 10.2 删除职工函数实现

```java
public void deleteEmp(Scanner scanner) {
    if (empList.isEmpty()) {
        System.out.println("文件不存在或记录为空！");
        return;
    }
    System.out.println("请输入想要删除的职工号：");
    int id = scanner.nextInt();
    int index = isExist(id);
    if (index == -1) {
        System.out.println("删除失败，未找到该职工");
        return;
    }
    empList.remove(index);
    save();
    System.out.println("删除成功！");
}
```

对比C++：C++需要手动将后面的元素前移，并注意`delete`被删除的对象防止内存泄漏。Java直接调用`ArrayList.remove(index)`即可，内存由GC回收。

```java
    int newId = scanner.nextInt();
    System.out.println("请输入新姓名：");
    String newName = scanner.next();
    System.out.println("请输入新的岗位：");
    System.out.println("1、普通职工");
    System.out.println("2、经理");
    System.out.println("3、老板");
    int newSelect = scanner.nextInt();
    Worker worker = null;
    switch (newSelect) {
        case 1:
            worker = new Employee(newId, newName);
            break;
        case 2:
            worker = new Manager(newId, newName);
            break;
        case 3:
            worker = new Boss(newId, newName);
            break;
        default:
            System.out.println("输入有误！");
            return;
    }
    empList.set(index, worker);

}
```

对比C++：C++修改时需要先`delete this->empArray[index]`释放旧对象内存，否则内存泄漏。Java中`empList.set(index, worker)`直接替换，旧对象由GC回收。C++还可能遇到虚析构函数问题，Java完全不用担心。

```java
}
```

### 15.2 对比C++实现

| 对比项 | C++ | Java |
|-------|-----|------|
| 多态机制 | `virtual` + `= 0`纯虚函数 | `abstract`抽象方法 |
| 数据存储 | `Worker**`二级指针 + 手动扩容 | `ArrayList<Worker>`自动扩容 |
| 内存管理 | `new/delete`手动管理 | GC自动回收 |
| 虚析构函数 | 必须`virtual ~Worker()` | 不需要 |
| 文件写入 | `ofstream` + 手动close | try-with-resources自动关闭 |
| 文件读取 | `ifstream >> id >> name >> dId` | `BufferedReader.readLine()` + split |
| 删除元素 | 手动前移数组 + delete | `ArrayList.remove()` |
| 排序 | 手动选择排序O(n²) | `sort()` + Lambda O(n log n) |
| 类型判断 | 存储deptId字段 | `instanceof`运算符 |
| 字符串比较 | `==`直接比较 | `equals()`方法比较 |
