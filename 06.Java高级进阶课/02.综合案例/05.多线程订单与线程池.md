## 04.与上一案例的承接

| 维度 | 04 案例 | 05 案例 |
|---|---|---|
| 线程模型 | 单线程 | 多线程 + 线程池 |
| 数据安全 | 单线程天然安全 | synchronized / 锁 / 原子类 / 并发集合 |
| 任务调度 | main 顺序执行 | ExecutorService 异步调度 |
| 错误处理 | 抛异常即可 | 多线程异常需 UncaughtExceptionHandler |
| 关键概念 | 反射 / 泛型 / 注解 | 竞态 / 死锁 / 可见性 / 原子性（"并发四大金刚"）|
