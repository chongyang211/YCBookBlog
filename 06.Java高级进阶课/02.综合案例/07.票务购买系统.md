## 01.票务购买系统

### 1.1 产品需求

模拟多个窗口售票、多人购票的场景。系统包括票务管理、窗口管理、顾客管理、交易日志等功能。

1. 多窗口（线程）售票
2. 用户购票行为模拟
3. 票务查询和统计
4. 日志和错误处理
5. 系统配置管理

### 1.2 程序功能

1. **初始化阶段**：加载配置；创建日志系统；初始化票务系统
2. **窗口启动**：创建售票窗口线程；每个窗口开始售票
3. **顾客购票**：顾客线程发起购票请求；系统处理购票事务
4. **动态调整**：监控票数并预警；动态增加票数
5. **关闭系统**：停止售票窗口；生成统计报告

### 1.3 技术栈说明

**并发控制设计**：

> (1) 锁机制

- **synchronized关键字**：保护共享资源（剩余票数），防止数据竞争
- **ReentrantLock**：更灵活的锁控制

> (2) 等待/通知机制

```java
// 等待条件
synchronized (lock) {
    while (condition) {
        lock.wait();
    }
}
// 通知所有等待线程
lock.notifyAll();
```

> (3) 原子操作 (AtomicInteger)

```java
AtomicInteger ticketsSold = new AtomicInteger(0);
ticketsSold.addAndGet(num); // 原子操作
```

对比C++：C++使用`std::mutex` + `std::condition_variable` + `std::atomic`，Java使用`synchronized` / `ReentrantLock` + `wait/notify` + `AtomicInteger`。

### 1.4 核心组件说明

- **TicketSystem**: 票务系统核心，管理票数和售票逻辑
- **TicketWindow**: 售票窗口，每个窗口运行在独立线程
- **Customer**: 顾客，异步发起购票请求
- **Logger**: 日志系统，线程安全的日志记录
- **ConfigManager**: 配置管理

### 2.2 日志系统实现

```java
import java.io.*;
import java.util.concurrent.locks.ReentrantLock;

public class Logger {
    private BufferedWriter logWriter;
    private final ReentrantLock logLock = new ReentrantLock();

    public Logger(String fileName) {
        try {
            logWriter = new BufferedWriter(new FileWriter(fileName, true));
        } catch (IOException e) {
            throw new RuntimeException("Failed to open log file: " + e.getMessage());
        }
    }

    public void log(String message, LogLevel level) {
        logLock.lock();
        try {
            String logMessage = "[" + level + "] " + message;
            logWriter.write(logMessage);
            logWriter.newLine();
            logWriter.flush();
            System.out.println(logMessage);
        } catch (IOException e) {
            System.err.println("Log write failed: " + e.getMessage());
        } finally {
            logLock.unlock();
        }
    }

    public void log(String message) {
        log(message, LogLevel.INFO);
    }

    public void close() {
        try {
            if (logWriter != null) {
                logWriter.close();
            }
        } catch (IOException e) {
            System.err.println("Log close failed: " + e.getMessage());
        }
    }
}
```

对比C++：C++使用`std::mutex` + `std::lock_guard`保护日志写入，Java使用`ReentrantLock` + `lock/unlock`。Java使用`try-finally`确保锁释放，C++使用RAII的`lock_guard`。

### 2.4 配置管理系统

```java
import java.util.*;
import java.io.*;

public class ConfigManager {
    private HashMap<String, Integer> config;

    public ConfigManager(String fileName) {
        config = new HashMap<>();
        try (BufferedReader br = new BufferedReader(new FileReader(fileName))) {
            String line;
            while ((line = br.readLine()) != null) {
                String[] parts = line.trim().split("\\s+");
                if (parts.length >= 2) {
                    config.put(parts[0], Integer.parseInt(parts[1]));
                }
            }
        } catch (FileNotFoundException e) {
            // 默认配置
            config.put("total_tickets", 100);
            config.put("num_windows", 3);
            config.put("num_customers", 10);
            config.put("max_tickets_per_customer", 5);
        } catch (IOException e) {
            throw new RuntimeException("Config read failed: " + e.getMessage());
        }
    }

    public int get(String key) {
        Integer value = config.get(key);
        if (value == null) {
            throw new RuntimeException("Config key not found: " + key);
        }
        return value;
    }
}
```

## 03.票务系统实现

### 3.1 设计票务系统类

```java
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.locks.*;

public class TicketSystem {
    private int totalTickets;
    private AtomicInteger remainingTickets;
    private final ReentrantLock ticketLock = new ReentrantLock();
    private final Condition condition = ticketLock.newCondition();
    private Logger logger;

    public TicketSystem(int total, Logger logger) {
        this.totalTickets = total;
        this.remainingTickets = new AtomicInteger(total);
        this.logger = logger;
        logger.log("Ticket system created with " + total + " tickets");
    }

    public int getRemainingTickets() {
        return remainingTickets.get();
    }

    public int getTotalTickets() {
        return totalTickets;
    }
}
```

对比C++：C++使用`std::atomic<int>` + `std::mutex` + `std::condition_variable`，Java使用`AtomicInteger` + `ReentrantLock` + `Condition`。

### 3.2 实现售票方法

```java
public boolean sellTicket(int num, String windowName) {
    ticketLock.lock();
    try {
        // 等待：直到票数足够或无票
        while (remainingTickets.get() < num && remainingTickets.get() > 0) {
            try {
                condition.await();
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                return false;
            }
        }
        if (remainingTickets.get() >= num) {
            remainingTickets.addAndGet(-num);
            logger.log(windowName + " sold " + num +
                    " tickets. Remaining: " + remainingTickets.get());
            condition.signalAll();
            return true;
        } else {
            logger.log(windowName + " failed to sell " + num +
                    " tickets. Not enough available.", LogLevel.WARNING);
            return false;
        }
    } finally {
        ticketLock.unlock();
    }
}
```

对比C++：C++使用`std::unique_lock` + `cv.wait(lock, predicate)`，Java使用`ticketLock.lock()` + `condition.await()`。两者都使用等待/通知模式避免忙等待。

### 3.3 实现加票方法

```java
public void addTickets(int num) {
    if (num <= 0) {
        logger.log("Failed to add tickets. Invalid number: " + num, LogLevel.WARNING);
        return;
    }
    ticketLock.lock();
    try {
        remainingTickets.addAndGet(num);
        logger.log("Added " + num + " tickets. Remaining: " + remainingTickets.get());
        condition.signalAll();
    } finally {
        ticketLock.unlock();
    }
}
```

## 04.售票窗口实现

### 4.1 售票窗口类

```java
import java.util.Random;
import java.util.concurrent.atomic.*;

public class TicketWindow implements Runnable {
    private String name;
    private TicketSystem ticketSystem;
    private Logger logger;
    private volatile boolean running;
    private AtomicInteger ticketsSold;
    private Thread workerThread;

    public TicketWindow(String name, TicketSystem system, Logger logger) {
        this.name = name;
        this.ticketSystem = system;
        this.logger = logger;
        this.running = true;
        this.ticketsSold = new AtomicInteger(0);
        logger.log("Ticket window " + name + " created");
    }

    public int getTicketsSold() {
        return ticketsSold.get();
    }

    public String getName() {
        return name;
    }
}
```

对比C++：C++使用`std::atomic<bool> running` + `std::thread workerThread`，Java使用`volatile boolean running` + `Thread workerThread`。C++使用`delete`禁用拷贝构造，Java不需要。

### 4.2 启动售票线程

```java
public void start() {
    workerThread = new Thread(this);
    workerThread.start();
}

@Override
public void run() {
    logger.log(name + " started selling tickets");
    Random random = new Random();
    while (running) {
        int numTickets = random.nextInt(5) + 1;
        if (ticketSystem.sellTicket(numTickets, name)) {
            ticketsSold.addAndGet(numTickets);
            try {
                Thread.sleep(100); // 模拟出票时间
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                break;
            }
        } else {
            logger.log(name + " stopped: not enough tickets", LogLevel.WARNING);
            break;
        }
    }
    logger.log(name + " stopped selling tickets");
}
```

对比C++：C++使用`std::thread([this] { ... })`创建线程，Java实现`Runnable`接口。C++使用`std::this_thread::sleep_for`，Java使用`Thread.sleep()`。

### 4.3 停止售票

```java
public void stop() {
    running = false;
    if (workerThread != null) {
        try {
            workerThread.join();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
}
```

### 5.2 顾客购票方法

```java
public void buyTickets(int num) {
    purchaseThread = new Thread(() -> {
        logger.log(name + " is trying to buy " + num + " tickets.");
        if (ticketSystem.sellTicket(num, name)) {
            logger.log(name + " successfully bought " + num + " tickets.");
        } else {
            logger.log(name + " failed to buy " + num + " tickets.", LogLevel.WARNING);
        }
    });
    purchaseThread.start();
}
```

对比C++：C++使用`std::thread([this, num]() { ... })`，Java使用`new Thread(() -> { ... })`。两者都使用Lambda表达式创建线程任务。

### 5.3 等待购票完成

```java
public void waitForPurchase() {
    if (purchaseThread != null) {
        try {
            purchaseThread.join();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
}
```

## 06.主程序整合

### 6.1 基本购票流程

```java
public static void main(String[] args) throws InterruptedException {
    // 读取配置
    ConfigManager config = new ConfigManager("config.txt");
    int totalTickets = config.get("total_tickets");
    int numWindows = config.get("num_windows");
    int numCustomers = config.get("num_customers");
    int maxPerCustomer = config.get("max_tickets_per_customer");

    // 初始化日志
    Logger logger = new Logger("ticket_system.log");

    // 初始化票务系统
    TicketSystem ticketSystem = new TicketSystem(totalTickets, logger);

    // 创建并启动售票窗口
    ArrayList<TicketWindow> windows = new ArrayList<>();
    for (int i = 1; i <= numWindows; i++) {
        TicketWindow window = new TicketWindow("Window " + i, ticketSystem, logger);
        windows.add(window);
        window.start();
    }

    // 创建顾客并购票
    ArrayList<Customer> customers = new ArrayList<>();
    Random random = new Random();
    for (int i = 1; i <= numCustomers; i++) {
        Customer customer = new Customer("Customer " + i, ticketSystem, logger);
        customers.add(customer);
        int numTickets = random.nextInt(maxPerCustomer) + 1;
        customer.buyTickets(numTickets);
        Thread.sleep(200);
    }

    // 动态增加票数
    Thread.sleep(2000);
    ticketSystem.addTickets(50);

    // 等待一段时间后停止
    Thread.sleep(5000);
    for (TicketWindow window : windows) {
        window.stop();
    }

    // 等待顾客购票完成
    for (Customer customer : customers) {
        customer.waitForPurchase();
    }

    // 输出统计
    logger.log("Remaining tickets: " + ticketSystem.getRemainingTickets());
    for (TicketWindow window : windows) {
        logger.log(window.getName() + " sold " + window.getTicketsSold() + " tickets");
    }
    logger.close();
}
```

### 7.1 动态票务监控

```java
public void monitorTickets() {
    Thread monitorThread = new Thread(() -> {
        while (true) {
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                break;
            }
            int remaining = getRemainingTickets();
            if (remaining < totalTickets / 4) {
                logger.log("Warning: Only " + remaining +
                        " tickets remaining!", LogLevel.WARNING);
            }
        }
    });
    monitorThread.setDaemon(true);
    monitorThread.start();
}
```

对比C++：C++使用`std::thread(...).detach()`创建分离线程，Java使用`thread.setDaemon(true)`设置守护线程。两者效果类似，当主线程结束时守护/分离线程自动终止。

## 08.性能监控与统计

### 8.1 性能监控类

```java
import java.util.concurrent.atomic.AtomicInteger;

public class PerformanceMonitor {
    private AtomicInteger totalSales = new AtomicInteger(0);
    private AtomicInteger successfulSales = new AtomicInteger(0);
    private AtomicInteger failedSales = new AtomicInteger(0);
    private long startTime;
    private Logger logger;

    public PerformanceMonitor(Logger logger) {
        this.logger = logger;
        this.startTime = System.currentTimeMillis();
    }

    public void recordSale(boolean success) {
        totalSales.incrementAndGet();
        if (success) {
            successfulSales.incrementAndGet();
        } else {
            failedSales.incrementAndGet();
        }
    }

    public void report() {
        long duration = (System.currentTimeMillis() - startTime) / 1000;
        int total = totalSales.get();
        StringBuilder sb = new StringBuilder();
        sb.append("\n==== PERFORMANCE REPORT ====\n");
        sb.append("Total sales attempts: ").append(total).append("\n");
        sb.append("Successful sales: ").append(successfulSales.get()).append("\n");
        sb.append("Failed sales: ").append(failedSales.get()).append("\n");
        sb.append("Success rate: ").append(
                total > 0 ? (100.0 * successfulSales.get() / total) : 0).append("%\n");
        sb.append("Duration: ").append(duration).append(" seconds\n");
        sb.append("TPS: ").append(duration > 0 ? total / duration : 0).append("\n");
        logger.log(sb.toString());
    }
}
```

## 09.项目总结

### 9.1 对比C++实现

| 对比项 | C++ | Java |
|-------|-----|------|
| 线程创建 | `std::thread([this] {...})` | `new Thread(() -> {...})` |
| 互斥锁 | `std::mutex` + `std::lock_guard` | `synchronized` / `ReentrantLock` |
| 条件变量 | `std::condition_variable` | `Condition` / `wait/notify` |
| 原子变量 | `std::atomic<int>` | `AtomicInteger` |
| 线程join | `thread.joinable()` + `join()` | `thread.join()` |
| 分离线程 | `thread.detach()` | `thread.setDaemon(true)` |
| volatile | `volatile`关键字 | `volatile`关键字（语义略有不同） |
| 智能指针 | `std::unique_ptr<TicketWindow>` | 不需要，GC自动管理 |
| 禁用拷贝 | `= delete` | 不需要 |
| 随机数 | `std::random_device` + `std::mt19937` | `Random` |
| 字符串格式化 | `std::stringstream` | `StringBuilder` / `+`拼接 |
| 异常处理 | `try-catch(std::exception&)` | `try-catch(Exception)` |
| 线程安全日志 | `std::mutex` + `std::ofstream` | `ReentrantLock` + `BufferedWriter` |
| 内存管理 | RAII + `unique_ptr` | GC自动回收 |
