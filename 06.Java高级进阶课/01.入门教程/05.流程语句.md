## 5.1 程序流程结构

Java 支持最基本的三种程序运行结构：顺序结构、选择结构、循环结构

* 顺序结构：程序按顺序执行，不发生跳转
* 选择结构：依据条件是否满足，有选择的执行相应功能
* 循环结构：依据条件是否满足，循环多次执行某段代码

## 5.2 选择结构

### 5.2.1 if语句

**作用**：执行满足条件的语句

if 语句的三种形式：单行格式 if、if-else、多条件 if-else if-else。

> 注意：Java 的 if 条件必须是 `boolean` 类型，不能像 C++ 那样用整数作为条件。

### 5.2.2 单行格式if语句

```java
int score = 85;
if (score >= 60) {
    System.out.println("及格");
}
```

### 5.2.3 if-else语句

```java
int score = 55;
if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

### 5.2.4 多条件的if语句

```java
int score = 85;
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 80) {
    System.out.println("良好");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

### 5.2.5 嵌套if语句

```java
int age = 20;
boolean hasLicense = true;

if (age >= 18) {
    if (hasLicense) {
        System.out.println("可以开车");
    } else {
        System.out.println("年龄够了，但没有驾照");
    }
} else {
    System.out.println("未满18岁，不能开车");
}
```

### 5.2.6 三元运算符

```java
int a = 10, b = 20;
int max = (a > b) ? a : b;
System.out.println("较大值：" + max);  // 20
```

### 5.2.7 switch语句

```java
int day = 3;
switch (day) {
    case 1:
        System.out.println("星期一");
        break;
    case 2:
        System.out.println("星期二");
        break;
    case 3:
        System.out.println("星期三");
        break;
    default:
        System.out.println("其他");
        break;
}
```

Java 的 switch 支持的类型：`byte`、`short`、`int`、`char`、`String`（JDK 7+）、枚举。

**对比 C++**：C++ 的 switch 不支持 `String` 类型，只支持整型和枚举。

```java
// JDK 7+ 支持 String
String fruit = "苹果";
switch (fruit) {
    case "苹果":
        System.out.println("Apple");
        break;
    case "香蕉":
        System.out.println("Banana");
        break;
    default:
        System.out.println("Unknown");
}
```

### 5.2.8 switch增强写法(JDK14+)

JDK 14 引入了 switch 表达式，更加简洁：

```java
int day = 3;
String dayName = switch (day) {
    case 1 -> "星期一";
    case 2 -> "星期二";
    case 3 -> "星期三";
    case 4 -> "星期四";
    case 5 -> "星期五";
    case 6, 7 -> "周末";
    default -> "无效";
};
System.out.println(dayName);  // 星期三
```

## 5.3 循环结构

### 5.3.1 while循环语句

```java
int i = 0;
while (i < 5) {
    System.out.println("i = " + i);
    i++;
}
```

### 5.3.2 do...while循环语句

```java
int i = 0;
do {
    System.out.println("i = " + i);
    i++;
} while (i < 5);
```

> do-while 至少执行一次循环体

### 5.3.3 for循环语句

```java
for (int i = 0; i < 5; i++) {
    System.out.println("i = " + i);
}
```

### 5.3.4 增强for循环

Java 5 引入的 for-each 循环，简化数组和集合的遍历：

```java
int[] arr = {10, 20, 30, 40, 50};
for (int num : arr) {
    System.out.println(num);
}

String[] names = {"张三", "李四", "王五"};
for (String name : names) {
    System.out.println(name);
}
```

**对比 C++**：C++11 也引入了类似的范围 for 循环 `for (auto x : arr)`。

### 5.3.5 嵌套循环

```java
// 打印九九乘法表
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "×" + i + "=" + (i * j) + "\t");
    }
    System.out.println();
}
```

## 5.4 跳转语句

### 5.4.1 break语句

```java
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;  // 跳出循环
    }
    System.out.println(i);
}
// 输出：0 1 2 3 4
```

### 5.4.2 continue语句

```java
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {
        continue;  // 跳过本次循环
    }
    System.out.println(i);
}
// 输出：1 3 5 7 9
```

### 5.4.3 标签和break/continue

Java 支持使用**标签**配合 `break` 和 `continue` 跳出多层循环：

```java
// 使用标签跳出外层循环
outer:
for (int i = 0; i < 5; i++) {
    for (int j = 0; j < 5; j++) {
        if (i == 2 && j == 3) {
            break outer;  // 直接跳出外层循环
        }
        System.out.println("i=" + i + ", j=" + j);
    }
}
```

**对比 C++**：C++ 没有标签 break，要跳出多层循环通常需要用 `goto`（不推荐）或设置标志变量。Java 的标签 break 更加优雅。

> 注意：Java 没有 `goto` 语句（虽然 `goto` 是保留关键字，但没有实现）。

## 5.5 综合案例：猜数字游戏

本案例融合流程语句章节的核心知识点：if-else多分支、switch、while/for循环、break/continue、嵌套循环、标签跳转等。

```java
import java.util.Random;
import java.util.Scanner;

/**
 * 猜数字游戏（含多种难度和统计功能）
 * 融合知识点：if-else、switch、while、for、do-while、break、continue、标签
 */
public class GuessNumberGame {

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        Random random = new Random();
        int totalGames = 0;
        int totalWins = 0;

        System.out.println("╔═══════════════════════════╗");
        System.out.println("║    欢迎来到猜数字游戏     ║");
        System.out.println("╚═══════════════════════════╝");

        // 外层循环：多局游戏
        gameLoop:
        while (true) {
            // switch 选择难度
            System.out.println("\n请选择难度：");
            System.out.println("1. 简单（1-50，10次机会）");
            System.out.println("2. 普通（1-100，7次机会）");
            System.out.println("3. 困难（1-200，5次机会）");
            System.out.println("0. 退出游戏");
            System.out.print("选择：");

            int choice = sc.nextInt();
            int maxNum, maxAttempts;

            // switch 增强写法
            switch (choice) {
                case 1 -> { maxNum = 50;  maxAttempts = 10; }
                case 2 -> { maxNum = 100; maxAttempts = 7; }
                case 3 -> { maxNum = 200; maxAttempts = 5; }
                case 0 -> { break gameLoop; }  // 标签 break 跳出外层循环
                default -> {
                    System.out.println("无效选择，请重新输入");
                    continue gameLoop;  // 标签 continue 跳过本次迭代
                }
            }

            int target = random.nextInt(maxNum) + 1;
            int attempts = 0;
            boolean won = false;
            int[] guessHistory = new int[maxAttempts];

            System.out.printf("\n数字已生成（1-%d），你有 %d 次机会！%n", maxNum, maxAttempts);

            // for 循环：限制猜测次数
            for (int i = 0; i < maxAttempts; i++) {
                System.out.printf("第 %d/%d 次，请输入猜测：", i + 1, maxAttempts);
                int guess = sc.nextInt();
                guessHistory[i] = guess;
                attempts++;

                // if-else 多分支判断
                if (guess < 1 || guess > maxNum) {
                    System.out.printf("请输入 1-%d 之间的数字！%n", maxNum);
                    i--;  // 无效猜测不计次数
                    attempts--;
                    continue;  // 跳过本次循环
                } else if (guess == target) {
                    won = true;
                    System.out.println("🎉 恭喜你猜对了！");
                    break;  // 跳出 for 循环
                } else if (guess < target) {
                    // 嵌套 if：给出更精确的提示
                    int diff = target - guess;
                    if (diff > maxNum / 2) {
                        System.out.println("太小了！差很远呢~");
                    } else if (diff > maxNum / 4) {
                        System.out.println("小了，但方向对了");
                    } else {
                        System.out.println("接近了！再大一点点");
                    }
                } else {
                    int diff = guess - target;
                    if (diff > maxNum / 2) {
                        System.out.println("太大了！差很远呢~");
                    } else if (diff > maxNum / 4) {
                        System.out.println("大了，但方向对了");
                    } else {
                        System.out.println("接近了！再小一点点");
                    }
                }

                // 剩余次数提醒
                int remaining = maxAttempts - i - 1;
                if (remaining > 0 && remaining <= 2) {
                    System.out.printf("⚠️ 注意：还剩 %d 次机会！%n", remaining);
                }
            }

            totalGames++;
            if (won) {
                totalWins++;
                // 三元运算评价
                String rating = attempts <= 3 ? "神级表现！" :
                                attempts <= 5 ? "表现优秀！" :
                                attempts <= 7 ? "还不错！" : "险胜！";
                System.out.printf("用了 %d 次猜中，%s%n", attempts, rating);
            } else {
                System.out.println("很遗憾，次数用完了！答案是：" + target);
            }

            // do-while：显示猜测历史
            System.out.println("\n本局猜测记录：");
            int idx = 0;
            do {
                if (idx >= attempts) break;
                String mark = guessHistory[idx] == target ? " ✓" :
                              guessHistory[idx] < target ? " ↑" : " ↓";
                System.out.printf("  第%d次：%d%s%n", idx + 1, guessHistory[idx], mark);
                idx++;
            } while (idx < attempts);
        }

        // 游戏总结
        System.out.println("\n╔═══════════════════════════╗");
        System.out.println("║       游戏结束统计        ║");
        System.out.println("╠═══════════════════════════╣");
        System.out.printf("║ 总局数：%-18d ║%n", totalGames);
        System.out.printf("║ 获胜：%-20d ║%n", totalWins);
        if (totalGames > 0) {
            double winRate = (double) totalWins / totalGames * 100;
            System.out.printf("║ 胜率：%-19.1f%% ║%n", winRate);
        }
        System.out.println("╚═══════════════════════════╝");
        System.out.println("感谢游玩，再见！");

        sc.close();
    }
}
```

**案例知识点总结：**

| 知识点 | 案例中的体现 |
|--------|-------------|
| if-else 多分支 | 猜大/猜小/猜中的判断 |
