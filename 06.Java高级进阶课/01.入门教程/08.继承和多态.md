## 8.1 继承基础

### 8.1.1 继承基本概念

继承是面向对象编程的核心特性之一，允许一个类（子类/派生类）基于另一个类（父类/基类）创建，从而复用父类的属性和方法。

```
父类（基类）：  Animal
                ↑
子类（派生类）：Dog, Cat
```

### 8.1.2 继承的语法

使用 `extends` 关键字实现继承：

```java
// 父类
public class Animal {
    protected String name;
    protected int age;

    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void eat() {
        System.out.println(name + " 在吃东西");
    }
}

// 子类
public class Dog extends Animal {
    private String breed;

    public Dog(String name, int age, String breed) {
        super(name, age);  // 调用父类构造方法
        this.breed = breed;
    }

    public void bark() {
        System.out.println(name + " 在汪汪叫");
    }
}

Dog dog = new Dog("旺财", 3, "金毛");
dog.eat();   // 继承自 Animal
dog.bark();  // Dog 自己的方法
```

**对比 C++**：C++ 使用 `:` 加访问修饰符继承（`class Dog : public Animal`），Java 使用 `extends`。C++ 没有访问修饰符限制，默认 private 继承；Java 只有 public 继承。

### 8.1.3 Java单继承

Java **只支持单继承**，一个类只能有一个直接父类：

```java
// 正确：单继承
class Dog extends Animal {}

// 错误：Java 不支持多继承
// class Dog extends Animal, Pet {}  // 编译错误

// 但可以通过接口实现"多继承"的效果
class Dog extends Animal implements Pet, Trainable {}
```

**对比 C++**：C++ 支持多继承（`class Dog : public Animal, public Pet {}`），但多继承容易导致菱形继承问题。Java 通过接口避免了这个问题。

### 8.1.4 继承中的构造方法

```java
public class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
        System.out.println("Animal 构造方法");
    }
}

public class Dog extends Animal {
    public Dog(String name) {
        super(name);  // 必须在第一行调用父类构造方法
        System.out.println("Dog 构造方法");
    }
}

Dog dog = new Dog("旺财");
// 输出：
// Animal 构造方法
// Dog 构造方法
```

> 构造顺序：先父类后子类。如果父类没有无参构造方法，子类必须显式调用 `super(参数)`。

## 8.2 方法重写

### 8.2.1 方法重写概念

子类可以重写（Override）父类的方法，提供自己的实现：

```java
public class Animal {
    public void makeSound() {
        System.out.println("动物发出声音");
    }
}

public class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("汪汪汪！");
    }
}

public class Cat extends Animal {
    @Override
    public void makeSound() {
        System.out.println("喵喵喵！");
    }
}
```

### 8.2.2 Override注解

`@Override` 注解不是必须的，但强烈推荐使用。它让编译器帮你检查是否正确重写了父类方法：

```java
@Override
public void makeSound() {  // 如果方法签名写错，编译器会报错
    System.out.println("汪汪汪！");
}
```

### 8.2.3 重写和重载区别

| 对比项 | 重写（Override） | 重载（Overload） |
|--------|-----------------|-----------------|
| 发生位置 | 子类和父类之间 | 同一个类中 |
| 方法名 | 相同 | 相同 |
| 参数列表 | 相同 | 必须不同 |
| 返回类型 | 相同或协变类型 | 可以不同 |
| 访问修饰符 | 不能更严格 | 无限制 |

## 8.3 super关键字

### 8.3.1 super访问父类

```java
public class Dog extends Animal {
    @Override
    public void makeSound() {
        super.makeSound();  // 调用父类的方法
        System.out.println("汪汪汪！");
    }
}
```

### 8.3.2 super调用构造方法

```java
public class Dog extends Animal {
    private String breed;

    public Dog(String name, int age, String breed) {
        super(name, age);  // 调用父类构造方法，必须在第一行
        this.breed = breed;
    }
}
```

**对比 C++**：C++ 使用初始化列表调用父类构造 `Dog(string name) : Animal(name) {}`，Java 使用 `super()` 在构造方法体中调用。

## 8.4 Object类

### 8.4.1 Object是所有类的父类

Java 中所有类都直接或间接继承自 `Object` 类。如果一个类没有显式 `extends`，则默认继承 `Object`。

```java
public class Account {  // 等价于 public class Account extends Object
}
```

### 8.4.2 toString方法

```java
public class Account {
    private String name;
    private double balance;

    @Override
    public String toString() {
        return "Account{name='" + name + "', balance=" + balance + "}";
    }
}

Account acc = new Account("张三", 1000);
System.out.println(acc);  // 自动调用 toString()
// 输出：Account{name='张三', balance=1000.0}
```

### 8.4.3 equals方法

```java
public class Account {
    private String name;
    private double balance;

    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (obj == null || getClass() != obj.getClass()) return false;
        Account other = (Account) obj;
        return name.equals(other.name) && Double.compare(balance, other.balance) == 0;
    }
}
```

### 8.4.4 hashCode方法

重写 `equals` 必须同时重写 `hashCode`：

```java
@Override
public int hashCode() {
    return Objects.hash(name, balance);
}
```

## 8.5 多态

### 8.5.1 多态基本概念

多态：同一个方法在不同对象上有不同的表现形式。多态的前提：

1. 有继承关系
2. 子类重写父类方法
3. 父类引用指向子类对象

```java
Animal animal1 = new Dog("旺财", 3, "金毛");   // 父类引用指向子类对象
Animal animal2 = new Cat("咪咪", 2);

animal1.makeSound();  // 汪汪汪！（调用的是 Dog 的方法）
animal2.makeSound();  // 喵喵喵！（调用的是 Cat 的方法）
```

### 8.5.2 向上转型和向下转型

```java
// 向上转型（自动）：子类 → 父类
Animal animal = new Dog("旺财", 3, "金毛");
animal.makeSound();  // 可以调用 Animal 中声明的方法
// animal.bark();    // 编译错误！Animal 没有 bark 方法

// 向下转型（强制）：父类 → 子类
if (animal instanceof Dog) {
    Dog dog = (Dog) animal;
    dog.bark();  // 现在可以调用 Dog 特有的方法了
}

// JDK 16+ 模式匹配
if (animal instanceof Dog dog) {
    dog.bark();  // 直接使用
}
```

### 8.5.3 多态案例

```java
public class Main {
    // 多态的典型应用：方法参数使用父类类型
    public static void animalShow(Animal animal) {
        animal.makeSound();  // 运行时根据实际类型调用对应方法
    }

    public static void main(String[] args) {
        animalShow(new Dog("旺财", 3, "金毛"));  // 汪汪汪！
        animalShow(new Cat("咪咪", 2));          // 喵喵喵！
    }
}
```

### 8.5.4 多态的好处

1. **提高代码可扩展性**：新增子类不需要修改已有代码。
2. **降低耦合度**：调用方只依赖父类/接口，不依赖具体实现。
3. **统一接口**：通过父类类型统一管理不同子类对象。

**对比 C++**：C++ 通过虚函数（`virtual`）实现多态，Java 中所有非 static、非 final、非 private 方法默认都是"虚方法"，不需要 `virtual` 关键字。

**多态的底层原理（方法分派）**：JVM 通过**虚方法表（vtable）** 实现多态。每个类在加载时都会建立一张虚方法表，表中存储了该类所有可被动态调用的方法的入口地址。子类的虚方法表会继承父类的表项，重写的方法会替换为子类的实现地址。调用时，JVM 使用 `invokevirtual` 指令根据对象**实际类型**的虚方法表找到方法入口——这就是**动态绑定（晚期绑定）**。而字段访问、`static` 方法、`private` 方法和构造方法则是**静态绑定（编译期确定）**，这也是为什么 `p.name` 访问的是父类字段而 `p.show()` 调用的是子类方法。

## 8.6 综合案例：图形绘制系统

本案例融合继承和多态章节的核心知识点：继承、方法重写、super、Object方法重写、多态、向上/向下转型、instanceof等。

```java
import java.util.ArrayList;
import java.util.Objects;

/**
 * 图形绘制系统
 * 融合知识点：继承、方法重写、super、多态、向上/向下转型、Object方法、instanceof
 */

// 父类：图形
class Shape {
    protected String color;
    protected boolean filled;

    public Shape() {
        this("红色", true);
    }

    public Shape(String color, boolean filled) {
        this.color = color;
        this.filled = filled;
    }

    public double area() { return 0; }
    public double perimeter() { return 0; }

    // 重写 toString
    @Override
    public String toString() {
        return String.format("Shape[color=%s, filled=%b]", color, filled);
    }

    // 重写 equals
    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (obj == null || getClass() != obj.getClass()) return false;
        Shape shape = (Shape) obj;
        return filled == shape.filled && Objects.equals(color, shape.color);
    }

    // 重写 hashCode
    @Override
    public int hashCode() {
        return Objects.hash(color, filled);
    }

    // 绘制方法（多态的核心）
    public void draw() {
        System.out.printf("  绘制 %s（%s%s）%n", getClass().getSimpleName(),
                color, filled ? ", 填充" : ", 空心");
    }
}

// 子类：圆形
class Circle extends Shape {
    private double radius;

    public Circle(double radius) {
        super();
        this.radius = radius;
    }

    public Circle(double radius, String color, boolean filled) {
        super(color, filled);
        this.radius = radius;
    }

    public double getRadius() { return radius; }

    @Override
    public double area() {
        return Math.PI * radius * radius;
    }

    @Override
    public double perimeter() {
        return 2 * Math.PI * radius;
    }

    @Override
    public void draw() {
        super.draw();  // 调用父类方法
        System.out.printf("    ● 半径=%.1f, 面积=%.2f, 周长=%.2f%n",
                radius, area(), perimeter());
    }

    @Override
    public String toString() {
        return String.format("Circle[radius=%.1f, %s]", radius, super.toString());
    }
}

// 子类：矩形
class Rectangle extends Shape {
    protected double width;
    protected double height;

    public Rectangle(double width, double height) {
        this.width = width;
        this.height = height;
    }

    public Rectangle(double width, double height, String color, boolean filled) {
        super(color, filled);
        this.width = width;
        this.height = height;
    }

    @Override
    public double area() {
        return width * height;
    }

    @Override
    public double perimeter() {
        return 2 * (width + height);
    }

    @Override
    public void draw() {
        super.draw();
        System.out.printf("    ■ 宽=%.1f, 高=%.1f, 面积=%.2f%n", width, height, area());
    }
}

// 子类的子类：正方形（继承矩形）
class Square extends Rectangle {
    public Square(double side) {
        super(side, side);
    }

    public Square(double side, String color, boolean filled) {
        super(side, side, color, filled);
    }

    @Override
    public void draw() {
        System.out.printf("  绘制正方形（%s%s）%n", color, filled ? ", 填充" : ", 空心");
        System.out.printf("    ◆ 边长=%.1f, 面积=%.2f%n", width, area());
    }
}

// 子类：三角形
class Triangle extends Shape {
    private double a, b, c;

    public Triangle(double a, double b, double c, String color) {
        super(color, false);
        if (a + b <= c || a + c <= b || b + c <= a) {
            throw new IllegalArgumentException("不能构成三角形");
        }
        this.a = a;
        this.b = b;
        this.c = c;
    }

    @Override
    public double area() {
        double s = (a + b + c) / 2;
        return Math.sqrt(s * (s - a) * (s - b) * (s - c));
    }

    @Override
    public double perimeter() {
        return a + b + c;
    }

    @Override
    public void draw() {
        super.draw();
        System.out.printf("    △ 边长=%.1f,%.1f,%.1f 面积=%.2f%n", a, b, c, area());
    }
}

// 画布类：演示多态
class Canvas {
    private ArrayList<Shape> shapes = new ArrayList<>();

    public void addShape(Shape shape) {
        shapes.add(shape);  // 向上转型：子类对象赋给父类引用
    }

    // 多态：统一调用 draw()
    public void drawAll() {
        System.out.println("╔════════════════════════════╗");
        System.out.println("║      画布 - 绘制所有图形    ║");
        System.out.println("╚════════════════════════════╝");
        for (Shape shape : shapes) {
            shape.draw();  // 多态调用，运行时决定调用哪个子类的方法
        }
    }

    // 多态 + instanceof：统计各类图形
    public void statistics() {
        int circles = 0, rectangles = 0, triangles = 0;
        double totalArea = 0;

        for (Shape shape : shapes) {
            totalArea += shape.area();

            // instanceof 判断实际类型
            if (shape instanceof Circle) {
                circles++;
            } else if (shape instanceof Square) {
                rectangles++;  // Square 也是 Rectangle，但这里先匹配
            } else if (shape instanceof Rectangle) {
                rectangles++;
            } else if (shape instanceof Triangle) {
                triangles++;
            }
        }

        System.out.println("\n--- 画布统计 ---");
        System.out.printf("  图形总数：%d%n", shapes.size());
        System.out.printf("  圆形：%d 个%n", circles);
        System.out.printf("  矩形/正方形：%d 个%n", rectangles);
        System.out.printf("  三角形：%d 个%n", triangles);
        System.out.printf("  总面积：%.2f%n", totalArea);
    }

    // 向下转型：获取特定类型的图形
    public void showCircleDetails() {
        System.out.println("\n--- 圆形详情 ---");
        for (Shape shape : shapes) {
            // JDK 16+ 模式匹配
            if (shape instanceof Circle circle) {
                System.out.printf("  半径=%.1f → 直径=%.1f%n",
                        circle.getRadius(), circle.getRadius() * 2);
            }
        }
    }
}

public class ShapeDrawSystem {
    public static void main(String[] args) {
        Canvas canvas = new Canvas();

        // 向上转型：子类对象添加到画布
        canvas.addShape(new Circle(5, "蓝色", true));
        canvas.addShape(new Rectangle(4, 6, "绿色", false));
        canvas.addShape(new Square(3, "黄色", true));
        canvas.addShape(new Triangle(3, 4, 5, "紫色"));
        canvas.addShape(new Circle(2.5));

        // 多态绘制
        canvas.drawAll();

        // 统计
        canvas.statistics();

        // 向下转型
        canvas.showCircleDetails();

        // equals 测试
        System.out.println("\n--- equals 测试 ---");
        Circle c1 = new Circle(5, "蓝色", true);
        Circle c2 = new Circle(5, "蓝色", true);
        System.out.println("c1.equals(c2) = " + c1.equals(c2));
        System.out.println("c1 == c2 = " + (c1 == c2));

        // 继承链测试
        System.out.println("\n--- 继承链测试 ---");
        Square sq = new Square(3);
        System.out.println("Square instanceof Rectangle: " + (sq instanceof Rectangle));
        System.out.println("Square instanceof Shape: " + (sq instanceof Shape));
        System.out.println("Square instanceof Object: " + (sq instanceof Object));
    }
}
```

**案例知识点总结：**

| 知识点 | 案例中的体现 |
|--------|-------------|
| 继承 | `Circle extends Shape`、`Square extends Rectangle` |
| super 调用构造方法 | `super(color, filled)` |
| super 调用父类方法 | `super.draw()` |
| 方法重写 @Override | `area()`、`perimeter()`、`draw()`、`toString()`、`equals()` |
| Object 方法 | `toString()`、`equals()`、`hashCode()` |
| 多态 | `Shape shape = new Circle()` 统一调用 `draw()` |
| 向上转型 | `addShape(new Circle())` |
| 向下转型 | `(Circle) shape` |
| instanceof | 判断类型 + JDK16 模式匹配 |
| 多层继承 | Shape → Rectangle → Square |
| 单继承 | Java 只能 extends 一个类 |
