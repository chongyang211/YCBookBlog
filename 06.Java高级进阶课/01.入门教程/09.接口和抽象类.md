## 9.1 抽象类

### 9.1.1 抽象类概念

抽象类是不能被实例化的类，用 `abstract` 关键字修饰。抽象类可以包含抽象方法（没有方法体的方法），子类必须实现这些抽象方法。

**对比 C++**：C++ 通过纯虚函数 `virtual void func() = 0;` 定义抽象类，Java 用 `abstract` 关键字更加明确。

### 9.1.2 抽象类语法

```java
// 抽象类
public abstract class Shape {
    protected String color;

    public Shape(String color) {
        this.color = color;
    }

    // 抽象方法：没有方法体，子类必须实现
    public abstract double area();
    public abstract double perimeter();

    // 普通方法：抽象类可以有具体实现的方法
    public void describe() {
        System.out.println("这是一个" + color + "的形状，面积为：" + area());
    }
}

// 子类：必须实现所有抽象方法
public class Circle extends Shape {
    private double radius;

    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }

    @Override
    public double area() {
        return Math.PI * radius * radius;
    }

    @Override
    public double perimeter() {
        return 2 * Math.PI * radius;
    }
}

public class Rectangle extends Shape {
    private double width, height;

    public Rectangle(String color, double width, double height) {
        super(color);
        this.width = width;
        this.height = height;
    }

    @Override
    public double area() {
        return width * height;
    }

    @Override
    public double perimeter() {
        return 2 * (width + height);
    }
}
```

### 9.1.3 抽象类特点

1. 不能被实例化（`new Shape()` 编译错误）。
2. 可以有构造方法（供子类调用）。
3. 可以有成员变量。
4. 可以有普通方法和抽象方法。
5. 子类必须实现所有抽象方法，除非子类也是抽象类。

## 9.2 接口

### 9.2.1 接口概念

接口（Interface）定义了一组行为规范，类通过实现接口来承诺遵循这些规范。接口是 Java 实现"多继承"的方式。

**接口的底层原理**：在字节码层面，接口方法的调用使用 `invokeinterface` 指令（而非普通虚方法的 `invokevirtual`）。这是因为一个类可以实现多个接口，接口方法在虚方法表中的位置不固定，需要在运行时通过**接口方法表（itable）** 进行二次查找。JDK 8 引入的 `default` 方法在字节码中标记为 `ACC_PUBLIC`，由实现类的虚方法表继承；如果多个接口有同名 default 方法，编译器会要求实现类显式重写以消除歧义——这就是 Java 在语言层面避免"菱形继承"问题的方式。

### 9.2.2 接口语法

```java
// 定义接口
public interface Payable {
    // 接口中的变量默认是 public static final（常量）
    double TAX_RATE = 0.06;

    // 接口中的方法默认是 public abstract
    void pay(double amount);
    double getBalance();
}

// 实现接口
public class Account implements Payable {
    private double balance;

    @Override
    public void pay(double amount) {
        balance -= amount;
        System.out.println("支付 " + amount);
    }

    @Override
    public double getBalance() {
        return balance;
    }
}
```

### 9.2.3 接口的多实现

一个类可以实现多个接口：

```java
public interface Printable {
    void print();
}

public interface Exportable {
    void export(String format);
}

// 一个类可以同时实现多个接口
public class Report implements Printable, Exportable {
    @Override
    public void print() {
        System.out.println("打印报表");
    }

    @Override
    public void export(String format) {
        System.out.println("导出为 " + format + " 格式");
    }
}
```

### 9.2.4 接口默认方法(JDK8+)

JDK 8 允许接口中定义有具体实现的 `default` 方法：

```java
public interface Loggable {
    // 默认方法：有具体实现，实现类可以选择重写或直接使用
    default void log(String message) {
        System.out.println("[LOG] " + message);
    }
}

public class Account implements Loggable {
    // 不需要重写 log 方法，直接继承默认实现
    public void deposit(double amount) {
        log("存款 " + amount);  // 使用默认方法
    }
}
```

### 9.2.5 接口静态方法(JDK8+)

```java
public interface StringUtils {
    static boolean isEmpty(String str) {
        return str == null || str.isEmpty();
    }
}

// 通过接口名调用
boolean result = StringUtils.isEmpty("");  // true
```

## 9.3 抽象类和接口区别

### 9.3.1 核心区别

| 对比项 | 抽象类 | 接口 |
|--------|--------|------|
| 关键字 | `abstract class` | `interface` |
| 继承/实现 | 单继承（`extends`） | 多实现（`implements`） |
| 构造方法 | 有 | 没有 |
| 成员变量 | 可以有各种成员变量 | 只能有 `public static final` 常量 |
| 方法 | 可以有抽象和具体方法 | JDK 8 前只能有抽象方法，JDK 8+ 可以有 default 和 static 方法 |
| 设计思想 | "是什么"（is-a 关系） | "能做什么"（has-a 能力） |

### 9.3.2 选择建议

- 如果多个类有共同的属性和行为 → 用**抽象类**（如 Animal 有 name、age）
- 如果只是定义能力/行为规范 → 用**接口**（如 Flyable、Swimmable）
- 需要多继承效果 → 用**接口**

## 9.4 综合案例

```java
// 接口：定义能力
public interface Flyable {
    void fly();
}

public interface Swimmable {
    void swim();
}

// 抽象类：定义共同属性
public abstract class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
    }

    public abstract void makeSound();
}

// 鸭子：继承 Animal，实现 Flyable 和 Swimmable
public class Duck extends Animal implements Flyable, Swimmable {
    public Duck(String name) {
        super(name);
    }

    @Override
    public void makeSound() {
        System.out.println(name + "：嘎嘎嘎！");
    }

    @Override
    public void fly() {
        System.out.println(name + " 在飞");
    }

    @Override
    public void swim() {
        System.out.println(name + " 在游泳");
    }
}

// 使用多态
public class Main {
    public static void main(String[] args) {
        Duck duck = new Duck("唐老鸭");
        duck.makeSound();  // 嘎嘎嘎！
        duck.fly();        // 在飞
        duck.swim();       // 在游泳

        // 通过接口引用
        Flyable flyer = duck;
        flyer.fly();

        Swimmable swimmer = duck;
        swimmer.swim();
    }
}
```

## 9.5 综合案例：支付系统

本案例融合接口和抽象类章节的核心知识点：抽象类、接口、多实现、default方法、静态方法、抽象类与接口的配合使用。

```java
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
import java.util.ArrayList;

/**
 * 支付系统
 * 融合知识点：抽象类、接口、多实现、default方法、接口静态方法、设计思想
 */

// 接口：定义日志能力
interface Loggable {
    // default 方法：提供默认日志实现
    default void log(String message) {
        String time = LocalDateTime.now().format(DateTimeFormatter.ofPattern("HH:mm:ss"));
        System.out.printf("  [%s LOG] %s%n", time, message);
    }
}

// 接口：定义支付能力
interface Payable {
    boolean pay(double amount);
    boolean refund(double amount);
    double getBalance();

    // 接口静态方法：校验金额
    static boolean isValidAmount(double amount) {
        return amount > 0 && amount < 1_000_000;
    }
}

// 接口：定义可查询能力
interface Queryable {
    String queryStatus();
    default void printStatus() {
        System.out.println("  状态：" + queryStatus());
    }
}

// 抽象类：支付方式基类（有共同属性和部分实现）
abstract class PaymentMethod implements Payable, Loggable, Queryable {
    protected String name;
    protected double balance;
    protected ArrayList<String> transactionHistory;
    private static int totalTransactions = 0;

    public PaymentMethod(String name, double initialBalance) {
        this.name = name;
        this.balance = initialBalance;
        this.transactionHistory = new ArrayList<>();
    }

    // 抽象方法：每种支付方式有不同的手续费计算
    public abstract double calculateFee(double amount);

    // 模板方法：支付流程（final 不允许重写）
    public final boolean processPay(double amount) {
        if (!Payable.isValidAmount(amount)) {  // 调用接口静态方法
            log("金额无效：" + amount);
            return false;
        }
        double fee = calculateFee(amount);
        double total = amount + fee;
        if (total > balance) {
            log("余额不足，需要 " + total + "，当前余额 " + balance);
            return false;
        }
        boolean result = pay(amount);
        if (result) {
            totalTransactions++;
            transactionHistory.add(String.format("支付 %.2f（手续费 %.2f）", amount, fee));
        }
        return result;
    }

    @Override
    public String queryStatus() {
        return String.format("%s [余额: %.2f, 交易: %d笔]",
                name, balance, transactionHistory.size());
    }

    public static int getTotalTransactions() { return totalTransactions; }
}

// 具体类：支付宝
class Alipay extends PaymentMethod {
    private String phoneNumber;

    public Alipay(String phone, double balance) {
        super("支付宝", balance);
        this.phoneNumber = phone;
    }

    @Override
    public double calculateFee(double amount) {
        return 0;  // 支付宝免手续费
    }

    @Override
    public boolean pay(double amount) {
        double fee = calculateFee(amount);
        balance -= (amount + fee);
        log(name + "支付 " + amount + " 元成功，免手续费");
        return true;
    }

    @Override
    public boolean refund(double amount) {
        balance += amount;
        log(name + "退款 " + amount + " 元");
        transactionHistory.add("退款 " + amount);
        return true;
    }

    @Override
    public double getBalance() { return balance; }
}

// 具体类：银行卡
class BankCard extends PaymentMethod {
    private String cardNumber;

    public BankCard(String card, double balance) {
        super("银行卡", balance);
        this.cardNumber = card.substring(card.length() - 4); // 只存后4位
    }

    @Override
    public double calculateFee(double amount) {
        return amount * 0.005;  // 银行卡 0.5% 手续费
    }

    @Override
    public boolean pay(double amount) {
        double fee = calculateFee(amount);
        balance -= (amount + fee);
        log(String.format("%s(尾号%s)支付 %.2f 元，手续费 %.2f",
                name, cardNumber, amount, fee));
        return true;
    }

    @Override
    public boolean refund(double amount) {
        balance += amount;  // 退款不退手续费
        log(name + "退款 " + amount + " 元（手续费不退）");
        transactionHistory.add("退款 " + amount);
        return true;
    }

    @Override
    public double getBalance() { return balance; }
}

// 具体类：微信支付
class WechatPay extends PaymentMethod {
    public WechatPay(double balance) {
        super("微信支付", balance);
    }

    @Override
    public double calculateFee(double amount) {
        return amount > 500 ? amount * 0.001 : 0;  // 500以上收0.1%手续费
    }

    @Override
    public boolean pay(double amount) {
        double fee = calculateFee(amount);
        balance -= (amount + fee);
        String feeInfo = fee > 0 ? String.format("手续费 %.2f", fee) : "免手续费";
        log(String.format("%s支付 %.2f 元，%s", name, amount, feeInfo));
        return true;
    }

    @Override
    public boolean refund(double amount) {
        balance += amount;
        log(name + "退款 " + amount + " 元");
        transactionHistory.add("退款 " + amount);
        return true;
    }

    @Override
    public double getBalance() { return balance; }
}

public class PaymentSystem {
    // 多态方法：接受任何支付方式
    public static void checkout(PaymentMethod payment, double amount) {
        System.out.printf("%n--- 结算：%.2f 元 ---%n", amount);
        payment.printStatus();  // 调用 Queryable 的 default 方法
        boolean success = payment.processPay(amount);
        System.out.println("  结果：" + (success ? "成功 ✓" : "失败 ✗"));
        if (success) {
            payment.printStatus();
        }
    }

    public static void main(String[] args) {
        // 创建不同的支付方式
        Alipay alipay = new Alipay("13800138000", 5000);
        BankCard bankCard = new BankCard("6222021234567890", 10000);
        WechatPay wechat = new WechatPay(3000);

        // 多态：统一的支付接口
        PaymentMethod[] payments = {alipay, bankCard, wechat};

        System.out.println("╔═══════════════════════════════╗");
        System.out.println("║        支付系统演示           ║");
        System.out.println("╚═══════════════════════════════╝");

        // 使用不同的支付方式支付
        checkout(alipay, 299.99);
        checkout(bankCard, 1580);
        checkout(wechat, 680);
        checkout(wechat, 88);  // 低于500，免手续费

        // 退款
        System.out.println("\n--- 退款操作 ---");
        bankCard.refund(500);

        // 通过接口引用使用
        System.out.println("\n--- 通过 Payable 接口引用 ---");
        Payable payable = alipay;
        System.out.println("余额：" + payable.getBalance());

        // 通过 Queryable 接口引用
        Queryable queryable = bankCard;
        queryable.printStatus();

        // 统计
        System.out.println("\n--- 系统统计 ---");
        System.out.println("总交易笔数：" + PaymentMethod.getTotalTransactions());
        for (PaymentMethod pm : payments) {
            System.out.printf("  %s%n", pm.queryStatus());
        }
    }
}
```

**案例知识点总结：**

| 知识点 | 案例中的体现 |
|--------|-------------|
| 抽象类 | `PaymentMethod` 有共同属性和模板方法 |
| 抽象方法 | `calculateFee()` 由子类实现 |
| 接口定义 | `Payable`、`Loggable`、`Queryable` |
| 接口多实现 | `PaymentMethod implements Payable, Loggable, Queryable` |
| default 方法 | `Loggable.log()`、`Queryable.printStatus()` |
| 接口静态方法 | `Payable.isValidAmount()` |
| 抽象类 + 接口配合 | 抽象类实现接口，具体类继承抽象类 |
| 多态 | `PaymentMethod[] payments`，`checkout(PaymentMethod, double)` |
| 接口引用 | `Payable payable = alipay`、`Queryable queryable = bankCard` |
| 设计思想 | is-a（继承）vs has-a（接口能力） |
