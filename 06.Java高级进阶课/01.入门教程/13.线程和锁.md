## 13.1 线程基础

### 13.1.1 线程介绍

Java 从语言级别支持多线程编程。一个 Java 程序至少有一个线程——`main` 线程。

**对比 C++**：C++11 才通过 `std::thread` 引入标准库线程支持，Java 从 1.0 版本就内置了线程支持。

### 13.1.2 创建线程-继承Thread

```java
public class MyThread extends Thread {
    @Override
    public void run() {
        for (int i = 0; i < 5; i++) {
            System.out.println(getName() + ": " + i);
        }
    }
}

MyThread t = new MyThread();
t.start();  // 启动线程（不是调用 run）
```

### 13.1.3 创建线程-实现Runnable

```java
public class MyRunnable implements Runnable {
    @Override
    public void run() {
        for (int i = 0; i < 5; i++) {
            System.out.println(Thread.currentThread().getName() + ": " + i);
        }
    }
}

Thread t = new Thread(new MyRunnable());
t.start();

// Lambda 简写
Thread t2 = new Thread(() -> {
    System.out.println("Lambda 线程执行");
});
t2.start();
```

### 13.1.4 创建线程-实现Callable

`Callable` 可以有返回值和抛出异常：

```java
import java.util.concurrent.*;

Callable<Integer> task = () -> {
    int sum = 0;
    for (int i = 1; i <= 100; i++) sum += i;
    return sum;
};

FutureTask<Integer> future = new FutureTask<>(task);
new Thread(future).start();
System.out.println("结果：" + future.get());  // 5050
```

### 13.1.5 线程生命周期

```
新建(New) → start() → 就绪(Runnable) → 获得CPU → 运行(Running)
                                              ↓
                            阻塞(Blocked/Waiting/Timed_Waiting)
                                              ↓
                                        终止(Terminated)
```

## 13.2 线程控制

### 13.2.1 线程休眠sleep

```java
Thread.sleep(1000);  // 当前线程休眠1秒
```

### 13.2.2 线程等待join

```java
Thread t = new Thread(() -> {
    System.out.println("子线程执行");
});
t.start();
t.join();  // 主线程等待 t 执行完毕
System.out.println("子线程执行完了");
```

### 13.2.3 线程让步yield

```java
Thread.yield();  // 让出CPU时间片，让其他线程执行
```

### 13.2.4 守护线程

```java
Thread daemon = new Thread(() -> {
    while (true) {
        System.out.println("守护线程运行中...");
    }
});
daemon.setDaemon(true);  // 设为守护线程
daemon.start();
// 主线程结束后，守护线程自动终止
```

## 13.3 线程安全

### 13.3.1 数据竞争问题

```java
public class Counter {
    private int count = 0;

    public void increment() {
        count++;  // 非原子操作，多线程下会出问题
    }

    public int getCount() {
        return count;
    }
}
```

### 13.3.2 synchronized关键字

```java
public class Counter {
    private int count = 0;

    // synchronized 方法
    public synchronized void increment() {
        count++;
    }

    public synchronized int getCount() {
        return count;
    }
}
```

### 13.3.3 synchronized方法和代码块

```java
public class Account {
    private double balance;
    private final Object lock = new Object();

    // 同步方法
    public synchronized void deposit(double amount) {
        balance += amount;
    }

    // 同步代码块（更细粒度的控制）
    public void withdraw(double amount) {
        synchronized (lock) {
            if (balance >= amount) {
                balance -= amount;
            }
        }
    }
}
```

**对比 C++**：C++ 使用 `std::mutex` 和 `std::lock_guard`，Java 用 `synchronized` 关键字更加简洁。

## 13.4 Lock锁

### 13.4.1 ReentrantLock

```java
import java.util.concurrent.locks.ReentrantLock;

public class Account {
    private double balance;
    private final ReentrantLock lock = new ReentrantLock();

    public void deposit(double amount) {
        lock.lock();
        try {
            balance += amount;
        } finally {
            lock.unlock();  // 必须在 finally 中释放锁
        }
    }
}
```

### 13.4.2 读写锁ReadWriteLock

```java
import java.util.concurrent.locks.ReadWriteLock;
import java.util.concurrent.locks.ReentrantReadWriteLock;

public class Account {
    private double balance;
    private final ReadWriteLock rwLock = new ReentrantReadWriteLock();

    public double getBalance() {
        rwLock.readLock().lock();  // 读锁（多线程可同时读）
        try {
            return balance;
        } finally {
            rwLock.readLock().unlock();
        }
    }

    public void deposit(double amount) {
        rwLock.writeLock().lock();  // 写锁（独占）
        try {
            balance += amount;
        } finally {
            rwLock.writeLock().unlock();
        }
    }
}
```

## 13.5 线程通信

### 13.5.1 wait和notify

```java
synchronized (lock) {
    while (条件不满足) {
        lock.wait();   // 释放锁并等待
    }
    // 执行操作
    lock.notifyAll();  // 唤醒其他等待的线程
}
```

### 13.5.2 生产者消费者模型

```java
import java.util.LinkedList;
import java.util.Queue;

public class MessageQueue {
    private final Queue<String> queue = new LinkedList<>();
    private final int capacity;

    public MessageQueue(int capacity) {
        this.capacity = capacity;
    }

    public synchronized void produce(String message) throws InterruptedException {
        while (queue.size() == capacity) {
            wait();  // 队列满了，等待
        }
        queue.offer(message);
        System.out.println("生产：" + message);
        notifyAll();  // 通知消费者
    }

    public synchronized String consume() throws InterruptedException {
        while (queue.isEmpty()) {
            wait();  // 队列空了，等待
        }
        String message = queue.poll();
        System.out.println("消费：" + message);
        notifyAll();  // 通知生产者
        return message;
    }
}
```

## 13.6 线程池

### 13.6.1 为什么需要线程池

频繁创建和销毁线程开销大，线程池可以复用线程，控制并发数量。

### 13.6.2 创建线程池

```java
import java.util.concurrent.*;

// 固定大小线程池
ExecutorService pool = Executors.newFixedThreadPool(3);

for (int i = 0; i < 10; i++) {
    final int taskId = i;
    pool.submit(() -> {
        System.out.println(Thread.currentThread().getName() + " 执行任务 " + taskId);
    });
}

pool.shutdown();  // 关闭线程池
```

### 13.6.3 线程池参数

```java
// 自定义线程池（推荐）
ThreadPoolExecutor executor = new ThreadPoolExecutor(
    2,                  // 核心线程数
    5,                  // 最大线程数
    60, TimeUnit.SECONDS, // 空闲线程存活时间
    new LinkedBlockingQueue<>(100),  // 任务队列
    new ThreadPoolExecutor.AbortPolicy()  // 拒绝策略
);
```

## 13.8 综合案例：多线程下载模拟器

本案例融合线程和锁章节的核心知识点：Thread/Runnable/Callable、synchronized、ReentrantLock、wait/notify、线程池、volatile、AtomicInteger等。

```java
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.atomic.AtomicLong;
import java.util.concurrent.locks.ReentrantLock;

/**
 * 多线程下载模拟器
 * 融合知识点：线程创建、synchronized、Lock、wait/notify、线程池、volatile、原子类
 */
public class DownloadSimulator {

    // 下载任务
    static class DownloadTask {
        final String fileName;
        final long totalSize;  // 总大小（KB）
        final AtomicLong downloadedSize;  // 已下载大小（原子类保证线程安全）
        volatile boolean paused;  // volatile 保证可见性
        volatile boolean cancelled;

        public DownloadTask(String fileName, long totalSize) {
            this.fileName = fileName;
            this.totalSize = totalSize;
            this.downloadedSize = new AtomicLong(0);
            this.paused = false;
            this.cancelled = false;
        }

        public double getProgress() {
            return (double) downloadedSize.get() / totalSize * 100;
        }

        public boolean isComplete() {
            return downloadedSize.get() >= totalSize;
        }
    }

    // 下载工作线程（实现 Callable，有返回值）
    static class DownloadWorker implements Callable<Boolean> {
        private final DownloadTask task;
        private final int threadId;
        private final long startPos;
        private final long endPos;
        private final ReentrantLock pauseLock;
        private final Object pauseMonitor;

        public DownloadWorker(DownloadTask task, int threadId,
                              long startPos, long endPos,
                              ReentrantLock pauseLock, Object pauseMonitor) {
            this.task = task;
            this.threadId = threadId;
            this.startPos = startPos;
            this.endPos = endPos;
            this.pauseLock = pauseLock;
            this.pauseMonitor = pauseMonitor;
        }

        @Override
        public Boolean call() throws Exception {
            long pos = startPos;
            while (pos < endPos && !task.cancelled) {
                // 暂停检查（wait/notify）
                synchronized (pauseMonitor) {
                    while (task.paused && !task.cancelled) {
                        pauseMonitor.wait();  // 暂停时等待
                    }
                }

                // 模拟下载一个块
                long chunkSize = Math.min(50, endPos - pos);
                Thread.sleep(10 + (int) (Math.random() * 20));

                // 原子操作更新进度
                task.downloadedSize.addAndGet(chunkSize);
                pos += chunkSize;
            }
            return !task.cancelled;
        }
    }

    // 进度监控线程（守护线程 + Runnable）
    static class ProgressMonitor implements Runnable {
        private final DownloadTask[] tasks;
        private volatile boolean running = true;
        private final AtomicInteger completedCount;

        public ProgressMonitor(DownloadTask[] tasks, AtomicInteger completedCount) {
            this.tasks = tasks;
            this.completedCount = completedCount;
        }

        @Override
        public void run() {
            while (running) {
                StringBuilder sb = new StringBuilder("\r  进度：");
                for (DownloadTask task : tasks) {
                    String status;
                    if (task.cancelled) status = "已取消";
                    else if (task.isComplete()) status = "完成 ✓";
                    else if (task.paused) status = "暂停";
                    else status = String.format("%.0f%%", task.getProgress());

                    sb.append(String.format("[%s:%s] ", task.fileName, status));
                }
                sb.append(String.format("已完成: %d/%d", completedCount.get(), tasks.length));
                System.out.print(sb);

                try {
                    Thread.sleep(200);
                } catch (InterruptedException e) {
                    break;
                }
            }
        }

        public void stop() { running = false; }
    }

    // 下载管理器
    static class DownloadManager {
        private final ExecutorService threadPool;
        private final ReentrantLock pauseLock = new ReentrantLock();
        private final Object pauseMonitor = new Object();
        private final AtomicInteger completedCount = new AtomicInteger(0);

        // synchronized 方法：线程安全的统计
        private int totalTasks;
        public synchronized void setTotalTasks(int n) { this.totalTasks = n; }
        public synchronized int getTotalTasks() { return totalTasks; }

        public DownloadManager(int poolSize) {
            // 自定义线程池
            threadPool = new ThreadPoolExecutor(
                    poolSize, poolSize * 2,
                    60, TimeUnit.SECONDS,
                    new LinkedBlockingQueue<>(100),
                    r -> {
                        Thread t = new Thread(r);
                        t.setDaemon(false);
                        return t;
                    }
            );
        }

        public void download(DownloadTask task, int threads) throws Exception {
            long chunkSize = task.totalSize / threads;
            Future<Boolean>[] futures = new Future[threads];

            // 提交多个下载工作线程
            for (int i = 0; i < threads; i++) {
                long start = i * chunkSize;
                long end = (i == threads - 1) ? task.totalSize : (i + 1) * chunkSize;
                futures[i] = threadPool.submit(
                        new DownloadWorker(task, i, start, end, pauseLock, pauseMonitor));
            }

            // 等待所有线程完成（join 的效果）
            boolean allSuccess = true;
            for (Future<Boolean> future : futures) {
                try {
                    Boolean result = future.get(30, TimeUnit.SECONDS);  // 超时控制
                    if (!result) allSuccess = false;
                } catch (TimeoutException e) {
                    future.cancel(true);
                    allSuccess = false;
                }
            }

            if (allSuccess && task.isComplete()) {
                completedCount.incrementAndGet();
            }
        }

        // 暂停（notify 唤醒）
        public void pauseTask(DownloadTask task) {
            task.paused = true;
        }

        public void resumeTask(DownloadTask task) {
            task.paused = false;
            synchronized (pauseMonitor) {
                pauseMonitor.notifyAll();
            }
        }

        public void cancelTask(DownloadTask task) {
            task.cancelled = true;
            synchronized (pauseMonitor) {
                pauseMonitor.notifyAll();
            }
        }

        public void shutdown() {
            threadPool.shutdown();
            try {
                threadPool.awaitTermination(10, TimeUnit.SECONDS);
            } catch (InterruptedException e) {
                threadPool.shutdownNow();
            }
        }

        public AtomicInteger getCompletedCount() { return completedCount; }
    }

    public static void main(String[] args) throws Exception {
        System.out.println("╔═══════════════════════════════╗");
        System.out.println("║    多线程下载模拟器           ║");
        System.out.println("╚═══════════════════════════════╝");

        DownloadManager manager = new DownloadManager(4);

        // 创建下载任务
        DownloadTask[] tasks = {
                new DownloadTask("video.mp4", 5000),
                new DownloadTask("music.mp3", 2000),
                new DownloadTask("doc.pdf", 1000),
        };
        manager.setTotalTasks(tasks.length);

        // 启动进度监控（守护线程）
        ProgressMonitor monitor = new ProgressMonitor(tasks, manager.getCompletedCount());
        Thread monitorThread = new Thread(monitor);
        monitorThread.setDaemon(true);
        monitorThread.start();

        // 并发下载所有任务
        Thread[] downloadThreads = new Thread[tasks.length];
        for (int i = 0; i < tasks.length; i++) {
            final DownloadTask task = tasks[i];
            downloadThreads[i] = new Thread(() -> {
                try {
                    manager.download(task, 3);
                } catch (Exception e) {
                    System.out.println("\n  下载出错：" + e.getMessage());
                }
            });
            downloadThreads[i].start();
        }

        // 模拟暂停和恢复
        Thread.sleep(500);
        System.out.println("\n\n  >>> 暂停 video.mp4");
        manager.pauseTask(tasks[0]);
        Thread.sleep(1000);
        System.out.println("\n  >>> 恢复 video.mp4");
        manager.resumeTask(tasks[0]);

        // 等待所有下载完成（join）
        for (Thread t : downloadThreads) {
            t.join();
        }

        monitor.stop();
        Thread.sleep(300);  // 让监控线程最后输出一次

        // 输出最终结果
        System.out.println("\n\n--- 下载结果 ---");
        for (DownloadTask task : tasks) {
            String status = task.isComplete() ? "完成 ✓" :
                    task.cancelled ? "已取消 ✗" : "未完成";
            System.out.printf("  %-12s %5dKB  %s%n", task.fileName, task.totalSize, status);
        }
        System.out.println("  总完成：" + manager.getCompletedCount() + "/" + tasks.length);

        manager.shutdown();
    }
}
```

**案例知识点总结：**

| 知识点 | 案例中的体现 |
|--------|-------------|
| Thread/Runnable | `ProgressMonitor implements Runnable` |
| Callable/Future | `DownloadWorker implements Callable<Boolean>`，`future.get()` |
| 线程池 | `ThreadPoolExecutor` 自定义参数 |
| synchronized | 同步方法 `setTotalTasks()` |
| ReentrantLock | `pauseLock` |
| wait/notify | 暂停/恢复机制 `pauseMonitor.wait()/notifyAll()` |
| volatile | `paused`、`cancelled`、`running` 可见性保证 |
| AtomicInteger/AtomicLong | 线程安全的计数器和进度 |
| 守护线程 | `monitorThread.setDaemon(true)` |
| Thread.join | 等待下载线程完成 |
| Thread.sleep | 模拟下载耗时 |
| Future.get(timeout) | 超时控制 |
