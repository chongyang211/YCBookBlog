## 7.1 类的介绍

### 7.1.1 类的含义

类是对象的模板（蓝图），封装了数据（属性/字段）和行为（方法）。对象是类的实例。

```
类（Class）：设计图纸        →  对象（Object）：根据图纸造出的房子
Account 类（账户模板）       →  张三的账户、李四的账户（具体的账户对象）
```

**对比 C++**：概念完全一致。区别在于 Java 中所有对象都在堆上创建（通过 `new`），没有 C++ 中在栈上创建对象的方式。

### 7.1.2 面向对象三大特性

1. **封装**：将数据和操作数据的方法绑定在一起，隐藏内部实现细节。
2. **继承**：子类继承父类的属性和方法，实现代码复用。
3. **多态**：同一个方法在不同对象上有不同的表现形式。

## 7.2 类定义和对象

### 7.2.1 类的定义

```java
public class Account {
    // 成员变量（属性）
    private String name;
    private double balance;

    // 构造方法
    public Account(String name, double balance) {
        this.name = name;
        this.balance = balance;
    }

    // 成员方法（行为）
    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
            System.out.println(name + " 存入 " + amount + "，余额：" + balance);
        }
    }

    public void withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
            System.out.println(name + " 取出 " + amount + "，余额：" + balance);
        }
    }

    // getter 和 setter
    public String getName() { return name; }
    public double getBalance() { return balance; }
}
```

### 7.2.2 创建对象

```java
// 使用 new 创建对象
Account acc1 = new Account("张三", 1000);
Account acc2 = new Account("李四", 2000);
```

**对比 C++**：

```cpp
// C++ 可以在栈上创建
Account acc1("张三", 1000);
// C++ 也可以在堆上创建
Account* acc2 = new Account("李四", 2000);
delete acc2;  // 需要手动释放
```

Java 不需要 `delete`，GC 会自动回收不再使用的对象。

### 7.2.3 访问类成员

```java
Account acc = new Account("张三", 1000);
acc.deposit(500);
acc.withdraw(200);
System.out.println(acc.getName());     // 张三
System.out.println(acc.getBalance());  // 1300
```

### 7.2.4 案例实践

```java
public class Main {
    public static void main(String[] args) {
        Account acc1 = new Account("张三", 1000);
        Account acc2 = new Account("李四", 2000);

        acc1.deposit(500);   // 张三 存入 500，余额：1500
        acc2.withdraw(800);  // 李四 取出 800，余额：1200

        System.out.println(acc1.getName() + " 余额：" + acc1.getBalance());
        System.out.println(acc2.getName() + " 余额：" + acc2.getBalance());
    }
}
```

## 7.3 类成员属性

### 7.3.1 成员变量

```java
public class Account {
    // 实例变量：每个对象各自拥有
    String name;
    double balance;

    // 类变量（静态变量）：所有对象共享
    static int totalCount = 0;
}
```

成员变量的默认值：

| 类型 | 默认值 |
|------|--------|
| `int`、`long` 等整数类型 | 0 |
| `float`、`double` | 0.0 |
| `boolean` | false |
| `char` | '\u0000' |
| 引用类型 | null |

### 7.3.2 成员方法

```java
public class Account {
    private String name;
    private double balance;

    // 实例方法
    public void deposit(double amount) {
        balance += amount;
    }

    // 静态方法
    public static void printWelcome() {
        System.out.println("欢迎使用银行系统");
    }
}

// 调用
Account acc = new Account();
acc.deposit(100);           // 实例方法通过对象调用
Account.printWelcome();     // 静态方法通过类名调用
```

### 7.3.3 访问权限

```java
public class Account {
    public String name;          // 公共
    protected double balance;    // 受保护
    int id;                      // 默认（包访问）
    private String password;     // 私有
}
```

### 7.3.4 封装思想

封装的核心思想：**属性私有化，方法公开化**。

```java
public class Account {
    // 属性私有
    private String name;
    private double balance;

    // 通过公开的方法访问
    public String getName() {
        return name;
    }

    public void setName(String name) {
        // 可以在 setter 中加入验证逻辑
        if (name != null && !name.isEmpty()) {
            this.name = name;
        }
    }

    public double getBalance() {
        return balance;
    }

    // balance 只提供 getter，不提供 setter（只读）
    // 余额只能通过 deposit 和 withdraw 修改
    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }
}
```

## 7.4 对象初始化

### 7.4.1 构造方法

构造方法在创建对象时自动调用，用于初始化对象。构造方法的名字**必须与类名相同**，**没有返回类型**。

```java
public class Account {
    private String name;
    private double balance;

    // 无参构造
    public Account() {
        this.name = "未命名";
        this.balance = 0;
    }

    // 有参构造
    public Account(String name, double balance) {
        this.name = name;
        this.balance = balance;
    }
}
```

> 注意：如果你不写任何构造方法，编译器会自动提供一个**默认的无参构造方法**。但如果你写了有参构造，编译器就不会自动生成无参构造了。

**对比 C++**：C++ 有构造函数和析构函数。Java 有构造方法但没有析构函数（有 `finalize` 方法，但已被弃用），内存由 GC 管理。

### 7.4.2 构造方法重载

```java
public class Account {
    private String name;
    private double balance;
    private String type;

    public Account() {
        this("未命名", 0, "普通");  // 调用另一个构造方法
    }

    public Account(String name) {
        this(name, 0, "普通");
    }

    public Account(String name, double balance, String type) {
        this.name = name;
        this.balance = balance;
        this.type = type;
    }
}
```

### 7.4.3 this关键字

`this` 指向当前对象的引用：

```java
public class Account {
    private String name;

    public Account(String name) {
        this.name = name;  // this.name 是成员变量，name 是参数
    }

    public Account getThis() {
        return this;  // 返回当前对象
    }
}
```

**对比 C++**：C++ 的 `this` 是指针（`this->`），Java 的 `this` 是引用（`this.`）。

### 7.4.4 构造代码块和静态代码块

```java
public class Account {
    static int count;

    // 静态代码块：类加载时执行一次
    static {
        count = 0;
        System.out.println("静态代码块执行");
    }

    // 构造代码块：每次创建对象时执行（在构造方法之前）
    {
        count++;
        System.out.println("构造代码块执行");
    }

    public Account() {
        System.out.println("构造方法执行");
    }
}

// 执行顺序：静态代码块 → 构造代码块 → 构造方法
```

### 7.4.5 对象生命周期

```java
public void method() {
    Account acc = new Account("张三", 1000);  // 对象创建，在堆上分配内存
    acc.deposit(500);
}  // 方法结束，acc 引用失效，对象变成垃圾，等待 GC 回收
```

**对比 C++**：C++ 需要手动 `delete` 释放堆上对象，栈上对象在作用域结束时自动销毁（RAII）。Java 全部由 GC 自动管理。

## 7.5 static关键字

### 7.5.1 静态变量

```java
public class Account {
    static int totalCount = 0;  // 所有对象共享
    String name;                // 每个对象各自拥有

    public Account(String name) {
        this.name = name;
        totalCount++;
    }
}

new Account("张三");
new Account("李四");
System.out.println(Account.totalCount);  // 2
```

### 7.5.2 静态方法

```java
public class MathUtils {
    public static int max(int a, int b) {
        return a > b ? a : b;
    }

    public static int min(int a, int b) {
        return a < b ? a : b;
    }
}

// 通过类名调用
int result = MathUtils.max(10, 20);
```

### 7.5.3 静态常量

```java
public class Constants {
    public static final double PI = 3.14159265;
    public static final int MAX_SIZE = 100;
    public static final String APP_NAME = "银行系统";
}

System.out.println(Constants.PI);
```

### 7.6.3 匿名内部类

```java

interface Callback {
```

## 7.7 枚举类

### 7.7.1 枚举定义

```java
public enum AccountType {
    SAVINGS,     // 储蓄账户
    CHECKING,    // 活期账户
    CREDIT       // 信用账户
}

// 使用
AccountType type = AccountType.SAVINGS;
System.out.println(type);  // SAVINGS
```

### 7.7.2 枚举方法

```java
public enum AccountType {
    SAVINGS("储蓄账户", 0.03),
    CHECKING("活期账户", 0.01),
    CREDIT("信用账户", 0.18);

    private String desc;
    private double rate;

    AccountType(String desc, double rate) {
        this.desc = desc;
        this.rate = rate;
    }

    public String getDesc() { return desc; }
    public double getRate() { return rate; }
}

// 使用
AccountType type = AccountType.SAVINGS;
System.out.println(type.getDesc());  // 储蓄账户
System.out.println(type.getRate());  // 0.03

// 遍历所有枚举值
for (AccountType t : AccountType.values()) {
    System.out.println(t.name() + ": " + t.getDesc());
}
```

**对比 C++**：C++ 的 `enum class` 只是整数常量的集合，Java 的枚举是完整的类，可以有属性、方法、构造方法，功能强大得多。

## 7.8 综合案例：图书馆管理系统

本案例融合类和对象章节的核心知识点：类定义、封装、构造方法、static成员、this关键字、内部类、枚举、对象生命周期等。

```java
import java.util.ArrayList;

/**
 * 图书馆管理系统
 * 融合知识点：类定义、封装、构造方法重载、static、this、内部类、枚举
 */
public class Library {
    // 静态常量
    public static final int MAX_BOOKS = 1000;

    // 枚举：图书状态
    public enum BookStatus {
        AVAILABLE("可借阅"),
        BORROWED("已借出"),
        DAMAGED("已损坏");

        private final String desc;
        BookStatus(String desc) { this.desc = desc; }
        public String getDesc() { return desc; }
    }

    // 枚举：图书类别
    public enum Category {
        FICTION("小说", 30),
        TECH("技术", 14),
        HISTORY("历史", 21);

        private final String name;
        private final int loanDays;  // 借阅天数
        Category(String name, int loanDays) {
            this.name = name;
            this.loanDays = loanDays;
        }
        public String getName() { return name; }
        public int getLoanDays() { return loanDays; }
    }

    // 内部类：图书
    public class Book {
        private final String isbn;
        private String title;
        private String author;
        private Category category;
        private BookStatus status;

        // 构造方法重载
        public Book(String isbn, String title, String author) {
            this(isbn, title, author, Category.FICTION);
        }

        public Book(String isbn, String title, String author, Category category) {
            this.isbn = isbn;
            this.title = title;
            this.author = author;
            this.category = category;
            this.status = BookStatus.AVAILABLE;
            bookCount++;  // 访问外部类的静态变量
        }

        // 封装：getter/setter
        public String getIsbn() { return isbn; }
        public String getTitle() { return title; }
        public String getAuthor() { return author; }
        public BookStatus getStatus() { return status; }
        public Category getCategory() { return category; }

        // 借阅方法（封装业务逻辑）
        public boolean borrow() {
            if (this.status != BookStatus.AVAILABLE) return false;
            this.status = BookStatus.BORROWED;
            return true;
        }

        // 归还方法
        public void returnBook() {
            this.status = BookStatus.AVAILABLE;
        }

        @Override
        public String toString() {
            return String.format("[%s] %s - %s (%s) [%s]",
                    isbn, title, author, category.getName(), status.getDesc());
        }
    }

    // 静态内部类：统计信息
    public static class Statistics {
        private int totalBooks;
        private int borrowedBooks;
        private int availableBooks;

        public Statistics(int total, int borrowed) {
            this.totalBooks = total;
            this.borrowedBooks = borrowed;
            this.availableBooks = total - borrowed;
        }

        public void print() {
            System.out.println("--- 图书馆统计 ---");
            System.out.printf("  总藏书：%d 本%n", totalBooks);
            System.out.printf("  可借阅：%d 本%n", availableBooks);
            System.out.printf("  已借出：%d 本%n", borrowedBooks);
            System.out.printf("  利用率：%.1f%%%n",
                    totalBooks > 0 ? (double) borrowedBooks / totalBooks * 100 : 0);
        }
    }

    // Library 的成员变量
    private String name;
    private ArrayList<Book> books;
    private static int bookCount = 0;  // 静态变量：全局图书计数

    // 构造代码块
    {
        System.out.println("图书馆实例初始化中...");
    }

    // 静态代码块
    static {
        System.out.println("图书馆类加载完成");
    }

    // 构造方法
    public Library(String name) {
        this.name = name;
        this.books = new ArrayList<>();
    }

    // 添加图书
    public Book addBook(String isbn, String title, String author, Category category) {
        if (books.size() >= MAX_BOOKS) {
            System.out.println("图书馆已满！");
            return null;
        }
        Book book = new Book(isbn, title, author, category);
        books.add(book);
        return book;
    }

    // 按关键字搜索
    public void search(String keyword) {
        System.out.println("搜索结果（关键字：" + keyword + "）：");
        boolean found = false;
        for (Book book : books) {
            if (book.getTitle().contains(keyword) || book.getAuthor().contains(keyword)) {
                System.out.println("  " + book);
                found = true;
            }
        }
        if (!found) System.out.println("  未找到匹配的图书");
    }

    // 获取统计信息
    public Statistics getStatistics() {
        int borrowed = 0;
        for (Book book : books) {
            if (book.getStatus() == BookStatus.BORROWED) borrowed++;
        }
        return new Statistics(books.size(), borrowed);
    }

    // 显示所有图书
    public void listAll() {
        System.out.println("\n=== " + name + " 藏书列表 ===");
        if (books.isEmpty()) {
            System.out.println("  暂无藏书");
            return;
        }
        for (int i = 0; i < books.size(); i++) {
            System.out.printf("  %d. %s%n", i + 1, books.get(i));
        }
    }

    // 静态方法：获取全局图书数量
    public static int getBookCount() {
        return bookCount;
    }

    public static void main(String[] args) {
        // 创建图书馆
        Library lib = new Library("城市中心图书馆");

        // 添加图书（使用不同的构造方法）
        Library.Book b1 = lib.addBook("978-1", "Java编程思想", "Bruce Eckel", Category.TECH);
        Library.Book b2 = lib.addBook("978-2", "三体", "刘慈欣", Category.FICTION);
        Library.Book b3 = lib.addBook("978-3", "人类简史", "尤瓦尔·赫拉利", Category.HISTORY);
        Library.Book b4 = lib.addBook("978-4", "Effective Java", "Joshua Bloch", Category.TECH);

        // 显示所有图书
        lib.listAll();

        // 借阅操作
        System.out.println("\n=== 借阅操作 ===");
        if (b1.borrow()) {
            System.out.println("借阅成功：" + b1.getTitle()
                    + "（可借 " + b1.getCategory().getLoanDays() + " 天）");
        }
        if (b2.borrow()) {
            System.out.println("借阅成功：" + b2.getTitle()
                    + "（可借 " + b2.getCategory().getLoanDays() + " 天）");
        }
        // 重复借阅
        if (!b1.borrow()) {
            System.out.println("借阅失败：" + b1.getTitle() + " 已被借出");
        }

        // 搜索
        System.out.println();
        lib.search("Java");

        // 归还
        System.out.println("\n=== 归还操作 ===");
        b1.returnBook();
        System.out.println("已归还：" + b1.getTitle());

        // 统计（使用静态内部类）
        System.out.println();
        Library.Statistics stats = lib.getStatistics();
        stats.print();

        // 静态方法
        System.out.println("\n全局图书总数：" + Library.getBookCount());

        // 枚举遍历
        System.out.println("\n=== 图书类别信息 ===");
        for (Category cat : Category.values()) {
            System.out.printf("  %s（%s）- 可借 %d 天%n",
                    cat.name(), cat.getName(), cat.getLoanDays());
        }
    }
}
```

| static final 常量 | `MAX_BOOKS` |
| 静态代码块 | 类加载时执行的初始化 |
| 构造代码块 | 每次创建对象前执行 |
| 成员内部类 | `Book` 类可访问外部类成员 |
| 静态内部类 | `Statistics` 不依赖外部类实例 |
| 枚举 | `BookStatus`、`Category` 带属性和方法 |
| toString 重写 | `Book.toString()` |
