## 11.1 集合概述

### 11.1.1 为什么需要集合

数组的局限：大小固定，不能动态扩容；只能存储同一类型元素；增删操作不方便。

集合的优势：大小动态变化；提供丰富的操作方法（增删改查排序等）；可以存储不同类型的对象（配合泛型更安全）。

**对比 C++**：C++ 的 STL 提供了 `vector`、`list`、`set`、`map` 等容器，Java 的集合框架与之对应。

### 11.1.2 集合体系结构

```
Collection（接口）
├── List（有序、可重复）
│   ├── ArrayList（数组实现，查询快）
│   ├── LinkedList（链表实现，增删快）
│   └── Vector（线程安全，已过时）
├── Set（无序、不重复）
│   ├── HashSet（哈希表实现）
│   ├── LinkedHashSet（有序的HashSet）
│   └── TreeSet（红黑树，有序）
└── Queue（队列）
    ├── LinkedList
    └── PriorityQueue

Map（接口，键值对）
├── HashMap（哈希表实现）
├── LinkedHashMap（有序的HashMap）
├── TreeMap（红黑树，有序）
└── Hashtable（线程安全，已过时）
```

## 11.2 List集合

### 11.2.1 ArrayList

**ArrayList 的底层原理**：`ArrayList` 内部使用 `Object[] elementData` 数组存储元素。默认初始容量为 **10**（首次 add 时才分配），当容量不足时按 `oldCapacity + (oldCapacity >> 1)` 扩容（即 1.5 倍）。扩容时调用 `Arrays.copyOf()` 创建新数组并复制数据，因此频繁扩容会影响性能。如果预知元素数量，建议使用 `new ArrayList<>(1000)` 预分配容量。`get(index)` 直接通过数组下标访问（O(1)），而 `add(index, element)` 和 `remove(index)` 需要调用 `System.arraycopy()` 移动后续元素（O(n)）。

```java
import java.util.ArrayList;

ArrayList<String> list = new ArrayList<>();

// 添加
list.add("张三");
list.add("李四");
list.add("王五");
list.add(1, "赵六");  // 在索引1处插入

// 获取
String name = list.get(0);  // 张三
int size = list.size();      // 4

// 修改
list.set(0, "张三丰");

// 删除
list.remove(0);           // 按索引删除
list.remove("李四");       // 按元素删除

// 查找
boolean contains = list.contains("王五");  // true
int index = list.indexOf("王五");           // 返回索引

// 遍历
for (String n : list) {
    System.out.println(n);
}
```


### 11.2.3 ArrayList和LinkedList区别

| 对比项 | ArrayList | LinkedList |
|--------|-----------|------------|
| 底层结构 | 动态数组 | 双向链表 |
| 随机访问 | O(1)，快 | O(n)，慢 |
| 增删（头部/中间） | O(n)，慢 | O(1)，快 |
| 内存占用 | 较少 | 较多（每个节点存储前后指针） |
| 适用场景 | 查询多，增删少 | 增删多，查询少 |

**对比 C++**：`ArrayList` 对应 `std::vector`，`LinkedList` 对应 `std::list`。

**疑惑**：LinkedList 增删真的比 ArrayList 快吗？

**答疑**：这个结论是有条件的。LinkedList 在**已知节点位置**时增删确实是 O(1)，但**查找节点**本身需要 O(n)。在实际测试中，由于 CPU 缓存友好性（数组是连续内存，链表节点分散），ArrayList 在大多数场景下性能都优于 LinkedList。

**论证**：

```java
// 实测：ArrayList vs LinkedList 在中间位置插入 10 万次
ArrayList<Integer> arrayList = new ArrayList<>();
LinkedList<Integer> linkedList = new LinkedList<>();

// ArrayList 中间插入：每次都要 arraycopy 移动元素
// 但数组是连续内存，CPU 缓存命中率高
for (int i = 0; i < 100000; i++) {
    arrayList.add(arrayList.size() / 2, i);  // 约 1200ms
}

// LinkedList 中间插入：先要从头遍历到中间位置（O(n)），然后插入（O(1)）
for (int i = 0; i < 100000; i++) {
    linkedList.add(linkedList.size() / 2, i);  // 约 20000ms！
}
```

**结果展示**：由于 LinkedList 需要先遍历定位，实际上中间位置插入远慢于 ArrayList。**在绝大多数实际场景中，ArrayList 是更好的选择**。JDK 官方文档也建议首选 ArrayList。

## 11.4 Map集合

### 11.4.1 HashMap

**HashMap 的底层原理**：JDK 8 的 `HashMap` 采用**数组 + 链表 + 红黑树**结构。内部是一个 `Node<K,V>[]` 数组（称为桶 bucket），默认初始容量 **16**，负载因子 **0.75**。`put(key, value)` 时先计算 `key.hashCode()` 并经过扰动函数 `(h = key.hashCode()) ^ (h >>> 16)` 得到桶索引；若该桶已有元素（哈希冲突），则以**链表**方式追加；当同一桶的链表长度 ≥ **8** 且数组长度 ≥ 64 时，链表会转化为**红黑树**（查找从 O(n) 优化到 O(log n)）。当元素总数超过 `容量 × 负载因子` 时进行 **2 倍扩容**，所有元素重新散列。这就是为什么自定义对象作为 key 时必须同时重写 `hashCode()` 和 `equals()`。

```java
import java.util.HashMap;

HashMap<String, Double> accounts = new HashMap<>();

// 添加键值对
accounts.put("张三", 1000.0);
accounts.put("李四", 2000.0);
accounts.put("王五", 3000.0);

// 获取
double balance = accounts.get("张三");  // 1000.0
double defaultVal = accounts.getOrDefault("赵六", 0.0);  // 0.0

// 判断
boolean hasKey = accounts.containsKey("张三");    // true
boolean hasVal = accounts.containsValue(1000.0);  // true

// 删除
accounts.remove("王五");

// 大小
int size = accounts.size();  // 2
```

```java
map.put("Charlie", 3000.0);
map.put("Alice", 1000.0);
```

### 11.4.3 Map遍历方式

```java
HashMap<String, Double> map = new HashMap<>();
map.put("张三", 1000.0);
map.put("李四", 2000.0);

// 方式1：遍历 entrySet
for (Map.Entry<String, Double> entry : map.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}

// 方式2：遍历 keySet
for (String key : map.keySet()) {
    System.out.println(key + ": " + map.get(key));
}

// 方式3：forEach (JDK 8+)
map.forEach((key, value) -> {
    System.out.println(key + ": " + value);
});
```

**对比 C++**：`HashMap` 对应 `std::unordered_map`，`TreeMap` 对应 `std::map`。

## 11.7 综合案例：通讯录管理系统

本案例融合集合框架章节的核心知识点：ArrayList、HashMap、HashSet、TreeMap、Iterator、Stream、Collections工具类等。

```java
import java.util.*;
import java.util.stream.Collectors;

/**
 * 通讯录管理系统
 * 融合知识点：ArrayList、HashMap、HashSet、TreeMap、Iterator、Stream、Collections
 */
public class ContactManager {
    // 联系人类
    static class Contact implements Comparable<Contact> {
        String name;
        String phone;
        String group;  // 分组：家人、朋友、同事

        public Contact(String name, String phone, String group) {
            this.name = name;
            this.phone = phone;
            this.group = group;
        }

        @Override
        public String toString() {
            return String.format("%-6s %-13s [%s]", name, phone, group);
        }

        // 用于 HashSet 去重
        @Override
        public boolean equals(Object o) {
            if (this == o) return true;
            if (!(o instanceof Contact c)) return false;
            return phone.equals(c.phone);  // 手机号相同视为同一联系人
        }

        @Override
        public int hashCode() {
            return Objects.hash(phone);
        }

        // 用于 TreeMap/TreeSet 排序
        @Override
        public int compareTo(Contact other) {
            return this.name.compareTo(other.name);
        }
    }

    // 使用 ArrayList 存储所有联系人
    private ArrayList<Contact> contacts = new ArrayList<>();
    // 使用 HashMap 实现快速查找（手机号 → 联系人）
    private HashMap<String, Contact> phoneIndex = new HashMap<>();
    // 使用 TreeMap 按分组管理
    private TreeMap<String, ArrayList<Contact>> groupMap = new TreeMap<>();

    // 添加联系人
    public boolean add(String name, String phone, String group) {
        if (phoneIndex.containsKey(phone)) {
            System.out.println("  手机号已存在：" + phone);
            return false;
        }
        Contact c = new Contact(name, phone, group);
        contacts.add(c);
        phoneIndex.put(phone, c);
        groupMap.computeIfAbsent(group, k -> new ArrayList<>()).add(c);
        return true;
    }

    // 通过手机号查找（HashMap O(1)）
    public Contact findByPhone(String phone) {
        return phoneIndex.get(phone);
    }

    // 通过姓名模糊查找（Stream）
    public List<Contact> searchByName(String keyword) {
        return contacts.stream()
                .filter(c -> c.name.contains(keyword))
                .collect(Collectors.toList());
    }

    // 删除联系人（Iterator 安全删除）
    public boolean remove(String phone) {
        Contact c = phoneIndex.remove(phone);
        if (c == null) return false;

        // 从 ArrayList 中删除（使用 Iterator）
        Iterator<Contact> it = contacts.iterator();
        while (it.hasNext()) {
            if (it.next().phone.equals(phone)) {
                it.remove();
                break;
            }
        }
        // 从分组中删除
        ArrayList<Contact> groupList = groupMap.get(c.group);
        if (groupList != null) {
            groupList.removeIf(contact -> contact.phone.equals(phone));
        }
        return true;
    }

    // 去重（HashSet）
    public int removeDuplicates() {
        HashSet<Contact> uniqueSet = new HashSet<>(contacts);
        int duplicates = contacts.size() - uniqueSet.size();
        if (duplicates > 0) {
            contacts.clear();
            contacts.addAll(uniqueSet);
            rebuildIndex();
        }
        return duplicates;
    }

    // 重建索引
    private void rebuildIndex() {
        phoneIndex.clear();
        groupMap.clear();
        for (Contact c : contacts) {
            phoneIndex.put(c.phone, c);
            groupMap.computeIfAbsent(c.group, k -> new ArrayList<>()).add(c);
        }
    }

    // 排序（Collections 工具类）
    public void sortByName() {
        Collections.sort(contacts);  // 使用 Comparable
    }

    public void sortByGroup() {
        contacts.sort(Comparator.comparing((Contact c) -> c.group)
                .thenComparing(c -> c.name));
    }

    // 统计（Stream）
    public void printStatistics() {
        System.out.println("\n--- 统计信息 ---");
        System.out.println("  总联系人数：" + contacts.size());

        // 按分组统计
        Map<String, Long> groupStats = contacts.stream()
                .collect(Collectors.groupingBy(c -> c.group, Collectors.counting()));
        groupStats.forEach((group, count) ->
                System.out.printf("  %s：%d 人%n", group, count));

        // 查找姓名最长的联系人
        contacts.stream()
                .max(Comparator.comparingInt(c -> c.name.length()))
                .ifPresent(c -> System.out.println("  姓名最长：" + c.name));
    }

    // 显示所有联系人
    public void listAll() {
        System.out.println("\n=== 所有联系人 ===");
        if (contacts.isEmpty()) {
            System.out.println("  通讯录为空");
            return;
        }
        for (int i = 0; i < contacts.size(); i++) {
            System.out.printf("  %d. %s%n", i + 1, contacts.get(i));
        }
    }

    // 按分组显示（TreeMap 有序遍历）
    public void listByGroup() {
        System.out.println("\n=== 按分组显示 ===");
        for (Map.Entry<String, ArrayList<Contact>> entry : groupMap.entrySet()) {
            System.out.println("【" + entry.getKey() + "】");
            for (Contact c : entry.getValue()) {
                System.out.println("  " + c);
            }
        }
    }

    // 导出为不可修改集合
    public List<Contact> exportReadOnly() {
        return Collections.unmodifiableList(contacts);
    }

    public static void main(String[] args) {
        ContactManager manager = new ContactManager();

        System.out.println("╔═══════════════════════════╗");
        System.out.println("║    通讯录管理系统演示     ║");
        System.out.println("╚═══════════════════════════╝");

        // 批量添加联系人
        manager.add("张三", "13800001111", "朋友");
        manager.add("李四", "13800002222", "同事");
        manager.add("王五", "13800003333", "家人");
        manager.add("赵六", "13800004444", "同事");
        manager.add("孙七", "13800005555", "朋友");
        manager.add("周八", "13800006666", "家人");
        manager.add("吴九", "13800007777", "同事");

        // 显示所有联系人
        manager.listAll();

        // HashMap 快速查找
        System.out.println("\n--- 手机号查找 ---");
        Contact found = manager.findByPhone("13800002222");
        System.out.println("  找到：" + (found != null ? found : "未找到"));

        // Stream 模糊查找
        System.out.println("\n--- 姓名搜索（含'三'）---");
        List<Contact> results = manager.searchByName("三");
        results.forEach(c -> System.out.println("  " + c));

        // 按分组显示（TreeMap 排序）
        manager.listByGroup();

        // 排序

        System.out.println("\n--- 按姓名排序后 ---");
        manager.listAll();

        // 删除联系人

        boolean removed = manager.remove("13800004444");
        System.out.println("  删除赵六：" + (removed ? "成功" : "失败"));

        // 统计信息（Stream）
        manager.printStatistics();

        // 不可修改集合
        System.out.println("\n--- 只读导出 ---");
        List<Contact> readOnly = manager.exportReadOnly();
        try {
            readOnly.add(new Contact("测试", "000", "测试"));
        } catch (UnsupportedOperationException e) {
            System.out.println("  只读集合不允许修改 ✓");
        }

        // Collections 工具方法
        System.out.println("\n--- Collections 工具 ---");
        ArrayList<Integer> nums = new ArrayList<>(List.of(5, 3, 8, 1, 9, 2));
        System.out.println("  原始：" + nums);
        Collections.sort(nums);
        System.out.println("  排序：" + nums);
        Collections.reverse(nums);
        System.out.println("  反转：" + nums);
        System.out.println("  最大值：" + Collections.max(nums));
        System.out.println("  最小值：" + Collections.min(nums));
        Collections.shuffle(nums);
        System.out.println("  打乱：" + nums);
```

**底层原理深度分析**：

**ArrayList 的扩容机制**：ArrayList 内部使用 `Object[]` 数组存储元素。默认初始容量为 **10**（JDK 8 中延迟初始化，首次 add 时才分配）。当数组满了需要扩容时，新容量 = 旧容量 * 1.5（`oldCapacity + (oldCapacity >> 1)`），然后调用 `Arrays.copyOf()` 将旧数组复制到新数组。这个复制操作的时间复杂度是 O(n)，所以频繁扩容会影响性能。

```java
// 如果预先知道元素数量，可以指定初始容量
List<String> list = new ArrayList<>(1000000);  // 避免多次扩容
```

**HashMap 的底层结构**：JDK 8 的 HashMap 使用**数组 + 链表 + 红黑树**的混合结构。初始容量为 16，负载因子为 0.75。当某个桶（bucket）的链表长度超过 **8** 且数组长度 >= **64** 时，链表转换为红黑树（查找从 O(n) 提升到 O(log n)）。当红黑树节点数降到 **6** 以下时，退化回链表。

```
HashMap 内部结构：
index:  [0]     [1]     [2]     [3]    ...   [15]
         |       |       |
        null    K1→V1   K2→V2          
                 |       |
                K3→V3   K4→V4
                         |
                       (链表长度>8 → 红黑树)
```
