## 15.1 注解入门

### 15.1.1 注解是什么

注解（Annotation）是 Java 5 引入的一种元数据机制，用于为代码提供额外的信息。注解不会直接影响程序逻辑，但可以被编译器、框架或运行时工具读取和处理。

**对比 C++**：C++ 没有内置的注解机制（C++11 引入了 `[[deprecated]]` 等属性），Java 的注解系统更加完善和强大。注解是 Spring、MyBatis 等框架的核心基础。

### 15.1.2 内置注解

```java
// @Override：标记方法重写了父类方法
@Override
public String toString() {
    return "Account";
}

// @Deprecated：标记已过时的方法
@Deprecated
public void oldMethod() {
    // 不推荐使用
}

// @SuppressWarnings：抑制编译器警告
@SuppressWarnings("unchecked")
public void method() {
    List list = new ArrayList();  // 不会产生警告
}

// @FunctionalInterface：标记函数式接口（JDK 8+）
@FunctionalInterface
public interface MyFunction {
    void execute();
}
```

### 15.1.3 元注解

元注解是用于注解"注解"的注解：

| 元注解 | 作用 |
|--------|------|
| `@Target` | 注解可以用在哪里（类、方法、字段等） |
| `@Retention` | 注解的生命周期（源码、编译、运行时） |
| `@Documented` | 注解会包含在 javadoc 中 |
| `@Inherited` | 注解可以被子类继承 |

```java
@Target(ElementType.METHOD)              // 只能用在方法上
@Retention(RetentionPolicy.RUNTIME)      // 运行时保留
public @interface MyAnnotation {
    String value();
}
```

## 15.2 自定义注解

### 15.2.1 自定义注解语法

```java
import java.lang.annotation.*;

@Target({ElementType.TYPE, ElementType.METHOD})
@Retention(RetentionPolicy.RUNTIME)
public @interface ApiInfo {
    String author() default "unknown";
    String version() default "1.0";
    String description();
}
```

### 15.2.2 自定义注解案例

```java
@ApiInfo(author = "yangchong", version = "2.0", description = "银行账户类")
public class Account {
    private String name;
    private double balance;

    @ApiInfo(description = "存款方法")
    public void deposit(double amount) {
        balance += amount;
    }
}
```

## 15.3 反射机制

### 15.3.1 反射概念

反射（Reflection）是 Java 的一种机制，允许程序在**运行时**获取类的信息（类名、方法、字段等），并动态地创建对象、调用方法、访问字段。

反射是很多框架的基础（Spring 的依赖注入、MyBatis 的 ORM 映射等）。

### 15.3.2 获取Class对象

```java
// 方式1：类名.class
Class<Account> cls1 = Account.class;

// 方式2：对象.getClass()
Account acc = new Account();
Class<?> cls2 = acc.getClass();

// 方式3：Class.forName（最灵活，类名可以是字符串变量）
Class<?> cls3 = Class.forName("com.bank.model.Account");

System.out.println(cls1 == cls2);  // true（同一个Class对象）
```

### 15.3.3 获取类信息

```java
Class<Account> cls = Account.class;

// 获取类名
System.out.println(cls.getName());           // com.bank.model.Account
System.out.println(cls.getSimpleName());     // Account

// 获取所有公共方法（包括继承的）
Method[] methods = cls.getMethods();
for (Method m : methods) {
    System.out.println(m.getName());
}

// 获取所有声明的字段（包括私有的）
Field[] fields = cls.getDeclaredFields();
for (Field f : fields) {
    System.out.println(f.getName() + " : " + f.getType().getSimpleName());
}

// 获取构造方法
Constructor<?>[] constructors = cls.getConstructors();
```

### 15.3.4 创建对象

```java
Class<Account> cls = Account.class;

// 通过无参构造创建
Account acc1 = cls.getDeclaredConstructor().newInstance();

// 通过有参构造创建
Constructor<Account> constructor = cls.getDeclaredConstructor(String.class, double.class);
Account acc2 = constructor.newInstance("张三", 1000.0);
```

### 15.3.5 调用方法

```java
Class<Account> cls = Account.class;
Account acc = new Account("张三", 1000);

// 获取方法并调用
Method depositMethod = cls.getMethod("deposit", double.class);
depositMethod.invoke(acc, 500.0);  // 等价于 acc.deposit(500.0)

// 调用私有方法
Method privateMethod = cls.getDeclaredMethod("validateAmount", double.class);
privateMethod.setAccessible(true);  // 允许访问私有方法
Object result = privateMethod.invoke(acc, 100.0);
```

### 15.3.6 访问字段

```java
Class<Account> cls = Account.class;
Account acc = new Account("张三", 1000);

// 访问私有字段
Field balanceField = cls.getDeclaredField("balance");
balanceField.setAccessible(true);  // 允许访问私有字段

double balance = (double) balanceField.get(acc);  // 读取
System.out.println("余额：" + balance);

balanceField.set(acc, 9999.0);  // 修改
System.out.println("修改后余额：" + acc.getBalance());
```

## 15.4 注解和反射结合

反射可以在运行时读取注解信息：

```java
Class<Account> cls = Account.class;

// 读取类上的注解
if (cls.isAnnotationPresent(ApiInfo.class)) {
    ApiInfo info = cls.getAnnotation(ApiInfo.class);
    System.out.println("作者：" + info.author());
    System.out.println("版本：" + info.version());
    System.out.println("描述：" + info.description());
}

// 读取方法上的注解
for (Method method : cls.getMethods()) {
    if (method.isAnnotationPresent(ApiInfo.class)) {
        ApiInfo info = method.getAnnotation(ApiInfo.class);
        System.out.println(method.getName() + ": " + info.description());
    }
}
```

这就是 Spring 框架实现 `@Autowired`、`@RequestMapping` 等注解功能的底层原理。

## 15.5 反射的优缺点

| 优点 | 缺点 |
|------|------|
| 运行时动态操作，灵活性极高 | 性能开销大（比直接调用慢） |
| 是框架和库的基础 | 破坏封装性（可以访问私有成员） |
| 实现通用工具和组件 | 代码可读性降低 |
| 支持插件化架构 | 编译期无法检查类型安全 |

> 建议：在业务代码中尽量少用反射，在框架和底层工具开发中合理使用。

## 15.6 综合案例：简易依赖注入框架

本案例融合注解和反射章节的核心知识点：自定义注解、元注解、反射获取类信息、动态创建对象、调用方法、访问字段、注解+反射结合。

```java
import java.lang.annotation.*;
import java.lang.reflect.*;
import java.util.*;

/**
 * 简易依赖注入框架
 * 模拟 Spring 的 @Component、@Autowired、@Value 功能
 * 融合知识点：自定义注解、元注解、反射创建对象/调用方法/访问字段
 */

// 自定义注解：标记可被容器管理的类（类似 @Component）
@Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)
@interface Component {
    String value() default "";  // Bean 名称
}

// 自定义注解：自动注入（类似 @Autowired）
@Target(ElementType.FIELD)
@Retention(RetentionPolicy.RUNTIME)
@interface Inject {
}

// 自定义注解：注入配置值（类似 @Value）
@Target(ElementType.FIELD)
@Retention(RetentionPolicy.RUNTIME)
@interface Value {
    String value();
}

// 自定义注解：初始化方法（类似 @PostConstruct）
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@interface Init {
}

// 简易 IoC 容器
class MiniContainer {
    // 存储 Bean 实例
    private final Map<Class<?>, Object> beans = new HashMap<>();
    // 存储配置
    private final Map<String, String> properties = new HashMap<>();

    public MiniContainer() {
        // 模拟配置
        properties.put("app.name", "MiniSpring");
        properties.put("app.version", "1.0.0");
        properties.put("server.port", "8080");
    }

    // 注册组件类
    public void register(Class<?>... classes) throws Exception {
        // 第一步：创建所有 Bean 实例
        for (Class<?> cls : classes) {
            if (cls.isAnnotationPresent(Component.class)) {
                Object instance = cls.getDeclaredConstructor().newInstance();
                beans.put(cls, instance);
                System.out.printf("  [容器] 注册 Bean: %s%n", cls.getSimpleName());
            }
        }

        // 第二步：注入依赖
        for (Object bean : beans.values()) {
            injectDependencies(bean);
        }

        // 第三步：调用初始化方法
        for (Object bean : beans.values()) {
            invokeInitMethods(bean);
        }
    }

    // 反射注入依赖
    private void injectDependencies(Object bean) throws Exception {
        Class<?> cls = bean.getClass();

        for (Field field : cls.getDeclaredFields()) {
            // 处理 @Inject
            if (field.isAnnotationPresent(Inject.class)) {
                Object dependency = beans.get(field.getType());
                if (dependency != null) {
                    field.setAccessible(true);  // 允许访问私有字段
                    field.set(bean, dependency);
                    System.out.printf("  [注入] %s.%s ← %s%n",
                            cls.getSimpleName(), field.getName(),
                            dependency.getClass().getSimpleName());
                } else {
                    System.out.printf("  [警告] 找不到 %s 类型的 Bean%n", field.getType().getSimpleName());
                }
            }

            // 处理 @Value
            if (field.isAnnotationPresent(Value.class)) {
                Value valueAnno = field.getAnnotation(Value.class);
                String propValue = properties.getOrDefault(valueAnno.value(), "");
                field.setAccessible(true);

                // 类型转换
                if (field.getType() == int.class || field.getType() == Integer.class) {
                    field.set(bean, Integer.parseInt(propValue));
                } else if (field.getType() == String.class) {
                    field.set(bean, propValue);
                }

                System.out.printf("  [配置] %s.%s = %s%n",
                        cls.getSimpleName(), field.getName(), propValue);
            }
        }
    }

    // 反射调用 @Init 方法
    private void invokeInitMethods(Object bean) throws Exception {
        for (Method method : bean.getClass().getDeclaredMethods()) {
            if (method.isAnnotationPresent(Init.class)) {
                method.setAccessible(true);
                method.invoke(bean);
                System.out.printf("  [初始化] 调用 %s.%s()%n",
                        bean.getClass().getSimpleName(), method.getName());
            }
        }
    }

    // 获取 Bean
    @SuppressWarnings("unchecked")
    public <T> T getBean(Class<T> type) {
        return (T) beans.get(type);
    }

    // 打印容器信息（反射获取类信息）
    public void printBeanInfo() {
        System.out.println("\n--- 容器中的 Bean 信息 ---");
        for (Map.Entry<Class<?>, Object> entry : beans.entrySet()) {
            Class<?> cls = entry.getKey();
            Component comp = cls.getAnnotation(Component.class);
            String beanName = comp.value().isEmpty() ?
                    cls.getSimpleName() : comp.value();

            System.out.printf("  Bean: %s%n", beanName);
            System.out.printf("    类名: %s%n", cls.getName());
            System.out.printf("    字段: %d 个%n", cls.getDeclaredFields().length);
            System.out.printf("    方法: %d 个%n", cls.getDeclaredMethods().length);

            // 获取带注解的字段
            for (Field f : cls.getDeclaredFields()) {
                Annotation[] annotations = f.getAnnotations();
                if (annotations.length > 0) {
                    System.out.printf("    @%s → %s %s%n",
                            annotations[0].annotationType().getSimpleName(),
                            f.getType().getSimpleName(), f.getName());
                }
            }
        }
    }
}

// ====== 业务类 ======

@Component("userRepo")
class UserRepository {
    private final List<String> users = new ArrayList<>();

    @Init
    private void loadData() {
        users.addAll(List.of("张三", "李四", "王五"));
    }

    public List<String> findAll() { return users; }

    public void addUser(String name) { users.add(name); }
}

@Component("userService")
class UserService {
    @Inject
    private UserRepository userRepository;

    @Value("app.name")
    private String appName;

    @Value("server.port")
    private int port;

    public void listUsers() {
        System.out.printf("  [%s:%d] 用户列表：%s%n",
                appName, port, userRepository.findAll());
    }

    public void addUser(String name) {
        userRepository.addUser(name);
        System.out.printf("  [%s] 添加用户：%s%n", appName, name);
    }
}

@Component
class AppController {
    @Inject
    private UserService userService;

    @Value("app.version")
    private String version;

    @Init
    private void start() {
        System.out.printf("  应用启动，版本：%s%n", version);
    }

    public void handleRequest() {
        System.out.println("\n--- 处理请求 ---");
        userService.listUsers();
        userService.addUser("赵六");
        userService.listUsers();
    }
}

public class MiniFrameworkDemo {
    public static void main(String[] args) throws Exception {
        System.out.println("╔═══════════════════════════════════╗");
        System.out.println("║   简易依赖注入框架演示            ║");
        System.out.println("╚═══════════════════════════════════╝");

        // 创建容器并注册组件
        System.out.println("\n--- 初始化容器 ---");
        MiniContainer container = new MiniContainer();
        container.register(UserRepository.class, UserService.class, AppController.class);

        // 打印 Bean 信息
        container.printBeanInfo();

        // 使用
        AppController controller = container.getBean(AppController.class);
        controller.handleRequest();

        // 反射补充演示
        System.out.println("\n--- 反射动态调用 ---");
        Object service = container.getBean(UserService.class);
        Method method = service.getClass().getDeclaredMethod("addUser", String.class);
        method.invoke(service, "孙七（反射调用）");

        Method listMethod = service.getClass().getDeclaredMethod("listUsers");
        listMethod.invoke(service);
    }
}
```

**案例知识点总结：**

| 知识点 | 案例中的体现 |
|--------|-------------|
| 自定义注解 | `@Component`、`@Inject`、`@Value`、`@Init` |
| 元注解 | `@Target`、`@Retention(RUNTIME)` |
| 内置注解 | `@SuppressWarnings` |
| 反射获取 Class | `cls.getAnnotation()`、`cls.getDeclaredFields()` |
| 反射创建对象 | `cls.getDeclaredConstructor().newInstance()` |
| 反射访问字段 | `field.setAccessible(true)`、`field.set()` |
| 反射调用方法 | `method.invoke(bean)` |
| 注解 + 反射结合 | 扫描注解 → 创建实例 → 注入依赖 → 调用初始化 |
| isAnnotationPresent | 判断是否有某注解 |
| getAnnotation | 获取注解实例，读取属性值 |
| 注解属性 | `value()`、`default` 默认值 |
