## 10.1 异常入门介绍

### 10.1.1 异常概念解释

程序的错误大致可以分为三种：

1. **语法错误**：编译阶段就能发现，如拼写错误、缺少分号等。
2. **逻辑错误**：程序能运行但结果不对，通过调试解决。
3. **运行时错误**：程序运行期间发生的错误，如除数为0、空指针、数组越界等。

Java 通过**异常机制**处理运行时错误，让程序有机会优雅地处理错误，而不是直接崩溃。

**异常处理的底层原理**：Java 的异常处理在字节码中通过**异常表（Exception Table）** 实现，而不是像某些语言使用 setjmp/longjmp。每个方法的 Code 属性中都包含一个异常表，记录了 `try` 块的起始/结束 PC、`catch` 处理器的入口 PC 和捕获的异常类型。当异常抛出时，JVM 在当前方法的异常表中查找匹配项；若未找到，则弹出当前栈帧，沿调用栈向上查找（**栈展开**），直到找到匹配的 handler 或到达栈顶（线程终止）。`throw new Exception()` 的开销主要来自**填充异常栈轨迹**（`fillInStackTrace()`），需要遍历整个调用栈——这就是为什么不应该用异常控制正常业务流程。

**对比 C++**：C++ 也有 try-catch 异常机制，但 C++ 没有"检查异常"的概念，异常处理不是强制的。Java 的异常处理更加规范和严格。

### 10.1.2 异常体系结构

```
Throwable
├── Error（严重错误，程序无法处理）
│   ├── OutOfMemoryError（内存溢出）
│   ├── StackOverflowError（栈溢出）
│   └── ...
└── Exception（异常，程序可以处理）
    ├── RuntimeException（运行时异常/非检查异常）
    │   ├── NullPointerException（空指针）
    │   ├── ArrayIndexOutOfBoundsException（数组越界）
    │   ├── ArithmeticException（算术异常）
    │   ├── ClassCastException（类型转换异常）
    │   └── ...
    └── 检查异常（编译时必须处理）
        ├── IOException（IO异常）
        ├── SQLException（数据库异常）
        ├── FileNotFoundException（文件未找到）
        └── ...
```

**关键区别**：
- **检查异常**：编译器强制要求处理（try-catch 或 throws），如 `IOException`。
- **运行时异常**：编译器不强制要求处理，如 `NullPointerException`。

### 10.1.3 异常基本语法

```java
try {
    // 可能会抛出异常的代码
} catch (异常类型 变量名) {
    // 异常处理代码
} finally {
    // 无论是否异常都会执行（可选）
}
```

### 10.1.4 捕获异常

```java
public class Main {
    public static void main(String[] args) {
        try {
            int result = 10 / 0;  // ArithmeticException
            System.out.println(result);
        } catch (ArithmeticException e) {
            System.out.println("发生算术异常：" + e.getMessage());
        }
        System.out.println("程序继续执行");
    }
}
// 输出：
// 发生算术异常：/ by zero
// 程序继续执行
```

**异常对象的常用方法**：

```java
try {
    int[] arr = null;
    System.out.println(arr[0]);
} catch (NullPointerException e) {
    // getMessage()：获取异常消息
    System.out.println("消息：" + e.getMessage());
    
    // toString()：获取异常类型 + 消息
    System.out.println("描述：" + e.toString());
    
    // printStackTrace()：打印完整的调用栈轨迹（调试用）
    e.printStackTrace();
    
    // getStackTrace()：以数组形式获取调用栈
    StackTraceElement[] stack = e.getStackTrace();
    for (StackTraceElement element : stack) {
        System.out.println("  at " + element);
    }
}
```

## 10.2 多级catch匹配

### 10.2.1 多级catch使用

```java
try {
    int[] arr = {1, 2, 3};
    System.out.println(arr[5]);       // ArrayIndexOutOfBoundsException
    System.out.println(10 / 0);       // ArithmeticException
} catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("数组越界：" + e.getMessage());
} catch (ArithmeticException e) {
    System.out.println("算术异常：" + e.getMessage());
} catch (Exception e) {
    System.out.println("其他异常：" + e.getMessage());
}
```

> 注意：catch 的顺序必须从子类到父类，否则编译错误。

### 10.2.2 多异常捕获(JDK7+)

```java
try {
    // ...
} catch (ArithmeticException | ArrayIndexOutOfBoundsException e) {
    System.out.println("发生异常：" + e.getMessage());
}
```

## 10.3 finally语句

### 10.3.1 finally基本用法

`finally` 块中的代码无论是否发生异常都会执行，通常用于释放资源：

```java
FileReader reader = null;
try {
    reader = new FileReader("test.txt");
    // 读取文件
} catch (FileNotFoundException e) {
    System.out.println("文件不存在");
} finally {
    // 释放资源
    if (reader != null) {
        try {
            reader.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

### 10.3.2 try-with-resources(JDK7+)

JDK 7 引入了 try-with-resources，自动关闭资源：

```java
// 自动关闭 reader，不需要 finally
try (FileReader reader = new FileReader("test.txt");
     BufferedReader br = new BufferedReader(reader)) {
    String line = br.readLine();
    System.out.println(line);
} catch (IOException e) {
    System.out.println("IO异常：" + e.getMessage());
}
// reader 和 br 会自动关闭
```

> 资源类必须实现 `AutoCloseable` 接口。

## 10.4 throw和throws

### 10.4.1 throw抛出异常

```java
public void deposit(double amount) {
    if (amount <= 0) {
        throw new IllegalArgumentException("存款金额必须大于0");
    }
    balance += amount;
}
```

### 10.4.2 throws声明异常

`throws` 用于在方法签名中声明该方法可能抛出的异常：

```java
// 声明可能抛出 IOException
public void readFile(String path) throws IOException {
    FileReader reader = new FileReader(path);
    // ...
}

// 调用方必须处理异常
public void process() {
    try {
        readFile("test.txt");
    } catch (IOException e) {
        System.out.println("文件读取失败");
    }
}
```

**对比 C++**：C++ 的异常规范（`throw()`）已被弃用，C++11 引入了 `noexcept`。Java 的 `throws` 是强制性的（对于检查异常），这使得异常处理更加规范。

## 10.5 自定义异常

### 10.5.1 自定义异常类

```java
// 继承 Exception：检查异常（调用方必须处理）
public class InsufficientBalanceException extends Exception {
    private double balance;
    private double amount;

    public InsufficientBalanceException(double balance, double amount) {
        super("余额不足：当前余额 " + balance + "，尝试取款 " + amount);
        this.balance = balance;
        this.amount = amount;
    }

    public double getBalance() { return balance; }
    public double getAmount() { return amount; }
}

// 继承 RuntimeException：运行时异常（调用方可以不处理）
public class InvalidAccountException extends RuntimeException {
    public InvalidAccountException(String message) {
        super(message);
    }
}
```

### 10.5.2 自定义异常实践

```java
public class Account {
    private String name;
    private double balance;

    public void withdraw(double amount) throws InsufficientBalanceException {
        if (amount > balance) {
            throw new InsufficientBalanceException(balance, amount);
        }
        balance -= amount;
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        Account acc = new Account("张三", 1000);
        try {
            acc.withdraw(2000);
        } catch (InsufficientBalanceException e) {
            System.out.println(e.getMessage());
            System.out.println("当前余额：" + e.getBalance());
        }
    }
}
```

**训练2**：自定义异常应该继承 `Exception` 还是 `RuntimeException`？请根据以下场景给出选择并说明理由：
- (a) 用户密码错误
- (b) 数据库连接失败
- (c) 程序内部逻辑 bug（如传入 null 参数）
- (d) 外部 API 返回错误

**疑惑**：为什么 Spring 框架把几乎所有异常都定义为 RuntimeException？

**答疑**：检查异常（Checked Exception）要求每个调用方都必须处理，在大型项目中会导致"异常签名污染"——低层的 `SQLException` 一路 throws 到最上层，破坏了分层架构的封装性。Spring 的理念是：如果调用方无法有效处理异常（如数据库连接失败），强制要求处理只会产生大量 `catch (Exception e) { e.printStackTrace(); }` 的无效代码。

**论证**：

```java
// 检查异常的问题：异常签名层层传播
// DAO → Service → Controller，每一层都要 throws
public User findUser(int id) throws SQLException { ... }           // DAO
public User getUser(int id) throws SQLException { ... }            // Service
public Response handleRequest(int id) throws SQLException { ... }  // Controller

// Spring 的做法：包装为运行时异常
public User findUser(int id) {
    try {
        return jdbcTemplate.queryForObject(...);
    } catch (DataAccessException e) {  // RuntimeException
        // Spring 把 SQLException 包装为 DataAccessException
        throw e;
    }
}
```

**结果展示**：Kotlin、C# 都没有检查异常，Go 使用错误值而非异常。Java 的检查异常是一个有争议的设计决策。

## 10.7 综合案例：银行转账系统

本案例融合异常处理章节的核心知识点：try-catch-finally、多级catch、try-with-resources、throw/throws、自定义异常、异常链等。

```java
import java.io.*;
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

/**
 * 银行转账系统
 * 融合知识点：try-catch、多级catch、finally、try-with-resources、throw/throws、自定义异常
 */

// 自定义异常：余额不足（检查异常）
class InsufficientFundsException extends Exception {
    private final double balance;
    private final double amount;

    public InsufficientFundsException(double balance, double amount) {
        super(String.format("余额不足：当前 %.2f，需要 %.2f，差额 %.2f",
                balance, amount, amount - balance));
        this.balance = balance;
        this.amount = amount;
    }

    public double getShortage() { return amount - balance; }
}

// 自定义异常：无效账户（运行时异常）
class InvalidAccountException extends RuntimeException {
    public InvalidAccountException(String accountId) {
        super("无效的账户ID：" + accountId);
    }
}

// 自定义异常：转账限额异常
class TransferLimitException extends Exception {
    public TransferLimitException(double amount, double limit) {
        super(String.format("超出单笔转账限额：转账 %.2f，限额 %.2f", amount, limit));
    }
}

// 银行账户类
class BankAccount {
    private final String id;
    private String name;
    private double balance;
    private static final double TRANSFER_LIMIT = 50000;

    public BankAccount(String id, String name, double balance) {
        // throw 运行时异常
        if (id == null || id.isEmpty()) {
            throw new InvalidAccountException(id);
        }
        if (balance < 0) {
            throw new IllegalArgumentException("初始余额不能为负数");
        }
        this.id = id;
        this.name = name;
        this.balance = balance;
    }

    // throws 声明检查异常
    public void withdraw(double amount) throws InsufficientFundsException {
        if (amount <= 0) {
            throw new IllegalArgumentException("取款金额必须大于0");
        }
        if (amount > balance) {
            throw new InsufficientFundsException(balance, amount);
        }
        balance -= amount;
    }

    public void deposit(double amount) {
        if (amount <= 0) {
            throw new IllegalArgumentException("存款金额必须大于0");
        }
        balance += amount;
    }

    // 转账方法：抛出多种异常
    public void transferTo(BankAccount target, double amount)
            throws InsufficientFundsException, TransferLimitException {
        if (target == null) {
            throw new InvalidAccountException("null");
        }
        if (amount > TRANSFER_LIMIT) {
            throw new TransferLimitException(amount, TRANSFER_LIMIT);
        }
        this.withdraw(amount);
        target.deposit(amount);
    }

    public String getId() { return id; }
    public String getName() { return name; }
    public double getBalance() { return balance; }

    @Override
    public String toString() {
        return String.format("[%s] %s - 余额: %.2f", id, name, balance);
    }
}

// 交易日志（演示 try-with-resources）
class TransactionLogger implements AutoCloseable {
    private BufferedWriter writer;
    private final String logFile;

    public TransactionLogger(String logFile) throws IOException {
        this.logFile = logFile;
        this.writer = new BufferedWriter(new FileWriter(logFile, true));
        writer.write("=== 交易日志开始 " + LocalDateTime.now() + " ===\n");
    }

    public void log(String message) throws IOException {
        String time = LocalDateTime.now().format(DateTimeFormatter.ofPattern("HH:mm:ss"));
        writer.write(String.format("[%s] %s%n", time, message));
        writer.flush();
    }

    @Override
    public void close() throws IOException {
        if (writer != null) {
            writer.write("=== 交易日志结束 ===\n\n");
            writer.close();
            System.out.println("  日志文件已关闭：" + logFile);
        }
    }
}

public class BankTransferSystem {

    // 安全转账方法：捕获所有异常
    public static boolean safeTransfer(BankAccount from, BankAccount to,
                                       double amount, TransactionLogger logger) {
        try {
            System.out.printf("%n--- 转账：%s → %s，金额 %.2f ---%n",
                    from.getName(), to.getName(), amount);

            from.transferTo(to, amount);

            String msg = String.format("成功：%s → %s 转账 %.2f",
                    from.getName(), to.getName(), amount);
            System.out.println("  ✓ " + msg);

            // 记录日志（可能抛出 IOException）
            try {
                logger.log(msg);
            } catch (IOException e) {
                System.out.println("  ⚠ 日志写入失败：" + e.getMessage());
            }
            return true;

        } catch (InsufficientFundsException e) {
            // 捕获余额不足
            System.out.println("  ✗ " + e.getMessage());
            System.out.printf("    还差 %.2f 元%n", e.getShortage());
            return false;

        } catch (TransferLimitException e) {
            // 捕获限额异常
            System.out.println("  ✗ " + e.getMessage());
            return false;

        } catch (InvalidAccountException e) {
            // 捕获无效账户（运行时异常）
            System.out.println("  ✗ " + e.getMessage());
            return false;

        } catch (IllegalArgumentException e) {
            // 捕获参数错误
            System.out.println("  ✗ 参数错误：" + e.getMessage());
            return false;

        } catch (Exception e) {
            // 兜底：捕获所有其他异常
            System.out.println("  ✗ 未知错误：" + e.getMessage());
            return false;

        } finally {
            // finally 始终执行：打印余额
            System.out.printf("  当前余额 → %s: %.2f, %s: %.2f%n",
                    from.getName(), from.getBalance(),
                    to.getName(), to.getBalance());
        }
    }

    public static void main(String[] args) {
        System.out.println("╔══════════════════════════════╗");
        System.out.println("║      银行转账系统演示        ║");
        System.out.println("╚══════════════════════════════╝");

        BankAccount zhang = new BankAccount("A001", "张三", 10000);
        BankAccount li = new BankAccount("A002", "李四", 5000);

        System.out.println("初始状态：");
        System.out.println("  " + zhang);
        System.out.println("  " + li);

        // try-with-resources：自动关闭日志
        try (TransactionLogger logger = new TransactionLogger("transfer_log.txt")) {

            // 正常转账
            safeTransfer(zhang, li, 3000, logger);

            // 余额不足
            safeTransfer(li, zhang, 20000, logger);

            // 超出限额
            safeTransfer(zhang, li, 60000, logger);

            // 金额为0（参数错误）
            safeTransfer(zhang, li, 0, logger);

            // 正常转账
            safeTransfer(li, zhang, 1000, logger);

        } catch (IOException e) {
            System.out.println("日志系统初始化失败：" + e.getMessage());
        }

        // 运行时异常演示
        System.out.println("\n--- 运行时异常演示 ---");
        try {
            new BankAccount("", "无效用户", 100);
        } catch (InvalidAccountException e) {
            System.out.println("捕获运行时异常：" + e.getMessage());
        }

        // JDK 7+ 多异常捕获
        System.out.println("\n--- 多异常捕获 ---");
        try {
            String numStr = "abc";
            int num = Integer.parseInt(numStr);
        } catch (NumberFormatException | ArithmeticException e) {
            System.out.println("捕获：" + e.getClass().getSimpleName() + " - " + e.getMessage());
        }

        // 最终状态
        System.out.println("\n最终状态：");
        System.out.println("  " + zhang);
        System.out.println("  " + li);

        // 清理测试日志文件
        new File("transfer_log.txt").delete();
    }
}
```

**案例知识点总结：**

| 知识点 | 案例中的体现 |
|--------|-------------|
| try-catch | `safeTransfer()` 中的多级异常捕获 |
| 多级 catch | 从具体到一般：InsufficientFunds → TransferLimit → Exception |
| 多异常捕获 | `catch (NumberFormatException \| ArithmeticException e)` |
| finally | 始终打印转账后的余额 |
| try-with-resources | `TransactionLogger` 自动关闭 |
| throw | 抛出异常 `throw new InsufficientFundsException(...)` |
| throws | 方法声明 `throws InsufficientFundsException, TransferLimitException` |
| 自定义检查异常 | `InsufficientFundsException extends Exception` |
| 自定义运行时异常 | `InvalidAccountException extends RuntimeException` |
| AutoCloseable | `TransactionLogger implements AutoCloseable` |
| 异常体系 | Error/Exception/RuntimeException 的区分 |
