## 3.1 运算符介绍

### 3.1.1 运算符由来

起源：数学与逻辑的抽象。运算符的概念源于数学（+, -, *, /, =）和形式逻辑（&&, ||, !）。

编程语言将这些符号引入，用于操作变量、常量和表达式，执行特定的计算或逻辑功能。

### 3.1.2 运算符本质

**对比 C++**：C++ 中运算符可以被重载（`operator+`），Java 中**不支持运算符重载**（唯一的例外是 `+` 用于字符串拼接，这是语言内置的）。

### 3.1.3 常见运算符

| **运算符类型** | **作用** |
|--------------|---------|
| 算术运算符 | 用于处理四则运算 |
| 赋值运算符 | 用于将表达式的值赋给变量 |
| 比较运算符 | 用于表达式的比较，返回 boolean 值 |
| 逻辑运算符 | 用于根据表达式的值返回 boolean 值 |
| 位运算符 | 用于对二进制位进行操作 |
| 三元运算符 | 简洁的条件表达式 |
| instanceof | 判断对象是否是某个类型的实例 |

## 3.2 算术运算符

**作用**：用于处理四则运算

| **运算符** | **术语** | **示例** | **结果** |
|-----------|---------|---------|---------|
| + | 加 | 10 + 5 | 15 |
| - | 减 | 10 - 5 | 5 |
| * | 乘 | 10 * 5 | 50 |
| / | 除 | 10 / 3 | 3（整数除法） |
| % | 取模 | 10 % 3 | 1 |
| ++ | 自增 | a++ / ++a | |
| -- | 自减 | a-- / --a | |

### 3.2.1 加减乘除

```java
public class Main {
    public static void main(String[] args) {
        int a = 10, b = 3;
        System.out.println(a + b);  // 13
        System.out.println(a - b);  // 7
        System.out.println(a * b);  // 30
        System.out.println(a / b);  // 3（整数除法，截断小数）

        // 要得到小数结果，至少一个操作数是浮点类型
        System.out.println((double) a / b);  // 3.3333...
        System.out.println(a / (double) b);  // 3.3333...

        // 除数不能为0
        // System.out.println(a / 0);  // ArithmeticException
        System.out.println(10.0 / 0);  // Infinity（浮点除以0得无穷大）
    }
}
```

### 3.2.2 取模

```java
System.out.println(10 % 3);   // 1
System.out.println(-10 % 3);  // -1（结果符号与被除数一致）
System.out.println(10 % -3);  // 1

// Java 浮点数也可以取模（C++ 不行）
System.out.println(10.5 % 3); // 1.5
```

### 3.2.3 递增递减

```java
int a = 10;
int b = ++a;  // 先加再赋值，a=11, b=11
System.out.println("a=" + a + ", b=" + b);

int c = 10;
int d = c++;  // 先赋值再加，c=11, d=10
System.out.println("c=" + c + ", d=" + d);
```

### 3.2.4 字符串拼接

Java 中 `+` 运算符被重载用于字符串拼接：

```java
String name = "张三";
int age = 25;
System.out.println("姓名：" + name + "，年龄：" + age);
// 输出：姓名：张三，年龄：25

// 注意运算顺序
System.out.println(1 + 2 + "abc");   // "3abc"（先算1+2=3，再拼接）
System.out.println("abc" + 1 + 2);   // "abc12"（先拼接"abc1"，再拼接"abc12"）
```

## 3.3 赋值运算符

### 3.3.1 赋值案例

```java
int a = 10;
a += 2;   // a = a + 2 = 12
a -= 3;   // a = a - 3 = 9
a *= 2;   // a = a * 2 = 18
a /= 3;   // a = a / 3 = 6
a %= 4;   // a = a % 4 = 2
System.out.println(a);  // 2
```

### 3.3.2 复合赋值隐含转换

复合赋值运算符会**自动进行强制类型转换**：

```java
byte b = 10;
// b = b + 1;    // 编译错误！b + 1 结果是 int
b += 1;          // OK！等价于 b = (byte)(b + 1)

short s = 100;
// s = s + 1;    // 编译错误！
s += 1;          // OK！自动强制转换
```

## 3.4 比较运算符

### 3.4.1 比较案例

比较运算符的结果是 `boolean` 类型：

```java
int a = 10, b = 20;
System.out.println(a == b);   // false
System.out.println(a != b);   // true
System.out.println(a > b);    // false
System.out.println(a < b);    // true
System.out.println(a >= b);   // false
System.out.println(a <= b);   // true
```

### 3.4.2 equals和==区别

这是 Java 中非常重要的知识点：

```java
// 基本类型：== 比较值
int a = 10, b = 10;
System.out.println(a == b);  // true

// 引用类型：== 比较地址，equals 比较内容
String s1 = new String("hello");
String s2 = new String("hello");
System.out.println(s1 == s2);      // false（不同对象，地址不同）
System.out.println(s1.equals(s2)); // true（内容相同）

// 字符串常量池的特殊情况
String s3 = "hello";
String s4 = "hello";
System.out.println(s3 == s4);      // true（常量池中同一个对象）
```

**对比 C++**：C++ 中 `==` 可以被重载（如 `std::string` 重载了 `==` 比较内容），Java 中 `==` 对于对象始终比较地址，比较内容必须用 `equals`。

## 3.5 逻辑运算符

### 3.5.1 逻辑非

```java
boolean a = true;
System.out.println(!a);   // false
System.out.println(!!a);  // true
```

### 3.5.2 逻辑与

```java
System.out.println(true && true);   // true
System.out.println(true && false);  // false
System.out.println(false && false); // false
```

### 3.5.3 逻辑或

```java
System.out.println(true || false);  // true
System.out.println(false || false); // false
```

### 3.5.4 短路特性

`&&` 和 `||` 具有**短路特性**：

```java
int a = 10;
// && 短路：第一个为 false，不会执行第二个
if (false && (++a > 0)) {}
System.out.println(a);  // 10（++a 没有执行）

// || 短路：第一个为 true，不会执行第二个
if (true || (++a > 0)) {}
System.out.println(a);  // 10（++a 没有执行）
```

Java 也有非短路的 `&` 和 `|`（用于逻辑运算时不短路），但实际开发中很少使用。

## 3.6 位运算符

```java
int a = 5, b = 3;  // 5: 0101, 3: 0011
System.out.println(a & b);   // 1  (0001) 按位与
System.out.println(a | b);   // 7  (0111) 按位或
System.out.println(a ^ b);   // 6  (0110) 按位异或
System.out.println(~a);      // -6         按位取反
System.out.println(a << 1);  // 10 (1010) 左移
System.out.println(a >> 1);  // 2  (0010) 有符号右移
System.out.println(a >>> 1); // 2  (0010) 无符号右移
```

**对比 C++**：Java 多了一个 `>>>` 无符号右移运算符。C++ 中右移运算的符号填充取决于实现，Java 明确区分了 `>>`（符号填充）和 `>>>`（零填充）。

## 3.7 运算符优先级

从高到低：

1. `()`（括号）
2. `++`、`--`、`!`、`~`（一元运算符）
3. `*`、`/`、`%`
4. `+`、`-`
5. `<<`、`>>`、`>>>`
6. `<`、`<=`、`>`、`>=`、`instanceof`
7. `==`、`!=`
8. `&`、`^`、`|`
9. `&&`、`||`
10. `? :`（三元运算符）
11. `=`、`+=`、`-=` 等

> 建议：不确定优先级时使用括号明确运算顺序，提高可读性。

## 3.8 instanceof运算符

### 3.8.1 instanceof介绍

`instanceof` 是 Java 特有的运算符，用于判断一个对象是否是某个类（或接口）的实例。

### 3.8.2 基本用法

```java
String str = "Hello";
System.out.println(str instanceof String);  // true
System.out.println(str instanceof Object);  // true

Object obj = new Integer(10);
System.out.println(obj instanceof Integer); // true
System.out.println(obj instanceof String);  // false

// null 不是任何类的实例
System.out.println(null instanceof String); // false
```

### 3.8.3 模式匹配（JDK16+）

JDK 16 引入了 `instanceof` 模式匹配，可以在判断的同时完成类型转换：

```java
Object obj = "Hello World";

// 传统写法
if (obj instanceof String) {
    String str = (String) obj;
    System.out.println(str.length());
}

// JDK 16+ 模式匹配写法
if (obj instanceof String str) {
    System.out.println(str.length());  // 直接使用 str
}
```

**对比 C++**：C++ 使用 `dynamic_cast` 进行运行时类型转换，失败返回 `nullptr`。Java 的 `instanceof` 更加简洁安全。

## 3.10 综合案例：简易计算器与数值分析器

本案例融合运算符章节的核心知识点：算术运算、比较运算、逻辑运算、位运算、三元运算、instanceof、短路特性等。

```java
import java.util.Scanner;

/**
 * 简易计算器与数值分析器
 * 融合知识点：所有运算符类型、短路求值、instanceof、运算符优先级
 */
public class CalculatorAnalyzer {

    // 四则运算
    public static double calculate(double a, double b, String op) {
        return switch (op) {
            case "+" -> a + b;
            case "-" -> a - b;
            case "*" -> a * b;
            case "/" -> b != 0 ? a / b : Double.NaN;
            case "%" -> b != 0 ? a % b : Double.NaN;
            default -> Double.NaN;
        };
    }

    // 数值分析：用位运算判断奇偶，用逻辑运算综合判断
    public static void analyzeNumber(int num) {
        // 位运算判断奇偶（比取模更高效）
        boolean isEven = (num & 1) == 0;
        // 比较运算
        boolean isPositive = num > 0;
        boolean isZero = num == 0;
        // 逻辑运算组合判断
        boolean isPositiveEven = isPositive && isEven;  // 正偶数
        boolean isSpecial = isZero || (num > 100 && isEven);  // 特殊数

        // 三元运算符
        String signStr = isZero ? "零" : (isPositive ? "正数" : "负数");
        String parityStr = isEven ? "偶数" : "奇数";

        System.out.printf("  数值：%d → %s，%s", num, signStr, parityStr);
        if (isPositiveEven) System.out.print("，正偶数");
        if (isSpecial) System.out.print("，特殊数");
        System.out.println();

        // 位运算演示
        System.out.printf("  二进制：%s，左移1位：%d，右移1位：%d%n",
                Integer.toBinaryString(num), num << 1, num >> 1);
    }

    // 短路特性演示
    public static void demonstrateShortCircuit() {
        System.out.println("\n--- 短路特性演示 ---");
        int counter = 0;

        // && 短路：第一个为 false，不执行第二个
        boolean result1 = (10 < 5) && (++counter > 0);
        System.out.println("&&短路后 counter = " + counter);  // 0

        // || 短路：第一个为 true，不执行第二个
        boolean result2 = (10 > 5) || (++counter > 0);
        System.out.println("||短路后 counter = " + counter);  // 0

        // 非短路的 & 和 |
        boolean result3 = (10 < 5) & (++counter > 0);
        System.out.println("&不短路后 counter = " + counter); // 1
    }

    // instanceof 演示
    public static void demonstrateInstanceof() {
        System.out.println("\n--- instanceof 演示 ---");
        Object[] items = {"Hello", 42, 3.14, true, null};

        for (Object item : items) {
            if (item instanceof String s) {        // JDK16+ 模式匹配
                System.out.printf("  String: \"%s\"，长度=%d%n", s, s.length());
            } else if (item instanceof Integer n) {
                System.out.printf("  Integer: %d，是否为偶数=%b%n", n, (n & 1) == 0);
            } else if (item instanceof Double d) {
                System.out.printf("  Double: %.2f%n", d);
            } else if (item instanceof Boolean b) {
                System.out.printf("  Boolean: %b，取反=%b%n", b, !b);
            } else {
                System.out.println("  null 或未知类型");
            }
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // 四则运算
        System.out.println("=== 简易计算器 ===");
        System.out.print("输入第一个数：");
        double num1 = sc.nextDouble();
        System.out.print("输入运算符(+,-,*,/,%)：");
        String op = sc.next();
        System.out.print("输入第二个数：");
        double num2 = sc.nextDouble();

        double result = calculate(num1, num2, op);
        // 比较运算：判断结果是否有效
        if (Double.isNaN(result)) {
            System.out.println("计算错误（除数为0或运算符无效）");
        } else {
            System.out.printf("%.2f %s %.2f = %.2f%n", num1, op, num2, result);
            // 复合赋值演示
            double accumulated = 0;
            accumulated += result;
            System.out.println("累加结果：" + accumulated);
        }

        // 数值分析
        System.out.println("\n=== 数值分析 ===");
        int[] testNums = {0, 7, -4, 128, 255};
        for (int n : testNums) {
            analyzeNumber(n);
        }

        // 短路特性
        demonstrateShortCircuit();

        // instanceof
        demonstrateInstanceof();

        // 运算符优先级陷阱
        System.out.println("\n--- 优先级陷阱 ---");
        int x = 5;
        System.out.println("2 + 3 * 4 = " + (2 + 3 * 4));       // 14，不是20
        System.out.println("x > 3 & x < 10: " + (x > 3 & x < 10)); // true
        System.out.println("true || false && false: " + (true || false && false)); // true（&&优先级高于||）

        sc.close();
    }
}
```
