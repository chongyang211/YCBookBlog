## 14.1 泛型入门

### 14.1.1 为什么需要泛型

没有泛型时，集合只能存 `Object`，取出时需要强制转换，容易出错：

```java
// 没有泛型
ArrayList list = new ArrayList();
list.add("Hello");
list.add(123);       // 可以放任何类型
String s = (String) list.get(1);  // 运行时 ClassCastException！

// 使用泛型
ArrayList<String> list2 = new ArrayList<>();
list2.add("Hello");
// list2.add(123);   // 编译错误！类型安全
String s2 = list2.get(0);  // 不需要强制转换
```

### 14.1.2 泛型的好处

1. **类型安全**：编译期检查类型，避免 ClassCastException。
2. **消除强制转换**：不需要手动类型转换。
3. **代码复用**：一份代码支持多种类型。

**对比 C++**：C++ 的模板（template）在编译时展开，为每种类型生成独立的代码。Java 的泛型通过类型擦除实现，运行时没有泛型信息。

## 14.2 泛型类

### 14.2.1 泛型类定义

```java
public class Box<T> {
    private T content;

    public void put(T item) {
        this.content = item;
    }

    public T get() {
        return content;
    }
}

// 使用
Box<String> stringBox = new Box<>();
stringBox.put("Hello");
String s = stringBox.get();  // 不需要强制转换

Box<Integer> intBox = new Box<>();
intBox.put(123);
int num = intBox.get();
```

### 14.2.2 多类型参数

```java
public class Pair<K, V> {
    private K key;
    private V value;

    public Pair(K key, V value) {
        this.key = key;
        this.value = value;
    }

    public K getKey() { return key; }
    public V getValue() { return value; }
}

Pair<String, Integer> pair = new Pair<>("age", 25);
System.out.println(pair.getKey() + ": " + pair.getValue());
```

## 14.3 泛型方法

### 14.3.1 泛型方法定义

```java
public class ArrayUtils {
    // 泛型方法：<T> 放在返回类型前面
    public static <T> void printArray(T[] arr) {
        for (T item : arr) {
            System.out.print(item + " ");
        }
        System.out.println();
    }

    public static <T extends Comparable<T>> T max(T a, T b) {
        return a.compareTo(b) > 0 ? a : b;
    }
}
```

### 14.3.2 泛型方法使用

```java
Integer[] nums = {1, 2, 3, 4, 5};
String[] names = {"Alice", "Bob", "Charlie"};

ArrayUtils.printArray(nums);    // 1 2 3 4 5
ArrayUtils.printArray(names);   // Alice Bob Charlie

int maxNum = ArrayUtils.max(10, 20);  // 20
String maxStr = ArrayUtils.max("abc", "xyz");  // xyz
```

## 14.5 通配符

### 14.5.1 无界通配符

```java
// ? 表示任意类型
public static void printList(List<?> list) {
    for (Object item : list) {
        System.out.println(item);
    }
}

printList(List.of(1, 2, 3));
printList(List.of("a", "b", "c"));
```

### 14.5.2 上界通配符

```java
// ? extends Number：Number 或 Number 的子类
public static double sum(List<? extends Number> list) {
    double total = 0;
    for (Number num : list) {
        total += num.doubleValue();
    }
    return total;
}

sum(List.of(1, 2, 3));        // List<Integer>，OK
sum(List.of(1.5, 2.5));       // List<Double>，OK
// sum(List.of("a", "b"));    // List<String>，编译错误
```

### 14.5.3 下界通配符

```java
// ? super Integer：Integer 或 Integer 的父类
public static void addNumbers(List<? super Integer> list) {
    list.add(1);
    list.add(2);
    list.add(3);
}

List<Number> numList = new ArrayList<>();
addNumbers(numList);  // OK
List<Object> objList = new ArrayList<>();
addNumbers(objList);  // OK
```

> **PECS 原则**：Producer Extends, Consumer Super。读取数据用 `extends`，写入数据用 `super`。

## 14.6 类型擦除

### 14.6.1 擦除机制

Java 泛型在编译后会被**擦除**，运行时没有泛型信息：

```java
// 编译前
List<String> list = new ArrayList<>();
list.add("Hello");
String s = list.get(0);

// 编译后（类型擦除）
List list = new ArrayList();
list.add("Hello");
String s = (String) list.get(0);  // 编译器自动插入强制转换
```

### 14.6.2 擦除的影响

```java
// 1. 不能用基本类型作为类型参数
// List<int> list;  // 编译错误，必须用 List<Integer>

// 2. 不能创建泛型数组
// T[] arr = new T[10];  // 编译错误

// 3. 运行时泛型类型相同
List<String> a = new ArrayList<>();
List<Integer> b = new ArrayList<>();
System.out.println(a.getClass() == b.getClass());  // true（都是 ArrayList）
```

**对比 C++**：C++ 模板不存在类型擦除，每种类型会生成独立的代码（代码膨胀），但运行时性能更高。Java 通过类型擦除避免了代码膨胀，但牺牲了一些运行时类型信息。

## 14.7 综合案例：通用数据容器

本案例融合泛型章节的核心知识点：泛型类、泛型方法、泛型接口、通配符（上界/下界）、类型擦除的影响等。

```java
import java.util.*;
import java.util.function.Predicate;

/**
 * 通用数据容器
 * 融合知识点：泛型类、泛型方法、泛型接口、上界/下界通配符、PECS原则
 */

// 泛型接口：可过滤
interface Filterable<T> {
    List<T> filter(Predicate<T> condition);
}

// 泛型接口：可转换
interface Transformable<T> {
    <R> DataContainer<R> map(java.util.function.Function<T, R> mapper);
}

// 泛型类：数据容器
class DataContainer<T> implements Filterable<T>, Transformable<T> {
    private List<T> items;

    // 构造方法
    public DataContainer() {
        this.items = new ArrayList<>();
    }

    // 安全添加
    @SafeVarargs
    public final DataContainer<T> addAll(T... elements) {
        Collections.addAll(items, elements);
        return this;  // 链式调用
    }

    // 泛型方法：查找第一个匹配的元素
    public <R> Optional<R> findFirst(Class<R> type) {
        for (T item : items) {
            if (type.isInstance(item)) {
                return Optional.of(type.cast(item));
            }
        }
        return Optional.empty();
    }

    // 实现 Filterable 接口
    @Override
    public List<T> filter(Predicate<T> condition) {
        List<T> result = new ArrayList<>();
        for (T item : items) {
            if (condition.test(item)) {
                result.add(item);
            }
        }
        return result;
    }

    // 实现 Transformable 接口：泛型方法，将 T 转换为 R
    @Override
    public <R> DataContainer<R> map(java.util.function.Function<T, R> mapper) {
        DataContainer<R> result = new DataContainer<>();
        for (T item : items) {
            result.addAll(mapper.apply(item));
        }
        return result;
    }

    // 上界通配符：接受 T 或 T 的子类的列表（Producer Extends）
    public void addFrom(List<? extends T> source) {
        items.addAll(source);
    }

    // 下界通配符：将元素复制到 T 或 T 的父类的列表（Consumer Super）
    public void copyTo(List<? super T> dest) {
        dest.addAll(items);
    }

    // 泛型方法：求最大值（有界类型参数）
    public static <T extends Comparable<T>> T max(List<T> list) {
        if (list.isEmpty()) throw new IllegalArgumentException("列表为空");
        T max = list.get(0);
        for (T item : list) {
            if (item.compareTo(max) > 0) max = item;
        }
        return max;
    }

    // 泛型方法：两个容器合并
    public static <T> DataContainer<T> merge(DataContainer<? extends T> a,
                                              DataContainer<? extends T> b) {
        DataContainer<T> result = new DataContainer<>();
        result.addFrom(a.getItems());
        result.addFrom(b.getItems());
        return result;
    }

    public List<T> getItems() { return Collections.unmodifiableList(items); }
    public int size() { return items.size(); }

    @Override
    public String toString() {
        return items.toString();
    }
}

// 多类型参数泛型类：键值对
class Pair<K, V> {
    private K key;
    private V value;

    public Pair(K key, V value) {
        this.key = key;
        this.value = value;
    }

    public K getKey() { return key; }
    public V getValue() { return value; }

    // 泛型方法：交换键值
    public Pair<V, K> swap() {
        return new Pair<>(value, key);
    }

    @Override
    public String toString() {
        return key + "=" + value;
    }
}

public class GenericDemo {

    // 无界通配符：打印任意类型的列表
    public static void printList(List<?> list) {
        System.out.print("  [");
        for (int i = 0; i < list.size(); i++) {
            if (i > 0) System.out.print(", ");
            System.out.print(list.get(i));
        }
        System.out.println("]");
    }

    // 上界通配符：计算数值列表的总和
    public static double sum(List<? extends Number> list) {
        double total = 0;
        for (Number num : list) {
            total += num.doubleValue();
        }
        return total;
    }

    public static void main(String[] args) {
        System.out.println("╔═══════════════════════════════╗");
        System.out.println("║      泛型综合案例演示         ║");
        System.out.println("╚═══════════════════════════════╝");

        // 泛型类使用
        System.out.println("\n--- 泛型类 ---");
        DataContainer<String> names = new DataContainer<>();
        names.addAll("张三", "李四", "王五", "赵六", "张伟");
        System.out.println("名字容器：" + names);

        DataContainer<Integer> numbers = new DataContainer<>();
        numbers.addAll(10, 25, 3, 42, 18, 7);
        System.out.println("数字容器：" + numbers);

        // 过滤（泛型接口）
        System.out.println("\n--- 过滤 ---");
        List<String> zhangNames = names.filter(n -> n.startsWith("张"));
        System.out.println("姓张的：" + zhangNames);

        List<Integer> bigNums = numbers.filter(n -> n > 15);
        System.out.println("大于15的：" + bigNums);

        // 转换（泛型方法）
        System.out.println("\n--- 转换 ---");
        DataContainer<Integer> nameLengths = names.map(String::length);
        System.out.println("名字长度：" + nameLengths);

        DataContainer<String> numStrings = numbers.map(n -> "第" + n + "号");
        System.out.println("转字符串：" + numStrings);

        // Pair 多类型参数
        System.out.println("\n--- Pair<K,V> ---");
        Pair<String, Integer> pair = new Pair<>("年龄", 25);
        System.out.println("原始：" + pair);
        Pair<Integer, String> swapped = pair.swap();
        System.out.println("交换：" + swapped);

        // 通配符
        System.out.println("\n--- 通配符 ---");
        List<Integer> intList = List.of(1, 2, 3);
        List<Double> doubleList = List.of(1.5, 2.5, 3.5);
        System.out.print("Integer: "); printList(intList);   // 无界通配符
        System.out.print("Double: "); printList(doubleList);
        System.out.println("Integer sum: " + sum(intList));    // 上界通配符
        System.out.println("Double sum: " + sum(doubleList));

        // PECS 原则演示
        System.out.println("\n--- PECS 原则 ---");
        DataContainer<Number> numContainer = new DataContainer<>();
        numContainer.addFrom(intList);      // ? extends Number (Producer)
        numContainer.addFrom(doubleList);
        System.out.println("Number容器（合并int和double）：" + numContainer);

        List<Object> objectList = new ArrayList<>();
        numContainer.copyTo(objectList);    // ? super Number (Consumer)
        System.out.println("复制到Object列表：" + objectList);

        // 有界类型参数
        System.out.println("\n--- 有界类型参数 ---");
        System.out.println("最大整数：" + DataContainer.max(List.of(3, 1, 4, 1, 5)));
        System.out.println("最大字符串：" + DataContainer.max(List.of("banana", "apple", "cherry")));

        // 合并两个容器
        System.out.println("\n--- 容器合并 ---");
        DataContainer<Integer> merged = DataContainer.merge(
                new DataContainer<Integer>().addAll(1, 2, 3),
                new DataContainer<Integer>().addAll(4, 5, 6));
        System.out.println("合并结果：" + merged);

        // 类型擦除演示
        System.out.println("\n--- 类型擦除 ---");
        DataContainer<String> strContainer = new DataContainer<>();
        DataContainer<Integer> intContainer = new DataContainer<>();
        System.out.println("类型相同？" +
                (strContainer.getClass() == intContainer.getClass()));  // true
        System.out.println("类名：" + strContainer.getClass().getName());
    }
}
```

| 知识点 | 案例中的体现 |
|--------|-------------|
| 泛型类 | `DataContainer<T>`、`Pair<K,V>` |
| 泛型接口 | `Filterable<T>`、`Transformable<T>` |
| 泛型方法 | `<R> findFirst(Class<R>)`、`<T extends Comparable<T>> max()` |
| 多类型参数 | `Pair<K, V>` |
| 无界通配符 | `List<?>` |
| 上界通配符 | `List<? extends Number>`（Producer Extends） |
| 下界通配符 | `List<? super T>`（Consumer Super） |
| PECS 原则 | `addFrom(? extends T)` / `copyTo(? super T)` |
| 有界类型参数 | `<T extends Comparable<T>>` |
| 类型擦除 | 运行时泛型信息丢失 |
| @SafeVarargs | 泛型可变参数安全标注 |
