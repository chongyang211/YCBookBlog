## 12.1 File类

### 12.1.1 File类介绍

`java.io.File` 类用于表示文件和目录的路径。它不能读写文件内容，只能操作文件/目录本身（创建、删除、判断是否存在等）。

```java
import java.io.File;

File file = new File("test.txt");
File dir = new File("/Users/yc/documents");
```

### 12.1.2 File常用方法

```java
File file = new File("test.txt");

// 判断
file.exists();        // 是否存在
file.isFile();        // 是否是文件
file.isDirectory();   // 是否是目录

// 获取信息
file.getName();       // 文件名
file.getPath();       // 路径
file.getAbsolutePath();  // 绝对路径
file.length();        // 文件大小（字节）
file.lastModified();  // 最后修改时间

// 创建和删除
file.createNewFile(); // 创建新文件
file.delete();        // 删除文件
```

### 12.1.3 目录操作

```java
File dir = new File("mydir");
dir.mkdir();     // 创建单级目录
dir.mkdirs();    // 创建多级目录

// 列出目录内容
File[] files = dir.listFiles();
if (files != null) {
    for (File f : files) {
        System.out.println(f.getName() + (f.isDirectory() ? " [目录]" : ""));
    }
}
```

## 12.2 IO流概述

### 12.2.1 IO流分类

| 分类 | 说明 | 适用场景 |
|------|------|---------|
| 字节流 | 以字节为单位读写（InputStream/OutputStream） | 图片、视频、二进制文件 |
| 字符流 | 以字符为单位读写（Reader/Writer） | 文本文件 |
| 缓冲流 | 带缓冲区，提高读写效率 | 大文件操作 |

### 12.2.2 IO流体系

```
字节流：
  InputStream（抽象类）
  ├── FileInputStream
  ├── BufferedInputStream
  └── ObjectInputStream

  OutputStream（抽象类）
  ├── FileOutputStream
  ├── BufferedOutputStream
  └── ObjectOutputStream

字符流：
  Reader（抽象类）
  ├── FileReader
  ├── BufferedReader
  └── InputStreamReader

  Writer（抽象类）
  ├── FileWriter
  ├── BufferedWriter
  └── OutputStreamWriter
```

**对比 C++**：C++ 使用 `ifstream`/`ofstream`/`fstream` 进行文件操作，Java 的 IO 体系更加分层和复杂，但也更灵活。

## 12.3 字节流

### 12.3.1 FileInputStream

```java
try (FileInputStream fis = new FileInputStream("test.txt")) {
    int data;
    while ((data = fis.read()) != -1) {
        System.out.print((char) data);
    }
} catch (IOException e) {
    e.printStackTrace();
}

// 使用字节数组读取（更高效）
try (FileInputStream fis = new FileInputStream("test.txt")) {
    byte[] buffer = new byte[1024];
    int len;
    while ((len = fis.read(buffer)) != -1) {
        System.out.print(new String(buffer, 0, len));
    }
} catch (IOException e) {
    e.printStackTrace();
}
```

### 12.3.2 FileOutputStream

```java
try (FileOutputStream fos = new FileOutputStream("output.txt")) {
    String content = "Hello Java IO!";
    fos.write(content.getBytes());
} catch (IOException e) {
    e.printStackTrace();
}

// 追加写入
try (FileOutputStream fos = new FileOutputStream("output.txt", true)) {
    fos.write("\n追加内容".getBytes());
} catch (IOException e) {
    e.printStackTrace();
}
```

### 12.3.3 文件复制

```java
public static void copyFile(String src, String dest) throws IOException {
    try (FileInputStream fis = new FileInputStream(src);
         FileOutputStream fos = new FileOutputStream(dest)) {
        byte[] buffer = new byte[4096];
        int len;
        while ((len = fis.read(buffer)) != -1) {
            fos.write(buffer, 0, len);
        }
    }
}
```

## 12.6 序列化

### 12.6.1 序列化概念

序列化是将对象转换为字节流的过程（保存到文件或网络传输），反序列化是将字节流还原为对象的过程。

### 12.6.2 序列化实现

```java
import java.io.*;

// 类必须实现 Serializable 接口
public class Account implements Serializable {
    private static final long serialVersionUID = 1L;
    private String name;
    private double balance;
    private transient String password;  // transient 字段不参与序列化

    public Account(String name, double balance, String password) {
        this.name = name;
        this.balance = balance;
        this.password = password;
    }

    @Override
    public String toString() {
        return "Account{name='" + name + "', balance=" + balance + "}";
    }
}

// 序列化（写入文件）
Account acc = new Account("张三", 1000, "123456");
try (ObjectOutputStream oos = new ObjectOutputStream(
        new FileOutputStream("account.dat"))) {
    oos.writeObject(acc);
} catch (IOException e) {
    e.printStackTrace();
}

// 反序列化（从文件读取）
try (ObjectInputStream ois = new ObjectInputStream(
        new FileInputStream("account.dat"))) {
    Account loaded = (Account) ois.readObject();
    System.out.println(loaded);  // Account{name='张三', balance=1000.0}
} catch (IOException | ClassNotFoundException e) {
    e.printStackTrace();
}
```

## 12.7 综合案例：配置文件管理器

本案例融合IO流和File章节的核心知识点：File操作、字节流、字符流、缓冲流、序列化、try-with-resources等。

```java
import java.io.*;
import java.nio.file.*;
import java.util.*;

/**
 * 配置文件管理器
 * 融合知识点：File操作、字节流/字符流、缓冲流、序列化、目录遍历
 */
public class ConfigManager {

    // 可序列化的配置类
    static class AppConfig implements Serializable {
        private static final long serialVersionUID = 1L;
        private Map<String, String> settings;
        private transient String runtimeInfo;  // transient 不参与序列化

        public AppConfig() {
            settings = new LinkedHashMap<>();
            runtimeInfo = "运行时信息";
        }

        public void set(String key, String value) { settings.put(key, value); }
        public String get(String key) { return settings.getOrDefault(key, ""); }
        public void remove(String key) { settings.remove(key); }
        public Map<String, String> getAll() { return Collections.unmodifiableMap(settings); }
    }

    private final String configDir;

    public ConfigManager(String configDir) {
        this.configDir = configDir;
    }

    // File 操作：初始化配置目录
    public void init() {
        File dir = new File(configDir);
        if (!dir.exists()) {
            boolean created = dir.mkdirs();
            System.out.println("创建配置目录：" + (created ? "成功" : "失败"));
        } else {
            System.out.println("配置目录已存在：" + dir.getAbsolutePath());
        }
    }

    // 字符流 + 缓冲流：保存为文本配置文件
    public void saveAsText(AppConfig config, String filename) {
        File file = new File(configDir, filename);
        // try-with-resources 自动关闭
        try (BufferedWriter bw = new BufferedWriter(new FileWriter(file))) {
            bw.write("# 应用配置文件");
            bw.newLine();
            bw.write("# 自动生成，请勿手动修改");
            bw.newLine();
            bw.newLine();

            for (Map.Entry<String, String> entry : config.getAll().entrySet()) {
                bw.write(entry.getKey() + "=" + entry.getValue());
                bw.newLine();
            }
            System.out.println("  文本配置已保存：" + file.getName());
        } catch (IOException e) {
            System.out.println("  保存失败：" + e.getMessage());
        }
    }

    // 字符流 + 缓冲流：读取文本配置文件
    public AppConfig loadFromText(String filename) {
        File file = new File(configDir, filename);
        AppConfig config = new AppConfig();

        if (!file.exists()) {
            System.out.println("  配置文件不存在：" + filename);
            return config;
        }

        try (BufferedReader br = new BufferedReader(new FileReader(file))) {
            String line;
            int lineNum = 0;
            while ((line = br.readLine()) != null) {
                lineNum++;
                line = line.trim();
                // 跳过注释和空行
                if (line.isEmpty() || line.startsWith("#")) continue;

                int eqIdx = line.indexOf('=');
                if (eqIdx > 0) {
                    String key = line.substring(0, eqIdx).trim();
                    String value = line.substring(eqIdx + 1).trim();
                    config.set(key, value);
                } else {
                    System.out.printf("  警告：第%d行格式错误：%s%n", lineNum, line);
                }
            }
            System.out.println("  文本配置已加载：" + filename + "（" + config.getAll().size() + " 项）");
        } catch (IOException e) {
            System.out.println("  加载失败：" + e.getMessage());
        }
        return config;
    }

    // 序列化：保存为二进制文件
    public void saveAsBinary(AppConfig config, String filename) {
        File file = new File(configDir, filename);
        try (ObjectOutputStream oos = new ObjectOutputStream(
                new BufferedOutputStream(new FileOutputStream(file)))) {
            oos.writeObject(config);
            System.out.println("  二进制配置已保存：" + file.getName()
                    + "（" + file.length() + " 字节）");
        } catch (IOException e) {
            System.out.println("  保存失败：" + e.getMessage());
        }
    }

    // 反序列化：读取二进制文件
    public AppConfig loadFromBinary(String filename) {
        File file = new File(configDir, filename);
        try (ObjectInputStream ois = new ObjectInputStream(
                new BufferedInputStream(new FileInputStream(file)))) {
            AppConfig config = (AppConfig) ois.readObject();
            System.out.println("  二进制配置已加载：" + filename);
            return config;
        } catch (IOException | ClassNotFoundException e) {
            System.out.println("  加载失败：" + e.getMessage());
            return new AppConfig();
        }
    }

    // 字节流：文件复制
    public void backupFile(String srcName, String destName) {
        File src = new File(configDir, srcName);
        File dest = new File(configDir, destName);

        try (FileInputStream fis = new FileInputStream(src);
             FileOutputStream fos = new FileOutputStream(dest)) {
            byte[] buffer = new byte[4096];
            int len;
            long totalBytes = 0;
            while ((len = fis.read(buffer)) != -1) {
                fos.write(buffer, 0, len);
                totalBytes += len;
            }
            System.out.printf("  备份完成：%s → %s（%d 字节）%n",
                    srcName, destName, totalBytes);
        } catch (IOException e) {
            System.out.println("  备份失败：" + e.getMessage());
        }
    }

    // File 操作：遍历配置目录
    public void listConfigFiles() {
        File dir = new File(configDir);
        File[] files = dir.listFiles();
        System.out.println("\n--- 配置目录文件列表 ---");
        System.out.println("  路径：" + dir.getAbsolutePath());

        if (files == null || files.length == 0) {
            System.out.println("  （空目录）");
            return;
        }

        long totalSize = 0;
        for (File f : files) {
            String type = f.isDirectory() ? "[目录]" : "[文件]";
            System.out.printf("  %s %-20s %d 字节%n", type, f.getName(), f.length());
            totalSize += f.length();
        }
        System.out.printf("  共 %d 个文件，总大小 %d 字节%n", files.length, totalSize);
    }

    // 清理：删除配置目录
    public void cleanup() {
        File dir = new File(configDir);
        File[] files = dir.listFiles();
        if (files != null) {
            for (File f : files) f.delete();
        }
        dir.delete();
        System.out.println("\n配置目录已清理");
    }

    public static void main(String[] args) {
        System.out.println("╔═══════════════════════════════╗");
        System.out.println("║    配置文件管理器演示         ║");
        System.out.println("╚═══════════════════════════════╝");

        ConfigManager manager = new ConfigManager("test_config");
        manager.init();

        // 创建配置
        AppConfig config = new AppConfig();
        config.set("app.name", "MyApp");
        config.set("app.version", "2.0");
        config.set("server.host", "localhost");
        config.set("server.port", "8080");
        config.set("database.url", "jdbc:mysql://localhost:3306/mydb");
        config.set("database.pool.size", "10");

        // 保存为文本
        System.out.println("\n--- 保存配置 ---");
        manager.saveAsText(config, "app.conf");

        // 保存为二进制
        manager.saveAsBinary(config, "app.dat");

        // 从文本加载
        System.out.println("\n--- 加载配置 ---");
        AppConfig loaded1 = manager.loadFromText("app.conf");
        System.out.println("  配置内容：");
        loaded1.getAll().forEach((k, v) -> System.out.printf("    %s = %s%n", k, v));

        // 从二进制加载
        AppConfig loaded2 = manager.loadFromBinary("app.dat");
        System.out.println("  配置内容（二进制）：");
        loaded2.getAll().forEach((k, v) -> System.out.printf("    %s = %s%n", k, v));

        // 备份文件
        System.out.println("\n--- 文件备份 ---");
        manager.backupFile("app.conf", "app.conf.bak");

        // 列出文件
        manager.listConfigFiles();

        // 清理
        manager.cleanup();
    }
}
```

**案例知识点总结：**

| 知识点 | 案例中的体现 |
|--------|-------------|
| File 类 | 创建目录 `mkdirs()`、判断存在 `exists()`、获取信息 |
| 目录操作 | `listFiles()` 遍历目录 |
| FileReader/FileWriter | 字符流读写文本配置 |
| BufferedReader/BufferedWriter | 缓冲流提高效率，`readLine()` 按行读取 |
| FileInputStream/FileOutputStream | 字节流实现文件复制 |
| ObjectInputStream/ObjectOutputStream | 序列化/反序列化 |
| Serializable | `AppConfig implements Serializable` |
| transient | `runtimeInfo` 字段不序列化 |
| try-with-resources | 所有流操作自动关闭 |
| 缓冲流包装 | `BufferedOutputStream(new FileOutputStream(...))` |
