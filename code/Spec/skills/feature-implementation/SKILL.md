# 功能实现

根据已确认的 spec 和 implementation plan，在 `src/` 中逐步执行代码变更。

## 执行步骤

1. **按 plan 顺序逐步执行**
   - 严格按照 plan 中定义的步骤顺序
   - 一次只做一个步骤，完成后再开始下一个
   - 发现 plan 有遗漏时，先说明再调整

2. **每步修改前读取目标文件**
   - 必须先读取最新内容，不基于记忆修改
   - 理解文件上下文，确认修改位置

3. **执行最小改动**
   - 只修改 plan 中指定的部分
   - 使用精确替换，不输出大段未修改代码
   - 保持现有代码风格

4. **确保代码质量**
   - 包含输入验证和错误处理
   - 公共接口有清晰注释
   - 不引入未使用的导入

5. **验证每步结果**
   - 每步完成后简要确认改动
   - 接口修改确认调用方不受影响

## 输出格式

每完成一个步骤：

```
✅ Step N 完成：[做了什么]
   文件：[修改的文件]
   改动：[简述]
```

全部完成后：

```
所有步骤已完成。共修改 N 个文件，新增 M 个文件。
进入下一阶段：测试编写。
```

## 注意事项

- 实施中发现 plan 有问题，**停下来说明**
- 需要修改 plan 之外的文件，**先说明原因等待确认**
- 不在实现阶段做"优化"
- 不确定的设计决策选择最简单方案
