## 技能文档

### 基本信息
- 技能名: `feature-implementation`
- 版本: v1.0.0
- 更新时间: 2026-03-26

### 适用场景
- 实施计划已确认，开始在 src/ 中编写或修改代码
- 按已确认的 plan 逐步执行代码变更

### 前置条件
- 有已确认的 implementation plan
- 对应的 spec 文件已分析
- 能访问 `src/` 目录

### 使用示例
```
确认 plan，请执行 spec-implement
请根据 specs/v1.6.0/0-example-feature.md 执行 spec-implement
```

### 注意事项
⚠️ 严格按 plan 执行，不擅自扩大改动范围
⚠️ 每步修改前必须先读取目标文件

### 相关技能
- `implementation-planning`: 前置技能，提供 plan
- `test-writing`: 后续技能，实现完成后补测试
