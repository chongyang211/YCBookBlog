## 技能文档

### 基本信息
- 技能名: `change-summary`
- 版本: v1.0.0
- 更新时间: 2026-03-26

### 适用场景
- 完成 spec 实施和测试后输出总结
- Bug 修复后总结改动
- 任何对 src/ 或 tests/ 有实质性修改后

### 前置条件
- 已完成功能实现和测试
- 有对应的 spec 文件

### 使用示例
```
请输出变更摘要
请总结这次改动
```

### 注意事项
⚠️ 变更摘要是必须步骤，不可跳过
⚠️ 必须包含文档同步建议

### 相关技能
- `test-writing`: 前置技能，测试完成后做摘要
- `spec-analysis`: 摘要中需对照 spec 验收标准
