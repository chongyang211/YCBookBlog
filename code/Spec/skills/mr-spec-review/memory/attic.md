# 规则归档区（Attic）

> 本文件存放被 **淘汰 / 拒收 / 休眠归档** 的 Pattern，来自 [`EVAL-SPEC.md`](./EVAL-SPEC.md) 的净化淘汰逻辑（§7）与入库门禁（§5.5 rejected）。
>
> 🎯 **归档而非删除**：保留状态、统计、淘汰理由，便于**审计**（为什么当初下架）与**恢复**（同类问题重现时可复活为 `shadow` 重新试用）。

## 归档条目格式

```markdown
### [来源编号] 标题

**归档状态**: retired | rejected | archived-dormant
**归档日期**: YYYY-MM-DD
**归档理由**: <误报淘汰 / 锚点失效无法重锚 / 冲突落败 / 长期0命中 / 入库回测未达标 …>
**最终统计**: 命中 N · TP x · FP y · Precision p · 独立上下文 c
**原四元组**: trigger / probe / assertion / fix（保留以便恢复）
**恢复条件**: <什么情况下可复活为 shadow>
```
