## 技能文档

### 基本信息
- 技能名: `test-writing`
- 版本: v1.0.0
- 更新时间: 2026-03-26

### 适用场景
- 功能实现完成后，根据 spec 补充测试
- 现有功能缺少测试需要补充
- Bug 修复后编写回归测试

### 前置条件
- 功能代码已实现
- 对应的 spec 文件包含验收标准和测试点

### 使用示例
```
请执行 spec-test
请根据 specs/v1.6.0/0-example-feature.md 执行 spec-test
```

### 注意事项
⚠️ 每个验收标准至少一个测试
⚠️ 必须覆盖 spec 中列出的边界情况

### 相关技能
- `feature-implementation`: 前置技能，先实现再测试
- `change-summary`: 后续技能，测试完成后输出摘要
