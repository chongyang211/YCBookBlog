# 触发评估用例

## 正例（应触发 palm-openapi skill）

1. "我是新接入的，怎么开始"
2. "帮我查询 user_123 的录掌状态"
3. "给我 Go 的签名实现代码"
4. "这条推送回调验签对吗"
5. "Code 10003 是什么意思"
6. "帮我算下这个请求的签名"
7. "把刚才的请求生成 curl"
8. "我刚拿到密钥，怎么跑通第一个接口"
9. "Java 怎么调用查询录掌结果"
10. "为什么我这边收到的回调验签老是不通过"
11. "帮我创建一个商户叫 Sunshine 便利店"
12. "把设备 SN_xxx 录入到商户 ABC 下面"
13. "切到生产环境"
14. "我用的是 v1.5 的签名规则，按这个算一遍"
15. "签名失败，帮我排查"

## 反例（不应触发 palm-openapi skill）

1. "帮我写一个 React 登录页面"
2. "Python 怎么读取 CSV 文件"
3. "帮我优化这段 SQL 查询"
4. "Git 怎么回滚到上一个版本"
5. "帮我写一个单元测试"
6. "Docker 容器怎么部署"
7. "帮我分析这段代码的性能问题"
8. "怎么配置 Nginx 反向代理"
9. "帮我写一个定时任务"
10. "数据库连接池怎么配置"
11. "帮我生成一个 JWT token"（通用JWT，非刷掌平台）
12. "微信支付接口怎么调用"（非刷掌平台）

## 边界用例（需要判断上下文）

1. "帮我签名" → 如果上下文中有刷掌平台相关信息则触发，否则不触发
2. "RSA 加密怎么做" → 如果是问刷掌平台的加密字段则触发，通用问题不触发
3. "接口报错了" → 如果上下文中有刷掌平台调用记录则触发
4. "帮我生成代码" → 如果是刷掌平台相关代码则触发
5. "验签失败" → 如果是刷掌平台推送验签则触发，其他平台不触发
