## 技能文档

### 基本信息
- 技能名: `palm-openapi`
- 创建人: @alfredyu (alfredyu@tencent.com)
- 版本: v1.0.0
- 更新时间: 2026-07-23

### 适用场景
帮助开发者快速接入刷掌开放平台 OpenAPI，适用于以下场景：
- 首次接入的开发者需要引导完成第一次成功调用
- 需要配置/切换凭证和环境
- 需要调用开放接口（录掌、查询、商户、设备等）
- 需要生成签名串或验证推送回调签名
- 遇到错误码需要诊断和修复建议
- 需要生成各语言（Java/Go/Python/PHP/Node.js）的代码片段
- 需要导出 curl 命令或回放历史请求

### 前置条件
- 已获取 SecretId 和 PrivateKey（RSA PKCS#8 格式）
- 已获取平台提供的 PublicKey（用于推送验签）
- 如需加密字段，已获取平台提供的加密公钥
- Python 3.6+ 环境（用于脚本工具）
- 已安装 `cryptography` 库：`pip3 install cryptography`

### 使用示例
```
"我是新接入的，怎么开始"
"帮我查询 user_123 的录掌状态"
"给我 Go 的签名实现代码"
"这条推送回调验签对吗"
"Code 10003 是什么意思"
"帮我算下这个请求的签名"
"把刚才的请求生成 curl"
```

### 注意事项
⚠️ 私钥必须为 PKCS#8 格式（`-----BEGIN PRIVATE KEY-----`），不支持 PKCS#1 格式
⚠️ 签名中的 Content-Type 必须与实际请求完全一致（注意 charset 问题）
⚠️ 时间戳为秒级 UNIX 时间戳，通常有 5 分钟有效期
⚠️ 加密字段使用 RSA-OAEP + SHA-256，不是普通 RSA 加密
⚠️ 推送验签使用平台提供的公钥，与调用签名使用的私钥是不同的密钥对
