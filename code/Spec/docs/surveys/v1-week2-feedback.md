# Spec-Driven AI 协作工作流 · 团队使用反馈问卷（v1，试运行第 2–3 周）

> **预计耗时**：8–12 分钟
> **匿名**：本问卷不收集姓名/工号，结果仅用于 v2 规则精简、命令合并、文档补齐与培训优化。
> **填写建议**：请基于近两周你**真实**用过的命令与真实经历作答；未用过的阶段直接勾选"未使用/不适用"即可，无需强填。
> **术语约定**：Spec = 要做什么；Plan = 怎么做；Tasks = 步步执行清单；三件套 = Spec + Plan + Tasks；MR = Merge Request。
