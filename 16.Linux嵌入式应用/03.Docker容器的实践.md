## 03.检查Docker服务状态

`systemctl` 是管理 systemd 服务的工具，Docker 通常作为一个 systemd 服务运行。

```bash
docker --version
sudo systemctl status docker
```

**输出示例：**
- **Docker 已启动**：
  ```
  ● docker.service - Docker Application Container Engine
     Loaded: loaded (/lib/systemd/system/docker.service; enabled; vendor preset: enabled)
     Active: active (running) since ...
  ```
- **Docker 未启动**：
  ```
  ● docker.service - Docker Application Container Engine
     Loaded: loaded (/lib/systemd/system/docker.service; enabled; vendor preset: enabled)
     Active: inactive (dead)
  ```

## 04.启动Docker服务

如果 Docker 未启动，可以使用以下命令启动：

```bash
sudo systemctl start docker
```

**设置 Docker 开机自启**
```bash
sudo systemctl enable docker
```

## 05.检查Docker是否运行

直接运行 `docker` 命令，如果 Docker 已启动，会显示 Docker 的帮助信息；如果未启动，会提示错误。

```bash
docker info
```

**Docker 已启动**：

```shell
CHONGYYANG-MB1:~ yangchong$ docker info
Client: Docker Engine - Community
 Version:    28.1.1
 Context:    colima
 Debug Mode: false

Server:
 Containers: 0
  Running: 0
  Paused: 0
  Stopped: 0
 Images: 2
 Server Version: 27.4.0
```

**Docker 未启动**：

```shell
Cannot connect to the Docker daemon at unix:///var/run/docker.sock. Is the docker daemon running?
```

## 06.检查Docker进程

通过 `ps` 命令查看 Docker 进程是否在运行。

**查看 Docker 进程**

```bash
ps aux | grep docker
```

**Docker 已启动**：

```shell
root      12345  0.0  0.1 123456 7890 ?        Ssl  10:00   0:00 /usr/bin/dockerd -H fd:// --containerd=/run/containerd/containerd.sock
```

**Docker 未启动**：没有与 Docker 相关的进程。

## 07.检查Docker套接字

Docker 通过 Unix 套接字（`/var/run/docker.sock`）与客户端通信。检查该文件是否存在。

**检查套接字文件**

```bash
ls -l /var/run/docker.sock
```

- **Docker 已启动**：
  ```
  srw-rw---- 1 root docker 0 Jan  1 10:00 /var/run/docker.sock
  ```
- **Docker 未启动**：
  ```
  ls: cannot access '/var/run/docker.sock': No such file or directory
  ```

## 08.检查Docker日志

如果 Docker 未启动，可以查看日志以排查问题。

**查看 Docker 日志**

```bash
sudo journalctl -u docker.service
```
