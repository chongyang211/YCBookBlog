## 摘要

Anthropic 提出的 MCP（Model Context Protocol）在 2024 年底掀起了一场"AI 接口革命"。本文从架构、通信机制、生态现状讲清 MCP，对比 Google 的 A2A，并用 Python SDK 从零写一个 MCP Server。

---

## 一、概念篇（30%）

### 1.1 MCP 解决了什么问题

- 工具接入的"N × M 复杂度爆炸"
- 从"每家一套 SDK"到"USB 化"

### 1.2 MCP 架构

- Client ↔ Server 的 JSON-RPC 通信
- Resources / Tools / Prompts 三种能力
- stdio / SSE / WebSocket 三种传输

### 1.3 MCP vs A2A

- MCP：LLM Client ↔ Tool Server
- A2A：Agent ↔ Agent
- 两者是互补，不是竞争
