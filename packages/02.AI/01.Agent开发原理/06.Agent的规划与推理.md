## 摘要

Agent 的推理策略不是拍脑袋选的。本文把四种主流策略（ReAct / CoT / Plan-Execute / ReWOO）从原理到成本一一对比，并用同一个"竞品调研"需求跑一次横向 benchmark，让你在下一次选型时有据可查。

---

## 一、概念篇（30%）

### 1.1 四种推理策略深度对比

| 策略 | 特点 | 适合场景 | Token 成本 |
|------|------|---------|-----------|
| ReAct | 思考-行动交替 | 探索型 | 中 |
| CoT | 先想清楚再动手 | 复杂推理 | 低 |
| Plan-and-Execute | 先规划再执行 | 多步骤 | 中-高 |
| ReWOO | 推理和调用解耦 | 高频调用 | 低 |
