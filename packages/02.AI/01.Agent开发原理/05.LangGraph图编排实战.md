## 摘要

链式调用适合线性任务，但真实 Agent 常有条件分支、循环、并行、人工审批 —— 这时链就变面条了。本文讲清 LangChain 到 LangGraph 的演进逻辑、图编排的核心概念，并用 LangGraph 重构第 4 篇的数据分析 Agent。

---

## 一、概念篇（30%）

### 1.1 LangChain 解决了什么

- 抽象层：统一 Tool / Model / Prompt / Memory
- 生态：Integrations 的价值
- 局限：Chain 只能线性

### 1.2 为什么需要 LangGraph

- 循环表达能力
- 状态管理
- 条件路由

### 1.3 LangGraph 五大核心概念

- **State**：贯穿全图的状态对象
- **Node**：一个执行单元
- **Edge**：无条件跳转
- **Conditional Edge**：条件跳转
- **Checkpoint**：状态持久化 & 断点续跑
