## 摘要

LLM 本身无状态，Agent 要有连贯行为就必须外挂记忆。本文把 Agent 的三类记忆讲透：短期记忆的 Token 预算、长期记忆的向量存储、工作记忆的状态机 —— 并给一个客服 Agent 的完整记忆栈实现。

---

## 一、概念篇（30%）

### 1.1 记忆的三层模型

- 短期记忆 = 对话上下文（messages）
- 工作记忆 = 一次任务的中间状态（TaskState）
- 长期记忆 = 跨会话的知识沉淀（向量库）

### 1.2 上下文窗口的"注意力衰减"

- Long Context ≠ Effective Context
- 中间信息容易被"遗忘"（Lost in the Middle 现象）
- 滑动窗口 vs 摘要压缩

### 1.3 记忆压缩的三种方案

- **摘要式**：把旧对话总结成一段话
- **关键帧式**：抽取几条重要事实
- **分层记忆**：热/温/冷三级存储
