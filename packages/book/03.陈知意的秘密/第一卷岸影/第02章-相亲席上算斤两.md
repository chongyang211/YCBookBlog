# 第02章 相亲席上算斤两

一个女人在相亲桌上被掂量的，不是她的学历。是她户口本上少了一个上海，多了一个弟弟。

母亲的第一条语音是周一早上七点十二分发的。六十秒。

陈知意在地铁上点开。信号不好，转了五秒才加载出来。母亲的声音从听筒里挤出来，每个字之间没有停顿，像一锅煮过头的粥。"知意啊你大姨给你介绍了一个男孩子也是南京毕业的现在上海浦东做金融比你大两岁房子首付已经凑齐了你这个周末去见一下。"六十秒，六十二个字。句号只有一处。在结尾。挤了一整段话的气，到最后一声"啊"才吐出来。

第二条语音是两个小时以后。周一早上九点十五分。陈知意在工位上刚打开电脑。这条短一点，三十二秒。"你二叔那边也有一个。徐汇区有房的。就是个子不太高。一米六八。跟你差不多高。人老实。你周末一起见了。别跑两趟。"第三条是中午十二点四十。四十五秒。母亲大概是在吃饭，背景里有碗筷声和电视机里午间新闻的女声。"还有你三舅妈介绍的那个。今年三十二。离异。没孩子。你要不要见一下。你三舅妈说他前妻是因为他太老实才离的。"

陈知意把三条语音连起来听了一遍。从头到尾，三分钟不到。母亲把她未来半年的婚姻可能性打包好了，像快递一样。大姨一个。二叔一个。三舅妈一个。每个亲戚手里捏着一个男人，从各自的熟人圈里捞出来的，放在微信聊天框里，推送给她。不收中介费，但要人情。

周末。三场相亲。一天之内。

她排了一个时间表。上午十点，一号。中午十二点半，二号。下午两点半，三号。时间表写在手机备忘录里，格式和项目甘特图一模一样。一号旁边标了"(浦东/金融/有首付)"，二号旁边标了"(徐汇/168/老实)"，三号旁边标了"(离异/无孩/太老实)"。标完之后她看着这三个备注，愣了几秒。删掉括号里的内容。重新备注：一号。二号。三号。像整理一份Excel表格。

上午十点。一号。浦东男。金融。他在一家证券公司的营业部做客户经理。见面约在世纪大道一家星巴克，他比她晚到了七分钟。推门进来的时候打了领带。格子领带，配一条深蓝色的休闲裤。坐下以后先点了两杯美式，然后把手机放在桌上，屏幕朝上。锁屏是一张K线图。

"听说你在字节做运营？什么职级？"他没有问她喝什么。美式已经端上来了。她把杯套转了一下，没有喝。"P6。"

"P6还行。你哪一年毕业的？南京大学是吧。本科还是硕士？"硕士。"家里是。苏北？"盐城。"哦。那还行。你爸妈做什么的？"

陈知意端起咖啡喝了一口。美式是苦的。苦到舌根后面去了。不是咖啡苦，是他问问题的方式。像在做一份问卷。每个问题后面都有一行空白，等她填答案。填完了，再翻到下一页。

"有个弟弟是吧。多大了。还在老家的？"二十六。在老家。

他点了点头。端起咖啡喝了一口。然后看了一下手机。屏幕亮了，K线图跳了一下。绿了。他的眼睛在绿色上多停了一秒。比看她任何一眼都久。这顿饭吃了大概五十分钟。临走他加了微信。备注写了：陈知意/字节P6/南大。

中午十二点半。二号。徐汇男。一六八。他选了一家生煎包店，人均三十不到。进门的时候她差点没认出来。他坐在靠墙的位置，正对着玻璃门，背挺得很直。直得像在腰后面塞了一块木板。

"你好，你是陈小姐吧。我是王阿姨介绍的。"他站起来。确实不高。她穿着平底鞋，和他差不多平齐。

他帮她拉开椅子。推了一杯水过来。水是温的。然后开始点菜。生煎包一客，小馄饨一碗，凉拌木耳一份。点完以后把菜单合上，放在桌边，动作很轻，没有发出任何声音。吃饭的时候他一直在说话。讲他在徐汇的房子。一室一厅，老房子，没有电梯，四楼。小区在下个月会装电梯。他的工作是一家出版社的校对，每天看八万字。眼睛近视八百五十度。说完自己的生活以后，问了她的。她的学历。她的工资。她的房租。她的家庭。

陈知意一一回答。他的问题比一号多，但每一个问题问完之后都会加一句"挺好的"。像一个英语听力测试，每听完一句就跟一个"OK"。吃到一半，他把凉拌木耳里最后一片木耳夹给了她。她说了谢谢。然后他擦了擦嘴，说了一句话。

"我觉得你挺好的。真的。就是你家是苏北的。我妈有点介意。她说苏北人不太讲究。但我不在乎。不过你有个弟弟。你弟弟以后结婚，你是不是得帮？"

陈知意把小馄饨碗里的调羹拿出来放在碗沿上。调羹磕了一下碗边，很轻的一声。像那天唐姐的纸箱碰电梯门框。"我弟弟的事。"她停了一下。"我自己还没想好。"

下午两点半。三号。离异男。约在中山公园的一家满记甜品。他三十二岁，前妻嫌他太老实。穿一件灰色的Polo衫，领子有点变形了。坐下来以后没有问她的学历和工作，只问了一句话。"你是自愿来相亲的，还是被家里逼的？"

陈知意被这个问题噎了一下。不是不能回答。是没有人问过这个。一号没问，二号没问，三号是第一个问这个的人。"都有。"

他笑了笑。很浅，嘴角只翘了一点点。"我也是。被我妈逼的。"然后他把菜单推给她。"你点。我什么都行。"她点了一份杨枝甘露。他点了一碗芝麻糊。两个人坐了一个小时。聊了电影，聊了上海哪些地方值得周末去逛一逛，聊了他前妻养的猫归谁了。没有聊房子，没有聊户口，没有聊弟弟。临走的时候他加了她微信。备注了：陈知意。

回去的地铁上。她把三个人的微信排成一排。一号的备注是"陈知意/字节P6/南大"。他把她的信息填进了自己的Excel表里，工整，干净。二号的备注是"陈小姐/168平行线/弟弟未决"。三号的备注是"陈知意"。只有名字。

她把三个人的备注改了。一号。二号。三号。

地铁从中山公园往中环方向开。她靠在地铁门的玻璃上，掏出手机刷了一下朋友圈。没有任何更新。打开了小红书。搜索框里空着。主页推荐了一条："嫁人是女人第二次投胎，选对了后半生躺平。"她点了不感兴趣。刷新。第二条："三十岁还不结婚你在等什么？高质量男性剩不下的。"又点了不感兴趣。刷新。第三条："女人过了三十五生育价值归零，你有多少资本可以挥霍？"把手机锁屏了。屏幕黑掉，映出她自己的脸。二十九岁。马上就要三十了。

地铁里报站。下一站，金沙江路。她把手机翻过来，屏幕朝下。和昨天在工位上一样。钢化膜碎的那个角硌了一下她的大腿。然后打开微信，把母亲今天发的第四条语音听了一下。

六十秒。"知意啊你今天见了三个怎么样啊有没有合适的你爸昨天晚上还说你眼光别太高了你自己也不小了再过两年别人就该挑你了不是让你挑了。"

她打了一行字。删了。又打了一行。又删了。最后回了一句话，九个字。"见完了。都挺好的。放心。"发出去。微信提示对方正在输入中。她关掉了对话窗口。

地铁在隧道里钻了一段。信号断了，她的手机屏幕上转了两圈。正在连接中。等信号恢复的时候，小红书主页已经自动刷新了。第四条推送弹出来："女人过了三十五生育价值归零。你有多少资本可以挥霍？"第五条："为什么上海土著不要外地女？有理有据。"她没有点。拇指悬在屏幕上方，悬了好几秒。然后按下电源键。锁屏。屏幕黑了，映出她自己的脸。二十九岁，坐在开往中环方向的地铁上，膝盖并拢，一只手握着手机，另一只手握着包带。包是两年前在网易严选打折时买的，表面的PU已经开始掉了，露出底下一层灰色的布。她低头看了一眼那个掉皮的位置。没有换。不是买不起。是每次想换包的时候都会想起下个月的房租。换一个包是三百块。三百块够交半个月的地铁费。够买两个月的护肝片。够在这座城市再撑七天。

地铁到站。金沙江路。她站起来，走到门口。车门玻璃上映着她的影子。一个穿深蓝色风衣的女生，头发扎了一个低马尾，橡皮筋是黑色的，没有花。她对着玻璃看了一眼。眼角的细纹在车门的白色灯光下比平时明显。不是新的。以前就有。只是平时不在这盏灯下面看。

下车。刷卡。闸机发出很短的滴声。走出站台的时候她打开微信。母亲的消息又来了。第五条。这次不是语音，是文字。母亲很少打字，打字很慢，但她打了。"你爸让我问你。"只有六个字。后面跟了三个表情。笑脸。玫瑰。大拇指。

陈知意站在地铁出口的台阶上，看了那条消息很久。站了一个台阶，把手机屏幕亮度调低了一点。然后回了一条。"等我回去再说。地铁上。"关掉对话。把手机放进包里，拉上拉链。台阶外面是晚上的上海。路灯已经亮了。地铁口的共享单车排了一排，黄的和蓝的混在一起。她扫了一眼，没有骑。走回出租屋。这一段路十五分钟。以前她会骑。今天不想骑。想走慢一点。这一小段路是她今天唯一一段不需要回答任何问题的路。
