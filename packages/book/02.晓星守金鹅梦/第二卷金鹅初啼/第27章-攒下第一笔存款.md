# 第27章 攒下第一笔存款

一千块在大人眼里不算什么。但如果你知道它是用多少个下午换来的——它就是一座山。

——金鹅

十二月的第一个周六。天已经很冷了。废品站的卷帘门冻得发涩，张叔往上推的时候铁皮发出一种很刺耳的吱嘎声，像有人在用指甲刮玻璃。门推到一半卡住了，他拍了两下轨道才升上去。空气是干的。冷。手指从手套里伸出来不到一分钟就僵了。分铝罐的时候指尖捏不住罐壁，总是从指缝滑下去。叮——声音比秋天的时候更脆。冷空气把金属震得比平时更响。

今天干完以后，张叔给了我二十五块。他数钱的时候哈了一口气在手指上，纸币被那口白汽扑了一下又干掉了。我把钱接过来。二十五块。加上上个月最后那十块奖金，加上之前攒的，加上送孩子和辅导小媛这两个月的工钱——我在心里把所有零散的进账加了一遍。大概接近一个整数了。

收工以后没直接回家。绕到社区银行。下午四点半，银行的大厅已经没什么人了。暖气很足，玻璃门上起了一层雾。我推门进去的时候，雾被推开一个手的形状。大理石地板映着头顶的日光灯管——白的光，白的地，白的柜台。柜员还是上次那个阿姨。她看到我，笑了一下。不是那种"又来了"的无奈，是已经习惯了。"今天存多少。""五十。"

她把钱接过去。纸币是三张——一张二十的，一张二十的，一张十块。硬币还有一小把，五角的，一块的，加起来大概六块多。柜员数硬币的时候把它们排在柜台上——三排。每排五个。最后一个少了一个。她数了两遍，然后在键盘上敲了一下。打印机响了——吱吱吱，很细的针打声。然后她把存折递回来。

我翻开存折。蓝色的封面翻开之后，第一页就是存款记录。一列日期，一列金额，一列利息。从最上面往下数——八月三十号，二十块。九月七号，十五块。九月十四号，十八块。一笔一笔往下排，每一笔的数字都不大。最多的从来没超过五十。整整四个月，存了一百多笔。我把手指压在最下面那行数字上——从右边的利息列往左推，推到存款余额那一列。四位数字。

1000.00。

不是1000加小数点。是1000整。后面那两个零在存折上是空的。但前面那个"1"和三个"0"连在一起的时候，有一种不太真实的感觉。我盯着看了很久。久到柜员阿姨问了一句"还有别的业务吗"。我说没有了。拿起存折把铁皮糖盒放进书包，转身往外走。走到门口推门出去，冷空气一下子灌进来。门在身后合上的时候发出一声气压闷响。走出去三步，然后蹲下去了。

不是坐在银行门口的台阶上——是蹲。膝盖弯到胸前，存折攥在手里，趴在膝盖上。不是高兴得哭了，不是激动。是一种被压了很久之后突然松开的感觉。四十五个下午。六十多趟接孩子。二十四个晚上辅导小媛。手套磨破了三副。那个欠了三十五块跑掉的人教会了我收定金。那个说"铁公鸡"的人还在走廊上用眼睛看我鞋。那个说"随便你"的人前天在食堂和我隔了一张桌子，谁也不看谁。所有这些下午、傍晚、天黑之后走回家的路——叠在一起，变成存折上一个四位数字。不是钱多。因为这些钱是捡来的。一个字一个字地捡，一个罐子一个罐子地捡，从废品站的灰里面、从接孩子的放学路上、从辅导作业的铅笔屑里捡回来的。我不知道自己蹲了多久。膝盖开始疼的时候手指还是攥着存折。封面被手心的汗洇湿了一小块——蓝色烫金字下面多了一个很浅的手掌印。

有人走过来。脚步声很轻，皮鞋底在大理石地面上发出不紧不慢的节奏。我在膝盖缝里看到一双黑布鞋——洗得发白的黑，鞋边磨出了一圈灰。然后是中山装的裤腿。深蓝色。"小姑娘。站起来。外面冷。"

陈爷爷。深灰色的厚棉袄外面套着那件永远不变的中山装。棉袄袖口磨破了，露出里面一小团棉花。手里还是那个保温杯，盖子拧着的，热气从杯盖缝里往外冒。他低头看我。没问"怎么了"。他在银行待了四十年，知道一个蹲在门口攥着存折的人不需要被问"怎么了"。他需要的是有人站在旁边，等她自己站起来。

我站起来。膝盖咔嗒响了一声。把存折翻到他面前。手指点在最下面那个数字上。1000.00。他看了一眼。摘下老花镜。用袖口擦了一下镜片。又戴上。再看一眼。然后笑了。不是客气的那种——"我就知道"的。"一千整。"这三个字不是对着存折说的，是对着我说的。像在念一个早就写好的评语。

他把我领进银行大厅。暖气把眼镜片又糊了一层雾，他又摘下来擦了一遍。大厅快下班了，保安在收警戒线，柜员在关电脑。陈爷爷找到一个角落的椅子让我坐下。他自己坐在旁边。保温杯搁在椅子扶手的浅槽里，刚好卡住。"什么时候开始存的。""八月底。""第一个二十块。""嗯。""你存了一百多次。"他不用看存折就知道。刚才在银行的玻璃窗外面，他已经看到我翻开存折盯着最后那行数字。他什么都没说，但他记住了第一笔记录的日期。

他把保温杯端起来喝了一口。放下。杯底咔嗒一声落在扶手的塑料槽里。然后他站起来，走到银行柜台那边。柜员还没走，在整理今天最后一批单据。陈爷爷和柜员说了一句话，声音太低，我听不见。柜员点点头，看了我一眼。然后陈爷爷从兜里掏出一个信封——牛皮纸的，边角磨得发毛，封口用一根红线绕了两圈。柜员接过去，在键盘上敲了几下。打印机又响了。

他走回来，坐下。没有说话。只是把手里的保温杯转了半圈——杯盖对着我。大概过了两分钟。柜员喊了一声"陈老师，好了"。他站起来走到柜台，拿了一张回执条，然后走回来。把回执条递给我。上面写了一行备注——"优秀学员奖学金"。金额——100.00。

我抬头看他。他摆了摆手。"不是我给你的。是你自己挣的。我只是帮你把该得的利息提前付了一点。"他把回执条折起来，塞进我的铁皮糖盒里，和存折放在一起。"你在银行存钱。我也在银行存东西——我存的是信任。你是我今年利息最高的一笔。"

我攥着铁皮糖盒。存折的边角和回执条的边角在盒子里碰了一下，很轻的纸摩擦声。想说谢谢。喉咙里堵住了。不是不想说——那一秒想起了很多事。废品站分铝罐的黄昏，张叔把食指按在我胸口说"你是好料"。奶奶把缺耳朵的小猪放进我手里说"现在轮到你存了"。第一次走进这家银行——手里只有二十块，声音小得像蚊子叫。不敢看柜员的脸。现在柜员认得我了。不需要报账号。她会对我笑。陈爷爷站起来。走到门口。推门之前回过头。"下次来存钱，把这个本子也带来。"他指了指我书包里的成功日记。"要检查。"

我坐在银行大厅的椅子上又坐了大概五分钟。大厅里的灯被保安关了一半——这边亮，那边暗。日光灯管灭掉的那半边，大理石地板变成了一种很沉的黑灰色。亮着的那半边，地板上映着我自己模糊的影子。把铁皮糖盒抱在怀里，走出银行。外面天已经全黑了。路灯亮着，橘黄色的光打在路边的枯树上，树枝的影子在人行道上分成很多很细的叉。冷风吹过来的时候嘴唇发干。但胸口是热的。不是体温。是那种"我终于做到了"的温度。

回到家。我妈在厨房切菜，我爸还没下班。我走进房间，把书包放下。第一件事——从枕头底下拿出成功日记。蓝色封面。歪着头的鹅。从第一页开始翻。第一条——"打开了成功日记的本子。"一页一页往后翻。每一页都写满了——至少五条，有些天写了六条。翻到最后一页的时候发现已经没有空白行了。最后一页写满的那天刚好是上周五。第一条是"今天放学雨很大，但还是去接了杨杨。鞋子全湿了。但杨杨在门口等我，手里举着伞。"第五条是"翻到两个月前写的第一条——'靠自己劳动赚到了人生第一笔钱'。两个月了。比那时候存多了很多。也比那时候安心了很多。"

整本写满了。从第一页到最后一页。像一册很薄的砖。

我把这本日记合上。手指在封面上摸了一下——蓝色封面上那只用水彩笔画的小鹅，鹅的脖子被这两个多月的翻阅磨淡了半截，边缘有点发毛。但还在。我把第一本成功日记放在书桌上。

拉开抽屉，拿出一本新的旧笔记本——蓝色封面，比第一本大一圈。从笔筒里抽出金色水彩笔。在封面上画了一只鹅。比第一只大。翅膀张开了一小半，脖子往右上方伸——不是歪着头了，是抬着的。画完用黑色水彩笔点了个眼睛。眼睛比第一只圆，瞳仁里留了两粒白点。一粒是光，一粒是已经走过的这一百多次存钱。

翻开扉页。在第一行写下了"1000元。"然后换行。笔停下来。看了一眼窗外。对面楼的窗户今天全亮着。每一扇。然后低头继续写。"如果平均每十块钱代表一次弯腰捡废品的话，我已经弯了一百次腰。"再换行。最后一句话用金色水彩笔写的。笔尖压在纸上比蓝色重，渗进纸纤维里，字的边缘有一点很细的洇。然后写下最后一行。

"但我的脊梁比任何时候都直。"

我把第一本成功日记和新日记并排放在书桌上。左边是小鹅——脖子是歪的，眼睛里只有一粒白点。是第一天的我。右边是大鹅——脖子抬起来了，眼睛里有光，是今天的我。两只鹅中间隔着铁皮糖盒。盒子里是存折。存折上是陈爷爷的回执条。回执条上的"优秀学员奖学金"在糖盒的阴影底下看不清楚，但我知道它在那里。

和第一本日记最后一页夹着的那张十块钱一样——不需要看见。它们都是记号。张叔手套上的灰留下的。陈爷爷红线绳绕的。都是别人用手递给我的。但站直的这个人，是我自己用一百次弯腰换来的。

我把灯关了。月光从窗帘缝里漏进来，照在两只鹅的封面上。一只歪着头。一只抬着头。中间的铁皮糖盒安安静静。小猪储蓄罐在盒子旁边，缺掉的耳朵挨着存折。它们都在等我写满第二本。
