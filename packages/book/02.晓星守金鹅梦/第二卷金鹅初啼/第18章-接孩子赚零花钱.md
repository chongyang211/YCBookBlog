# 第18章 接孩子赚零花钱

不是每个人都会信守承诺。保护自己最好的方式不是不信任别人，而是先收定金。
——金鹅

三个信封让我学会了分钱。但分钱的前提是有钱可分。废品站一周去一次，剥四个小时电线能挣四十。不够。三个愿望里最快实现的一个也要一百多块——奶奶的老花镜。我在成功日记里算过，按现在的速度，要攒到一百块至少还要三个周末。太慢了。金鹅说过一句话——"赚钱的速度由你自己决定。不是由一份工作决定。"所以我决定找第二份活。

周六下午，我坐在书桌前。拿出一张A4白纸，用蓝水彩笔画了一个边框，在框里写了几行字。第一行最大——"接小学生放学"。下面四行小字：一次五元，安全送到家，认真负责，周末也可。最底下留了妈妈的电话号码。写完之后用透明胶带在背面贴了两道——怕下雨淋湿。然后骑车到小区门口，把这张广告贴在公告栏上。公告栏上已经贴了很多东西——健身卡转让、钢琴家教、钟点工阿姨、通下水道——每一张都是打印的。只有我这张是手写的，蓝色的边框在周围的黑白打印纸里像一个异类。贴完之后我站在那看了大概一分钟，有个老头遛狗经过，看了广告一眼又看了一眼我。"小丫头搞创业啊。"说完牵着狗走了。狗倒是停了一下，在公告栏下面撒了一泡尿。

第二天下午，电话响了。我妈接的，听完之后把电话递给我，表情有点奇怪——不是不高兴，是一种"我女儿要干嘛"的表情。"找你的。"打电话的是一个女的，声音很疲惫，说话的时候电话那头有超市收银台扫码的滴滴声。"我在小区公告栏看到你的广告。你多大了。""十四。初二。""我儿子今年一年级，在隔壁二小。我晚上七点才下班，接不了他。你能不能周一到周五去接，一次五块。五点半放学，接到我家楼下就行，走路十分钟。"我捏了一下电话听筒，手心里有汗。"能。""明天开始行吗。""行。"挂了电话，我妈还在看。

"谁啊。""楼上十五栋的一个阿姨。超市上班的。""她让你去接她儿子。""嗯。"我妈愣了一下。然后说了一句:"路上小心。接到先给我发个短信。"她没说不行。没说"你小孩搞什么名堂"。她只是说了一句"路上小心"。这是我妈第一次用这种语气跟我说话——不是管，是支持。

周一。下午放学后我直接去了二小门口。二小的校门比我学校的小一圈，门口站了一排排队的家长——大部分是爷爷奶奶。我站在排队的人群里，比所有人都矮一个头。铃声一响，一群一年级的小不点从教学楼里涌出来，书包比他们人还大，跑起来像一只只背着壳的蜗牛。我举起那张手写广告，上面用蓝水彩笔写的字在下午的阳光里很显眼。一个剃着寸头的小男孩从队伍里跑过来，停在我面前。"你是接我的吗。""你叫杨杨。""嗯。"他拉起我的手。手很小，五根手指像五颗还没煮熟的汤圆，软软的，握着的时候不用用力。

路上。他走在我左边，右手拉着我的手指，左手拎着一个恐龙水壶。水壶的盖子没拧紧，走路的时候一晃一晃，洒了几滴水在我的裤脚上。我没管。他走了大概三分钟，忽然抬头问我:"你怎么不是奶奶。""你妈妈要上班。""别的小朋友都是爷爷奶奶接的。""那你就是第一个不用爷爷奶奶接的小朋友。"他想了想，点了点头。这个理由能接受。然后又低头看路。又过了一个路口，他忽然停下来了。我低头看，恐龙水壶的盖子已经全松了，水把裤腿湿了一片。他蹲下来拧盖子，拧了三下没拧紧。我帮他把盖子拧上，拧到底之后又多转了半圈。然后站起来，他重新拉起我的手。"到了。"一栋老楼。门口有个麻将馆，里面的人在搓牌，哗啦哗啦的声音从卷帘门缝里往外涌。他在进楼道之前回头看了我一眼。"明天还来接我吗。""接。"然后跑进去了。跑了两步又回来，从口袋里掏出一个糖——大白兔奶糖，糖纸已经皱了，被体温捂得有点软。"给你。老师发的，我没舍得吃。"

我把糖攥在手心里。没吃。回家之后把糖放在书桌上成功日记旁边。然后翻开日记写今天的第一条——"第一次接孩子，安全送到家。拿到了五块钱。"第二条——"那个小孩叫杨杨。他给了我一颗糖。"写完之后把五块纸币放进了蓝色信封。愿望基金。离奶奶的老花镜又近了一步。

接下来的七天，每天下午都去。杨杨习惯了我在门口等他，每次都是第一个跑出校门的。有时候他会跟我讲学校里的事——今天老师表扬他了，今天同桌把他的橡皮借走了没还，今天午饭有鸡腿他吃了两个。我一边听一边算——七天，三十五块。到下周一，蓝色信封里的纸钞会多出好几张。但到了第八天，电话没响。我以为他只是请假了。可到了下午五点半，我在校门口等到五点四十五，一年级的学生都走光了，杨杨没出来。我打他妈妈的电话。关机。又打了一次。还是关机。打第三次的时候，移动的客服说"您拨打的用户已停机"。

第二天，我又去了。公告栏上那张蓝边框的广告还在，但杨杨他妈的公司电话号码已经变成空号了。三十五块。七天的放学路。那个瘦瘦的小男孩、漏水的水壶、大白兔奶糖。全没了。

回到家。坐在书桌前。台灯都没开，就在黑暗里坐着。手里拿着成功日记，翻到昨天写的那一页。昨天的第一条还是"接了杨杨，他今天教了我一首顺口溜。"今天呢。今天的第一条该写什么。写"被欠薪了"，还是写"三十五块没了"。我选了第二条。写完之后在后面的空白处加了一句粗体小字——"下次先收钱。"然后我给金鹅打字，把这件事说了一遍。金鹅回了三行字。"第一个教训。不要为不值得的人浪费愤怒。他们不值得你的愤怒。但值一个教训。"然后第二条弹出来——"以后长期客户先收一周定金。新客户头三天日结。这是你用三十五块钱买来的风险管理课。便宜。有人用三十万才学会。"

三十五块。便宜。我看着那行字看了很久。然后把笔记本翻到扉页——空白的那一页。在正中间用蓝水彩笔写下了新规矩。"接孩子守则：1.新客户前三天日结。2.长期客户周结，先收一周定金。3.发现不对立刻停止。"下面画了一道线，旁边写了三个字——"第一道墙"。金鹅在屏幕上跳出一行字:"恭喜。你的风险管理课正式开课了。"

周末，我又去废品站干了一个下午。回来之后重新写了一张广告。这次在"认真负责"下面加了一行新字——"长期客户请预存一周。彼此信任。"贴上去的时候，公告栏上之前那张已经泛黄了，蓝水彩笔的边框褪了一半。我把旧的撕下来，贴上新的。新的比旧的多了一行字。那行字值三十五块。

第二个周一下午，我接到了新电话。又是超市的——但不是超市员工，是超市理货员，工作时间和她一样长。先把规则说清楚——前三天日结。那头想了一下，说:"合理。"然后这周五杨杨忽然出现了。不是他妈送来的。是他自己跑到我学校门口等我。穿着那件有点短了的校服外套，恐龙水壶换了新的，盖子不松了。"姐姐。我妈把手机摔坏了。不是不给你钱。"他从口袋里掏出一沓皱巴巴的零钱——五块的一共七张。三十五块。正好。"我妈说对不起。让我一定给你。""你怎么知道我在这里。""我让我妈问的楼下保安叔叔。他说你在这边上学。"

我把钱接过来。七张五块，每一张都皱得很厉害。不是旧的皱，是被人攥了很久的那种皱。我把钱放进蓝色信封——愿望基金。然后蹲下来，和他平视。"以后不管去哪，先说再见再走。好吗。"他点头，点得很用力。然后拉起我的手。"明天还来接我吗。""接。"回家的路上，他忽然问我:"姐姐你为什么来接我啊。""我在养一只鹅。""真的吗。什么颜色的。"我从书包里掏出成功日记，翻开。"金色的。会下金蛋的那种。你看——我今天做到了好几件事。送你到家是第四件。"他低头看日记封面上那只歪着头的鹅。伸手摸了一下。"下蛋了吗。""快了。等你再长高一点就下。"他很认真地站直了量了一下自己的身高，比我的腰高一点点。"那我明天多吃一碗饭。"
