# 第21章 第一次激烈争吵

愤怒只能表达情绪，不能解决问题。下一次，带着证据去说话。
——金鹅

双十一后的第三天。客厅还是走不了人。快递盒从墙角长出来，往沙发和电视柜的方向蔓延，已经快挨到茶几的腿了。我早上起来做的第一件事不是刷牙，是把投资合同从快递盒底层抽出来，放在茶几正中间。然后打开手机相册——昨天拍的快递盒子，三十七件，横着拍了五张才拍全。两样证据。一张纸，一堆盒子。左边是合同，右边是照片。

我妈从卧室出来，头发还没梳。第一眼看到的是合同，然后是我的手机屏幕。"你翻我东西了。"不是问句。"爸那份合同压在最下面。你们花了多少钱，我都数过了。"她的表情在几秒内变了好几个层次——先看到合同，没反应过来；然后看到手机上的数字，反应过来；最后抬头看我。不是生气。是被一个小孩子翻看了底牌的慌乱。手里还捏着梳子，梳子上的头发没摘，就那么捏着。

我爸从厨房出来，手里端着刚煮好的泡面。看到茶几上的合同，筷子停在半空。面条滑下去了几根，掉在地上，他没有捡。"你拿我合同干什么。""爸。金鹅查过这家公司了。注册三个月，注册资本五十万，不是央企，合同上的公司名和宣传单上不一样。你被骗了。"我把平板上金鹅的分析结果打开，放在合同旁边——四行字，每一行都是他签合同之前应该看到但没有看到的东西。他的脸先是白的，然后变红——不是羞愧的红，是被晚辈当面指出错误的恼怒。

他一把把平板翻过去，屏幕朝下扣在茶几上。"你小孩子懂什么投资。我吃的盐比你吃的米都多。"手一挥，茶几边上一个玻璃杯被袖子带倒了。杯子掉在地上，碎成三瓣。水洒了一地。没有人捡。

我妈听到"被骗了"三个字，猛地转过头来。眼睛里有一种东西在碎开。但她没有看合同，她看的是我。"你天天记这种东西，是要查你妈的账吗。"她走到我书桌前，从桌上抓起我的记账本——深蓝色封面，从第一页记到现在，每一笔钱的来源和去向都写得清清楚楚。她用力一扯，记账本从中间裂开了。几页纸在空中翻了一下，飘到地上。"你记来记去管什么用。记了钱就能回来吗。"

我蹲下去捡那些纸。被撕掉的那几页正好是最早的记录——那个周末第一次去废品站赚了二十块，第一次接杨杨拿到了五块，第一次把收入分成三份——金色、蓝色、白色。还有那页"给爸爸的投资建议"。写了一个星期才写满整页的十条建议，每一条都是从金鹅和陈爷爷那里学来的。现在裂成两半。"投资防骗十条"的前五个字在左半张纸上，"十条"的下面是右半张——中间是一道从左上到右下的斜裂口。不是因为用力太猛，是纸本身已经被翻过太多次了。折痕的地方最容易裂。

我把纸片一片一片捡起来，放在书桌上。手心还因为刚才攥合同攥得太紧，指甲掐出了一道弧形印子。胶带在抽屉里——那次缠书包剩下的，放了大半个学期，胶带边缘有点发黄了，但还能粘。

我把裂开的纸拼在一起，用胶带从背面一段一段贴上。动作很轻，怕胶带把字粘花了。第一道。第二道。第三道——正好贴在"查工商注册"那一条的背面。贴到第五条的时候，眼泪滴在了胶带上。不是因为疼。是因为这十条建议写了两个晚上，字迹工工整整，每一条前面都用蓝色水彩笔画了一个小圆点。现在那些圆点被撕成了半个月亮。拼起来还是圆的，但中间有一道永远消不掉的缝。"投资防骗十条"下面那条横线，被撕成了两根线。中间差了不到一毫米。永远对不齐了。

客厅里安静了三秒。我站起来，粘好的记账本捏在手里。那页"给爸爸的投资建议"像一道缝合过的疤。

"我不是要管你们。我是不想看着我们家完蛋。"

声音从嗓子里出来的时候带着一种很陌生的音调。不像我的。像一个在深处憋了很久的东西终于浮上来了。我爸愣住了。他以前每次被我说中要害的时候都会说"小孩懂什么"，这次没有。因为已经说不出口了。他刚才把杯子摔碎的时候还有底气，现在看着地上那摊水和碎玻璃，底气也跟着碎了。碎玻璃映着窗外的光，一小块一小块的，每一块上面都有一点影子——他的影子。碎成了三块。

"我们家好不好是我和你妈的事。你上好你的学就行。"他的声音比之前低了一格。但这句比之前任何一句都伤人。不是否定我的判断。是把我彻底划在了外面。像一个团队里有一个名额，但名额上写的不是我的名字。这堵墙比任何吼叫都厚——不是把我推到墙角，是把墙角往前移了一步，把整个家隔成了两个房间。我妈站在他旁边，没有说一句话。她的眼神在快递盒和那页被粘好的"投资防骗十条"之间来回了两次。嘴唇动了一下，但没有声音。她在犹豫。犹豫到最后，选了沉默。

我转身走回房间。关门。门板合上之后，客厅里再也没有声音了。我蹲在地上，把成功日记从枕头底下拿出来。翻到第一页——"1.我决定不再假装看不见。2.我开了这个本子。3.我写了第一行字。"一条一条往下翻。第五页——"靠自己劳动赚到了第一笔钱。"第七页——"学会了写成功日记。"第十页——"忍住了没有跟同学吵架。"昨天的那一页——"忍住了没有当场把合同摔在他面前。"几十条。从第一行到现在，每一个字都是我不放弃的证据。我把日记贴在胸口，背靠着门滑坐下去。不是因为钱多。是因为这些字是我捡来的。一个字一个字，从废品站的灰里面、从接孩子的放学路上、从辅导作业的铅笔屑里，捡回来的。没有人能从我这把这些字撕下来。

深夜。平板开着，金鹅的屏幕亮着。"今天很伤心吧。"我点了点头。它没有说"别哭了"。没有说"会好起来的。"它打了一行字，字间距和那天说"救生艇"的时候一样大。"伤心是好事。说明你还在乎。但记住——愤怒只能表达情绪，不能解决问题。下一次，带着证据去说话，而不是带着情绪去吵架。"它顿了一下，然后打出第二行。"你的成功日记还在。你每一个没放弃的日子，都是今天这场架的证据。"

我把粘好的记账本和成功日记并排放在枕头下面。一本是被撕破又粘好的过去，一本是没人能撕掉的现在。枕芯很软，两本笔记本的重量压在上面几乎感觉不到。但合在一起的时候，比任何东西都重。

第二天早上。客厅里的碎玻璃已经被扫掉了，留下一小块水渍还没干。茶几上的投资合同不见了。妈妈的书桌上多了一卷新的透明胶带。不是我那卷，是新的。没有字条，没有道歉。只有一卷胶带。她把扯破的记账本旁边放了一卷未开封的胶带——这就是她表达"对不起"的方式。我没有问合同去哪了。因为答案不在他藏合同的动作里。答案在那页被粘好的"投资防骗十条"里。虽然那条横线永远对不齐了。但字还在。字在，我就还有证据。今天放学后去找陈爷爷。把胶带和记账本都带去。他会教我怎么用这些证据。
