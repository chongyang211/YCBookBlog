# 第41章 压垮家庭的稻草

"人总是在最坏的事情上再加一件，才会承认自己撑不住了。不是第二件有多重。是第一件已经把骨头压满了裂纹。第二件只是让它断了。"

——金鹅

从医院回来的那天晚上，茶几上堆满了纸。

不是快递单。不是宣传单。是账单。信用卡账单、网贷还款通知、房贷催缴单、水电费欠费单、物业费催收函。还有一张奶奶的住院费用预估单——入院押金三万，总费用五到八万。所有纸加在一起不到半斤重。但林建国把它们摆在茶几上的时候，茶几往下沉了一下。不是真的沉了。是弹簧本来就有问题。但晓星觉得它沉了。

林建国坐在沙发上。面前摊着一张白纸。从晓星记账本上撕下来的，背面还有她用蓝色彩铅画的进度条——那条从零到百分之一点几的细线，画了一半就停下了。他把纸翻过来，在空白那面写。笔是一支圆珠笔，笔芯用到最后那截，出水不顺畅，每写一个字要顿一下。

信用卡。八万。网贷。五万。二哥。五万。大姐。八千。物业水电。三千六。奶奶手术押金。三万。他一行一行写下去。每个数字旁边都标注了来源和日期。写得工工整整。像一个会计在做年终结算。但他不是会计。他是那个欠钱的人。

写完最后一行，他把笔放下。从上到下又看了一遍。然后把这些年的投资亏损也加上去了。充电桩十万。虚拟币三万。保健品加盟两万。共享经济一万五。

他在纸的下方画了一道横线，下面写了一个总数。笔尖在纸上顿了三下才写出那个数字。三十一万六千四百元。他盯着那个数字看了很久。然后说了一句话。声音不响。但客厅里太安静了，那句话说出口的时候像一颗石子扔进了一口枯井。能听见石子落地的声音，但听不到水花。

"我明天去办离婚吧。"

王秀兰坐在沙发另一头。腿上摊着一件晓星的校服，袖口脱线了，她正在缝。听到这句话的时候针没有停。缝了一针。又缝了一针。第三针的时候针尖扎进了指头肚。她把手指拿到眼前看了一眼，一颗血珠从指纹的纹路里渗出来，慢慢变大。她把手指放在嘴里含了一下。把校服放在旁边。

"房子卖了还债。我带我妈回老家。你和晓星过。"林建国说。每个字之间隔的时间一样长。不长不短。不是平静。是连"激动"这件事都做不到了。

王秀兰拿起茶几上那张纸。从头到尾看了一遍。每个数字都看了。看到"充电桩 十万"的时候眼睛停了一下。又继续往下看。看到最后那个总数——三十一万六千四百元——她没有哭。只是把纸翻过去。空白面朝上。

她不想看到自己也是这串数字里的一部分。那些数字里有多少是她买回来的——被剪掉打折标签的带鱼、堆在墙角没有再长高的快递盒、退掉的封闭训练营一万八、还有手机里敲了又删敲了又删的"收到[鲜花]"。她算不清。她从来没算过。以前不算是因为不敢算。现在不算是因为算不过来了。

她把那张纸空白面朝上放在茶几上。拿起了针。继续缝校服袖子。缝了大概七八针。线和线之间的距离很均匀，每一针都一样长。她以前缝东西没有这么整齐。现在手上的力气小了，拉线的时候不敢使劲，怕把线扯断。线断了还得重新穿针。穿针这种事情她以前不觉得有什么难的。现在觉得每一件小事都有可能成为压断她的最后一根稻草，所以每一件小事都做得格外小心。她缝完最后一针，打了个结，用牙把线咬断。把校服叠好放在沙发扶手上。然后说了句话。

"算了一辈子账。到头来把自己算没了。"

她说的是"自己"。不是"你"。不是"他"。是"自己"。

晓星站在房间门口。门开了一条缝。这些话她都听到了。每一个字。从"离婚"到"卖房"到"回老家"到"三十一万六千四百元"到"把自己算没了"。她站在门后面，手按在门板上。门板是复合板的，很薄，父母声音从客厅传过来的时候门板会微微震动。震动的频率和他们的声音高度一致。

她没有推门出去。她转过身。走回书桌前。坐了下来。

书桌上摊着她的东西。铁皮糖盒。记账本。金鹅存折。平板在枕头底下，没电。她把糖盒打开。存折上有一行数字。前段时间重新攒的，每一个数字都是一笔一笔存进去的。她把存折翻开。最新一页。金鹅账户：两千三百元。她把存折放在一边。打开记账本，翻到愿望基金那一页。八百元。

她用笔在这两个数字下面各画了一条下划线。然后把它们加在一起。三千一百元。比奶奶的入院押金还差两万六千九百元。比那个三十一万六千四百元——她停住了。没有往下算。不是算不出来。是不想算。

她把记账本翻到空白一页。拿起蓝色水彩笔。这支笔削了很多次了，现在只有小拇指的一半长。笔杆上有一道她以前无聊时用指甲掐出来的凹痕。她握着那支笔，在纸上写。字写得很慢。一笔一画。撇是撇，捺是捺。每一个字都用了写毛笔字的力气。

"这是我全部的力量。"

换行。

"虽然很少。"

换行。

"但这是全部。"

她放下笔。把那一页撕下来，对折了一次，夹进存折里。存折的蓝色封面合上以后，折进去的那页纸露出一个角。白色的。在蓝色封面中间像一面很小的旗。

客厅里安静了很久。林建国坐在沙发上，面前是那张背面朝上的纸。王秀兰继续缝另一只袖子。晓星房间的台灯还亮着。窗外的雪停了。积雪把路灯的光反射上来，整间屋子比平时亮了一点。蓝莹莹的光从窗帘缝隙漏进来，照在茶几上那沓账单上。账单最上面是信用卡还款通知单。红色加粗的数字。晓星房间的门缝还开着。但她没有再去听客厅里的声音。她把记账本合上。把糖盒盖上。把存折放进糖盒里。糖盒的铁皮有点凉。她在糖盒盖子上看到自己的倒影。那张脸被铁皮的弧度拉得有点变形。下巴比平时尖了一点。

和今天在医院缴费窗口屏幕上看到的那张脸一样。
