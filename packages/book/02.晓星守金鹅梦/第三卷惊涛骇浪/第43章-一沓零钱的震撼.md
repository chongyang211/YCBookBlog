# 第43章 一沓零钱的震撼

"钱不会说话。但一堆零钱放在一起的时候，比任何一张支票都响。"

——金鹅

中午。晓星一个人去了银行。铁皮糖盒揣在棉袄内侧的口袋里，走路的时候糖盒的角硌着肋骨，每走一步就硌一下。

银行大厅里没什么人。年后的第一个工作日，大理石地板上映着日光灯的长条形倒影。她走到柜台前面，踮起脚，把存折推进凹槽。

柜员是个戴眼镜的中年男人，看了她一眼。一个小女孩，一个人来取钱，取的是全部。他把存折接过去，在键盘上敲了几下。屏幕上的数字跳了几下，然后问了一句——"全取？"晓星点了点头。

柜员没有多问。他把钱从抽屉里取出来，一张一张点。一百的。一百的。还是一百的。点了三十一张。然后剩下的就不是一百的了。几张五十，几张二十，几张十块，几张五块。最后是一堆硬币。一元的。五角的。他把纸币码齐，硬币装在一个小塑料袋里。所有东西一起从凹槽里推出来。晓星接过来。三十一张一百的——三千一百元。和她在记账本上算的一模一样。

她没有马上走。在柜台旁边的填单台上把钱重新数了一遍。一百的叠成一摞放在左边，五十的叠成一小摞放在中间，十块五块的放在右边。硬币从小塑料袋里倒出来，在填单台的木桌面上滚了两下，一枚五角硬币滚到桌子边缘，她用掌心按住了。然后从口袋里掏出那根老化的橡皮筋。奶奶的橡皮筋。上面全是裂纹，但还能用。她先把纸币卷成一卷，用橡皮筋扎紧。然后把硬币装回塑料袋里。纸币和硬币放进铁皮糖盒。和存折放在一起。存折上那行"零存整取·第七笔"还在，但数字已经归零了。

糖盒的盖子扣上。咔嗒。和今天早上一样的声音。

下午。她去了医院。上了三楼骨科病房。走廊里还是那股味道——消毒水混着午饭的菜味。日光灯还是白得发青。推床轮子的吱嘎声还在响。一切和昨天一样，除了她怀里那个铁皮糖盒更重了。不是重量。是里面的东西换了。

奶奶的病房在三楼走廊尽头。门口挂着一块塑料牌，上面写着"张桂兰"——那是奶奶的名字。她以前从来没注意过奶奶叫什么。她只知道叫奶奶。

推开门。病房里有三张床。奶奶躺在最里面靠窗那张。窗帘拉开了一半，太阳刚好照在床尾的被子上。奶奶醒着，侧着头在看窗外。窗外是医院的锅炉房，一根烟囱正冒着白烟。听到门响，奶奶转过头来。脸上那层灰白的颜色比昨天淡了一点，嘴唇没那么干了。

左腿还是被一个金属支架固定着，被子下面鼓起一个奇怪的形状。

"丫头。"奶奶说。声音比昨天有力气了。力气的恢复好像让她更担心了——因为有力气就意味着能想更多事。她看着晓星手里的糖盒，看了很久。晓星把糖盒放在床头柜上。打开。把那卷用老化橡皮筋扎着的钱拿出来。纸币。塑料袋里的硬币。她把硬币从塑料袋里倒出来，叮叮当当滚在床头柜上。有几枚滚到了台灯底座边上，撞出清脆的声音。然后从棉袄里面掏出一个东西。小猪储蓄罐。陶瓷的，耳朵缺了一只，肚子上的釉彩磨花了，但被擦得很干净。昨天晚上她用湿布擦了一遍。她把储蓄罐底部的塞子拔开，把纸币塞进去，把硬币一枚一枚投进去。硬币落进陶瓷罐子里，每一声都不一样。五角的清脆，一元的有闷响。最后一声落下去以后，她把塞子塞回储蓄罐底部。把小猪放在床头柜上。和奶奶的水杯挨在一起。小猪的鼻子朝着窗户。

病房里忽然很安静。隔壁床的阿姨在喝粥，勺子停在半空中。临床陪护的大爷手里剥了一半的橘子没有再剥。

门口有个护士推着小车进来换药。车轮的声音在门框上碰了一下，停了。她看了一眼床头柜上那只缺了耳朵的小猪，又看了一眼晓星的手。那双手上有茧。分铝罐磨的。接孩子冻的。捡矿泉水瓶勒的。护士低下头，从小车上拿起药瓶。她的睫毛湿了一下。不是因为别的护士在看。是因为那个储蓄罐。和一个孩子手上的茧。她把药换完，推着小车出去了。车轮在地上的声音比进来的时候轻。

奶奶没有看储蓄罐。她在看晓星的手。看了很久。然后把手伸到枕头底下。摸了半天，摸出一个红布包来。红布已经很旧了，布边起了毛。她放在被子上，一层一层打开。一共包了三层。最里面是一沓钱。一百的，大概有三十张。用一根红头绳扎着，头绳上系了一个很小的结。"丫头。"奶奶把那沓钱塞到晓星手里。她的手还是凉的。"这是奶奶攒的。攒了一辈子。不多。加上你的那些，够交押金。"

林建国站在病房门口。他不知道什么时候到的。手里拎着一个保温壶，里面是王秀兰早上熬的小米粥。粥还冒着热气，隔着壶壁能摸得到。他就站在门口。门只推开了一半，他的身体卡在门框里，没有进来。

他看着女儿把储蓄罐底部的塞子拔开。看着她把里面的东西倒在床头柜上——一百的、五十的、十块的、五块的、硬币叮叮当当滚了一地。一枚五角硬币一直滚到他脚边，在鞋面上磕了一下，躺在地上不动了。他弯腰去捡。拇指和食指捏住那枚硬币的边缘，拿起来。硬币上有一层暗哑的光。他翻过来。背面刻着年份。2015 年。他蹲在地上，又捡起一枚。2009 年。又一枚。2006 年。每一枚都比他过去十年做过的任何一个"投资"更诚实。他不是在捡硬币。他是在低下头，一粒一粒地，把自己的脸从泥里捡起来。

傍晚。陈爷爷来了。他穿着那件洗得发白的深蓝色中山装，手里拎着一个旧的公文包。没有水果。公文包里是一沓现金。两万元整，用银行的封条扎着。他把钱放在床头柜上，和那只缺了耳朵的小猪放在一排。

"小林。"他说。"这不是接济。是借。利息按照银行同期利率的一半算。借条在这里。"他从公文包内侧的口袋里抽出一张纸。借条是手写的，陈爷爷的字，一笔一画，和晓星纸条上的字一样工整。"签了字，这笔钱就归你们管。但有一个条件——"他看了林建国一眼。"还款期限三年。中间如果你再碰任何投资项目，借款立即到期。能做到吗。"

林建国接过笔。笔是陈爷爷从公文包里拿出来的。同一支钢笔。上次在茶几上签财务规划方案的时候，晓星见过这支笔。这一次他签的不是盲目的投资合同。他签的是一份借条。林建国两个字写在纸上。一笔一画。和他昨晚写账单时的字迹一样。但有一个地方不同。他的手没有抖。签完以后他把笔还给陈爷爷。把那张借条递过去。递的时候纸条边缘碰到陈爷爷的手指。陈爷爷看了一眼借条上的签名，然后把借条折好放回公文包里。没有说别的。只说了一句——"走。去缴费。"

三个人走到一楼的缴费窗口。还是那个窗口，还是那台电脑屏幕，还是那个涂着红色指甲油的收费员。

林建国把一沓钱推进凹槽。晓星的三千一百元。奶奶的三千元。陈爷爷的两万元。加上家里活期余额里最后凑出来的一点。三万元整。收费员把钱过了一遍验钞机，验钞机发出沙沙沙的声音，蓝光在每张纸币上扫过去。然后打印出一张收据，从小窗口推出来。林建国拿起收据。上面印着：住院押金。叁万元整。已缴清。他把收据折好，放进了棉袄内侧的口袋。和晓星早上放糖盒是同一个位置。

他转身走出缴费大厅。外面的雪停了。太阳从云层缝里漏出来，医院的玻璃幕墙反着光。他把手从口袋里拿出来。这双手写过了太多的投资合同、借条、催收还款承诺。每一份他签的时候手都在抖。不是因为紧张，是因为他从来不确定自己签的是什么。今天他签了三份东西。一份借条。一份缴费单。没有一份在抖。不是因为这三份轻。是因为这三份重。重到他的手终于接住了地。
