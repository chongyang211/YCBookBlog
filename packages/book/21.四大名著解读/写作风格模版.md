# 四大名著解读 · 写作风格模版

> 提炼自《煮酒论英雄·一筷见心法》，适用于古典名著现代解读类长文。

---

## 零、硬性规范（文件名 · 篇幅 · 标点）

### 文件命名

```
数字.篇名.md
```

文件放在对应卷目录下，按序号排列：

```
1.煮酒论英雄·一筷见心法.md
2.浔阳楼题诗·一笔毁半生.md
3.黛玉初进府·一步定终身.md
```

格式拆解：`数字` + `.` + `经典场景` + `·` + `四字洞察` + `.md`

- 数字：卷内序号，从 1 递增
- 经典场景：四到六字概括原著名场面
- 四字洞察：提炼核心教训，格式为"一+量词+动词+名词"

### 字数目标

每篇正文（不含 frontmatter）控制在 **5000-6000 字**。这是一个硬约束：太短撑不起六境结构，太长则拖沓失焦。精简的核心原则是"一句话能说清的不用两句话"，砍掉所有冗余修饰而非核心信息。

验证命令：`sed '1,15d' file.md | wc -m`

### 标点硬规则一：禁用破折号

**全文禁用中文破折号 `——`。** 所有原本用破折号的位置，改用标准标点：

| 破折号原用途 | 替换为 | 示例 |
|-------------|--------|------|
| 解释/说明 | 冒号 `：` | `他做了一件事：把杯子放下` |
| 因果/结论 | 逗号 `，` | `他看清了局势，所以选择了沉默` |
| 语意转折 | 句号 `。` | `他以为赢了。其实他输得彻底。` |
| 插入补充 | 逗号 `，` | `宋江，按今天的说法，就是文书科长` |
| 列举前导 | 冒号 `：` | `三个细节：独酌、贵酒、临窗` |

验证命令：`grep -c '——' file.md`，必须输出 `0`。

### 标点硬规则二：全文中文化

**正文全文使用中文标点符号，禁止混杂英文标点。** 对照表：

| 英文 | 中文 | 说明 |
|------|------|------|
| `,` | `，` | 逗号 |
| `.` | `。` | 句号（URL和数字中的点号除外） |
| `:` | `：` | 冒号 |
| `;` | `；` | 分号 |
| `?` | `？` | 问号 |
| `!` | `！` | 感叹号 |
| `()` | `（）` | 括号 |
| `""` | `""` | 双引号 |

例外：frontmatter 中的 URL（如 `permalink`、`link`）和 ISO 日期（如 `2026-05-22`）保留英文标点。

### 紧凑原则

- 段落长度比原模版缩减约 40%：场景段 80-150 字，分析段 120-200 字，工具段 80-150 字
- 对话引述只保留最有冲击力的一句，其余用间接引语
- 排比不超过三组，超过则砍掉最弱的那组
- 每个境的开头和结尾各一句话切入/切出，不做铺陈

## 一、整体篇章架构（六境递进法）

每篇采用六层递进结构，由浅入深，从现象到本质再到应用：

```
一境·当下入局   →  二境·古今同局   →  三境·勘破真相
四境·剔肉见骨   →  五境·古为今用   →  六境·余韵留白
```

每"境"下辖三个子板块，每个子板块也遵循同一命名格式：

### 命名规则

| 层级 | 格式 | 示例 |
|------|------|------|
| 主标题 | `第X卷·XX/第X篇·XXXX·XXXX` | 第一卷·立身之本 第1篇·煮酒论英雄·一筷见心法 |
| 境标题 | `数字+境+·+四字概括` | 一境·当下入局 / 四境·剔肉见骨 |
| 子板块标题 | `数字+量词+四字成语/短语` | 一幕拉开帷幕 / 三问勾人入局 / 三招随手可取 |

## 二、六境拆解与写作范式

### 第一境：当下入局

**目的**：用一个高度具体的现代场景，让读者一秒代入。

**三个子板块**：

#### 子板块1：一幕拉开帷幕（场景构建）

- **时间**：精确到星期、时刻（"上周三晚上八点零七分"）
- **地点**：具体且有画面感（"望京一家私房菜的圆桌上"）
- **人物**：半匿名化处理（"张总""老周"），赋予一两个独特标识（"洗得发白的灰色 polo""端着保温杯"）
- **触发事件**：一个细微动作引发全场注意（"保温杯往桌上轻轻一搁"）
- **落点**：主角的心理反应 + 感官细节（"茶水还在杯里晃，心里咯噔一下"）

```
句式要点：
- 开场用"那天"牵引叙事
- 善用"比...晚半秒""不重，但很准"这类精妙的时间/程度描写
- 以主角的"被架住"状态收尾，制造悬念
```

#### 子板块2：三难压上心头（困境剖析）

- **结构**：用排比句展开多个维度的两难（"说不说，是个问题；说什么，是更大的问题"）
- **技法**：用"太X，等于Y；太X，等于Z"的对仗推进
- **落点**：把现代场景与古典名著做第一次连接（"这分明就是几百年前那一幕的现代翻版"）

```
句式要点：
- "说不说，是个问题；说什么，是更大的问题" 类递进排比
- "一旦...就..." 的连锁推演
- 段尾突然拔高，点出古今同构
```

#### 子板块3：三问勾人入局（读者钩子）

- **结构**：连续三个"你有没有..."的反问句，层层收紧
- **技法**：
  - 第一问：指认普遍经历（"一个比你强的人，用一个看似随意的问题..."）
  - 第二问：深挖恐惧（"背后藏着多少陷阱..."）
  - 第三问：抛出核心悬念（"刘备面对的是和你今天一模一样的局"）

```
句式要点：
- 必须用"你有没有"或"你是否曾"开篇
- 三个问句一个比一个具体，一个比一个尖锐
- 最后一个问句必须把读者和古人绑定
```

### 第二境：古今同局

**目的**：从现代自然过渡到古典原著，建立古今对照。

#### 子板块1：一句跨越千年（桥梁句）

- **结构**：一个反问句 + 一个肯定句
- **范式**："你以为X只有Y才有？翻开《Z》第N回，你会发现，几百年前的A地，B坐过比你今天烫得多的椅子。"

#### 子板块2：一笔勾出阵局（历史背景）

- **核心信息**：时间（精确到年）+ 人物处境 + 各方博弈关系
- **技法**：
  - 用"名义上...实际上..."揭示表里不一
  - 补充一个生动的日常细节来展示人物策略（"在后院里种菜"）
  - 用"但你要真以为...那就把...看得太轻了"做转折

#### 子板块3：名场跃然纸上（场景还原）

- **写法**：像电影剧本一样复述原文场景
- **要素**：天气 → 环境 → 人物动作 → 对话 → 氛围评价
- **关键句收尾**："这就是《XXX》整部书里最危险、也最经典的一场XX"

---

### 第三境：勘破真相

**目的**：对经典场景做逐帧慢镜分析，挑出常人忽略的细节。

#### 子板块1：慢镜逐帧细看

- **结构**：将场景切成"第N帧"，逐帧解读
- **每帧格式**：
  - `第N帧：人物动作/对白`
  - `这一帧很关键，因为...`
- **帧数**：5-7帧为宜
- **技法**：每一帧只讲一个信息点，用"因为"引出背后的动机分析

#### 子板块2：一秤一两皆心（深度称量）

- **写法**：把场景中的每个道具、每个细节逐一追问"为什么"
- **范式**：`XX为什么要用A？因为A的B属性，暗含了C的意图`
- **关键句式**："X不是在Y，X是在Z"（揭示表象与实质的反差）

#### 子板块3：三处缝隙透光（冷门发现）

- **结构**：列出3个被普遍忽略的细节
- **每处格式**：
  - `第N个缝隙：XX做了什么，原文紧接着写...`
  - `这句话其实暴露了.../这不是A，这是B...`
- **技法**：每个缝隙都要颠覆一个流行认知，让读者有"原来如此"的快感

---

### 第四境：剔肉见骨

**目的**：打破流行解读，直击人性底层逻辑。

#### 子板块1：先破陈词俗见

- **结构**：先立靶（"市面上九成解读都会落到X"），再一一击碎
- **范式**：`说A是X，其实是把A贬低成了Y；说B是Z，更是把B矮化成了W`
- **核心句**：`"这个解读太浅了，浅到几乎是侮辱原著"`
- **转折句**：`"真相恰恰相反：A赢的不是X，是Y；B做的也不是Z，是W"`

#### 子板块2：直探人性深处

- **写法**：提炼出一个核心的人性洞察（曹操对"人才"的定义），以此为线索串联多个人物命运
- **技法**：
  - 用一个角色的核心定义作为锚点（"曹操对'人才'的真实定义"）
  - 用排比列举多个案例（孔融、杨修、荀彧）来证明定义
  - 最后回到主角，解释他活下来的真正原因：不是运气，是"装"
- **金句收尾**：`"真本事不是赢，是活；而活下来的方式，从来不是硬扛，是配合对方完成他想要的剧本"`

#### 子板块3：还原时代风骨

- **写法**：把人物行为放回具体的历史年代来分析
- **要素**：年份 + 政治格局 + 统治者的核心恐惧 + 主角的独特威胁 + 最终判断
- **收尾技法**：翻转认知："不是A看走了眼，是B的'装'做得实在太好"

---

### 第五境：古为今用

**目的**：从古典智慧中提炼出现代实战工具。

#### 子板块1：古今同坐一席（镜像回扣）

- **写法**：把开头的现代场景和古典场景做一一对应
- **范式**："把A地的X切换回B地的Y，你就会发现，甲的哪句话和乙的哪句话，结构上一模一样"
- **关键词**："都是用一个看似X的Y，把Z架到W面前"
- **收尾**：用对比制造俏皮感："曹操用青梅，张总用保温杯；刘备装的是怕雷，你装的是..."

#### 子板块2：三招随手可取（实战工具）

- **结构**：3个工具，每个工具 = 名称 + 对应原文出处 + 现代话术模板 + 本质解读
- **命名范式**："第N招叫'XXXX'"
- **每招内容**：
  1. 招名（四字短语，加引号）
  2. 对应原文："对应原文里刘备那句'XXXX'"
  3. 使用场景说明
  4. 具体话术示例（"比如可以说'...'"，用双引号包裹完整回答）
  5. 本质解码："这一句X的本质，是把A的Y换成了B的Z"

#### 子板块3：三线步步惊心（避坑指南）

- **结构**：3条红线，每条 = 禁忌行为 + 原因 + 正确做法
- **范式**：`第N条红线，永远不要XXXX。因为AAAAAA。刘备整场酒局没做过NNNN，他只是YYYYY，因为YYYY本身就是一种ZZZZ。`

---

### 第六境：余韵留白

**目的**：推荐延伸阅读，设下悬念钩子。

#### 子板块1：原文三处必读

- **范式**：`如果想读原文，《XX》第N回是必读，重点关注N个细节：一是...；二是...；三是...`
- **每处细节**都要点出"注意什么"和"体会什么"

#### 子板块2：延伸三卷参看

- **范式**：`可以搭配《XX》第N回里XX对XX的那段XX一起读，理解XX的真实心境；也可以对照《XX》关于这段的记载，感受XX是如何把一段简短的史料演绎成XX`
- 通常给出3个延伸方向：原书相关章节 / 正史对照 / 名家批注

#### 子板块3：一问引出下章

- **写法**：抛出一个与前文结论矛盾或深化的问题
- **范式**："XX靠YYYY活了下来，但你有没有想过：AAA难道真没ZZ？如果ZZ了，他为什么还要BBB？这个问题，会带我们进入下一章：《CCCC的DDDD》。"
- **关键**：问题必须颠覆前文表面结论，将读者带入更深的思考

## 三、句式风格工具箱

### 3.1 标志性句式

| 功能 | 句式模板 |
|------|----------|
| 古今穿越 | "你以为X只有Y才有？翻开《Z》第N回，你会发现..." |
| 场景收束 | "这就是《XXX》整部书里最危险、也最经典的..." |
| 破旧立新 | "这个解读太浅了，浅到几乎是侮辱原著" |
| 翻转认知 | "真相恰恰相反：A赢的不是X，是Y" |
| 本质洞察 | "X不是在Y，X是在Z" |
| 古今类比 | "区别只在于，A用X，B用Y；A装的是X，你装的是Y" |
| 金句收尾 | "真本事不是赢，是活；而活下来的方式，从来不是..." |

### 3.2 修辞标志

- **对偶排比**："说不说，是个问题；说什么，是更大的问题"
- **递进推演**："一旦说错了一个名字，明天这话就会从某条微信群漏出去，传到..."
- **反差封装**："看着窝囊、其实野心勃勃" / "最不像英雄的日常"
- **连串追问**：三个"为什么"或"你有没有"连续发射
- **数据级精确**：在模糊叙事中嵌入精确细节（"晚上八点零七分""公元199年"）

### 3.3 语言质感

- **半文半白**：古典词汇（"韬光养晦""挟天子以令诸侯"）+ 现代口语（"心里咯噔一下""做得挺凶啊"），混搭自然
- **镜头语言**："一帧一帧看""把镜头切换回""慢镜""逐帧"，用影视术语增强画面感
- **称量隐喻**："过秤""一秤一两皆心""称重""筛选"，用商业/交易词汇解读权力关系
- **游戏/棋局隐喻**："入局""阵局""棋局""算盘""博弈"，把人际关系处理为策略推演

### 3.4 人称策略

- **"你"直接对话读者**：全篇高频使用第二人称，制造"说的就是你"的代入感
- **"我们"拉近距离**："我们把那场酒局的镜头放慢""我们现在一句一句称"
- **第三人称叙事**：场景构建时保持旁观者视角的客观质感

## 四、段落组织法则

### 4.1 段落长度（紧凑版）

注意：为控制整篇在 5000-6000 字，段落长度需比参考篇更紧凑：

- 场景段落：80-150字，画面感密集型
- 分析段落：120-200字，逻辑推演型
- 工具段落：80-150字，实用性读法

每段只承载一个核心信息点，多出来的另起一段。

### 4.2 段内结构

每段的黄金骨架：

```
【断言/场景切片】→【展开/引用原文】→【深层解读】→【金句收束】
```

### 4.3 转折词惯用清单

- 冒号（：）：用作因果解释、场景收束、翻转认知，核心连接符
- 句号（。）：用作语意转折，短句节奏控制
- "但要注意"：引入风险提示
- "恰恰相反"：翻转前文观点
- "区别只在于"：类比的精妙落点

## 五、数字编排术

全文贯穿"三"字美学，几乎所有论据都以"三"为单位组织：

| 位置 | 内容 |
|------|------|
| 第一境 | 三难压心头 + 三问勾人入局 |
| 第三境 | 六帧逐帧 + 三处缝隙 |
| 第五境 | 三招工具 + 三条红线 |
| 第六境 | 三处必读 + 三卷参看 |

**变体规则**：偶尔用"六帧""五帧"打破规律，避免机械感，但大骨架仍是"三的倍数"。

## 六、起名字心法

### 章节标题

- 立身之本 / 处世之道 / 驭人之术：提炼为"XX之X"三字格式
- 煮酒论英雄·一筷见心法："经典场景+核心洞察"双标题

### 文件命名

`数字.经典场景·四字洞察.md`，例如 `3.黛玉初进府·一步定终身.md`。

- 数字：卷内序号，从 1 递增，对齐 `1.煮酒论英雄...`、`2.浔阳楼题诗...` 的格式
- 经典场景：四到六字原著名场面概括
- 四字洞察：一 + 量词 + 动词 + 名词（一筷见心法、一步定终身、一棒撼乾坤）

### 子板块标题

每四个字要同时做到：

1. **有数字**：一/二/三（暗示可操作、可量化）
2. **有量词**：幕/问/招/线/处/笔
3. **有动作/意境**：拉开帷幕、压下心头、勾人入局、随手可取、步步惊心
4. **有音韵**：尽量做到四字成语或类成语的平仄节奏

## 七、写作流程清单

按此文风写一篇的完整步骤：

```
□ 1. 选定名著经典场景，提炼一个"现代对应场景"
□ 2. 用精确时间+地点+匿名人物+触发性动作，写出第一境的现代场景
□ 3. 用三组排比展开困境，用三连反问勾住读者
□ 4. 用"你以为...翻开..."桥接古今，还原历史背景与名场面
□ 5. 把经典场景切成5-7帧逐帧分析，挑出3个被忽略的细节
□ 6. 挑战流行解读，提出"真相恰恰相反"的翻转观点
□ 7. 用一个人性洞察串联多个人物命运，拔高立意
□ 8. 附加时代背景分析，说明"为什么是这个人，在这个时刻"
```
