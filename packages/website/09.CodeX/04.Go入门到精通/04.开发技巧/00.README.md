## 📈 学习建议

1. **先读模块一（排错）**：故障排错是工程师"差距最明显"的能力，先把这 5 篇读完，团队会立刻看到你的成长
2. **再读模块二（调优）**：pprof + trace 是 Go 工程师的"瑞士军刀"，掌握后能解决 90% 的性能问题
3. **模块三随用随查**：工程能力是"日积月累"，把这 5 篇当 checklist 用，每次写代码前对一遍
4. **模块四进阶必读**：当你成长为团队 Lead，灰度 + 故障复盘是必备能力
