# 数据库系统原理系列

## 学习方法

本系列延续**疑惑→答疑→论证→结论**的教学模式：

1. **疑惑**：从慢查询、死锁、数据不一致等线上故障切入
2. **答疑**：给出数据库层面的根本原因
3. **论证**：通过 EXPLAIN 分析、源码剖析深入理解
4. **结论/技术演变**：总结设计思想，展示 MySQL 版本演进
