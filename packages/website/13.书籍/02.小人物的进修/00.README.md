# 《自我精进》

> 一个普通人十年间从迷茫到清醒的自我修炼手册

---

## 1.为什么写这本书

这本书不是一时起意的产物，而是我过去十余年的亲身经历、反复修改、多年积累的沉淀。

我出身普通，没有天赋异禀，也没有名校光环。刚入职场那几年，我像大多数年轻人一样陷在焦虑里：每天被琐碎任务推着跑，听了很多道理却用不出来，读了很多书却记不住，定了无数目标却总是半途而废。我不甘心，就开始满世界找方法——翻书、听课、请教前辈、拆解优秀的人。那几年我看了大量的书：从《高效能人士的七个习惯》《原则》《思考，快与慢》到《金字塔原理》《麦肯锡方法》《刻意练习》，从《认知觉醒》《学会提问》到稻盛和夫、彼得·德鲁克、查理·芒格的著作——加起来少说二三百本。

可越读越发现一个问题：**书读得再多，也替代不了自己的实践。** 很多方法在书里看着漂亮，放到真实场景里就不好使；很多道理听着通透，一到自己身上就使不出来。我开始逼自己做一件事：**每学一个方法，必须在真实工作和生活里跑一遍，然后用自己的话把它重新写出来。** 跑不通的就丢掉，跑通的就记下来，记下来之后还要反复修改——今年这么想，明年做得更多了再回头改，后年经验更深了再重写一遍。

就这样，一本笔记从最初几千字，慢慢长成了几万字，最后变成了现在这本书。它不是学者写的理论总结，而是一个普通人用十年光阴、一次次摔跤和爬起，一字一句磨出来的实战手册。我写它，不是因为我有多厉害，恰恰是因为我足够"普通"——如果连我这样起点一般、资质平平的人都能靠这些方法实现蜕变，那么任何一个愿意行动的人，都可以。

愿这本书，能在你迷茫时给你方向，在你困顿时给你方法，在你懈怠时推你一把。

---

## 2.本书的推荐语篇

**"这不是一本教你'想明白'的鸡汤书，而是一本帮你'做到位'的操作手册。"**

职场中最残酷的真相是：大多数人不是不努力，而是不会努力。这本书恰好填补了"知道"和"做到"之间的鸿沟。作者从自身经历出发，将方法论与真实场景深度结合，既有体系化的思维框架，又有拿来即用的实操工具。对于每一个想要突破自我的普通人，这是一本值得反复翻阅的修炼指南。

难得看到一本书能把"学习怎么学习"、"做事怎么做事"、"说话怎么说话"这些看似简单实则极难的底层能力，拆解得如此清晰。不空谈，不鸡汤，全是可落地的干货。

## 3.本系列的内容介绍

本系列以"一个普通人如何系统性地提升自我"为核心命题，围绕**学习、成事、立言**三大能力维度，拆为相互独立又层层递进的三卷。

系列遵循一条贯穿始终的主线：

```
学得会   →   做得到   →   说得清
（卷一）     （卷二）     （卷三）
 输入         输出         放大
```

| 卷 | 书名 | 副标题 | 内容构成 |
|---|------|--------|---------|
| 卷一 | [自我精进·学习](../04.自我精进·学习/00.README.md) | 学得会的认知、信息与学习方法 | 认知觉醒 + 信息筛选 + 学习方法 |
| 卷二 | [自我精进·成事](../05.自我精进·成事/00.README.md) | 做得到的 25 个目标与做事方法论 | 目标管理 + 事前谋划 + 事中执行 + 事后复盘 |
| 卷三 | [自我精进·立言](../06.自我精进·立言/00.README.md) | 说得清的表达力与思维力修炼 | 底蕴储备 + 沟通实战 + 公众表达 + 底层思维 |

「立言」出自传统「三不朽」（立德、立功、立言），三卷由此形成完整递进：**修己 → 立功 → 传世**。

每一节内容包含：**思维框架 + 真实案例 + 实操方法 + 刻意练习**，确保读者不仅"看懂"，更能"做到"。

## 4.本书的读者对象

1.初入职场1-5年，渴望快速成长但找不到方法的年轻人

2.遇到发展瓶颈，想要系统性突破的职场人

3.想提升学习效率、做事能力、表达水平的终身学习者

4.带团队的管理者，希望推荐给团队成员的成长读本

## 6.本书的特色亮点

1.**真实性**：每一个方法都来自作者的亲身实践，不是纸上谈兵

2.**系统性**：七大维度构成完整修炼体系，彼此关联、层层递进

3.**实操性**：每节包含思维框架、案例分析、方法步骤、课后练习

4.**普适性**：面向所有想要自我提升的普通人，不设门槛

## 7.本系列的总结

如果把整个系列浓缩成一句话，它讲的其实只是一件事——**一个普通人，如何把"知道"变成"做到"，再把"做到"变成"说出去"。**

三卷，不是三本孤立的书，而是一个人从"被生活推着走"到"推着生活走"所必经的三道关口：

**第一关 · 学得会（卷一）**：把"学得多"换成"学得会"，让学习本身成为一项可以被练习、被复制的技能。

**第二关 · 做得到（卷二）**：把"蛮力硬干"换成"事前—事中—事后"的方法闭环，让每一件事都能沉淀为下一件事的起点。

**第三关 · 说得清（卷三）**：把"肚里有货倒不出"换成"想得清楚也说得清楚"，让表达成为能力的放大器；而"想得清楚"的根，是底层的思维修炼。

三关层层递进，形成完整闭环：**学得会才做得到 → 做得到才有的说 → 说得清反过来倒逼想得深、学得更透。**

这个系列想传递的核心价值观其实很朴素：

1.**承认平凡，但不甘平庸。** 普通人的突破，不靠天赋，靠方法加时间。

2.**方法论不是背下来的，是跑出来的。** 所有没在真实场景里跑过一遍的方法，都不算你的。

3.**成长是一个系统工程，不是一场短跑。** 十年磨一剑，和三个月速成，是两种人生。

4.**写下来、改下去、传下去。** 把走过的路写清楚，既是沉淀自己，也是照亮后来人。

十年回头看，最庆幸的不是走了多快，而是没有走偏。愿你读完这个系列时，不只是"又读了几本书"，而是真的开始动手——在你的工作里、在你的生活里，写下属于你自己的第二部《自我精进》。
