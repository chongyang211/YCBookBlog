# 《自我精进》三册独立出版方案

> 文档性质：书籍出版工作方案
> 制定日期：2026-08-29
> 适用对象：`packages/website/13.书籍/02.小人物的进修`
> 核心目标：**每一册都能独立出版、独立销售、独立成立**

---

## 一、核心结论

**41.5 万字的单本拆成 3 册，但拆分只是手段，「每册独立成书」才是目标。**

**系列名**：自我精进　　**贯穿语**：**学得会，做得到，说得清**

| | 现状 | 目标 |
|---|---|---|
| 形态 | 1 本 41.5 万字（约 600 页） | 3 册（卷一 / 卷二 / 卷三），各 12-17 万字 |
| 书名 | 《自我精进》单本 | 卷一《自我精进·学习》／卷二《自我精进·成事》／卷三《自我精进·立言》 |
| 关系 | 一本大书 | **三本独立的书**，共享「自我精进」品牌，用「学 → 做 → 说」串联 |
| 阅读依赖 | 必须从第 1 章读起 | **任意一册都能独立读懂**，按卷序读收获最完整 |

## 二、原书诊断（为什么必须拆）

### 2.1 核心数据

| 指标 | 数值 |
|------|------|
| 总字数 | **414,673 字** |
| 章节数 | 55 节（正文 53 节 + 结语 / 后记 2 篇） |
| 平均单节 | 约 7,400 字 |
| 预估页数 | 约 600 页 |

> **⚠️ 稿件缺口**：原 README 中规划的「56. 全书金句索引」（38 句）**文件不存在**。它既是附录内容，也是重要的营销物料（可提炼为书签、图文），必须补写——见第九节清单第 8 项。

### 2.2 三个致命问题

1. **体量超标**：市场标准是单本 15-20 万字，41.5 万字 = 600 页、定价 90+ 元，出版社选题会基本过不了
2. **主题过散**：一本书装七个能力域，读者印象是「什么都讲 = 什么都不精」
3. **结构失衡**：第5章占 33%（20 节），第2章只占 4%（2 节），最大章是最小的 7.4 倍

---

## 三、独立出版的三大原则

要让每一册都能独立成立，必须满足三条：

### 原则 1：独立开篇

每册都要有自己的「开篇」，直接回答三个问题：**这本书解决什么问题、写给谁看、怎么用**。

> 读者拿起卷二，不需要先读卷一就知道在讲什么。

### 原则 2：独立编号

每册**重新建立章节编号体系**（第1章、第2章……），**不沿用原书的 5.1、5.2 这类编号**。

> 否则读者翻开卷二看到「5.13 金字塔汇报」，会本能觉得"这是某本书的中间章节"，独立感瞬间消失。

### 原则 3：独立闭环

每册内部要形成 **「问题 → 方法 → 练习 → 总结」** 的完整闭环，并以自己的结语收尾。

> 三册之间可以有递进关系（学了 → 做了 → 说出去了），但**不互为前置条件**。

---

## 四、标题规范：全书统一 7 字

### 4.1 为什么必须统一

原书 **46 个纯中文标题全部是 7 个字**（"学习的七大原则""要带上技能地图""鱼骨图分析方法"……），这是本书自带的排版特色。出版时目录页会集中呈现几十个标题，**7 字对齐能形成强烈的视觉秩序感**，是这本书专业感的直接体现。

一旦新增章节破坏这个规律（比如写一个 15 字的长标题），目录页立刻变得参次不齐。

### 4.2 统计结果：46 个符合，9 个待调整

| 状态 | 数量 | 说明 |
|------|------|------|
| ✅ 符合 7 字 | 46 个 | 全部为纯中文标题 |
| ⚠️ 待调整 | 9 个 | 7 个含英文缩写 + 2 个结语后记 |

**待调整的 9 个**：

| 序号 | 原标题 | 视觉宽 | 处理 | 新标题 |
|------|--------|--------|------|--------|
| 21 | OKR目标规划法 | 6.5 | 保持 | — |
| 22 | SMART目标设定 | 6.5 | 保持 | — |
| 23 | SWOT分析方法论 | 7.0 | 保持 ✓ | — |
| 24 | **MECE分析法则** | 6.0 | **改名** | **MECE分析的方法** |
| 27 | RACI责任矩阵法 | 7.0 | 保持 ✓ | — |
| 28 | **PDCA执行方法** | 6.0 | **改名** | **PDCA循环执行法** |
| 32 | STAR摸底分析法 | 7.0 | 保持 ✓ | — |
| 54 | **写给平凡的你** | 6.0 | **改名** | **写给平凡人的话** |
| 55 | **十年回望后记** | 6.0 | **改名** | **十年回望的后记** |

> **宽度计算**：中文字符按 1 计，英文/数字按 0.5 计（英文字宽约为汉字一半）。4 字母缩写（SWOT/RACI/STAR/PDCA/MECE）+ 5 个汉字 = 2 + 5 = 7，正好达标；而"MECE分析法则""PDCA执行方法"只有 4 个汉字，宽度 6，需补 1 字。

### 4.3 新增章节的 7 字标题

新增 6 节必须严格遵守 7 字规范，并延续原书标题的多种结构（偏正 / 动宾 / 并列 / 主谓）：

| 编号 | 内容 | 7 字标题 |
|------|------|---------|
| 2.3 | 信息源管理 | **建立优质信息源** |
| 2.4 | 卡片笔记法 | **卡片笔记写作法** |
| 3.7 | 对抗遗忘 | **对抗遗忘记忆法** |
| 3.8 | 主题阅读 | **主题式阅读方法** |
| 4.1 | 知识迁移 | **知识迁移与运用** |
| 4.2 | 输出倒逼输入 | **输出倒逼着输入** |

### 7.2 为什么叫「立言」

**「立言」= 内在思想 + 外在言说**，一个词同时涵盖本卷两块内容：

```text
立言
 ├─ 立（思想）：专注 · 记忆 · 思考 · 质疑 · 情商   → 第 4 章
 └─ 言（言说）：底蕴 · 沟通 · 提问 · 演讲         → 第 1-3 章
```

所以第 4 章的 7 节思维内容**不是跑题，而是「立」的那半边**。这正是本书区别于市面「话术类」表达书的关键——**只教话术的书，读者学完依然说不出有内容的话**。

同时，「立言」出自传统「三不朽」（立德、立功、立言），与卷一、卷二形成完整递进：

```text
卷一 学习（修己）  →  卷二 成事（立功）  →  卷三 立言（传世）
```

## 八、三册协同：连得起来，又不互相依赖

### 8.1 贯穿三册的一句话

> **学得会，做得到，说得清**

这 9 个字是整套书的精神内核，也是三册之间的连接线：

```text
卷一 自我精进·学习  →  卷二 自我精进·成事  →  卷三 自我精进·立言
       （输入）              （输出）                （放大）
     学得会什么            做得到什么             说得清什么
     认知·信息·方法        目标·做事 25 法        表达力·思维力
```

**逻辑链**：先能学明白 → 再把事做成 → 最后把价值说出去，构成「输入 → 输出 → 放大」的完整能力闭环。

### 8.2 四个连接设计

| 设计 | 做法 | 效果 |
|------|------|------|
| ① 卷号 | 卷一 / 卷二 / 卷三 | 物理上绑成一套，读者知道阅读顺序 |
| ② 品牌锚点 | 三册统一「自我精进 · 」前缀 | 一眼看出是同一系列 |
| ③ 副标题句式 | 统一「**X得X的 + 内容**」：学得会的… / 做得到的… / 说得清的… | 三册摆在一起极整齐，且与贯穿语呼应 |
| ④ 内容握手 | 每册开篇承接上一册、结语引出下一册（见 8.3） | 读完一册自然想读下一册 |

### 8.3 内容握手（互相导流的具体写法）

| 位置 | 写法 |
|------|------|
| 卷一《结语》 | 学得会之后，真正的考验是把它做出来——这正是卷二要解决的。 |
| 卷二《开篇》 | 很多人学得会，却做不成。会学和会做之间，隔着 25 个方法。 |
| 卷二《结语》 | 做得成还不够，还得让别人看见——卷三讲怎么把价值说清楚。 |
| 卷三《开篇》 | 你的能力上限，往往取决于你能表达出多少。做得好，还要说得清。 |

### 8.4 独立性保障（连而不依赖）

| 保障项 | 做法 |
|--------|------|
| 编号独立 | 每册各自从第 1 章开始编号，不出现 5.x、6.x 这类跨册编号 |
| 开篇独立 | 每册开篇直接讲清本册解决什么问题，不引用其他册 |
| 闭环独立 | 每册都有「问题 → 方法 → 练习 → 结语」的完整结构 |
| 案例独立 | 每册案例可自解释，不依赖其他册的背景 |

> **关键**：三册是「推荐顺序」而非「强制顺序」。任意一册单独读都成立，只是按卷一 → 卷二 → 卷三读，收获最完整。

### 8.5 品牌与营销协同

- 统一封面设计语言，卷号醒目（卷一 / 卷二 / 卷三）
- 每册扉页列出另两册目录 + 一句本册金句（互相导流）
- 38 句金句按「学 / 做 / 说」三类分到三册，每册印本册金句 + 另两册各一句
- 全套出礼盒装，腰封印贯穿语「学得会，做得到，说得清」
