# 《自我精进》拆分与出版方案

> 文档性质：书籍出版工作方案
> 制定日期：2026-08-29
> 适用对象：`packages/website/13.书籍/02.小人物的进修`

---

## 一、一句话结论

**41.5 万字的单本必须拆成 3 本，形成「自我精进」系列。** 保留现状出版社大概率拒稿，拆分后每本 12-17 万字、170-250 页，符合市场标准且能互相导流。

---

## 二、现状诊断

### 2.1 核心数据

| 指标 | 数值 |
|------|------|

| 章节数 | 56 节（7 章 + 附录后记） |
| 平均单节 | 约 7,400 字 |
| 预估页数 | 约 **600 页** |

### 2.2 各章体量分布（严重失衡）

| 章节 | 字数 | 节数 | 占比 |
|------|------|------|------|
| 第1章 自我认知 | 54,934 | 6 | 13% |

| 第3章 学习方法 | 45,436 | 6 | 11% |
| 第4章 目标计划 | 37,373 | 5 | 9% |

最大章（第5章 13.5 万字）是最小的（第2章 1.8 万字）的 **7.4 倍**。

### 2.3 三个致命问题

#### 问题 1：单本 41.5 万字，市场不接受（最致命）

| | 市场标准 | 本书现状 | 差距 |
|---|---|---|---|
| 单本字数 | 15-20 万字 | 41.5 万字 | 超 2 倍 |
| 单本页数 | 250-320 页 | ~600 页 | 超 1 倍 |
| 定价区间 | 39-59 元 | 需 89-99 元 | 翻倍 |

**后果**：600 页、定价 90 元的个人成长书，出版社选题会基本过不了。纸张/印刷/物流成本高，定高价又压制销量，新人作者拿这个体量几乎没有谈判筹码。

#### 问题 2：主题跨度过大

一本书装了 **七个能力域**：认知、信息、学习、目标、做事、沟通、思维。

读者心理是「**什么都讲 = 什么都不精**」。市场成功案例全是单点突破——《学会提问》只讲批判性思维、《金字塔原理》只讲逻辑表达、《刻意练习》只讲练习方法。

#### 问题 3：章节结构失衡

第5章占 33%（20 节 13.5 万字），读者连续读 20 节方法论会严重疲劳；第2章只有 2 节，存在感极弱。全书"头重脚轻"，阅读节奏崩坏。

### 2.4 保留现状的风险

| 环节 | 结果 |
|------|------|
| 投稿出版社 | 大概率拒稿（新人作者 + 600 页 = 成本与风险双高） |
| 自出版/电子书 | 可行，但定价低、专业感弱，损害个人品牌 |
| 读者反馈 | 可预期："太厚了读不完"、"内容散，找不到重点" |

## 三、拆分方案（核心）

### 3.1 拆分逻辑

按「**输入 → 输出 → 放大**」的能力链条切分，每本对应一个读者能明确感知的痛点：

```
第1本：内化（认知 + 信息 + 学习）  ← 怎么学
第2本：外化（目标 + 做事）        ← 怎么做
第3本：放大（表达 + 思维）        ← 怎么说 / 怎么想
```

**为什么是 3 本而不是 4 本**：拆 4 本会导致后两本只有 7.5 万和 4.9 万字，单本低于 8 万字会显得"太薄、不够分量"，定价低、市场接受度差。3 本能让每本都落在合理区间。

## 四、拆分之外的 5 项优化任务

拆分只是第一步，达到出版标准还需完成：

### 任务 1：单章篇幅压缩（工作量最大）

当前平均 7,400 字/节，偏长。有两个选择：

- **方案 A**：压缩到 3,000-5,000 字/节（保留章节数，精简内容）
- **方案 B**：**保持字数，把长节拆成 2-3 个小节**，每节配小标题

> **建议方案 B**：不损失内容，且小节化后更适合碎片化阅读，读者完成感更强。

### 任务 2：案例去"时效性"

书中存在依赖具体年份的表述（如"十年前选择了互联网"），出版后很快过时。

**修改原则**：改成不依赖具体年份的表达，如"在行业起飞的前一年进去"。

**需检查的章节**：第1章（认知类案例）、第5章（职场类案例）。

### 任务 3：强化"练习"模块

原 README 承诺每节包含「思维框架 + 真实案例 + 实操方法 + 刻意练习」。

**这是本书相对鸡汤书的核心差异化，必须落实**。建议每节章末增加：

- 3-5 条「行动清单」（可直接照做）
- 1 个「自测问题」（检验是否真懂）

> 读者在豆瓣/电商写好评的关键理由，往往就是"练习有用"。

### 任务 4：金句索引做成传播物料

附录的"38 句救命话"是极好的营销点。建议单独提炼为：

- 实体书签（随书附赠或独立售卖）
- 小红书/公众号图文（出书前后做传播）

### 任务 5：内容去重复查

原 README 已提到做过一次合并（"原《构建知识的体系》与《学习方法论沉淀》主题重合，已合并"）。

拆分后需**再查一轮跨册重复**，重点检查：

- 目标管理类：SMART / OKR / 目标设立（第2本内部）
- 复盘类：四维度总结 / 阶段复盘 / 结果的检查改进（第2本内部）
- 思维类：体系思维（第1本）vs 思考能力提升（第3本）

## 六、出版路径建议

### 路径 A：传统出版（推荐首选）

- **目标出版社**：机械工业出版社、中信出版社、人民邮电出版社（经管/成长类强势）
- **投稿材料**：选题策划书 +  complete 书稿 + 作者简介 + 市场分析
- **谈判要点**：强调"系列书"属性（一套三本，出版社更愿意打包签约）
- **预期周期**：签约后 6-12 个月上市

### 路径 B：自出版 / 电子书（备选）

- 平台：微信读书、得到、知乎盐选、亚马逊 KDP
- 优势：周期短、保留全部版权和收益
- 劣势：缺乏专业编辑把关、营销靠自己

> **建议**：先用第2本（工具箱，最市场化）投传统出版，同时把第1本做成电子书试水，用电子书数据反哺传统出版谈判。

### 营销建议

1. **先做第2本的口碑**：工具箱最容易出"实用"口碑，也最容易在职场社群传播
2. **作者 IP 联动**：你有技术博客（yccoding.com，1081 篇文章）和开源作品，这是出版社看重的"自带流量"
3. **金句先行**：出书前 3 个月开始用金句图文在社交平台造势
