# 卷一 · 自我精进 · 学习

> **学得会的认知、信息与学习方法**

---

## 1. 本卷定位

系列贯穿语是「**学得会，做得到，说得清**」，本卷负责第一环：**学得会**。

这不是一本讲「学习很重要」的鸡汤书，而是一套**让你真的能学会**的可操作系统。从认清自己开始，到在信息洪流里筛选出有用的部分，再到用对方法把知识真正内化。

---

## 2. 解决什么问题

| 痛点 | 本卷的解法 |
|------|-----------|
| 收藏一堆，用时找不到 | 第 2 章：信息筛选 + 建立优质信息源 + 卡片笔记 |
| 学得慢、看了就忘 | 第 3 章：完整学习闭环 + 对抗遗忘记忆法 |
| 学了很多却用不出来 | 第 4 章：知识迁移与运用 + 输出倒逼着输入 |

---

## 3. 适合谁读

- 在校学生、应届生
- 职场 0-3 年，感觉"学不动了"的新人
- 想重建学习体系的终身学习者

## 7. 出版级质量标准

本册所有正文均以 [1.2 需求层次的模型](./02.认知觉醒/02.需求层次的模型.md) 为标杆样板。开篇必是数据化真实案例，写清人、时、地、数（如「跳槽 22k → 30k」「阿杰 2100 篇收藏、随机抽 100 篇」），而不是「有一个朋友」式的模糊叙事。理论段后两百字内必须接作者一手经验，浓度对齐 2.3 的「替代性完成 / 蔡格尼克效应」自然转译。

每节 mermaid 控制在两张以内且必须承载因果或流程，罗列型图（把文字搬进方框、无信息增量的）一律删除或降级为表格。少用 `- ` 列表与 `> ` 引用，尽量用流畅段落配 `**bold**` 强调；凡列表超过 5 项即改写为段落。每节至少要有一个技术案例，可以是学框架、读源码、排线上事故或做技术分享。

结尾五段式必备：总结回顾三件事、后来发生的改变（写数据化收益）、今天起改变三点、课后作业思考、下一站过渡。每章开头须有一张 30 秒可读完的断点自测表，直接对应开篇的「存不下 / 记不住 / 用不出」三断点。所有小节标题严格控制在 7 字。
