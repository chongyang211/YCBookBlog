# 卷一 · 自我精进 · 学习

> **学得会的认知、信息与学习方法**

---

## 1. 本卷定位

系列贯穿语是「**学得会，做得到，说得清**」，本卷负责第一环——**学得会**。

这不是一本讲"学习很重要"的鸡汤书，而是一套**让你真的能学会**的可操作系统。从认清自己开始，到在信息洪流里筛选出有用的部分，再到用对方法把知识真正内化。

---

## 2. 解决什么问题

| 痛点 | 本卷的解法 |
|------|-----------|
| 学得慢、看了就忘 | 第 3 章的完整学习闭环 |
| 收藏一堆，用时找不到 | 第 2 章的信息筛选与知识管理 |
| 学了很多却用不出来 | 第 1 章的认知觉醒 + 第 3 章的方法论沉淀 |

---

## 3. 适合谁读

- 在校学生、应届生
- 职场 0-3 年，感觉"学不动了"的新人
- 想重建学习体系的终身学习者

## 5. 与另两卷的关系

```text
卷一 学习（修己）  →  卷二 成事（立功）  →  卷三 立言（传世）
     学得会                做得到                说得清
```

三卷是「**输入 → 输出 → 放大**」的能力闭环。本卷解决"输入"，但**可以独立阅读**——你不需要先读卷二、卷三，也不需要先读完本卷才能读它们。
