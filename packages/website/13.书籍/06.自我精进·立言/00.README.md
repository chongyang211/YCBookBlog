# 卷三 · 自我精进 · 立言

> **说得清的表达力与思维力修炼**

---

## 1. 本卷定位

系列贯穿语是「**学得会，做得到，说得清**」，本卷负责最后一环——**说得清**，并把能力放大出去。

---

## 2. 为什么叫「立言」

**「立言」= 内在思想 + 外在言说**，一个词同时涵盖本卷两块内容：

```text
立言
 ├─ 立（思想）：专注 · 记忆 · 思考 · 质疑 · 情商   → 第 4 章
 └─ 言（言说）：底蕴 · 沟通 · 提问 · 演讲         → 第 1-3 章
```

所以第 4 章的 7 节思维内容**不是跑题，而是「立」的那半边**。这正是本书区别于市面「话术类」表达书的关键——**只教话术的书，读者学完依然说不出有内容的话**。

同时，「立言」出自传统「三不朽」（立德、立功、立言）：

```text
卷一 学习（修己）  →  卷二 成事（立功）  →  卷三 立言（传世）
```

---

## 3. 解决什么问题

| 痛点 | 本卷的解法 |
|------|-----------|
| 肚里有货倒不出 | 第 1-3 章的完整表达链条 |
| 说话没内容、没观点 | 第 4 章的思维地基（思考、质疑） |
| 一上台就紧张 | 第 3 章的公众演讲方法 |
| 表达不得体、接不住话 | 第 2 章的沟通实战（理解、提问） |

---

## 4. 适合谁读

- 技术人（会做但说不清，最典型的痛点人群）
- 需要频繁汇报、述职、演讲的职场人
- 想提升表达与思维底层能力的终身学习者

## 6. 与另两卷的关系

```text
卷一 学习（修己）  →  卷二 成事（立功）  →  卷三 立言（传世）
     学得会                做得到                说得清
```

本卷是能力闭环的最后一环：把内在的能力外化，让价值被看见。三卷按卷序读收获最完整，但**本卷可独立阅读**。
