# 卷二 · 自我精进 · 成事

> **做得到的 25 个目标与做事方法论**

---

## 1. 本卷定位

系列贯穿语是「**学得会，做得到，说得清**」，本卷负责第二环——**做得到**。

很多人学得会，却做不成。会学和会做之间，隔着 25 个具体的方法。本卷按「**事前 → 事中 → 事后**」的做事全流程编排，是一套可反复查阅的工具箱。

---

## 6. 内容质量评估与夯实清单（2026-09-03）

> 依据出版方案第 4 版抽样诊断：本册**内容就绪度 65 / 100**。单册先行投稿的既定策略不变，但投稿前必须解决「汇编感」。

### 优势（保持）

- **「事前 → 事中 → 事后」全流程闭环**，三册中结构最顺，25 法作为「工具箱」检索价值高
- **单节案例范本已有**：2.4 SMART 的「三次打回 + 11 处红批注 + Leader 便签」是全套书「事故案例」的标准写法

### 短板（补齐）

- **最大风险：汇编感**——SMART / OKR / SWOT / MECE / PDCA / 六顶帽 / 金字塔……每个方法单讲都拼不过原典，全书像「经典方法论百科」。开篇已立「做事链路四断点」框架，但正文里隐身了，25 法仍是散装的
- **P1 遗留未做**：SMART 与 1.2 高度重复、PDCA 前讲重复、复盘时长 4 套数值未统一、「跳一跳」比喻多处出现
- **技术场景浓度不稳**：SMART 节有 K8s / CKA（好），但不少方法换成任何职业都成立

### 夯实清单（✅ = 已完成）

- [ ] **去重（既定 P1）**：SMART 三讲压缩为「详见 2.4」、PDCA 前讲指向 3.1、复盘时长统一为 15 分钟、「跳一跳」只留 2.4 一处
- [ ] **断点框架贯穿**：把开篇的「做事链路四断点」做成每章开头的自测表——25 法不再是 25 个平行工具，而是「断在哪 → 用哪个」的处方（验收：任意一节 30 秒内可知治哪个断点）
- [ ] **每法一个事故案例**：25 个方法，每个都长在一个作者亲历的具体事故上（SMART 三次打回是范本），消灭「我有个朋友」式模糊案例
- [ ] **技术场景浓度**：每节至少一个技术案例（重构翻车 / 排障 / 述职 / 跨部门拉通 / 技术选型）
- [ ] **图瘦身**：每节图 ≤ 2 张，罗列型图降级为表格

## 7. 出版级质量标准

本册所有正文均以 [2.4 SMART 目标设定](./02.事前谋划/04.SMART目标设定.md)（「三次打回 + 11 处红批注 + Leader 便签」）与卷一 [1.2 需求层次的模型](../04.自我精进·学习/02.认知觉醒/02.需求层次的模型.md) 为标杆样板。开篇必是数据化真实事故案例，写清人、时、地、数——如「三次打回」「11 处红批注」——而不是「我有个朋友」式的模糊叙事。方法讲解段后两百字内必须接作者亲历事故，25 法每一法都要长在一个具体事故上。

每节 mermaid 控制在两张以内且必须承载因果或流程，罗列型图（把文字搬进方框、无信息增量的）一律删除或降级为表格。少用 `- ` 列表与 `> ` 引用，用流畅段落 + `**bold**` 强调；凡列表超过 5 项即改写为段落。每节至少一个技术场景案例，可以是重构翻车、线上排障、跨部门拉通、技术选型或述职答辩。

结尾五段式必备：总结回顾三件事、后来发生的改变、今天起改变三点、课后作业思考、下一站过渡。每章开头须有一张 30 秒可读完的断点自测表，与开篇的「做事链路四断点」直接挂钩——让 25 法不再是 25 个平行工具，而是「断在哪 → 用哪个」的处方。所有小节标题严格控制在 7 字。

## 8. 分阶段优化路线图

**阶段一 · 标杆定型**：本 README 补出版标准，以 2.4 SMART 为范本锁定"每法必有事故案例"的写法。

**阶段二 · 汇编感突围**（本册最重）：先做去重——SMART 三讲压缩为「详见 2.4」、PDCA 前讲指向 3.1、复盘时长统一为 15 分钟、「跳一跳」比喻只留 2.4 一处；随后 25 法每法补作者亲历事故案例；把开篇的「做事链路四断点」做成每章开头自测表，让框架从"隐身"变成"贯穿"。

**阶段三 · 合稿夯实**：与卷一卷三合计补齐 15.7 万字体量，本册就绪度从 65 → 85+；同步准备可先行投稿的样章与作者简介物料。
