# 卷二 · 自我精进 · 成事

> **做得到的 25 个目标与做事方法论**

---

## 1. 本卷定位

系列贯穿语是「**学得会，做得到，说得清**」，本卷负责第二环：**做得到**。

很多人学得会，却做不成。会学和会做之间，隔着 25 个具体的方法。本卷按「**事前 → 事中 → 事后**」的做事全流程编排，是一套可反复查阅的工具箱。

---

## 2. 解决什么问题

| 痛点 | 本卷的解法 |

| 做完就忘，经验留不下来 | 第 4 章的事后复盘 3 法 |

## 3. 适合谁读

- 职场 3-8 年，想从「能干」升级到「靠谱」的人
- 带团队的管理者
- 需要频繁推进项目、跨部门协作的人

## 7. 出版级质量标准

本册所有正文均以 [2.4 SMART 目标设定](./02.事前谋划/04.SMART目标设定.md)（「三次打回 + 11 处红批注 + Leader 便签」）与卷一 [1.2 需求层次的模型](../04.自我精进·学习/02.认知觉醒/02.需求层次的模型.md) 为标杆样板。开篇必是数据化真实事故案例，写清人、时、地、数，如「三次打回」「11 处红批注」，而不是「我有个朋友」式的模糊叙事。方法讲解段后两百字内必须接作者亲历事故，25 法每一法都要长在一个具体事故上。

每节 mermaid 控制在两张以内且必须承载因果或流程，罗列型图（把文字搬进方框、无信息增量的）一律删除或降级为表格。少用 `- ` 列表与 `> ` 引用，用流畅段落 + `**bold**` 强调；凡列表超过 5 项即改写为段落。每节至少一个技术场景案例，可以是重构翻车、线上排障、跨部门拉通、技术选型或述职答辩。

结尾五段式必备：总结回顾三件事、后来发生的改变、今天起改变三点、课后作业思考、下一站过渡。每章开头须有一张 30 秒可读完的断点自测表，与开篇的「做事链路四断点」直接挂钩，让 25 法不再是 25 个平行工具，而是「断在哪 → 用哪个」的处方。所有小节标题严格控制在 7 字。
