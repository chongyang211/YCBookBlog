# 卷二 · 自我精进 · 成事

> **做得到的 25 个目标与做事方法论**

---

## 1. 本卷定位

系列贯穿语是「**学得会，做得到，说得清**」，本卷负责第二环——**做得到**。

很多人学得会，却做不成。会学和会做之间，隔着 25 个具体的方法。本卷按「**事前 → 事中 → 事后**」的做事全流程编排，是一套可反复查阅的工具箱。

---

## 2. 解决什么问题

| 痛点 | 本卷的解法 |
|------|-----------|
| 目标定了却总完不成 | 第 1 章的目标管理 5 法 |
| 动手前不知道怎么谋划 | 第 2 章的事前谋划 9 法 |
| 执行中失控、问题频发 | 第 3 章的事中执行 8 法 |
| 做完就忘，经验留不下来 | 第 4 章的事后复盘 3 法 |

---

## 3. 适合谁读

- 职场 3-8 年，想从"能干"升级到"靠谱"的人
- 带团队的管理者
- 需要频繁推进项目、跨部门协作的人
