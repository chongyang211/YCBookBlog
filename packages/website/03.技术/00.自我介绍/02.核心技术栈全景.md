# 核心技术栈全景

十年积累，深入使用和持续学习的技术体系。

## 编程语言

| 语言 | 深度 | 核心领域 |
| ---- | ---- | -------- |
| C++ | 精通 | 现代 C++11/14/17/20，并发编程（`std::thread` / `jthread` / `shared_mutex` / `std::atomic`），STL 源码，模板元编程，RAII，性能调优 |
| C | 精通 | 指针与内存管理，标准库，NDK 开发，嵌入式裸机编程 |

| Swift / Objective-C | 熟悉 | iOS UIKit，ARC 内存管理，GCD 多线程 |

## 架构与设计

- **面向对象**：SOLID 六大原则，组合优于继承，接口隔离
- **设计模式**：23 种 GoF 模式在 Android / C++ 中的落地实现
- **架构模式**：Clean Architecture，MVVM / MVI，六边形架构，事件驱动（Event Sourcing）
- **数据库**：MySQL InnoDB 索引 / 事务 / 锁机制，Redis 五种结构底层实现与缓存策略
