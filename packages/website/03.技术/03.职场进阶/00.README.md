# 软实力系列

> 技术决定下限，软实力决定上限。

## 一、系列缘起

我写完 `程序员精进路` 讲了怎么把代码写扎实，写完 `产品思考` 讲了怎么把需求想清楚。有读者留言问我：

> "杨老师，我技术不差，产品感也在补，为什么晋升到 P6 就卡住了？"

我盯着这条留言看了很久。因为我自己就卡过。

那年我做完一个技术方案，评审时被总监问："你这个方案要用多少人多少月？为什么值得？换个方案会怎样？" 我卡壳了 30 秒——我知道答案，**但我组织不出来**。

那次评审之后，我用了三年时间补齐六件事：

**写作、演讲、沟通、时间、规划、影响力。**

补完这六件事，我从 P6 到 P8 用了不到四年。回头看，**这六件事才是 P6 到 P8 的真正分水岭**。技术底子只是入场券。

这个系列，就是这三年我踩过的坑和总结的方法。

## 二、六件事的位置

代码功底、产品视角、软实力，三件东西不是并列关系——是**三层放大器**：

```text
                    ┌──────────────────────────┐
                    │    软实力（本系列）        │  ← 放大器 ×10
                    │  让前两层被看到、被信任      │
                    ├──────────────────────────┤
                    │    产品视角（产品思考系列）  │  ← 放大器 ×3
                    │  让代码解决真正的问题        │
                    ├──────────────────────────┤
                    │    技术功底（精进路系列）    │  ← 基座
                    │  让你能做出东西              │
                    └──────────────────────────┘
```

一个只有技术功底的 P5 = 1 分
+ 产品视角 = 3 分
+ 软实力 = 30 分

这就是为什么同样的技术能力，有人一直是"执行"，有人却成了"关键先生"。

## 三、六件事的关系

六件事内部又分为两组：

### 表达三角（对外）

```text
        技术写作
          / \
         /   \
        /     \
    技术演讲──高效沟通
```

写作是"异步的表达"、演讲是"高浓度的表达"、沟通是"日常的表达"——**三者共享同一套底层能力**：结论先行、换位思考、证据支撑。

### 势能三角（对内）

```text
        时间管理
          / \
         /   \
        /     \
    职业规划──影响力建设
```

时间管理决定你**每天的产出密度**、职业规划决定你**每年的方向对不对**、影响力建设决定你**每次成果的传播半径**——三者一起决定了你的势能积累速度。

## 四、六项能力水位表

不同职级对六项能力的要求是不一样的。我把大厂的通用职级映射到这张表：

| 能力 | P5 初级 | P6 骨干 | P7 专家 | P8 高级 |
|:---:|:---:|:---:|:---:|:---:|
| **写作** | 能写清 PR 说明 | 能写方案文档 | 能写跨部门评审文档 | 能写行业级白皮书 |
| **演讲** | 组内周会不紧张 | 全组分享讲清一个话题 | 跨部门/公司大会 | 行业大会主题演讲 |
| **沟通** | 需求能对齐 | 冲突能推动 | 跨角色能斡旋 | 高管能对话 |
| **时间** | 完成自己任务 | 并行 2-3 事项 | 兼顾产出与带人 | 分身有术不失控 |
| **规划** | 明白下一步 | 明白 3 年方向 | 明白职业锚点 | 帮别人做规划 |
| **影响力** | 组内被认可 | 部门内被认可 | 公司内被认可 | 行业内被认可 |

**卡在哪一格，就重点补哪一格。** 这份手册的六章正好对应六列。

## 六、三种阅读路径

不必按顺序读，选一条最贴近你现在困境的路径：

### 路径 A · 新人成长路（P5 → P6，1-3 年经验）

```text
04 时间管理 → 01 技术写作 → 03 高效沟通 → 05 职业规划
```

先解决"每天忙但没产出" → 再解决"能做但说不清" → 再解决"能说但对齐不了" → 最后解决"方向感"。

### 路径 B · 骨干突破路（P6 → P7，3-6 年经验）

```text
01 技术写作 → 02 技术演讲 → 06 技术影响力 → 05 职业规划
```

先解决"文档能被更多人看" → 再解决"评审能过更大的场" → 再解决"影响能出团队" → 最后解决"下一站往哪跳"。

### 路径 C · 高级晋升路（P7 → P8，6 年以上）

```text
05 职业规划 → 03 高效沟通 → 06 技术影响力 → 02 技术演讲
```

先解决"技术锚点" → 再解决"高管对话" → 再解决"行业能见度" → 最后解决"大会级演讲"。

## 八、一句话摘要

如果没时间读完整个系列，先记住六句话：

1. **写作**：结论先行、对比择优、处处为读者省时间。
2. **演讲**：60% 探索过程 + 30% 方法提炼 + 10% 成果——**不是念文档**。
3. **沟通**：切换频道，同一件事对不同角色讲不同的版本。
4. **时间**：管理精力，不是管理时间——高能时段做难事。
5. **规划**：为"成长"跳槽，不为"逃避"跳槽。
6. **影响力**：一砖一瓦垒起来的——每天多写一句文档就是砖。
