# 技术模版

技术方案设计、复盘、分享的标准化模版集合——让每一次技术文档都有章可循。

## 模版速览

| 编号 | 模版 | 适用场景 | 核心价值 |
|------|------|----------|----------|
| 01 | 技术设计文档集 | 方案评审 / 架构设计 | 从需求到落地的完整设计链路 |
| 02 | 技术复盘专项集 | 事故复盘 / 项目总结 | 根因分析 → 改善措施 → 预防机制 |
| 03 | 技术业务分享集 | 组内分享 / 跨团队分享 | 结构化表达，让分享更高效 |
| 04 | 十分钟分享模版 | 周会快速分享 | 短时间讲清楚一个技术点 |
| 05 | 技术标准化实践 | 规范制定 / 流程优化 | 将个人经验沉淀为团队标准 |

## 使用指南

```
设计文档 → 方案落地
    ↓
复盘模版 → 经验沉淀
    ↓
分享模版 → 知识传播
    ↓
标准化   → 团队复用
```

### 什么时候用设计文档？

- 新项目立项，需要技术评审
- 重大重构，需要对齐方案
- 跨团队协作，需要统一接口

### 什么时候用复盘模版？

- 线上事故后，需要根因分析
- 项目上线后，需要经验总结
- 季度回顾，找出可改进点

### 什么时候用分享模版？

- 攻克了一个技术难题
- 学完了一个新技术栈
- 需要向团队推广某个实践

## 核心心法

1. **先套模版再改** - 模版是起点不是终点，根据实际场景灵活调整
2. **写给人看** - 假设读者没有参与你的工作，从背景开始讲
3. **数据说话** - 用指标衡量效果，避免"感觉变快了"
4. **可复制** - 模版的目的是让其他人也能复用你的方法论
5. **持续迭代** - 每次用完后更新模版，让它越来越实用
