# 1.经典高频问题

- OSI与TCP/IP：必问，OSI七层与TCP/IP四层模型，每一层的典型协议与作用。
- TCP三次握手：必问，为什么是三次不是两次/四次，SYN/ACK的含义，SYN Flood攻击与SYN Cookie防御。
- TCP四次挥手：必问，为什么是四次不是三次，TIME_WAIT状态存在的原因（2MSL），CLOSE_WAIT过多的排查思路。
- TCP与UDP：必问，可靠性、连接性、有序性、流控、拥塞控制、使用场景的全面对比。
- TCP可靠传输：序号与确认号、超时重传、快速重传、SACK、流量控制（滑动窗口）、拥塞控制（慢启动、拥塞避免、快重传、快恢复）。
- HTTP协议：必问，HTTP报文结构，GET与POST的区别（幂等、长度、缓存），常见状态码（1xx/2xx/3xx/4xx/5xx）含义。
- HTTP版本演进：HTTP/1.0、1.1、2.0、3.0各自特性（长连接、管道化、多路复用、头部压缩HPACK、QUIC）。
- HTTPS：必问，TLS握手全过程，对称加密与非对称加密结合，证书链验证，为什么HTTPS比HTTP慢。
- DNS解析：必问，递归查询与迭代查询，DNS缓存层级，DNS劫持与HTTPDNS。
- 从输入URL到页面渲染：必问，DNS解析 → TCP连接 → TLS握手 → HTTP请求 → 服务端处理 → HTTP响应 → 浏览器渲染全流程。
- Socket编程：TCP/UDP socket编程流程，accept/connect/bind/listen/send/recv系统调用。
- IO模型：必问，阻塞IO、非阻塞IO、IO多路复用（select/poll/epoll区别）、信号驱动IO、异步IO，Reactor与Proactor模式。
- epoll原理：必问，红黑树+就绪链表的实现，LT与ET模式的区别，为什么epoll比select/poll高效。
- 跨域：同源策略，CORS、JSONP、Nginx反向代理、postMessage等跨域方案，预检请求OPTIONS。
- Cookie与Session：Cookie与Session的区别，SameSite属性，JWT与Session对比，分布式Session如何存储。
- 网络抓包：Charles/Fiddler/Wireshark抓包原理，HTTPS抓包需要安装根证书的原因，证书校验绕过。
- 粘包与拆包：TCP为什么有粘包，解决方案（定长、分隔符、长度字段）。
- 限流与重试：令牌桶与漏桶算法，指数退避重试策略，幂等性设计。

# 2.补充：更多经典常见问题

- TCP状态机：11种状态全景图，主动关闭方TIME_WAIT与被动关闭方CLOSE_WAIT的排查（代码没close还是对端FIN没处理），大量TIME_WAIT的调优（reuse/port_range）。
- 拥塞控制进阶：cwnd与ssthresh的变化过程演算题，BBR算法的思想（与传统基于丢包的对比），流量控制与拥塞控制的区别（接收方窗口 vs 网络容量）。
- TCP keepalive与心跳：为什么应用层要自己做心跳（keepalive默认2小时太长），心跳包的设计（间隔与超时判定），WebSocket的心跳。
- TCP异常场景：拔网线后TCP连接的状态（保活定时器），RST出现的场景（端口未监听/半开连接），TCP半连接队列与全连接队列溢出。
- 滑动窗口细节：发送窗口与接收窗口的关系，零窗口与窗口探测，Nagle算法与延迟确认（为什么小包场景要关闭Nagle）。
- UDP进阶：UDP如何实现可靠传输（KCP/QUIC的思路：重传+确认+序号），UDP适用场景（实时音视频、游戏、DNS）。
- QUIC与HTTP/3：QUIC为什么基于UDP实现，0-RTT握手，连接迁移（换网络不断线），解决队头阻塞。
- HTTPS进阶：TLS1.2与1.3握手的差异（1.3一次往返），对称加密算法选择（AES-GCM/ChaCha20），中间人攻击与证书锁定（SSL Pinning），抓包原理本质。
- HTTP缓存：强缓存与协商缓存的字段与流程（Cache-Control/ETag/Last-Modified），刷新与强制刷新的缓存行为差异。
- JWT深入：JWT三段结构，无法主动失效的解决方案（黑名单/短过期+refresh token），JWT存储位置（localStorage的XSS风险 vs cookie的CSRF）。
- RESTful设计：REST的核心约束，资源命名与HTTP动词规范，幂等性（PUT/DELETE幂等而POST不幂等），RESTful vs RPC风格。
- RPC原理：RPC框架的分层（动态代理+序列化+网络传输+服务发现），HTTP与RPC的对比（传输效率/头开销），gRPC与Protobuf。
- 序列化协议：JSON/XML/Protobuf/MessagePack的体积与性能对比，Protobuf为什么快（二进制+Varint+字段编号），序列化的兼容性设计。
- 负载均衡：四层（LVS）与七层（Nginx）负载均衡的区别，轮询/加权/最小连接/IP哈希算法，健康检查机制。
- CDN原理：CDN的DNS调度（CNAME与智能DNS），边缘节点与回源，静态加速与动态加速，缓存命中率优化。
- 网络分层排障：ping/traceroute/netstat/ss/tcpdump的用法，连接建立慢如何定位（DNS/TCP/TLS哪个阶段慢），502/504的排查思路。
- ARP与局域网：ARP的工作流程与ARP欺骗，MAC地址与IP地址的分工，交换机/路由器/NAT设备的工作层次。
- ICMP：ping的原理（ICMP回显请求与应答），traceroute的TTL递增原理，ICMP与端口号（没有端口概念）。
- IPv4与IPv6：IPv4耗尽与NAT缓解，IPv6的地址结构优势，双栈与隧道过渡方案。
- P2P与NAT穿透：NAT的四种类型，UDP打洞原理，STUN/TURN/ICE（WebRTC连接建立的基础）。
- 分布式理论：CAP三选二的权衡，BASE理论，一致性哈希与虚拟节点（数据分布与扩缩容），分布式锁的三种实现（Redis/数据库/ZK）。
