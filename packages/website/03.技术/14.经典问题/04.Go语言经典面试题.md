# 1.语言基础

### 1.1 核心数据类型

- **slice的底层结构与扩容陷阱**：必问，slice底层结构（指针+len+cap），扩容机制（小于256翻倍、之后约1.25倍增长），slice作为参数传递的影响，切片共享底层数组的陷阱（append与截取）。
- **map的底层结构与并发陷阱**：必问，底层结构（hmap+桶bucket），扩容与渐进式迁移（evacuate），为什么遍历无序，并发读写panic（fatal error不可recover），sync.Map的适用场景（读多写少）。
- **string与[]byte的互转成本**：互转的内存拷贝成本，string的不可变性，拼接的性能（strings.Builder vs +），rune与byte的区别，len(string)返回字节数。
- **map桶结构与扩容的细节**：桶的字段结构（tophash+8个key+8个value+overflow），负载因子6.5的设计，等量扩容（整理碎片）与翻倍扩容，为什么key必须可比较（浮点NaN不可作key）。
- **interface的底层与nil的坑**：必问，iface与eface的区别（有方法集与空接口），类型断言与类型-switch，nil接口与接口持有nil指针的坑（== nil为false的场景），接口的隐式实现。

### 1.2 语法与控制流

- **defer的执行时机与陷阱**：必问，defer的执行顺序（LIFO），defer与return的执行时机，命名返回值与匿名返回值被defer修改的差异，defer的开放编码（open-coded）优化。
- **panic与recover的机制**：panic的传播机制，recover为什么必须在defer中调用，跨goroutine无法recover的问题，panic后的资源清理。
- **init函数与包初始化顺序**：包的初始化顺序（依赖拓扑），init的执行时机与多次导入，全局变量初始化顺序，init与main的先后。
- **error处理的包装与边界**：错误包装errors.Is/As/Unwrap（Go1.13），自定义错误类型，error与panic的使用边界，统一错误码设计。
- **Go泛型的约束与性能**（Go1.18+）：类型参数与约束，any与comparable，泛型函数与泛型结构体，泛型的性能（编译期生成 vs 接口动态派发）。
- **Go语言的常见坑汇总**：for range遍历的变量复用（Go1.22前闭包捕获的坑），slice append共享底层数组，map并发写fatal不可recover，nil map可读不可写，nil slice与空slice的JSON序列化差异（null与[]）。

# 2.并发编程

### 2.1 调度与协程

- **GMP调度模型的工作原理**：必问，G/M/P三者含义，GMP的调度流程，为什么需要P（调度上下文与本地队列），work stealing与hand off机制。
- **goroutine与线程的轻量对比**：goroutine为什么轻量（初始2KB栈+动态扩缩），与内核线程的映射关系（M:N），上下文切换成本对比。
- **GMP进阶的全局与本地队列**：为什么GOMAXPROCS默认等于CPU核数，全局队列与本地队列的配合，netpoller如何让阻塞IO不占用线程，sysmon监控线程的作用（抢占调度）。
- **基于信号的抢占调度原理**：Go1.14前为什么for死循环无法被抢占（GC等不动），基于信号的抢占（SIGURG）原理。

### 2.2 通信与同步

- **channel的底层与使用陷阱**：必问，无缓冲与有缓冲channel的区别，向nil/closed channel发送或接收的行为，channel的底层结构（hchan：环形队列+发送/接收等待队列+锁），channel死锁场景。
- **channel底层hchan的实现细节**：hchan的lock为什么粒度小，发送/接收的快速路径（先看等待队列直接移交），close后等待队列的唤醒顺序，带缓冲的满/空阻塞位置。
- **select多路复用与nil妙用**：多channel的就绪选择，default的非阻塞读写，nil channel在select中的妙用（禁用分支），随机性避免饥饿。
- **sync包的并发原语汇总**：Mutex的两种模式（正常/饥饿），RWMutex的读写锁实现，WaitGroup的Add/Done/Wait顺序问题，Once的实现（双检查+原子），Cond的使用场景。
- **sync.Mutex的两种模式细节**：正常模式的自旋条件，饥饿模式的公平切换（等待超1ms），解锁未加锁的panic，TryLock的语义。
- **context的四种与取消传播**：必问，四种context（WithCancel/WithTimeout/WithDeadline/WithValue），取消的传播机制，为什么context.Value只传请求元数据不传业务参数，context泄漏（未cancel）。
- **原子操作与Go内存模型**：atomic包的CAS/Add/Load/Store，Go的happens-before规则，为什么atomic.Value不能存nil与不同类型。

### 2.3 并发模式

- **五种经典并发模式的实现**：fan-in/fan-out（扇入扇出），worker pool手写，pipeline模式，or-done与超时控制，singleflight防缓存击穿。
- **errgroup的错误收集与取消**：并发子任务的错误收集与取消传播，WaitGroup的errgroup替代方案，SetLimit的并发控制。
- **定时器的泄漏与正确用法**：time.After的内存泄漏（未触发前不会被回收），NewTimer与Reset的正确用法，time.Ticker忘记Stop的泄漏。
- **协程泄漏的场景与排查**：什么场景会泄漏（channel阻塞/goroutine死循环），pprof的goroutineprofile，NumGoroutine监控。

# 3.内存与运行时

- **GC三色标记与写屏障**：必问，三色标记法原理，写屏障的作用（保证标记正确性），混合写屏障的优化，GC触发时机（阈值/定时/手动），STW的阶段。
- **内存对齐与逃逸分析**：struct字段的排列优化（大字段在前），空结构体struct{}为什么占0字节，逃逸分析的判断（go build -gcflags），返回指针/闭包引用/接口导致的逃逸。
- **内存管理与对象池**：tcmalloc思想（mcache/mcentral/mheap），逃逸到堆与栈分配的性能差异，对象池sync.Pool（GC会清空的原理与Put/Get的注意事项）。
- **unsafe与指针的转换规则**：unsafe.Pointer的规则，uintptr与unsafe.Pointer转换的时机限制（GC移动对象），为什么不能存uintptr做中转。
- **runtime包的关键API**：Gosched让出，LockOSThread的场景（GUI/C库调用），NumGoroutine监控协程泄漏，GODEBUG调试参数。

# 4.工程实践与框架

- **性能调优的pprof与benchmark**：pprof的采集与火焰图解读（CPU/heap/goroutine），benchmark的b.N与b.ResetTimer，逃逸+内联分析（-gcflags="-m -m"）。
- **单元测试与竞争检测**：表驱动测试，t.Run子测试，mock与接口设计，TestMain的夹具，go test的竞争检测-race。
- **依赖管理与go module机制**：go module的语义化版本，go.mod与go.sum的作用，最小版本选择（MVS）与npm依赖树的区别，replace与vendor。
- **Web框架Gin与标准库选型**：Gin的路由树（radix tree）原理，中间件的洋葱模型，Echo与标准库net/http的选择，标准库http.ServeMux的1.22增强（方法与路径参数）。
- **微服务与gRPC实践**：gRPC的流式（四种模式），Protobuf定义与生成，服务注册发现（etcd/consul），限流熔断（sentinel）。

# 5.高频手写代码清单

- **并发类的四个手写实现**：手写worker pool（固定goroutine+任务channel），手写fan-in合并多个channel，手写带超时的select请求，手写singleflight。
- **同步类的三个手写实现**：手写简化版Once/Mutex（atomic+CAS实现），手写读写锁思路，手写信号量（channel实现）。
- **数据结构类的三个手写**：手写泛型LRU（map+双向链表），手写线程安全map（分片锁），手写ring buffer。
- **算法类的三个手写场景**：go routine实现并发爬虫（限流+超时+取消），生产者消费者（channel+select+done），交替打印（两个channel乒乓）。
- **工具类的三个手写封装**：手写重试函数（指数退避+context取消），手写并发安全的对象池，手写计时器包装（自动Stop）。
