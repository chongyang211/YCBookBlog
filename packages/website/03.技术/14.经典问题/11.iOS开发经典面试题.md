# 1.内存管理

### 1.1 ARC与引用计数

- **ARC与五种属性修饰符**：必问，ARC与MRC的区别，引用计数如何实现，strong/weak/assign/copy/retain的使用场景与差异，autoreleasepool原理与释放时机。
- **weak自动置nil的底层实现**：必问，weak如何实现自动置nil，SideTable结构，weak_table与weak_entry的哈希存储。

### 1.2 内存布局与排查

- **内存五大区与Tagged Pointer**：栈、堆、全局区、常量区、代码区，Tagged Pointer技术与NSNumber/NSString的小对象优化。
- **循环引用的三种排查工具**：Instruments的Leaks，Xcode Memory Graph，MLeaksFinder的原理（栈堆一致性，pop时检测未释放对象），delegate为什么用weak。
- **僵尸对象与野指针定位**：NSZombieEnabled的原理（释放后对象替换为_Zombie类捕获消息），为什么只能在Debug下用（内存不真正释放），野指针崩溃如何定位（收尸工具/地址复现）。

### 1.3 拷贝与类型

- **深拷贝与浅拷贝的组合规则**：copy与mutableCopy的组合规则，容器类（NSArray/NSDictionary）的深拷贝方法，自定义对象的NSCopying/NSMutableCopying。
- **id与instancetype的区别**：两者的区别（类型检查时机），为什么初始化方法推荐instancetype，instancetype的相关结果类型。

# 2.对象模型与Runtime

### 2.1 对象与类

- **OC对象的本质与isa指针**：对象的本质（struct objc_object），isa指针与Class的关系，isa的位域设计（nonpointer isa）。
- **类对象与元类的继承链**：类对象、元类对象、根元类的继承链，方法调用如何通过isa查找到IMP。

### 2.2 消息机制与Runtime

- **objc_msgSend与消息转发**：必问，objc_msgSend流程，方法缓存cache_t，消息转发三大阶段（动态方法解析、快速转发、完整转发）。
- **Runtime的核心结构与方法交换**：必问，类结构class_rw_t/class_ro_t，方法交换Method Swizzling的使用场景与坑，关联对象objc_setAssociatedObject原理。
- **Runtime的四大应用场景**：字典转模型的原理（runtime遍历属性+KVC），模型自动归档解档，防崩溃方案（方法交换替换NSArray/NSDictionary的越界方法），JsonModel的设计。

### 2.3 Category与通知

- **Category的加载与限制**：Category的加载时机与Extension的区别，为什么不能添加成员变量（运行时已分配内存），+load与+initialize的调用时机与顺序，同名方法覆盖规则，关联对象的内存管理（ObjcAssociation）。
- **NSNotification的派发机制**：通知的实现原理，通知是同步派发还是异步派发（同步），NSNotificationCenter的NotificationQueue如何异步合并，iOS9后不移除通知还会崩溃吗（自动移除但野指针仍需注意）。

# 3.Runloop与事件响应

- **Runloop与线程及六种应用**：必问，Runloop与线程的关系，CFRunLoopMode（default/tracking/common），Runloop在AutoreleasePool、事件响应、手势识别、定时器、CADisplayLink、卡顿检测中的作用。
- **事件响应链与hitTest流程**：必问，hitTest:withEvent:与pointInside:withEvent:的调用流程，First Responder的传递机制。
- **UIView与CALayer的职责划分**：为什么UIView可以响应事件而CALayer不能，隐式动画与显式动画。
- **UIView动画与Core Animation**：UIView动画（块动画的原理是Layer属性动画）与Core Animation的区别，关键帧与转场动画，CADisplayLink驱动的帧动画，属性动画与隐式动画的触发区别。

# 4.Block与属性关键字

- **Block的三种类型与捕获规则**：必问，Block的三种类型（__NSGlobalBlock__/__NSStackBlock__/__NSMallocBlock__），Block对外部变量的捕获规则，__block的原理。
- **Block进阶与循环引用破解**：Block修改基本类型为什么要__block，__block修饰对象在ARC/MRC的差异（ARC下堆拷贝），Block作为方法参数什么情况下栈块（逃逸），循环引用的三种破解（weak-self、weak-strong dance、参数传入）。
- **属性关键字的使用与陷阱**：copy为什么常用于NSString和Block，atomic为什么不能保证线程安全，readonly/readwrite/getter/setter的使用。
- **属性关键字进阶的三个坑**：assign修饰对象崩溃的原因（释放后指针不置nil），copy修饰NSMutableArray变成NSArray的坑，nonnull/nullable/null_unspecified/null_resettable泛型约束。

# 5.多线程

- **GCD的四种队列组合**：GCD同步/异步、串行/并行队列的四种组合，dispatch_once/dispatch_group/dispatch_barrier，@synchronized的实现原理（NSOperation与GCD的取舍见下方专门条目）。
- **GCD进阶的五种实战**：dispatch_barrier读写锁实现多读单写，dispatch_semaphore控制并发数，dispatch_source（定时器/文件监听），GCD定时器与NSTimer对比（RunLoop依赖与精度），_dispatch_main_queue与主线程。
- **并发安全的锁选型对比**：OSSpinLock为什么不安全（优先级反转），os_unfair_lock与pthread_mutex，NSRecursiveLock递归锁，读写锁方案选择。
- **NSOperation与GCD的取舍**：（依赖/取消/KVO观察），自定义Operation需要重写哪些方法（main/isConcurrent/isFinished的KVO通知），队列的最大并发数与挂起恢复。
- **线程安全容器的三种实现**：如何实现线程安全的可变数组（串行队列同步访问/读写锁/栅栏dispatch_barrier），atomic为什么不能保证容器操作安全（只保证属性存取）。

# 6.KVO与KVC

- **KVO的底层原理与坑**：必问，KVO底层原理（isa-swizzling动态生成NSKVONotifying_子类），手动触发KVO，KVO的坑与解决方案，自定义KVO实现。
- **KVC的取值赋值完整流程**：KVC的取值赋值流程，自动装箱拆箱，setValue:forUndefinedKey:的作用。

# 7.渲染与性能优化

- **离屏渲染的触发与规避**：触发场景（圆角、阴影、蒙版、光栅化），如何避免离屏渲染，CoreAnimation的渲染流水线。
- **性能监控体系的建立与排序**：如何建立性能监控体系（线下工具+线上APM），各项优化的优先级如何排序（启动/卡顿/内存/包体积的专项见下方条目）。
- **启动优化进阶与二进制重排**：pre-main阶段（动态库加载/rebase/bind/初始化）如何统计，二进制重排的原理，静态库与动态库对启动的影响，首屏渲染优化。
- **包体积的五种优化手段**：无用资源检测，图片压缩（webp/heic），代码段优化（strip），动态化下发，Asset.car优化。
- **Crash分析与dSYM符号化**：dSYM符号化还原崩溃堆栈，常见崩溃类型（野指针/越界/后台任务超时/OOM），Crash日志的解读与归类，线上崩溃率的治理。
- **UITableView的四个优化点**：Cell高度缓存与预计算，图片异步解码（decode在子线程），离屏渲染的规避，RunLoop空闲时执行渲染任务（CFRunLoopObserver监听kCFRunLoopBeforeWaiting）。
- **图片加载与内存峰值控制**：imageNamed与imageWithContentsOfFile的区别（缓存策略），大图加载如何防OOM（分段解码/降采样），批量图片的内存峰值控制。
- **Instruments四大工具的场景**：Time Profiler/Allocations/Leaks/Core Animation各自用在什么场景，如何用Time Profiler定位卡顿函数。

# 8.网络与WebView

- **网络层设计与证书校验**：AFNetworking的架构（session管理+序列化+可达性），NSURLSession与NSURLConnection的区别，网络层封装（请求派发/缓存/重试/取消），HTTPS证书校验与SSL Pinning。
- **WKWebView与Cookie同步**：WKWebView与UIWebView的对比（进程分离/性能），WKWebView的Cookie同步问题，JS与Native的交互（ScriptMessageHandler与JSExport），离线包方案。

# 9.持久化与音视频

- **七种持久化方案的选型**：plist/UserDefaults/archive/SQLite/CoreData/Realm/WCDB的选型对比，FMDB的线程安全（FMDatabaseQueue），CoreData与SQLite的关系。
- **音视频的渲染与通话基础**：AVPlayer与AVPlayerItem的关系，视频渲染流程（解码→OpenGL/Metal渲染），视频通话（WebRTC）基础，音视频编解码基础概念。

# 10.Swift与SwiftUI

- **Swift基础与三种派发机制**：值类型与引用类型的区别，Optional原理（两层枚举Optional<T>），if let/guard let/可选链的适用差异，协议扩展与默认实现，Swift的派发机制（静态/函数表/消息）。
- **Swift进阶与并发模型**：值类型深拷贝（CoW写时复制），String与NSString的桥接，泛型与关联类型，throws/try?/try!与Result的错误处理，weak与unowned的选择（是否可能为nil），闭包的循环引用（capture list），actor与并发模型，async/await与GCD对比，Swift ARC与OC的差异（桥接/值类型引用计数）。
- **SwiftUI数据流与互操作**：数据流的四种属性包装器（@State/@Binding/@ObservedObject/@EnvironmentObject），body的diff机制，与UIKit的互操作（UIViewRepresentable），性能注意点。

# 11.架构与工程

- **三种架构模式的对比选型**：MVC、MVVM、VIPER的对比，组件化方案（URL Router、Protocol、Target-Action），路由跳转设计。
- **OC与C++混编的场景**：Objective-C++的使用场景，extern "C"的作用，OC对象在C++结构体中的内存管理。
- **包管理与二进制组件化**：CocoaPods与SPM的原理对比（ruby插件 vs 原生集成），Pods的Aggregate Target结构，二进制组件化与速度优化。
- **iOS签名链与描述文件**：iOS的签名链如何工作（Apple根证书→开发者证书→描述文件→App），开发/Ad-Hoc/企业/AppStore四种Provisioning Profile的区别，重签名的原理。
- **沙盒限制与动态库加载**：App沙盒的限制，App Group如何跨App共享数据，.framework与.a的区别，iOS允许加载动态库吗（嵌入式动态库可以）。
- **dyld启动与lazy bind**：dyld在启动时做了什么（加载依赖库/rebase/bind），lazy bind的延迟绑定原理，+load与C++静态构造器的执行时机，main之前的耗时统计。

# 12.高频手写与场景题

- **iOS的四个高频手写**：手写简化版KVO（isa替换+方法转发）、手写delegate防止循环引用、手写多读单写的线程安全容器、用Runtime交换方法防止数组越界崩溃。
- **iOS的四个场景设计题**：设计一个图片加载框架（三级缓存+内存警告处理）、设计一个路由组件（注册/解耦/传参/回退）、设计一个自动埋点方案（hook的方式与时机）、设计启动任务编排框架。
