# 1.经典高频问题

- 内存管理：必问，ARC与MRC的区别，引用计数如何实现，strong/weak/assign/copy/retain的使用场景与差异，autoreleasepool原理与释放时机。
- weak原理：必问，weak如何实现自动置nil，SideTable结构，weak_table与weak_entry的哈希存储。
- OC对象：对象的本质（struct objc_object），isa指针与Class的关系，isa的位域设计（nonpointer isa）。
- 类与元类：类对象、元类对象、根元类的继承链，方法调用如何通过isa查找到IMP。
- 消息机制：必问，objc_msgSend流程，方法缓存cache_t，消息转发三大阶段（动态方法解析、快速转发、完整转发）。
- Runtime：必问，类结构class_rw_t/class_ro_t，方法交换Method Swizzling的使用场景与坑，关联对象objc_setAssociatedObject原理。
- Category：Category的加载时机，Category与Extension的区别，+load与+initialize的调用时机与顺序，同名方法覆盖规则。
- Runloop：必问，Runloop与线程的关系，CFRunLoopMode（default/tracking/common），Runloop在AutoreleasePool、事件响应、手势识别、定时器、CADisplayLink、卡顿检测中的作用。
- 多线程：GCD同步/异步、串行/并行队列的四种组合，dispatch_once/dispatch_group/dispatch_barrier，NSOperation与GCD的对比，@synchronized的实现原理。
- KVO：必问，KVO底层原理（isa-swizzling动态生成NSKVONotifying_子类），手动触发KVO，KVO的坑与解决方案，自定义KVO实现。
- KVC：KVC的取值赋值流程，自动装箱拆箱，setValue:forUndefinedKey:的作用。
- Block：必问，Block的三种类型（__NSGlobalBlock__/__NSStackBlock__/__NSMallocBlock__），Block对外部变量的捕获规则，__block的原理，循环引用与解决。
- 属性关键字：copy为什么常用于NSString和Block，atomic为什么不能保证线程安全，readonly/readwrite/getter/setter的使用。
- 内存五大区：栈、堆、全局区、常量区、代码区，Tagged Pointer技术与NSNumber/NSString的小对象优化。
- UIView与CALayer：UIView与CALayer的职责划分，为什么UIView可以响应事件而CALayer不能，隐式动画与显式动画。
- 事件响应链：必问，hitTest:withEvent:与pointInside:withEvent:的调用流程，First Responder的传递机制。
- 图像渲染：离屏渲染的触发场景（圆角、阴影、蒙版、光栅化），如何避免离屏渲染，CoreAnimation的渲染流水线。
- 性能优化：启动优化（pre-main/main阶段）、卡顿监控（Runloop检测、子线程ping主线程）、内存优化、包体积优化。
- SwiftUI/Swift：值类型与引用类型的区别，Optional原理，协议扩展与默认实现，Swift的派发机制（静态/函数表/消息）。
- 架构设计：MVC、MVVM、VIPER的对比，组件化方案（URL Router、Protocol、Target-Action），路由跳转设计。

# 2.补充：更多经典常见问题

- 属性关键字进阶：assign修饰对象崩溃的原因（释放后指针不置nil），copy修饰NSMutableArray变成NSArray的坑，nonnull/nullable/null_unspecified/null_resettable泛型约束。
- 循环引用排查：Instruments的Leaks，Xcode Memory Graph，MLeaksFinder的原理（栈堆一致性，pop时检测未释放对象），delegate为什么用weak。
- Block进阶：Block修改基本类型为什么要__block，__block修饰对象在ARC/MRC的差异（ARC下堆拷贝），Block作为方法参数什么情况下栈块（逃逸），循环引用的三种破解（weak-self、weak-strong dance、参数传入）。
- GCD进阶：dispatch_barrier读写锁实现多读单写，dispatch_semaphore控制并发数，dispatch_source（定时器/文件监听），GCD定时器与NSTimer对比（RunLoop依赖与精度），_dispatch_main_queue与主线程。
- 并发安全：OSSpinLock为什么不安全（优先级反转），os_unfair_lock与pthread_mutex，NSRecursiveLock递归锁，读写锁方案选择。
- OC与C++混编：Objective-C++的使用场景，extern "C"的作用，OC对象在C++结构体中的内存管理。
- 启动优化进阶：pre-main阶段（动态库加载/rebase/bind/初始化）如何统计，二进制重排的原理，静态库与动态库对启动的影响，首屏渲染优化。
- 包体积优化：无用资源检测，图片压缩（webp/heic），代码段优化（strip），动态化下发，Asset.car优化。
- 深拷贝与浅拷贝：copy与mutableCopy的组合规则，容器类（NSArray/NSDictionary）的深拷贝方法，自定义对象的NSCopying/NSMutableCopying。
- 分类与类扩展深入：Category为什么不能添加成员变量（运行时已分配内存），关联对象的内存管理（ObjcAssociation），Category的+load会全部调用而方法同名覆盖。
- Runtime应用：字典转模型的原理（runtime遍历属性+KVC），模型自动归档解档，防崩溃方案（方法交换替换NSArray/NSDictionary的越界方法），JsonModel的设计。
- 持久化方案：plist/UserDefaults/archive/SQLite/CoreData/Realm/WCDB的选型对比，FMDB的线程安全（FMDatabaseQueue），CoreData与SQLite的关系。
- 网络层设计：AFNetworking的架构（session管理+序列化+可达性）， NSURLSession与NSURLConnection的区别，网络层封装（请求派发/缓存/重试/取消），HTTPS证书校验与SSL Pinning。
- WebView相关：WKWebView与UIWebView的对比（进程分离/性能），WKWebView的Cookie同步问题，JS与Native的交互（ScriptMessageHandler与JSExport），离线包方案。
- 音视频基础：AVPlayer与AVPlayerItem的关系，视频渲染流程（解码→OpenGL/Metal渲染），视频通话（WebRTC）基础，音视频编解码基础概念。
- 动画体系：UIView动画（块动画的原理是Layer属性动画）与Core Animation的区别，关键帧与转场动画，CADisplayLink驱动的帧动画，属性动画与隐式动画的触发区别。
- Swift进阶：值类型与引用类型的深拷贝（CoW写时复制），String与NSString的桥接，weak在Swift中的实现，闭包的循环引用（capture list），actor与并发模型，async/await与GCD对比。
- SwiftUI进阶：数据流的四种属性包装器（@State/@Binding/@ObservedObject/@EnvironmentObject），body的diff机制，与UIKit的互操作（UIViewRepresentable），性能注意点。
- 手写高频：手写简化版KVO（isa替换+方法转发）、手写delegate防止循环引用、手写多读单写的线程安全容器、用Runtime交换方法防止数组越界崩溃。
- 场景设计题：设计一个图片加载框架（三级缓存+内存警告处理）、设计一个路由组件（注册/解耦/传参/回退）、设计一个自动埋点方案（hook的方式与时机）、设计启动任务编排框架。
