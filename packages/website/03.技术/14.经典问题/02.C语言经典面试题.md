# 1.指针与数组

- 指针：必问，指针与数组的区别，指针的指针如何理解，函数指针与指针函数如何区分，野指针与悬空指针的产生原因与规避方法。
- 数组与指针：sizeof(数组) 与 sizeof(指针) 的区别，数组退化为指针的场景，二维数组传参的三种写法。
- 指针数组与数组指针：`int *p[10]` 与 `int (*p)[10]` 的区分方法，函数指针数组的应用（跳转表、状态机）。
- 二级指针的应用：为什么修改一级指针的值要传二级指针，链表头插法为什么要用 `struct Node **`。
- 指针运算：指针加减的含义（按类型大小偏移），void*指针的加减限制，指针相减的前提（同一数组内），指针比较的前提。

# 2.内存管理

- 内存管理：malloc/calloc/realloc/free的区别与使用场景，内存泄漏如何定位，堆栈内存分配差异，内存对齐原理与 #pragma pack 的作用。
- 内存分区：代码区、常量区、全局/静态区、堆、栈的划分依据，局部变量、全局变量、static变量、const变量分别存储在哪个区。
- malloc底层：brk与mmap的分工（小对象走brk、大对象走mmap），ptmalloc的bin设计，为什么频繁malloc/free会碎片化。
- 内存池：为什么需要内存池，简单内存池的设计思路（空闲链表），如何解决内存碎片。
- free与置NULL：free后的指针为什么要置NULL，double free的后果，free栈上内存/未malloc指针会发生什么。
- 内存排查工具：valgrind的使用（memcheck检测泄漏），AddressSanitizer，gdb排查段错误，core dump文件分析。
- 段错误排查：常见原因（空指针、越界、栈溢出、非法free），如何用gdb定位段错误位置。

# 3.关键字与修饰符

- const/volatile/static：const修饰指针的四种写法，volatile在多线程/中断/硬件寄存器中的作用，static修饰变量与函数的可见性与生命周期差异。
- static三大作用：修饰局部变量（延长生命周期）、修饰全局变量/函数（限制文件可见性）的场景题各出一道。
- volatile深入：volatile与原子性的关系（volatile不保证原子性），volatile与锁的配合使用，编译器优化对volatile变量的影响。
- 关键字：typedef与#define的区别，register/auto/extern的含义，sizeof 为何是运算符而不是函数。
- 数据类型字节数：char/short/int/long/long long在32位与64位平台下各占几个字节，指针的字节数由什么决定（地址总线），long在64位Windows（4字节）与Linux（8字节）的差异。
- 优化相关：restrict关键字的含义，编译器-O2优化可能引发的问题，如何防止变量被优化掉。

# 4.结构体与联合体

- 结构体与联合体：struct内存对齐计算，位域的使用，union的底层原理和字节序检测（判断大小端）。
- 深入struct：柔性数组（struct末尾的char data[0]）的用法，struct赋值的效率与陷阱，结构体函数指针模拟面向对象。

# 5.字符串与函数

- 字符串：strcpy/strncpy/memcpy/memmove的区别，为何memmove能处理重叠内存，手写strcpy/strlen要求考虑健壮性。
- 手写函数系列：手写memcpy（考虑内存重叠）、手写atoi（考虑正负号、溢出、非法字符）、手写strcat/strcmp/strstr，这些是笔试高频。
- 函数调用：函数调用栈帧结构（ebp/esp的保存与恢复），参数传递顺序（从右往左压栈），可变参数va_list实现原理，尾递归优化。
- 回调函数：回调函数的设计思想，qsort的comparator使用，回调与函数指针的结合，C语言如何实现多态。
- main函数细节：argc与argv的含义，main的三种标准签名，main返回值的意义，atexit注册退出回调。
- 程序退出方式：exit/_exit/abort/return的区别（是否刷新缓冲区/是否调atexit/是否产生core），main函数之前与之后还能做什么（__attribute__((constructor))/atexit）。
- 递归与栈：递归的本质（每层调用一个栈帧），尾递归为什么可以被编译器优化（复用栈帧），什么情况下栈溢出，如何改写为循环。
- setjmp与longjmp：setjmp/longjmp是什么（C语言的跨函数跳转），解决什么问题（模拟异常处理），与C++异常机制的区别（不执行析构）。

# 6.编译链接与库

- 预处理与编译：预处理、编译、汇编、链接四个阶段分别做了什么，extern "C" 作用，头文件重复包含如何解决（#ifndef / #pragma once）。
- 宏与inline：宏定义的副作用（如 #define MAX(a,b)），do{...}while(0)的作用，宏与 inline 函数的优劣对比。
- 静态库与动态库：静态库与动态库的创建与区别（.a与.so），动态库的加载时机（加载时/运行时），符号查找顺序，dlopen/dlsym的使用。
- 符号与链接：强符号与弱符号，链接时符号未定义/重复定义的错误定位，ELF文件的段结构（.text/.data/.bss/.rodata）。

# 7.系统编程

### 7.1 进程与线程

- 进程与线程：进程与线程的区别，fork的返回值含义（父子进程区分），写时复制COW，孤儿进程与僵尸进程的产生与回收（wait/waitpid）。
- 进程间通信IPC：管道、命名管道FIFO、消息队列、共享内存、信号量、信号、socket的原理与适用场景对比，共享内存为什么要配信号量。
- 锁机制：互斥锁、自旋锁、读写锁、条件变量的使用场景，死锁的四个必要条件与预防，生产者消费者模型手写。

### 7.2 网络与IO编程

- TCP与UDP编程：socket/bind/listen/accept/connect/send/recv的完整流程，UDP如何实现可靠传输，SO_REUSEADDR的作用。
- 多路复用：select/poll/epoll的区别与底层实现，LT与ET模式，epoll为什么高效（红黑树+就绪链表），惊群问题。
- 信号处理：signal与sigaction的区别，信号处理函数中的可重入问题（为什么不能在处理函数里malloc/printf）。

# 8.位运算与字节序

- 位运算：常考题如不用临时变量交换两个数、判断2的幂、统计二进制中1的个数、lowbit用途。
- 大小端：如何判断大小端，网络字节序与主机字节序的转换（htonl/ntohl）。

# 9.文件IO与常见陷阱

- 文件IO：fopen/open的区别，缓冲IO与非缓冲IO，fflush作用，文件读写出错如何定位。
- 常见陷阱：数组越界、缓冲区溢出、整数溢出、有符号/无符号比较陷阱、浮点数精度比较。
- 经典笔试题：判断链表有环（快慢指针）、实现memmove、统计一个数二进制中1的个数、用位运算求绝对值、大小端转换。
