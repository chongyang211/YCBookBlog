# 1.网络基础与模型

- **OSI七层与TCP/IP四层模型**：必问，每一层的典型协议与作用。
- **DNS递归与迭代解析过程**：必问，递归查询与迭代查询，DNS缓存层级，DNS劫持与HTTPDNS。
- **从输入URL到页面渲染全流程**：必问，DNS解析 → TCP连接 → TLS握手 → HTTP请求 → 服务端处理 → HTTP响应 → 浏览器渲染全流程。
- **ARP协议与局域网设备分工**：ARP的工作流程与ARP欺骗，MAC地址与IP地址的分工，交换机/路由器/NAT设备的工作层次。
- **ICMP协议与ping的原理**：ping的原理（ICMP回显请求与应答），traceroute的TTL递增原理，ICMP与端口号（没有端口概念）。
- **IPv4与IPv6的演进过渡**：IPv4耗尽与NAT缓解，IPv6的地址结构优势，双栈与隧道过渡方案。
- **子网掩码与CIDR的计算**：子网掩码的作用（区分网络位与主机位），CIDR表示法（如192.168.1.0/24）如何理解，如何计算两个IP是否在同一网段。

# 2.TCP与UDP

### 2.1 连接管理

- **TCP三次握手的过程与原因**：必问，为什么是三次不是两次/四次，SYN/ACK的含义，SYN Flood攻击与SYN Cookie防御。
- **TCP四次挥手与TIME_WAIT**：必问，为什么是四次不是三次，TIME_WAIT状态存在的原因（2MSL），CLOSE_WAIT过多的排查思路。
- **TCP十一种状态与排查调优**：11种状态全景图，主动关闭方TIME_WAIT与被动关闭方CLOSE_WAIT的排查（代码没close还是对端FIN没处理），大量TIME_WAIT的调优（reuse/port_range）。
- **TCP异常场景的四种判断**：拔网线后TCP连接的状态（保活定时器），RST出现的场景（端口未监听/半开连接），TCP半连接队列与全连接队列溢出。
- **TCP半关闭与shutdown的区别**：半关闭是什么（一方发FIN但仍可收数据），shutdown与close的区别（shutdown只断一个方向/不释放fd），半关闭的应用场景（客户端发完请求继续收响应）。

### 2.2 可靠传输

- **TCP与UDP的全面对比**：必问，可靠性、连接性、有序性、流控、拥塞控制、使用场景的全面对比。
- **TCP可靠传输的六大机制**：序号与确认号、超时重传、快速重传、SACK、流量控制（滑动窗口）、拥塞控制（慢启动、拥塞避免、快重传、快恢复）。
- **拥塞控制进阶与BBR算法**：cwnd与ssthresh的变化过程演算题，BBR算法的思想（与传统基于丢包的对比），流量控制与拥塞控制的区别（接收方窗口 vs 网络容量）。
- **滑动窗口与Nagle算法细节**：发送窗口与接收窗口的关系，零窗口与窗口探测，Nagle算法与延迟确认（为什么小包场景要关闭Nagle）。
- **TCP保活与应用层心跳设计**：为什么应用层要自己做心跳（keepalive默认2小时太长），心跳包的设计（间隔与超时判定）。
- **粘包拆包的原因与解决**：TCP为什么有粘包，解决方案（定长、分隔符、长度字段）。

### 2.3 UDP与现代传输

- **UDP上实现可靠传输的思路**：（KCP/QUIC的思路：重传+确认+序号），UDP适用场景（实时音视频、游戏、DNS）。
- **QUIC协议与HTTP/3设计**：QUIC为什么基于UDP实现，0-RTT握手，连接迁移（换网络不断线），解决队头阻塞。

# 3.HTTP与HTTPS

### 3.1 HTTP协议

- **HTTP报文与状态码详解**：必问，HTTP报文结构，GET与POST的区别（幂等、长度、缓存），常见状态码（1xx/2xx/3xx/4xx/5xx）含义。
- **HTTP四个版本的演进特性**：HTTP/1.0、1.1、2.0、3.0各自特性（长连接、管道化、多路复用、头部压缩HPACK、QUIC）。
- **强缓存与协商缓存的流程**：字段与流程（Cache-Control/ETag/Last-Modified），刷新与强制刷新的缓存行为差异。
- **RESTful设计的核心约束**：REST的核心约束，资源命名与HTTP动词规范，幂等性（PUT/DELETE幂等而POST不幂等），RESTful vs RPC风格。
- **断点续传与分块传输机制**：Range请求头与206 Partial Content如何工作，Accept-Ranges字段，Transfer-Encoding: chunked分块传输的使用场景（流式响应/未知长度）。

### 3.2 HTTPS与加密

- **HTTPS的TLS握手全过程**：必问，对称加密与非对称加密结合，证书链验证，为什么HTTPS比HTTP慢。
- **HTTPS进阶与TLS1.3差异**：TLS1.2与1.3握手的差异（1.3一次往返），对称加密算法选择（AES-GCM/ChaCha20），中间人攻击与证书锁定（SSL Pinning），抓包原理本质。
- **加密算法的基础与选型**：对称（AES/ChaCha20）与非对称（RSA/ECC）的原理与选型，哈希（MD5/SHA256）的特性与用途，数字签名与数字证书的签发验证流程。

# 4.会话认证与Web安全

- **Cookie与Session及JWT对比**：Cookie与Session的区别，SameSite属性，JWT与Session对比，分布式Session如何存储。
- **JWT的结构与失效方案**：JWT三段结构，无法主动失效的解决方案（黑名单/短过期+refresh token），JWT存储位置（localStorage的XSS风险 vs cookie的CSRF）。
- **跨域方案与预检请求机制**：同源策略，CORS、JSONP、Nginx反向代理、postMessage等跨域方案，预检请求OPTIONS。

# 5.网络编程与IO模型

- **Socket编程的系统调用流程**：TCP/UDP socket编程流程，accept/connect/bind/listen/send/recv系统调用。
- **五种IO模型与Reactor模式**：必问，阻塞IO、非阻塞IO、IO多路复用（select/poll/epoll区别）、信号驱动IO、异步IO，Reactor与Proactor模式。
- **epoll的底层实现与两种模式**：必问，红黑树+就绪链表的实现，LT与ET模式的区别，为什么epoll比select/poll高效。
- **C10K到C10M的演进路径**：高并发服务器的演进（多进程→多线程→事件驱动），零拷贝（sendfile/splice）在高并发中的应用。

# 6.分布式与中间件

- **RPC框架的分层与原理**：RPC框架的分层（动态代理+序列化+网络传输+服务发现），HTTP与RPC的对比（传输效率/头开销），gRPC与Protobuf。
- **序列化协议的性能对比**：JSON/XML/Protobuf/MessagePack的体积与性能对比，Protobuf为什么快（二进制+Varint+字段编号），序列化的兼容性设计。
- **四层与七层负载均衡区别**：四层（LVS）与七层（Nginx）负载均衡的区别，轮询/加权/最小连接/IP哈希算法，健康检查机制。
- **CDN的调度与回源机制**：CDN的DNS调度（CNAME与智能DNS），边缘节点与回源，静态加速与动态加速，缓存命中率优化。
- **限流重试与幂等性设计**：令牌桶与漏桶算法，指数退避重试策略，幂等性设计。
- **NAT穿透与P2P连接建立**：NAT的四种类型，UDP打洞原理，STUN/TURN/ICE（WebRTC连接建立的基础）。
- **长短连接选型与弱网优化**：长连接与短连接的选型场景（高频请求/推送用长连接），长连接如何保活与断线重连，移动端弱网优化手段（DNS预解析/连接预热/请求合并/HTTP2/QUIC各自解决什么问题）。
- **CAP理论与分布式锁实现**：CAP三选二的权衡，BASE理论，一致性哈希与虚拟节点（数据分布与扩缩容），分布式锁的三种实现（Redis/数据库/ZK）。

# 7.排障与抓包

- **抓包工具的原理与HTTPS抓包**：Charles/Fiddler/Wireshark抓包原理，HTTPS抓包需要安装根证书的原因，证书校验绕过。
- **网络分层排障的命令与思路**：ping/traceroute/netstat/ss/tcpdump的用法，连接建立慢如何定位（DNS/TCP/TLS哪个阶段慢），502/504的排查思路。
