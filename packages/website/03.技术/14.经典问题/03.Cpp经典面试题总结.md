# 1.面向对象基础

- **C与C++的区别及兼容性**：C++相比C最大的区别（面向对象/泛型/异常），C++新增了哪些特性，C++是否完全兼容C（绝大多数兼容但非100%）。
- **引用与指针的区别与实现**：引用和指针的区别（是否可空/是否可重绑定/是否需解引用），引用底层如何实现（指针常量），可以有空引用吗，能否返回局部变量的引用。
- **函数重载与name mangling**：C++为什么支持重载而C不支持（名字修饰），name mangling的规则，extern "C"解决什么问题（跨语言链接）。
- **友元函数的作用与边界**：friend的作用（访问私有成员），友元是否破坏封装（有限度），友元能否被继承/传递（不能）。
- **面向对象三大特性的实现机制**：封装/继承/多态的C++实现，虚函数表vtable与虚表指针vptr内存布局，多态调用的实际流程。
- **重载重写隐藏的区别与规则**：三者的区别，重载决议的匹配规则，父类同名函数隐藏与using声明，运算符重载的规则与限制。
- **构造析构函数的执行细节**：成员初始化列表的必要性（const/引用成员），初始化顺序与声明顺序一致，析构顺序与构造相反，为什么成员函数中调用虚函数没有多态。
- **对象生命周期与三五法则**：构造/析构顺序，拷贝构造与赋值运算符的区别，三/五法则（Rule of Three/Five）。
- **深拷贝与浅拷贝的陷阱案例**：默认拷贝构造的行为，什么时候必须自定义拷贝构造，浅拷贝导致double free的案例分析。
- **空类与含虚函数类的大小**：空类sizeof为什么是1，含虚函数的类为什么多8字节（虚表指针），静态成员变量是否占对象空间，对齐后的内存计算。

# 2.虚函数与多态底层

- **虚函数与虚析构函数的细节**：必问，虚函数、纯虚函数、虚析构函数的区别，为什么构造函数不能是虚函数、析构函数为什么要声明为虚函数。
- **三种继承方式与菱形继承**：公有/保护/私有继承的访问规则，菱形继承问题与虚继承的解决原理，virtual base class的内存布局。
- **虚函数表与多态调用流程**：虚函数表的存放位置（只读数据段），同一类的多个对象共享vtable，多重继承下的虚表布局，虚函数调用如何通过两次解引用完成。
- **虚析构函数深入与设计**：不写虚析构的内存泄漏场景，protected非虚析构的设计（不可删除的基类），纯虚析构函数的定义。

# 3.内存管理与智能指针

- **new与malloc的区别及原理**：new/delete与malloc/free的区别，new的两步过程（operator new + 构造），placement new，定位new的使用场景。
- **new失败处理与配对规则**：new失败抛异常还是返回nullptr（new(nothrow)），set_new_handler，new[]与delete[]为何要配对。
- **三种智能指针的区别与原理**：必问，unique_ptr/shared_ptr/weak_ptr的区别与使用场景，shared_ptr的引用计数如何线程安全，循环引用如何用weak_ptr解决，手写实现shared_ptr。
- **make_shared的优势与原理**：一次分配对象与控制块，异常安全，与shared_ptr<T>(new T)的对比。

# 4.现代C++特性

### 4.1 移动语义与类型推导

- **左值右值与移动语义原理**：左值引用与右值引用的区别，移动语义与std::move原理，完美转发与std::forward，返回值优化RVO/NRVO。
- **移动语义的细节与陷阱**：std::move只是转换不做移动，被move后的对象状态，五法则（移动构造/移动赋值也要写），noexcept移动与vector扩容优化。
- **auto与decltype的推导规则**：auto的推导规则与模板T一致，decltype(auto)，auto&/auto*/auto&&的区分，结构化绑定。
- **std::function与std::bind的封装**：可调用对象的统一封装，std::bind的占位符，function的性能开销（类型擦除），与函数指针/lambda的选择。

### 4.2 Lambda与模板

- **Lambda的捕获方式与底层实现**：捕获方式（值/引用/mutable/this），Lambda的底层实现（匿名类+operator()），捕获引起的悬空引用。
- **模板特化偏特化与SFINAE**：函数模板与类模板，模板特化与偏特化，SFINAE，模板元编程基础（变长参数与实例化见下方专门条目）。
- **万能引用与引用折叠规则**：T&&万能引用与右值引用的区别（推导语境），引用折叠规则（&& + & = &）。
- **可变参数模板的展开方式**：typename... Args参数包的展开方式（递归展开/折叠表达式），参数包的sizeof...计算。
- **模板实例化与头文件依赖**：为什么模板声明和实现通常放头文件（编译期需要看到完整定义），显式实例化与隐式实例化的区别。
- **if constexpr的编译期裁剪**：编译期分支裁剪，与普通if在模板中的区别，替代tag dispatch的用法。

### 4.3 新标准特性

- **C++11到17的核心特性清单**：auto、decltype、lambda、范围for、nullptr、初始化列表、结构化绑定、std::optional、std::variant等必问。
- **C++17与20的新特性**：折叠表达式，CTAD类模板实参推导，C++20的concepts/coroutines/ranges/spaceship操作符。

# 5.关键字与类型系统

- **四种类型转换的使用与安全性**：const、constexpr、mutable的区别，static_cast/dynamic_cast/const_cast/reinterpret_cast四种转换的使用场景与安全性。
- **const深入与顶层底层const**：const成员函数与mutable配合，const对象只能调用const成员函数，顶层const与底层const的区分。
- **static成员的原理与细节**：静态成员变量必须在类外定义的原因，静态成员函数为什么没有this指针，静态局部变量的线程安全性（C++11保证）。
- **inline的本质与ODR规则**：inline只是对编译器的建议，inline与ODR（单一定义规则），inline函数必须定义在头文件的原因，构造/析构中的隐式代码。

# 6.STL与常用库

- **STL常见容器的底层实现**：vector扩容机制（1.5倍/2倍），map与unordered_map底层实现（红黑树 vs 哈希表），deque的分段连续内存布局，list的双向链表实现。
- **vector的核心细节与惯用法**：push_back的均摊O(1)，reserve与resize的区别，erase-remove惯用法，emplace_back与push_back的区别（原地构造）。
- **map与unordered_map的选型**：有序需求选map，纯查找选unordered_map，unordered_map的哈希冲突与rehash，自定义类型的哈希与相等仿函数。
- **string的SSO与string_view陷阱**：SSO短字符串优化，string的COW为何被废弃，string_view的作用与生命周期陷阱。
- **迭代器失效场景与分类**：迭代器失效场景（vector扩容、map/set erase），五种迭代器分类。
- **algorithm常用算法的底层实现**：sort的底层（内省排序），lower_bound/upper_bound的使用，std::remove与erase的配合，for_each与lambda。

# 7.并发编程

- **C++多线程与内存序总览**：std::thread、std::mutex、std::condition_variable、std::atomic的使用，内存序memory_order六种语义。
- **std::thread的join与detach**：两者的区别，thread析构前必须join/detach否则terminate，jthread的自动join，thread_guard的RAII封装。
- **条件变量的使用与原理**：wait必须用unique_lock的原因，虚假唤醒与谓词，notify_one与notify_all的选择，为什么修改共享变量要加锁。
- **atomic与六种内存序语义**：六种memory_order的使用场景，relaxed/acquire/release/seq_cst的语义，什么时候必须用seq_cst，atomic与mutex的性能对比。
- **线程安全单例的多种实现**：C++11的Meyers单例（局部static），call_once实现，为什么C++11后不需要DCL。
- **future与async的异步编程模型**：std::future/promise/task-based编程，std::async的启动策略（async/deferred），packaged_task的用法。

# 8.异常安全与RAII

- **异常安全级别与RAII思想**：异常安全三个级别（基本/强/不抛），RAII思想，为什么析构函数不要抛异常，noexcept的作用。
- **强异常安全与copy-and-swap**：copy-and-swap惯用法如何实现强异常安全（先拷贝再交换再提交），operator=的异常安全写法。

# 9.编译链接与底层性能

- **ODR规则与符号冲突解决**：一次定义原则（ODR）是什么，符号冲突（重复定义/重复符号）怎么解决，weak symbol的作用。
- **编译器优化与去虚拟化**：编译器常见优化（inline/常量折叠/循环展开/RVO），devirtualization去虚拟化是什么，final关键字的性能作用（阻断派生帮助去虚化）。
- **内存对齐进阶与伪共享**：alignas/alignof的用法，false sharing伪共享是什么（两个线程频繁写的变量落在同一缓存行），如何避免（alignas(64)填充）。

# 10.高频手写代码题

- **四大高频手写类的实现**：手写String类（深拷贝+移动语义+swap），手写shared_ptr/unique_ptr，手写线程安全队列（mutex+condition_variable），实现RAII的锁守卫。
- **单例与线程安全队列的手写**：手写Meyers单例与call_once单例，手写线程安全的std::queue封装（带超时pop）。
