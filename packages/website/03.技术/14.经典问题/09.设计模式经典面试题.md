# 1.经典高频问题

- 单例模式：必问，懒汉/饿汉/双重检查锁/静态内部类/枚举五种实现，为什么DCL需要volatile，如何防止反射和反序列化破坏单例。
- 工厂模式：简单工厂、工厂方法、抽象工厂三者的区别与适用场景，Spring BeanFactory就是典型工厂模式的应用。
- 建造者模式：Builder模式的使用场景（属性多、可选参数多），与工厂模式的区别，典型应用如OkHttpClient.Builder、StringBuilder。
- 原型模式：浅克隆与深克隆的实现，Cloneable接口，clone方法的设计原理。
- 适配器模式：类适配器与对象适配器，使用场景如ListView的Adapter、IO流中的InputStreamReader。
- 装饰器模式：与继承的区别、与代理模式的区别，IO流体系是装饰器模式的典型应用。
- 代理模式：必问，静态代理、JDK动态代理、CGLIB动态代理三者区别，JDK动态代理为什么只能代理接口，InvocationHandler原理。
- 观察者模式：必问，被观察者与观察者的关系，推模型与拉模型，事件总线EventBus、RxJava、LiveData都是观察者模式的应用。
- 策略模式：与状态模式的区别，消除大量if-else的常用手段，Comparator就是典型策略模式。
- 责任链模式：OkHttp的Interceptor链、Android的事件分发、Servlet的Filter链都是责任链模式。
- 模板方法模式：抽象类定义算法骨架，子类实现细节步骤，AQS、AsyncTask都是模板方法的应用。
- 迭代器模式：Iterator接口的设计思想，fail-fast与fail-safe的区别。
- 享元模式：Integer.valueOf的缓存池、String常量池都是享元模式。
- 六大设计原则：单一职责、开闭原则、里氏替换、接口隔离、依赖倒置、迪米特法则，每个原则的含义与代码体现。
- 设计模式的本质：面向接口编程、组合优于继承、封装变化，如何在项目中识别该用哪个模式。

# 2.补充：更多经典常见问题

- 观察者与发布订阅的区别：必问易混点，观察者是直接依赖（Subject持有Observer列表），发布订阅通过事件中心解耦（EventBus/消息队列）。
- 装饰器与代理的区别：意图不同——装饰器增强功能（IO流包装），代理控制访问（延迟加载、权限、远程代理），代码结构几乎一样。
- 策略与状态的区别：策略由客户端主动选择算法，状态由对象内部状态自动切换行为，状态模式通常持有Context引用。
- 单例的线程安全横评：五种实现哪几种天然线程安全，静态内部类如何做到懒加载+线程安全（类初始化锁），Android中的单例（Application/Database）。
- 工厂模式进阶：工厂方法符合开闭原则而简单工厂不满足，DI容器（Spring/Hilt/Koin）本质是工厂+反射+注解的组合。
- 命令模式：将请求封装成对象，支持撤销/重做/排队，典型如文本编辑器的undo、任务队列、Runnable就是命令接口。
- 外观模式：为一堆复杂子系统提供统一入口，如系统的统一API网关、图片加载库的Glide.with().load().into()链式入口。
- 组合模式：树形结构的统一处理（View与ViewGroup、文件与文件夹），与迭代器配合遍历整棵树。
- 桥接模式：将抽象与实现分离（颜色与形状两个维度自由组合），与继承膨胀问题的对比。
- 备忘录模式：保存与恢复对象状态，文本编辑器撤销、游戏存档、Activity的onSaveInstanceState。
- 中介者模式：网状依赖变成星型依赖，聊天室、MVC中的Controller、机场调度塔台。
- 享元进阶：内部状态与外部状态的划分，线程池复用线程、Message对象池（obtain/recycle）都是享元思想。
- 代理进阶场景：远程代理（RPC stub）、虚代理（图片懒加载占位）、保护代理（权限校验）、智能引用代理（引用计数）， Retrofit的动态代理解析注解。
- 模板方法vs策略消除重复：模板靠继承固定骨架，策略靠组合替换算法，组合优于继承时选策略。
- 手写高频题：手写线程安全DCL单例、用策略+工厂重构if-else的案例题、手写简单EventBus（观察者+反射）、用责任链实现敏感词过滤。
- 框架中的模式辨认：OkHttp（责任链+建造者+外观）、Retrofit（动态代理+建造者+适配器）、Glide（享元+责任链）、Spring AOP（动态代理）、Handler（观察者变体+生产者消费者），面试常问「你项目里用了什么模式」。
- 设计原则代码题：违反单一职责的类如何拆分、用开闭原则给结算系统加新支付方式、依赖倒置在MVP/MVVM中的体现。
