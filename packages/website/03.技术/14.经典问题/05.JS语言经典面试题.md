# 1.语言基础

### 1.1 类型与运算

- **JS的数据类型与类型判断**：必问，原始类型与引用类型的区别，typeof、instanceof、Object.prototype.toString的差异，如何精准判断数组。
- **==与===及隐式类型转换规则**：隐式类型转换规则（ToPrimitive），[] == false 为什么是true，null与undefined的区别，NaN的判断。
- **0.1加0.2为何不等于0.3**：IEEE 754双精度的存储原理，大数精度丢失与bigint/decimal解决方案，Number的边界值（MAX_SAFE_INTEGER）。

### 1.2 作用域与原型

- **作用域体系与闭包的原理应用**：必问，函数作用域、块级作用域、词法作用域，闭包的原理与经典应用场景，闭包引起的内存泄漏。
- **变量提升与暂时性死区的原理**：什么是变量提升，函数声明与函数表达式的提升差异（声明整体提升vs只提升变量名），暂时性死区是什么，IIFE立即执行函数的作用（模块化时代是否还有用）。
- **执行上下文与执行栈的机制**：什么是执行上下文与执行栈，变量对象与活动对象的关系，作用域链如何形成。
- **this的四种绑定规则与指向**：（默认/隐式/显式/new），箭头函数this的特殊性，call/apply/bind的区别与手写实现。
- **原型链的查找流程与三要素**：必问，__proto__、prototype、constructor三者关系，原型链查找流程，new的执行过程，instanceof的底层原理。
- **寄生组合式继承与class实现**：寄生组合式继承，ES6 class与extends的底层实现（仍是原型链），super关键字原理。
- **Object.create与new的区别**：（是否执行构造函数），如何用Object.create实现继承，class中的static方法与new.target。
- **ES6及以后的核心新特性**：let/const与var的区别、暂时性死区、解构赋值、Symbol、Proxy/Reflect、Map/Set、迭代器与生成器。
- **深浅拷贝的区别与实现方案**：赋值、浅拷贝、深拷贝的差异，常见深拷贝实现（JSON、递归、structuredClone），循环引用如何处理。
- **前端模块化方案的演进与对比**：CommonJS、AMD、CMD、UMD、ES Module的区别，CommonJS与ESM的差异（同步/异步、值拷贝/引用），循环依赖的处理。

# 2.异步编程

- **事件循环与宏微任务的执行顺序**：必问，宏任务与微任务，事件循环执行顺序，Promise.then、setTimeout、setImmediate、process.nextTick的执行时机。
- **Promise的状态链式与组合方法**：必问，Promise三种状态，链式调用原理，Promise.all/race/allSettled/any的区别，手写Promise符合Promise/A+规范。
- **async与await的底层实现原理**：async/await的底层实现（Generator+Promise），异步代码的错误处理，串行并行执行。
- **Promise并发控制与取消超时方案**：如何实现最大并发数的请求调度器（常见笔试题），如何取消一个Promise（AbortController），Promise超时控制。
- **定时器的问题与动画帧的时机**：setTimeout/setInterval有什么问题（最小间隔限制/后台标签页节流/漂移），requestAnimationFrame的执行时机，requestIdleCallback的用途，如何实现请求重试（指数退避）。
- **经典代码输出题的执行顺序**：涉及变量提升、闭包、this、事件循环的综合输出题，setTimeout与Promise的执行顺序，async函数中return的值类型。

# 3.手写代码系列

- **八种高频手写函数的实现**：手写call/apply/bind、手写new、手写instanceof、手写深拷贝（WeakMap解决循环引用）、手写Promise.all/race、手写防抖节流、手写柯里化、手写sleep函数。
- **防抖与节流的实现与差异**：使用场景（输入搜索、滚动、resize），手写debounce与throttle，leading/trailing的差异。

# 4.浏览器与V8引擎

- **从输入URL到页面渲染的过程**：全流程拆解，重绘与回流，事件委托原理（跨域方案见第5章）。
- **事件捕获冒泡与委托的机制**：事件捕获与冒泡流程，addEventListener第三个参数，stopPropagation与stopImmediatePropagation的区别，事件委托的优劣。
- **事件对象的target与currentTarget**：两者的区别，preventDefault与stopPropagation的分工，passive监听器的意义。
- **DOM操作的性能与优化手段**：原生DOM操作为什么慢（触发回流），DocumentFragment为什么能优化（脱离文档流批量操作），history.pushState/replaceState用在什么场景（SPA路由不刷新）。
- **V8引擎的执行流程与优化机制**：V8执行流程，隐藏类与内联缓存，V8的GC机制（新生代Scavenge、老生代Mark-Sweep/Mark-Compact）。
- **V8垃圾回收与内存泄漏避免**：引用计数与标记清除，V8的分代回收机制，如何避免内存泄漏（全局变量、闭包、DOM引用、定时器）。
- **浏览器多进程架构的原理**：进程与线程架构（多进程模型），渲染进程的合成线程，requestIdleCallback，浏览器预解析与脚本阻塞。
- **四种前端存储方案的对比选型**：cookie/localStorage/sessionStorage/indexedDB的对比，token存储方案，大数据量存储如何处理。

# 5.网络与安全

- **强缓存与协商缓存的机制流程**：强缓存（Expires/Cache-Control）与协商缓存（Last-Modified/ETag）的流程，from memory cache与from disk cache的区别，缓存策略如何配置。
- **XSS与CSRF的原理和防御**：XSS的类型（存储型/反射型/DOM型）与防御（转义/CSP），CSRF的原理与防御（token/SameSite/Referer校验），点击劫持。
- **跨域的多种解决方案与原理**：CORS预检请求的触发条件与流程，withCredentials，JSONP原理与局限，Nginx反向代理跨域，postMessage通信安全。
- **WebSocket的原理与实时方案对比**：WebSocket与HTTP轮询/长轮询/SSE对比，WebSocket握手过程，WebSocket心跳保活与断线重连设计，fetch与axios的区别（拦截器/取消/兼容性）。
- **前端错误捕获与监控上报方案**：window.onerror与unhandledrejection，try/catch不能捕获异步错误，SourceMap还原线上报错，前端埋点方案。

# 6.性能与高频场景题

- **JS运行时性能的优化手段**：长任务的识别与拆分（time slicing），虚拟列表原理（大数据量渲染），requestAnimationFrame与防抖节流的配合，内存泄漏的排查（首屏/图片/构建层面的优化见前端篇）。
- **滚动加载与懒加载的场景实现**：滚动加载（IntersectionObserver vs scroll监听），图片懒加载实现方案演进，一键回到顶部。
