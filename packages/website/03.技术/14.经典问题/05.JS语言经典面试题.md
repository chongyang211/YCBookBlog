# 1.语言基础

### 1.1 类型与运算

- 数据类型：必问，原始类型与引用类型的区别，typeof、instanceof、Object.prototype.toString的差异，如何精准判断数组。
- ==与===：隐式类型转换规则（ToPrimitive），[] == false 为什么是true，null与undefined的区别，NaN的判断。
- 数值精度：0.1+0.2为什么不等于0.3（IEEE 754双精度），大数精度丢失与bigint/decimal解决方案，Number的边界值（MAX_SAFE_INTEGER）。

### 1.2 作用域与原型

- 作用域与闭包：必问，函数作用域、块级作用域、词法作用域，闭包的原理与经典应用场景，闭包引起的内存泄漏。
- this指向：四种绑定规则（默认/隐式/显式/new），箭头函数this的特殊性，call/apply/bind的区别与手写实现。
- 原型链：必问，__proto__、prototype、constructor三者关系，原型链查找流程，new的执行过程，instanceof的底层原理。
- 继承：寄生组合式继承，ES6 class与extends的底层实现（仍是原型链），super关键字原理。
- ES6+新特性：let/const与var的区别、暂时性死区、解构赋值、Symbol、Proxy/Reflect、Map/Set、迭代器与生成器。
- 深浅拷贝：赋值、浅拷贝、深拷贝的差异，常见深拷贝实现（JSON、递归、structuredClone），循环引用如何处理。
- 模块化：CommonJS、AMD、CMD、UMD、ES Module的区别，CommonJS与ESM的差异（同步/异步、值拷贝/引用），循环依赖的处理。

# 2.异步编程

- 事件循环：必问，宏任务与微任务，事件循环执行顺序，Promise.then、setTimeout、setImmediate、process.nextTick的执行时机。
- Promise：必问，Promise三种状态，链式调用原理，Promise.all/race/allSettled/any的区别，手写Promise符合Promise/A+规范。
- async/await：async/await的底层实现（Generator+Promise），异步代码的错误处理，串行并行执行。
- Promise并发控制：如何实现最大并发数的请求调度器（常见笔试题），如何取消一个Promise（AbortController），Promise超时控制。
- 代码输出题：涉及变量提升、闭包、this、事件循环的综合输出题，setTimeout与Promise的执行顺序，async函数中return的值类型。

# 3.手写代码系列

- 手写系列高频：手写call/apply/bind、手写new、手写instanceof、手写深拷贝（WeakMap解决循环引用）、手写Promise.all/race、手写防抖节流、手写柯里化、手写sleep函数。
- 防抖与节流：使用场景（输入搜索、滚动、resize），手写debounce与throttle，leading/trailing的差异。

# 4.浏览器与V8引擎

- 浏览器相关：从输入URL到页面渲染全过程，重绘与回流，事件委托原理，跨域解决方案（CORS/JSONP/代理）。
- 事件机制深入：事件捕获与冒泡流程，addEventListener第三个参数，stopPropagation与stopImmediatePropagation的区别，事件委托的优劣。
- V8引擎：V8执行流程，隐藏类与内联缓存，V8的GC机制（新生代Scavenge、老生代Mark-Sweep/Mark-Compact）。
- 垃圾回收：引用计数与标记清除，V8的分代回收机制，如何避免内存泄漏（全局变量、闭包、DOM引用、定时器）。
- 浏览器原理：进程与线程架构（多进程模型），渲染进程的合成线程，requestIdleCallback，浏览器预解析与脚本阻塞。
- 前端存储：cookie/localStorage/sessionStorage/indexedDB的对比，token存储方案，大数据量存储如何处理。

# 5.网络与安全

- HTTP缓存：强缓存（Expires/Cache-Control）与协商缓存（Last-Modified/ETag）的流程，from memory cache与from disk cache的区别，缓存策略如何配置。
- 前端安全：XSS的类型（存储型/反射型/DOM型）与防御（转义/CSP），CSRF的原理与防御（token/SameSite/Referer校验），点击劫持。
- 跨域深入：CORS预检请求的触发条件与流程，withCredentials，JSONP原理与局限，Nginx反向代理跨域，postMessage通信安全。
- 网络进阶：WebSocket与HTTP轮询/长轮询/SSE对比，WebSocket握手过程，WebSocket心跳保活与断线重连设计，fetch与axios的区别（拦截器/取消/兼容性）。
- 错误监控：window.onerror与unhandledrejection，try/catch不能捕获异步错误，SourceMap还原线上报错，前端埋点方案。

# 6.框架基础与TypeScript（与前端篇互补）

- 响应式原理：Vue2的Object.defineProperty与Vue3的Proxy对比，依赖收集与派发更新流程，为什么Vue3用Proxy（可以监听新增删除/数组下标）。
- 虚拟DOM与Diff：虚拟DOM的本质与优势，diff算法的同层比较与key的作用，Vue的双端diff与React的fiber架构对比。
- React高频：函数组件与类组件，hooks原理（链表），useState/useEffect/useMemo/useCallback的使用场景，闭包陷阱，受控与非受控组件。
- TypeScript：type与interface的区别，泛型与泛型约束，工具类型（Partial/Pick/Omit/Record/ReturnType），unknown与any的区别，协变与逆变。

# 7.性能与高频场景题

- 性能优化：首屏优化（SSR/骨架屏/预渲染/CDN），图片优化（懒加载/webp/响应式图片srcset），代码分割与tree shaking，虚拟列表原理，requestAnimationFrame与防抖节流的配合。
- 节流进阶与场景题：滚动加载（IntersectionObserver vs scroll监听），图片懒加载实现方案演进，一键回到顶部。
