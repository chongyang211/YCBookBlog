# 1.HTML与CSS经典问题

### 1.1 布局与定位

- 盒模型：标准盒模型与IE盒模型的区别，box-sizing的取值，width是否包含padding与border。
- BFC：必问，BFC的概念与触发条件（overflow/float/position/flex），BFC解决什么问题（margin塌陷、浮动溢出、环绕文字）。
- 布局三件套：flex布局的容器与项目属性（主轴/交叉轴/换行/shrink-basis），grid的行列定义与区域命名，两栏/三栏布局的五种实现（flex/grid/float+BFC/absolute/表格）。
- 定位与层级：position五种取值，absolute相对谁定位，z-index生效条件，层叠上下文的触发（transform/opacity/z-index/FLIP）。
- 居中大全：水平居中、垂直居中、水平垂直居中的多种方案（flex/grid/absolute+transform/absolute+负margin），各自适用场景。
- 布局实战：圣杯布局与双飞翼布局，瀑布流的实现（多列/绝对定位/虚拟化），吸顶与滚动联动，弹窗居中与滚动穿透（body锁滚动）。

### 1.2 移动端与响应式

- 移动端适配：必问，rem/em/vw/vh的区别，flexible方案与viewport适配，1px边框问题的原因与解决，安全区域适配（env(safe-area-inset)）。
- 响应式设计：媒体查询的断点设计，移动优先与桌面优先，picture/srcset响应式图片，容器查询了解即可。

### 1.3 渲染与动画

- CSS3新特性：transition与animation的区别（事件与状态），transform的合成层加速（GPU），will-change的作用与滥用，keyframes的贝塞尔曲线。
- 浏览器渲染：重绘与回流的触发条件与规避（批量修改/文档碎片/脱离文档流），合成层（transform/opacity不触发回流），requestAnimationFrame的时机。
- 选择器与权重：优先级计算规则（inline > id > class > tag），!important的层级，伪类与伪元素的区别，:nth-child与:nth-of-type的差异。

### 1.4 HTML与语义化

- 语义化与无障碍：语义化标签的意义（SEO/可读性/无障碍），alt与aria标签，图片懒加载的loading属性。
- HTML5：history与hash路由对浏览器API的依赖，WebSocket与SSE，Web Worker的适用场景（存储方案对比见JS篇）。

# 2.Vue经典问题

### 2.1 响应式与渲染

- 响应式原理：必问，Vue2的Object.defineProperty与Vue3的Proxy对比，依赖收集与派发更新流程，Vue2数组的七个变异方法与缺陷（新增属性/下标修改）。
- 双向绑定：v-model的本质（:value + @input），组件上的v-model如何自定义（modelValue与update），修饰符（lazy/number/trim）的实现。
- 虚拟DOM与diff：必问，虚拟DOM的优势与本质，diff的同层比较与首尾指针算法（Vue2双端/Vue3最长递增子序列），key的作用与index作key的问题。
- nextTick：为什么修改数据后DOM不是立即更新（异步渲染队列），nextTick的原理（微任务），获取更新后DOM的时机。
- ref与reactive：必问，ref的深层响应与shallowRef，reactive的解构丢失响应问题（toRefs解决），为什么ref需要.value，原始值与对象的包装。

### 2.2 组件与状态

- 组件通信：props/emit，v-model双向，provide/inject，$attrs与$listeners透传，事件总线与状态管理的选择，expose与ref。
- computed与watch：computed的缓存与惰性求值，watch的deep/immediate，watchEffect的自动依赖收集，watch清理副作用（onCleanup）。
- 生命周期：选项式与组合式API的生命周期对照，setup的执行时机，父子组件生命周期顺序（挂载/更新/销毁），keep-alive的activated/deactivated。
- Pinia与Vuex：状态管理的核心思想（单向数据流），Pinia去掉mutation的原因，模块化与组合式store，持久化方案。

### 2.3 生态与优化

- Vue3新特性：组合式API解决了什么（逻辑复用/代码组织），Fragment/Teleport/Suspense，setup语法糖，编译优化（静态提升/patchFlag靶向更新）。
- Vue Router：hash与history模式的实现与优缺点，导航守卫的执行顺序，动态路由与权限路由的两种方案（前端过滤/后端下发），路由懒加载。
- 性能优化：v-if与v-show的选择，v-for的key与避免与v-if同节点，大列表虚拟滚动，组件懒加载与keep-alive缓存，shallowRef处理大对象。

# 3.React经典问题

### 3.1 组件与Hooks

- 函数组件与类组件：两者的差异（this/生命周期/闭包），为什么React主推函数组件（hooks的逻辑复用），类组件的遗留场景。
- Hooks原理：必问，hooks为什么不能写在条件语句里（链表顺序），useState的闭包陷阱与函数式更新，useState与useReducer的选择。
- 副作用：useEffect的依赖数组与执行时机（每次/变化/仅一次），cleanup函数的清理时机，useLayoutEffect与useEffect的先后（同步/异步），严格模式的双调用。
- 性能Hooks：useMemo/useCallback的缓存与引用相等，React.memo的浅比较，什么时候不需要优化（成本大于收益），useTransition与并发渲染。
- 受控与非受控：受控组件的原理与适用，非受控的ref操作，表单库（react-hook-form）的原理。

### 3.2 原理与生态

- Fiber架构：必问，为什么需要Fiber（可中断的渲染），时间切片与优先级调度，双缓冲树（current与workInProgress），reconcile与commit两阶段。
- 合成事件：React合成事件与原生事件的区别，事件委托到root的实现（React17前是document），阻止默认行为与冒泡的坑。
- 状态管理：状态提升与组合，Context的渲染陷阱（value变化导致全量重渲染），Zustand/Redux Toolkit/MobX的选型，服务端状态与客户端状态分离（React Query）。
- 路由：React Router的动态路由与嵌套路由（Outlet），路由守卫的实现，懒加载与Suspense的配合。
- 新特性：Server Components的边界（服务端组件零客户端包），Suspense的异步协调，use的用法，Actions与表单处理。

# 4.工程化与性能优化

### 4.1 构建工具链

- Webpack必问：loader与plugin的区别，构建流程（初始化/编译/输出），Tree Shaking的原理与限制（ESM静态分析），HMR热更新的原理（websocket+模块替换）。
- Vite：为什么快（esbuild预构建+原生ESM按需编译），与Webpack冷启动对比，生产构建为什么用Rollup，插件机制。
- Babel：AST的生成与转换流程，preset与plugin的执行顺序，polyfill与transform-runtime的区别，为什么要配置browserslist。
- Monorepo：pnpm workspace的原理（符号链接），Turborepo/Nx的任务编排与缓存，与multirepo的取舍。
- 规范化：ESLint与Prettier的分工，husky+lint-staged的提交检查，commitlint的提交规范，CI/CD流水线（lint/test/build/deploy）。

### 4.2 性能优化与监控

- 打包优化：代码分割（splitChunks/动态import），体积分析（webpack-bundle-analyzer），按路由懒加载，依赖预构建，gzip/brotli压缩与CDN。
- 首屏优化：必问，SSR/SSG/预渲染的选择，骨架屏与loading，关键CSS内联，图片懒加载与webp，preload/prefetch/preconnect的优先级。
- 性能指标：Core Web Vitals三大指标（LCP/INP/CLS）的定义与优化手段，FCP/TTI，性能预算，Lighthouse的使用。
- 性能监控：PerformanceObserver采集指标，错误的捕获（onerror/unhandledrejection/SourceMap还原），FPS监控（requestAnimationFrame），埋点与上报（sendBeacon）。

### 4.3 微前端

- 微前端：为什么需要微前端（巨石拆分/技术栈无关），qiankun的沙箱机制（快照/Proxy两种），CSS隔离（shadow DOM/scoped），应用间通信。

# 5.Node.js与SSR

- 事件循环差异：Node的事件循环六个阶段（timers/poll/check等），与浏览器事件循环的区别，process.nextTick与setImmediate的顺序。
- 模块与包管理：CommonJS与ESM在Node中的共存与互操作，node_modules的扁平化与幽灵依赖，pnpm的符号链接优势。
- API与框架：Express与Koa的对比（中间件模型：线性回调 vs 洋葱圈），async中间件的错误处理，Nest的IoC思想。
- 流与Buffer：Buffer的内存分配，Stream的四种类型（可读/可写/双工/转换），背压（pipe与highWaterMark），大文件处理的流式方案。
- 进程管理：cluster的原理（主从+端口复用），pm2的负载均衡与守护重启，worker_threads与child_process的选择。
- SSR原理：同构渲染的流程（服务端渲染首屏+客户端注水 hydration），Nuxt/Next的实现思路，SSR的坑（window/document不可用、内存泄漏）。

# 6.跨端与小程序

- 小程序双线程：必问，渲染层与逻辑层分离的架构，为什么这样设计（安全与管控），通信的序列化开销，Skyline渲染引擎的改进。
- 小程序框架对比：Taro与uni-app的多端方案（编译时/运行时），remax的运行时方案原理，选型考量（团队技术栈/性能/生态）。
- 小程序原理：WXS为什么快（运行在渲染层），自定义组件与Component构造器，分包加载与独立分包，分包预下载。
- Hybrid方案：JSBridge的原理（URL拦截/注入API），通信的封装，离线包与热更新机制，原生与H5的能力边界。
- 跨端框架：Flutter的渲染管线（自绘引擎），React Native的Fabric架构与新渲染器，与原生通信的桥接，选型对比（性能/动态性/团队）。
- Electron：主进程与渲染进程的职责，进程间通信（ipcMain/ipcRenderer/preload），安全配置（contextIsolation），包体积优化。

# 7.高频手写与场景题

- 手写系列：手写Vue简易响应式（defineProperty/Proxy两种），手写简化版diff，手写React的useState（链表模拟），手写事件总线mitt，手写深拷贝（见JS篇）。
- 场景设计题：设计一个虚拟列表（固定高度/动态高度两种），设计一个图片懒加载指令（IntersectionObserver），设计一个前端水印方案（MutationObserver防篡改），设计表单动态渲染引擎（schema驱动），设计一个埋点SDK（采集/批量上报/失败重试）。
- 调试与排查：白屏问题排查思路（资源加载/JS错误/渲染），内存泄漏排查（Memory面板/对比堆快照），长任务定位（Performance面板），请求失败的降级方案。
- 综合场景：大文件上传（分片/断点续传/并发控制/hash校验），实时协作的思路（OT/CRDT概念），扫码登录的轮询与长连接切换，列表的乐观更新与回滚。
