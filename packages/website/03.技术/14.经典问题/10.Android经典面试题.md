# 1.经典高频问题

- 崩溃专题：崩溃治理，崩溃监听，崩溃原理，以及捕获崩溃异常。崩溃降级。
- ANR专题：ANR原理，信息收集，分析，监控，治理。造成ANR原因有哪些，如何解决的？
- 卡顿专题：卡顿原因，卡顿监控，卡顿治理，说一下卡顿治理的优化措施。如何监控渲染卡顿？
- 网络专题：网络优化，弱网，监控。如何抓包，放抓包处理等等，避免网络拦截
- 内存专题：内存监控，内存治理，内存如何分配。内存泄漏怎么排查，平常有做过哪些内存优化相关的工作？
- 启动专题：启动优化，页面打开优化，统计耗时。App启动过程有哪些优化？
- 稳定性专题：稳定性优化，做了那些稳定性工作，产生那些业绩，hook疑难问题解决？
- 安全专题：安全防御，挂载，xposed的工作原理。如何防抓包？涉及到抓包原理是什么？
- 图片专题：图片优化，大图检测，大图加载，图片加载流程，如何减少图片占用内存，图片圆角处理
- OOM专题：OOM是如何产生，OOM场景，OOM如何优化，OOM排查思路，OOM是如何监控
- FPS专题：通过invalidate说一下屏幕刷新机制？什么是流畅度？说一下Choreographer作用，VSYNC信号理解？FPS监控设计如何做？
- UI优化：布局检测工具有哪些？如何统计布局的损耗？源码如何加载xml布局？布局卡顿优化
- 进程专题：系统为什么会杀掉进程？进程回收优先级？app切换到后台后为什么容易被杀死？系统杀的为什么是我的进程，这是按照什么标准来选择的？
- 线程专题：如何做线程优化？如何统一线程调用？有哪些可以做异步任务的方式？线程CPU排查，线程卡顿。
- IPC专题：跨进程通信方案，AIDL是如何实现的？如何理解死亡代理，Binder机制，Binder流程原理。
- 组件化：module A 和 module B 之间有需要调用 Api 这块怎么解决的？module A 和 module B 之间如何通讯？
- Activity专题：必问，Activity生命周期，启动模式（standard/singleTop/singleTask/singleInstance），onSaveInstanceState触发时机，Activity启动流程（AMS/ActivityThread）。
- Fragment专题：Fragment生命周期，add/replace/show/hide区别，Fragment通信方式（接口/ViewModel/FragmentResult API），多Fragment嵌套管理。
- Handler机制：必问，Handler/Looper/MessageQueue/Message四者关系，主线程为什么不需要手动prepare Looper，MessageQueue的延迟消息如何实现，HandlerThread与IntentService原理。
- View绘制流程：必问，measure/layout/draw三大流程，MeasureSpec三种模式，自定义View的三种方式，事件分发的dispatchTouchEvent/onInterceptTouchEvent/onTouchEvent。
- Binder机制：必问，Binder驱动原理，一次拷贝的mmap实现，ServiceManager作用，AIDL生成代码分析。
- 热修复与插件化：类加载热修复（Tinker）、Native热修复（AndFix）原理对比，插件化DexClassLoader与资源加载解决方案。
- Jetpack：Lifecycle原理、LiveData原理（观察者+生命周期感知）、ViewModel如何跨配置变更存活、Room、WorkManager、Navigation。
- Kotlin协程：协程与线程区别，挂起函数原理（CPS变换+状态机），CoroutineScope/Job/Dispatchers，Flow与RxJava对比。

# 2.补充：更多经典常见问题

- 四大组件：Activity/Service/BroadcastReceiver/ContentProvider的作用与启动方式，四大组件的注册与声明，隐式Intent与显式Intent。
- Service深入：startService与bindService的区别，Service与IntentService，前台Service与后台限制（Android 8.0+），Service保活方案与局限。
- 广播机制：普通广播/有序广播/本地广播，动态注册与静态注册的时机与差异（Android 8.0 静态广播限制），广播的安全性。
- ContentProvider：ContentProvider的启动与共享原理，URI结构，和 Binder 的关系，ContentProvider何时初始化（Application之后/首进程）。
- Context：Context的种类（Application/Activity/Service），不同Context能做什么（show Dialog/启动Activity），Context内存泄漏场景。
- 启动流程深入：App启动流程（Launcher → AMS → Zygote fork → ActivityThread → onCreate），冷启动与热启动，启动器的字节码优化（baseline profile）。
- apk打包流程：aapt资源打包 → javac → dex → 打包签名（v1/v2/v3签名差异），V2签名为什么更安全（全文件校验）。
- ClassLoader：DexClassLoader与PathClassLoader的区别，Android的双亲委派与打破（热修复），class文件与dex文件差异。
- Dalvik与ART：ART的AOT/JIT混合编译，dexopt与dex2oat，64K方法数限制与multidex原理。
- RecyclerView必问：四级缓存（ scrap/cache/RecycledViewPool)，与ListView对比，LayoutManager与ItemDecoration，DiffUtil的差量更新，预取机制。
- 事件分发深入：滑动冲突的三种场景与解决（外部拦截法/内部拦截法），requestDisallowInterceptTouchEvent，onTouch与onTouchEvent的优先级。
- RecyclerView/ListView卡顿：布局层级优化（ConstraintLayout/merge/ViewStub），过度绘制检测（GPU过度绘制），bindViewHolder中的耗时优化。
- OkHttp必问：拦截器责任链（应用/网络拦截器区别），连接池复用与keepalive，重试与重定向，DNS解析，如何自定义拦截器加签名。
- Retrofit原理：动态代理解析注解生成请求，与OkHttp的关系，ConverterAdapter与CallAdapter的设计， suspend函数如何适配（KotlinExtensions）。
- Glide必问：三级缓存（活动资源/内存/LRU磁盘），生命周期的感知（RequestManager与Fragment），Bitmap的池化（LruBitmapPool），大图加载（subsampling）。
- 图片内存计算：Bitmap内存 = 宽×高×每个像素字节数，RGB_565与ARGB_8888，inSampleSize采样，为什么同一图片不同dpi设备占用不同。
- 数据持久化：SQLite与Room，SharedPreferences的缺点（全量读取/IO），MMKV的原理（mmap），DataStore的协程化，GreenDao/WCDB。
- Jetpack Compose：声明式UI与命令式UI的区别，重组与副作用（remember/derivedStateOf），Modifier链的原理，与Flutter渲染对比。
- 架构模式：MVC/MVP/MVVM/MVI的演进与数据流向，ViewModel与DataBinding的配合，单向数据流的理解，组件化架构（ARouter的原理：路由表+反射/映射）。
- Kotlin高频：空安全与let/run/apply/also/with的作用域函数，扩展函数原理（静态方法），密封类与枚举，内联函数（inline与reified），委托（by lazy原理），协程作用域的取消传播。
- Gradle构建：build生命周期，task依赖，transform API废弃后的字节码注入（AGP 8），插件与模块化配置。
- 性能工具：Systrace/Perfetto的解读，LeakCanary原理（WeakReference+引用队列），Matrix的卡顿监控原理，线上APM方案。
- 手写高频：手写Handler的简化版（Message/Looper/MessageQueue），手写事件分发伪代码，手写RecyclerView的ViewCacheExtension场景，手写一个热修复类加载器的思路。
