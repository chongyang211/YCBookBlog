# 1.四大组件与Application

### 1.1 Activity与Fragment

- **Activity生命周期与启动模式**：必问，Activity生命周期，启动模式（standard/singleTop/singleTask/singleInstance），onSaveInstanceState触发时机，Activity启动流程（AMS/ActivityThread）。
- **Activity回调的细节辨析**：onStart与onResume、onPause与onStop的区别（可见vs前台），onNewIntent的触发时机（singleTop复用）与作用，onSaveInstanceState与onPause的执行顺序，如何避免配置改变时重建（configChanges）。
- **Fragment生命周期与通信方式**：Fragment生命周期，add/replace/show/hide区别，Fragment通信方式（接口/ViewModel/FragmentResult API），多Fragment嵌套管理。
- **Fragment懒加载与常见坑**：Fragment如何做懒加载（setUserVisibleHint/onHiddenChanged的时机与配合），getActivity()为什么有时为null（异步回调时Fragment已销毁），Fragment视图重叠的原因与解决（onSaveInstanceState恢复旧实例）。

### 1.2 Service与广播

- **Service的两种启动与保活**：startService与bindService的区别，Service与IntentService，前台Service与后台限制（Android 8.0+），Service保活方案与局限。
- **广播的种类与注册差异**：普通广播/有序广播/本地广播，动态注册与静态注册的时机与差异（Android 8.0 静态广播限制），广播的安全性。

### 1.3 Provider、Context与启动

- **ContentProvider的启动与共享原理**：URI结构，和 Binder 的关系，ContentProvider何时初始化（Application之后/首进程）。
- **Context的种类与泄漏场景**：Context的种类（Application/Activity/Service），不同Context能做什么（show Dialog/启动Activity），Context内存泄漏场景。
- **App冷启动的完整流程**：（Launcher → AMS → Zygote fork → ActivityThread → onCreate），冷启动与热启动，启动器的字节码优化（baseline profile）。

# 2.Handler与消息机制

- **Handler机制的四件套关系**：必问，Handler/Looper/MessageQueue/Message四者关系，主线程为什么不需要手动prepare Looper，MessageQueue的延迟消息如何实现，HandlerThread与IntentService原理。
- **IdleHandler与同步屏障消息**：IdleHandler的使用场景（延迟初始化），同步屏障如何优先执行异步消息（屏幕刷新的原理）。

# 3.View体系与UI

- **View的三大流程与事件分发**：必问，measure/layout/draw三大流程，MeasureSpec三种模式，自定义View的三种方式，事件分发的dispatchTouchEvent/onInterceptTouchEvent/onTouchEvent。
- **事件分发深入与滑动冲突**：滑动冲突的三种场景与解决（外部拦截法/内部拦截法），requestDisallowInterceptTouchEvent，onTouch与onTouchEvent的优先级。
- **RecyclerView的四级缓存机制**：必问，四级缓存（scrap/cache/RecycledViewPool），与ListView对比，LayoutManager与ItemDecoration，DiffUtil的差量更新，预取机制。
- **UI布局层级与渲染优化**：布局层级优化（ConstraintLayout/merge/ViewStub），布局检测工具与过度绘制检测（GPU过度绘制），如何统计布局的损耗，源码如何加载xml布局，bindViewHolder中的耗时优化。
- **屏幕刷新与FPS监控设计**：通过invalidate说一下屏幕刷新机制？什么是流畅度？说一下Choreographer作用，VSYNC信号理解？FPS监控设计如何做？
- **三种动画体系的区别与原理**：View动画（补间）/帧动画/属性动画的区别，补间动画为什么不能改变事件响应区域（只改绘制不改属性），属性动画如何改变View属性（setX与setTranslationX的区别），插值器与估值器的作用，AnimatorSet的编排。

# 4.虚拟机与构建体系

- **apk打包流程与三种签名**：aapt资源打包 → javac → dex → 打包签名（v1/v2/v3签名差异），V2签名为什么更安全（全文件校验）。
- **Gradle构建与自定义插件**：build生命周期与task依赖，implementation与api的区别（是否传递依赖），从编译到apk的过程有哪些task参与，如何统计编译耗时，transform API废弃后的字节码注入（AGP 8），怎么自定义插件。
- **ClassLoader与双亲委派机制**：DexClassLoader与PathClassLoader的区别，Android的双亲委派与打破（热修复），class文件与dex文件差异。
- **Dalvik与ART的编译差异**：ART的AOT/JIT混合编译，dexopt与dex2oat，64K方法数限制与multidex原理。

# 5.IPC与Binder

- **Binder机制与AIDL实现分析**：必问，Binder驱动原理，一次拷贝的mmap实现，ServiceManager作用，跨进程通信方案选型，AIDL如何实现与生成代码分析，死亡代理的理解。

# 6.网络、数据与WebView

- **网络优化与抓包防抓包**：网络优化，弱网，监控。如何抓包与防抓包（避免网络拦截）。
- **OkHttp的拦截器与连接池**：必问，拦截器责任链（应用/网络拦截器区别），连接池复用与keepalive，重试与重定向，DNS解析，如何自定义拦截器加签名。
- **Retrofit的动态代理原理**：动态代理解析注解生成请求，与OkHttp的关系，ConverterAdapter与CallAdapter的设计，suspend函数如何适配（KotlinExtensions）。
- **五种数据持久化方案对比**：SQLite与Room，SharedPreferences的缺点（全量读取/IO），MMKV的原理（mmap），DataStore的协程化，GreenDao/WCDB。
- **Serializable与Parcelable对比**：两者的区别与原理，Parcelable为什么性能更高（内存序列化vs反射），serialVersionUID的作用，如何简化Parcelable编写（@Parcelize注解）。
- **AsyncTask与HandlerThread异步**：AsyncTask的原理与不足（串行/生命周期），HandlerThread的使用场景（IntentService见第1章Service专题）。
- **WebView混合开发与内存泄漏**：WebView的内核选择与兼容，JS与Native的交互（addJavascriptInterface/JSBridge），WebView的内存泄漏排查，离线包与预加载方案。

# 7.图片与内存

- **图片优化与加载全链路**：图片优化，大图检测，大图加载，图片加载流程，如何减少图片占用内存，图片圆角处理。
- **Glide的缓存与生命周期感知**：必问，三级缓存（活动资源/内存/LRU磁盘），生命周期的感知（RequestManager与Fragment），Bitmap的池化（LruBitmapPool），大图加载（subsampling）。
- **Bitmap的内存计算与采样**：Bitmap内存 = 宽×高×每个像素字节数，RGB_565与ARGB_8888，inSampleSize采样，为什么同一图片不同dpi设备占用不同。
- **内存分配监控与泄漏排查**：内存如何分配，内存监控与治理，内存泄漏怎么排查，你做过哪些内存优化的工作？
- **OOM的产生场景与治理**：OOM是如何产生的，OOM常见场景，OOM如何优化与排查，OOM如何监控。

# 8.性能优化与稳定性

- **崩溃的产生与治理降级**：崩溃的产生原理，崩溃监听与异常捕获，崩溃治理与降级。
- **ANR原理与信息收集分析**：ANR原理，信息收集，分析，监控，治理。造成ANR原因有哪些，如何解决的？
- **卡顿的原因监控与治理**：卡顿原因，卡顿监控，卡顿治理，说一下卡顿治理的优化措施。如何监控渲染卡顿？
- **启动优化与页面打开优化**：统计耗时。App启动过程有哪些优化？
- **稳定性优化的量化收益**：稳定性优化，做了哪些稳定性工作，有哪些量化收益，hook疑难问题解决？
- **线程优化与CPU排查**：如何做线程优化？如何统一线程调用？有哪些可以做异步任务的方式？线程CPU排查，线程卡顿。
- **进程回收优先级与杀死标准**：系统为什么会杀掉进程？进程回收优先级如何排序？app切换到后台后为什么容易被杀死（按什么标准选择牺牲进程）？
- **四大性能工具的原理与解读**：Systrace/Perfetto的解读，LeakCanary原理（WeakReference+引用队列），Matrix的卡顿监控原理，线上APM方案。

# 9.安全与热修复

- **安全防御与Hook框架原理**：安全防御，挂载，xposed的工作原理。如何防抓包？涉及到抓包原理是什么？
- **热修复与插件化的原理**：类加载热修复（Tinker）、Native热修复（AndFix）原理对比，插件化DexClassLoader与资源加载解决方案。

# 10.架构与新技术

- **组件化的跨模块通信方案**：module A 和 module B 之间有需要调用 Api 这块怎么解决的？module A 和 module B 之间如何通讯？
- **四种架构模式的演进对比**：MVC/MVP/MVVM/MVI的演进与数据流向，ViewModel与DataBinding的配合，单向数据流的理解，组件化架构（ARouter的原理：路由表+反射/映射）。
- **Jetpack核心组件的原理**：Lifecycle原理、LiveData原理（观察者+生命周期感知）、ViewModel如何跨配置变更存活、Room、WorkManager、Navigation。
- **LiveData的四个细节陷阱**：连续set两次相同数据收到几次（一次，版本号去重），连续postValue相同数据收到几次（可能丢中间值，mPending标志），LiveData能在子线程接收吗（observe必须在主线程，postValue切线程），粘性事件问题与解决。
- **Jetpack Compose与Flutter对比**：声明式UI与命令式UI的区别，重组与副作用（remember/derivedStateOf），Modifier链的原理，与Flutter渲染对比。
- **Kotlin协程的原理与对比**：协程与线程区别，挂起函数原理（CPS变换+状态机），CoroutineScope/Job/Dispatchers，Flow与RxJava对比。
- **Kotlin高频语法与原理**：空安全与let/run/apply/also/with的作用域函数，扩展函数原理（静态方法），密封类与枚举，内联函数（inline与reified），委托（by lazy原理），协程作用域的取消传播。

# 11.高频手写题
