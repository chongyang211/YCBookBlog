# 1.语言基础

### 1.1 语法与常用类

- **Java八种基本类型及包装类**：8种基本类型与默认值，对应的包装类，Integer缓存池（-128~127）导致==比较的坑，自动装箱拆箱的原理与性能。
- **各数据类型的字节数与取值范围**：int/char/long/double各占多少字节，double强转int为何精度损失（截断非四舍五入），int/long取值范围，数值越界如何处理（BigInteger/溢出前检查）。
- **char能否存储中文汉字与编码**：char型变量能否存储一个中文汉字（可以，Unicode双字节），char两个字节如何存UTF-8字符，Unicode与UTF-8/UTF-16的关系。
- **浮点数二进制表示与精度丢失**：浮点数在二进制中如何表示（IEEE 754），为何0.1+0.2不等于0.3，从存储角度分析精度丢失，Java如何比较浮点数是否相同（误差范围/BigDecimal）。
- **equals与==的区别及hashCode约定**：==比较引用与equals比较内容的本质，为什么重写equals必须同时重写hashCode，不重写hashCode会出什么问题（HashMap丢数据）。
- **String三兄弟的区别与底层原理**：String/StringBuilder/StringBuffer的区别与使用场景，String为什么设计成不可变，字符串常量池与intern()原理，字符串拼接的编译期优化。
- **Object核心方法的设计意图详解**：hashCode/equals/toString/clone/finalize/wait/notify的设计意图，finalize为什么废弃。
- **finally的执行时机与不执行场景**：try里有return时finally还执行吗，什么情况下finally不执行（System.exit/线程被杀），try-with-resources的关闭顺序。
- **Java异常体系与处理机制**：为何设计异常，Error和Exception异常体系，异常处理机制是什么？异常捕获流程？异常性能分析？
- **泛型擦除的理解与哪些会被擦除**：泛型擦除理解。方法，成员变量，方法体里面局部变量，那些会被擦除。
- **反射的原理性能与使用场景**：反射性能问题如何理解，如何提高反射效率，怎么获取泛型类型，反射使用场景和设计思想。
- **注解的分类与运行期框架设计**：注解场景有哪些，分类，注解为何跟反射一起用。编译器和运行期注解框架如何设计？
- **JDK动态代理与CGLIB的区别**：JDK动态代理与CGLIB的实现原理和区别，为什么JDK代理只能基于接口，代理在框架中的应用（Spring AOP、MyBatis Mapper）。
- **Java8及以后版本的新特性**：Lambda与方法引用，Stream流的中间/终止操作与惰性求值，Optional避免NPE，接口default方法，新日期时间API。

### 1.2 面向对象

- **抽象类与接口的区别与选型**：语法差异与选型（模板复用 vs 能力契约），JDK8后接口的default/static/private方法，抽象类能否有构造器，一个类实现多个接口的冲突处理。
- **四种内部类的区别与使用场景**：四种内部类（静态/成员/局部/匿名）的区别与使用场景，匿名内部类访问局部变量为什么必须final（或有效final），Lambda与匿名内部类的区别。
- **重写与重载的规则与匹配优先级**：重写的规则（两同两小一大），重载的匹配优先级，方法hiding（静态方法）的坑。
- **继承与聚合的区别与如何选择**：继承（is-a）与聚合（has-a）的区别与选择，为什么类只能单继承而接口可以多继承。
- **Java是值传递还是引用传递**：Java到底是值传递还是引用传递（只有值传递），方法内修改对象属性外部为何可见，String作为参数为何外部不变。
- **final、finally、finalize的区别**：final/finally/finalize的区别，final修饰类/方法/变量的作用，被final修饰的类能否修改属性（可以），内部类引用外部局部变量为何必须final（有效final）。
- **静态成员的继承重写与初始化顺序**：静态属性和静态方法能否被继承（能）与能否被重写（不能，只能被隐藏），静态块/构造方法/成员初始化的执行顺序。

# 2.集合框架

### 2.1 List与Set

- **Java集合体系的总览与选型**：Collection与Map的体系结构，ArrayList与LinkedList的底层和选型，fail-fast机制，Arrays.asList的坑，集合工具类Collections常见用法。
- **ArrayList的扩容机制与线程安全**：初始容量与1.5倍扩容机制，与Vector的区别，线程安全的List方案（CopyOnWriteArrayList）。
- **LinkedList底层实现与ArrayDeque选型**：底层双向链表实现，与ArrayList在增删查改上的性能差异，能否当作队列和栈使用，LinkedList与ArrayDeque的选型。
- **HashSet与TreeSet的底层实现**：HashSet底层如何实现（基于HashMap的key），如何保证元素不重复（hashCode+equals），TreeSet的有序实现（红黑树）。
- **迭代器安全删除与fail-fast机制**：ConcurrentModificationException的产生原因，遍历中删除的正确姿势（iterator.remove/removeIf/倒序遍历），fail-fast与fail-safe的区别。

### 2.2 Map族

- **HashMap的底层实现与树化条件**：1.7，1.8的差异，1.8中什么情况下转换为红黑树，构造函数中参数代表的意思。
- **HashMap树化阈值为什么是8和6**：为什么链表长度超过8才转红黑树（泊松分布概率），为什么退化阈值是6而不是8（避免在临界点频繁互相转换）。
- **ConcurrentHashMap的演进与原理**：必问，1.7分段锁与1.8 CAS+synchronized的演进，为什么key/value不允许null，size()如何统计，与Hashtable的区别。
- **LinkedHashMap与LRU缓存的实现**：与HashMap的区别（双向链表维护插入/访问顺序），accessOrder模式如何实现LRU缓存。
- **TreeMap红黑树实现与选型**：底层红黑树实现，与AVL树的对比（为什么选红黑树），TreeMap与HashMap的选型（有序遍历/范围查询 vs 纯查找）。

# 3.并发编程

### 3.1 线程基础

- **多线程并发问题与线程安全方式**：多线程并发问题，并发三要素，有哪些保证线程安全的方式。
- **线程的六种状态与生命周期**：NEW/RUNNABLE/BLOCKED/WAITING/TIMED_WAITING/TERMINATED六种状态，sleep与wait的区别，yield/join/interrupt的作用。
- **线程通信的wait与notify机制**：Object的wait和notify。阻塞唤醒，一般会用一个代码或者具体的场景来询问如何保证多线程同步。
- **线程与进程的内存占用关系**：如一个线程占多少内存、一个进程可以开多少线程、一个进程占用多少内存等。如何处理线程异常。

### 3.2 锁与同步

- **Synchronized底层实现与锁升级**：必问，java的锁机制。特别是jdk6之后的锁优化以及运用场景。为什么是重量级的、JVM层如何实现，锁升级和降级。
- **Lock接口与AQS的实现原理**：必问，AQS的原理最好懂。一般会拿来和synchronize比较。具体原理是怎么实现的？
- **synchronized与ReentrantLock对比**：锁实现层面对比，公平锁与非公平锁，可重入原理，Condition.await/signal与wait/notify的区别。
- **volatile的作用与缓存一致性协议**：必问，会拿来和锁比较，他的两个重要作用。更深点会问到cpu缓存一致性协议、以及指令重排的类型与原理。
- **JMM内存模型与happens-before规则**：Java内存模型的主内存与工作内存，原子性/可见性/有序性分别靠什么保证，happens-before八大规则。
- **死锁的产生条件与排查解决**：产生的四个必要条件与预防，如何解决死锁问题，手写一个死锁程序（两个线程互相持有对方需要的锁），thread dump如何生成与分析（jstack/可视化工具），活锁与死锁的区别。
- **各类锁概念的定义与场景对比**：公平锁与非公平锁，乐观锁与悲观锁，互斥锁与读写锁的概念、实现与适用场景对比（偏向/轻量级/重量级锁见Synchronized条目）。
- **经典并发场景题的解决方案**：每秒最多10个线程同时调用第三方接口如何实现（Semaphore限流），T1/T2/T3三个线程如何保证顺序执行（join/CountDownLatch），volatile修饰的int做i++是否线程安全，不用锁如何保证自增安全（AtomicInteger/CAS）。

### 3.3 并发工具

- **CAS原理与原子类的底层实现**：CAS原理与ABA问题及解决方案，AtomicInteger底层，LongAdder与AtomicLong的高并发对比。
- **ThreadLocal的原理与内存泄漏**：底层ThreadLocalMap结构，为什么Key设计成弱引用，内存泄漏的产生与避免，如何正确remove，应用场景（日期工具、链路追踪）。
- **线程池的设计原理与参数设置**：核心设计思想，线程池分类和使用场景，线程池复用问题，execute和submit有何区别，工作队列和阻塞队列如何理解，核心参数如何设置（CPU密集 vs IO密集）。
- **CompletableFuture的异步编排**：Future的局限，thenApply/thenCompose/allOf编排，异步任务异常处理，与线程池的搭配。

# 4.JVM与内存

- **JVM运行时数据区的内存分布**：JVM内存模型、运行时数据区、native内存分布。很看对JVM的理解程度。
- **对象的创建布局与死亡判定**：对象内存布局，对象的创建过程和内存分配情况，如何访问对象（句柄 vs 直接指针），对象如何判断死亡，如何理解方法调用栈帧等。
- **GC的判定算法与回收过程**：（判断对象是否存活，GC算法），垃圾回收机制，GC链路分析过程。
- **JVM分代与主流垃圾回收器**：新生代老年代划分，Minor GC/Full GC触发条件，CMS与G1的区别，G1的Region设计，ZGC了解即可。
- **类加载机制与初始化顺序**：类加载的触发时机，成员初始化顺序，类加载器原理与使用场景（双亲委派见下一条）。
- **双亲委派模型与打破场景**：加载-验证-准备-解析-初始化各阶段做什么，双亲委派的作用与打破场景（SPI、热部署、Tomcat），三种类加载器。
- **JVM线上问题的排查命令与思路**：CPU飙高怎么查（top定位进程→thread -n定位线程→jstack），OOM怎么查（jmap dump→MAT分析），GC频繁怎么定位，常用JVM参数（-Xms/-Xmx/-Xmn/Metaspace）。
- **四种引用类型的特点与用途**：强/软/弱/虚引用的特点与回收时机，为什么需要四种引用（精细化控制生命周期），软引用适合做内存敏感缓存，弱引用与ThreadLocalMap的Key设计，虚引用与引用队列配合回收堆外内存。

# 5.IO与序列化

- **BIO、NIO、AIO的区别与原理**：NIO的Buffer/Channel/Selector三大组件，零拷贝（mmap与sendfile），DirectByteBuffer与堆内Buffer。
- **Java序列化机制与协议对比**：Serializable与Externalizable，serialVersionUID作用，Java序列化与JSON/Protobuf的对比。
- **transient关键字的作用与细节**：transient关键字的作用（不参与序列化），transient与static的区别，反序列化后transient字段的值是什么（默认值）。
- **IO基础概念与File类的使用**：Bit/Byte/char的长度与区别，File类创建目录（mkdir/mkdirs）与判断存在（exists）的方法，同步IO/异步IO/阻塞IO/非阻塞IO的概念。
- **流为什么必须关闭与怎么关闭**：流为什么必须关闭，关闭的位置（finally/try-with-resources），多个流嵌套时的关闭顺序（后开先关），不关闭的后果（句柄泄漏）。

# 6.加解密与编码

> 说明：加密算法在网络协议中的应用（TLS握手、证书链）见《08.网络编程经典面试题》第3.2节，本节聚焦 Java 工程师的加密与编码实操。

- **对称与非对称加密的配合使用**：对称加密（AES/DES）与非对称加密（RSA/ECC）的算法特点与使用场景，如何理解单向加密（哈希不可逆），HTTPS中对称+非对称的配合。
- **MD5的用途与安全增强方案**：用途与应用场景（完整性校验/指纹），如何增强MD5安全性（加盐/双重MD5/换SHA256），MD5算法的大致流程（填充/分组/轮函数）。
- **Base64编码的原理与使用场景**：Base64是加密算法吗（是编码不是加密），哪些场景使用Base64（图片内联/HTTP传二进制/证书），本质是什么（3字节映射4个可见字符），为什么Base64处理的数据有利于多设备传输（全ASCII可见字符）。

# 7.高频代码题

- **高频多线程代码题的写法**：生产者消费者（wait/notify与BlockingQueue两种写法）、两个线程交替打印、手写线程安全的单例（DCL+volatile）、多线程求和。
- **手写LRU缓存的两种实现**：LinkedHashMap实现与手写HashMap+双向链表两种版本，get.put的O(1)设计。
