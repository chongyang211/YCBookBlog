# 1.经典高频问题

- 数组与链表：数组的随机访问O(1)与链表的插入删除O(1)对比，单链表翻转、环形链表判断（快慢指针）、合并两个有序链表必问。
- 栈与队列：用两个栈实现队列、用两个队列实现栈，单调栈经典题（下一个更大元素、柱状图最大矩形），单调队列（滑动窗口最大值）。
- 哈希表：必问，冲突解决（开放寻址、链地址法、再哈希），负载因子，一致性哈希原理，如何设计一个LRU/LFU缓存。
- 字符串：KMP算法next数组原理，Manacher求最长回文子串，字符串匹配算法的时空复杂度对比。
- 二叉树：必问，三种遍历（前中后序）的递归与迭代写法，层序遍历，二叉树的最近公共祖先，二叉树的直径。
- BST/平衡树：BST的插入删除查找，AVL与红黑树的差异（平衡条件），红黑树的应用（HashMap/TreeMap/epoll），B树与B+树的区别及在数据库中的应用。
- 堆：大根堆小根堆的建堆过程，堆排序O(nlogn)，Top K问题的两种解法（堆 vs 快速选择）。
- 图：DFS与BFS，拓扑排序，最短路径（Dijkstra、Floyd、Bellman-Ford），最小生成树（Prim、Kruskal），并查集。
- 排序：必问，快排/归并/堆排/冒泡/插入/选择/希尔/计数/基数/桶排的时空复杂度与稳定性，快排的优化（三数取中、随机化、小区间插排）。
- 递归与回溯：全排列、N皇后、子集、组合总和、括号生成等经典回溯题。
- 动态规划：必问，背包问题（0-1、完全、多重）、最长递增子序列LIS、最长公共子序列LCS、编辑距离、股票问题系列，状态定义与状态转移方程。
- 贪心算法：贪心与动态规划的区别，区间调度、跳跃游戏、分发糖果等经典题。
- 分治：归并排序、快速排序、大整数乘法、最近点对问题。
- 双指针与滑动窗口：对撞指针、快慢指针、滑动窗口的三种经典问题（最长无重复子串、最小覆盖子串、找所有异位词）。
- 位运算：只出现一次的数字、汉明距离、状态压缩DP、位运算实现加法。
- 时间空间复杂度：大O表示法，摊还分析（如vector扩容），空间换时间的典型思路。

# 2.补充：更多经典常见问题

- 数组经典必刷：两数之和（哈希一次遍历）、三数之和（排序+双指针）、移动零、删除有序数组重复项、旋转数组、缺失的数字、多数元素（摩尔投票）、下一个排列。
- 链表经典必刷：反转链表II（区间反转）、K个一组翻转链表、环形链表II（找入环口）、相交链表（双指针互换）、回文链表、重排链表、合并K个有序链表（小根堆）。
- 二分查找系列：标准二分、左边界/右边界模板（while条件与mid偏移），旋转排序数组搜索、寻找峰值、 x的平方根，二分答案（爱吃香蕉的珂珂、运送包裹）。
- 滑动窗口系列：无重复字符的最长子串、长度最小的子数组、最小覆盖子串、滑动窗口最大值（单调队列）、找所有字母异位词。
- 栈的经典题：有效括号、最小栈（辅助栈）、用栈实现队列、每日温度（单调栈）、删除字符串中的所有相邻重复项、字符串解码。
- 二叉树进阶：验证二叉搜索树（中序递增）、锯齿形层序遍历、二叉树的右视图、对称二叉树、路径总和II、二叉搜索树中的众数、树的子结构、从前序与中序遍历构造二叉树。
- 动态规划进阶：爬楼梯、打家劫舍I/II、零钱兑换I/II、分割等和子集（0-1背包）、目标和、最长回文子串、最大子数组和（Kadane）、乘积最大子数组、不同路径I/II、单词拆分、扰乱字符串。
- 回溯必刷：全排列II（去重）、子集II、组合总和II、分割回文串、复原IP地址、电话号码的字母组合、单词搜索。
- 图论进阶：岛屿数量（网格DFS/BFS）、腐烂的橘子（多源BFS）、课程表I/II（拓扑排序）、克隆图、单词接龙（BFS）、冗余连接（并查集）。
- 堆的经典题：前K个高频元素、数组中第K个最大元素、合并K个升序链表、丑数、中位数维护（对顶堆：数据流的中位数）。
- 前缀和与差分：区域和检索（一维/二维前缀和）、和为K的子数组（前缀和+哈希）、航班预订统计（差分）。
- 字典树Trie：实现Trie、单词搜索II、添加与搜索单词、数组中两个数的最大异或值。
- 智力与数学题：只出现一次的数字I/II/III（位运算）、比特位计数、快乐数（快慢指针判环）、阶乘后的零、Pow(x,n)快速幂。
- 高频设计题：LRU缓存（哈希+双向链表）、LFU缓存、设计推特（哈希+堆）、时间Map、常数时间插入删除与获取随机元素（哈希+数组互换删除）。
- 算法思想总结：如何从暴力解优化到最优（一题多解的思路），递归改迭代、记忆化搜索改DP的套路，面试中先讲思路再写代码的沟通技巧。

# 3.高频手写代码清单

- 排序类：手写快速排序（含三数取中优化）、手写归并排序、手写堆排序。
- 链表类：手写单链表反转（迭代与递归）、手写LRU。
- 数据结构类：手写HashMap（简化版：数组+链表+扩容）、手写Trie、手写小根堆。
- 字符串类：手写KMP、手写atoi。
- 动态规划类：手写背包、手写编辑距离的DP表并解释每个格子含义。
