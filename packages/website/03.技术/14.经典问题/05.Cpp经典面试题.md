# 1.经典高频问题

- 面向对象三大特性：封装/继承/多态的C++实现，虚函数表vtable与虚表指针vptr内存布局，多态调用的实际流程。
- 虚函数：必问，虚函数、纯虚函数、虚析构函数的区别，为什么构造函数不能是虚函数、析构函数为什么要声明为虚函数。
- 继承：公有/保护/私有继承的访问规则，菱形继承问题与虚继承的解决原理，virtual base class的内存布局。
- 内存管理：new/delete与malloc/free的区别，new的两步过程（operator new + 构造），placement new，定位new的使用场景。
- 智能指针：必问，unique_ptr/shared_ptr/weak_ptr的区别与使用场景，shared_ptr的引用计数如何线程安全，循环引用如何用weak_ptr解决，手写实现shared_ptr。
- 左值与右值：左值引用与右值引用的区别，移动语义与std::move原理，完美转发与std::forward，返回值优化RVO/NRVO。
- 模板：函数模板与类模板，模板特化与偏特化，SFINAE，变长模板参数，模板元编程基础。
- STL容器：vector扩容机制（1.5倍/2倍），map与unordered_map底层实现（红黑树 vs 哈希表），deque的分段连续内存布局，list的双向链表实现。
- STL迭代器：迭代器失效场景（vector扩容、map/set erase），五种迭代器分类。
- 常量与类型：const、constexpr、mutable的区别，static_cast/dynamic_cast/const_cast/reinterpret_cast四种转换的使用场景与安全性。
- C++11/14/17特性：auto、decltype、lambda、范围for、nullptr、初始化列表、结构化绑定、std::optional、std::variant等必问。
- Lambda：捕获方式（值/引用/mutable/this），Lambda的底层实现（匿名类+operator()）。
- 多线程：std::thread、std::mutex、std::condition_variable、std::atomic的使用，内存序memory_order六种语义。
- 异常：异常安全三个级别（基本/强/不抛），RAII思想，为什么析构函数不要抛异常，noexcept的作用。
- 对象生命周期：构造/析构顺序，拷贝构造与赋值运算符的区别，三/五法则（Rule of Three/Five）。

# 2.补充：更多经典常见问题

- 重载/重写/隐藏：三者的区别，重载决议的匹配规则，父类同名函数隐藏与using声明，运算符重载的规则与限制。
- 深拷贝与浅拷贝：默认拷贝构造的行为，什么时候必须自定义拷贝构造，浅拷贝导致double free的案例分析。
- 空类与对象大小：空类sizeof为什么是1，含虚函数的类为什么多8字节（虚表指针），静态成员变量是否占对象空间，对齐后的内存计算。
- 多态底层细节：虚函数表的存放位置（只读数据段），同一类的多个对象共享vtable，多重继承下的虚表布局，虚函数调用如何通过两次解引用完成。
- 构造/析构函数细节：成员初始化列表的必要性（const/引用成员），初始化顺序与声明顺序一致，析构顺序与构造相反，为什么成员函数中调用虚函数没有多态。
- inline深入：inline只是对编译器的建议，inline与ODR（单一定义规则），inline函数必须定义在头文件的原因，构造/析构中的隐式代码。
- static成员：静态成员变量必须在类外定义的原因，静态成员函数为什么没有this指针，静态局部变量的线程安全性（C++11保证）。
- const深入：const成员函数与mutable配合，const对象只能调用const成员函数，顶层const与底层const的区分。
- new失败与bad_alloc：new失败抛异常还是返回nullptr（new(nothrow)），set_new_handler，new[]与delete[]为何要配对。
- vector核心细节：push_back的均摊O(1)，reserve与resize的区别，erase-remove惯用法，emplace_back与push_back的区别（原地构造）。
- map与unordered_map选型：有序需求选map，纯查找选unordered_map，unordered_map的哈希冲突与rehash，自定义类型的哈希与相等仿函数。
- string实现：SSO短字符串优化，string的COW为何被废弃，string_view的作用与生命周期陷阱。
- 线程安全的单例：C++11的Meyers单例（局部static），call_once实现，为什么C++11后不需要DCL。
- std::thread细节：join与detach的区别，thread析构前必须join/detach否则terminate，jthread的自动join，thread_guard的RAII封装。
- 条件变量：wait必须用unique_lock的原因，虚假唤醒与谓词，notify_one与notify_all的选择，为什么修改共享变量要加锁。
- atomic与内存序：六种memory_order的使用场景，relaxed/acquire/release/seq_cst的语义，什么时候必须用seq_cst，atomic与mutex的性能对比。
- 虚析构函数深入：不写虚析构的内存泄漏场景，protected非虚析构的设计（不可删除的基类），纯虚析构函数的定义。
- 移动语义细节：std::move只是转换不做移动，被move后的对象状态，五法则（移动构造/移动赋值也要写），noexcept移动与vector扩容优化。
- 类型推导：auto的推导规则与模板T一致，decltype(auto)，auto&/auto*/auto&&的区分，结构化绑定。
- C++17/20新特性：if constexpr，折叠表达式，CTAD类模板实参推导，C++20的concepts/coroutines/ranges/spaceship操作符。
- 手写代码题：手写String类（深拷贝+移动语义+swap），手写shared_ptr/unique_ptr，手写线程安全队列（mutex+condition_variable），实现RAII的锁守卫。
