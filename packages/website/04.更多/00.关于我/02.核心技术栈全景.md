# 核心技术栈全景

十年积累，深入使用和持续学习的技术体系。

## 编程语言

| 语言 | 深度 | 核心领域 |
| ---- | ---- | -------- |
| C++ | 精通 | 现代 C++11/14/17/20，并发编程（`std::thread` / `jthread` / `shared_mutex` / `std::atomic`），STL 源码，模板元编程，RAII，性能调优 |
| C | 精通 | 指针与内存管理，标准库，NDK 开发，嵌入式裸机编程 |
| Java | 精通 | JVM 内存模型与 GC，JUC 并发包，集合框架源码，Android Framework |
| Go | 熟练 | Goroutine 调度（GMP 模型），内存模型与 GC，网络编程，标准库设计 |
| Python | 熟练 | 自动化脚本，数据处理，运维工具，AI 辅助开发 |
| JavaScript / TypeScript | 熟悉 | Vue 3 组件开发，Node.js，前端工程化（Webpack / Vite） |
| Swift / Objective-C | 熟悉 | iOS UIKit，ARC 内存管理，GCD 多线程 |

## 底层与系统

| 领域 | 具体技术 |
| ---- | -------- |
| 操作系统 | Linux 进程调度（CFS）、虚拟内存（页表 / TLB / COW）、文件系统（VFS）、信号机制、ELF 可执行文件格式 |
| 网络协议 | TCP/IP 协议栈（三次握手 / 四次挥手 / 拥塞控制），HTTP/2 / HTTP/3，WebSocket，TLS 1.3 |
| 计算机组成 | CPU 流水线、缓存一致性协议（MESI）、内存屏障、原子操作（CAS / LL/SC）、SIMD |
| 编译原理 | GCC / Clang 编译选项，链接器脚本，编译期优化（LTO / PGO），Sanitizer 三件套（ASan / UBSan / TSan） |

| iOS | 熟悉 | Swift / ObjC 混编，RunLoop 与事件分发，GCD 多线程，CoreAnimation 动画框架 |

## 架构与设计

- **面向对象**：SOLID 六大原则，组合优于继承，接口隔离
- **设计模式**：23 种 GoF 模式在 Android / C++ 中的落地实现
- **架构模式**：Clean Architecture，MVVM / MVI，六边形架构，事件驱动（Event Sourcing）
- **数据库**：MySQL InnoDB 索引 / 事务 / 锁机制，Redis 五种结构底层实现与缓存策略
