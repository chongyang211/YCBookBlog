## 摘要

Agent 评测比 LLM 评测难 —— 多步骤、有状态、有工具调用。本文给一套完整的评测方法论：指标体系、追踪工具、自动化回归 —— 让你在灰度前对 Agent 心里有数。

---

## 一、概念篇（30%）

### 1.1 Agent 评测的独特挑战

- 多步骤：错在哪一步？
- 有状态：能复现吗？
- 有工具：工具不稳定怎么办？

### 1.2 Agent 评测的指标体系

- 任务完成率（Task Success Rate）
- 工具调用准确率（Tool Call Accuracy）
- 平均步数（Avg Steps）
- Token 成本（Cost per Task）
- 端到端延迟（E2E Latency）

### 1.3 可观测性三支柱

- Traces：一次任务的完整调用链
- Metrics：聚合指标
- Logs：结构化日志
