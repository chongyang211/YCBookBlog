## 摘要

单 Agent 已能应付 80% 的场景，剩下 20% 需要多 Agent。本文讲清四种协作模式、对比 CrewAI 和 AutoGen 的 API 哲学，并用两套框架实现同一个"内容创作团队"，让你选型有依据。

---

## 一、概念篇（30%）

### 1.1 多 Agent 系统的四种协作模式

- **Pipeline 流水线**：顺序传递
- **Debate 辩论**：多方论证
- **Hierarchical 层级**：Manager 调度 Worker
- **Swarm 自由协作**：无中心涌现

### 1.2 CrewAI vs AutoGen 的哲学差异

- Role-based（CrewAI）
- Conversation-based（AutoGen）
- LangGraph Multi-Agent 的第三条路

### 1.3 多 Agent 的"沟通协议"

- 消息格式
- 角色边界
- 终止条件

## 三、思考篇（20%）

### 3.1 多 Agent 的"沟通税"

- Token 消耗指数级增长
- 一次任务从 $0.5 到 $5 的真实数据

### 3.2 什么时候多 Agent 比单 Agent 强

- 需要角色化专业能力
- 任务能明确切分
- 结果需要多视角审查

### 3.3 什么时候多 Agent 是伪需求

- 单 Agent + Prompt 分段就够了
- 强制多 Agent 只会增加协调开销
