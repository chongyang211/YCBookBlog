## 摘要

**能做什么**：读 API 文档 → 生成用例 → 执行 → 失败分析 → 反思修复。
**技术栈**：Swagger 解析 + pytest + Agent 反思机制
**代码量**：约 1000 行
**对标产品**：Testim、Mabl

---

## 一、这个项目能做什么

- 给一个 OpenAPI YAML，自动产出覆盖正常 / 异常 / 边界的测试代码
- 自动执行并生成报告
- 失败用例自我反思、修正

---

## 二、技术选型与架构

### 架构图

```mermaid
graph LR
    S[OpenAPI] --> P[Parser]
    P --> G[Case Generator]
    G --> E[Executor]
    E -->|失败| R[Reflection]
    R --> G
    E -->|成功| Rep[报告]
```

### 核心 Agent 能力

- Tool：`parse_openapi`
- Tool：`run_pytest`
- Tool：`analyze_failure`
- Tool：`patch_case`（自我修复）
