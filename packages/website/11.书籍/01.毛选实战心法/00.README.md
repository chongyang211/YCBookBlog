# 《毛选实战心法》

把毛选从"政治读物"的标签下解放出来，还原成一套每个普通人都能用、能用得上的硬核思维框架。

**用毛选解真实问题：不是让你"知道这一节讲什么"，而是让你合上书，能在下一次开会、下一次决策、下一次冲突、下一次复盘里切一刀。**

---

## 内容提要

毛选的核心从来不是别的，就是"**实事求是**"四个字：从真实问题出发，摸清客观规律，在实践、认识、再实践的循环里，一步步把问题解决。这不是政治，是解决问题的通用工具；不是大人物的特权，是每个普通人在快速迭代的行业里站稳脚跟的方法论。

全书 54 章不是随机拼凑，而是一套有内在逻辑的"**思维操作系统**"，从哲学根基到行动表层，构成一条完整的知行合一路径：

```
第一篇 毛选阅读总框架  ，  入门：先搭骨架，再填血肉
       ↓
第二篇 哲学思维和基础  ，  根基：矛盾论 / 实践论 / 实事求是 / 群众路线
       ↓
第三篇 战略制定和规划  ，  顶层：战略观 / 规划观 / 资源分配 / 独立自主
       ↓
第四篇 策略执行和实践  ，  落地：解剖麻雀 / 弹钢琴 / 谈判观 / 风险管理
       ↓
第五篇 组织建设的艺术  ，  团队：精兵简政 / 知人善任 / 官兵一致
       ↓
第六篇 个人修养与成长  ，  自我：心态 / 学习 / 自我批评 / 失败观
```

读完这六篇 54 章，你拥有的不是 54 个零散概念，而是一套从思维底层到行动表层的完整作战系统。

### 一条铁规：讲一次 + 用一次

- **讲一次**：用大白话讲给一个不熟悉这个领域的朋友听，他能复述出来，才算懂。
- **用一次**：在下一周的真实场景里强制用一次这一章的方法，能跑出反馈，才算会。

**讲不出来的懂，就是不懂；用不出来的会，就是不会。**

## 附录三 · 本书体例（单章 12 节通用结构）

> 每一章都是一个完整的认知闭环，从真实场景切入，到拿走工具收束。

```
┌─────────────────────────────────────────────────────────────┐
│ ## 01. 一个真实场景                              300-500 字 │
│    ├─ 时间 + 地点 + 人物 + 对话（有具体日期最佳）          │
│    ├─ 冲突点在第 2-3 段抛出                                 │
│    └─ 末尾一句话过渡到"这一篇要解决的问题"                 │
├─────────────────────────────────────────────────────────────┤
│ ## 02. 市面误读之辨                              600-800 字 │
│    ├─ 列 2-3 派流行说法                                    │
│    ├─ 说清各自"偏在哪里"（不要"完全错"，要"偏在哪"）       │
│    └─ 引出"我们准备怎么讲"的悬念                           │
├─────────────────────────────────────────────────────────────┤
│ ## 03. 三层独家主张                              800-1000 字│
│    ├─ 主张一（一句话金句 + 简短论证）                      │
│    ├─ 主张二（同上）                                        │
│    └─ 主张三（同上）                                        │
│    这三个主张必须与全书其他篇的主张不重复                  │
├─────────────────────────────────────────────────────────────┤

│    └─ 他为什么必须讲、讲给谁听                             │
├─────────────────────────────────────────────────────────────┤
│ ## 05. 原文四维精读                              900-1100 字│
│    引 2-3 段原文，每段做四维分析：                          │
│      · 字眼：哪个词是关键                                  │
```

## 后记

写这本书，只想做一件事：帮你从"墙上芦苇"变成"解剖麻雀"的人——从靠收藏金句活着，变成靠解决真实问题活着；从"懂得很多但用不上"，变成"懂得不多但每一个都能切到血管"。

如果全书只能留下一句话，我希望是这一句：

**"实事求是。从你脚下的真实问题出发，反复跑实践和认识，直到把问题解决。"**
