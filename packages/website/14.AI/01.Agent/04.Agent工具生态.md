### 1.1 Agent 工具的五大分类

- **API 工具**：HTTP 调用、SaaS 接入

- **UI 操控**：Playwright、Selenium、桌面自动化
- **文件操作**：读写、diff、格式转换
- **数据库查询**：向量库、SQL、NoSQL、图数据库
