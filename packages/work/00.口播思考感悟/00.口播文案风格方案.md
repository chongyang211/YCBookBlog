# 口播文案 · 风格方案

## 一、对标的流量密码

| 账号 | 为什么火 | 能偷什么 |
|------|----------|----------|
| 心理唠叨兽 | 用"你有没有…"让你觉得他在说你，然后给你一个反常识的解释 | 共情钩子 + 认知颠覆 |
| 大橙子有话说 | 说话带刺但不让人讨厌，一句话能把你的遮羞布扯掉 | 锋利观点 + 不讨好感 |
| 崔磊 | 每句话都在制造"原来如此"的瞬间 | 信息差，给你你不知道但要命的东西 |
| 阿怀 | 用"我告诉你"的压迫感输出，粉丝反而更信 | 笃定感 + 不容置疑的语气 |

**共同规律**：都不是"教你做人"，而是"替你说出你不敢说的话"。观众转发的动机不是"这个好有用"，而是**"这就是我想说但不知道怎么说的话"**。

## 二、选题铁律

### 一句话：观点必须冒犯一类人

温和等于没人看。每一个选题，你当场就能说出"谁会不同意"——如果所有人都同意，这篇不用写。

**选题自检三问**：
1. 看完标题，有没有人想骂你？ → 有，就对了
2. 这个观点，是不是大部分人心里想过但不敢说？ → 是，这是爆款
3. 能不能用一句话说清楚？ → 不能，说明你没想清楚

### 六类高流量选题模板

| 类型 | 公式 | 例子 |
|------|------|------|
| 揭老底 | 你以为 X 是因为 Y，其实是 Z | 你以为工资低是能力问题，其实是你不会汇报 |
| 掀桌子 | 别再说 X 了，真相是 Y | 别再相信"吃亏是福"了，吃亏就是吃亏 |
| 诛心流 | 有一种人，X，但他们不知道 Y | 有一种人，30 岁就死了，80 岁才埋 |
| 反共识 | 所有人都说 X，但我劝你别 X | 所有人都说要努力，但我劝你别太努力 |
| 贴标签 | 如果你 X，恭喜你，你是 Y | 如果你觉得上班如上坟，恭喜你，你还活着 |
| 算账流 | X 这件事，一年让你亏了 Y | 不敢拒绝这件事，一年让你亏了 10 万块 |

## 三、脚本五段式（流量版）

```
┌─────────────────────────────────────────┐
│ 钩子 (3秒)                               │
│ 一句让目标人群停下滑动手指的暴论          │
├─────────────────────────────────────────┤
│ 撕伤口 (15秒)                            │
│ 用"你有没有过…""你是不是也…"精准打击一人群  │
│ 关键词：具体场景，非抽象道理               │
├─────────────────────────────────────────┤
│ 补一刀 (10秒)                            │
│ 把问题升级：你以为这就完了？还有更扎心的    │
│ "更可怕的是…""但真相是…"                  │
├─────────────────────────────────────────┤
│ 转机 (20秒)                              │
│ 反常识解法。给出一个"卧槽原来可以这样"的瞬间 │
│ "有没有一种可能…""但其实…"                │
├─────────────────────────────────────────┤
│ 收尾钩 (5秒)                             │
│ 金句 + 留白式互动                        │
│ "所以我想问你…"（不说点赞关注）           │
└─────────────────────────────────────────┘
```

**时长目标**：500-600 字，口播约 60-75 秒。抖音完播率最优区间是 45-75 秒，超过 90 秒断崖下跌。

## 四、文字配方

### 4.1 节奏控制

| 节奏型 | 字数 | 作用 |
|--------|------|------|
| 短句连击 | 3-5 字 × 3 句 | 开篇造势，像鼓点 |
| 场景白描 | 10-15 字 × 3 句 | 画面代入，制造共情 |
| 一句话暴击 | 8-12 字 | 金句位置，必须能截屏 |
| 问句收尾 | 10-15 字 | 制造留白，引导评论区 |

### 4.2 口语配方

- "你" 出现频率：每 100 字至少 3 次。不是"我们每个人"，是"你"
- 转折词密度：每 100 字至少 1 个"但/可/其实/有没有一种可能"
- 禁止词："众所周知""毋庸置疑""第一点第二点""家人们""一键三连"

### 4.3 情绪曲线

```
情绪值
  │     ┌─ 补刀（最低点）
  │    ╱ ╲
  │   ╱   ╲
  │  ╱     ╲___ 转机（拉回）
  │ ╱ 痛点           ╲___ 收尾（留白）
  │╱ 代入                 ╲___
  └────────────────────────────→ 时间
```

观众在最低点（"补刀"）时情绪被压到最底，此时给的"转机"最有冲击力——**跌得越深，弹得越高**。

## 五、爆款公式验证

把上述所有规则压缩成一条执行清单：

```
[ ] 选题能让一类人骂你
[ ] 开头 8 个字内出现"你"
[ ] 用了一个具体场景而非抽象概念
[ ] 有一句话能截屏（金句）
[ ] 全文出现至少 2 个"但"
[ ] 结尾是一个问句，不是总结
[ ] 朗读一遍不卡壳
```
