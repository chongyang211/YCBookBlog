## 二、输出标准

### 2.1 单篇硬指标

| 维度 | 标准 | 为什么 |
|------|------|--------|
| 字数 | 400-600 字 | 60-75 秒完播率最优 |
| 段落 | ≤5 段 | 超过 5 段观众记不住主线 |
| 句长 | ≤15 字 | 超过 15 字口播会断气 |
| 场景 | ≥1 个具体场景 | 没有场景的文案等于白写 |
| 争议 | 有一类人不同意 | 没人反对=没人转发 |
| 金句 | 结尾 1 句可截屏 | 截屏分享=你的免费传播 |

### 2.2 验收 7 条

```
[ ] 第一句不是自我介绍，是暴论
[ ] "你" 出现 ≥8 次
[ ] "但/可是/其实" 出现 ≥2 次
[ ] 有一个"你有没有过"或"是不是这样"
[ ] 没有"第一第二""众所周知""家人们"
[ ] 结尾是问句，不是"加油"
[ ] 能截屏分享
```

## 三、改造流水线

### 3.1 已有底稿 → 改写

```
原稿
  │
  ├── 1. 砍长句：>15 字的拆两句
  ├── 2. 换人称：所有"我们"→"你"
  ├── 3. 补钩子：第一句必须是暴论
  ├── 4. 加场景：至少补一个"你有没有过…"
  ├── 5. 埋金句：结尾补可截屏句
  └── 6. 过验收：7 条自查
```

### 3.2 空壳选题 → 创作

```
H2 标题（如"别把平台当本事"）
  │
  ├── 1. 提取核心观点（一句话说清楚）
  ├── 2. 选流量模板（揭老底/掀桌子/诛心流…）
  ├── 3. 搭五段骨架（钩子→痛点→补刀→转机→收尾）
  ├── 4. 填具体场景（职场/社交具体事件）
  └── 5. 过验收
```

## 四、发布策略

### 4.1 冷启动节奏

| 阶段 | 时长 | 条数 | 选题策略 |
|------|------|------|----------|
| 炸号期 | 前 3 天 | 每天 2 条 | 只发 S 级，只选评论必吵架的 |
| 冲权重 | 第 4-7 天 | 每天 1 条 | S+A 混合 |
| 稳定期 | 第 2 周起 | 3-4 条/周 | A+B 穿插，保持周更 2 条 S |

### 4.2 黄金发布时间

职场/人性/沟通类：周一至周四 20:00-22:00（打工人下班刷手机高峰）
情感/成长类：周五周六 21:00-23:00（周末前情绪低谷）
理财/经济类：周日 10:00-12:00（计划下周的高认知时间）

### 4.3 评论区运营

评论区是第二个流量入口，不是附属品。

- **故意留破绽**：文案中留一个"这也不对"的缺口，观众天然想纠正你
- **自己抢沙发**：发完立刻用小号留一条争议评论，带动风向
- **置顶金句**：把文案里最好的那句置顶在评论区，二次曝光

## 五、数据迭代闭环

```
发布 → 观察 2h 数据
  │
  ├── 完播率 < 30% → 钩子不够炸 → 改开头
  ├── 点赞率 < 3%  → 共鸣不够 → 补场景
  ├── 评论率 < 0.5% → 争议不够 → 选题太安全
  ├── 转发率 < 0.3% → 金句不够 → 结尾改一句
  └── 都达标 → 复用模板量产同类型
```

**不看粉丝量，看互动率。** 1 万粉丝 10% 互动 > 10 万粉丝 1% 互动。平台推流的唯一标准是这条内容有没有让人"停下来"。
