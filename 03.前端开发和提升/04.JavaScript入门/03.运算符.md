## 3.1 算术运算符

用于执行基本的数学运算。

| 运算符 | 描述           | 示例           |
|--------|----------------|----------------|
| `+`    | 加法           | `3 + 2` → `5`  |
| `-`    | 减法           | `5 - 2` → `3`  |
| `*`    | 乘法           | `3 * 2` → `6`  |
| `/`    | 除法           | `6 / 2` → `3`  |
| `%`    | 取余           | `5 % 2` → `1`  |
| `**`   | 指数（幂）     | `2 ** 3` → `8` |
| `++`   | 自增           | `let a = 1; a++` → `2` |
| `--`   | 自减           | `let a = 1; a--` → `0` |


## 3.2 赋值运算符

用于为变量赋值。

| 运算符 | 描述           | 示例                |
|--------|----------------|---------------------|
| `=`    | 赋值           | `let a = 5`         |
| `+=`   | 加后赋值       | `a += 2` → `a = a + 2` |
| `-=`   | 减后赋值       | `a -= 2` → `a = a - 2` |
| `*=`   | 乘后赋值       | `a *= 2` → `a = a * 2` |
| `/=`   | 除后赋值       | `a /= 2` → `a = a / 2` |
| `%=`   | 取余后赋值     | `a %= 2` → `a = a % 2` |
| `**=`  | 指数后赋值     | `a **= 2` → `a = a ** 2` |

## 3.3 比较运算符

用于比较两个值，返回布尔值（`true` 或 `false`）。

| 运算符 | 描述           | 示例                |
|--------|----------------|---------------------|
| `==`   | 等于（值相等） | `5 == '5'` → `true` |
| `===`  | 严格等于（值和类型都相等） | `5 === '5'` → `false` |
| `!=`   | 不等于         | `5 != '5'` → `false` |
| `!==`  | 严格不等于     | `5 !== '5'` → `true` |
| `>`    | 大于           | `5 > 3` → `true`    |
| `<`    | 小于           | `5 < 3` → `false`   |
| `>=`   | 大于等于       | `5 >= 5` → `true`   |
| `<=`   | 小于等于       | `5 <= 3` → `false`  |

## 3.4 逻辑运算符

用于组合或操作布尔值。

| 运算符 | 描述           | 示例                |
|--------|----------------|---------------------|
| `&&`   | 逻辑与         | `true && false` → `false` |
| `||`   | 逻辑或         | `true || false` → `true`  |
| `!`    | 逻辑非         | `!true` → `false`         |

## 3.5 位运算符

用于对二进制数进行操作。

| 运算符 | 描述           | 示例                |
|--------|----------------|---------------------|
| `&`    | 按位与         | `5 & 1` → `1`       |
| `|`    | 按位或         | `5 | 1` → `5`       |
| `^`    | 按位异或       | `5 ^ 1` → `4`       |
| `~`    | 按位非         | `~5` → `-6`         |
| `<<`   | 左移           | `5 << 1` → `10`     |
| `>>`   | 右移           | `5 >> 1` → `2`      |
| `>>>`  | 无符号右移     | `-5 >>> 1` → `2147483645` |

## 3.6 三元运算符

用于简化 `if-else` 语句。

| 运算符 | 描述           | 示例                |
|--------|----------------|---------------------|
| `? :`  | 三元运算符     | `5 > 3 ? 'Yes' : 'No'` → `'Yes'` |

### **7. 类型运算符**
用于检查变量类型。

| 运算符 | 描述           | 示例                |
|--------|----------------|---------------------|
| `typeof` | 返回变量类型 | `typeof 5` → `'number'` |
| `instanceof` | 检查对象是否为某类的实例 | `[] instanceof Array` → `true` |

---

### **8. 其他运算符**
| 运算符 | 描述           | 示例                |
|--------|----------------|---------------------|
| `,`    | 逗号运算符     | `let a = (1, 2, 3)` → `a = 3` |
| `?.`   | 可选链运算符   | `obj?.prop` → 如果 `obj` 为 `null` 或 `undefined`，返回 `undefined` |
| `??`   | 空值合并运算符 | `null ?? 'default'` → `'default'` |
| `...`  | 展开运算符     | `[...[1, 2], 3]` → `[1, 2, 3]` |

---

### **9. 运算符优先级**
JavaScript 中的运算符优先级决定了表达式中运算的顺序。以下是一些常见的优先级（从高到低）：
1. `()`（分组）
2. `++`, `--`（自增、自减）
3. `*`, `/`, `%`（乘法、除法、取余）
4. `+`, `-`（加法、减法）
5. `<`, `<=`, `>`, `>=`（比较）
6. `==`, `!=`, `===`, `!==`（相等）
7. `&&`（逻辑与）
8. `||`（逻辑或）
9. `=`（赋值）

---

### **10. 示例**
```javascript
// 算术运算符
let a = 5 + 3 * 2; // 11

// 比较运算符
let b = (5 > 3) ? 'Yes' : 'No'; // 'Yes'

// 逻辑运算符
let c = true && false; // false

// 三元运算符
let d = (a > 10) ? 'High' : 'Low'; // 'High'

// 可选链运算符
let obj = { prop: { value: 10 } };
let e = obj?.prop?.value; // 10

// 空值合并运算符
let f = null ?? 'default'; // 'default'
```

---

### **总结**
JavaScript 的运算符涵盖了从基本算术到复杂逻辑的各种操作。掌握这些运算符的用法和优先级，可以帮助你编写更高效、更简洁的代码。
