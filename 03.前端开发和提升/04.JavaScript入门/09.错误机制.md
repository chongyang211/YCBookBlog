## 9.1 错误类型

JavaScript 错误处理机制是确保代码健壮性和稳定性的重要手段。通过捕获和处理错误，可以防止程序崩溃，并提供更好的用户体验。以下是 JavaScript 错误处理的详细指南：

### 9.1.1 错误类型说明

JavaScript 中的错误分为以下几种类型：

1. **`Error`**：通用错误类型，其他错误类型都继承自它。
2. **`SyntaxError`**：语法错误，通常在解析代码时发生。
3. **`ReferenceError`**：引用错误，通常发生在访问未定义的变量时。
4. **`TypeError`**：类型错误，通常发生在对错误类型的值进行操作时。
5. **`RangeError`**：范围错误，通常发生在数值超出有效范围时。
6. **`URIError`**：URI 错误，通常发生在处理 URI 时使用无效参数。
7. **`EvalError`**：`eval` 函数执行错误（已弃用）。

---

### **2. 抛出错误**
使用 `throw` 关键字抛出错误。
```javascript
function divide(a, b) {
  if (b === 0) {
    throw new Error("Division by zero is not allowed!");
  }
  return a / b;
}

console.log(divide(10, 0)); // 抛出错误
```

---

### **3. 捕获错误**
使用 `try...catch` 语句捕获和处理错误。
```javascript
try {
  const result = divide(10, 0);
  console.log(result);
} catch (error) {
  console.error("An error occurred:", error.message);
}
```

---

### **4. `finally` 块**
`finally` 块中的代码无论是否发生错误都会执行，通常用于清理资源。
```javascript
try {
  const result = divide(10, 0);
  console.log(result);
} catch (error) {
  console.error("An error occurred:", error.message);
} finally {
  console.log("Execution completed.");
}
```

---

### **5. 自定义错误**
可以通过继承 `Error` 类创建自定义错误类型。
```javascript
class CustomError extends Error {
  constructor(message) {
    super(message);
    this.name = "CustomError";
  }
}

try {
  throw new CustomError("This is a custom error!");
} catch (error) {
  console.error(error.name, error.message); // CustomError This is a custom error!
}
```

---

### **6. 异步错误处理**
#### **6.1 Promise 错误处理**
使用 `.catch()` 捕获 Promise 中的错误。
```javascript
fetch("https://example.com/data")
  .then((response) => response.json())
  .catch((error) => {
    console.error("Fetch error:", error);
  });
```

#### **6.2 `async/await` 错误处理**
使用 `try...catch` 捕获 `async/await` 中的错误。
```javascript
async function fetchData() {
  try {
    const response = await fetch("https://example.com/data");
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error("Fetch error:", error);
  }
}

fetchData();
```

---

### **7. 全局错误处理**
#### **7.1 `window.onerror`**
捕获全局未处理的错误。
```javascript
window.onerror = function (message, source, lineno, colno, error) {
  console.error("Global error:", message, "at", source, "line", lineno);
  return true; // 阻止默认错误提示
};
```

#### **7.2 `unhandledrejection`**
捕获未处理的 Promise 拒绝。
```javascript
window.addEventListener("unhandledrejection", function (event) {
  console.error("Unhandled rejection:", event.reason);
});
```

### **8. 调试错误**
- **`console.error()`**：打印错误信息。
- **`console.trace()`**：打印调用堆栈。
- **开发者工具**：使用浏览器的开发者工具调试错误。

---

### **9. 最佳实践**
1. **捕获特定错误**：避免捕获所有错误，只捕获你能够处理的错误。
2. **提供有意义的错误信息**：帮助开发者快速定位问题。
3. **记录错误**：将错误信息记录到日志中，便于后续分析。
4. **优雅降级**：在发生错误时提供备用方案，确保用户体验。
5. **测试错误场景**：编写测试用例覆盖可能的错误场景。

### **10. 示例：完整的错误处理**
```javascript
class NetworkError extends Error {
  constructor(message) {
    super(message);
    this.name = "NetworkError";
  }
}

async function fetchData(url) {
  try {
    const response = await fetch(url);
    if (!response.ok) {
      throw new NetworkError("Network response was not ok");
    }
    const data = await response.json();
    return data;
  } catch (error) {
    if (error instanceof NetworkError) {
      console.error("Network error:", error.message);
    } else {
      console.error("Unexpected error:", error.message);
    }
    throw error; // 重新抛出错误
  }
}

fetchData("https://example.com/data")
  .then((data) => console.log(data))
  .catch((error) => console.error("Failed to fetch data:", error.message));
```
