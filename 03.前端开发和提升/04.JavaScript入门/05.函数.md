## 5.1 函数定义

函数是一段可以反复调用的代码块。函数还能接受输入的参数，不同的参数有唯一对应的返回值。

### 5.1.1 函数声明

使用 `function` 关键字定义函数。

函数声明会被提升（hoisted），可以在定义之前调用。

```javascript
function greet(name) {
    return `Hello, ${name}!`;
}

console.log(greet("Alice")); // Hello, Alice!
```
