### 6.1 符合数据类型

### 6.1.1 Object

**`Object`**：创建和操作对象。

方法：`Object.keys()`、`Object.values()`、`Object.assign()`。

### 6.1.2 Array

**`Array`**：创建和操作数组。

方法：`push()`、`pop()`、`map()`、`filter()`、`reduce()`。

### 6.1.3 Map

**`Map`**：存储键值对。

方法：`set()`、`get()`、`has()`。

### 6.1.4 Set

**`Set`**：存储唯一值。

方法：`add()`、`delete()`、`has()`。

### 6.1.5 WeakMap

**`WeakMap` 和 `WeakSet`**：弱引用版本的 `Map` 和 `Set`。

## 6.2 特殊数据类型

### 6.2.1 Date

**`Date`**：处理日期和时间。

方法：`Date.now()`、`getFullYear()`、`getMonth()`。


### 6.2.2 RegExp

**`RegExp`**：处理正则表达式。

方法：`test()`、`exec()`。

### 6.2.3 Error

**`Error`**：处理错误。

子类：`SyntaxError`、`TypeError`、`ReferenceError`。

## 6.3 全局对象

### 6.3.1 Math

**`Math`**：提供数学运算功能。

方法：`Math.random()`、`Math.floor()`、`Math.max()`。

### 6.3.2 JSON

**`JSON`**：处理 JSON 数据。

方法：`JSON.parse()`、`JSON.stringify()`。

### 6.3.3 Promise

**`Promise`**：处理异步操作。

方法：`then()`、`catch()`、`finally()`、`Promise.all()`。

### 6.3.4 Proxy

**`Proxy`**：创建对象的代理。

### 6.3.5 Reflect

**`Reflect`**：提供操作对象的静态方法。
