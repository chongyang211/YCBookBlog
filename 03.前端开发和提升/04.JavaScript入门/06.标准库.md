## 6.1 全局对象

### 6.1.1 Object

用于创建和操作对象。常用方法：`Object.keys()`、`Object.values()`、`Object.assign()`、`Object.create()` 等。

### 6.1.2 Function

用于创建和操作函数。常用方法：`call()`、`apply()`、`bind()`。

#### **1.4 `String`**
- 用于创建和操作字符串。
- 常用方法：`split()`、`slice()`、`indexOf()`、`replace()` 等。

#### **1.5 `Number`**
- 用于处理数字。
- 常用方法：`toFixed()`、`toPrecision()`、`isNaN()`、`isFinite()` 等。

#### **1.6 `Boolean`**
- 用于处理布尔值。

#### **1.7 `Symbol`**
- 用于创建唯一的标识符。

#### **1.8 `BigInt`**
- 用于处理大整数。

#### **1.9 `Math`**
- 提供数学运算功能。
- 常用方法：`Math.random()`、`Math.floor()`、`Math.max()`、`Math.min()` 等。

#### **1.10 `Date`**
- 用于处理日期和时间。
- 常用方法：`Date.now()`、`getFullYear()`、`getMonth()`、`getDate()` 等。

#### **1.11 `RegExp`**
- 用于处理正则表达式。
- 常用方法：`test()`、`exec()`。

#### **1.12 `Error`**
- 用于处理错误。
- 常用子类：`SyntaxError`、`TypeError`、`ReferenceError` 等。

#### **1.13 `Promise`**
- 用于处理异步操作。
- 常用方法：`then()`、`catch()`、`finally()`、`Promise.all()`、`Promise.race()`。

#### **1.14 `Map` 和 `Set`**
- `Map`：用于存储键值对。
- `Set`：用于存储唯一值。

#### **1.15 `WeakMap` 和 `WeakSet`**
- `WeakMap`：键必须是对象的弱引用。
- `WeakSet`：值必须是对象的弱引用。

#### **1.16 `Proxy`**
- 用于创建对象的代理，拦截和自定义操作。

#### **1.17 `Reflect`**
- 提供操作对象的静态方法。

#### **1.18 `JSON`**
- 用于处理 JSON 数据。
- 常用方法：`JSON.parse()`、`JSON.stringify()`。

### **2. 全局函数**
#### **2.1 `eval()`**
- 执行字符串中的 JavaScript 代码。

#### **2.2 `isNaN()`**
- 检查值是否为 `NaN`。

#### **2.3 `isFinite()`**
- 检查值是否为有限数。

#### **2.4 `parseInt()` 和 `parseFloat()`**
- 将字符串转换为整数或浮点数。

#### **2.5 `encodeURI()` 和 `decodeURI()`**
- 编码或解码 URI。

#### **2.6 `encodeURIComponent()` 和 `decodeURIComponent()`**
- 编码或解码 URI 组件。

### **3. 浏览器相关对象**
#### **3.1 `Window`**
- 表示浏览器窗口。
- 常用属性：`window.document`、`window.location`、`window.localStorage`。

#### **3.2 `Document`**
- 表示 HTML 文档。
- 常用方法：`getElementById()`、`querySelector()`、`createElement()`。

#### **3.3 `Navigator`**
- 提供浏览器信息。
- 常用属性：`navigator.userAgent`、`navigator.language`。

#### **3.4 `Location`**
- 提供当前页面的 URL 信息。
- 常用属性：`location.href`、`location.pathname`。

#### **3.5 `History`**
- 提供浏览器历史记录。
- 常用方法：`history.back()`、`history.pushState()`。

#### **3.6 `Storage`**
- 提供本地存储功能。
- 常用方法：`localStorage.setItem()`、`sessionStorage.getItem()`。

#### **3.7 `Fetch API`**
- 用于发起网络请求。
- 常用方法：`fetch()`。

#### **3.8 `WebSocket`**
- 用于实现 WebSocket 通信。

---

### **4. 其他**
#### **4.1 `Intl`**
- 提供国际化功能。
- 常用对象：`Intl.DateTimeFormat`、`Intl.NumberFormat`。

#### **4.2 `Web Workers`**
- 用于在后台运行脚本。

#### **4.3 `Blob` 和 `File`**
- 用于处理二进制数据。

#### **4.4 `URL` 和 `URLSearchParams`**
- 用于处理 URL 和查询参数。

### **5. 示例**
```javascript
// 数组操作
const numbers = [1, 2, 3];
const doubled = numbers.map(n => n * 2);
console.log(doubled); // 输出: [2, 4, 6]

// 字符串操作
const str = 'Hello, World!';
console.log(str.slice(0, 5)); // 输出: Hello

// 日期操作
const now = new Date();
console.log(now.getFullYear()); // 输出: 当前年份

// Promise 示例
const promise = new Promise((resolve, reject) => {
  setTimeout(() => resolve('Done!'), 1000);
});
promise.then(result => console.log(result)); // 输出: Done!

// Fetch API 示例
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data));
```
