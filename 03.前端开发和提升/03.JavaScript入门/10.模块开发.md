## 10.1 导入和导出

### 10.1.1 模块化概念

JavaScript 中的 `export` 是 ES6（ECMAScript 2015）引入的模块化语法，用于从模块中导出变量、函数、类等，以便其他模块可以使用 `import` 导入这些内容。

### 10.1.2 基本导出

> **1.导出单个变量、函数或类**

使用 `export` 关键字直接导出。

```javascript
// module.js
export const name = 'Alice';
export function greet() {
  console.log('Hello!');
}
export class Person {
  constructor(name) {
    this.name = name;
  }
}
```

> **2.导出默认值**

使用 `export default` 导出模块的默认值，一个模块只能有一个默认导出。

```javascript
// module.js
const message = 'Hello, World!';
export default message;
```

### 10.1.3 批量导出

> **1.导出多个内容**

在模块底部统一导出。

```javascript
// module.js
const name = 'Alice';
function greet() {
  console.log('Hello!');
}
class Person {
  constructor(name) {
    this.name = name;
  }
}

export { name, greet, Person };
```

> **2.重命名导出**

使用 `as` 关键字重命名导出的内容。

```javascript
// module.js
const name = 'Alice';
function greet() {
  console.log('Hello!');
}

export { name as userName, greet as sayHello };
```

### 10.1.4 导入导出结合

> **1.重新导出**

从一个模块中导入内容并立即导出。

```javascript
// module.js
export { name, greet } from './anotherModule.js';
```

> **2.重新导出默认值**

重新导出另一个模块的默认值。

```javascript
// module.js
export { default } from './anotherModule.js';
```
