## 01.TypeScript介绍

TypeScript 是一种基于 JavaScript 的强类型编程语言，它通过静态类型检查增强了 JavaScript 的开发体验。

TypeScript 的基础类型系统是其核心特性之一，它允许开发者明确变量、函数参数和返回值的类型，从而提高代码的可读性、可维护性和安全性。

## 02.基本类型

TypeScript 支持 JavaScript 的所有基本数据类型，并提供了额外的类型支持。

### 1.1 布尔类型 (`boolean`)

表示 `true` 或 `false`。

```typescript
let isDone: boolean = false;
```

### 1.2 数字类型 (`number`)

表示整数或浮点数，支持二进制、八进制、十进制和十六进制。

```typescript
let decimal: number = 6;
let hex: number = 0xf00d;
let binary: number = 0b1010;
let octal: number = 0o744;
```

### 1.3 字符串类型 (`string`)

表示文本数据，可以使用单引号、双引号或模板字符串。

```typescript
let color: string = "blue";
color = `Color is ${color}`;
```

### 1.4 数组类型 (`Array`)

表示一组相同类型的元素，有两种定义方式：

```typescript
let list1: number[] = [1, 2, 3];
let list2: Array<number> = [1, 2, 3];
```

### 1.5 元组类型 (`Tuple`)

表示一个已知元素数量和类型的数组，各元素的类型可以不同。

```typescript
let tuple: [string, number];
tuple = ["hello", 10]; // 正确
tuple = [10, "hello"]; // 错误
```

#### **1.6 枚举类型 (`enum`)**
为一组数值赋予友好的名字。
```typescript
enum Color { Red, Green, Blue }
let c: Color = Color.Green; // 1
```

#### **1.7 任意类型 (`any`)**
表示任意类型，关闭类型检查。
```typescript
let notSure: any = 4;
notSure = "maybe a string";
notSure = false;
```

#### **1.8 空类型 (`void`)**
表示没有任何类型，通常用于函数返回值。
```typescript
function warnUser(): void {
    console.log("This is a warning message");
}
```

#### **1.9 `null` 和 `undefined`**
表示 `null` 或 `undefined` 值。
```typescript
let u: undefined = undefined;
let n: null = null;
```

#### **1.10 `never` 类型**
表示永远不会发生的值，通常用于抛出异常或无限循环的函数。
```typescript
function error(message: string): never {
    throw new Error(message);
}
```

#### **1.11 `unknown` 类型**
表示未知类型，比 `any` 更安全，需要类型检查后才能使用。
```typescript
let value: unknown;
value = "hello";
if (typeof value === "string") {
    console.log(value.toUpperCase());
}
```

---

### **2. 类型推断**
TypeScript 可以根据赋值自动推断变量的类型。
```typescript
let num = 10; // 推断为 number 类型
num = "hello"; // 错误
```

---

### **3. 联合类型 (`Union Types`)**
表示一个值可以是多种类型之一。
```typescript
let value: string | number;
value = "hello";
value = 10;
```

---

### **4. 类型别名 (`Type Aliases`)**
为类型创建一个别名，方便复用。
```typescript
type StringOrNumber = string | number;
let value: StringOrNumber;
value = "hello";
value = 10;
```

---

### **5. 字面量类型 (`Literal Types`)**
表示一个具体的值，通常与联合类型一起使用。
```typescript
let direction: "left" | "right" | "up" | "down";
direction = "left"; // 正确
direction = "side"; // 错误
```

---

### **6. 类型断言 (`Type Assertion`)**
告诉 TypeScript 一个值的具体类型。
```typescript
let value: any = "hello";
let length: number = (value as string).length;
```

---

### **7. 非空断言 (`Non-null Assertion`)**
明确告诉 TypeScript 一个值不是 `null` 或 `undefined`。
```typescript
let value: string | null = "hello";
console.log(value!.toUpperCase()); // 非空断言
```

---

### **8. 类型守卫 (`Type Guards`)**
通过条件语句缩小类型范围。
```typescript
function isString(value: any): value is string {
    return typeof value === "string";
}

let value: string | number;
if (isString(value)) {
    console.log(value.toUpperCase());
} else {
    console.log(value.toFixed(2));
}
```

---

### **9. 只读属性 (`readonly`)**
表示属性不可修改。
```typescript
interface Point {
    readonly x: number;
    readonly y: number;
}

let p: Point = { x: 10, y: 20 };
p.x = 5; // 错误
```

---

### **10. 类型扩展 (`Intersection Types`)**
将多个类型合并为一个类型。
```typescript
interface A {
    a: number;
}
interface B {
    b: string;
}
type C = A & B;
let obj: C = { a: 1, b: "hello" };
```

---

### **总结**
TypeScript 的基础类型系统提供了丰富的类型支持，包括基本类型、联合类型、类型别名、类型断言等。通过合理使用这些特性，可以显著提高代码的健壮性和可维护性。
