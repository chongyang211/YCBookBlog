# 专栏笔记总结大全
#### 目录说明
- 01.函数声明




TypeScript 中的函数是 JavaScript 函数的扩展，增加了类型支持，使得函数的参数和返回值可以明确指定类型。

## 01.函数声明

### 1.1 基本函数声明

```typescript
function add(x: number, y: number): number {
    return x + y;
}
```

### 1.2 函数表达式

```typescript
const add = function(x: number, y: number): number {
    return x + y;
};
```

### 1.3 箭头函数

```typescript
const add = (x: number, y: number): number => x + y;
```

---

### **2. 函数参数**
#### **2.1 参数类型**
可以为函数的参数指定类型。
```typescript
function greet(name: string): void {
    console.log(`Hello, ${name}`);
}
```

#### **2.2 可选参数**
使用 `?` 标记可选参数，可选参数必须位于必选参数之后。
```typescript
function greet(name: string, age?: number): void {
    if (age) {
        console.log(`Hello, ${name}, you are ${age} years old`);
    } else {
        console.log(`Hello, ${name}`);
    }
}
```

#### **2.3 默认参数**
为参数提供默认值。
```typescript
function greet(name: string, age: number = 30): void {
    console.log(`Hello, ${name}, you are ${age} years old`);
}
```

#### **2.4 剩余参数**
使用 `...` 语法表示剩余参数，剩余参数必须是数组类型。
```typescript
function sum(...numbers: number[]): number {
    return numbers.reduce((acc, curr) => acc + curr, 0);
}
console.log(sum(1, 2, 3)); // 6
```

---

### **3. 函数返回值**
#### **3.1 返回值类型**
可以为函数指定返回值类型。
```typescript
function add(x: number, y: number): number {
    return x + y;
}
```

#### **3.2 `void` 返回值**
表示函数没有返回值。
```typescript
function logMessage(message: string): void {
    console.log(message);
}
```

#### **3.3 `never` 返回值**
表示函数永远不会返回（例如抛出异常或无限循环）。
```typescript
function throwError(message: string): never {
    throw new Error(message);
}
```

---

### **4. 函数重载**
TypeScript 支持函数重载，允许为同一个函数提供多个类型定义。
```typescript
function add(x: number, y: number): number;
function add(x: string, y: string): string;
function add(x: any, y: any): any {
    return x + y;
}

console.log(add(1, 2)); // 3
console.log(add("Hello, ", "World")); // "Hello, World"
```

---

### **5. 函数类型**
#### **5.1 函数类型定义**
可以为函数定义类型。
```typescript
type AddFunction = (x: number, y: number) => number;
const add: AddFunction = (x, y) => x + y;
```

#### **5.2 函数作为参数**
函数可以作为参数传递给其他函数。
```typescript
function calculate(x: number, y: number, operation: (a: number, b: number) => number): number {
    return operation(x, y);
}

const result = calculate(10, 5, (a, b) => a + b);
console.log(result); // 15
```

---

### **6. `this` 类型**
可以为函数指定 `this` 的类型。
```typescript
interface User {
    name: string;
    greet(this: User): void;
}

const user: User = {
    name: "Alice",
    greet() {
        console.log(`Hello, ${this.name}`);
    }
};

user.greet(); // "Hello, Alice"
```

---

### **7. 泛型函数**
使用泛型使函数适用于多种类型。
```typescript
function identity<T>(arg: T): T {
    return arg;
}

let output1 = identity<string>("hello"); // 类型为 string
let output2 = identity<number>(42);      // 类型为 number
```

---

### **8. 异步函数**
使用 `async` 和 `await` 处理异步操作。
```typescript
async function fetchData(): Promise<string> {
    const response = await fetch("https://api.example.com/data");
    const data = await response.json();
    return data;
}

fetchData().then(data => console.log(data));
```

---

### **9. 函数中的类型推断**
TypeScript 会根据上下文自动推断函数的参数和返回值类型。
```typescript
const add = (x: number, y: number) => x + y; // 返回值类型推断为 number
```

---

### **10. 函数中的类型守卫**
通过条件语句缩小参数的类型范围。
```typescript
function isString(value: any): value is string {
    return typeof value === "string";
}

function printValue(value: string | number) {
    if (isString(value)) {
        console.log(value.toUpperCase());
    } else {
        console.log(value.toFixed(2));
    }
}
```

---

### **总结**
TypeScript 的函数在 JavaScript 的基础上增加了类型支持，提供了更强大的功能，如函数重载、泛型、异步函数等。通过合理使用这些特性，可以显著提高代码的类型安全性和可维护性。
