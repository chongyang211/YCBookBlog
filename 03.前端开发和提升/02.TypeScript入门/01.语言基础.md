## 01.前沿介绍

TypeScript 是一种基于 JavaScript 的强类型编程语言，它通过静态类型检查增强了 JavaScript 的开发体验。

TypeScript 的基础类型系统是其核心特性之一，它允许开发者明确变量、函数参数和返回值的类型，从而提高代码的可读性、可维护性和安全性。

## 02.变量和常量

### 2.1 变量名

变量名遵循 JavaScript 的命名规则：

- 以字母、下划线（`_`）或美元符号（`$`）开头。
- 不能以数字开头。
- 区分大小写。
- 不能使用保留字（如 `let`、`class` 等）。

### 2.2 变量声明

使用 `let`、`const` 或 `var` 声明变量：

- `let`：块级作用域，可重新赋值。
- `const`：块级作用域，不可重新赋值。
- `var`：函数作用域，可重新赋值（不推荐使用）。

示例：

```typescript
let age: number = 25;
const name: string = "Alice";
var isActive: boolean = true; // 不推荐
```

## 03.数据类型

TypeScript 支持 JavaScript 的所有基本数据类型，并提供了额外的类型支持。

### 3.1 布尔类型

布尔类型 (`boolean`)，表示 `true` 或 `false`。

```typescript
let isDone: boolean = false;
```

### 3.2 数字类型

数字类型 (`number`)，表示整数或浮点数，支持二进制、八进制、十进制和十六进制。

```typescript
let decimal: number = 6;
let hex: number = 0xf00d;
let binary: number = 0b1010;
let octal: number = 0o744;
```

### 3.3 字符串类型

字符串类型 (`string`)，表示文本数据，可以使用单引号、双引号或模板字符串。

```typescript
let color: string = "blue";
color = `Color is ${color}`;
```

### 3.4 元组类型

元组类型 (`Tuple`)，表示一个已知元素数量和类型的数组，各元素的类型可以不同。

```typescript
let tuple: [string, number];
tuple = ["hello", 10]; // 正确
tuple = [10, "hello"]; // 错误
```

### 3.5 枚举类型 (`enum`)

为一组数值赋予友好的名字。

```typescript
enum Color { Red, Green, Blue }
let c: Color = Color.Green; // 1
```

### 3.6 任意类型 (`any`)

表示任意类型，关闭类型检查。

```typescript
let notSure: any = 4;
notSure = "maybe a string";
notSure = false;
```

### 3.7 空类型 (`void`)

表示没有任何类型，通常用于函数返回值。

```typescript
function warnUser(): void {
    console.log("This is a warning message");
}
```

### 3.8 `null` 和 `undefined`

表示 `null` 或 `undefined` 值。

```typescript
let u: undefined = undefined;
let n: null = null;
```

### 3.9 `never` 类型

表示永远不会发生的值，通常用于抛出异常或无限循环的函数。

```typescript
function error(message: string): never {
    throw new Error(message);
}
```

### 3.10 `unknown` 类型

表示未知类型，比 `any` 更安全，需要类型检查后才能使用。

```typescript
let value: unknown;
value = "hello";
if (typeof value === "string") {
    console.log(value.toUpperCase());
}
```

## 04.数组

### 4.1 数组字面量

使用 `[]` 定义数组。表示一组相同类型的元素，有两种定义方式：

```typescript
let list1: number[] = [1, 2, 3];
let list2: Array<number> = [1, 2, 3];
```

### 4.2 数组中元素

数组元素可以是任意类型。

```typescript
let mixed: (number | string)[] = [1, "two", 3];
```
