TypeScript 的高级类型是其类型系统的强大扩展，提供了更灵活和复杂的类型操作能力。

这些高级类型可以帮助开发者更好地描述和约束代码的行为，提升代码的安全性和可维护性。以下是 TypeScript 中常见的高级类型及其用法：

## 01.联合类型

联合类型 (`Union Types`)，表示一个值可以是多种类型之一。

```typescript
let value: string | number;
value = "hello"; // 正确
value = 10;      // 正确
value = true;    // 错误
```

## 02.交叉类型

交叉类型 (`Intersection Types`)，将多个类型合并为一个类型，新类型包含所有类型的特性。

```typescript
interface A {
    a: number;
}
interface B {
    b: string;
}
type C = A & B;
let obj: C = { a: 1, b: "hello" };
```

## 03.类型别名

类型别名 (`Type Aliases`)，为类型创建一个别名，方便复用。

```typescript
type StringOrNumber = string | number;
let value: StringOrNumber;
value = "hello"; // 正确
value = 10;      // 正确
```

## 04.字面量类型

字面量类型 (`Literal Types`)，表示一个具体的值，通常与联合类型一起使用。

```typescript
let direction: "left" | "right" | "up" | "down";
direction = "left"; // 正确
direction = "side"; // 错误
```

## 05.索引签名

索引签名 (`Index Signatures`)，用于描述对象中动态属性的类型。

```typescript
interface StringDictionary {
    [key: string]: string;
}
let dict: StringDictionary = {
    name: "Alice",
    age: "30" // 错误，值必须是 string 类型
};
```

## 06.映射类型

映射类型 (`Mapped Types`)。基于现有类型创建新类型，通常用于批量修改属性。

```typescript
type Readonly<T> = {
    readonly [P in keyof T]: T[P];
};
interface Person {
    name: string;
    age: number;
}
type ReadonlyPerson = Readonly<Person>;
let person: ReadonlyPerson = { name: "Alice", age: 30 };
person.name = "Bob"; // 错误，属性是只读的
```

---

### **7. 条件类型 (`Conditional Types`)**
根据条件选择类型。
```typescript
type IsString<T> = T extends string ? true : false;
type A = IsString<"hello">; // true
type B = IsString<10>;      // false
```

---

### **8. 类型推断 (`Infer`)**
在条件类型中推断类型。
```typescript
type ReturnType<T> = T extends (...args: any[]) => infer R ? R : never;
function foo(): number {
    return 42;
}
type FooReturnType = ReturnType<typeof foo>; // number
```

---

### **9. 模板字面量类型 (`Template Literal Types`)**
基于字符串字面量创建新类型。
```typescript
type EventName = "click" | "hover";
type HandlerName = `on${Capitalize<EventName>}`;
let handler: HandlerName = "onClick"; // 正确
handler = "onHover"; // 正确
handler = "onScroll"; // 错误
```

---

### **10. 类型守卫 (`Type Guards`)**
通过条件语句缩小类型范围。
```typescript
function isString(value: any): value is string {
    return typeof value === "string";
}

let value: string | number;
if (isString(value)) {
    console.log(value.toUpperCase());
} else {
    console.log(value.toFixed(2));
}
```

---

### **11. 类型断言 (`Type Assertion`)**
告诉 TypeScript 一个值的具体类型。
```typescript
let value: any = "hello";
let length: number = (value as string).length;
```

---

### **12. 非空断言 (`Non-null Assertion`)**
明确告诉 TypeScript 一个值不是 `null` 或 `undefined`。
```typescript
let value: string | null = "hello";
console.log(value!.toUpperCase()); // 非空断言
```

---

### **13. 类型谓词 (`Type Predicates`)**
用于自定义类型守卫。
```typescript
function isFish(pet: Fish | Bird): pet is Fish {
    return (pet as Fish).swim !== undefined;
}
```

---

### **14. 类型兼容性 (`Type Compatibility`)**
TypeScript 使用结构化类型系统，只要结构匹配，类型就是兼容的。
```typescript
interface Named {
    name: string;
}
class Person {
    name: string;
}
let p: Named;
p = new Person(); // 正确，因为结构匹配
```

---

### **15. 类型工具 (`Utility Types`)**
TypeScript 提供了一些内置的工具类型，用于简化类型操作。

#### **`Partial<T>`**
将类型 `T` 的所有属性变为可选。
```typescript
interface Person {
    name: string;
    age: number;
}
type PartialPerson = Partial<Person>;
let person: PartialPerson = { name: "Alice" }; // age 是可选的
```

#### **`Required<T>`**
将类型 `T` 的所有属性变为必选。
```typescript
type RequiredPerson = Required<PartialPerson>;
let person: RequiredPerson = { name: "Alice", age: 30 };
```

#### **`Readonly<T>`**
将类型 `T` 的所有属性变为只读。
```typescript
type ReadonlyPerson = Readonly<Person>;
let person: ReadonlyPerson = { name: "Alice", age: 30 };
person.name = "Bob"; // 错误，属性是只读的
```

#### **`Record<K, T>`**
创建一个对象类型，其属性键为 `K`，值为 `T`。
```typescript
type PersonRecord = Record<"name" | "age", string>;
let person: PersonRecord = { name: "Alice", age: "30" };
```

#### **`Pick<T, K>`**
从类型 `T` 中选择部分属性 `K`。
```typescript
type NameOnly = Pick<Person, "name">;
let person: NameOnly = { name: "Alice" };
```

#### **`Omit<T, K>`**
从类型 `T` 中排除部分属性 `K`。
```typescript
type AgeOnly = Omit<Person, "name">;
let person: AgeOnly = { age: 30 };
```

---

### **总结**
TypeScript 的高级类型提供了强大的工具，用于描述复杂的类型关系和约束。通过合理使用这些特性，可以显著提高代码的类型安全性和可维护性。
