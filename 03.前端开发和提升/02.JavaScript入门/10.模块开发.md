## 10.1 导入和导出

`export` 是 JavaScript 模块化的核心语法，支持导出变量、函数、类等内容，并通过 `import` 在其他模块中使用。掌握 `export` 和 `import` 的使用可以更好地组织和管理代码。

### 10.1.1 模块化概念

模块化是指将一个大的程序文件，拆分成许多小的文件，然后将小文件组合起来。

JavaScript 中的 `export` 是 ES6（ECMAScript 2015）引入的模块化语法，用于从模块中导出变量、函数、类等，以便其他模块可以使用 `import` 导入这些内容。

### 10.2.1 基本导出

> **1.导出单个变量、函数或类**

使用 `export` 关键字直接导出。

```javascript
// module.js
export const name = 'Alice';
export function greet() {
  console.log('Hello!');
}
export class Person {
  constructor(name) {
    this.name = name;
  }
}
```

> **2.导出默认值**

使用 `export default` 导出模块的默认值，一个模块只能有一个默认导出。

```javascript
// module.js
const message = 'Hello, World!';
export default message;
```

### 10.2.2 批量导出

> **1.导出多个内容**

在模块底部统一导出。

```javascript
// module.js
const name = 'Alice';
function greet() {
  console.log('Hello!');
}
class Person {
  constructor(name) {
    this.name = name;
  }
}

export { name, greet, Person };
```

> **2.重命名导出**

使用 `as` 关键字重命名导出的内容。

```javascript
// module.js
const name = 'Alice';
function greet() {
  console.log('Hello!');
}

export { name as userName, greet as sayHello };
```

### 10.2.3 重新导出

> **1.重新导出**

从一个模块中导入内容并立即导出。

```javascript
// module.js
export { name, greet } from './anotherModule.js';
```

> **2.重新导出默认值**

重新导出另一个模块的默认值。

```javascript
// module.js
export { default } from './anotherModule.js';
```

## 10.3 导入模块

### 10.3.1 导入使用

> **1.导入命名导出**

使用 `import { ... } from 'module'` 导入命名导出。

```javascript
// main.js
import { name, greet, Person } from './module.js';
console.log(name); // 输出: Alice
greet(); // 输出: Hello!
const person = new Person('Bob');
console.log(person.name); // 输出: Bob
```

> **2.导入默认导出**

使用 `import defaultExport from 'module'` 导入默认导出。

```javascript
// main.js
import message from './module.js';
console.log(message); // 输出: Hello, World!
```

> **3.导入所有内容**

使用 `import * as alias from 'module'` 导入所有内容并绑定到一个对象。

```javascript
// main.js
import * as module from './module.js';
console.log(module.name); // 输出: Alice
module.greet(); // 输出: Hello!
```

### 10.3.2 动态导入

使用 `import()` 动态加载模块，返回一个 `Promise`。
```javascript
// main.js
import('./module.js').then(module => {
  console.log(module.name); // 输出: Alice
  module.greet(); // 输出: Hello!
});
```

### 10.3.3 注意事项

1. **模块作用域**：模块中的变量、函数、类默认是模块作用域，不会污染全局作用域。
2. **严格模式**：模块默认启用严格模式。
3. **文件扩展名**：在浏览器中使用模块时，文件扩展名必须是 `.js` 或 `.mjs`。
4. **跨模块引用**：模块路径可以是相对路径、绝对路径或模块名称（如 `'lodash'`）。

## 10.4 综合案例

### 10.4.1 项目结构

```
src/
  ├── utils/
  │   └── math.js
  ├── models/
  │   └── user.js
  └── main.js
```

### 10.4.2 多个模块

**1. 创建 `math.js` 模块**。`math.js` 是一个工具模块，提供了一些数学相关的函数。

```javascript
// src/utils/math.js

// 命名导出：加法函数
export function add(a, b) {
  return a + b;
}

// 命名导出：减法函数
export function subtract(a, b) {
  return a - b;
}

// 默认导出：乘法函数
export default function multiply(a, b) {
  return a * b;
}
```

**2. 创建 `user.js` 模块**。`user.js` 是一个用户模块，定义了一个 `User` 类。

```javascript
// src/models/user.js

// 默认导出：User 类
export default class User {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  greet() {
    console.log(`Hello, my name is ${this.name} and I am ${this.age} years old.`);
  }
}
```

### 10.4.3 主类模块

**创建 `main.js` 主模块**。`main.js` 是主模块，导入了 `math.js` 和 `user.js`，并使用它们的功能。

```javascript
// src/main.js

// 导入 math.js 的命名导出
import { add, subtract } from "./utils/math.js";
// 导入 math.js 的默认导出
import multiply from "./utils/math.js";
// 导入 user.js 的默认导出
import User from "./models/user.js";

// 使用 math.js 的函数
console.log("加法结果：", add(10, 5)); // 15
console.log("减法结果：", subtract(10, 5)); // 5
console.log("乘法结果：", multiply(10, 5)); // 50

// 使用 user.js 的 User 类
const user = new User("Alice", 25);
user.greet(); // Hello, my name is Alice and I am 25 years old.
```
