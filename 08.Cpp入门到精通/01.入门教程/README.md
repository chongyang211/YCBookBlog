## 01.基础语法

- 1.1.1 C++语言介绍：是一种静态类型的、编译式的、通用的、大小写敏感的、不规则的编程语言，支持过程化编程、面向对象编程和泛型编程。
- 1.1.2 C++的特点：包括面向对象开发的四大特性：封装，继承，多态，抽象。
- 1.1.3 C++标准库：1.核心语言；2.C++ 标准库；3.标准模板库（STL）。
- 1.1.4 C++应用领域：1.系统编程；2.游戏开发；3.图形分析；4.桌面应用开发（比如qt应用）。
- 1.2.1 编译器是什么：是将 C++ 源代码转换为机器代码的工具，使程序能够在计算机上运行。
- 1.2.2 GCC编译器：通过 g++ 来编译cpp文件，编译后会生成一个a.out文件。
- 1.2.3 Clang编译器：Clang 是 LLVM 项目的一部分，专注于提供快速编译和清晰的错误信息。
- 1.2.5 IDE开发环境：IDE 集成了编译器、编辑器、调试器等工具，提供更便捷的开发体验。
- 1.4.0 最简单编译：`g++ main.cpp`，由于命令行中未指定可执行程序的文件名，编译器采用默认的 a.out。
- 1.4.1 编译单个文件：`g++ program.cpp -o program`，-o 选项指定可执行程序的文件名。
- 1.4.2 编译多个文件：`g++ main.cpp utils.cpp -o program`，这里要注意多个cpp文件放到一块。
- 1.4.3 指定C++标准：g++ 有些系统默认是使用 C++98，可以指定使用 C++11 来编译 main.cpp 文件。`g++ -std=c++11 main.cpp`。
- 1.4.4 启用优化：GCC/G++ 编译器提供的一组预定义的优化策略，旨在提高生成代码的执行效率。
- 1.6.1 命名空间概念：您可能会写一个名为 xyz() 的函数，在另一个可用的库中也存在一个相同的函数 xyz()。防止命名冲突，将代码逻辑分组。
- 1.6.2 定义命名空间：namespace MyNamespace {}，
- 1.6.3 访问命名空间成员：通过命名空间直接访问变量和成员函数，比如，`MyNamespace::value`，`MyNamespace::print();`。
- 1.6.4 嵌套命名空间：访问嵌套命名空间，比如这样，`Outer::Inner::print();`。
- 1.6.5 匿名命名空间：
- 1.6.7 标准命名空间：C++ 标准库的所有内容都定义在 `std` 命名空间中。
- 1.7.1 头文件扩展名：.h 是传统的 C 和 C++ 头文件扩展名，广泛使用。
- 1.7.2 头文件和实现类：.h头文件只放类，函数，变量的声明。具体的实现放在 `.cpp` 文件中。建议每个类单独一个头文件，便于维护和管理。
- 1.7.3 头文件保护：使用头文件保护（`#ifndef` / `#define` 或 `#pragma once`）防止重复包含。
- 1.8.1 访问控制修饰符:访问控制修饰符用于定义类成员的访问权限。`public`所有均可访问，`private`类本身访问，`protected`类和派生类访问。
- 1.8.2 存储类型修饰符：用于定义变量的存储方式和生命周期。比如`auto`自动推导类型，比如`static`表示静态变量生命周期整个程序。
- 1.8.3 类型限定符：类型限定符用于修饰变量的行为或属性。比如`const`不可修改，`volatile`禁止编译器优化保证多线程数据安全。
- 1.8.4 函数修饰符：`inline`内联函数，`virtual`虚函数需要被派生类重写，`override`明确被重写，`final`禁止被重写。
- 1.8.5 类修饰符：`final`禁止类被继承，`abstract`表示抽象类，通过纯虚函数实现抽象类。


## 02.数据类型

- 2.1.1 基本数据类型：比较常见有int，short，long，long long等不同的类型。还有浮点型，字符型，布尔型数据。
- 2.1.2 固定宽度类型：int、long 等类型的宽度是编译器决定，不同平台可能不一致，为了解决这种误差才设计固定宽度类型数据。
- 2.1.3 空类型 (void)：表示“无类型”或“无值”。1.函数不返回任何值；2.函数无参数；3.指向未指定类型的指针。
- 2.2.1 有符号类型：默认是有符号，有符号类型可以存储负数、正数和零，其中最高位用于表示符号（0 表示正数，1 表示负数）。
- 2.2.2 无符号类型：无符号类型是指只能表示非负数（包括零）的数据类型。例如，`unsigned int`表示无符号整数。
- 2.2.3 固定宽度整数类型：它们提供了明确大小的整数类型，方便跨平台开发时确保数据大小的一致性。
- 2.3.1 字符类型列表：字符型变量用于显示单个字符，字符型变量并不是把字符本身放到内存中存储，而是将对应的`ASCII`编码放入到存储单元。
- 3.3.2 字符类型特点：`char` 可以是有符号或无符号，具体取决于编译器和平台。 通常用于存储 ASCII 字符（0 到 127）。
- 2.3.3 字符使用场景：`char`主要是用在处理 `ASCII` 字符，或者处理 `Unicode` 字符
- 2.4 浮点类型：浮点类型用于表示实数（即带小数点的数字）。它们基于 IEEE 754 标准，提供了不同精度的浮点数表示。
- 2.5.1 布尔类型使用：布尔数据类型代表真或假的值。
- 2.5.2 布尔类型底层：占用 1 个字节，虽然底层用 1 和 0 表示，但在代码层面应始终使用 true和 false以提高可读性和避免混淆。
- 2.6.1 变量：给一段指定的内存空间起名，方便操作这段内存。
- 2.6.2 常量：第一种宏常量`#define 常量名 常量值`；第二种在变量定义前加关键字`const`，修饰该变量为常量，不可修改。
- 2.7 类型转换：将一种数据类型转换为另一种数据类型的过程。C++ 提供了多种类型转换方式，包括隐式转换和显式转换。
- 2.7.1 隐式类型转换：隐式类型转换由编译器自动完成，通常发生在赋值、表达式计算或函数调用时。
- 2.7.2 显式类型转换：C风格转换是强制转化，比如将`double`转化为`int`类型。C++风格是提供了四种显式转换运算符，更加安全和明确。
- 2.7.2.1 `static_cast`：用于基本数据类型之间的转换，以及具有继承关系的类之间的转换。
- 2.7.2.2 `dynamic_cast`：用于具有多态性的类之间的转换（通常用于向下转型），转换失败时返回 `nullptr`。
- 2.7.2.3 `const_cast`：用于移除或添加 `const` 或 `volatile` 修饰符。
- 2.7.3.4 `reinterpret_cast`：用于低级别的类型转换，通常用于指针或整数之间的转换。
- 2.7.4 类型转换总结：C++ 提供了四种显式转换运算符：`static_cast`、`dynamic_cast`、`const_cast`、`reinterpret_cast`。


## 03.运算符

- 3.1.1 运算符由来：主要是数学与逻辑的抽象，引入编程中用于操作变量、常量和表达式。
- 3.1.2 运算符本质：从底层看，运算符是编译器内置的、具有特定功能的“函数”。当你写 a + b时，编译器会将其翻译成类似 operator+(a, b)。
- 3.2.4 算术运算符底层原理：硬件指令与编译器翻译，被编译器翻译成目标 CPU 架构的机器指令。这些指令直接在 CPU 的算术逻辑单元 (ALU) 上执行。
- 3.4.1 比较运算符案例：用于表达式的比较，并返回一个真值或假值。
- 3.4.2 比较运算符底层原理：
- 3.5.1 逻辑非：用于取反操作，将真变为假，将假变为真。
- 3.5.2 逻辑与：当两个操作数都为真时，结果为真；否则结果为假。
- 3.5.3 逻辑或：当多个操作数据，有一个为真的时候结果为真；否则结果为假。
- 3.8.1 sizeof介绍：`sizeof` 是一个运算符，用于获取数据类型或变量所占用的内存大小（以字节为单位）。
- 3.8.2 基本用法：`sizeof(类型)`：获取某种数据类型的大小。`sizeof(表达式)`：获取表达式结果类型的大小。
- 3.8.3 sizeof与数组：`sizeof` 可以用于计算数组的总大小或数组元素的大小。
- 3.8.4 sizeof与结构体：`sizeof` 可以用于计算结构体的大小。注意，结构体的大小可能会受到内存对齐的影响。
- 3.8.5 sizeof与类：`sizeof` 可以用于计算类的大小。类的大小包括成员变量的大小，并可能受到内存对齐和虚函数表（如果有虚函数）的影响。
- 3.8.6 sizeof与指针：`sizeof`用于指针时，返回指针本身的大小，而不是指针指向的对象的大小。
- 3.8.7 sizeof与字符串：`sizeof` 用于字符串时，返回字符串数组的大小，而不是字符串的长度。
- 3.8.8 sizeof动态内存：`sizeof` 不能用于计算动态分配内存的大小，因为它只能计算编译时已知的类型或变量的大小。

## 04.复合类型

- 4.1.1 复合数据类型：是由基本数据类型组合而成的更复杂的数据结构。它们允许将多个值组织在一起，以便更高效地管理和操作数据。
- 4.2.2 C风格字符串：C风格字符串是`char 变量名[] = "字符串值"`，
- 4.2.3 C++风格字符串：C++风格字符串`string  变量名 = "字符串值"`，
- 4.4.1 数组基本概念：是一种用于存储相同类型元素的连续内存数据结构。数组的大小在声明时固定，不能动态改变。
- 4.5.1 什么是联合体：是一种特殊的数据类型，它允许在相同的内存位置存储不同的数据类型。
- 4.5.2 联合体定义：联合体的定义语法与结构体类似，使用关键字 `union`。
- 4.5.3 联合体特点：联合体在同一时间只能存储一个成员的值。修改一个成员会影响其他成员的值。
- 4.6 枚举：是一种用户定义的数据类型，用于表示一组命名的整数常量。
- 4.6.1 无作用域枚举：无作用域枚举是 C 语言风格的枚举（`enum 名称`），枚举常量在全局作用域中可见。
- 4.6.2 有作用域枚举：C++11 引入了有作用域枚举（`enum class 名称`），枚举常量在枚举的作用域内可见，避免了命名冲突。
- 4.6.3 枚举底层类型：默认情况下，枚举的底层类型是 `int`，但可以显式指定其他整数类型。
- 4.6.4 枚举应用场景：使用枚举表示程序的状态或模式，使用枚举表示选项或标志。

## 06.函数

- 6.1.1 函数概念：是一段可重用的代码块，用于执行特定的任务。函数可以提高代码的模块化、可读性和可维护性。
- 6.1.2 函数声明和定义：函数的定义一般主要有5个步骤，返回值类型，函数名，参数，函数体语句，return返回值。
- 6.1.3 函数分类：有参函数和无参函数
- 6.1.4 Lambda函数:C++11 引入了 Lambda 函数，用于定义匿名函数。
- 6.2.1 值传递：传递参数的副本，函数内对参数的修改不会影响原始值。
- 6.2.2 引用传递：传递参数的引用，函数内对参数的修改会影响原始值。
- 6.4.1 函数重载案例：是指在同一个作用域内，可以定义多个同名函数，但它们的参数列表不同。函数重载允许使用相同的函数名来实现不同的功能。
- 6.5.1 内联函数是什么：通过将函数体直接插入到调用处，内联函数可以避免函数调用的额外开销（如栈帧的创建和销毁），从而提高程序的执行效率。
- 6.5.2 内联函数定义：在函数声明或定义前加上 `inline` 关键字：编译器会尝试将函数调用替换为函数体，以减少函数调用的开销。



## 07.指针

- 7.1.1 什么是指针：它存储了一个内存地址。指针可以指向其他变量或对象的内存地址，通过指针，可以直接访问和操作内存中的数据。
- 7.1.2 指针声明：语法是`数据类型 *指针变量名;`，举一个例子，int *number，那么number便是一个指针。
- 7.1.3 指针初始化：指针在使用前必须初始化，否则会指向一个未知的内存地址，可能导致程序崩溃。
- 7.1.3 指针占用空间：在 C++ 中，指针的大小取决于编译器和操作系统的位数。在 32 位系统中，指针通常占用 4 个字节（32 位）的内存空间。
- 7.2.1 取地址运算符：`&` 用于获取变量的内存地址。
- 7.2.2 解引用运算符：`*` 用于访问指针指向的内存地址中的值。
- 7.4 指针和函数：指针可以作为函数的参数或返回值，用于传递或返回内存地址。
- 7.5 指针与常量：1.常量指针；2.指向常量的指针；3.指向常量的常量指针。
- 7.6.1 指针的指针：指针可以指向另一个指针。
- 7.6.2 函数指针：函数指针是指向函数的指针变量，可以用于动态调用函数。
- 7.7.1 空指针：空指针通常用来表示指针没有被初始化或者指向了无效的内存地址。在 C++ 中，空指针的值通常是 0 或者使用 nullptr 关键字表示。
- 7.7.2 野指针：野指针是指指向未知内存地址或已释放的内存地址的指针，使用野指针可能会导致程序崩溃、内存泄漏或产生不可预测的行为。

## 08.引用

- 8.1.1 什么是引用：引用是一个变量的别名，它必须在声明时初始化，并且一旦绑定到一个变量后，就不能再绑定到其他变量。
- 8.1.2 引用的声明：给变量起别名，`数据类型 &引用名 = 变量名;`
- 8.2.1 引用必须初始化：引用在声明时必须绑定到一个变量，否则会编译错误。
- 8.2.2 引用不能重新绑定：引用一旦绑定到一个变量后，就不能再绑定到其他变量。
- 8.2.3 引用访问数据：通过引用可以访问和修改原变量的值。
- 8.4.1 引用作为函数参数：函数可以返回引用，但必须确保返回的引用指向的变量在函数调用结束后仍然有效。
- 8.4.2 引用作为函数返回值：引用可以作为函数的返回值，但必须确保返回的引用指向有效的内存。
- 8.5.1 常量引用：常量引用（const 引用）用于防止通过引用修改原变量，同时避免拷贝开销。
- 8.6 引用的本质：引用的本质在c++内部实现是一个指针常量。

## 09.结构体

- 9.1.1 什么是结构体：是一种用户定义的数据类型，用于将不同类型的数据组合在一起。以便更方便地管理和操作这些数据。
- 9.2.1 结构体定义：`struct 结构体名 {}`，这种方式来定义结构体。主要作用是：1.组织数据，2.传递复杂数据。
- 9.2.2 结构体创建：3种不同创建方式，最常见是`student stu`，然后通过stu.name来访问结构体中元素。
- 9.3.1 结构体做参数：将结构体作为参数向函数中传递，如果不想修改主函数中的数据，用值传递，反之用地址传递。
- 9.3.2 结构体做返回值：
- 9.3.3 结构体const场景：使用 const 关键字修饰结构体意味着该结构体实例是不可修改的，即其成员变量在声明后不能被修改。
- 9.4 结构体数组：结构体数组允许你在一个数组中存储多个结构体实例，每个实例可以包含多个数据成员。
- 9.5 结构体嵌套：这种结构体嵌套的方式允许你创建更复杂的数据结构，将多个相关的数据项组合在一起。
- 9.6 结构体指针：利用操作符`-> `就可以访问到结构体中属性。

## 10.类和对象

- 10.1 类的介绍：C++认为==万事万物都皆为对象==，对象上有其属性和行为。
- 10.1.1 类的含义：类是一种用户自定义的数据类型，用于封装数据和方法（函数）。类可以看作是一种模板，用于创建具有相似属性和行为的对象。
- 10.1.2 struct和class区别：struct和class唯一的区别就在于，默认的访问权限不同。
- 10.2.1 类的定义：用户自定义的类型，在设计类的时候，属性和行为写在一起，表现事物。
- 10.2.2 创建对象：创建无参数对象 `Student yc1;`，通过有参函数创建对象`Student yc2(number, name);`
- 10.2.3 访问类成员：创建对象以后，可以使用点号.来访问成员变量和成员函数。比如：`yc1.name = "打工充";`

- 11.1.1 继承基本概念：允许一个类可以基于另外一个类而创建，而且可以复用其基类的成员并可以拓展功能。
- 11.1.2 继承的语法：`class Dog : public Animal`，注意这个访问修饰符可以是`public`，`private`，`protected`等。
- 11.2.1 公有继承：子类对象可以访问到基类的公共权限属性和方法，基类私有的不能访问。
- 11.2.2 保护继承：在保护继承中，基类 **`public` 和 `protected` 成员** 在派生类中都变为 **`protected`** 成员，而基类**`private` 成员** 在派生类中仍然是不可访问的。

- 11.3.1 继承中对象模型：单继承中，派生类对象包含基类部分和派生类部分。
- 11.3.2 继承中构造和析构顺序：继承中，先调用父类的构造函数然后再调用子类构造函数，在销毁时先调用子类析构函数然后在调用父类析构函数。

## 10.动态内存

- `10.1 内存分区模型`：将内存大方向划分为4个区域，代码区，全局区，栈区，堆区
- 15.1.1 如何理解代码区：存储程序的二进制代码（即编译后的机器指令）。主要是在函数作用域中的代码，执行完即释放。
- 15.1.2 如何理解全局区：1.全局变量存储在全局区，2.静态局部变量存储在全局区。特点是在程序启动时分配，程序结束时释放。
- 15.1.3 如何理解栈区：存储局部变量、函数参数、函数返回地址等。一般在函数方法中，比如局部变量存储在栈区，方法调用完后就释放。
- 15.1.4 如何理解堆区：存储动态分配的内存（如 new 和 malloc 分配的内存），这些动态内存需要手动释放
- 15.2.1 什么是动态内存：指程序在运行时（而不是编译时）从堆区（Heap）分配的内存。通过 new 和 delete 操作符来分配和释放内存。
- 15.2.5 如何理解内存泄漏：如果动态分配的内存没有被释放，会导致内存泄漏。解决方法：确保每次 new 都有对应的 delete。
- 15.2.6 如何理解野指针：未初始化的指针称为野指针，访问野指针会导致未定义行为。
- 15.2.7 如何理解悬空指针问题：释放内存后，指针仍然指向已释放的内存地址，称为悬空指针。解决方法：释放内存后将指针置为 nullptr。
- 15.4 智能指针：用于自动管理动态内存，避免内存泄漏和悬空指针。
- 15.4.1 unique_ptr：独占所有权的智能指针。
- 15.4.2 shared_ptr：共享所有权的智能指针。
- 15.4.3 weak_ptr：弱引用，不增加引用计数。
