# 14.类型系统与类型推导原理

## 引言

C++拥有静态类型语言中最复杂、最强大的类型系统之一。从C++11开始，`auto`、`decltype`等类型推导机制让C++代码变得更简洁，但也带来了理解上的挑战。本文将深入探讨C++类型系统的设计原理、类型推导的底层规则，以及现代C++中类型相关的各种机制。

## 一、C++类型系统概览

### 1.1 类型的本质

```
类型在编译器中的含义：
  1. 内存大小：这个类型的对象需要多少字节
  2. 内存布局：数据成员如何在内存中排列
  3. 对齐要求：对象的首地址必须是几字节的倍数
  4. 合法操作：哪些运算符和函数可以应用于这个类型
  5. 值的解释：相同的bit pattern在不同类型下有不同含义

例子：4字节内存 0x40490FDB
  作为int:   1078530011
  作为float: 3.14159265（IEEE 754）
  作为char[4]: "@I\x0f\xdb"
  类型决定了如何解释这些字节
```

```
C++ 类型体系:

基础类型 (Fundamental Types)

│   │   ├── wchar_t
│   │   ├── short / unsigned short
│   │   ├── int / unsigned int
│   │   ├── long / unsigned long

│   └── 浮点类型
│       ├── float

复合类型 (Compound Types)
```

## 二、隐式类型转换

### 2.1 转换的层级

```cpp
// C++中隐式转换的优先级（从高到低）：
// 1. 精确匹配（无需转换）
// 2. 左值变换（lvalue transformation）
// 3. 限定修饰转换（qualification adjustment）
// 4. 提升（promotion）
// 5. 标准转换（conversion）
// 6. 用户定义转换（user-defined conversion）

// 整数提升 (Integer Promotion)
void promotions() {
    char c = 'A';
    short s = 100;
    
    // char和short在运算时提升为int
    auto r1 = c + s;   // int（不是char也不是short）
    auto r2 = c + c;   // int（即使两个操作数都是char）
    
    // bool提升为int
    auto r3 = true + true;  // int: 2
}

// 算术转换 (Usual Arithmetic Conversions)
void arithmetic_conversions() {
    int i = 10;
    unsigned u = 20;
    long l = 30;
    double d = 40.0;
    
    // 规则：较低精度转换为较高精度
    auto r1 = i + d;   // double（int → double）
    auto r2 = i + l;   // long（int → long）
    auto r3 = i + u;   // unsigned int（有符号 → 无符号，危险！）
    
    // 陷阱：有符号与无符号比较
    int x = -1;
    unsigned y = 1;
    if (x < y) {
        // 不会执行！因为 -1 转换为 unsigned 变成了一个很大的数
        std::cout << "Expected" << std::endl;
    }
    // x被转换为unsigned: (unsigned)(-1) = 4294967295
    // 4294967295 < 1 为false
}
```

### 2.2 用户定义转换

```cpp
class Rational {
public:
    Rational(int num = 0, int den = 1)  // 可以从int隐式转换
        : num_(num), den_(den) {}
    
    // 转换运算符：Rational → double
    operator double() const {
        return static_cast<double>(num_) / den_;
    }
    
    // C++11 explicit转换运算符
    explicit operator bool() const {
        return num_ != 0;
    }
    
private:
    int num_, den_;
};

void user_defined_conversions() {
    Rational r(3, 4);
    
    // 隐式转换：int → Rational（通过构造函数）
    Rational r2 = 5;   // 等价于 Rational(5)
    
    // 隐式转换：Rational → double（通过转换运算符）
    double d = r;       // 0.75
    
    // explicit转换运算符
    if (r) {            // OK：在条件上下文中explicit bool可以隐式转换
        // ...
    }
    // bool b = r;      // 错误：explicit禁止隐式转换
    bool b = static_cast<bool>(r);  // OK：显式转换
}

// explicit构造函数
class String {
public:
    explicit String(int size) : data_(size, '\0') {}
    String(const char* s) : data_(s) {}
    
private:
    std::string data_;
};

void explicit_demo() {
    String s1("hello");       // OK：const char* → String
    String s2(10);            // OK：直接构造
    // String s3 = 10;        // 错误：explicit阻止隐式转换
    String s4 = "hello";     // OK：非explicit构造函数
    
    // 在函数调用中
    void take_string(String s);
    take_string("hello");    // OK
    // take_string(10);      // 错误：explicit
    take_string(String(10)); // OK：显式构造
}
```

### 2.3 转换的二义性

```cpp
class A {
public:
    operator int() const { return 0; }
};

class B {
public:
    B(const A&) {}  // 从A隐式转换
};

void take_b(B b) {}
void take_int(int n) {}

void ambiguity() {
    A a;
    
    take_int(a);   // OK：A → int（唯一路径）
    take_b(a);     // OK：A → B（唯一路径）
    
    // 但如果A同时有operator B()...
    // void f(int);
    // void f(B);
    // f(a);        // 二义性！A→int 和 A→B 优先级相同
}
```

## 三、auto类型推导

### 3.1 auto的基本规则

```cpp
// auto的推导规则与模板参数推导相同
// auto x = expr; 等价于 template<typename T> void f(T param);

auto x = 42;           // int（整数字面量）
auto d = 3.14;         // double
auto s = "hello";      // const char*（不是string！）

const auto& cr = x;    // const int&
auto* p = &x;          // int*

// auto会丢弃顶层const和引用
const int ci = 42;
auto a = ci;            // int（丢弃const）

int& ri = x;
auto b = ri;            // int（丢弃引用）

// 保持const和引用需要显式声明
const auto& c = ci;     // const int&
auto& d2 = ci;          // const int&（底层const保留）
```

### 3.2 auto推导的特殊情况

```cpp
// 初始化列表
auto il = {1, 2, 3};     // std::initializer_list<int>
// auto il2 = {1, 2.0};  // 错误：不能推导混合类型

// C++14: auto在函数返回类型
auto add(int a, int b) {
    return a + b;         // 推导为int
}

// 多条return必须类型一致
auto ambiguous(bool flag) {
    if (flag) return 1;    // int
    else return 2;         // int（必须一致）
    // return 1.0;         // 如果和上面不一致，编译错误
}

// C++14: auto在lambda参数中
auto generic_lambda = [](auto x, auto y) {
    return x + y;
};
// 等价于：
// struct Lambda {
//     template<typename T, typename U>
//     auto operator()(T x, U y) const { return x + y; }
// };

// C++17: 类模板参数推导（CTAD）
std::vector v = {1, 2, 3};            // std::vector<int>
std::pair p = {42, "hello"};          // std::pair<int, const char*>
std::tuple t = {1, 2.0, "three"};    // std::tuple<int, double, const char*>

// C++20: auto在函数参数中（简写模板）
void print(auto const& value) {
    std::cout << value << std::endl;
}
// 等价于：
// template<typename T>
// void print(T const& value) { ... }
```

### 3.3 auto与类型退化

```cpp
// auto的推导涉及类型退化（decay）
// 规则与模板参数推导一致

// 数组退化为指针
int arr[10];
auto a = arr;    // int*（不是int[10]）
auto& b = arr;   // int(&)[10]（引用保留数组类型）

// 函数退化为函数指针
void foo(int);
auto f = foo;    // void(*)(int)
auto& g = foo;   // void(&)(int)

// 理解decay
#include <type_traits>

static_assert(std::is_same_v<
    std::decay_t<int[10]>, 
    int*
>);

static_assert(std::is_same_v<
    std::decay_t<void(int)>, 
    void(*)(int)
>);

static_assert(std::is_same_v<
    std::decay_t<const int&>, 
    int
>);
```

## 四、decltype类型推导

### 4.1 decltype的规则

```cpp
// decltype(expr) 推导表达式的类型，但不求值

int x = 42;
decltype(x) y = x;           // int（变量名 → 声明类型）

const int& rx = x;
decltype(rx) z = x;          // const int&（保留引用和const）

// decltype的两种模式：

// 模式一：对变量名，返回变量的声明类型
int i = 0;
decltype(i)    a;    // int
decltype((i))  b = i; // int& ← 注意！加括号变成了左值表达式

// 模式二：对表达式，根据值类别返回类型
// 左值表达式 → T&
// 亡值表达式 → T&&
// 纯右值表达式 → T

int arr[5];
decltype(arr[0]) c = i;     // int&（arr[0]是左值）
decltype(1 + 2) d;           // int（1+2是纯右值）
decltype(std::move(i)) e = std::move(i);  // int&&（亡值）
```

### 4.2 decltype(auto)

```cpp
// C++14引入decltype(auto)：使用decltype的规则进行推导

// 对比auto和decltype(auto)
int x = 42;
int& rx = x;

auto a = rx;            // int（auto丢弃引用）
decltype(auto) b = rx;  // int&（decltype保留引用）

// 最常用场景：完美转发返回值
template<typename Container, typename Index>
auto get_element(Container& c, Index i) 
    -> decltype(auto)        // 保留返回值的引用特性
{
    return c[i];             // 如果c[i]返回T&，函数也返回T&
}

std::vector<int> v = {1, 2, 3};
decltype(auto) elem = get_element(v, 0);  // int&
elem = 100;  // 修改了v[0]

// 注意陷阱
decltype(auto) f1() {
    int x = 42;
    return x;      // OK: decltype(x) = int
}

decltype(auto) f2() {
    int x = 42;
    return (x);    // 危险！decltype((x)) = int&，返回局部变量的引用！
}
```

### 4.3 decltype在模板中的应用

```cpp
// 尾随返回类型（C++11）
template<typename T, typename U>
auto add(T t, U u) -> decltype(t + u) {
    return t + u;
}

// C++14：直接auto即可
template<typename T, typename U>
auto add14(T t, U u) {
    return t + u;
}

// 但有时decltype更精确
template<typename Container>
auto front(Container& c) -> decltype(c.front()) {
    return c.front();
}
// 如果用auto，会丢弃引用
// decltype保留c.front()的返回类型（通常是T&）

// std::declval：在不创建对象的情况下获取类型
#include <utility>

template<typename T, typename U>
using add_result_t = decltype(std::declval<T>() + std::declval<U>());
// 不需要T和U有默认构造函数

// 使用示例
static_assert(std::is_same_v<add_result_t<int, double>, double>);
static_assert(std::is_same_v<add_result_t<std::string, const char*>, std::string>);
```

## 五、模板参数推导

### 5.1 函数模板推导规则

```cpp
template<typename T>
void f(T param);           // 按值传递

template<typename T>
void g(T& param);          // 按引用传递

template<typename T>
void h(T&& param);         // 万能引用

int x = 42;
const int cx = 42;
const int& rx = x;

// 按值传递：丢弃const和引用
f(x);    // T = int
f(cx);   // T = int（丢弃const）
f(rx);   // T = int（丢弃引用和const）

// 按引用传递：保留const
g(x);    // T = int,       param: int&
g(cx);   // T = const int, param: const int&
g(rx);   // T = const int, param: const int&

// 万能引用：引用折叠
h(x);    // T = int&,        param: int& （左值→左值引用）
h(cx);   // T = const int&,  param: const int&
h(42);   // T = int,         param: int&& （右值→右值引用）
```

### 5.2 引用折叠规则

```cpp
/*
引用折叠规则（Reference Collapsing）:
  T& &    → T&     (左值引用 + 左值引用 = 左值引用)
  T& &&   → T&     (左值引用 + 右值引用 = 左值引用)
  T&& &   → T&     (右值引用 + 左值引用 = 左值引用)
  T&& &&  → T&&    (右值引用 + 右值引用 = 右值引用)

规律：只要有一个左值引用，结果就是左值引用
     只有两个都是右值引用，结果才是右值引用
*/

// 这就是万能引用和完美转发的基础
template<typename T>
void wrapper(T&& arg) {
    // 如果传入左值int：T = int&, arg类型 = int& && = int&
    // 如果传入右值int：T = int,  arg类型 = int&&
    
    // std::forward利用引用折叠保持值类别
    inner(std::forward<T>(arg));
}

// std::forward的实现原理
template<typename T>
T&& forward(std::remove_reference_t<T>& arg) noexcept {
    return static_cast<T&&>(arg);
}

// 当T = int&时：
//   static_cast<int& &&>(arg) = static_cast<int&>(arg)
//   → 转发为左值

// 当T = int时：
//   static_cast<int&&>(arg)
//   → 转发为右值
```

### 5.3 CTAD：类模板参数推导 (C++17)

```cpp
// C++17: Class Template Argument Deduction

// 标准库容器
std::vector v = {1, 2, 3};            // vector<int>
std::pair p = {42, 3.14};             // pair<int, double>
std::optional o = 42;                  // optional<int>

// 自定义类的CTAD
template<typename T, typename U>
struct MyPair {
    T first;
    U second;
    
    MyPair(T f, U s) : first(f), second(s) {}
};

// 编译器自动生成推导指引
MyPair mp = {1, 2.0};  // MyPair<int, double>

// 自定义推导指引（Deduction Guide）
template<typename T>
struct Container {
    Container(T) {}
    Container(std::initializer_list<T>) {}
};

// 推导指引
Container(const char*) -> Container<std::string>;

Container c1 = 42;       // Container<int>
Container c2 = "hello";  // Container<std::string>（通过推导指引）

// 聚合体的CTAD (C++20)
template<typename T, typename U>
struct Aggregate {
    T x;
    U y;
};

Aggregate a = {1, 2.0};  // C++20: Aggregate<int, double>
```

### 6.3 SFINAE原理

```cpp
// SFINAE: Substitution Failure Is Not An Error
// 模板参数替换失败不是错误，只是把该候选排除

// 基础示例
template<typename T>
typename T::value_type get_first(const T& container) {
    return *container.begin();
}

template<typename T>
T get_first(T value) {
    return value;
}

// get_first(std::vector<int>{1,2,3}) → 调用第一个（int有value_type）
// get_first(42) → 第一个替换失败（int没有value_type）→ 调用第二个

// enable_if实现SFINAE
template<typename T, 
         typename = std::enable_if_t<std::is_integral_v<T>>>
T double_value(T x) {
    return x * 2;
}

template<typename T,
         typename = std::enable_if_t<std::is_floating_point_v<T>>>
T double_value(T x) {
    return x + x;
}

// 返回值位置的SFINAE
template<typename T>
auto serialize(const T& obj) 
    -> std::enable_if_t<std::is_arithmetic_v<T>, std::string>
{
    return std::to_string(obj);
}

template<typename T>
auto serialize(const T& obj)
    -> std::enable_if_t<std::is_class_v<T>, std::string>
{
    return obj.to_string();
}
```

## 七、Concepts (C++20)

### 7.1 从SFINAE到Concepts

```cpp
// C++20 Concepts: SFINAE的优雅替代

// SFINAE方式（冗长、难读）
template<typename T, 
         typename = std::enable_if_t<
             std::is_integral_v<T> && (sizeof(T) >= 4)>>
T old_style(T x) { return x * 2; }

// Concepts方式（简洁、清晰）
template<typename T>
concept LargeInteger = std::is_integral_v<T> && (sizeof(T) >= 4);

template<LargeInteger T>
T new_style(T x) { return x * 2; }

// 或使用requires子句
template<typename T>
    requires std::is_integral_v<T> && (sizeof(T) >= 4)
T another_style(T x) { return x * 2; }

// 或简写模板
auto shortest_style(LargeInteger auto x) { return x * 2; }
```

### 7.2 定义Concepts

```cpp
#include <concepts>

// 基本concept定义
template<typename T>
concept Numeric = std::is_arithmetic_v<T>;

template<typename T>
concept Addable = requires(T a, T b) {
    { a + b } -> std::convertible_to<T>;  // a+b的结果可以转为T
};

template<typename T>
concept Printable = requires(T a, std::ostream& os) {
    { os << a } -> std::same_as<std::ostream&>;
};

// 复合concept
template<typename T>
concept Container = requires(T c) {
    typename T::value_type;           // 必须有value_type
    typename T::iterator;             // 必须有iterator
    { c.begin() } -> std::same_as<typename T::iterator>;
    { c.end() } -> std::same_as<typename T::iterator>;
    { c.size() } -> std::convertible_to<std::size_t>;
    { c.empty() } -> std::convertible_to<bool>;
};

// 继承式concept
template<typename T>
concept SortableContainer = Container<T> && requires(T c) {
    requires std::random_access_iterator<typename T::iterator>;
};

// 使用concepts
template<Container C>
void print_all(const C& container) {
    for (const auto& elem : container) {
        std::cout << elem << " ";
    }
    std::cout << std::endl;
}

// 标准库预定义concepts
// std::integral, std::floating_point, std::signed_integral
// std::same_as, std::derived_from, std::convertible_to
// std::regular, std::movable, std::copyable
// std::equality_comparable, std::totally_ordered
// std::invocable, std::predicate
// std::input_iterator, std::random_access_iterator
// std::range
```

### 7.3 Concepts与重载决议

## 八、类型擦除

### 8.1 std::function

```cpp
#include <functional>

// std::function: 类型擦除的可调用对象包装器
std::function<int(int, int)> op;

// 可以存储各种可调用对象
op = [](int a, int b) { return a + b; };          // lambda
op = std::plus<int>{};                              // 函数对象
op = static_cast<int(*)(int,int)>([](int a, int b) { return a + b; }); // 函数指针

// std::function的简化实现原理
template<typename Signature>
class MyFunction;

template<typename Ret, typename... Args>
class MyFunction<Ret(Args...)> {
public:
    // 类型擦除的基类
    struct Concept {
        virtual ~Concept() = default;
        virtual Ret invoke(Args... args) = 0;
        virtual std::unique_ptr<Concept> clone() const = 0;
    };
    
    // 具体类型的模型
    template<typename F>
    struct Model : Concept {
        F func;
        Model(F f) : func(std::move(f)) {}
        Ret invoke(Args... args) override {
            return func(std::forward<Args>(args)...);
        }
        std::unique_ptr<Concept> clone() const override {
            return std::make_unique<Model>(func);
        }
    };
    
    // 构造函数（模板，接受任何可调用对象）
    template<typename F>
    MyFunction(F f) : impl_(std::make_unique<Model<F>>(std::move(f))) {}
    
    // 调用
    Ret operator()(Args... args) const {
        return impl_->invoke(std::forward<Args>(args)...);
    }
    
    // 复制
    MyFunction(const MyFunction& other) 
        : impl_(other.impl_ ? other.impl_->clone() : nullptr) {}
    
private:
    std::unique_ptr<Concept> impl_;
};
```

### 8.3 std::variant (C++17)

```cpp
#include <variant>

// variant: 类型安全的union
std::variant<int, double, std::string> v;

v = 42;                    // 持有int
v = 3.14;                  // 持有double
v = std::string("hello");  // 持有string

// 访问方式
std::string s = std::get<std::string>(v);   // OK
// int i = std::get<int>(v);                // 抛出bad_variant_access

// std::visit: 模式匹配
std::visit([](auto&& arg) {
    using T = std::decay_t<decltype(arg)>;
    if constexpr (std::is_same_v<T, int>)
        std::cout << "int: " << arg << std::endl;
    else if constexpr (std::is_same_v<T, double>)
        std::cout << "double: " << arg << std::endl;
    else if constexpr (std::is_same_v<T, std::string>)
        std::cout << "string: " << arg << std::endl;
}, v);

// Overload pattern
template<typename... Ts>
struct overloaded : Ts... { using Ts::operator()...; };
template<typename... Ts>
overloaded(Ts...) -> overloaded<Ts...>;

std::visit(overloaded{
    [](int i) { std::cout << "int: " << i << "\n"; },
    [](double d) { std::cout << "double: " << d << "\n"; },
    [](const std::string& s) { std::cout << "string: " << s << "\n"; }
}, v);
```

### 9.1 编译期类型计算

```cpp
// 编译期判断和分发
template<typename T>
auto process(T value) {
    if constexpr (std::is_integral_v<T>) {
        return value * 2;
    } else if constexpr (std::is_floating_point_v<T>) {
        return value * 2.0;
    } else if constexpr (std::is_same_v<T, std::string>) {
        return value + value;
    } else {
        static_assert(always_false<T>::value, "Unsupported type");
    }
}

// always_false辅助
template<typename>
struct always_false : std::false_type {};
```

### 9.2 类型列表（TypeList）

```cpp
// 编译期类型列表
template<typename... Ts>
struct TypeList {};

// 获取第一个类型
template<typename List>
struct Front;

template<typename Head, typename... Tail>
struct Front<TypeList<Head, Tail...>> {
    using type = Head;
};

// 获取列表大小
template<typename List>
struct Size;

template<typename... Ts>
struct Size<TypeList<Ts...>> {
    static constexpr size_t value = sizeof...(Ts);
};

// 查找类型
template<typename List, typename T>
struct Contains;

template<typename T>
struct Contains<TypeList<>, T> : std::false_type {};

template<typename Head, typename... Tail, typename T>
struct Contains<TypeList<Head, Tail...>, T> 
    : std::conditional_t<std::is_same_v<Head, T>,
                         std::true_type,
                         Contains<TypeList<Tail...>, T>> {};

// 使用
using MyTypes = TypeList<int, double, std::string>;
static_assert(Size<MyTypes>::value == 3);
static_assert(std::is_same_v<Front<MyTypes>::type, int>);
static_assert(Contains<MyTypes, double>::value);
static_assert(!Contains<MyTypes, float>::value);
```

### 10.1 typeid与type_info

### 10.2 dynamic_cast

```cpp
class Base {
public:
    virtual ~Base() = default;
};

class Derived1 : public Base {
public:
    void specific_method() { std::cout << "Derived1\n"; }
};

class Derived2 : public Base {
public:
    void other_method() { std::cout << "Derived2\n"; }
};

void dynamic_cast_demo(Base* bp) {
    // 指针版本：失败返回nullptr
    if (auto* d1 = dynamic_cast<Derived1*>(bp)) {
        d1->specific_method();
    } else if (auto* d2 = dynamic_cast<Derived2*>(bp)) {
        d2->other_method();
    }
    
    // 引用版本：失败抛出std::bad_cast
    try {
        Derived1& d1 = dynamic_cast<Derived1&>(*bp);
        d1.specific_method();
    } catch (const std::bad_cast& e) {
        std::cout << "Not Derived1: " << e.what() << std::endl;
    }
}

/*
dynamic_cast的底层实现：
1. 获取对象的vptr（虚表指针）
2. 从虚表获取type_info
3. 遍历继承层次，检查是否能转换
4. 开销较大，不适合性能关键路径

替代方案：
- enum tag（手动类型标记）
- visitor模式
- std::variant + std::visit
*/
```

## 十一、类型转换运算符

### 11.1 四种类型转换

```cpp
// static_cast: 编译期检查的类型转换
double d = 3.14;
int i = static_cast<int>(d);            // 显式窄化
Base* bp = new Derived();
Derived* dp = static_cast<Derived*>(bp); // 向下转型（不安全，不检查）
void* vp = static_cast<void*>(bp);       // 指针→void*
bp = static_cast<Base*>(vp);             // void*→指针

// dynamic_cast: 运行时检查的多态转型
Base* bp2 = new Derived();
Derived* dp2 = dynamic_cast<Derived*>(bp2);  // 安全：运行时检查

// const_cast: 添加或移除const
const int ci = 42;
int* pi = const_cast<int*>(&ci);  // 移除const
// *pi = 100;  // 未定义行为！（原始对象是const）

// 合法用途：
void legacy_api(char* str);
void wrapper(const char* str) {
    // 我们知道legacy_api不会修改str
    legacy_api(const_cast<char*>(str));
}

// reinterpret_cast: 位模式重新解释
int x = 42;
int* p = &x;
uintptr_t addr = reinterpret_cast<uintptr_t>(p);  // 指针→整数
int* p2 = reinterpret_cast<int*>(addr);            // 整数→指针

// 也可以在不相关的指针类型之间转换
float f = 3.14f;
int bits = *reinterpret_cast<int*>(&f);  // 查看float的位模式
// 注意：这违反了strict aliasing规则
// 应该用memcpy或std::bit_cast (C++20)
```

### 11.2 std::bit_cast (C++20)

```cpp
#include <bit>

// bit_cast: 安全的位模式重新解释
float f = 3.14f;
int bits = std::bit_cast<int>(f);  // 安全！不违反aliasing规则

// 要求：源类型和目标类型大小相同，且都是trivially copyable
static_assert(sizeof(float) == sizeof(int));

// 等价于（C++20之前的安全做法）：
// float f = 3.14f;
// int bits;
```

### 12.1 类型推导选择指南

```
┌────────────────────┬──────────────────────────────┐
│ 场景               │ 推荐方式                      │
├────────────────────┼──────────────────────────────┤
│ 简单变量声明       │ auto                         │
│ 保留引用/const     │ decltype(auto)               │
│ 返回值类型推导     │ auto（C++14）                 │
│ 完美转发返回值     │ decltype(auto)               │
│ 模板约束           │ Concepts (C++20)             │
│ 旧代码SFINAE       │ enable_if + type_traits      │
│ 获取表达式类型     │ decltype(expr)               │
│ 编译期分支         │ if constexpr + type_traits   │
│ 类型安全联合       │ std::variant                 │
│ 任意类型容器       │ std::any                     │
│ 类型擦除回调       │ std::function                │
└────────────────────┴──────────────────────────────┘
```

### 12.2 C++类型系统的演进

```
C++98/03: 静态类型系统基础
  - 基础类型、类类型
  - 隐式/显式类型转换
  - RTTI (typeid, dynamic_cast)
  - 模板和函数重载

  - auto关键字
  - decltype
  - 右值引用和引用折叠
  - type_traits库
  - nullptr_t

C++14: 推导能力增强
  - auto返回类型推导
  - decltype(auto)
  - 泛型lambda (auto参数)

C++17: 结构化绑定与variant
  - 结构化绑定 (auto [a, b] = ...)
  - CTAD (类模板参数推导)
  - std::variant / std::optional / std::any
  - if constexpr
  - std::void_t

C++20: Concepts革命
  - Concepts和requires
  - auto函数参数（简写模板）
  - std::bit_cast
  - std::source_location

C++23及未来:
  - 模式匹配 (Pattern Matching)
```
