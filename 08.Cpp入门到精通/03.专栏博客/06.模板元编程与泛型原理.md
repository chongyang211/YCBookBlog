## 1. 引言

模板是C++最强大也最复杂的特性之一。它不仅是泛型编程的基础，更构成了一套完整的编译期计算系统——模板元编程（Template Metaprogramming, TMP）。

### 1.1 模板的三重角色

```
C++模板的三重角色：
├── 1. 泛型编程工具：编写类型无关的代码（STL）
├── 2. 编译期计算引擎：在编译期执行计算和逻辑
└── 3. 代码生成器：按需实例化特化版本
```

## 2. 函数模板

### 2.1 基础语法与实例化

```cpp
// 函数模板定义
template<typename T>
T max_value(T a, T b) {
    return (a > b) ? a : b;
}

// 模板参数推导
void function_template_basics() {
    int a = max_value(3, 5);        // T推导为int
    double b = max_value(3.14, 2.72); // T推导为double
    
    // 显式指定模板参数
    auto c = max_value<double>(3, 3.14);  // 强制T为double
    
    // 推导失败的情况
    // auto d = max_value(3, 3.14);  // 错误：T不一致（int vs double）
}

// 多个模板参数
template<typename T, typename U>
auto add(T a, U b) -> decltype(a + b) {
    return a + b;
}

// C++14简化：返回类型推导
template<typename T, typename U>
auto add_v2(T a, U b) {
    return a + b;
}
```

### 2.2 模板实例化过程

**疑惑**：模板是怎么变成真正可执行代码的？

```cpp
template<typename T>
T square(T x) { return x * x; }

// 当你写：
int a = square(5);      // 触发实例化 square<int>
double b = square(3.14); // 触发实例化 square<double>

// 编译器在后台生成：
// int square_int(int x) { return x * x; }
// double square_double(double x) { return x * x; }

// 关键点：
// 1. 模板本身不生成代码
// 2. 只有使用时才会实例化（惰性实例化）
// 3. 每种类型组合生成一份独立的代码
// 4. 这就是"代码膨胀"的来源
```

**答疑**：模板实例化分两个阶段：

```
第一阶段（定义时）：
├── 检查模板语法是否正确
├── 检查不依赖模板参数的名称
└── 不检查依赖模板参数的表达式

第二阶段（实例化时）：
├── 将模板参数替换到模板中
├── 检查替换后的代码是否合法
├── 生成实际的函数/类代码
└── 进行完整的类型检查和语义分析
```

### 2.3 函数模板重载

```cpp
// 非模板函数优先于模板函数
void print(int x) {
    std::cout << "Non-template: " << x << std::endl;
}

template<typename T>
void print(T x) {
    std::cout << "Template: " << x << std::endl;
}

template<typename T>
void print(T* x) {
    std::cout << "Pointer template: " << *x << std::endl;
}

void overload_resolution() {
    print(42);         // 非模板版本（精确匹配优先）
    print(3.14);       // 模板版本 T=double
    int x = 10;
    print(&x);         // 指针模板版本（更特化）
    print<>(42);       // 强制使用模板版本
}
```

## 3. 类模板

### 3.1 基础类模板

```cpp
template<typename T, size_t N>
class Array {
    T data_[N];
    
public:
    constexpr size_t size() const { return N; }
    
    T& operator[](size_t idx) {
        if (idx >= N) throw std::out_of_range("Index out of range");
        return data_[idx];
    }
    
    const T& operator[](size_t idx) const {
        if (idx >= N) throw std::out_of_range("Index out of range");
        return data_[idx];
    }
    
    T* begin() { return data_; }
    T* end()   { return data_ + N; }
    const T* begin() const { return data_; }
    const T* end()   const { return data_ + N; }
};

void class_template_demo() {
    Array<int, 5> arr;       // T=int, N=5
    Array<double, 10> darr;  // T=double, N=10
    // 每个不同的T和N组合是一个独立的类型
    // Array<int, 5> 和 Array<int, 10> 是完全不同的类型
}
```

### 3.2 类模板的成员函数

```cpp
template<typename T>
class Stack {
    std::vector<T> data_;
    
public:
    void push(const T& val);
    void push(T&& val);
    T pop();
    const T& top() const;
    bool empty() const { return data_.empty(); }
    
    // 成员函数模板（可以与类模板参数不同）
    template<typename U>
    Stack<T>& operator=(const Stack<U>& other);
};

// 类外定义
template<typename T>
void Stack<T>::push(const T& val) {
    data_.push_back(val);
}

template<typename T>
void Stack<T>::push(T&& val) {
    data_.push_back(std::move(val));
}

template<typename T>
T Stack<T>::pop() {
    T val = std::move(data_.back());
    data_.pop_back();
    return val;
}

// 成员模板的类外定义
template<typename T>
template<typename U>
Stack<T>& Stack<T>::operator=(const Stack<U>& other) {
    // 允许不同类型间的赋值（如 Stack<double> = Stack<int>）
    // 只要U可以转换为T
    data_.clear();
    for (const auto& elem : other.data_) {
        data_.push_back(static_cast<T>(elem));
    }
    return *this;
}

// 类模板参数推导(CTAD) - C++17
void ctad_demo() {
    std::vector v = {1, 2, 3};    // 推导为 vector<int>
    std::pair p = {1, 3.14};      // 推导为 pair<int, double>
    // Stack s = ...;             // 需要推导指引
}
```

## 4. 模板特化

### 4.1 完全特化

```cpp
// 主模板
template<typename T>
class TypeInfo {
public:
    static std::string name() { return "unknown"; }
    static size_t alignment() { return alignof(T); }

// 完全特化
template<>
class TypeInfo<int> {
public:
    static std::string name() { return "int"; }
    static size_t alignment() { return 4; }
    static int min() { return INT_MIN; }
    static int max() { return INT_MAX; }
};

template<>
class TypeInfo<double> {
public:
    static std::string name() { return "double"; }
    static size_t alignment() { return 8; }
};

void specialization_demo() {
    std::cout << TypeInfo<int>::name() << std::endl;     // "int"
    std::cout << TypeInfo<double>::name() << std::endl;  // "double"
    std::cout << TypeInfo<char>::name() << std::endl;    // "unknown"
}
```

### 4.2 偏特化

```cpp
// 偏特化：只特化部分参数或添加约束

// 主模板
template<typename T>
class Container {
public:
    void info() { std::cout << "Generic container\n"; }
};

// 指针类型的偏特化
template<typename T>
class Container<T*> {
public:
    void info() { std::cout << "Pointer container\n"; }
};

// 数组类型的偏特化
template<typename T, size_t N>
class Container<T[N]> {
public:
    void info() { std::cout << "Array container [" << N << "]\n"; }
};

void partial_specialization() {
    Container<int> c1;      // 主模板
    Container<int*> c2;     // 指针特化
    Container<int[10]> c3;  // 数组特化
    
    c1.info();  // Generic container
    c2.info();  // Pointer container
    c3.info();  // Array container [10]
}

// 注意：函数模板不能偏特化！只能重载
// template<typename T>
// void func(T*) {}  // 这是重载，不是偏特化
```

## 5. SFINAE与类型萃取

### 5.1 SFINAE原则

SFINAE（Substitution Failure Is Not An Error）——替换失败不是错误。

```cpp
#include <type_traits>

// SFINAE基础示例
template<typename T>
typename T::value_type get_value(const T& container) {
    return container.front();
}

// 如果T没有value_type成员，这个特化会"替换失败"
// 但这不是编译错误，编译器会继续查找其他重载

template<typename T>
T get_value(T value) {
    return value;
}

void sfinae_basic() {
    std::vector<int> vec = {1, 2, 3};
    auto a = get_value(vec);    // 第一个重载：T::value_type存在
    auto b = get_value(42);     // 第二个重载：int没有value_type
}
```

### 5.2 std::enable_if

```cpp
// enable_if: 条件性地启用/禁用模板
template<typename T>
typename std::enable_if<std::is_integral<T>::value, T>::type
safe_divide(T a, T b) {
    if (b == 0) throw std::runtime_error("Division by zero");
    return a / b;
}

template<typename T>
typename std::enable_if<std::is_floating_point<T>::value, T>::type
safe_divide(T a, T b) {
    return a / b;  // 浮点除零产生inf，不需要检查
}

// C++14简化写法
template<typename T, std::enable_if_t<std::is_integral_v<T>>* = nullptr>
T safe_abs(T x) {
    return x < 0 ? -x : x;
}

// C++17 if constexpr 更简洁
template<typename T>
T safe_divide_v2(T a, T b) {
    if constexpr (std::is_integral_v<T>) {
        if (b == 0) throw std::runtime_error("Division by zero");
    }
    return a / b;
}
```

## 6. 模板元编程

### 6.1 编译期计算

```cpp
// 经典示例：编译期阶乘
template<int N>
struct Factorial {
    static constexpr int value = N * Factorial<N-1>::value;
};

template<>
struct Factorial<0> {
    static constexpr int value = 1;
};

// 编译期fibonacci
template<int N>
struct Fibonacci {
    static constexpr int value = Fibonacci<N-1>::value + Fibonacci<N-2>::value;
};

template<> struct Fibonacci<0> { static constexpr int value = 0; };
template<> struct Fibonacci<1> { static constexpr int value = 1; };

void compile_time_computation() {
    constexpr int fact5 = Factorial<5>::value;  // 120，编译期计算
    constexpr int fib10 = Fibonacci<10>::value; // 55，编译期计算
    
    // 可以用在需要编译期常量的地方
    int arr[Factorial<3>::value];  // int arr[6]
    static_assert(Fibonacci<10>::value == 55, "Fibonacci check");
}

// C++14+更推荐使用constexpr函数（见第15篇）
constexpr int factorial(int n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}
```

### 6.2 类型计算

```cpp
// 编译期类型列表
template<typename... Ts>
struct TypeList {};

// 获取第一个类型
template<typename List>
struct Head;

template<typename T, typename... Ts>
struct Head<TypeList<T, Ts...>> {
    using type = T;
};

// 获取剩余类型
template<typename List>
struct Tail;

template<typename T, typename... Ts>
struct Tail<TypeList<T, Ts...>> {
    using type = TypeList<Ts...>;
};

// 计算类型列表长度
template<typename List>
struct Length;

template<typename... Ts>
struct Length<TypeList<Ts...>> {
    static constexpr size_t value = sizeof...(Ts);
};

// 检查类型是否在列表中
template<typename T, typename List>
struct Contains;

template<typename T>
struct Contains<T, TypeList<>> : std::false_type {};

template<typename T, typename... Ts>
struct Contains<T, TypeList<T, Ts...>> : std::true_type {};

template<typename T, typename U, typename... Ts>
struct Contains<T, TypeList<U, Ts...>> : Contains<T, TypeList<Ts...>> {};

void type_computation_demo() {
    using MyTypes = TypeList<int, double, std::string>;
    
    using First = Head<MyTypes>::type;  // int
    using Rest = Tail<MyTypes>::type;   // TypeList<double, string>
    
    constexpr size_t len = Length<MyTypes>::value;  // 3
    
    constexpr bool has_int = Contains<int, MyTypes>::value;       // true
    constexpr bool has_char = Contains<char, MyTypes>::value;     // false
}
```

## 7. 可变参数模板

### 7.1 参数包基础

```cpp
// 可变参数模板
template<typename... Args>
void print_all(Args... args) {
    // sizeof...(args) 获取参数个数
    std::cout << "参数个数: " << sizeof...(args) << std::endl;
}

// 递归展开参数包
void print() {}  // 递归终止

template<typename T, typename... Rest>
void print(T first, Rest... rest) {
    std::cout << first << " ";
    print(rest...);  // 递归展开
}

// C++17折叠表达式（更简洁）
template<typename... Args>
void print_fold(Args... args) {
    ((std::cout << args << " "), ...);  // 一元右折叠
    std::cout << std::endl;
}

// 折叠表达式的四种形式：
// (E op ...)       一元右折叠: E1 op (E2 op (E3 op E4))
// (... op E)       一元左折叠: ((E1 op E2) op E3) op E4
// (E op ... op I)  二元右折叠: E1 op (E2 op (E3 op I))
// (I op ... op E)  二元左折叠: ((I op E1) op E2) op E3

template<typename... Args>
auto sum(Args... args) {
    return (args + ...);  // 一元右折叠
}

template<typename... Args>
bool all_true(Args... args) {
    return (args && ...);  // 一元右折叠
}
```

### 7.2 可变参数模板的应用

```cpp
// 1. 完美转发的工厂函数
template<typename T, typename... Args>
std::unique_ptr<T> make_unique_impl(Args&&... args) {
    return std::unique_ptr<T>(new T(std::forward<Args>(args)...));
}

// 2. 类型安全的printf
template<typename T>
void format_arg(std::ostream& os, const T& val) {
    os << val;
}

template<typename... Args>
std::string format(const std::string& fmt, Args... args) {
    std::ostringstream oss;
    size_t pos = 0;
    
    // 使用折叠表达式处理每个参数
    auto process = [&](const auto& arg) {
        size_t next = fmt.find("{}", pos);
        if (next != std::string::npos) {
            oss << fmt.substr(pos, next - pos);
            format_arg(oss, arg);
            pos = next + 2;
        }
    };
    
    (process(args), ...);
    oss << fmt.substr(pos);
    return oss.str();
}

void variadic_demo() {
    print_fold(1, 2.5, "hello", 'x');
    std::cout << sum(1, 2, 3, 4, 5) << std::endl;  // 15
    
    std::string msg = format("Name: {}, Age: {}", "Alice", 30);
    std::cout << msg << std::endl;  // Name: Alice, Age: 30
}
```

## 9. 模板设计模式

### 9.1 策略模式(Policy-Based Design)

```cpp
// 排序策略
struct AscendingPolicy {
    template<typename T>
    static bool compare(const T& a, const T& b) { return a < b; }
};

struct DescendingPolicy {
    template<typename T>
    static bool compare(const T& a, const T& b) { return a > b; }
};

// 存储策略
template<typename T>
struct VectorStorage {
    using container_type = std::vector<T>;
    static void add(container_type& c, const T& val) { c.push_back(val); }
};

template<typename T>
struct DequeStorage {
    using container_type = std::deque<T>;
    static void add(container_type& c, const T& val) { c.push_back(val); }
};

// 策略组合
template<typename T, 
         typename SortPolicy = AscendingPolicy,
         template<typename> class StoragePolicy = VectorStorage>
class SortedCollection {
    typename StoragePolicy<T>::container_type data_;
    
public:
    void add(const T& val) {
        StoragePolicy<T>::add(data_, val);
    }
    
    void sort() {
        std::sort(data_.begin(), data_.end(),
            [](const T& a, const T& b) {
                return SortPolicy::compare(a, b);
            });
    }
    
    void print() const {
        for (const auto& item : data_)
            std::cout << item << " ";
        std::cout << std::endl;
    }
};

void policy_demo() {
    SortedCollection<int> asc;  // 默认：升序 + vector
    SortedCollection<int, DescendingPolicy, DequeStorage> desc;  // 降序 + deque
    
    for (int x : {5, 3, 1, 4, 2}) { asc.add(x); desc.add(x); }
    asc.sort();  asc.print();   // 1 2 3 4 5
    desc.sort(); desc.print();  // 5 4 3 2 1
}
```

### 9.2 表达式模板

```cpp
// 表达式模板：避免临时对象，延迟计算
// 用于高性能数学库（Eigen、Blaze等）

// 简化版本：向量加法
template<typename E>
class VecExpr {
public:
    double operator[](size_t i) const {
        return static_cast<const E&>(*this)[i];
    }
    size_t size() const {
        return static_cast<const E&>(*this).size();
    }
};

class Vec : public VecExpr<Vec> {
    std::vector<double> data_;
public:
    Vec(size_t n) : data_(n) {}
    Vec(std::initializer_list<double> init) : data_(init) {}
    
    double& operator[](size_t i) { return data_[i]; }
    double operator[](size_t i) const { return data_[i]; }
    size_t size() const { return data_.size(); }
    
    // 从表达式构造
    template<typename E>
    Vec(const VecExpr<E>& expr) : data_(expr.size()) {
        for (size_t i = 0; i < data_.size(); i++)
            data_[i] = expr[i];
    }
};

// 加法表达式（不计算，只记录操作）
template<typename E1, typename E2>
class VecAdd : public VecExpr<VecAdd<E1, E2>> {
    const E1& lhs_;
    const E2& rhs_;
public:
    VecAdd(const E1& l, const E2& r) : lhs_(l), rhs_(r) {}
    double operator[](size_t i) const { return lhs_[i] + rhs_[i]; }
    size_t size() const { return lhs_.size(); }
};

template<typename E1, typename E2>
VecAdd<E1, E2> operator+(const VecExpr<E1>& a, const VecExpr<E2>& b) {
    return VecAdd<E1, E2>(static_cast<const E1&>(a), static_cast<const E2&>(b));
}

void expression_template_demo() {
    Vec a = {1, 2, 3};
    Vec b = {4, 5, 6};
    Vec c = {7, 8, 9};
    
    // 传统方式：a + b + c
    // 创建临时对象tmp = a + b，然后再tmp + c
    
    // 表达式模板：
    Vec result = a + b + c;
    // a + b 返回 VecAdd<Vec, Vec>（不计算）
    // (a+b) + c 返回 VecAdd<VecAdd<Vec,Vec>, Vec>（仍不计算）
    // 赋值给result时，一次遍历完成所有计算：result[i] = a[i]+b[i]+c[i]
    // 零临时对象！
}
```

## 10. 模板的高级技巧

### 10.1 模板模板参数

```cpp
// 模板的参数也可以是模板
template<typename T, 
         template<typename, typename> class Container = std::vector>
class Stack {
    Container<T, std::allocator<T>> data_;
public:
    void push(const T& val) { data_.push_back(val); }
    T pop() { T v = data_.back(); data_.pop_back(); return v; }
};

void template_template_demo() {
    Stack<int, std::vector> vs;  // 使用vector
    Stack<int, std::deque> ds;   // 使用deque
    vs.push(1); ds.push(2);
}
```

### 10.2 变量模板(C++14)

```cpp
// 变量也可以是模板
template<typename T>
constexpr T pi = T(3.14159265358979323846);

template<typename T>
constexpr bool is_integral_v = std::is_integral<T>::value;

void variable_template_demo() {
    float  pf = pi<float>;   // 3.14159f
    double pd = pi<double>;  // 3.14159265358979
    
    static_assert(is_integral_v<int>);
    static_assert(!is_integral_v<double>);
}
```

### 10.3 模板的友元

```cpp
template<typename T>
class Box {
    T value_;
public:
    explicit Box(T val) : value_(val) {}
    
    // 友元函数模板
    template<typename U>
    friend bool operator==(const Box<U>& a, const Box<U>& b);
    
    // 友元类模板
    template<typename U>
    friend class BoxPrinter;
};

template<typename T>
bool operator==(const Box<T>& a, const Box<T>& b) {
    return a.value_ == b.value_;
}
```

## 11. 总结

### 11.1 模板知识图谱

```
C++模板
├── 函数模板
│   ├── 类型推导
│   ├── 重载
│   └── 特化（完全）
├── 类模板
│   ├── 成员函数模板
│   ├── 特化（完全/偏）
│   └── CTAD(C++17)
├── 可变参数模板
│   ├── 参数包
│   ├── 递归展开
│   └── 折叠表达式(C++17)
├── 元编程
│   ├── 编译期计算
│   ├── 类型计算
│   ├── SFINAE
│   └── if constexpr(C++17)
├── 类型萃取
│   ├── type_traits
│   ├── enable_if
│   └── Concepts(C++20)
└── 设计模式
    ├── 策略模式(Policy)
    ├── CRTP
    └── 表达式模板
```

### 11.2 最佳实践

| 建议 | 说明 |
|------|------|
| 优先用constexpr函数 | 代替模板元编程做编译期计算 |
| 优先用Concepts | 代替SFINAE做类型约束 |
| 优先用if constexpr | 代替特化做条件编译 |
| 限制模板嵌套深度 | 过深的嵌套导致编译缓慢和错误信息难读 |
| 头文件放定义 | 模板需要在使用处可见 |
| 注意代码膨胀 | 每种类型实例化一份代码 |

模板是C++的灵魂特性。掌握了模板，就掌握了C++泛型编程和编译期计算的核心能力。
