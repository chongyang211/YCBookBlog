## 1. 数据库系统需求

### 1.1 需求介绍

本项目旨在使用C++实现一个简易的内存数据库系统，帮助学习者理解数据库的基本原理和操作。

该系统支持基本的数据库操作，包括表的创建、数据的增删改查，以及数据的持久化存储。

### 1.2 功能介绍

- **表管理**：支持创建数据表，定义表结构
- **数据操作**：支持插入、删除、更新和查询数据
- **数据类型**：支持整型(int)、浮点型(float)、字符串(string)三种基本数据类型
- **持久化**：支持将数据保存到文件和从文件加载数据
- **内存管理**：自动管理动态内存分配和释放

### 1.3 核心功能模块

1. **数据结构模块**：定义列、行、表、数据库等核心数据结构
2. **表操作模块**：实现表的创建和管理
3. **数据操作模块**：实现数据的增删改查功能
4. **文件操作模块**：实现数据的持久化存储
5. **内存管理模块**：负责动态内存的分配和释放

### 1.4 功能分析

- **简单易用**：提供直观的API接口，便于理解和使用
- **类型安全**：通过枚举类型确保数据类型的正确性
- **内存安全**：使用RAII原则，自动管理内存生命周期
- **可扩展性**：模块化设计，便于功能扩展

## 3. 定义数据结构

### 3.1 列结构体

```cpp
// 数据类型枚举
enum DataType {
    TYPE_INT,      // 整型
    TYPE_FLOAT,    // 浮点型
    TYPE_STRING    // 字符串型
};

// 列类 - 定义表的列结构
class Column {
public:
    std::string name;  // 列名
    DataType type;     // 数据类型

    Column(const std::string& name, DataType type) : name(name), type(type) {}
};
```

**设计说明**：

- 使用枚举类型定义支持的数据类型，确保类型安全
- Column类封装列的基本属性：名称和数据类型
- 构造函数简化对象创建过程

### 3.2 行结构体

**设计说明**：

- 使用void*指针数组存储不同类型的数据。但同时缺少类型安全性，因为void*指针缺乏编译时类型检查
- columnTypes数组记录每个数据的类型，用于正确的类型转换
- 析构函数确保动态分配的内存得到正确释放

```cpp
// 行类 - 存储一行数据
class Row {
public:
    std::vector<void*> data;              // 存储实际数据的指针数组
    std::vector<DataType> columnTypes;    // 存储每列的数据类型

    ~Row() {
        // 析构函数负责释放动态分配的内存
        for (size_t i = 0; i < data.size(); i++) {
            if (data[i]) {
                switch (columnTypes[i]) {
                    case TYPE_INT:
                        delete static_cast<int*>(data[i]);
                        break;
                    case TYPE_FLOAT:
                        delete static_cast<float*>(data[i]);
                        break;
                    case TYPE_STRING:
                        delete static_cast<std::string*>(data[i]);
                        break;
                }
            }
        }
    }
};
```

### 3.3 表结构体

Table类采用了简单直观的关系型数据库表结构设计：

- 包含表的基本信息：表名、列定义、行数据。
- 使用指针数组管理行对象，便于动态添加和删除
- 析构函数确保所有行对象得到正确释放

```cpp
// 表类 - 表示数据库中的一张表
class Table {
public:
    std::string name;              // 表名
    std::vector<Column> columns;   // 列定义
    std::vector<Row*> rows;        // 行数据

    Table(const std::string& name) : name(name) {}

    ~Table() {
        // 析构函数释放所有行对象
        for (size_t i = 0; i < rows.size(); i++) {
            if (rows[i]) delete rows[i];
        }
    }
};
```

列式存储元数据： columns存储表的结构信息（列名和数据类型），使用Column类封装列的属性，包含名称和数据类型枚举

行式存储数据：rows存储实际的数据行，每个Row包含void*指针数组来存储不同类型的数据。

### 3.4 数据库结构体

设计理念：1.Database作为顶层容器，管理多个Table对象；2.采用指针存储Table，便于动态管理和多态扩展。

```text
Database (数据库层)
  └── Table (表层)
      ├── Column (列定义层)
      └── Row (数据行层)
```

职责分离：

1. Database：管理表集合、提供数据库级操作
2. Table：管理行数据、维护表结构
3. Row/Column：处理具体数据存储

```cpp
// 数据库类 - 管理多张表
class Database {
public:
    std::vector<Table*> tables;  // 存储所有表的指针

    ~Database() {
        // 析构函数释放所有表对象
        for (size_t i = 0; i < tables.size(); i++) {
            if (tables[i]) delete tables[i];
        }
    }

    // 核心功能接口
    void createTable(const std::string& tableName, const std::vector<Column>& columns);
    void insertRow(const std::string& tableName, const std::vector<void*>& data);
    void deleteRow(const std::string& tableName, int rowIndex);
    void updateRow(const std::string& tableName, int rowIndex, const std::vector<void*>& data);
    void queryTable(const std::string& tableName);
    void saveToFile(const std::string& filename);
    void loadFromFile(const std::string& filename);
};
```

**设计说明**：

- Database类是系统的核心，管理所有表对象
- 提供完整的数据库操作接口
- 使用RAII原则管理资源生命周期

步骤1：表查找

```cpp
    }
```

步骤2：索引有效性验证

```cpp
// 边界检查：确保索引非负且在有效范围内
if (rowIndex >= 0 && rowIndex < tables[i]->rows.size()) {
    // 执行删除操作
} else {
    std::cout << "行索引无效！" << std::endl;
```

步骤3：内存释放与容器更新

```cpp
delete tables[i]->rows[rowIndex];                    // 释放Row对象内存
tables[i]->rows.erase(tables[i]->rows.begin() + rowIndex); // 从容器中移除
```

内存管理策略： 1.先释放，后移除：确保没有内存泄漏；2.delete调用Row的析构函数，自动释放所有列数据的内存；3.vector::erase()从容器中移除指针，保持容器完整性

```cpp
void Database::deleteRow(const std::string& tableName, int rowIndex) {
    for (size_t i = 0; i < tables.size(); i++) {
        if (tables[i]->name == tableName) {
            // 检查行索引有效性
            if (rowIndex >= 0 && rowIndex < tables[i]->rows.size()) {
                delete tables[i]->rows[rowIndex];  // 释放行对象内存
                tables[i]->rows.erase(tables[i]->rows.begin() + rowIndex);  // 从容器中移除
                std::cout << "行删除成功！" << std::endl;
            } else {
                std::cout << "行索引无效！" << std::endl;
            }
            return;
        }
    }
    std::cout << "表 '" << tableName << "' 不存在！" << std::endl;
}
```

**实现要点**：
- 验证表名和行索引的有效性
- 先释放行对象的内存，再从容器中移除
- 提供详细的错误信息

```cpp
void Database::updateRow(const std::string& tableName, int rowIndex, const std::vector<void*>& data) {
```

### 5.1 保存数据到文件
```cpp
void Database::saveToFile(const std::string& filename) {
    std::ofstream file(filename.c_str(), std::ios::binary);
    if (!file) {
        std::cout << "无法打开文件 '" << filename << "'！" << std::endl;
        return;
    }

    // 保存表的数量
    size_t tableCount = tables.size();
    file.write((char*)&tableCount, sizeof(tableCount));

    // 保存每张表的数据
    for (size_t i = 0; i < tables.size(); i++) {
        Table* table = tables[i];
        
        // 保存表名
        size_t nameLength = table->name.size();
        file.write((char*)&nameLength, sizeof(nameLength));
        file.write(table->name.c_str(), nameLength);

        // 保存列信息
        size_t columnCount = table->columns.size();
        file.write((char*)&columnCount, sizeof(columnCount));
        
        for (size_t j = 0; j < table->columns.size(); j++) {
            const Column& column = table->columns[j];
            size_t columnNameLength = column.name.size();
            file.write((char*)&columnNameLength, sizeof(columnNameLength));
            file.write(column.name.c_str(), columnNameLength);
            file.write((char*)&column.type, sizeof(column.type));
        }

        // 保存行数据
        size_t rowCount = table->rows.size();
        file.write((char*)&rowCount, sizeof(rowCount));

        for (size_t j = 0; j < table->rows.size(); j++) {
            Row* row = table->rows[j];
            for (size_t k = 0; k < table->columns.size(); k++) {
                switch (table->columns[k].type) {
                    case TYPE_INT:
                        file.write((char*)row->data[k], sizeof(int));
                        break;
                    case TYPE_FLOAT:
                        file.write((char*)row->data[k], sizeof(float));
                        break;
                    case TYPE_STRING: {
                        std::string* str = (std::string*)row->data[k];
                        size_t strLength = str->size();
                        file.write((char*)&strLength, sizeof(strLength));
                        file.write(str->c_str(), strLength);
                        break;
                    }
                }
            }
        }
    }

    file.close();
    std::cout << "数据库保存成功！" << std::endl;
}
```

**实现要点**：
- 使用二进制格式保存，提高效率和准确性
- 保存数据结构的层次信息：表数量→表信息→列信息→行数据
- 对字符串类型特殊处理，先保存长度再保存内容
- 确保文件操作的安全性检查

### 5.2 从文件加载数据
```cpp
void Database::loadFromFile(const std::string& filename) {
    std::ifstream file(filename.c_str(), std::ios::binary);
    if (!file) {
        std::cout << "无法打开文件 '" << filename << "'！" << std::endl;
        return;
    }

    // 读取表的数量
    size_t tableCount;
    file.read((char*)&tableCount, sizeof(tableCount));

    // 读取每张表的数据
    for (size_t i = 0; i < tableCount; i++) {
        // 读取表名
        size_t nameLength;
        file.read((char*)&nameLength, sizeof(nameLength));
        char* nameBuffer = new char[nameLength + 1];
        file.read(nameBuffer, nameLength);
        nameBuffer[nameLength] = '\0';
        std::string tableName(nameBuffer);
        delete[] nameBuffer;

        Table* table = new Table(tableName);

        // 读取列信息
        size_t columnCount;
        file.read((char*)&columnCount, sizeof(columnCount));

        for (size_t j = 0; j < columnCount; j++) {
            size_t columnNameLength;
            file.read((char*)&columnNameLength, sizeof(columnNameLength));
            char* columnNameBuffer = new char[columnNameLength + 1];
            file.read(columnNameBuffer, columnNameLength);
            columnNameBuffer[columnNameLength] = '\0';
            std::string columnName(columnNameBuffer);
            delete[] columnNameBuffer;

            DataType columnType;
            file.read((char*)&columnType, sizeof(columnType));

            table->columns.push_back(Column(columnName, columnType));
        }

        // 读取行数据
        size_t rowCount;
        file.read((char*)&rowCount, sizeof(rowCount));

        for (size_t j = 0; j < rowCount; j++) {
            Row* row = new Row();
            for (size_t k = 0; k < table->columns.size(); k++) {
                const Column& column = table->columns[k];
                switch (column.type) {
                    case TYPE_INT: {
                        int* value = new int;
                        file.read((char*)value, sizeof(int));
                        row->data.push_back(value);
                        break;
                    }
                    case TYPE_FLOAT: {
                        float* value = new float;
                        file.read((char*)value, sizeof(float));
                        row->data.push_back(value);
                        break;
                    }
                    case TYPE_STRING: {
                        size_t strLength;
                        file.read((char*)&strLength, sizeof(strLength));
                        char* strBuffer = new char[strLength + 1];
                        file.read(strBuffer, strLength);
                        strBuffer[strLength] = '\0';
                        std::string* value = new std::string(strBuffer);
                        delete[] strBuffer;
                        row->data.push_back(value);
                        break;
                    }
                }
            }
            table->rows.push_back(row);
        }

        tables.push_back(table);
    }

    file.close();
    std::cout << "数据库加载成功！" << std::endl;
}
```

**实现要点**：
- 按照保存时的格式逆序读取数据
- 动态分配内存重建数据结构
- 正确处理字符串的读取和内存管理
- 确保读取过程中的内存安全

## 7.问题和思考

### 7.1 遍历为何用size_t

这里提一个问题：for遍历，为何用size_t而不是int？使用size_t的原因是什么？

1.类型匹配

```cpp
// rows.size() 返回的是 size_t 类型
std::vector<Row*> rows;
size_t vectorSize = rows.size();  // 类型匹配
```

2.避免编译器警告

```cpp
// 使用int会产生警告：signed/unsigned comparison
for (int i = 0; i < rows.size(); i++) {  // 警告！
    // ...
}

// 使用size_t没有警告
for (size_t i = 0; i < rows.size(); i++) {  // 正确
    // ...
}
```

3.语义更准确：size_t专门用于表示大小和索引，语义明确。int可以是负数，但数组索引不应该是负数

4.标准库一致性

```cpp
// 标准库容器的成员函数都返回size_t
vector::size()     // 返回size_t
string::length()   // 返回size_t
array::size()      // 返回size_t
```

### 8.3 三个延伸挑战

**A（基础）· 用 `std::variant` 替换原生 `union`**：如果你当前用的是 `union ColumnValue { int i; float f; char s[64]; }`，升级为 `using ColumnValue = std::variant<int, float, std::string>;`（C++17）。然后用 `std::visit` 统一打印所有类型——代码会从 `switch` 地狱变成优雅的单行。

**B（进阶）· WHERE 子句**：给 `select` 操作加上条件过滤，例如：
```cpp
db.select("users", {"name","age"}, [](const Row& r) { return r.get<int>("age") >= 18; });
```
这里需要用 `std::function<bool(const Row&)>`（卷一第 16 章）作为过滤器参数。

**C（挑战）· 简易 SQL 解析**：从字符串 `"SELECT name FROM users WHERE age > 18"` 解析出动作 / 列 / 表 / 条件，调用对应的 API。这是**字符串处理 + 状态机**的硬核训练，做下来基本等于写了 MiniSQL 的第一版。
