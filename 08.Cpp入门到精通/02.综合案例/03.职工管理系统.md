## 01.管理系统需求

### 1.1 需求介绍

职工管理系统可以用来管理公司内所有员工的信息，本教程主要利用C++来实现一个基于多态的职工管理系统

公司中职工分为三类：普通员工、经理、老板，显示信息时，需要显示职工编号、职工姓名、职工岗位、以及职责

1. 普通员工职责：完成经理交给的任务
2. 经理职责：完成老板交给的任务，并下发任务给员工
3. 老板职责：管理公司所有事务

### 1.2 功能介绍

管理系统中需要实现的功能如下：

* 退出管理程序：退出当前管理系统
- 增加职工信息：实现批量添加职工功能，将信息录入到文件中，职工信息为：职工编号、姓名、部门编号
- 显示职工信息：显示公司内部所有职工的信息
- 删除离职职工：按照编号删除指定的职工
- 修改职工信息：按照编号修改职工个人信息
- 查找职工信息：按照职工的编号或者职工的姓名进行查找相关的人员信息
- 按照编号排序：按照职工编号，进行排序，排序规则由用户指定
- 清空所有文档：清空文件中记录的所有职工信息 （清空前需要再次确认，防止误删）

### 1.3 核心功能模块

**职工管理**：

- 多态创建三种职工类型
- 职责动态绑定（函数指针）

**文件系统**：

- 自动保存/加载（带版本校验）
- 数据完整性验证（魔数+校验和）
- 备份恢复机制

**用户界面**：

- 直观菜单系统
- 实时反馈机制
- 操作日志记录

### 1.4 功能分析

职工信息的存储格式：我们将采用文本文件存储，每行存储一个职工的信息，格式为：职工编号,姓名,部门编号,岗位类型（1表示普通员工，2表示经理，3表示老板）。

### 1.5 设计核心思路

设计思路：

1. 抽象一个Worker基类，包含职工的基本信息（编号、姓名、部门编号）和显示信息的纯虚函数，以及职责的纯虚函数。
2. 派生三个子类：Employee（普通员工）、Manager（经理）、Boss（老板），分别实现纯虚函数。
3. 管理类WorkerManager，用于管理所有职工，包括增删改查、排序、清空、文件读写等功能。
4. 使用文件存储职工数据，文件名为worker.txt，存储格式为每行一个职工，包含职工编号、姓名、部门编号（用于标识岗位）以及一个表示岗位类型的字段（或者通过部门编号来区分岗位）。

职工的分类为：普通员工、经理、老板

#pragma once
#include<iostream>
#include<string>
using namespace std;

//职工抽象基类
class Worker {
public:

    virtual string getDeptName() = 0;

    virtual ~Worker() = default;

### 5.6 virtual作用原理

```cpp
virtual void showInfo() = 0;
virtual string getDeptName() = 0;
```

这两个函数都是纯虚函数（Pure Virtual Function），= 0表示纯虚函数。

原因1：实现多态机制

1. 运行时多态：virtual关键字使函数调用在运行时确定，而不是编译时
2. 动态绑定：通过基类指针调用函数时，会根据实际对象类型调用相应的函数实现

原因2：强制子类实现

1. 纯虚函数必须在派生类中被重写实现
2. 使Worker成为抽象基类，无法直接实例化
3. 确保所有派生类都提供自己的具体实现

```cpp
Worker* emp = new Employee(1, "张三", 1);
Worker* mgr = new Manager(2, "李四", 2);
Worker* boss = new Boss(3, "王五", 3);

// 同样的调用，不同的实现
emp->showInfo();   // 调用Employee::showInfo()
mgr->showInfo();   // 调用Manager::showInfo()
boss->showInfo();  // 调用Boss::showInfo()
```

如果不使用virtual：

```cpp
// 假设没有virtual
void showInfo();  // 普通函数

Worker* worker = new Employee();
worker->showInfo();  // 只会调用Worker::showInfo()，不是Employee::showInfo()
```

### 5.7 虚函数表机制

编译器实现原理：

1. 每个包含虚函数的类都有一个虚函数表(vtable)
2. 对象中包含指向虚函数表的指针(vptr)
3. 函数调用时通过vptr查找正确的函数地址

### 6.3 增加职工功能

在`workerManager.h`中添加成员函数

```cpp
// 添加职工
void addEmp();
```

addEmp函数采用动态数组扩容的设计模式，通过重新分配内存空间来实现职工数据的添加。

`workerManager.cpp`中实现该函数

1. 步骤1：输入验证。进行输入合法性检查，确保数量大于0
2. 步骤2：动态内存扩容。计算新的数组大小：原有职工数量 + 新增职工数量，分配新的内存空间，存储Worker指针数组。
3. 步骤3：数据迁移。将原有职工数据从旧数组复制到新数组，保持原有数据的完整性。
4. 步骤4：添加新职工数据。循环输入新职工的基本信息；根据岗位选择创建不同类型的Worker对象（多态应用）；将新创建的对象存储到数组的相应位置
5. 步骤5：内存管理和状态更新。

```cpp
//增加职工
void WorkerManager::addEmp() {
    //步骤1：输入验证
    cout << "请输入增加职工数量： " << endl;
    int addNum = 0;
    cin >> addNum;
    if (addNum == 0) {
        cout << "输入有误，请重新输入大于0的数值" << endl;
        return;
    }
    
    //步骤2：动态内存扩容。计算新的数组大小：原有职工数量 + 新增职工数量，分配新的内存空间，存储Worker指针数组。
    //计算新空间大小
    int newSize = this->empNum + addNum;
    //开辟新空间
    Worker ** newSpace = new Worker*[newSize];
    
    //步骤3：数据迁移。
    //将原空间下内容存放到新空间下
    if (this->empArray != NULL){
        for (int i = 0; i < this->empNum; i++){
            newSpace[i] = this->empArray[i];
        }
    }
    //输入新数据
    for (int i = 0; i < addNum; i++) {
        int id;
        string name;
        int dSelect;
        cout << "请输入第 " << i + 1 << " 个新职工编号：" << endl;
        cin >> id;
        cout << "请输入第 " << i + 1 << " 个新职工姓名：" << endl;
        cin >> name;
        cout << "请选择该职工的岗位：" << endl;
        cout << "1、普通职工" << endl;
        cout << "2、经理" << endl;
        cout << "3、老板" << endl;
        cin >> dSelect;
        Worker * worker = NULL;
        switch (dSelect) {
            case 1: //普通员工
                worker = new Employee(id, name, 1);
            break;
            case 2: //经理
                worker = new Manager(id, name, 2);
            break;
            case 3:  //老板
                worker = new Boss(id, name, 3);
            break;
            default:
                break;
        }
        newSpace[this->empNum + i] = worker;
    }
    //释放原有空间
    delete[] this->empArray;
    //更改新空间的指向
    this->empArray = newSpace;
    //更新新的个数
    this->empNum = newSize;
    //提示信息
    cout << "成功添加" << addNum << "名新职工！" << endl;
    //输入新数据
    clearScreen();
}
```

在WorkerManager.cpp的析构函数中，释放堆区数据

```cpp
WorkerManager::~WorkerManager() {
    //析构函数实现
    if (this->empArray != NULL) {
        delete[] this->empArray;
    }
}
```

### 6.4 添加职工原理

内存管理原理

1. 动态分配：使用new操作符动态分配内存
2. 指针数组：Worker**二级指针存储Worker对象的地址
3. 内存释放：及时释放旧内存避免内存泄漏

多态应用

### 10.5 删除职工原理

算法核心：数组元素前移删除法

```cpp
for (int i=index ; i < this->empNum ; i++) {
    this->empArray[i] = this->empArray[i+1];
}
this->empNum--;
```

这是经典的顺序表删除算法，时间复杂度为 O(n)。通过指针重新赋值实现元素"删除"，而非真正释放内存，删除位置后的所有元素依次向前移动一个位置。

### 10.6 内存泄漏风险

关键问题：内存泄漏风险

```cpp
// 当前实现只是移动指针，没有释放被删除对象的内存
this->empArray[i] = this->empArray[i+1];
```

被删除的 Worker 对象内存没有被 delete，造成内存泄漏。数组最后一个位置会保留重复的指针引用

```cpp
// 先释放要删除的对象内存
delete this->empArray[index];
// 再进行指针移动
for (int i=index ; i < this->empNum-1 ; i++) {
    this->empArray[i] = this->empArray[i+1];
}
// 清空最后一个位置
this->empArray[this->empNum-1] = nullptr;
this->empNum--;
```

### 12.4 遇到问题说明

问题代码如下所示：

```cpp
//先删除
delete this->empArray[index];
```

**报错问题的日志**：

```text
WorkerManager.cpp:306:9: warning: delete called on 'Worker' that is abstract but has non-virtual destructor [-Wdelete-abstract-non-virtual-dtor]
  306 |         delete this->empArray[index];
      |         ^
1 warning generated.
```

这个警告是由于在 WorkerManager.cpp 文件的第 306 行，你尝试删除一个指向抽象类 Worker 的指针，但 Worker 类没有定义虚析构函数。

**问题分析**

1. **抽象类**：`Worker` 是一个抽象类（至少包含一个纯虚函数），因此不能直接实例化。
2. **非虚析构函数**：如果基类（`Worker`）的析构函数不是虚函数，那么通过基类指针删除派生类对象时，只会调用基类的析构函数，而不会调用派生类的析构函数。这会导致派生类的资源未被正确释放，从而引发内存泄漏或未定义行为。
3. **警告信息**：编译器警告你，`delete` 操作符被用于一个抽象类指针，但该类的析构函数不是虚函数。

**解决方法**

为了使 `delete` 操作符能够正确调用派生类的析构函数，需要在 `Worker` 类中定义一个虚析构函数。

在 `Worker` 类的定义中添加虚析构函数：

```cpp
class Worker {
public:
    // 纯虚函数，使 Worker 成为抽象类
    virtual void doWork() = 0;

    // 添加虚析构函数
    // 将析构函数声明为虚函数，确保通过基类指针删除派生类对象时，能够正确调用派生类的析构函数。
    // `= default` 表示使用编译器生成的默认实现。
    virtual ~Worker() = default;
};
```

假设 `Worker` 类及其派生类的定义如下：

```cpp
#include <iostream>

// 基类
class Worker {
public:
    virtual void doWork() = 0;  // 纯虚函数
    virtual ~Worker() = default;  // 虚析构函数
};

// 派生类
class ConcreteWorker : public Worker {
public:
    void doWork() override {
        std::cout << "ConcreteWorker is working!" << std::endl;
    }

    ~ConcreteWorker() {
        std::cout << "ConcreteWorker destroyed!" << std::endl;
    }
};

int main() {
    Worker* worker = new ConcreteWorker();
    worker->doWork();
    delete worker;  // 正确调用 ConcreteWorker 的析构函数
    return 0;
}
```

**输出**

```
ConcreteWorker is working!
ConcreteWorker destroyed!
```

**注意事项**

1. **所有基类都应定义虚析构函数**：
   如果一个类可能被继承，并且可能通过基类指针删除派生类对象，那么基类的析构函数必须是虚函数。

2. **避免内存泄漏**：
   如果没有虚析构函数，派生类的资源可能无法正确释放，导致内存泄漏。

3. **抽象类的析构函数可以是纯虚函数**：
   如果需要，可以将析构函数声明为纯虚函数，但必须提供实现：
   ```cpp
   class Worker {
   public:
       virtual void doWork() = 0;
       virtual ~Worker() = 0;
   };

   Worker::~Worker() {}  // 纯虚析构函数的实现
   ```

        cout << "文件不存在或记录为空！" << endl;
    } else {
        cout << "请选择排序方式： " << endl;
        cout << "1、按职工号进行升序" << endl;
        cout << "2、按职工号进行降序" << endl;
        int select = 0;
        cin >> select;
        for (int i = 0; i < this->empNum; i++) {
            int minOrMax = i;
            for (int j = i + 1; j < empNum; j++) {
                if (select == 1) {
                    //升序
                    if (this->empArray[minOrMax]->id > empArray[j]->id) {
                        minOrMax = j;
                    }
                } else {
                    //降序
                    if (empArray[minOrMax]->id < empArray[j]->id) {
                        minOrMax = j;
                    }
                }
            }
            if (i != minOrMax) {
                Worker * temp = empArray[i];
                empArray[i] = empArray[minOrMax];
                empArray[minOrMax] = temp;
            }
        }
        cout << "排序成功,排序后结果为：" << endl;
        this->save();
        this->showEmp();
    }
    pause();
}

void WorkerManager::cleanFile() {

    int select = 0;
