# `IotUpgradeSchd::DownloadTask` 全流程

## 〇、函数定位

```text
ExecuteUpgradeQuery → FilterUpgradeTasks → DownloadAllTasks（循环）
                                              └─ DownloadTask(单个任务)  ← 本流程
                                          → ADVICE gate → InstallAllTasks
```

每次调用处理**一个**升级任务，返回 `0=成功` 或错误码。

## 一、流程步骤

### 1. 准备与开始埋点

| 步骤 | 内容 | 位置 |
|---|---|---|
| 确定下载文件名 | `GetDownloadFilename(task)` | :686 |
| 埋点 `kOtaStartDownload` | version + sub_appid（16160 表） | :690-698 |
| 任务页上报 `Downloading(6)+0` | FR-1，后台任务页进入“下载中” | :702 |

### 2. 构造进度心跳回调（:704-729）

- 30s `TimeCounter` 计时开始；
- 回调由 `DownloadProgressThrottler` 内层节流后触发，组装 16160 埋点：
  - `progress_pct`：`(offset+now)/total`，clamp 0~100；Content-Length 未知时 **-1**（不猜值）；
  - `speed_bps`：trailing 30s 滑窗平均速率；
  - `task_uid` + `version`：与后台任务关联键；
- Commit 走 HeartBeat 线程异步入队，不阻塞下载线程。

### 3. 调用 `DownloadService::Download`（:730-733）

内部流程（download_service.cpp）：

```text
缓存检查：目标文件已存在且 MD5 匹配 → 直接返回路径（跳过下载）
        │ 未命中
        ▼
按策略分支（云端下发，缺省 FULL）
  NONE：trunc 打开 .crdownload，直下
  FULL：追加打开 → seekp 尾部取 offset
        → offset>0 时 Range: bytes=0-0 探测（15s）
           206=续传 / 200 或 416=truncate 重下 / 其他=失败
        → 带 Range 主下载
传输中：限速 1MB/s｜总超时 15min｜低速熔断 <1KB/s×30s｜TCP keepalive
        10MB 本地日志｜Throttler 30s 心跳
完成后：状态码 2xx 校验 → MD5 校验（失败删半成品）→ rename 落盘
返回：variant<string 路径> 或 int32 错误码
```

### 4a. 失败分支（:750-764）——三条通道一次收口

| 顺序 | 通道 | 内容 |
|---|---|---|
| ① | task 标记 | `download_success=false`，`download_error_code=原始码` |
| ② | 埋点 `kOtaDownloadFail` | `result_code`=**原始细码** + `timecost` |
| ③ | 上位机 PosLink | `FAILED` + 原始细码；msg = `"download failed: {组件名}, report_code: {映射码}"` |
| ④ | 任务页 `ReportUpgradeStatus` | `Fail(4)` + `ToReportCode` 映射码（30503 / 30510←20101 / 30502←其余全部） |

返回原始 `error_code` 给调用方。

### 4b. 成功分支（:766-772）

- `task.download_path` 记录落盘路径，`download_success=true`；
- 埋点 `kOtaDownloadSuccess` + `timecost`（`result_code=0`）；
- 任务页/上位机此阶段**不推进**（Installing 在安装阶段才发）；
- 返回 0。

## 二、调用方循环语义（`DownloadAllTasks`，:659-683）

```text
for 每个任务:
    成功 → 收进 downloaded_tasks
    失败 → 记 first_error（首个错误），继续下一个任务（不中断批次）
全部结束:
    downloaded_tasks 为空 → 返回 first_error（无错误记录则 30502 兜底）
    否则                  → 返回 0，进入 ADVICE gate / 安装阶段
```

注：批次中**任一任务失败即导致整体返回非 0**，外层 `ExecuteUpgradeQuery` 会 `FinishUpgrade()` 结束本轮——即“部分下载成功”的任务也不会进入安装。

## 三、一次完整调用的输出汇总

| 输出 | 成功 | 失败 |
|---|---|---|
| 返回值 | 0 | 原始错误码 |
| task 状态 | `download_path` + `download_success=true` | `download_error_code` + `download_success=false` |
| 16160 埋点 | Start + Progress×N + Success | Start + Progress×N + Fail |
| 任务页 | `Downloading(6)`（终态在安装/后续阶段） | `Downloading(6)` → `Fail(4)`+映射码 |
| 上位机 | 无 | `FAILED`+原始码（msg 含映射码） |
