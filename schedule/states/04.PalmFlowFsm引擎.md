## `palm_flow_fsm_def.h` 的作用

这是状态机的**结构定义文件**——前面三问里的 `FlowAction`/`FlowContext`/`FlowEvent` 在这里是“词汇”，这个文件才是把 HFSM2 引擎、状态层次和转移图**装配起来**的地方。包含四部分：

### 1. `PalmFlowFsmContext`（第 37–51 行）— 状态的“工具箱”

HFSM2 注入的业务 Context（spec FR-10），状态通过 `control.context()` 访问：
- `biz_ctx` — 就是上一问的 `FlowContext`（业务数据黑板）；
- 五个 `std::function` 闭包 — 状态对机器的全部操作接口：`request_action`（入队 Action）、`emit_event`（上行事件）、`broadcast`（状态变化广播）、`arm_timer`/`disarm_timer`（状态超时）。由 `PalmFlowMachine` 构造时绑定（即上次看到的 `DoRequestAction` 等 wrapper）。

用闭包而非直接引用 wrapper class，是为了**打破循环依赖**：状态头文件只依赖本文件 + state_base。

### 2. HFSM2 配置与类型别名（第 55–56 行）

`C` / `M` 把 `PalmFlowFsmContext&` 配置为 HFSM2 的 Context 类型，`FSM` 别名（第 208 行起）就是**整棵状态树的声明**。

### 3. 状态类前向声明（第 60–86 行）— 状态的“花名册”

6 个 Head（`RootHead`/`RunningHead`/`BizProcessHead`/`RecognizingHead`/`RegisteringHead`/`VerifyingHead`）+ 19 个 leaf 状态，具体行为实现在 `palm_flow_states.h/.cpp`。

### 4. 状态层次 `FSM`（第 208–253 行）+ 注释里的转移图（第 88–207 行）— **状态机的“地图”**

层次结构（HFSM2 三层 Composite）：

```
Root
├─ Created / Starting
├─ Composite<RunningHead>
│   ├─ Detecting / PalmEntered / OptPassed
│   └─ Composite<BizProcessHead>
│       ├─ Composite<RecognizingHead>   识别子树: RecognizeEntry / LocalRecognizing / Recognizing(云端)
│       ├─ Composite<RegisteringHead>   注册子树: RegisterEntry / RegisterSubmitting /
│       │                                WaitingBindInput / WaitingScanInput / RegisterByCodeSubmitting
│       ├─ Composite<VerifyingHead>     加验子树: VerifyEntry / Verifying / VerifySubmitting
│       ├─ ResultObtained               统一 0xA3 出口（瞬态）
│       └─ WaitingHostAck               HOST_ACK 等待态
└─ Stopping / Done
```

层级本身承载语义：`StopReqEvent` 由 `RunningHead.react` 统一处理（任意运行子状态都可被打断 → kAbort 直转 Stopping）；而 BizProcessHead 子树不可打断（业务提交中不许停）。

### 5.完善版：状态层次全景图

```
Root (RootHead)
│
├─ CreatedState                          # 初始态。Reset 入口；Machine 构造时自动 enter，emit 首次广播
│

│    enter: request_action(kRunOnStart)
│    ├─ StartOkEvent  ──▶ Detecting
│    └─ StartFailEvent(kAbort) ──▶ Stopping          # 启动失败，跳过 ResultObtained
│
├─ Composite<RunningHead>                # ★ 运行区：react(StopReqEvent) 统一在这里拦截
│    │                                   #   → 任意子状态可被打断 → kAbort 直转 Stopping（不发 0xA3）
│    │
│    ├─ DetectingState                   # 检测中（等 SDK OptLive 链路信号）
│    │    ├─ PalmEnteredEvent ──▶ PalmEntered
│    │    └─ (Hybrid 100025 retry: request kSwitchSdkToRegister, ++retry_count)
│    │
│    ├─ PalmEnteredState                 # 掌已进入
│    │    └─ OptPassEvent ──▶ OptPassed
│    │
│    ├─ OptPassedState                   # 优选通过
│    │    enter: StopCodeScan（防扫码与识别并发）+ request_action(kDecidePostOpt)
│    │    react VerdictPostOptEvent:
│    │    ├─ V_Submit        ──▶ Recognizing 子树（经 RecognizeEntry）
│    │    ├─ V_EnterRegister ──▶ RegisterEntry        # HostEnroll / Hybrid 二轮
│    │    └─ V_Complete      ──▶ ResultObtained
│    │
│    └─ Composite<BizProcessHead>        # ★ 业务处理区：不可打断（IsInterruptible=false）
│         │
│         ├─ Composite<RecognizingHead>  # ── 识别子树（story 136969382）──
│         │    ├─ RecognizeEntryState    # 瞬态：update 按同步开关+工作模式分派
│         │    │    ├─ 端侧 ──▶ LocalRecognizing
│         │    │    └─ 云端 ──▶ Recognizing
│         │    ├─ LocalRecognizingState  # 等 SDK 端侧识别结果
│         │    │    enter: arm_timer(kLocalIdentifyRequest)
│         │    │    react LocalIdentifyResultEvent → request kDecidePostRec
│         │    └─ RecognizingState       # 云端 HTTP 路径（原 RecognizingState 保名下移）
│         │         enter: palm_data/camera_data 齐备即 request kRecRequest
│         │                              # Controller 按 IsActive<VerifyingHead> 路由 /recognize
│         │         react RecResponseEvent → request kDecidePostRec
│         │         （响应 → VerdictPostRecEvent）
│         │
│         ├─ Composite<RegisteringHead>  # ── 注册子树 ──
│         │    ├─ RegisterEntryState     # 瞬态：等数据齐备 request kRegisterRequest
│         │    ├─ RegisterSubmittingState# 注册提交中
│         │    │    react RegisterResponseEvent → request kDecidePostRegister
│         │    │    react VerdictPostRegisterEvent:
│         │    │    ├─ V_Complete      ──▶ ResultObtained
│         │    │    ├─ V_RequireVerify ──▶ Verifying 子树
│         │    │    ├─ V_WaitBindInput ──▶ WaitingBindInput      # palm_state=Unregistered + HOST
│         │    │    └─ V_WaitScanInput ──▶ WaitingScanInput      # palm_state=Unregistered + CPM
│         │    ├─ WaitingBindInputState  # 等上位机录掌（story 135094532）
│         │    │    enter: arm_timer(kBindInputRequest) + emit NeedBindInputEvent(0xAC, kBindInput)
│         │    │    react BindPalmRequestEvent  → disarm + request kProcessBindPalm
│         │    │    react BindPalmResultEvent:
│         │    │    ├─ 成功 ──▶ ResultObtained（completion_source=kBindFinished）
│         │    │    └─ 失败 ──▶ 自循环重试（emit 0xAC error_code≠0，不限次，timer 不重置）
│         │    │    StateTimeout ──▶ ResultObtained（PALM_SESSION_TIMEOUT=124）
│         │    ├─ WaitingScanInputState  # 反扫码等身份码（story 137286676）
│         │    │    enter: arm_timer(kScanInputRequest，deadline 跨重试保留) + emit 0xAC(kScanInput)

│         │    │    StateTimeout ──▶ ResultObtained（SCAN_INPUT_TIMEOUT=161）
│         │    └─ RegisterByCodeSubmittingState  # 身份码注册提交
│         │         enter: request kRegisterByCodeRequest + arm_timer(kRegisterRequest)
│         │         react RegisterByCodeResultEvent:
│         │         ├─ code=0          ──▶ ResultObtained（kBindFinished，0xA3 is_bind_palm=1）
│         │         ├─ 163 码过期      ──▶ 回 WaitingScanInput（0xAC 163 重试）
│         │         ├─ 162 非身份码    ──▶ 回 WaitingScanInput（0xAC 162 重试）
│         │         └─ 其他(116/141/…) ──▶ ResultObtained 收敛结束
│         │
│         ├─ Composite<VerifyingHead>    # ── 加验子树（story 134755867）──
│         │    │    入口：识别/注册决策返 V_RequireVerify（need_verify=true）
│         │    ├─ VerifyEntryState       # 瞬态：enter 空，update 直转 Verifying
│         │    ├─ VerifyingState         # 等上位机 0x0D 加验数据
│         │    │    enter: arm_timer(kVerifyRequest) + emit NeedVerifyEvent(0xAB)
│         │    │    ├─ VerifyDataEvent(0x0D) ──▶ VerifySubmitting
│         │    │    ├─ VerifyErrorEvent(拒绝) ──▶ ResultObtained（exit=ret_code）
│         │    │    └─ StateTimeout ──▶ ResultObtained（VERIFY_TIMEOUT=129）
│         │    └─ VerifySubmittingState  # 加验提交
│         │         enter: request kRecRequest（复用识别 Action，路由 /verify-palm）+ arm_timer
│         │         react RecResponseEvent → kDecidePostRec:
│         │         ├─ V_Complete   ──▶ ResultObtained
│         │         └─ V_RetryVerify(100038 且 retry<3) ──▶ 回 Verifying（++verify_retry_count）
│         │         StateTimeout ──▶ ResultObtained
│         │
│         ├─ ResultObtainedState         # ★ 统一结果出口（瞬态，story 135810205）
│         │    update: 按 ctx.completion_source 分派 emit 0xA3：
│         │    ├─ kNormal       → OnPalmResultEvent
│         │    ├─ kScanFinished → OnScanResultEvent
│         │    ├─ kBindFinished → OnBindResultEvent
│         │    └─ 之后: need_host_ack=true ──▶ WaitingHostAck / false ──▶ Stopping
│         │
│         └─ WaitingHostAckState         # HOST_ACK 等待（story 135810205）
│              enter: arm_timer(kHostAckRequest, 20s) + loading 灯
│              ├─ HostAckResultEvent(0x14) ──▶ Stopping（exit_code 透传）
│              └─ StateTimeout ──▶ Stopping
│
├─ StoppingState                         # 收尾。enter: request_action(kRunOnStop)
│    │                                   # kNormal/kBind/kScan 路径另 emit OnSessionCompleteEvent
│    └─ StopOkEvent ──▶ Done             # 纯收尾态，结果灯 3s 窗口由 DeviceStateMachine 承载
│
└─ DoneState                             # 终态。一轮结束，Controller RunLoop 检测 Done 退出 RunOneRound
```

文件里的大段 ASCII 注释就是**完整状态转移图**：`Created→Starting→Detecting→PalmEntered→OptPassed` 主干、三条决策边（`V_Submit`→识别 / `V_EnterRegister`→注册 / `V_Complete`→出口）、加验子树流程、录掌等待的重试循环与 124 超时、`ResultObtained`→`WaitingHostAck`→`Stopping`→`Done` 的收尾链。

一句话总结：`palm_flow_fsm_def.h` 是状态机的**装配图纸**——声明状态层次树（`FSM` 别名）和状态的执行环境（Context + 闭包 API），转移逻辑图以注释形式画在这里，具体状态行为在 `palm_flow_states.cpp`，运行时由 `palm_flow_machine.cpp` 实例化。
