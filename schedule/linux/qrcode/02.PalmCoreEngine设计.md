`PalmCoreEngine` 是**厂商算法引擎的门面**（vendor 库，只有头文件 + so，源码不可见）——把摄像头采集、刷掌识别、扫码、灯光全部封进一个黑盒单例。项目里业务代码**从不直接调它**，统一经 `PalmCoreManager` 这层门面。快速搞懂它看四张表 + 一张图：

## 1. 它是什么

```cpp
class PalmCoreEngine {           // 单例（GetInstance），pimpl 隐藏实现
  void Init(auth, initializer, enable_local_feature_sync, sync_gap_second);
  void Release(user);
  ...
  struct Impl;                   // 全部实现藏在 Impl 里
};
```

- **单例 + pimpl**：业务侧只见接口，实现（算法 pipeline、摄像头）全在 so 里，排查问题时是黑盒
- **每个 API 都带 `user` 参数**：设计上支持多实例，项目里恒传同一个标识，可当不存在
- **依赖倒置是精髓**：`IPalmCoreInitializer` 由业务实现——引擎不管文件路径、语言、网络请求、数据上报，全部回调问业务（`PalmFuncInvokeParam` 特征拉取就是引擎发命令、业务做 HTTP）

## 2. API 五大能力组

| 能力组 | API | 关键点 |
|---|---|---|
| **生命周期** | `Init` / `Release` | 鉴权参数（pipeline/camera 双 license）；Release 后须重新 Init |
| **刷掌检测** | `StartPalmDetect(work_mode, session_id, enable_local_identify)` / `StopPalmDetect(full_stop)` | work_mode：kPay支付/kRegister注册/kIdentify核身；`full_stop=false` 热停止（再启快）、`true` 全释放（重启慢 1s） |
| **扫码** | `StartCodeScan(enable_bar_code)` / `StopCodeScan` / `IsCodeScanning` | 条形码默认关（仅自检开） |
| **端侧特征库** | `UpdateServiceConfig` / `NotifySyncRemoteFeature` / `GetLocalFeatureSyncInfo` | 支撑本地掌库比对（v2.1 端侧识别）；游标+增量同步 |
| **灯光/日志** | `SetLightState` / `FlushLog` | 6 种灯效：Idle 暗绿/Loading 转圈/Success 绿常亮/Warning 黄/Error 红/Detecting 呼吸 |

## 3. 三条回调通道（Listener）

| Listener | 回调 | 场景 |
|---|---|---|
| `IEngineStateListener` | `OnInitSuc` / `OnInitError` / **`OnFatalErr`** | 致命错误 → 触发上层自愈（摄像头/算法致命异常重启上报就是消费它） |
| `IPalmDetectListener` | `OnGetPalmStatus`（**每帧**） | UI 引导文案 + TTS（“请把手掌对准…”） |
| | `OnPalmOptLiveComplete` | **优选结果**：只含 `encrypt_data` 密文——云端识别路径，业务拿不到明文特征 |
| | `OnPalmLocalIdentifyComplete` | **本地识别结果**：code + hand_type——端侧识别路径 |
| `ICodeScanResultListener` | `OnCodeScanResult` | 扫码结果（`code_content` + `code_type_name`，就俩字段） |

## 4. 安全/加密边界

- 特征/图像**密文出引擎**：`PalmSvrEncryptConfig`（国密 SM2+SM4-GCM / 国际 RSA+AES-GCM）由业务经 Initializer 下发公钥，`PalmOptLiveResult` 里的数据业务侧不可解
- 明文特征只存在于引擎内部——业务层永远只碰“加密数据”或“本地比对结果”

## 5. 在项目中的位置（谁在用它）

```
业务层（FSM/Controller/各 Service）
        │ 只经这一层
        ▼
PalmCoreManager（门面：消费者位掩码、信号广播、线程投递）
        │ AddXxxListener / StartXxx
        ▼
PalmCoreEngine（vendor 黑盒：算法 pipeline + 摄像头 + 灯光）
```

`PalmCoreManager` 存在的理由：引擎的 Start/Stop 是**全局独占**的，而业务有多个角色（激活/License/刷掌会话/自检）都想用——门面用消费者位掩码做引用计数，并把自己注册成引擎 Listener，再把结果用信号（`CodeScanResultSig` 等）广播出去。

**一句话总结**：PalmCoreEngine = 刷掌 + 扫码 + 灯光的一体化算法黑盒；记住“Init 鉴权、Start/Stop 带热停语义、结果全走三个 Listener、密文出边界”这四点就够用了。
