# Facility · 01 总览与分层架构

> 系列第一篇。覆盖 facility 层定位、L0~L3 分层、23 个模块职责速查与架构设计原则。系列：02 启动与退出编排 / 03 线程模型与调度 / 04 时间体系 / 05 故障恢复与韧性。

## 一、定位

`src/facility/` 是 palm_app 的**基础设施层**：为 biz（业务编排）与 service（后台服务）提供线程、网络、存储、时间、密钥、设备控制等底座能力，**不含任何刷掌业务逻辑**。业务层 50+ 处消费它；它对业务层只有两个"反向注入点"（见第五节）。

## 二、分层架构

```text
┌─────────────────────────────────────────────────────────┐
│ L3 顶层编排                                              │
│   app(进程门面/PID锁/重启) ←→ bootstrap(两阶段启动编排)     │
│   platform_bridge(wepalm SDK 9 接口桥)                    │
├─────────────────────────────────────────────────────────┤
│ L2 编排/聚合                                              │
│   scheduler(1s基频调度)  recover(故障恢复汇聚)             │
│   device_state(设备仲裁状态机)  app_state(会话观察者)       │
│   palm_core(算法SDK适配)  link(P2P厂测通道)                │
├─────────────────────────────────────────────────────────┤
│ L1 单一依赖基础件                                         │
│   network(→keystore)  ntp  time  system  device(→system) │
│   device_action(→system)  tts(→network)                  │
├─────────────────────────────────────────────────────────┤
│ L0 纯基础件（零内部依赖）                                  │
│   thread  config(MMKV)  cache(MMKV)  log  keystore       │
│   utils  crash  hook                                     │
└─────────────────────────────────────────────────────────┘
```

## 四、设计原则

1. **依赖单向向下、基本无环**：`keystore → network → palm_core → device_state → recover → system/device_action`；bootstrap 在最顶层聚合一切；
2. **facility 不依赖 biz，例外靠注入**：device_action 的上位机通知（`SetNotifySender`，device_action.h:33）由 biz 注入回调，避免编译期反向依赖——本层最重要的架构约束；
3. **持久化统一 MMKV**：Config（KV）与 FileCaches（文件）同源，断电安全，退出 Flush；
4. **线程与调度统一走 thread + scheduler**（03 篇）；时间判定统一走 time + ntp（04 篇）。

## 五、三个命名/认知陷阱

1. **BootTask 静态注册机制已废弃**：`BOOT_TASK_DECL` 宏与 `task_graph.cpp` 依赖声明还在，但 `SetTaskDeps` 是空实现（bootstrapper.cpp:141-142），实际顺序硬编码在 Run 里——不要按"任务图调度"理解启动；
2. **facility/link ≠ PosLink**：link/ 是产线厂测 P2P 通道（与 pos_link 串口互斥）；PosLink 串口实现在 `src/biz/pos/`（pos_transferer.h:14-18）；
3. **palm_core 是适配层不是 SDK**：facility 与 biz 的 `PalmCoreManager` 是同一个类（实现在 facility/palm_core/），biz 只是订阅者。
