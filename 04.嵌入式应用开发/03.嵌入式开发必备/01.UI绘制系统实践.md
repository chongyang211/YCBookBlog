## 1.UI系统架构

### 1.1 系统层级设计

```
┌─────────────────────────────────────────┐
│              Application                │  ← 应用程序入口
├─────────────────────────────────────────┤
│           DisplayService                │  ← 显示服务层
├─────────────────────────────────────────┤
│               UI Layer                  │  ← UI抽象层
├─────────────────────────────────────────┤
│            ActivationUI                 │  ← 业务UI层
├─────────────────────────────────────────┤
│               LVGL                      │  ← 图形库层
├─────────────────────────────────────────┤
│            Linux FrameBuffer            │  ← 硬件抽象层
└─────────────────────────────────────────┘
```

### 1.2 核心组件

- **DisplayService**: 显示服务，负责LVGL初始化和屏幕管理
- **UI**: UI工具类，提供字体、图片、资源管理等功能
- **ActivationUI**: 激活流程专用UI管理器
- **Thread System**: 多线程系统，确保UI线程安全

## 2.UI启动和退出

### 2.1 UI启动流程

```cpp
// main.cpp -> Application::Run()
int Application::Run(int argc, char *argv[]) {
    // 在主线程中启动UI系统
    Threads::Instance()->RunMainThread([]() {
        // 1. 初始化显示服务
        DisplayService::Instance()->Init();
        // 2. 初始化激活UI
        ActivationUi::Instance()->Init();
        ActivationUi::Instance()->Show();
    });
}
```

### 2.2 DisplayService初始化

```cpp
int DisplayService::Init() {
    // 1. 读取屏幕分辨率信息
    InitDisplayInfo(&screen_width_, &screen_height_);
    // 2. 初始化LVGL HAL层
    InitHal();
    // 3. 初始化LVGL屏幕
    InitLvScr();
    // 4. 启动UI循环
    Start();
    initialized_ = true;
    return 0;
}
```

### 2.3 UI退出流程

```cpp
DisplayService::~DisplayService() {
    Stop();  // 停止UI循环
}

void DisplayService::Stop() {
    if (refresh_timer_) {
        refresh_timer_->cancel();  // 取消刷新定时器
    }
}
```

## 3.UI绘制原理

### 3.1 LVGL绘制架构

系统使用LVGL (Light and Versatile Graphics Library) 作为图形引擎：

```cpp
void DisplayService::InitHal() {
    // 1. 初始化LVGL核心
    lv_init();
    lv_extra_init();
    
    // 2. 初始化Linux FrameBuffer驱动
    fbdev_init();
    
    // 3. 创建双缓冲区
    auto buf_px_cnt = screen_width_ * screen_height_;
    disp_buf_ = std::make_unique<lv_color_t[]>(buf_px_cnt);
    disp_buf2_ = std::make_unique<lv_color_t[]>(buf_px_cnt);
    
    // 4. 初始化显示驱动
    lv_disp_draw_buf_init(&draw_buf_, disp_buf_.get(), disp_buf2_.get(), buf_px_cnt);
    lv_disp_drv_init(&disp_drv_);
    disp_drv_.draw_buf = &draw_buf_;
    disp_drv_.flush_cb = fbdev_flush;  // 刷新回调
    disp_drv_.hor_res = screen_width_;
    disp_drv_.ver_res = screen_height_;
    disp_drv_.rotated = LV_DISP_ROT_270;  // 屏幕旋转270度
    lv_disp_drv_register(&disp_drv_);
}
```

### 3.2 UI刷新循环

```cpp
void DisplayService::Tick() {
    // 1. 处理LVGL定时器和绘制任务
    auto interval_ms = lv_timer_handler();
    
    // 2. 设置下次刷新时间（5ms间隔）
    refresh_timer_->expires_after(std::chrono::milliseconds(5));
    
    // 3. 异步等待下次刷新
    refresh_timer_->async_wait([this](const auto &ec) {
        if (!ec) Tick();  // 递归调用，形成刷新循环
    });
}
```

## 4.系统层级设计

### 4.1 线程架构

```cpp
enum GlobalThreadType {
    kMainThread = 0,      // 主线程 = UI线程
    kUiThread = kMainThread,
    kHeartBeatThread,     // 心跳线程
    kIotThread,          // IoT操作线程
    kActivationThread,   // 激活状态机专用线程
};
```

**线程职责分工**:
- **MainThread/UIThread**: 所有UI操作必须在此线程执行
- **ActivationThread**: 激活状态机逻辑处理
- **IotThread**: 网络请求、音频播放等IO操作
- **HeartBeatThread**: 周期性任务和上报

### 4.2 线程安全机制

```cpp
void ActivationUi::UpdateState(ActivationState state, const std::string& message, int server_code) {
    // 确保UI更新在主线程中执行

    Threads::MainThread()->Post([this, state, msg_copy, server_code]() {
        // 在主线程中安全更新UI
        UpdateUIForState(state, msg_copy, server_code);
    });
}
```

class Application {

## 7. 激活UI状态机

### 7.1 状态定义

```cpp
enum class ActivationState {
    kWaitingForScan,                    // 等待扫码激活
    kStartingUp,                        // 启动中（检查状态）
    kActivating,                        // 激活中
    kActivated,                         // 完成激活
    kNetworkError,                      // 联网失败
    kActivationFailedRetryable,         // 激活失败（可重试）
    kActivationFailedNonRetryable       // 激活失败（不可重试）
};
```

### 7.2 状态转换流程

```
[启动] → kStartingUp → [检查激活状态]
                    ↓
                [未激活] → kWaitingForScan → [扫码成功] → kActivating → [激活成功] → kActivated
                    ↓                           ↓              ↓
                [网络错误] → kNetworkError      [激活失败]      [激活失败]
                    ↓                           ↓              ↓
                [可重试] ← kActivationFailedRetryable    kActivationFailedNonRetryable
```

## 8. 音频系统集成

### 8.1 音频播放接口

```cpp
void ActivationController::PlayTTSAudio(const std::string& audio_name) {
    // 检查设备音频能力
    if (!Device::HasCapacity(Device::Capacity::kAudio)) {
        LOG_W("Device does not support audio playback");
        return;
    }
    
    // 构建音频文件路径
    std::string audio_path = Application::GetAppResPath("audio/" + audio_name);
    
    // 在IoT线程中播放音频，避免阻塞UI
    Threads::IotThread()->Post([audio_path]() {
        PalmInterface::Instance()->Play(audio_path, [audio_path](error_code ec, int32_t result) {
            if (ec) {
                LOG_E("Failed to play TTS audio {}: {}", audio_path, ec.message());
            } else {
                LOG_I("TTS audio {} played successfully, result: {}", audio_path, result);
            }
        });
    });
}
```

## 10. 调试和故障排除

### 10.1 日志系统

```cpp
// 日志级别
LOG_I("Info message: {}", value);      // 信息
LOG_W("Warning message: {}", value);   // 警告

```

### 10.2 常见问题

#### 10.2.1 UI不更新
- **原因**: UI操作不在主线程
- **解决**: 使用`Threads::MainThread()->Post()`

#### 10.2.2 图片不显示
- **原因**: 路径错误或文件不存在
- **解决**: 检查`LvRes()`路径转换和文件存在性

#### 10.2.3 字体显示异常
- **原因**: 字体文件缺失或权重不支持
- **解决**: 确认字体文件存在，使用支持的权重值

#### 10.2.4 内存泄漏
- **原因**: LVGL对象未正确释放
- **解决**: 使用`lv_obj_del()`释放对象，实现RAII模式
