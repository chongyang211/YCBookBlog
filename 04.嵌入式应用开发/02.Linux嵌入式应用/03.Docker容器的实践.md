## 03.检查Docker服务状态

`systemctl` 是管理 systemd 服务的工具，Docker 通常作为一个 systemd 服务运行。

```bash
docker --version
sudo systemctl status docker
```

**输出示例：**
- **Docker 已启动**：
  ```
  ● docker.service - Docker Application Container Engine
     Loaded: loaded (/lib/systemd/system/docker.service; enabled; vendor preset: enabled)
     Active: active (running) since ...
  ```
- **Docker 未启动**：
  ```
  ● docker.service - Docker Application Container Engine
     Loaded: loaded (/lib/systemd/system/docker.service; enabled; vendor preset: enabled)
     Active: inactive (dead)
  ```

## 04.启动Docker服务

如果 Docker 未启动，可以使用以下命令启动：

```bash
sudo systemctl start docker
```

**设置 Docker 开机自启**
```bash
sudo systemctl enable docker
```

## 05.检查Docker是否运行

直接运行 `docker` 命令，如果 Docker 已启动，会显示 Docker 的帮助信息；如果未启动，会提示错误。

```bash
docker info
```

**Docker 已启动**：

```shell
CHONGYYANG-MB1:~ yangchong$ docker info
Client: Docker Engine - Community
 Version:    28.1.1
 Context:    colima
 Debug Mode: false

Server:
 Containers: 0
  Running: 0
  Paused: 0
  Stopped: 0
 Images: 2
 Server Version: 27.4.0
```

**Docker 未启动**：

```shell
Cannot connect to the Docker daemon at unix:///var/run/docker.sock. Is the docker daemon running?
```

## 06.检查Docker进程

通过 `ps` 命令查看 Docker 进程是否在运行。

**查看 Docker 进程**

```bash
ps aux | grep docker
```

**Docker 已启动**：

```shell
root      12345  0.0  0.1 123456 7890 ?        Ssl  10:00   0:00 /usr/bin/dockerd -H fd:// --containerd=/run/containerd/containerd.sock
```

**Docker 未启动**：没有与 Docker 相关的进程。

## 07.检查Docker套接字

Docker 通过 Unix 套接字（`/var/run/docker.sock`）与客户端通信。检查该文件是否存在。

**检查套接字文件**

```bash
ls -l /var/run/docker.sock
```

- **Docker 已启动**：
  ```
  srw-rw---- 1 root docker 0 Jan  1 10:00 /var/run/docker.sock
  ```
- **Docker 未启动**：
  ```
  ls: cannot access '/var/run/docker.sock': No such file or directory
  ```

## 08.检查Docker日志

如果 Docker 未启动，可以查看日志以排查问题。

**查看 Docker 日志**

```bash
sudo journalctl -u docker.service
```


从错误信息来看，您在尝试从 `csighub.tencentyun.com` 拉取 Docker 镜像时遇到了认证问题，具体原因是未提供有效的用户名和密码。以下是解决该问题的步骤：

---

### **1. 确认镜像仓库的访问权限**
`csighub.tencentyun.com` 是一个私有 Docker 镜像仓库，需要登录才能访问。请确保：
- 您有该仓库的访问权限。
- 您拥有正确的用户名和密码。

---
ssh-keygen -t ed25519 -C "chongyyang@tencent.com"
### **2. 登录 Docker 镜像仓库**
使用 `docker login` 命令登录到 `csighub.tencentyun.com`：

```bash
docker login csighub.tencentyun.com
```

系统会提示您输入用户名和密码。输入正确的凭据后，登录成功。

---

### **3. 检查登录状态**
登录成功后，运行以下命令检查是否已正确登录：

```bash
cat ~/.docker/config.json
```

确保文件中包含 `csighub.tencentyun.com` 的认证信息。

---

### **4. 重新拉取镜像**
登录成功后，重新尝试拉取镜像：

```bash
docker pull csighub.tencentyun.com/aikit/rv1109-m3:v1.0.1
```

---

### **5. 使用 Token 认证（如果需要）**
如果用户名和密码无法登录，可能需要使用 Token 认证。请联系镜像仓库的管理员获取 Token，然后使用以下命令登录：

```bash
echo <YOUR_TOKEN> | docker login csighub.tencentyun.com -u <USERNAME> --password-stdin
```

将 `<YOUR_TOKEN>` 替换为您的 Token，`<USERNAME>` 替换为您的用户名。

---

### **6. 检查网络连接**
如果仍然无法拉取镜像，请检查您的网络连接，确保可以访问 `csighub.tencentyun.com`：

```bash
ping csighub.tencentyun.com
```

如果无法访问，可能是网络问题或防火墙限制。

---

### **7. 使用代理（如果需要）**
如果您的网络需要代理，可以配置 Docker 使用代理：

1. 编辑或创建 Docker 配置文件 `~/.docker/config.json`，添加以下内容：
   ```json
   {
     "proxies": {
       "default": {
         "httpProxy": "http://<PROXY_HOST>:<PROXY_PORT>",
         "httpsProxy": "http://<PROXY_HOST>:<PROXY_PORT>",
         "noProxy": "localhost,127.0.0.1"
       }
     }
   }
   ```
   将 `<PROXY_HOST>` 和 `<PROXY_PORT>` 替换为您的代理地址和端口。

2. 重启 Docker 服务：
   ```bash
   sudo systemctl restart docker
   ```

---

### **8. 联系镜像仓库管理员**
如果以上方法均无效，请联系 `csighub.tencentyun.com` 的管理员，确认：
- 您的账户是否有权限访问该镜像。
- 镜像是否存在或可用。
