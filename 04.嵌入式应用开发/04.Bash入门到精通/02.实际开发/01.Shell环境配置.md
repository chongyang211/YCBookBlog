## 01.查看使用的Shell

在 macOS 上，了解当前使用的 Shell 是 Zsh 还是 Bash 非常简单。

### 1.1 echo $SHELL

**方法 1：使用 `echo $SHELL` 命令**
1. 打开终端。
2. 运行以下命令：

```bash
CHONGYYANG-MB1:~ yangchong$ echo $SHELL
/bin/bash
```

- 如果输出是 `/bin/zsh`，说明当前使用的是 Zsh。
- 如果输出是 `/bin/bash`，说明当前使用的是 Bash。

### 1.2 使用`ps`命令

**方法 2：使用 `ps` 命令**

1. 打开终端。
2. 运行以下命令：

```bash
CHONGYYANG-MB1:~ yangchong$ ps -p $$
PID TTY           TIME CMD
42597 ttys001    0:00.01 -bash
```

- 在输出中查找 `COMMAND` 列，如果显示 `zsh`，说明当前使用的是 Zsh；如果显示 `bash`，说明当前使用的是 Bash。

### 1.3 查看默认Shell

**方法 3：查看默认Shell**
1. 打开终端。
2. 运行以下命令：
   ```bash
   echo $0
   ```
    - 如果输出是 `-zsh`，说明当前使用的是 Zsh。
    - 如果输出是 `-bash`，说明当前使用的是 Bash。


### 1.4 切换Shell
如果你想切换默认 Shell，可以使用以下命令。

**切换到 Zsh**
```bash
chsh -s /bin/zsh
```

**切换到 Bash**

```bash
chsh -s /bin/bash
```

切换后，需要重新启动终端或重新登录以生效。



### 1.5 Zsh和Bash区别

Zsh 和 Bash 都是 Unix/Linux 系统中常用的 Shell，但它们有一些显著的区别：

| 特性                | Zsh                                      | Bash                                      |
|---------------------|------------------------------------------|------------------------------------------|
| **默认 Shell**      | macOS Catalina（10.15）及更高版本默认 Shell。 | macOS Catalina 之前版本的默认 Shell。     |
| **兼容性**          | 兼容 Bash，但有一些语法和行为差异。       | 广泛兼容，是大多数脚本的标准 Shell。      |
| **功能**            | 提供更强大的自动补全、主题和插件支持。     | 功能相对简单，但足够满足大多数需求。      |
| **配置文件**        | `~/.zshrc`                               | `~/.bashrc` 或 `~/.bash_profile`          |
| **插件和主题**      | 支持丰富的插件和主题（如 Oh My Zsh）。     | 插件和主题支持较少。                      |
| **性能**            | 启动速度较慢，但功能更强大。               | 启动速度较快，适合轻量级使用。            |
| **社区支持**        | 社区活跃，插件和主题资源丰富。             | 社区支持广泛，但插件和主题较少。          |

**如何选择 Zsh 或 Bash**

- **选择 Zsh**：
    - 如果你喜欢强大的自动补全、主题和插件功能。
    - 如果你使用 macOS Catalina 或更高版本，Zsh 是默认 Shell。
    - 如果你需要更现代化的 Shell 体验。

- **选择 Bash**：
    - 如果你需要兼容性更好的 Shell，尤其是运行脚本时。
    - 如果你更喜欢轻量级和快速的 Shell。
    - 如果你习惯了 Bash 的语法和行为。



## 02.Shell环境变量

在 Bash 中，环境配置通常通过环境变量和配置文件来管理。


### 2.1 查当前环境变量

#### **方法 1：使用 `printenv` 命令**
`printenv` 命令可以列出所有环境变量及其值。
```bash
printenv
```

#### **方法 2：使用 `env` 命令**
`env` 命令也可以列出所有环境变量。
```bash
env
```

#### **方法 3：查看特定环境变量**
使用 `echo` 命令查看特定环境变量的值。例如：
```bash
echo $PATH
echo $HOME
echo $USER
```

### 2.2 查Bash配置文件

Bash 的环境配置通常通过以下配置文件加载：

| 配置文件                | 说明                                      |
|-------------------------|-----------------------------------------|
| `~/.bash_profile`       | 用户登录时加载，适用于登录 Shell。        |
| `~/.bashrc`             | 每次打开新的终端时加载，适用于非登录 Shell。 |
| `~/.bash_logout`        | 用户注销时加载。                         |
| `/etc/profile`          | 系统级别的配置文件，适用于所有用户。      |
| `/etc/bashrc`           | 系统级别的 Bash 配置文件，适用于所有用户。 |

#### **查看配置文件内容**
使用 `cat` 或 `less` 命令查看配置文件内容。例如：
```bash
cat ~/.bash_profile
cat ~/.bashrc
```

### 2.3 查当前Shell配置

#### **方法 1：使用 `set` 命令**
`set` 命令可以显示当前 Shell 的所有变量和函数。
```bash
set
```

#### **方法 2：使用 `declare` 命令**
`declare` 命令可以显示当前 Shell 的所有变量。
```bash
declare
```

### 2.4 查看Bash版本
了解当前 Bash 版本有助于判断支持的功能。
```bash
bash --version
```

**查看 Bash 的启动文件加载顺序**

Bash 在启动时会按照特定顺序加载配置文件。以下是典型的加载顺序：
1. `/etc/profile`（系统级别）
2. `~/.bash_profile` 或 `~/.bash_login` 或 `~/.profile`（用户级别）
3. `~/.bashrc`（用户级别，非登录 Shell）

---

### 2.5 是否为登录Shell

#### **方法 1：使用 `shopt` 命令**
```bash
shopt login_shell
```
- 如果输出为 `on`，表示当前是登录 Shell。
- 如果输出为 `off`，表示当前是非登录 Shell。

#### **方法 2：查看 `$0` 变量**
```bash
echo $0
```
- 如果输出为 `-bash`，表示当前是登录 Shell。
- 如果输出为 `bash`，表示当前是非登录 Shell。


### 2.6 Shell环境总结

| 操作                                | 说明                                      |
|-------------------------------------|-----------------------------------------|
| 查看所有环境变量                    | 使用 `printenv` 或 `env`。               |
| 查看特定环境变量                    | 使用 `echo $变量名`。                    |
| 查看 Bash 配置文件                  | 使用 `cat ~/.bash_profile` 或 `cat ~/.bashrc`。 |
| 查看当前 Shell 的变量和函数          | 使用 `set` 或 `declare`。                |
| 查看 Bash 版本                      | 使用 `bash --version`。                  |
| 检查当前 Shell 是否为登录 Shell      | 使用 `shopt login_shell` 或 `echo $0`。  |

通过以上方法，你可以全面了解 Bash 的环境配置。如果需要修改配置，可以编辑相应的配置文件（如 `~/.bashrc` 或 `~/.bash_profile`），然后运行 `source` 命令使更改生效：
```bash
source ~/.bashrc
```


                        在 Bash 中，环境变量用于存储系统或用户级别的配置信息，影响 Shell 的行为和程序的运行。以下是关于 Bash 环境变量配置的详细说明：

---

### **1. 环境变量的基本操作**
#### **查看环境变量**
- 查看所有环境变量：
  ```bash
  printenv
  ```
  或
  ```bash
  env
  ```
- 查看特定环境变量：
  ```bash
  echo $变量名
  ```
  例如：
  ```bash
  echo $PATH
  ```

#### **设置环境变量**
- 临时设置环境变量（仅在当前 Shell 会话中有效）：
  ```bash
  export 变量名=值
  ```
  例如：
  ```bash
  export MY_VAR="Hello, World!"
  ```

- 永久设置环境变量（需要写入配置文件）：
  编辑 Bash 配置文件（如 `~/.bashrc` 或 `~/.bash_profile`），添加以下内容：
  ```bash
  export 变量名=值
  ```
  例如：
  ```bash
  export PATH=$PATH:/usr/local/bin
  ```
  保存文件后，运行以下命令使更改生效：
  ```bash
  source ~/.bashrc
  ```

#### **删除环境变量**
- 删除环境变量：
  ```bash
  unset 变量名
  ```
  例如：
  ```bash
  unset MY_VAR
  ```

---

### **2. 常见的环境变量**
| 变量名         | 说明                                      |
|----------------|-----------------------------------------|
| `PATH`         | 可执行文件的搜索路径。                   |
| `HOME`         | 当前用户的主目录路径。                   |
| `USER`         | 当前用户名。                             |
| `SHELL`        | 当前 Shell 的路径。                      |
| `PWD`          | 当前工作目录的路径。                     |
| `LANG`         | 系统的语言和区域设置。                   |
| `PS1`          | 命令行提示符的格式。                     |
| `EDITOR`       | 默认的文本编辑器。                       |
| `TERM`         | 终端类型。                               |

---

### **3. 配置环境变量的文件**
Bash 的环境变量可以通过以下配置文件设置：

| 配置文件                | 说明                                      |
|-------------------------|-----------------------------------------|
| `~/.bash_profile`       | 用户登录时加载，适用于登录 Shell。        |
| `~/.bashrc`             | 每次打开新的终端时加载，适用于非登录 Shell。 |
| `~/.bash_logout`        | 用户注销时加载。                         |
| `/etc/profile`          | 系统级别的配置文件，适用于所有用户。      |
| `/etc/bashrc`           | 系统级别的 Bash 配置文件，适用于所有用户。 |

#### **配置文件的加载顺序**
1. `/etc/profile`（系统级别）
2. `~/.bash_profile` 或 `~/.bash_login` 或 `~/.profile`（用户级别）
3. `~/.bashrc`（用户级别，非登录 Shell）

---

### **4. 示例：配置 `PATH` 环境变量**
#### **临时添加路径到 `PATH`**
```bash
export PATH=$PATH:/usr/local/bin
```

#### **永久添加路径到 `PATH`**
1. 打开 `~/.bashrc` 文件：
   ```bash
   nano ~/.bashrc
   ```
2. 添加以下内容：
   ```bash
   export PATH=$PATH:/usr/local/bin
   ```
3. 保存文件并运行以下命令使更改生效：
   ```bash
   source ~/.bashrc
   ```

---

### **5. 示例：自定义环境变量**
#### **设置自定义变量**
1. 打开 `~/.bashrc` 文件：
   ```bash
   nano ~/.bashrc
   ```
2. 添加以下内容：
   ```bash
   export MY_VAR="Hello, World!"
   ```
3. 保存文件并运行以下命令使更改生效：
   ```bash
   source ~/.bashrc
   ```

#### **使用自定义变量**
```bash
echo $MY_VAR
```

---

### **6. 总结**
| 操作                                | 说明                                      |
|-------------------------------------|-----------------------------------------|
| 查看环境变量                        | 使用 `printenv` 或 `echo $变量名`。      |
| 设置临时环境变量                    | 使用 `export 变量名=值`。                |
| 设置永久环境变量                    | 编辑 `~/.bashrc` 或 `~/.bash_profile`。  |
| 删除环境变量                        | 使用 `unset 变量名`。                    |
| 常见环境变量                        | `PATH`, `HOME`, `USER`, `SHELL` 等。     |
| 配置文件                            | `~/.bashrc`, `~/.bash_profile` 等。      |

通过以上方法，你可以灵活配置和管理 Bash 的环境变量，满足不同的开发和使用需求。
