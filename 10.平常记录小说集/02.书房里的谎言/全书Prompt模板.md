## §0 极简触发协议（先看这里）

### §0.1 一次性初始化（每个新对话只做一次）

每打开一个新对话窗口，先把以下五份文件作为附件一次性发给 AI（**顺序固定**）：

```
1. 全书方案的设计.md
2. 全书框架和分卷.md
3. 全书Prompt模板.md  ← 本文件
4. 一致性档案.md
5. 参考作品的拆解.md
```

随后输入这一句固定开场白：

```
这是《书房里的谎言》的全书宪法+模板+100 章数据卡+原型拆解。请整体读入并记住。
之后我用 §0.2 的命令调用，你按命令直接出稿，不要让我再粘贴任何内容。
读完回复"已就位"。
```

AI 回复"已就位"后，进入 §0.2 命令模式。

### §0.2 七条万能命令（日常只输这七种）

| 命令 | 含义 | AI 应该做什么 |
|---|---|---|
| `写 N` | 写第 N 章 | 自动从 §C 取数据卡 + §G 取本章应用符号 + §A 宪法约束，按 §B 规约出稿 ≈4500 字（4000-5000）|
| `沉淀 N` | 第 N 章写完后让 AI 输出"档案行" | 按 §F.1 单行模板输出 6 字段，作者复制粘贴到《一致性档案.md》|
| `自检 N` | 第 N 章写完后强制走自检 | 按 §B.8 自检表逐项打勾，**有 ❌ 立刻原地重写整章**|
| `修复 N : 问题` | 已写章节的局部修复 | 按 §B.9 即时修复指令表精准修订，不重写整章 |
| `卷N 体检` | 一卷写完后做卷级体检 | 按 §F.5 卷级体检清单，覆盖伏笔/钩子/符号/反转节点四项 |
| `下一章预读` | 写完 N 章后预看 N+1 章 | AI 只输出 N+1 章的钩子接口与三视角分配建议（不出稿）|
| `合写 N+M` | 仅限相邻两章且必须为 T0/T1 同章型 | AI 先确认两章 §D 钩子可连写，再合并出稿 ≤9500 字 |

### §0.3 命令执行规约（AI 必须遵守）

写章节（`写 N`）时的内部步骤：

1. **读取章型**：先从 §C.X 数据卡顶部读取 `章型: T?`（T0-T5 六种），按对应骨架生效
2. **读取统一符号**：从 §G 看 N 是否在某符号"必须出现章号"列表内
3. **读取主导意象**：从 §C.X 数据卡读取本章主导意象
4. **读取三视角分配**：从 §C.X 数据卡读取本章"明/暗/外"三视角配比
5. **读取人物状态**：从《一致性档案.md》最近 3 行+本章应当出现人物的 §H 档案
6. **填写字数预算表**：按 §B.7 预先列出每段字数预算，再开写
7. **执行**：按 §B.5 章型骨架 + §B.7 输出格式出稿
8. **不在命令中的事一律不做**：不主动写下一章、不展开方案外人物、不擅自调整反转节点

如果 AI 发现 `写 N` 命令对应章节的数据卡缺失，必须**先报"§C.N 数据卡未填，请补充以下 8 字段"**，再停手，不允许凭空创作。

如果 AI 发现章节统一符号、主导意象、三视角分配等关键字段冲突或缺失，必须**先按 §B.9 报修复方案**，再让作者裁决，不允许擅自补全。

如果 AI 发现书名出现"《顶流的访客》"或女主播叫"苏梅"，**立即停笔**，按 §I.1 报命名漂移，要求作者确认后才能继续。

### §0.4 日常工作流（一章 = 4 行字）

```
写 N            ← 等待 AI 出稿 ≈4500 字
自检 N          ← 强制走自检表，确保任意 ❌ 立即修复
沉淀 N          ← 复制粘贴到《一致性档案.md》第 N 章位置
下一章预读      ← AI 给出 N+1 章接口建议，便于明天接着写
```

2. **不准提前揭穿身份诡计**——李梅"林飞母亲"的真实身份**严禁在第 83 章前以任何形式（视角切换、回忆、内心独白、外人对话、监控特写）暴露给读者**。读者只能从沈驰的视角看到"顶级律师童瑾"。**唯一例外**：第 6/13/66/68 章可写林建军视角的监听场景，但此时林建军视角必须严格回避对"妻子身份"的指认，仅以"我妻子""她"指代。
3. **不准让沈驰变成脸谱化反派**——必须保留**资本野心+人设维护+偶尔的人性闪回**三层。第 28-30 章他对林飞"威逼利诱"必须有"先安抚后翻脸"的明面节奏；第 47 章栽赃过程必须有"我也是不得已"的内心自欺。
4. **不准让李梅变成全知全能的复仇女神**——必须保留**3 个月维权挫败的精神重创+情绪失控边缘+对法律自身的怀疑**三层。第 17 章"林飞"二字出口时**必须有指尖颤抖**；第 75 章怒吼**必须有真情绪伪装**的双层结构。
5. **不准用"巧合"或"金手指"推进情节**——所有线索（沉尸地点、苏晚忏悔信、林飞 U 盘、林建军监听）必须在前文有具体的伏笔。每次"突破"必须由**人物动机+技术能力+现实条件**三者支撑，缺一不可。
6. **不准与已写章节矛盾**（伤疤数量、人物记忆、时间线、合同金额、违约金数额、地点名称、手机型号、电子脚镣型号、录音笔型号）。出现矛盾立即按 §I.2 启动修复。
7. **不准字数超出每章 4000-5000 区间**（全书 100 章 ≈40 万中文字符）。**T5 留白冷章**例外允许 3500-4500 字；**合写章**例外允许 8000-9500 字。

### §A.8 反转伏笔三层闭环（每章须做）

每章必须做到**前伏笔回响 1 处 + 当章新伏笔铺设 1 处 + 当章谎言漏洞自暴 1 处**——三件齐备才允许沉淀。具体规约见 §B.6.5。

### §A.9 三视角铁律（贯穿全书）

本书采用三视角并置叙事，每章必须明确视角分配：

- **明视角（沈驰视角 / 书房内）**：他相信童瑾是真律师，他相信自己在编谎，他不知道对面坐的是受害者母亲——读者透过他的眼睛看到"假律师正在帮真凶脱罪"的滑稽与残忍。
- **暗视角（李梅内心 / 书房内）**：她每一句话都是审讯，每一个微表情都是表演，她真实情绪被压在西装与人皮面具之下——读者透过偶尔泄露的"指尖颤抖""桌下攥拳"看到真正的悲恸。**严禁直白写"林飞母亲""我儿子"等暴露身份字眼**，只能用"那孩子""二十二岁的孩子""那个名字"等回避表达。
- **外视角（林建军 / 对岸江景酒店）**：他举着望远镜看妻子，他听耳机里的对话，他攥拳到指甲入肉——他是读者通往真相的"前置情绪通道"，但他视角中**必须严格回避对"妻子身份是谁的母亲"的指认**，仅以"她""老李"指代，让真相留到第 83 章再揭晓。

每章三视角配比建议见 §B.6.6。

## §B 写作规约（每章必读 · 机械执行）

## §B.1 风格基准（必须模仿这种语感）

> 风格基准段（必须能写出这种"高密度对话+心理双面+物证细节"的语感才算合格）：

```
童瑾把皮包搁在膝头，抬手看了一眼手表。指针走到三点四十七分。她说，秘密证人不会等你，沈总，控方那边比你想的快。

沈驰笑了一下。他笑的时候眼角没有动，只有嘴角抬了一寸，像在权衡这一寸抬多少才不显得心虚。他说，童律师，您放心，我能跟你说的，全是真的。

她没接他的话。她的手指搁在皮包扣上，那个金属扣是冷的，比她的指尖凉两度。她在心里数到第七秒，才开口：那林飞的事，你打算什么时候说？

他眼里有那么一瞬的空白。一瞬而已，像断电之后室内灯还有余光。他端起茶杯，茶水进喉的动作慢了半拍。这半拍，被她看进去了，记在了胸口的位置——那里贴着一张照片，二寸的，2023 年那个孩子的毕业照。

窗外对岸的酒店里，林建军把耳机往耳朵里按了按。他听见杯沿与瓷碟相碰的脆响，听见妻子那句"林飞"出口前停顿的半秒。他攥着望远镜的手指甲已经掐进掌心，渗出血丝来。他没有出声。他知道她需要这半秒，让那两个字从喉咙里出来，又把那两个字从眼睛里收回去。
```

**这一段做对了什么**（每点都是 §B.6 七律的具体落地）：

- 高密度对话：3 句对白 + 1 句动作 + 1 句心理 + 1 句外视角，**比例≈3:2:2:1**
- 物证细节：手表、皮包扣、茶杯、耳机、望远镜、照片——**6 件具体物**
- 双面性：沈驰"笑"和"眼角不动"的双层动作；李梅"看表"与"心数到 7"的双层时间感
- 三视角并置：明（沈驰对话）+暗（李梅指尖与心数）+外（林建军耳机与攥拳）
- 留白：林飞母亲的身份**绝口不提**，只用"那个孩子""二寸毕业照"暗示，**让读者去拼**

## §B.2 五条硬性禁令（违反一条即重写）

1. ❌ 不准用"激烈交锋""险象环生""刀光剑影""智斗升级"等武侠/爽文式抽象修辞——本书是**心理审讯**不是"打斗"。
2. ❌ 不准把心理活动直接外化为长段独白——心理必须**通过物证、动作、停顿、温度感、节奏感**间接表达，每段独白不超过 3 句。
3. ❌ 不准在沈驰视角章节里使用全知叙述——他不知道童瑾是李梅，他不知道对岸有人监听，**他视角内必须保留这两条核心盲区**。
4. ❌ 不准让对白"开车上路"——每段对话**必须有压力源**（时间倒计时、秘密证人威胁、辩护逻辑漏洞、心理博弈节点之一）。无压力的闲谈一段都不行。
5. ❌ 不准凭"警觉的本能""敏锐的直觉""资深律师的经验"等抽象描述代替具体动作——必须给出**具体的微表情/具体的物证/具体的时间锚**。

## §B.3 段落颗粒度（机械执行 · 字数优先 · 长段适度）

- **每段字数**：90-160 字为主（中位 120），允许 20% 段落 ≤80 字（用于反转节奏点、停顿、视角切换）
- **每章总段数**：30-45 段（中位 38），不超过 50 段
- **段间留白**：每 5-7 段强制 1 段 ≤60 字短段，作为"呼吸点"
- **字数总区间**：4000-5000 字（T5 留白冷章 3500-4500 字，合写章 8000-9500 字）

> **数学校核**：38 段 × 120 字中位 = 4560 字，正中区间。AI 写之前必须按 §B.7 输出格式预先填字数预算表。

## §B.4 句长比例（机械执行 · 长句为主）

- **长句**（≥25 字）：占 35-45%，承载推理、心理、复合动作
- **中句**（12-24 字）：占 40-50%，承载对白、物证陈述、动作衔接
- **短句**（≤11 字）：占 15-20%，承载反转节奏、单字暴击、视角切换

短句不能扎堆——连续 3 个短句即触发 §B.9 修复指令的"短句堆积警告"。

## §B.6 写作风格七律 + 三层细节

### §B.6.1 七律（每章必须七律齐备）

1. **物证优先**：每段心理活动必须挂在一个具体物证上——手表、烟灰缸、玻璃杯、电子脚镣、人皮面具、录音笔、监听耳机、毕业照、安眠药瓶、合同复印件、法袍、墓碑——见物即心。
2. **微表情精确**：每个反派的微表情必须精确——"嘴角抬一寸""眼角不动""喉结上下一次""鼻翼微颤"，**禁用"露出狰狞表情"等抽象描述**。
3. **时间倒计时锚**：T0/T1 章每隔 4-6 段必须出现一次时间锚（手表指针、墙上挂钟、手机时间），**让读者实时感受 4 小时倒计时的压迫**。
4. **温度感落点**：玻璃凉/茶水凉/江风冷/手心汗——**用温度替代抽象的"紧张/冷漠"**。每章至少 3 处温度锚。
5. **节奏切换音**：每段视角切换前必须有一个"切换音"——杯沿与瓷碟相碰、皮包扣金属响、电子脚镣警示绿灯闪烁、对岸窗户反光晃过——让节奏不破。
6. **沉默作为武器**：李梅的沉默必须"具体"——具体到她在数到第几秒、具体到她手指在皮包扣上停了多久。**禁用"她沉默了"，要写"她数到第七秒"**。
7. **物件回响**：每章必须让 §G 七大统一物证中至少 1 件出现，让 §G 主导意象池中 1 个意象贯穿全章。

### §B.6.2 三层细节（每章必须三层齐备）

- **行业层**：直播 GMV、合同违约金、AI 数字人、霸王条款、刷单刷量、税务总局、市监总局——每章至少 1 个行业细节，体现本书"现实批判"内核。
- **司法层**：电子脚镣、取保候审、刑事立案、合法取证、证据链闭环、当庭质证、数罪并罚、附带民事诉讼——每章至少 1 个司法细节，体现本书"法治"内核。
- **情感层**：李梅胸口的毕业照、林建军攥拳到指甲入肉、苏晚书房里那瓶安眠药、林飞那个 22 岁的笑容——每章至少 1 个情感锚点，体现本书"父母为子追凶"内核。

### §B.6.3 心理双面写法（每个主角章必备）

每章主角的心理必须写"明面想法+暗面真情"两层：

```
明面：他笑着说，童律师真是名不虚传，这钱花得太值了。
暗面：他在心里把"值"字念了第三遍，第三遍那个字开始发抖。
```

```
明面：她点头，说沈总放心，我不会让控方钻这个空子。
暗面：她的指尖按在皮包扣的第三个齿上，按到第七秒才松。
```
