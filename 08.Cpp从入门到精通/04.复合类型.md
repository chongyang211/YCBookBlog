## 4.8 容器

### 4.8.1 vector

动态数组，支持随机访问。

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5};
    vec.push_back(6); // 添加元素
    for (int i : vec) {
        std::cout << i << " "; // 输出: 1 2 3 4 5 6
    }
    return 0;
}
```

### 4.8.2 list

双向链表，支持高效插入和删除。

```cpp
#include <iostream>
#include <list>

int main() {
    std::list<int> lst = {1, 2, 3, 4, 5};
    lst.push_front(0); // 在头部添加元素
    for (int i : lst) {
        std::cout << i << " "; // 输出: 0 1 2 3 4 5
    }
    return 0;
}
```

### 4.8.4 map

键值对容器，基于红黑树实现，按键排序。

```cpp
#include <iostream>
#include <map>

int main() {
    std::map<std::string, int> m;
    m["Alice"] = 25;
    m["Bob"] = 30;
    for (const auto &pair : m) {
        std::cout << pair.first << ": " << pair.second << std::endl;
    }
    return 0;
}
```

### 4.8.4 unordered_map

基于哈希表的键值对容器，查找效率高。

```cpp
#include <iostream>
#include <unordered_map>

int main() {
    std::unordered_map<std::string, int> um;
    um["Alice"] = 25;
    um["Bob"] = 30;
    for (const auto &pair : um) {
        std::cout << pair.first << ": " << pair.second << std::endl;
    }
    return 0;
}
```
