## 4.1 数组

### 4.1.1 数组基本概念

在 C++ 中，**数组** 是一种用于存储相同类型元素的连续内存数据结构。数组的大小在声明时固定，不能动态改变。

数组是一组相同类型元素的集合，这些元素在内存中连续存储。数组的每个元素可以通过索引访问。

### 4.1.2 数组的声明

```cpp
数据类型 数组名[数组大小];
```

- `数据类型`：数组中元素的类型（如 `int`、`double` 等）。
- `数组名`：数组的名称。
- `数组大小`：数组中元素的数量，必须是一个常量表达式。

**示例**

```cpp
int arr[5]; // 声明一个包含 5 个整数的数组
```

### 4.1.3 数组初始化

数组可以在声明时初始化，也可以后续赋值。

**1.声明时初始化**

```cpp
int arr[5] = {1, 2, 3, 4, 5}; // 完全初始化
int arr2[5] = {1, 2}; // 部分初始化，未初始化的元素为 0
int arr3[] = {1, 2, 3, 4, 5}; // 自动推断数组大小
```

**2.后续赋值**

```cpp
int arr[5];
arr[0] = 10;
arr[1] = 20;
```

### 4.1.4 访问数组元素

数组元素通过索引访问，索引从 `0` 开始。

**示例**

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[5] = {10, 20, 30, 40, 50};

    cout << "First element: " << arr[0] << endl;
    cout << "Third element: " << arr[2] << endl;

    return 0;
}
```

### 4.1.5 多维数组

```cpp
数据类型 数组名[行数][列数];
```

案例如下：

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[2][3] = {{1, 2, 3}, {4, 5, 6}};

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            cout << "arr[" << i << "][" << j << "] = " << arr[i][j] << endl;
        }
    }

    return 0;
}
```

### 4.1.6 数组作为函数参数

数组可以作为函数参数传递，通常以指针的形式传递。**示例**

```cpp
#include <iostream>
using namespace std;

void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}

int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    printArray(arr, 5); // 传递数组和大小
    return 0;
}
```

### 4.1.7 动态数组

C++ 使用 `new` 和 `delete` 运算符动态分配和释放数组。

**动态分配数组**

```cpp
int *arr = new int[5]; // 动态分配一个包含 5 个整数的数组
for (int i = 0; i < 5; i++) {
    arr[i] = i + 1;
}
```

**释放数组**

```cpp
delete[] arr; // 释放动态数组
```


## 4.8 容器

### 4.8.1 vector

动态数组，支持随机访问。

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5};
    vec.push_back(6); // 添加元素
    for (int i : vec) {
        std::cout << i << " "; // 输出: 1 2 3 4 5 6
    }
    return 0;
}
```

### 4.8.2 list

双向链表，支持高效插入和删除。

```cpp
#include <iostream>
#include <list>

int main() {
    std::list<int> lst = {1, 2, 3, 4, 5};
    lst.push_front(0); // 在头部添加元素
    for (int i : lst) {
        std::cout << i << " "; // 输出: 0 1 2 3 4 5
    }
    return 0;
}
```

### 4.8.4 map

键值对容器，基于红黑树实现，按键排序。

```cpp
#include <iostream>
#include <map>

int main() {
    std::map<std::string, int> m;
    m["Alice"] = 25;
    m["Bob"] = 30;
    for (const auto &pair : m) {
        std::cout << pair.first << ": " << pair.second << std::endl;
    }
    return 0;
}
```

### 4.8.4 unordered_map

基于哈希表的键值对容器，查找效率高。

```cpp
#include <iostream>
#include <unordered_map>

int main() {
    std::unordered_map<std::string, int> um;
    um["Alice"] = 25;
    um["Bob"] = 30;
    for (const auto &pair : um) {
        std::cout << pair.first << ": " << pair.second << std::endl;
    }
    return 0;
}
```
