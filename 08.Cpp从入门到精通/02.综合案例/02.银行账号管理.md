## 01.项目需求和功能

### 1.1 需求介绍

银行账户管理系统，满足你提出的功能需求。该系统支持开户、存款、取款、查询余额、转账、保存数据到文件以及从文件读取数据。

### 1.2 功能要求

**功能要求**：

1. **开户**：创建新账户，输入账户号、姓名和初始余额。
2. **存款**：根据账户号存款，更新账户余额。
3. **取款**：根据账户号取款，更新账户余额。
4. **查询余额**：根据账户号查询当前余额。
5. **转账**：支持从一个账户转账到另一个账户。
6. **保存数据到文件**：将账户数据保存到文件中。
7. **从文件读取数据**：启动时从文件加载账户数据。

### 1.3 设计思路

**面向对象设计**

- **Account 类**：表示一个银行账户，封装了账户号、姓名、余额等属性，以及存款、取款、转账等行为。
- **Bank 类**：管理多个账户，提供开户、存款、取款、查询余额、转账等功能。
- **FileManager 类**：负责将账户数据保存到文件和从文件加载数据，实现了数据的持久化。

**模块化设计**将系统分为多个模块（类），每个模块负责特定的功能：

- **Account**：账户的核心逻辑。
- **Bank**：账户的管理和操作。
- **FileManager**：文件读写操作。
- **Main 函数**：用户交互界面。

**数据持久化**

- 使用文件存储账户数据，确保程序关闭后数据不会丢失。
- 文件格式为 CSV（逗号分隔值），便于读取和解析。


### 1.4 涉及知识点

**面向对象编程（OOP）**

- **封装**：将账户的属性和行为封装在 `Account` 类中，隐藏内部实现细节。
- **继承**：本案例未使用继承，但可以通过继承扩展功能（如不同类型的账户）。
- **多态**：本案例未使用多态，但可以通过多态实现更灵活的设计（如不同账户类型的行为差异）。

**标准模板库（STL）**

- **`std::vector`**：用于存储多个账户，提供动态数组的功能。
- **`std::string`**：用于处理字符串（如账户号、姓名）。
- **`std::ifstream` 和 `std::ofstream`**：用于文件的读写操作。
- **`std::stringstream`**：用于解析文件中的 CSV 数据。

**文件操作**

- **文件读写**：使用 `std::ifstream` 和 `std::ofstream` 实现文件的读取和写入。
- **CSV 格式**：文件中的数据以逗号分隔，便于解析和存储。

**用户输入处理**

- **`std::cin` 和 `std::getline`**：用于从用户输入中获取数据。
- **输入验证**：确保用户输入的金额为正数，账户号存在等。

**错误处理**

- **空指针检查**：在查找账户时，检查返回的指针是否为空。
- **文件打开检查**：在读写文件时，检查文件是否成功打开。

**循环和条件语句**

- **`while` 循环**：用于主菜单的持续显示和用户交互。
- **`switch` 语句**：根据用户选择执行不同的操作。

**函数和模块化**

- **函数封装**：将功能封装到独立的函数中（如 `displayMenu`、`findAccount`）。
- **模块化设计**：将不同功能分配到不同的类中，提高代码的可维护性。

### 1.5 项目结构设计

项目分为以下几个部分：

- **Account 类**：表示银行账户，包含账户号、姓名、余额等属性。
- **Bank 类**：管理所有账户，提供开户、存款、取款、查询余额、转账等功能。
- **FileManager 类**：负责将账户数据保存到文件和从文件加载数据。
- **Main 函数**：提供用户交互界面，调用 Bank 类的功能。

## 03.录入开户信息

### 3.1 定义用户体

```cpp
class Account {
private:
    std::string accountNumber; // 账户号
    std::string name;          // 姓名
    double balance;            // 余额
public:
    // 构造函数
    Account(const std::string& accNumber, const std::string& accName, double initialBalance) {
        this->accountNumber = accNumber;
        this->name = accName;
        this->balance = initialBalance;
    }
    
    // 获取账户号
    std::string getAccountNumber() const {
        return accountNumber;
    }

    // 获取姓名
    std::string getName() const {
        return name;
    }

    // 获取余额
    double getBalance() const {
        return balance;
    }
};
```

## 06.项目概括总结

### 6.1 类详细设计

#### **3.1 Account 类**
- **属性**：
    - `accountNumber`：账户号。
    - `name`：账户持有人姓名。
    - `balance`：账户余额。
- **方法**：
    - `deposit`：存款。
    - `withdraw`：取款。
    - `transfer`：转账。
    - `display`：显示账户信息。

#### **3.2 Bank 类**
- **属性**：
    - `accounts`：存储所有账户的 `std::vector`。
- **方法**：
    - `createAccount`：创建新账户。
    - `findAccount`：根据账户号查找账户。
    - `deposit`：存款。
    - `withdraw`：取款。
    - `queryBalance`：查询余额。
    - `transfer`：转账。
    - `displayAllAccounts`：显示所有账户信息。

#### **3.3 FileManager 类**
- **方法**：
    - `saveToFile`：将账户数据保存到文件。
    - `loadFromFile`：从文件加载账户数据。

#### **3.4 Main 函数**
- **功能**：
    - 显示菜单。
    - 根据用户选择调用 `Bank` 类的相应方法。
    - 处理用户输入。

### 6.2 扩展性设计

- **支持更多账户类型**：可以通过继承 `Account` 类实现不同类型的账户（如储蓄账户、信用卡账户）。
- **支持更多操作**：可以添加更多功能（如修改账户信息、删除账户）。
- **支持更多文件格式**：可以扩展 `FileManager` 类以支持 JSON、XML 等文件格式。
