### **设计思路**

1. **核心目标**：
    - 实现一个轻量级的数据库管理系统，支持表的创建、数据的插入、查询、保存和加载。

    - **表管理**：创建表、定义列。
    - **数据管理**：插入行、查询表。
    - **持久化**：将数据库保存到文件，从文件加载数据库。

3. **数据结构**：
    - 使用 `std::vector` 存储表、列和行。
    - 使用 `void*` 指针存储不同类型的数据（如 `int`、`float`、`std::string`）。

4. **文件存储**：
    - 使用二进制文件保存和加载数据库，确保数据的完整性和高效性。

---

### **设计步骤**

1. **定义数据结构**：
    - **`Column` 类**：表示表的列，包含列名和数据类型。
    - **`Row` 类**：表示表中的一行，包含数据和列类型信息。
    - **`Table` 类**：表示表，包含表名、列和行。
    - **`Database` 类**：表示数据库，包含多个表。

2. **实现核心功能**：
    - **创建表**：根据列定义创建表。
    - **插入行**：将数据插入到指定表中。
    - **查询表**：输出表的所有数据。
    - **保存数据库**：将数据库保存到二进制文件。
    - **加载数据库**：从二进制文件加载数据库。

3. **处理数据类型**：
    - 使用 `enum` 定义数据类型（如 `int`、`float`、`string`）。
    - 使用 `void*` 指针存储不同类型的数据，并在操作时根据数据类型进行类型转换。

4. **文件读写**：
    - 使用 `std::ofstream` 和 `std::ifstream` 进行二进制文件的读写。
    - 保存时，将表名、列名、数据类型和数据写入文件。
    - 加载时，从文件中读取数据并重建数据库。

5. **内存管理**：
    - 使用 `new` 和 `delete` 动态分配和释放内存。
    - 在 `Row` 和 `Table` 的析构函数中释放动态分配的内存，避免内存泄漏。

### **使用的技术点**

1. **面向对象编程（OOP）**：
    - 使用类封装数据库、表、行和列。
    - 通过成员函数实现功能，如 `createTable`、`insertRow`、`queryTable` 等。

2. **标准模板库（STL）**：
    - 使用 `std::vector` 存储表、列和行。
    - 使用 `std::string` 存储字符串数据。

3. **枚举类型（`enum`）**：
    - 使用 `enum` 定义数据类型，如 `TYPE_INT`、`TYPE_FLOAT`、`TYPE_STRING`。

4. **动态内存管理**：
    - 使用 `new` 和 `delete` 动态分配和释放内存。
    - 使用 `void*` 指针存储不同类型的数据。

5. **文件操作**：
    - 使用 `std::ofstream` 和 `std::ifstream` 进行二进制文件的读写。
    - 使用 `write` 和 `read` 函数保存和加载数据。

6. **类型转换**：
    - 使用 `static_cast` 将 `void*` 指针转换为具体类型（如 `int*`、`float*`、`std::string*`）。

7. **错误处理**：
    - 在文件操作时检查文件是否成功打开。
    - 在插入行时检查表是否存在。
