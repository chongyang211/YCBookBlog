### 2.2 日志系统实现

主要是把日志打印到控制台，并且存储到file文件中

```cpp
class Logger {
private:
    //日志文件file
    std::ofstream logFile;
    //日志锁，多线程安全
    std::mutex logMutex;
public:
    //在构造函数中传入文件路径，打开文件。如果文件不存在则抛出错误
    Logger(const std::string& fileName) {
        logFile.open(fileName,std::ios::out | std::ios::app);
        if (!logFile.is_open()) {
            throw std::runtime_error("Failed to open log file.");
        }
    }
    //在析构函数中，关闭文件流
    ~Logger() {
        if (logFile.is_open()) {
            logFile.close();
        }
    }
    //打印日志，需要传入打印内容和打印日志级别，默认是info日志类型
    void log(const std::string& message , LogLevel level = LogLevel::INFO) {
        //多线程安全，这里用lock_guard锁
        std::lock_guard<std::mutex> lock(logMutex);
        std::string levelStr;
        switch (level) {
            case LogLevel::INFO: levelStr = "INFO"; break;
            case LogLevel::DEBUG: levelStr = "DEBUG"; break;
            case LogLevel::WARNING: levelStr = "WARNING"; break;
            case LogLevel::ERROR: levelStr = "ERROR"; break;
        }
        std::string logMessage = "[" + levelStr + "] " + message;
        logFile << logMessage << std::endl;
        std::cout << logMessage << std::endl;
    }
};
```

### 2. 多线程实现要点

#### (1) 售票窗口线程
每个窗口有自己的工作线程处理队列中的顾客请求：
```cpp
void processQueue() {
    while (running) {
        // 等待队列中有顾客
        unique_lock<mutex> lock(queueMutex);
        cv.wait(lock, [this] { return !customerQueue.empty() || !running; });
        
        // 处理顾客请求
        unique_ptr<Customer> customer = move(customerQueue.front());
        customerQueue.pop();
        lock.unlock();
        
        // 处理购票流程（查询、预订、支付、出票）
        if (customer) {
            // ... 具体购票流程
        }
        
        // 模拟服务时间
        this_thread::sleep_for(chrono::milliseconds(serviceTime));
    }
}
```

#### (2) 客户行为模拟线程
模拟真实场景中的顾客到来模式：
```cpp
void simulateCustomerBehavior() {
    while (running) {
        // 随机选择顾客
        int customerIdx = customerDist(gen);
        auto it = next(customers.begin(), customerIdx);
        
        // 复制顾客信息
        unique_ptr<Customer> customerCopy = make_unique<Customer>(*(it->second));
        
        // 随机选择售票窗口
        int windowIdx = windowDist(gen);
        ticketWindows[windowIdx]->addCustomer(move(customerCopy));
        
        // 随机间隔时间
        this_thread::sleep_for(chrono::milliseconds(waitDist(gen)));
    }
}
```

#### (3) 线程间同步机制
- **互斥锁(mutex)**: 保护共享资源（事件数据、客户数据等）
- **条件变量(condition_variable)**: 窗口通知机制处理顾客队列
- **原子操作(atomic)**: 记录售票数量、收入等统计信息
