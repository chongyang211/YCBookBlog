## 19.4 头文件保护

### 19.4.1 理解头文件保护

`#ifndef`, `#define`, 和 `#endif` 是 C++ 中的预处理指令，用于防止头文件被多次包含（即防止重复包含）。 这种技术称为 **头文件保护** 或 **包含保护**。

### 19.4.2 用例说明

`#ifndef`, `#define`, `#endif`，用于防止头文件被多次包含。

```cpp
#ifndef MYHEADER_H
#define MYHEADER_H

// 头文件内容

#endif // MYHEADER_H
```

### 19.4.3 头文件保护作用

在 C++ 中，如果一个头文件被多次包含（例如，多个源文件都包含了同一个头文件），可能会导致重复定义错误。头文件保护通过条件编译来避免这种情况。



### 1111

C++ 预处理器是 C++ 编译过程中的一个独立阶段，它在实际编译之前对源代码进行处理。预处理器通过执行一系列指令（以 `#` 开头的命令）来修改源代码，生成一个经过处理的版本，然后将其传递给编译器。

以下是 C++ 预处理器的核心功能和常见用法：

---

### **1. 头文件包含 (`#include`)**

`#include` 用于将其他文件的内容插入到当前文件中。通常用于包含头文件。

```cpp
#include <iostream>  // 包含标准库头文件
#include "myheader.h" // 包含用户定义的头文件
```

- `< >`：用于包含标准库头文件，编译器会在系统路径中查找。
- `" "`：用于包含用户定义的头文件，编译器会先在当前目录中查找，然后在系统路径中查找。

---

### **2. 宏定义 (`#define`)**

`#define` 用于定义宏，宏是一个标识符，代表一段代码或值。

```cpp
#define PI 3.14159 // 定义常量宏
#define MAX(a, b) ((a) > (b) ? (a) : (b)) // 定义函数宏
```

- 宏在预处理阶段会被直接替换为定义的内容。
- 注意：宏没有类型检查，容易引入错误，建议优先使用 `const` 或 `inline` 函数。

---

### **3. 条件编译 (`#if`, `#ifdef`, `#ifndef`, `#else`, `#elif`, `#endif`)**

条件编译用于根据条件决定是否编译某段代码。

```cpp
#define DEBUG 1

#if DEBUG
    std::cout << "调试模式" << std::endl;
#else
    std::cout << "发布模式" << std::endl;
#endif
```

- `#ifdef`：如果宏已定义，则编译后续代码。
- `#ifndef`：如果宏未定义，则编译后续代码。
- `#else` 和 `#elif`：用于多条件分支。

### **5. 预定义宏**

C++ 预处理器提供了一些预定义宏，用于获取编译环境信息。

```cpp
std::cout << "当前文件: " << __FILE__ << std::endl; // 当前文件名
std::cout << "当前行号: " << __LINE__ << std::endl; // 当前行号
std::cout << "编译日期: " << __DATE__ << std::endl; // 编译日期
std::cout << "编译时间: " << __TIME__ << std::endl; // 编译时间
```

---

### **6. 错误指令 (`#error`)**

`#error` 用于在预处理阶段生成错误信息，并停止编译。

```cpp
#if !defined(CXX_VERSION)
    #error "CXX_VERSION 未定义"
#endif
```

---

### **7. 警告指令 (`#warning`)**

`#warning` 用于在预处理阶段生成警告信息，但不会停止编译。

```cpp
#if defined(OLD_VERSION)
    #warning "使用旧版本代码"
#endif
```

---

### **8. 行控制 (`#line`)**

`#line` 用于修改编译器报告的行号和文件名。

```cpp
#line 100 "myfile.cpp"
std::cout << "当前行号: " << __LINE__ << std::endl; // 输出 100
```

---

### **9. 空指令 (`#`)**

`#` 是一个空指令，没有实际作用，通常用于占位。

---

### **10. 宏取消定义 (`#undef`)**

`#undef` 用于取消已定义的宏。

```cpp
#define MY_MACRO 1
#undef MY_MACRO
```

---

### **11. 字符串化操作符 (`#`)**

`#` 用于将宏参数转换为字符串。

```cpp
#define STRINGIFY(x) #x
std::cout << STRINGIFY(Hello World) << std::endl; // 输出 "Hello World"
```

---

### **12. 连接操作符 (`##`)**

`##` 用于将两个标记连接成一个标记。

```cpp
#define CONCAT(a, b) a##b
int xy = 10;
std::cout << CONCAT(x, y) << std::endl; // 输出 10
```

---

### **13. 预处理器与编译器的关系**

1. **预处理阶段**：
    - 预处理器处理所有以 `#` 开头的指令，生成一个经过处理的源代码文件。
2. **编译阶段**：
    - 编译器将预处理后的代码编译为目标文件。

---

### **示例：综合使用预处理器**

```cpp
#include <iostream>
#define DEBUG 1
#define MAX(a, b) ((a) > (b) ? (a) : (b))

int main() {
    #ifdef DEBUG
        std::cout << "调试模式" << std::endl;
    #endif

    int x = 10, y = 20;
    std::cout << "最大值: " << MAX(x, y) << std::endl;

    #if __cplusplus >= 201103L
        std::cout << "C++11 或更高版本" << std::endl;
    #else
        std::cout << "C++98" << std::endl;
    #endif

    return 0;
}
```

### **总结**

C++ 预处理器是一个强大的工具，可以用于：
- 包含头文件
- 定义宏
- 条件编译
- 获取编译环境信息
- 生成错误或警告

合理使用预处理器可以提高代码的灵活性和可维护性，但应避免滥用宏，以免引入难以调试的问题。

### **实现 FileManager.cpp**

在 `FileManager.cpp` 中实现头文件中声明的函数：

```cpp
#include "FileManager.h"
#include <fstream>
#include <iostream>

// 构造函数
FileManager::FileManager() {
    // 初始化代码
}

// 读取文件内容
std::vector<std::string> FileManager::readFile(const std::string& filePath) {
    std::vector<std::string> lines;
    std::ifstream file(filePath);
    if (file.is_open()) {
        std::string line;
        while (std::getline(file, line)) {
            lines.push_back(line);
        }
        file.close();
    } else {
        std::cerr << "无法打开文件: " << filePath << std::endl;
    }
    return lines;
}

// 写入文件内容
void FileManager::writeFile(const std::string& filePath, const std::vector<std::string>& content) {
    std::ofstream file(filePath);
    if (file.is_open()) {
        for (const auto& line : content) {
            file << line << std::endl;
        }
        file.close();
    } else {
        std::cerr << "无法写入文件: " << filePath << std::endl;
    }
}

// 检查文件是否存在
bool FileManager::fileExists(const std::string& filePath) {
    std::ifstream file(filePath);
    return file.good();
}
```
