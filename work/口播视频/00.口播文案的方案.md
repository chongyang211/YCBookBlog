# 口播文案 · 风格方案

## 一、对标的流量密码

| 账号 | 为什么火 | 能偷什么 |
|------|----------|----------|
| 心理唠叨兽 | 用"你有没有…"让你觉得他在说你，然后给你一个反常识的解释 | 共情钩子 + 认知颠覆 |
| 大橙子有话说 | 说话带刺但不让人讨厌，一句话能把你的遮羞布扯掉 | 锋利观点 + 不讨好感 |
| 崔磊 | 每句话都在制造"原来如此"的瞬间 | 信息差，给你你不知道但要命的东西 |
| 阿怀 | 用"我告诉你"的压迫感输出，粉丝反而更信 | 笃定感 + 不容置疑的语气 |

**共同规律**：都不是"教你做人"，而是"替你说出你不敢说的话"。观众转发的动机不是"这个好有用"，而是**"这就是我想说但不知道怎么说的话"**。

## 二、选题铁律

### 一句话：观点必须冒犯一类人

温和等于没人看。每一个选题，你当场就能说出"谁会不同意"——如果所有人都同意，这篇不用写。

**选题自检三问**：
1. 看完标题，有没有人想骂你？ → 有，就对了
2. 这个观点，是不是大部分人心里想过但不敢说？ → 是，这是爆款
3. 能不能用一句话说清楚？ → 不能，说明你没想清楚

### 六类高流量选题模板

| 类型 | 公式 | 例子 |
|------|------|------|
| 揭老底 | 你以为 X 是因为 Y，其实是 Z | 你以为工资低是能力问题，其实是你不会汇报 |
| 掀桌子 | 别再说 X 了，真相是 Y | 别再相信"吃亏是福"了，吃亏就是吃亏 |
| 诛心流 | 有一种人，X，但他们不知道 Y | 有一种人，30 岁就死了，80 岁才埋 |
| 反共识 | 所有人都说 X，但我劝你别 X | 所有人都说要努力，但我劝你别太努力 |
| 贴标签 | 如果你 X，恭喜你，你是 Y | 如果你觉得上班如上坟，恭喜你，你还活着 |
| 算账流 | X 这件事，一年让你亏了 Y | 不敢拒绝这件事，一年让你亏了 10 万块 |

## 三、脚本五段式（流量版）

```
┌─────────────────────────────────────────┐
│ 钩子 (3秒)                               │
│ 一句让目标人群停下滑动手指的暴论          │
├─────────────────────────────────────────┤
│ 撕伤口 (15秒)                            │
│ 用"你有没有过…""你是不是也…"精准打击一人群  │
│ 关键词：具体场景，非抽象道理               │
├─────────────────────────────────────────┤
│ 补一刀 (10秒)                            │
│ 把问题升级：你以为这就完了？还有更扎心的    │
│ "更可怕的是…""但真相是…"                  │
├─────────────────────────────────────────┤
│ 转机 (20秒)                              │
│ 反常识解法。给出一个"卧槽原来可以这样"的瞬间 │
│ "有没有一种可能…""但其实…"                │
├─────────────────────────────────────────┤
│ 收尾钩 (5秒)                             │
│ 金句 + 留白式互动                        │
│ "所以我想问你…"（不说点赞关注）           │
└─────────────────────────────────────────┘
```

**时长目标**：500-600 字，口播约 60-75 秒。抖音完播率最优区间是 45-75 秒，超过 90 秒断崖下跌。

## 四、文字配方

### 4.1 节奏控制

| 节奏型 | 字数 | 作用 |
|--------|------|------|
| 短句连击 | 3-5 字 × 3 句 | 开篇造势，像鼓点 |
| 场景白描 | 10-15 字 × 3 句 | 画面代入，制造共情 |
| 一句话暴击 | 8-12 字 | 金句位置，必须能截屏 |
| 问句收尾 | 10-15 字 | 制造留白，引导评论区 |

### 4.2 口语配方

- "你" 出现频率：每 100 字至少 3 次。不是"我们每个人"，是"你"
- 转折词密度：每 100 字至少 1 个"但/可/其实/有没有一种可能"
- 禁止词："众所周知""毋庸置疑""第一点第二点""家人们""一键三连"

### 4.3 情绪曲线

```
情绪值
  │     ┌─ 补刀（最低点）
  │    ╱ ╲
  │   ╱   ╲
  │  ╱     ╲___ 转机（拉回）
  │ ╱ 痛点           ╲___ 收尾（留白）
  │╱ 代入                 ╲___
  └────────────────────────────→ 时间
```

观众在最低点（"补刀"）时情绪被压到最底，此时给的"转机"最有冲击力——**跌得越深，弹得越高**。

## 五、爆款公式验证

把上述所有规则压缩成一条执行清单：

```
[ ] 选题能让一类人骂你
[ ] 开头 8 个字内出现"你"
[ ] 用了一个具体场景而非抽象概念
[ ] 有一句话能截屏（金句）
[ ] 全文出现至少 2 个"但"
[ ] 结尾是一个问句，不是总结
[ ] 朗读一遍不卡壳
```

## 七、输出标准

### 7.1 单篇硬指标

| 维度 | 标准 | 为什么 |
|------|------|--------|
| 字数 | 500-600 字 | 60-75 秒完播率最优 |
| 段落 | ≤5 段 | 超过 5 段观众记不住主线 |
| 句长 | ≤15 字 | 超过 15 字口播会断气 |
| 场景 | ≥1 个具体场景 | 没有场景的文案等于白写 |
| 争议 | 有一类人不同意 | 没人反对=没人转发 |
| 金句 | 结尾 1 句可截屏 | 截屏分享=你的免费传播 |

### 7.2 验收 7 条

```
[ ] 第一句不是自我介绍，是暴论
[ ] "你" 出现 ≥8 次
[ ] "但/可是/其实" 出现 ≥2 次
[ ] 有一个"你有没有过"或"是不是这样"
[ ] 没有"第一第二""众所周知""家人们"
[ ] 结尾是问句，不是"加油"
[ ] 能截屏分享
```

## 八、改造流水线

### 8.1 已有底稿 → 改写

```
原稿
  │
  ├── 1. 砍长句：>15 字的拆两句
  ├── 2. 换人称：所有"我们"→"你"
  ├── 3. 补钩子：第一句必须是暴论
  ├── 4. 加场景：至少补一个"你有没有过…"
  ├── 5. 埋金句：结尾补可截屏句
  └── 6. 过验收：7 条自查
```

### 8.2 空壳选题 → 创作

```
H2 标题（如"别把平台当本事"）
  │
  ├── 1. 提取核心观点（一句话说清楚）
  ├── 2. 选流量模板（揭老底/掀桌子/诛心流…）
  ├── 3. 搭五段骨架（钩子→痛点→补刀→转机→收尾）
  ├── 4. 填具体场景（职场/社交具体事件）
  └── 5. 过验收
```

## 九、发布策略

### 9.1 冷启动节奏

| 阶段 | 时长 | 条数 | 选题策略 |
|------|------|------|----------|
| 炸号期 | 前 3 天 | 每天 2 条 | 只发 S 级，只选评论必吵架的 |
| 冲权重 | 第 4-7 天 | 每天 1 条 | S+A 混合 |
| 稳定期 | 第 2 周起 | 3-4 条/周 | A+B 穿插，保持周更 2 条 S |

### 9.2 黄金发布时间

职场/人性/沟通类：周一至周四 20:00-22:00（打工人下班刷手机高峰）
情感/成长类：周五周六 21:00-23:00（周末前情绪低谷）
理财/经济类：周日 10:00-12:00（计划下周的高认知时间）

### 9.3 评论区运营

评论区是第二个流量入口，不是附属品。

- **故意留破绽**：文案中留一个"这也不对"的缺口，观众天然想纠正你
- **自己抢沙发**：发完立刻用小号留一条争议评论，带动风向
- **置顶金句**：把文案里最好的那句置顶在评论区，二次曝光

## 十、数据迭代闭环

```
发布 → 观察 2h 数据
  │
  ├── 完播率 < 30% → 钩子不够炸 → 改开头
  ├── 点赞率 < 3%  → 共鸣不够 → 补场景
  ├── 评论率 < 0.5% → 争议不够 → 选题太安全
  ├── 转发率 < 0.3% → 金句不够 → 结尾改一句
  └── 都达标 → 复用模板量产同类型
```

**不看粉丝量，看互动率。** 1 万粉丝 10% 互动 > 10 万粉丝 1% 互动。平台推流的唯一标准是这条内容有没有让人"停下来"。

## 十一、完整示例：汇报能力是核心

你有没有过这种委屈——一个项目你干了 80% 的活，熬了最多的夜，填了最深的坑。结果季度复盘的时候，拿 A 的居然是那个只在群里发了几个 PPT 的人。

不服气。对吧？

但你先别急着骂。**我问你一个问题：你的领导，真的知道你干了什么吗？**

你想想看。你写了三千行代码，他没看见。你凌晨三点爬起来修了一个 P0 故障，他不知道。你为了这个项目推掉了三个朋友的饭局，他更不可能知道。他不是不想关心你——**是他的带宽根本不够。** 一个 Leader 手底下六七个你，每个人都说自己很忙，他拿什么判断谁是真忙、谁是假忙？

那个拿 A 的人，不是比你干得多。他是比你更早想明白了一件事：**职场里，没有说出来的成果，就是不存在的成果。**

你以为汇报是拍马屁。你以为把事情做完自然会被看见。你以为"金子总会发光"——但你没想过，你在地下三千米，谁来挖你？

更扎心的是：Leader 向他的 Leader 汇报的时候，也需要素材。**你不给他子弹，他拿什么给你争资源、争晋升、争年终奖？** 他只能拿那个给了子弹的人去汇报。

所以这不是道德问题，这是信息结构问题。你在底层拼命输出，但信息从来不上传——你卡的不是天花板，是自己的嘴。

试试一个最简单的动作：下次周报里，别写"完成了 XX 模块开发"。写成"完成了 XX 模块，上线后接口耗时降低 40%，用户投诉从每周 3 起降到 0"。

你给了他一发子弹。他下次开会就能替你开枪。

所以我想问你——如果今天你就要给 Leader 做一次 30 秒的口头汇报，你会说什么？
