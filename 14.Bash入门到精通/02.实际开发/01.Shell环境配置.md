## 01.查看使用的Shell

在 macOS 上，了解当前使用的 Shell 是 Zsh 还是 Bash 非常简单。

### 1.1 echo $SHELL

**方法 1：使用 `echo $SHELL` 命令**
1. 打开终端。
2. 运行以下命令：

```bash
CHONGYYANG-MB1:~ yangchong$ echo $SHELL
/bin/bash
```

- 如果输出是 `/bin/zsh`，说明当前使用的是 Zsh。
- 如果输出是 `/bin/bash`，说明当前使用的是 Bash。

#### **方法 2：使用 `ps` 命令**
1. 打开终端。
2. 运行以下命令：
   ```bash
   ps -p $$
   ```
    - 在输出中查找 `COMMAND` 列，如果显示 `zsh`，说明当前使用的是 Zsh；如果显示 `bash`，说明当前使用的是 Bash。

#### **方法 3：查看默认 Shell**
1. 打开终端。
2. 运行以下命令：
   ```bash
   echo $0
   ```
    - 如果输出是 `-zsh`，说明当前使用的是 Zsh。
    - 如果输出是 `-bash`，说明当前使用的是 Bash。

---

### **2. 切换 Shell**
如果你想切换默认 Shell，可以使用以下命令。

#### **切换到 Zsh**
```bash
chsh -s /bin/zsh
```

#### **切换到 Bash**
```bash
chsh -s /bin/bash
```

切换后，需要重新启动终端或重新登录以生效。

---

### **3. Zsh 和 Bash 的区别**
Zsh 和 Bash 都是 Unix/Linux 系统中常用的 Shell，但它们有一些显著的区别：

| 特性                | Zsh                                      | Bash                                      |
|---------------------|------------------------------------------|------------------------------------------|
| **默认 Shell**      | macOS Catalina（10.15）及更高版本默认 Shell。 | macOS Catalina 之前版本的默认 Shell。     |
| **兼容性**          | 兼容 Bash，但有一些语法和行为差异。       | 广泛兼容，是大多数脚本的标准 Shell。      |
| **功能**            | 提供更强大的自动补全、主题和插件支持。     | 功能相对简单，但足够满足大多数需求。      |
| **配置文件**        | `~/.zshrc`                               | `~/.bashrc` 或 `~/.bash_profile`          |
| **插件和主题**      | 支持丰富的插件和主题（如 Oh My Zsh）。     | 插件和主题支持较少。                      |
| **性能**            | 启动速度较慢，但功能更强大。               | 启动速度较快，适合轻量级使用。            |
| **社区支持**        | 社区活跃，插件和主题资源丰富。             | 社区支持广泛，但插件和主题较少。          |

---

### **4. 如何选择 Zsh 或 Bash**
- **选择 Zsh**：
    - 如果你喜欢强大的自动补全、主题和插件功能。
    - 如果你使用 macOS Catalina 或更高版本，Zsh 是默认 Shell。
    - 如果你需要更现代化的 Shell 体验。

- **选择 Bash**：
    - 如果你需要兼容性更好的 Shell，尤其是运行脚本时。
    - 如果你更喜欢轻量级和快速的 Shell。
    - 如果你习惯了 Bash 的语法和行为。

---

### **5. 总结**
| 操作                                | 说明                                      |
|-------------------------------------|-----------------------------------------|
| 查看当前 Shell                      | 使用 `echo $SHELL` 或 `ps -p $$`。       |
| 切换 Shell                          | 使用 `chsh -s /bin/zsh` 或 `chsh -s /bin/bash`。 |
| Zsh 和 Bash 的区别                  | Zsh 功能更强大，Bash 兼容性更好。        |
| 选择 Shell                          | 根据需求选择 Zsh 或 Bash。               |

通过以上方法，你可以轻松了解当前使用的 Shell，并根据需求在 Zsh 和 Bash 之间切换。
