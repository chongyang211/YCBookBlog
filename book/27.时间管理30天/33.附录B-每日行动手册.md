## 01.工具页〇：起始画像卡

**对应章节**：序章（开填）、Day 30（回读闭环）。

**版式说明**：一页手写卡片，介于扉页与工具页之间——它不测量任何东西，只负责存档"出发那天的你"。全书第一张动笔的工具页，也是最后一张被回读的。

**字段清单**：

| 区域 | 填写内容 |
|:---|:---|
| 今天的日期 | ____年__月__日（Day 01 当天） |
| 此刻的感受 | 三个词以内：__________（多数人写的是：忙、累、想变） |
| 我的一天 | 用一句话描述你典型的一天：__________ |
| 最想改变的一件事 | __________ |
| 三十天后的期待 | 我希望一个月后的我：__________ |
| 给三十天后的一句话 | （写给那个即将走完三十天的自己） |

**使用方法**：序章那天填好，夹在这本书的附录里，三十天不去动它。Day 30 那天取出来逐行对读——用 Day 01 教的眼光：**只看见，不评判。**读完做终章的核心功课：在卡片背面，写下那个"三十天前做不到、现在做得到"的事，签上名字和日期。这张卡从此有了正反两面：正面是起点，背面是第一圈复利。**每年可以再填一张新的：它是你的年度存档。**

## 02.工具页一：五种时间饼图

**对应章节**：Day 01（记录）、Day 05（分类）、Day 29（平衡）。

**版式说明**：一页两个空白饼图并排，左边标"昨天·实际"，右边标"下周·理想"。饼图外圈印五色图例。

**字段清单**：

| 色标 | 时间类型 | 实际占比（左图填） | 理想占比（右图填） |
|:---:|:---|:---:|:---:|
| 蓝 | 生存时间 | ___% | ___% |
| 金 | 赚钱时间 | ___% | ___% |
| 绿 | 好看时间 | ___% | ___% |
| 橙 | 好玩时间 | ___% | ___% |
| 紫 | 心流时间 | ___% | ___% |

**使用方法**：第一步，先填左图——按 Day 01 的记录算出昨天五种时间的实际占比，手绘切分；第二步，再填右图——不是"理想的人生"，是"下周够得着的调整"（Day 29 规则：**只调一项**）。两图并排放，中间那条差距，就是下周的行动。第三步，每周日重画一次，四张连起来看趋势。

## 03.工具页二：人生起落图

**对应章节**：Day 03（起落图）、Day 30（年终重画）。

**版式说明**：横轴 0–80 岁（每格 5 岁，"现在"的位置画一条竖线加粗），纵轴 -10 到 +10（情绪高度，0 线居中）。留白区域印引导语。

**字段清单**：

| 区域 | 填写内容 |
|:---|:---|
| 曲线主体 | 标出 10–15 个决定性瞬间，按年龄与情绪高度打点连线 |
| 瞬间标签 | 每个点旁写 3–5 个字的事件名（如"高考""转行""父母病"） |
| 当前位置 | 竖线处标注"我现在在这里"与当前情绪分 |
| 洞察一 | 我的得失感，主要取决于：________ |
| 洞察二 | 我的低谷模式（共通触发点）：________ |
| 洞察三 | 我的高峰模式（共通条件）：________ |
| 下一个高峰 | 我想创造的下一个决定性瞬间：________ |

**使用方法**：一次画完，约四十分钟，找一个不被打扰的晚上。画完先放三天再看——第一遍看到的是事件，第三遍看到的才是模式。**每年年底重画一次**：把新的一年补上去，看着你的曲线自己长。

## 04.工具页三：三十天训练计划

**对应章节**：Day 12（训练计划）、Day 13（对手）、Day 11（教练）。

**版式说明**：上半页为信息区，下半页为三十天打卡表（每行一天：日期、任务、完成、备注四列）。

**字段清单**：

| 区域 | 填写内容 |
|:---|:---|
| 本期目标 | 一句话，可量化、有截止日（踮踮脚够得到） |
| 教练 | 姓名/账号 + 我请教过的问题 |
| 对手 | 姓名/账号 + 三个可量化指标 |
| 下一个赛点 | 事件 + 截止日期 + 评估标准 |
| 偷懒配额 | 本月允许偷懒 ___ 天（建议 6 天，即 20%） |

**打卡表（示例行）**：

| Day | 日期 | 今日任务（3 件小事） | 完成 | 备注 |
|:---:|:---|:---|:---:|:---|
| 1 | __月__日 | ①____ ②____ ③____ | ☐ | |
| 2 | __月__日 | ①____ ②____ ③____ | ☐ | |
| … | … | … | … | … |
| 28 | __月__日 | 周复盘：本月偷懒用了几天？ | ☐ | |
| 30 | __月__日 | 结营盘点：计划需续期/需修订 | ☐ | |

**使用方法**：每周末留一行做复盘（每 7 天一行），偷懒配额必须预填——**先批准自己可以偷懒，偷懒才不会变成放弃。**

## 05.工具页四：心流触发四步卡

**对应章节**：Day 26（清空与仪式）、Day 27（结界与模拟）。

**版式说明**：名片大小口袋卡（亦可打印成桌卡）。**正面**四步流程，**背面**自查三问。

**正面**：

```text
① 清空大脑 — 便签倾倒 → 只圈一件 → 手机入抽屉
② 建立仪式 — 泡茶/戴耳机/固定序列（10 分钟内）
③ 干扰结界 — 轻度关通知 | 中度断网 | 重度离场
④ 颅内模拟 — 闭眼 3 分钟：流程 → 第一段 → 体感

计时开始：__:__        进入状态：__:__
```

**背面**：

```text
自查三问：
Q1 我现在只留了一件吗？
Q2 我的仪式做完了吗？
Q3 我彩排过"被打断之后怎么回来"吗？
都不缺 — 开始。
缺哪个 — 先补哪个。
```

**使用方法**：每次深度工作前，正面从上往下走一遍，记下"计时开始"和"进入状态"两个时刻——两者的差是你的**入场用时仪表盘**（Day 27 的数据）。结营后这张卡继续用，目标：入场用时从十五分钟降到三分钟。

## 06.工具页五：小念头记录本

**对应章节**：Day 15（小念头与大兴趣）。

**版式说明**：五十页格式化记录页，每页一条记录，四栏结构。

**字段清单（每条记录四栏）**：

| 栏目 | 填写引导 |
|:---|:---|
| ① 感受 | 我觉得：___（受启发/心动/嫉妒/舒畅……一个词） |
| ② 事件 | 引发感受的事实：___（客观描述，不带评价） |
| ③ 判断 | 因此我认为：___ |
| ④ 行为 | 我想去试试：___（最小的一步） |

**示例**：

```text
① 感受：很受启发，有点兴奋
② 事件：看到一位建筑师用视频讲清了工序排期
③ 判断：讲得清楚的人比做得多的人稀缺
④ 行为：把这周的项目复盘写成一篇讲给外行看的短文
```

**附：信号与噪音对照小表**（印在扉页）：

| 信号（记满一页再看） | 噪音（当页打叉） |
|:---|:---|
| 反复出现的主题 | 短暂兴奋、隔夜即忘 |
| 越做越有能量 | 依赖外部刺激（攀比、热点） |
| 时间越久越坚定 | 事后空虚 |

**使用方法**：只记正向的小念头（嫉妒也算——嫉妒是最诚实的向往）。**每三个月翻一遍全本**，找重复出现的主题——那就是 Day 15 说的"大兴趣的早期数据"。

## 07.工具页六：五种时间周复盘表

**对应章节**：Day 01（记录）、Day 05（分类）、Day 29（动态平衡）。

**版式说明**：A4 一页一周，周日晚十五分钟填写。是七张工具页里**唯一长期使用**的核心表。

**字段清单**：

| 区域 | 填写内容 |
|:---|:---|
| 五问周报 | Q1 本周最投入的一件事：___ |
| | Q2 最想删掉的一段时间：___ |
| | Q3 完成了什么有痕迹的东西：___ |
| | Q4 和最重要的人相处了多久：___ |
| | Q5 下周想为自己保留哪段时间：___ |
| 五种占比 | 生存___% · 赚钱___% · 好看___% · 好玩___% · 心流___% |
| 三盏灯 | 长期疲惫 ☐ · 长期空虚 ☐ · 长期焦虑 ☐（连亮 4 周才勾） |
| 下周只调一项 | 调整：___（具体到时段和动作） |
| 本周一句话 | 给下周的自己：___ |

**使用方法**：固定周日晚上，十五分钟，五步走：**翻账 → 染色 → 体检（三盏灯）→ 定一项 → 一句话**。规矩只有一条，Day 29 的军规——**只调一项**。连续四周后，把四张表放在一起看：Q2 的答案连续四周指向同一件事吗？那就是你生活的第一块病灶，下周该动刀了。
