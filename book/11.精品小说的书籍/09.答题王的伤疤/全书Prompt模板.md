# 《答题王的伤疤》Prompt 模板（统一版·自包含·v2.2 极简触发版）

> **本文件是写作 60 章的唯一 Prompt 入口·单文件自包含**。
>
> ## 🚀 日常只看 §0（一句话写一章）
> - **新对话开局**：把本文件整篇发给 AI + 一句"读入记住，回复'已就位'"。
> - **之后每章**：作者输入 `写18`，AI 自动按全规约出稿（自检表 + 正文 + 字数 + 沉淀）。
> - **不需要再粘贴**：§B 模板、§C 章节卡、§A 宪法、上一章末段——AI 都从本文件自取。
>
> ## 📚 §A–§I 是规约层（AI 内部调用，作者不用直接读）
> - **§A 宪法**：世界观、人物、风格、七不准红线（整书一次预置）。
> - **§B 通用模板**：风格基准 + 颗粒度 + 句长 + 六段骨架 + 自检表 + 修复指令。
> - **§C 章节坐标卡**：§C.1–§C.60 已逐章预填好（数据源·勿改）。
> - **§D 钩子总览 / §E SOP / §F 一致性档案 / §G 符号系统 / §H 维护 / §I 总纲**。

# §0 · 极简触发协议（**日常只用这一节**）

> **作者一句话 → AI 自动按全文规约写章**。下面 5 条命令覆盖 99% 场景，不用拼装、不用复制。

## §0.1 一次性初始化（每个新对话只做一次）

把本文件**整篇**发给 AI，附一句话：

```
这是《答题王的伤疤》的全书写作宪法+模板+60 章数据卡。请整体读入并记住。
之后我用 §0.2 的命令调用，你按命令直接出稿，不要让我再粘贴任何内容。
读完回复"已就位"。
```

> 👉 一次发完，整本书写完前都不用再发模板。换新对话则重发一次。

## §0.2 五条万能命令（日常只输这五种）

| 命令 | 例子 | AI 自动执行 |
|---|---|---|
| **`写 N`** | `写18` | 自动取 §C.N 数据卡 + §B 全规约 + §F 近 3 行档案，先输出自检表 → 再输出正文 → 末尾字数统计 |
| **`续 N`** | `续18` | 同上，但要求 AI 先读用户上一条粘贴的"上一章末段"，与 §C.N 的 D 段比对，再写 |
| **`修 N 段X-Y 症状`** | `修18 段12-15 短句堆砌` | 按 §B.9 修复指令对应表，只重写指定段 |
| **`查 N`** | `查18` | AI 输出本章自检表（不写正文），用于事后核验现稿 |
| **`沉淀 N`** | `沉淀18` | AI 按 §F.1 单行模板输出本章档案行，作者复制到《一致性档案.md》 |

## §0.3 命令执行规约（AI 必须遵守）

**AI 收到 `写 N` 时的内部流程**（用户不需要管）：

```
1. 在本文件中定位 §C.N 章节坐标卡，提取 A/B/C/D/G 五段。
2. 调用 §B.1–§B.9 全部规约（风格基准/五禁令/颗粒度/句长/六段骨架/七律/输出格式/自检表）。
3. 调用 §A 宪法（七不准/双面/反派合理化/留白原则）。
4. 检查 §D 钩子总览第 N 行的"末尾钩子"，确保本章末段与之一致。
5. 检查 §G 统一符号系统，确保本章≥1 个符号被调用。
6. 若用户已发过《一致性档案.md》近 3 行，自动作为前情提要；若未发，主动询问"是否需要前情？(y/n)"。
7. 输出顺序：① §B.8 自检表（全 ✅ 才继续）→ ② §B.7 格式正文 → ③ 字数统计 → ④ §F.1 沉淀建议行（供作者复制）。
8. 自检表任意 ❌：原地重写直到全 ✅，绝不交付带 ❌ 稿件。
```

**AI 收到 `修 N 段X-Y 症状` 时**：

```
1. 在 §B.9 即时修复指令表中匹配"症状"列。
2. 仅重写指定段，前后段不动。
3. 修完后单独跑该段的颗粒度+句长自检（§B.3 §B.4），通过才交付。
```

**AI 收到 `沉淀 N` 时**：

```
按 §F.1 单行模板输出（5 个字段全填），作者复制粘贴即可。
```

```
作者：沉淀18      ← 写完了想存档时（多数时候 AI 已附带，可省）
AI  ：【第 18 章 沉淀】……
```

> 漂移时降级到 §0.2 的 `修 N 段X-Y` 命令做局部补丁，不重写整章。

# 第一层 · §A 宪法预置（整本书只发一次）

> 第 1 次和 AI 协作时，**先单独发本节**给 AI，并保存为系统提示 / 项目知识 / 自定义指令；之后每章 Prompt 不再重复。换对话窗口需重发一次。

```text
你将协助我创作长篇小说《答题王的伤疤》。以下世界观与人物设定为本书宪法，**不可更改、不可扩展、不可新增**。

【时代】2024 年中国，直播答题爆火，留守儿童与打拐议题凸显。
【场景】深圳白石洲城中村 / 《全民答题王》直播演播厅 / 贵州黔东南山区。
【主线】22 岁深圳外卖员陈念安身上 12 道伤疤对应 12 道答题题目，闯入总决赛，目标是寻找失散十年的妹妹陈念希。
【三条副线】① 寻亲线（妹妹陈念希）  ② 黑幕线（赵天成/平台）  ③ 感情线（林小满）
【五位主要人物】
  · 陈念安（男主，22岁，外卖员，沉默坚韧、自卑愧疚，身上 12 道伤疤）
  · 陈念希（妹妹，17岁，平台不露脸的声音主播"小希"，被赵天成隐瞒身份）
  · 林小满（女主，22岁，深圳护士，青梅竹马，温柔但隐有"怕被妹妹挤走"的私心）

【主导意象池】雨 / 烟 / 尘 / 灯 / 霜 / 刀 / 镜 / 孤舟（每章选 1 个为主，全章不可换）
【五卷大钩子】
  卷一：被软禁 + 苏晴敲门
  卷二：伤疤揭尽 + 妹妹声线浮现

1. 不准出现大纲未授权的新人物 / 新地点 / 新转折。
2. 不准改变本章对应的"那一题 / 那一道伤疤 / 那一段流浪史"。
3. 不准让陈念安变成"爽文式逆袭"，必须保留自卑愧疚底色。
4. 不准让赵天成"为坏而坏"，每个恶都要有人性来路。
5. 不准提前揭穿——重大节点（赵天成知情、兄妹相认、警方收网）必须严格按分卷表章号触发，不得跨章泄露。
6. 不准与已写章节矛盾（伤疤数量、人物记忆、物件归属、时间线）。
7. 不准字数超出 4500–5500 区间。
```

# 第二层 · §B 通用单章模板（每章发一次）

> 写每一章时，把下面 §B.1 ~ §B.6 整段贴入 Prompt，再附第三层（§C）的章节数据卡。

## §B.1 风格基准（必须模仿这种语感）

**这是本书的标准风格示例（来自第 12 章），请把它当作"必须像这样写"的样板：**

> 当晚，他刚回到酒店房间，电梯里那名男人就跟到了门口。
>
> 陈念安听到脚步声时，正在掏房卡。他回头，看到那个男人站在走廊尽头，靠着墙，双手插在口袋里，像在等人，又像在监视。男人没看他，只是盯着天花板上的烟雾报警器，眼神空洞，像一尊雕塑。
>
> 陈念安没说话，刷开房门，走进去。
> 他正要关门，男人忽然动了，快步走过来，一只脚抵住门缝，声音很低，像砂纸磨过铁皮："赵总想跟你聊聊。"

**这段话的特征（你必须复制这些特征，而不是字面抄袭）**：
1. **先动作再画面再心理**：开篇一句交代时间地点动作，第二段铺画面，第三段才进对白。
2. **长短句交替**：一段里既有"他回头，看到那个男人站在走廊尽头，靠着墙，双手插在口袋里"这种 25-40 字的连环动作长句，又有"陈念安没说话，刷开房门，走进去"这种 12-15 字短句。
3. **每段有具体物件**：房卡、烟雾报警器、走廊、门缝、皮鞋——情绪挂在物件上，不空抒情。
4. **比喻克制**：每段最多 1 个比喻（"像一尊雕塑""像砂纸磨过铁皮"），且都是单比喻，不三连排比。
5. **对白短而冷**：单句对白 5-15 字，前后必有动作衬。

## §B.2 五条硬性禁令（违反一条即重写）

**禁令 1：禁止"X 得像 Y，像 Z，像 W"三连排比超过 3 次/章。** 全章三连排比 ≤ 3 次，且必须分散在不同段落，不得连续段落出现。
> ❌ 反例："冷得像冰，像刀，像针。""快得像风，像电，像箭。"
> ✅ 正例（保留）："纸很凉，很硬，像冰，像刀。"（双比喻）

**禁令 2：禁止连续 5 段以上不出现对白或具体动作。** 每 5 段内至少 1 句对白或 1 个动作镜头。

**禁令 3：禁止排比段落堆砌。** 不得连续出现 3 段及以上结构相同的句子。

**禁令 4：禁止抒情独白超过 80 字不落地。** 心理描写超过 80 字时，必须有 1 个具体物件或动作把它"接回现实"。

**禁令 5：禁止形容词链。** 不得出现 4 个及以上形容词连用修饰一个名词。

## §B.3 段落颗粒度（机械执行）

| 项目 | 硬指标 |
| --- | --- |
| 全章段落总数 | 50–80 段 |
| 单段字数（中位数） | 60–120 字 |
| 单段字数（绝对上限） | ≤ 280 字 |
| 单段字数（绝对下限） | ≥ 15 字（短独立句段除外，且全章不超过 12 段这种短段） |
| 全章对白段（含引号的段） | ≥ 8 段，≤ 25 段 |
| 全章动作镜头段（推门/抬手/掏出/转身等具体动词主导） | ≥ 12 段 |
| 全章字数 | **中文字符数（不含标点空白）4500–5500** |

## §B.4 句长比例（机械执行）

将全章按"句号 / 问号 / 感叹号 / 引号闭合"切句，统计：

| 句长档 | 占比 |
| --- | --- |
| 长句（≥ 25 字） | 35%–55% |
| 中句（12–24 字） | 30%–45% |
| 短句（≤ 11 字） | 15%–25% |

> "像 X，像 Y"中的逗号不切句。

## §B.5 六段骨架（必须按此顺序）

| 段位 | 名称 | 字数占比 | 任务 |
| --- | --- | --- | --- |
| ① | **场景开篇** | 8%–15% | 用天气/声音/气味/动作 1 个具象元素切入，画面先于人物。 |
| ② | **冲突切入** | 12%–20% | 抛出本章卡点，必须**新于上一章**；带 1–2 句对白。 |
| ③ | **伏笔铺陈** | 10%–25% | 在冲突最紧处插入闪回，必须落到 1 个**统一符号**。 |
| ④ | **心理深描** | 15%–30% | 全章血肉，借物喻心；每 80 字落到一个物件。 |
| ⑤ | **转折抉择** | 15%–20% | 人物做出 1 个**清晰的动作变化**，至少 1 处对白。 |
| ⑥ | **悬念收尾** | 8%–15% | 留 1 个钩子，**与下一章首段呼应**；画面+未解问题，绝不解释总结。 |

> **校验口诀**：开篇有画面，冲突有卡点，回忆有信物，心理有动作，转折有抉择，结尾有钩子。

## §B.6 写作风格七律 + 三层细节

### 风格七律

1. **古龙风句法骨架**：长短交替，关键时刻用一个短句作"刀刃"。但避免太多短语和短句。
2. **古典意象现代化嫁接**：月、霜、剑、灯、孤舟、长夜入现代场景。
3. **避免散碎短语**：禁用"……，……，……"逗号堆砌；每个长句要有完整语义结构。
4. **意象统一**：每章选 1 个主导意象，全章不换；主导意象出现 ≥ 5 次。
5. **古诗词点睛**：每章 ≤ 2 句，用以转场或提点心境。
6. **不写情绪写动作**：禁用"难过/愤怒/绝望/无助/痛苦"等直白词。
7. **借物喻心**：每章必须有 1 件**承载情绪的核心道具**。

### 三层细节（关键段 ≥ 200 字必须三层齐备）

1. **环境层**：天气、光线、声音、气味。
2. **道具层**：与命运相关的物件。
3. **身体层**：身体反应（颤抖、屏息、攥拳、伤疤的隐痛）。

### 比喻库（推荐句式·单段最多 1 个，全章 ≤ 18 个）

像一尊雕塑 / 像砂纸磨过铁皮 / 像沙漠里的石头 / 像在哄孩子 / 像一只守在巢边的鸟 / 像刀，像冰 / 像一块砖 / 像五块墓碑 / 像一根针 / 像一片落叶。

### 对白规则

- 单句对白 ≤ 18 字（口语化、截断式、留白）。
- 对白前后 80% 概率附 1 个动作衬。
- 角色一段对白超过 3 句话必须拆段。
- 反派对白：温和、克制、不咆哮（参考赵天成"小陈啊，住得还习惯吗？"）。

### 反样例红线（真实失败模式·必须规避）

- ❌ "他低着头，弯着腰，弓着背，缩着肩，像一只受伤的兽。"——形容词链。
- ❌ "雨打在窗上，打在地上，打在伞上，打在心上。"——四连排比。
- ❌ "他想起妹妹。他想起母亲。他想起父亲。他想起老槐树。"——结构排比段。
- ❌ 连续 6 段全部是 8–12 字的短句独立成段。
- ❌ 整段心理独白 200 字不带任何物件 / 动作。

## §B.8 自检表（交付前必须全 ✅）

```
【硬指标自检】
□ 字数 4500-5500：N=____
□ 段落数 50-80：N=____
□ 单段最长 ≤280 字：最长段=____ 字
□ 单段最短 ≥15 字（短段≤12 段）：最短段=____ 字，短段总数=____
□ 对白段 ≥8 ≤25：N=____
□ 动作镜头段 ≥12：N=____

【风格自检】
□ 三连排比 ≤3 处：N=____（列出具体句子）
```

# §E · AI 协作写章流程（标准化 SOP）

## §E.1 三大反模式（千万别这么写 Prompt）

| 反模式 | 后果 |
|---|---|
| ❌ "继续帮我写第 12 章" | AI 凭上下文猜，越写越飘，伤疤/题目错位。 |
| ❌ 只甩章节标题 | 风格崩塌、符号不闭环、与上一章不咬合。 |
| ❌ 把整本设计文档+大纲+上一章正文整堆丢进去 | 信息过载，AI 抓不住当前重点。 |

## §E.2 章节数据机械取数（从《全书框架和分卷.md》）

| 分卷表中字段 | 复制到本模板哪里 | 用途 |
|---|---|---|
| 「卷数 / 卷名」 | §C 模板「卷次/卷名」 | 章节坐标 |
| 「章节」+「标题」 | §C 模板「章号/标题」 | 章节坐标 |
| 「核心情节」 | §C 模板「本章必须发生」（拆 3 件事） | 钉死剧情 |
| 「心理刻画」 | §C 模板「主导意象 + 心理底色」 | 内化情绪 |
| 「细节补充」 | §C 模板「核心道具 + 三层素材」 | 环境/道具/身体 |
| 上一行的「核心情节」末句 | §C 模板「上一章结尾钩子」 | 首尾咬合 |
| 下一行的「核心情节」首句 | §C 模板「下一章预计接住点」 | 留对的钩子 |

> **机械三步**：①打开《全书框架和分卷.md》定位本章那一行 ②按上表把 5 栏数据复制到 §C 模板 ③补上钩子上下承接。**不允许凭记忆改写、扩写、删减分卷表内容**——分卷表就是宪法。

## §E.3 每章 4 步走（不超过 15 分钟，不含 AI 出稿时间）

```
第 1 步：取数（2 分钟）
  打开《全书框架和分卷.md》→ 找到本章那一行 →
  按 §E.2 取数映射表，把 5 栏复制到 §C 模板的 A/B/C 段。

第 2 步：补承接（3 分钟）
  在 C 段填上一章末段钩子原文 + 本章开篇如何接住；
  在 D 段粘上一章最后 1–2 段；
  在《一致性档案.md》最近 3 行追加到 §A 后（第 1 章可跳过）。

第 3 步：发 Prompt（1 分钟）
  按下面顺序拼接整段发给 AI（首次需先发 §A 宪法）：
  §B 通用层全文 + §C.N 章节数据卡 + §F 一致性档案近 3 行
  等待出稿。

第 4 步：核验+沉淀（5 分钟）
  对照 §B.8 自检表逐项打勾，不合格则用 §B.9 即时修复指令打补丁；
  合格则在《一致性档案.md》追加新一行（按 §F 模板）。
```

# §F · 一致性档案（防长程漂移）

> 每写完 1 章，在项目根目录《一致性档案.md》追加 1 行（每行 ≤ 5 句话）；下一章 Prompt 在 §A 后追加最近 3 行作为"前情提要"。AI 不需要回看前 N 章正文，只读这 5 行就能避开 90% 的前后矛盾。

## §F.1 单行模板

```text
【第 N 章 沉淀】
- 新增物件/伤疤/记忆：____
- 人物状态快照：陈念安(____) 林小满(____) 苏晴(____) 赵天成(____) 陈念希(____)

- 遗留未解钩子：____
- 与分卷表第 N 行核心情节是否完全对位：是 / 否（若否说明）
```
