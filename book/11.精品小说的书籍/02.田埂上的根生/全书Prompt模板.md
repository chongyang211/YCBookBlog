# 《田埂根生》Prompt 模板（统一版·自包含·v1.0）

> **本文件是写作 100 章的唯一 Prompt 入口·单文件自包含**。
>
> ## 🚀 日常只用 §0（一句话写一章）
> - **新对话开局**：把本文件整篇发给 AI + 一句"读入记住，回复'已就位'"。
> - **之后每章**：作者输入 `写18`，AI 自动按全规约出稿（自检表 + 正文 + 字数 + 沉淀）。
> - **不需要再粘贴**：§B 模板、§C 章节卡——AI 都从本文件自取。
>
> ## 📚 §A–§F 是规约层（AI 内部调用，作者不用直接读）
> - **§A 宪法**：世界观、人物、风格铁律、五不准红线。
> - **§B 通用模板**：风格基准 + 颗粒度 + 句长 + 六段骨架 + 自检表 + 修复指令。
> - **§C 章节数据卡**：§C.0 数据填空模板 + 从《全书框架和分卷.md》取数映射表。
> - **§D 钩子总览 / §E 一致性档案 / §F 符号系统与维护**。

# §0 · 极简触发协议（**日常只用这一节**）

> **作者一句话 → AI 自动按全文规约写章**。下面 5 条命令覆盖 99% 场景。

## §0.1 一次性初始化（每个新对话只做一次）

把本文件**整篇**发给 AI，附一句话：

```
这是《田埂根生》的全书写作宪法+模板+100 章数据源。
请整体读入并记住。之后我用 §0.2 的命令调用，你按命令直接出稿，不要让我再粘贴任何内容。
读完回复"已就位"。
```

> 👉 一次发完，整本书写完前都不用再发模板。换新对话则重发一次。

## §0.2 五条万能命令（日常只输这五种）

| 命令 | 例子 | AI 自动执行 |
|---|---|---|
| **`写 N`** | `写18` | 从《全书框架和分卷.md》取第 N 章数据卡 + §B 全规约，先输出自检表 → 再输出正文 → 末尾字数统计 |
| **`续 N`** | `续18` | 同上，但要求 AI 先读用户上一条粘贴的"上一章末段"，比对后写 |
| **`修 N 段X-Y 症状`** | `修18 段12-15 细节堆砌` | 按 §B.8 修复指令对应表，只重写指定段 |
| **`查 N`** | `查18` | AI 输出本章自检表（不写正文），用于事后核验 |
| **`沉淀 N`** | `沉淀18` | AI 按 §E.1 单行模板输出本章档案行，作者复制到《一致性档案.md》 |

## §0.3 命令执行规约（AI 必须遵守）

**AI 收到 `写 N` 时的内部流程**：

```
1. 从《全书框架和分卷.md》中定位第 N 章数据行，提取：7 字标题、核心情节、心理刻画、细节补充。
2. 将核心情节拆解为"本章必须发生的 3 件事"，作为 B 段三件事。
3. 从心理刻画+细节补充中提炼：主导意象、心理底色、统一符号调用、核心道具、三层素材。
4. 调用 §B 所有规约：风格基准/六段骨架/六条禁令/颗粒度/句长/输出格式/自检表。
5. 调用 §A 宪法：五不准红线、老舍式叙事风格、全员特点。
6. 检查 §D 钩子总览，确保本章末段钩子与第 N 行一致。
7. 检查 §F 统一符号系统，确保本章 ≥1 个符号被调用。
8. 输出顺序：① 自检表（全 ✅ 才继续）→ ② 正文（按 §B.6 格式）→ ③ 字数统计 → ④ 沉淀建议行。
9. 自检表任意 ❌：原地重写直到全 ✅，绝不交付带 ❌ 稿件。
```

**AI 收到 `修 N 段X-Y 症状` 时**：

```
1. 在 §B.8 即时修复指令表中匹配"症状"列。
2. 仅重写指定段，前后段不动。
3. 修完后单独跑该段的颗粒度+句长自检，通过才交付。
```

## §0.4 日常工作流（一章 = 3 行字）

```
作者：写18
AI  ：（自检表 ✅ + 正文 + 字数 + 沉淀建议）
作者：沉淀18      ← 写完了想存档时
AI  ：【第 18 章 沉淀】……
```

# §A · 宪法预置（整本书只发一次）

> **以下设定为本书宪法，不可更改、不可扩展、不可新增。**

```text
你将协助我创作长篇小说《田埂根生》。以下设定为本书宪法，严格遵守：

【时代】1965 年 - 2026 年，完整覆盖大集体时代末期、改革开放、90 年代农民工潮、21 世纪城镇化加速、乡村振兴等中国当代史关键节点。
【场景】豫东周口陈家村的黄土地、土坯房、麦场；郑州/武汉的建筑工地、工棚；县城重点高中、武汉大学校园；城市商品房小区、社区居委会。
【主线】以 60 后农民陈根生的一生为缩影，写透中国亿万农民的生存状态、吃苦与牺牲。保留人性真实复杂度，最终落脚于平凡中的伟大。

【核心叙事风格·老舍式平实叙事】
- 语言：口语化、接地气、不煽情、不炫技。用最朴素的话说最深的事。
- 叙事距离：第三人称有限视角，以陈根生的眼睛和感受为中心，不跳入全知上帝视角评说。
- 情绪表达：不写"难过/愤怒/绝望/痛苦"等直白情绪词——情绪藏在动作、物件和沉默里。
- 细节为王：每一段的画面里必须有一个具体的、可触摸的物件（锄头、煤油灯、汇款单、红薯面窝头、打补丁的衣服……），不悬空抒情。
- 时代质感：精准还原不同年代的农村风貌——60 年代工分本、70 年代生产队喇叭、80 年代粮站窗口、90 年代公用电话亭、2000 年代诺基亚手机、2020 年健康码。

【四位主要人物】
· 陈根生（主人公，1965 年生）：豫东农民/农民工。木讷寡言、勤恳本分、能吃万般苦、认死理、嘴笨心善，骨子里有股不服输的韧劲，一辈子为家人而活。身上有常年劳作的手茧和伤疤。
· 李秀莲（根生妻子，1966 年生）：性格泼辣却心善，能持家、肯吃苦，刀子嘴豆腐心，一辈子跟着根生风里来雨里去。
· 陈凯（大儿子，1988 年生）：聪明刻苦、自尊心强，青春期自卑叛逆，大学后逐渐懂事感恩。代际冲突的核心载体。
· 陈娟（小女儿，1990 年生）：懂事孝顺、隐忍牺牲，温柔善良。为供哥哥读书主动辍学打工，农村女孩为家庭牺牲的典型。

【七位次要人物】
· 陈守义（根生父亲）：积劳成疾老农民，一辈子守着土地，临终托付根生撑起家。
· 根生母亲：典型的农村母亲，一辈子围着灶台和儿女转。
· 老木匠（根生师傅）：村里老木匠，教根生手艺，赠他一套木匠工具。
· 老所长（孤山岭司法所所长，仅出现于孤鹰模板，本书无此人物，勿新增）
· 赵刚（战友，仅出现于孤鹰模板，本书无此人物，勿新增）
· 林晓雅（陈凯女友/妻子）：武汉城里姑娘，家境优越，温柔懂事。
· 村支书/邻里乡亲：群像，代表农村淳朴的邻里关系。

【八大统一符号】
1. 8 亩责任田：根生一辈子的命根子，分田到户的喜悦、每一寸土质的记忆。
2. 木匠工具（刨子/凿子/墨斗）：手艺安身立命的底气，贯穿一生的技能。
3. 全家福照片：工棚里揣在怀里的思念，汇款单旁压着的家。
4. 汇款单/欠条：一辈子的经济痕迹——往外寄的钱、往里借的债。
5. 红薯面窝头：饥荒年代的食物记忆，刻进骨头的饥饿感。
6. 永久牌自行车：80 年代农村的"大件"，根生咬咬牙买的第一个值钱物件。
7. 老槐树：陈家村口的老槐树，离乡时回头望、归乡时第一眼看见的坐标。
8. 金黄的麦田：全书的核心意象，麦浪起落就是根生一辈子的节奏。

【五卷锚点】（对应 5 卷×20 章=100 章）
第一卷（1-20）：1965-1984，出生→学手艺→分田到户→成家，立住"黄土少年"底色。
第二卷（21-40）：1985-1999，儿女出生→进城打工→欠薪讨薪→女儿辍学，父子冲突埋线。
第三卷（41-60）：2000-2012，供儿上大学→父子冲突爆发→儿初入职场醒悟，父子第一次松动。
第四卷（61-80）：2013-2020，买房背债→老伴患病→婆媳矛盾→疫情志愿者→父子彻底和解。
第五卷（81-100）：2021-2026，归乡还债→乡村振兴→家风传承→麦浪中完成一生的回望。

【五不准·内容红线（任一触发立即重写，不接受辩解）】
1. 不准出现大纲未授权的新人物/新地点/新转折。
2. 不准改变本章在分卷表中对应的"核心情节"，不得跨章跳跃年代。
3. 不准把陈根生写成"完美圣人"——他必须有卑微、有无奈、有隐忍，甚至有软弱和想放弃的时刻。
4. 不准让陈凯在青春期之前就对父亲表现出嫌弃——攀比心的萌芽必须严格按分卷表节奏，第 31 章才第一次出现。
5. 不准让煽情超过一个度——全书泪点最多的地方（欠薪归家、卖血凑学费、父女争执、父子最终和解）必须用"克制"的方式写：不写嚎啕大哭，写眼眶红了但把泪憋回去，写动作的停顿，写沉默。

【情感表达铁律·不说只做】
- 爱不说"我爱你"——说"多吃点"，说"钱不够了跟爹说"，说汇款单上那句"别委屈自己"。
- 愧疚不说"对不起"——做木匠活到深夜给家人攒钱，把新文具轻轻放在孩子枕边，蹲在田埂上抽一夜旱烟。
- 思念不说"想你了"——工棚里拿出全家福看了半夜，电话亭前排队等一小时只为了听孩子叫一声"爸"。
- 心疼不说"我心疼你"——看着秀莲在地里风吹日晒，一声不吭把重活全部抢过来干了。

【全员性格锚点·每章至少体现 1 个】
| 角色 | 性格关键词 | 标志性动作/语言 |
| --- | --- | --- |
```

# §B · 通用单章模板

## §B.1 风格基准（必须模仿这种语感）

**这是本书的标准风格——源自第一章已落定的正文，请把它当作"必须像这样写"的样板：**

**开篇·诗词起笔**：
> 天寒地冻腊月天，北风卷地百草折。
> ——豫东民谚

**正文·示例段落**：
> 一九六五年的腊月，豫东平原上的风像是从冰窖里刮出来的。陈家村坐落在周口地界最不起眼的一角，几十户人家散落在黄土岗子上，土坯房一间接一间，远远望去，像是从这片黄土地里长出来的——连同那些低矮的门楣、糊着旧报纸的窗格、门口一垛垛快要烧光的麦秸，都是一副认命的模样。
>
> 可这一夜，这间认命的土坯房里，却烧着一盏不肯认命的灯。
>
> 煤油灯的光是昏黄的，会颤的。灯芯结了一个豆大的灯花，吐着细微的噼啪声，把陈守义那张被烟熏得发黑的脸，映得忽明忽暗。他在屋里蹲了多久，自己也说不清。只记得灶膛里的麦秸灭了三次，又被他点了三次。
>
> 他不识字。可他认得一种感觉——喉咙发紧、手心出汗、气吸进去了半天才记得呼出来。

**结尾·悬念收束**：
> 而无人知道——也无人会知道——就在这一夜远天的尽头，那阵被陈守义听见、又被他甩开的隐隐响动，是一个时代正在缓慢而沉重地揭开它的第一道褶。
>
> 这道褶，将在往后的岁月里一圈一圈地扩大，把这片黄土地上的每一户人家，连同陈家村东头这间土坯房里刚刚降生的这个叫陈根生的婴儿，全部卷进它无声的洪流中去。
>
> 襁褓里的孩子翻了个身，小嘴咂了一下，发出一声细细的哼鸣。煤油灯的火苗跳了跳，像在对什么点头，又像在对什么摇头。

**这段话的特征（你必须复制这些特征）**：
1. **诗词开篇**：每章开头用一句古诗词、民谚或民歌引入意境，诗词必须与本章主题呼应，2-4 句为限，独立成段。
2. **先意境再人物**：开篇用天气/季节/大地/村庄等大面积意象铺开氛围，人物在画面中自然走入，不急推人。
3. **细节锚定年代**：煤油灯、红薯面糊、粗瓷碗、工分本、旱烟袋、布包袱、扫盲班识字本——每一件都是 60 年代豫东农村的活证据。
4. **动作承载情感**：不写"激动"，写"手在抖"；不写"不舍"，写"蹲着看了很久"；不写"敬畏"，写"磕了三个头"。
5. **长短句交响**：短句如刀刃（"软的。暖的。"），长句如平原长风（"他在心里把这几个字过了好几遍，最后从嘴里吐出来的，只有两个字。"），两者交替滚动，不靠频繁分段制造伪节奏。
6. **对白极少而极重**：每段对白 3-15 字，全章对白不超过人物必须开口的时刻，其余一律用动作和物件替代。
7. **克制收尾**：最深处的情感用物件沉默或者用隐喻收住（"煤油灯的火苗跳了跳，像在对什么点头，又像在对什么摇头。"），不解释，不说破。
8. **悬念结尾**：末段必须留一个"未解题"——可以是对未来的暗示、对时代洪流的凝视、对人物命运的预言，画面+留白，绝不总结，绝不闭合。

## §B.2 六条硬性禁令（违反一条即重写）

**禁令 1：禁止直白抒情词。**
不得使用：难过、愤怒、绝望、无助、痛苦、屈辱、感动、心疼、舍不得——情绪必须通过动作、物件和沉默传达。
> ❌ "他心里满是难过"
> ✅ "他把汇款单折了又折，折成一个硬硬的小方块，塞进贴身口袋里。"

**禁令 2：禁止连续 3 段以上不出现具体物件。**
每 3 段内至少出现 1 个可触摸的物件（锄头/碗/汇款单/自行车把手/补丁/煤油灯/方便面袋……）。
> ❌ 连续 3 段纯心理描写或纯叙述
> ✅ 每 3 段内必有 1 个具体物件落地

**禁令 3：禁止排比式抒情。**
不得出现"他想起……他想起……他想起……"三连排比；不得出现"多苦啊，多累啊，多难啊"感叹堆砌。
> ❌ "他想起了父亲的白发，想起了母亲的病，想起了妹妹的牺牲"（三连排比）
> ✅ "父亲的白发出现在梦里的时候，他在工棚的硬板床上翻了第二十四个身。"

**禁令 4：禁止心理独白超过 80 字不落地。**
心理描写超过 80 字时必须有一个具体物件或动作把它接回现实。
> ❌ 整段 200 字"他在想……他觉得……他回忆……"
> ✅ 想了一百多字后，接一句"他把烟头按灭在搪瓷缸里，缸底没水，烟头嗞了一声。"

**禁令 5：禁止形容词链。**
不得出现 4 个及以上形容词连用修饰一个名词。
> ❌ "那是多么孤单、漫长、黑暗、寒冷的夜晚啊"
> ✅ "夜很长。工地的灯早就灭了，只有北风从活动板房的缝往里钻。"

**禁令 6：禁止陈凯在青春期之前就表现出叛逆。**
陈凯的攀比心和嫌弃父亲的言行，必须严格从第 31 章开始萌芽，第 42-44 章集中爆发。之前的章节中，陈凯只是一个正常的、有点内向的农村孩子。

## §B.3 段落颗粒度（字数优先·段落克制）

| 项目 | 硬指标 |
| --- | --- |
| **全章字数（最高优先级）** | **中文字符数（不含标点空白）3800–4200，超 ±100 字即不合格，低于 3800 必须补写** |
| 全章段落总数 | 28–36 段（绝对上限 38 段，超过即不合格） |
| 单段字数（中位数） | 110–160 字 |
| 单段字数（推荐区间） | 80–200 字 |
| 单段字数（绝对上限） | ≤ 260 字 |
| 单段字数（绝对下限·常规段） | ≥ 50 字 |
| 短段（< 50 字）总数 | ≤ 3 段/全章（仅用于生死攸关的极简一击） |
| 全章对白段 | ≥ 5 段，≤ 10 段 |
| 全章动作镜头段 | ≥ 8 段 |

> **段落克制原则**：老舍式叙事的美感来自"段落内部的节奏"，不是来自频繁分段。每个段落必须自成一个完整的画面单元（环境+物件+动作至少占其二），写完一个画面再换段。相邻同场景/同人物的叙述绝不切成碎片——短段只用于文学意义上的"重锤一击"，其余一律用中长段交响。

## §B.4 句长比例

| 句长档 | 占比 |
| --- | --- |
| 长句（≥ 20 字） | 40%–55% |
| 中句（10–19 字） | 35%–50% |
| 短句（≤ 9 字） | 5%–15%（仅在"刀刃时刻"使用） |

> 短句不超过连续 2 个，两个短句后必须接 1 个中长句拉回节奏。

## §B.5 标准六段骨架（每章通用）

| 段位 | 名称 | 字数占比 | 目标字数 | 段数 | 任务 |
| --- | --- | --- | --- | --- | --- |
| ① | **诗化开篇** | 10%–14% | 400–560 | 3–6 段 | **诗词/民谚起笔**：1-2 句古诗词、民谚或民歌独立成段引入意境 → 用天气/季节/大地/村庄等大面积意象铺开 → 人物在画面中自然走入。诗词必须与本章主题呼应。 |
| ② | **情节推进** | 18%–22% | 720–880 | 6–8 段 | 推进本章核心情节（三件事之第 1、2 件），带 1–2 句对白。每段必须有具体物件落地。 |
| ③ | **细节铺陈** | 16%–20% | 640–800 | 5–7 段 | 用意食物件（粗瓷碗、汇款单、补丁衣裳、煤油灯……）和身体微动作，把情感铺到地面，不悬空抒情。呼应前文或本卷统一符号。 |
| ④ | **情感重场** | 22%–26% | 880–1040 | 7–9 段 | 全章血肉——本章最重要的一段情感画面。不是概括叙述，是一个具体的、可看见的场景（喂奶/起名/磕头/缝衣裳/送饭……），物件+动作+沉默为主，对白点缀。 |
| ⑤ | **转折收束** | 14%–18% | 560–720 | 5–7 段 | 完成核心情节第 3 件事，人物做出一个清晰的动作变化（起身/关门/写字/远望……），为结尾悬念做铺垫。 |
| ⑥ | **悬念收尾** | 10%–14% | 400–560 | 3–5 段 | **末段必须留钩子**：画面+未解问题。可以是时代洪流的暗示、人物命运的预言、一处未闭合的情感、一个意味深长的物件特写。**绝不解释总结，绝不圆满收束**——让读者心里留一个"然后呢？"。 |
| **合计** | — | 100% | 3800–4200 | 29–42 段 | 总盘必须 ≤ 4200，且 ≥ 3800 |

> **校验口诀**：开篇有诗意，推进有物件，细节有烟火，情感有克制，转折有动作，收尾有悬念。
