# 第七卷·第一章 成吉思汗统一蒙古·草原帝国的崛起靠制度与团结

## 一、开篇锚点：那个从八个人做到八百人却散了的创业团队

我有个朋友姓林，2018 年和七个清华校友一起出来创业做企业级 SaaS。最开始的八个人都是顶尖学校出身、都做过大厂技术骨干、彼此关系也好——他们从公司一起步就是"朋友 + 合伙人 + 同事"三重关系叠加。前两年发展飞快，2020 年拿到 B 轮的时候团队已经扩到八十人估值五亿。但接下来的两年，林总告诉我他们经历了创业以来最痛苦的"组织痉挛期"。第一次痉挛是公司从八十人扩到三百人——原本"八个朋友拍脑袋决策"的模式直接崩了，新来的中层来自字节、阿里、华为每家都有自己的一套打法，你说你的他说他的，公司的会议从"对齐共识"变成"派系吵架"。第二次痉挛是公司从三百人扩到八百人——这次崩的是利益分配：最早的八个合伙人之间没有股权细则全靠"兄弟情义"，但当公司估值二十亿、当一些合伙人开始有自己的小山头时——"兄弟情义"完全顶不住，两个合伙人在一年内先后离开分别带走了一支三十人的核心团队。最后一次痉挛是 2022 年裁员潮公司缩到三百人。林总私下跟我说："其实我们公司不是死于市场也不是死于产品——死于我们一直没建立起'制度'。八个人的时候我们靠默契，八十人的时候我们靠习惯，但到八百人光靠默契和习惯是不够的得靠制度，可那时候已经晚了。"我问他如果重来一次会在什么时候建制度，他想了很久说："在我们只有八个人的时候，在'还不需要制度'的时候建——等到'需要'的时候再建已经晚了，因为那时候每个人的利益已经板结了谁都不肯让步。"

这个故事和八百年前的草原惊人地像。铁木真接手父亲的部落时手下只剩几十个人比林总八个人还少，他面对的草原比林总面对的中国 SaaS 市场还乱——大大小小几百个部落互相攻伐互相劫掠互不臣服每一个部落都是一个独立的小王国，这种环境里想做一个统一的"草原帝国"难度远远大于今天的创业公司从八个人做到八百人。但铁木真做成了，他的成功秘诀恰好就是林总最后悔没做的那件事——在最早期还没人觉得需要的时候就建立制度。这一章我们就来拆铁木真的"草原创业史"到底用了哪三套制度、为什么这三套制度能把一盘散沙做成铁律之师、以及在你今天的小团队里怎么提前埋下"组织能撑到八百人"的制度种子。

## 二、史实还原：从被抛弃的少年到"成吉思汗"

铁木真姓孛儿只斤乞颜部人，生于宋绍兴三十二年（1162，一说 1167），卒于元太祖二十二年（1227）享年六十六岁。他出身并不显赫但也不是底层——父亲也速该是乞颜部的"把阿秃儿"（勇士）在草原上小有名气。铁木真九岁那年父亲带他去他岳父家"指婚"把他订给了同部的小女孩孛儿帖，回程路上也速该被塔塔儿部毒酒害死——一夜之间铁木真从"贵族少年"变成"孤儿寡母"。更残酷的是也速该一死原本依附于他的乞颜部牧民们立刻"用脚投票"集体抛弃了铁木真一家跟了别的部落首领，铁木真的母亲诃额仑带着五个孩子靠捡草根、捕鱼、挖野菜活下来。少年铁木真的童年里有几件刻骨的事：十几岁时被泰赤乌部抓走戴上木枷做奴隶靠装病装死才逃了出来；他唯一的八匹马被偷他追了三天三夜遇到一个素不相识的小伙子博尔术，博尔术二话不说丢下自家的活骑马陪他一起追——这就是后来"四杰"之一博尔术的由来；他和母亲、弟弟们靠捕鱼为生还因为分鱼问题亲手射死了同父异母的弟弟别克帖儿。这些苦难给铁木真留下了三个深入骨髓的认知：第一部落联盟是靠不住的因为利益一散人就跑；第二光靠血缘是靠不住的亲弟弟也可以反目；第三能依靠的只有"忠诚"但忠诚不能凭空产生必须用利益、规则、共同记忆共同打造——这三条是后来成吉思汗整套制度设计的底层逻辑。

二十岁前后铁木真做了两件事开始重新崛起。第一件是找回了被订下娃娃亲的孛儿帖正式娶为妻——这个动作让他重新获得了岳父家弘吉剌部的支持。第二件是主动去找父亲的"安达"（结义兄弟）王罕认王罕为义父，王罕是当时草原上最有势力的克烈部首领——铁木真这个动作相当于"傍大款 + 认靠山"，从此他依附于王罕开始有了第一支稳定的小队伍。他还和小时候玩耍的札木合"重新结安达"——札木合当时是札答兰部首领势力比铁木真大得多，两个义兄弟一度并肩作战共同对抗篾儿乞惕部。但这个"三人同盟"（铁木真、王罕、札木合）很快就出现裂痕，原因很简单——铁木真在每一次合作中都吸走了一部分人心。他对手下的一个特点引人注目：抢来的战利品不独占按贡献分——这在当时的草原上极其罕见，当时的常规做法是"首领独占大头"，铁木真的"按功分配"立刻让一批不得志的小首领开始投靠他。到了 1190 年代中期札木合先和铁木真翻脸，两人在十三翼之战中正式开打，这一仗铁木真输了但札木合赢了之后做了一件错事——把七十个俘虏煮死在七十口大锅里，这种残暴让札木合阵营内部一批人寒了心纷纷转投铁木真。输了一仗的铁木真反而因为对手的残暴而吸到了一批新人，这是草原上的人心规律——强者会被人怕，仁者会被人投，铁木真后来一辈子在用这条规律。到 1200 年前后铁木真和王罕也翻脸了，原因还是利益分配——王罕的儿子桑昆嫉妒铁木真的崛起挑唆王罕灭铁木真，铁木真在合兰真沙陀战役中被王罕大军围攻最后只剩十九骑突围逃到班朱尼河边和这十九个人一起饮了"班朱尼河浊水"为誓——这就是后来的"班朱尼之誓"。这十九个人后来全部成为蒙古帝国的开国元勋，铁木真终其一生没有忘记他们——这是他后来"利益必须按贡献分配"原则的最早雏形。

班朱尼之誓后两年铁木真奇迹般地翻盘。1203 年他突袭克烈部一夜之间灭了王罕——这一战让铁木真成为草原上仅次于札木合的第二大势力。1204 年他攻打乃蛮部乃蛮部首领塔阳汗轻敌被铁木真用"夜里多点篝火制造大军假象"的疑兵之计吓懵——乃蛮部一战覆灭，札木合走投无路被自己的部下绑去献给铁木真，铁木真按"杀主之罪"处死了那几个部下又劝降札木合，札木合拒绝自请处死，铁木真让他"以贵族之礼不流血而死"。1206 年春蒙古各部聚集于斡难河源召开"忽里勒台"大会共推铁木真为"成吉思汗"——意思是"拥有海洋四方的大汗"，这一年铁木真四十四岁。从九岁丧父到四十四岁加冕，铁木真用了三十五年时间把草原从"几百个部落"做成"一个国家"，但这只是第一步——真正决定他能成为"成吉思汗"而不只是"草原上又一个霸主"的，是接下来的制度建设。加冕大汗之后铁木真在斡难河源的"忽里勒台"大会上同时颁布了三件事——这三件事才是蒙古帝国的真正起点。

第一件是千户制。他把全国（草原上）所有部众重新打散按"千户—百户—十户"的军事行政单位重新编组——全国共分九十五千户每千户由一名千户长统辖，千户长不是世袭的是大汗任命的，这一刀直接砍掉了原来的部落血缘组织——以前你属于"乞颜部"或"札答兰部"，现在你属于"第几千户"千户之上是大汗。第二件是大札撒（也写作"札撒"），这是蒙古帝国的根本大法——第一部成文的草原法律内容覆盖军事、行政、刑事、民事各个方面：禁止部落间私斗、禁止抢掠平民、奸淫者死、临阵脱逃者死、不传军令者死、保护商旅、宗教自由、不许侮辱萨满和僧侣……这些条文极其严苛但极其清晰，草原上第一次有了"白纸黑字的规则"而不是"看首领心情"。第三件是怯薛军，这是大汗的禁卫军最初一万人从各千户中抽调忠勇可靠的子弟充任——怯薛军不仅是大汗的护卫更是高级军官、行政官员的"预备役"，简单说怯薛军是蒙古帝国的"中央党校 + 黄埔军校 + 国务院储备干部"三合一，年轻贵族要做高官必须先进怯薛军接受大汗亲自训练。这三件事一发草原上的"部落时代"彻底终结"帝国时代"开始。接下来的二十年成吉思汗带着这套制度组建的军队先后灭西夏、金、花剌子模——蒙古铁骑一路打到中亚、伏尔加河、黑海北岸。1227 年他在征讨西夏的途中病逝于六盘山临终前留下分封诸子的遗嘱——蒙古帝国分成四个汗国但宗主仍归大汗（窝阔台、蒙哥、忽必烈一脉）。铁木真死的时候他亲手缔造的帝国疆域东到日本海西到里海北到贝加尔湖南到秦岭——人类历史上版图最大的陆上帝国雏形已成。

## 三、破局解读：蒙古帝国凭什么"以小博大"——四层底层逻辑

读到这里可能有人会说成吉思汗厉害是因为蒙古铁骑天生能打，这个判断是错的。游牧民族能打但能打的游牧民族在历史上不少——匈奴、鲜卑、突厥、契丹、女真——每一个时代都出过"草原上最能打的那拨人"，可只有蒙古做出了横跨欧亚的世界帝国。真正的差异不在战斗力在组织力。第一层是千户制——把"血缘组织"换成"功能组织"。千户制是成吉思汗最致命的一刀，它砍掉的是草原上延续了上千年的"部落血缘联盟"模式。部落联盟的问题是什么？是忠诚的对象不是大汗是部落首领——一个部落的人天生效忠他们的部落首领，大汗能调动部落首领但没法直接调动牧民，这种结构在打仗的时候极其脆弱——只要前线的某个部落首领倒戈或者临阵退缩他下面的人就跟着一起退。千户制干了一件事：把所有部落打散按地理 + 军事单位重新编组，一千户长辖一千户下面再分十个百户、一百个十户，编完之后原来同一个部落的人被分散到不同千户里——你身边的战友可能不再是你叔叔大爷而是几个完全陌生的、来自其他部落的人。这一刀的杀伤力在于牧民的忠诚对象从"部落首领"被换成了"千户长 + 大汗"——千户长是大汗任命的、可随时撤换的，这意味着大汗第一次拥有了对全国基层武装力量的直接调度权。这个逻辑放在今天的企业里对应的就是"矩阵式组织 vs 山头式部门"——山头式部门每个总监带自己的兵 CEO 想调人调不动，矩阵式组织所有人按职能 + 项目编组 CEO 可以直接调任何人，林总的公司之所以崩在三百人本质就是没完成从"山头式"到"矩阵式"的切换。

第二层是大札撒——把"首领心情"换成"白纸黑字"。大札撒是成吉思汗的第二刀，它砍掉的是草原上更古老的"人治"模式。部落时代的草原所有规矩都在首领脑子里——首领今天高兴你犯了事可以放过你，首领明天不高兴你哈个气都可能掉脑袋，这种"看心情"的治理在小部落还行得通（五十个人嘛首领脑子能装下），但是几百个、几千个、几十万个人聚在一起"看心情"就成了灾难。大札撒做的事很简单——把所有规矩白纸黑字写下来：哪些是死罪、哪些是流刑、哪些是赔偿、哪些是奖励——清清楚楚每个千户长每个百户长都拿到一份，这一下子蒙古帝国的法律执行不再依赖"首领心情"而是依赖"条文 + 执行人"。更关键的是大札撒的几条铁律：禁止部落内私斗、禁止侵犯商旅、奸淫者死、临阵脱逃者死、不传军令者死——这五条把蒙古军队的纪律推到当时全世界最高的水准。后来蒙古铁骑横扫欧亚让欧洲史学家最惊恐的不是他们能打是他们的组织纪律——每个士兵都知道自己该做什么、该听谁的、不该做什么，这种纪律不是天生的是大札撒训练出来的。放到今天的企业这一层对应的就是"SOP（标准作业流程）和绩效条例"——一个公司有没有清晰的、白纸黑字的、所有人都能查到的规则决定了它能不能从"几个朋友拍脑袋"做成"几百号人的稳定组织"。

第三层是怯薛军——把"贵族世袭"换成"绩效晋升"。怯薛军是成吉思汗的第三刀，它砍掉的是部落贵族对高层的"世袭垄断"。部落时代的草原首领的位置是世袭的——你爹是部落首领你长大就是新部落首领跟你能不能打、能不能管事无关，这种世袭体系最大的问题是两三代之后最高层就被一群草包占满。怯薛军干了一件颠覆性的事：所有贵族子弟想做高官必须先进怯薛军接受大汗的亲自训练和考察，在怯薛军里你能做什么、做到什么级别决定了你以后能在帝国里做什么——这相当于把"出身决定地位"变成了"绩效决定地位"。更狠的是怯薛军里还吸纳了大量非贵族出身但有才能的人——比如博尔术、木华黎、博尔忽、赤老温这"四杰"本身出身都不算高是凭本事进入怯薛军再凭本事爬到帝国最高层。这一下子蒙古帝国的高层不再是"部落贵族小圈子"而是一个"半开放、按能力流动的精英池"——这个精英池里有出身好的、有出身差的、有蒙古人、有契丹人（耶律楚材）、有汉人、有色目人、甚至后来有欧洲人——只要你能为大汗做事、有真本事就有机会上来。对比一下宋朝就明白这个制度多狠了——宋朝的高层晋升靠科举但科举只面向农耕区的汉族士人，蒙古的怯薛军更广几乎面向整个帝国的所有族群——蒙古的"人才池"比宋朝大十倍。放到今天的企业这一层对应的就是"晋升通道"——一个公司的中高层是从哪儿来的（是老板的亲戚朋友？是只看资历的"老员工"？还是从基层里凭绩效爬上来的？）这个问题的答案决定了公司能走多远。

第四层也是最常被忽略但最致命的一层——利益分配机制。部落时代的草原抢来的战利品 90% 归首领——士兵们出生入死回来分到的可能就是几头牛、几个奴隶，这种分配方式让士兵的积极性始终上不来，反正打多打少都拿不到几样。成吉思汗反着来：他在每一次征战之前都明确"抢来的战利品按功劳分；阵亡者的份额由家属继承"，这种分法在当时的草原上极其罕见——它带来的效果是蒙古士兵的战斗欲望比对手高一个量级，每个普通士兵都知道只要我打得好我就能分到一份，只要我战死了我家人就能拿到一份。更重要的是成吉思汗对早期跟他混的"班朱尼十九人"永远没忘——这十九人后来全部分到了千户、万户、四杰之列子孙后代世袭高官，这种"跟我打天下的人我永远不亏待"的传统让无数人愿意为他卖命。放到今天的企业这一层对应的就是"股权激励 + 期权分配 + 奖金机制"——林总公司之所以崩在第二次痉挛本质就是早期八个合伙人之间没把股权细则定清楚，到了利益规模足够大的时候早期的"兄弟情义"扛不住后期的"利益错位"。

## 四、现实映射：你的小团队怎么提前埋下"能撑到八百人"的制度种子

成吉思汗用这四层制度把"几百个部落"做成"一个帝国"，今天我们用不上这么大的盘子但核心逻辑放在小团队、小组织上完全一样适用。第一条行动指南是在团队还有 5—10 人的时候就把"分配规则"写下来。很多创业者犯的最大错是觉得"现在就这几个人谈钱伤感情"——把利益分配的规则推给"以后再定"，但成吉思汗给我们的第一条铁律是最重要的规则要在"还不需要"的时候就定下来。具体怎么做？第一股权 / 期权要在公司注册的当天就分清楚，不要靠"口头承诺"要写进公司章程——每个合伙人占多少、什么时候 vest、什么情况下回收；第二奖金 / 提成的规则要在第一个员工入职前就写下来，不是"这次你多劳多得"而是"销售额超过 X 给 Y%、利润超过 A 给 B%"——具体到数字、具体到比例、具体到发放时间；第三"打江山的兄弟"和"后来的高管"要分两条赛道，早期合伙人的股权要锁定但同时要预留一个"动态期权池"给后来加入的高级人才，不要用静态的"创业元老"压死动态的"新生力量"。成吉思汗对班朱尼十九人永远不亏待但他同时不断把后来加入的人才（比如耶律楚材、刘秉忠的前辈）拉到核心——这两条赛道并行不悖。

第二条行动指南是在组织还在 30—50 人时就把"打仗的规则"白纸黑字化。很多管理者犯的第二个错是觉得"现在大家都很默契写流程显得官僚"——把 SOP（标准作业流程）的建设推给"以后做大了再说"，但默契是有人数上限的——超过五十人默契就不够用了。具体怎么做？第一把核心业务流程画成一张图，从客户进来到合同签订再到交付完成每一步谁负责、用什么模板、走多长时间——一张图说清楚所有人都能看到；第二把红线写成一份"团队大札撒"，哪些是绝对不能做的（比如和客户私下收钱、虚报报销、泄露公司机密）违反的后果是什么（开除、扣多少钱、走法律）——一二三四列清楚发给每一个新人；第三把"模糊地带"逐渐固化，每次出了"靠人情解决的事"不要解决完就过去，要复盘要把它写成下一次的"明文规定"——让"靠人情"在你的组织里逐渐消失让"靠规则"成为默认。大札撒不是一次性写出来的，它是成吉思汗在二十多年的统一战争中遇到一个问题就立一条规则、遇到一个例外就补一条条款慢慢积累出来的，你的团队 SOP 也应该是这么长出来的。

第三条行动指南是在组织还在初创期就要建立"非血缘 + 非情分"的人才晋升通道。很多创业者犯的第三个错是高层全是"我哥们儿、我同学、我前同事"，这种结构在前两年问题不大——大家彼此信任沟通成本低，但它的天花板是很硬的——当公司需要"专业人才"时你的核心圈层里没有人能匹配，于是只能"将就用"，于是公司就在专业问题上一次次撞墙。具体怎么做？第一给"非朋友圈"的人才留通道，从公司有第一个员工开始就要明确——最高层不是只有合伙人才能进，每年从中层里识别 1—2 个"潜力股"给他们机会、给他们试错空间、给他们越级汇报的权限；第二让晋升标准透明化，不要让"晋升"变成"老板拍脑袋"，要有明确的能力模型 + 业绩门槛 + 评估流程——新来的员工要能看到"我做到 X 下一步可以是 Y"，这种透明度本身就是凝聚力；第三警惕"创业元老越级"现象，早期跟你打江山的人如果能力跟不上公司发展，你要敢于让他从"业务一线"退到"战略顾问"把位置让给真正能打的新人——成吉思汗的怯薛军核心思想就是"高层职位是按能力筛选的不是按入职先后排队的"，这是大多数创业公司的死穴。

## 五、史镜启示录：写给每一个想把小团队做成大组织的人

第一条铁律是赢的不是个人勇武是把零散个体整合成统一组织的"组织力"——这是从草原到企业不变的铁律。第二条铁律是真正重要的规则要在"还不需要"的时候定，等到"需要"再定就晚了，因为那时候每个人的利益已经板结谁都不肯让步。第三条铁律是千户制的本质是"组织功能 > 部落血缘"——你的公司一旦要破百人就必须开始把"按关系编组"换成"按职能编组"。第四条铁律是大札撒的本质是"明规则 > 看心情"——一个组织能撑多大取决于它把多少"靠默契"的事情转成了"靠规则"。第五条铁律是怯薛军的本质是"绩效晋升 > 出身世袭"——一个组织走多远取决于它对"非朋友圈"的人才留了多大的位置。第六条铁律是班朱尼之誓的本质是"打江山的人永远不亏待"——这是凝聚力的源头但要和"绩效晋升"两条赛道同时存在不能用一条压死另一条。第七条铁律是个人能力是天花板组织能力才是底盘——铁木真的勇武决定了他能做"草原霸主"他的制度才让他做成"成吉思汗"。
