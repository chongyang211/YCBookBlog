# 第33章 陈爷爷上门来访

"一个人讲道理，别人不一定听。但一个人把他的一辈子摊在桌上。没有人能假装没看见。"

周日下午两点。门铃响了。晓星去开门。陈爷爷站在门口，穿着那件洗得发白的深蓝色中山装，胸口的钢笔别针在冬日的阳光下有一点反光。左手拎着一兜水果。苹果和橘子。很普通的那种，超市里论斤卖的。不是贵重东西。他往屋里看了一眼。客厅里林建国正从沙发上站起来。王秀兰跟在后面，手在围裙上擦了又擦。

"陈行长。"林建国的声音有点紧。他不知道这位退休的老行长来干什么。但他知道女儿的事对方全都清楚。这种感觉像是没复习就被叫上了讲台。"坐。您坐。"王秀兰把沙发上堆着的两件没叠的衣服抱走了，腾出一块地方。陈爷爷坐下来，把水果放在茶几边上。挨着那只铁皮糖盒。他看了一眼糖盒，没有碰。

"小林。秀兰。今天来不是兴师问罪的。晓星是我在银行见过的最特别的客户。"他说话很慢，每个字之间都有一小段空白。"我不是来教育你们的。教育人这件事。我当了四十年行长，最清楚。没用。人只会被自己看见的东西说服。我今天来，就是想给你们看几样东西。"

他从随身的旧公文包里拿出一个牛皮纸信封。信封的边角磨得起了毛，封口处贴了一层透明胶带。打开。里面是三样东西。

第一样。一沓银行流水。计算机打印纸，已经泛黄了。最早的一页日期是一九八五年三月。工资五十六元。存了十元。后面每一页都是这个格式。日期。工资。存款。偶尔有取款。取款那一栏备注写着"孩子学费""母亲住院""购房首付"。但取完之后第二个月存款又恢复了。从来没有中断过。

一九八六年。一九八七年。一九九零年。一九九五年。二零零一年。二零零八年。二零一五年。一直记到去年。四十年的纸页在茶几上摊开来，从这头铺到那头。每一页上的数字都比上一页多一点点。没有暴富的月份，没有翻倍的年份，没有任何奇迹。就是十个点、十五个点、二十个点地往上走。像一只蜗牛爬一根杆子。很慢。慢到每一页单独看都看不出变化。但四十页连在一起，最后一个数字是第一个数字的上百倍。

林建国从第一页看到最后一页。看得很慢。手指在纸面上走，像在看一张他从来没读懂过的地图。他看了两遍。不是在看数字。是在看那四十年的每一个"存"字。他想起自己那些投资。二零零八年买股票，二零一五年投P2P，二零二一年加入虚拟货币群，二零二三年签了共享充电桩加盟。每一次都告诉自己"这次不一样"。每一次的合同都比他面前这沓纸厚。但每一次的结局都一样。钱没了。只有合同还留着。

"四十年。"陈爷爷说。"没有一个月中断过。我结婚那年存的少了点。十块。孩子上大学那年取得多了点。两万。但从来没有一个月是零。"

他把流水的最后一页翻过来。背面有一行手写的钢笔字。墨迹比印刷字深，笔锋很稳。"财富不是挣来的，是攒出来的。挣是加法，攒是乘法。"

林建国盯着那行字看了很久。他是做技术出身的，比任何人都懂什么叫复利。每天进步百分之一，一年后是原来的三十七倍。存钱也一样。每个月存一点，几十年后你算不明白。每个月亏一点，几十年后你也算不明白。算不明白的窟窿。他做了一辈子加法。从来没做过乘法。

第二样东西。一沓剪报。从旧报纸和杂志上剪下来的。每一张都发黄了。陈爷爷把这些剪报一张一张摆在茶几上。第一张。十年前。新能源项目非法集资，老板卷款跑路，涉案金额过亿，受害者多为工薪阶层。第二张。七年前。贵金属交易平台爆雷，投资者本金全损，有人跳楼。第三张。五年前。共享经济加盟骗局，数千加盟商血本无归。第四张。三年前。保健品传销被查。第五张。去年的。虚拟货币平台关闭，投资人围堵写字楼。

他一张一张摆过去，摆了七八张。每一张上的新闻标题都很眼熟。林建国看着那些标题，手指在膝盖上攥紧了。不是因为这些骗局他都知道。是因为每一个骗局他都信过。有的是真金白银投进去的。有的只是在手机上看了很久，差一点就转账了。他在每一张剪报上都看到了自己的影子。

"骗子从来不发明新的骗局。"陈爷爷的声音很轻。"他们只会换包装。十年前叫新能源，十年后还叫新能源。换了个公司名，换了个CEO的照片，换了个Logo。别的一样。都是告诉你。这次不一样，这次真的能翻倍。"

他停了片刻。然后拿出一张唯一不太一样的剪报。报纸的社会新闻版。标题很短。上面写的是一个保洁阿姨，工资一个月两千出头，靠十五年基金定投供两个孩子读完大学。一个儿子在深圳做工程师。一个女儿在成都当护士。陈爷爷指着这张剪报。"这个阿姨我认识。她存钱的方法和晓星一模一样。每个月发工资，先存五百。剩下的才花。五百块不多。十五年也不长。但她坚持下来了。你们知道她坚持下来靠的是什么吗。不是毅力。是习惯。习惯不用咬牙。咬牙的事长久不了。"

第三样东西。一个旧笔记本。黑色封皮，边角磨白了。里面夹着一张手写的纸。陈爷爷把那张纸拿出来，放在茶几正中。上面是一行一行的字，用钢笔写的。字体很端正。

"家庭财务重建方案"。下面分四个阶段。一、止血。停掉所有非必要开支。删除所有购物APP。取消所有不必要的订阅。二、建立应急缓冲。存够一个月生活费。放在一个绝对不能动的账户里。三、偿还高息债务。信用卡优先。网贷其次。四、重建信用和长期储蓄。每个月固定存入一笔，三十年起。

"这套方案我给无数人做过。"陈爷爷把那张纸推近了一些。"在银行的时候。退休以后。每一次对方都听得很认真。点头。说回去就照做。然后第二天信用卡照刷，投资照投。你们知道为什么吗。因为他们觉得那是别人的方案，不是自己的。今天我把这张纸放在这里。不要求你们照做。只要求你们看一眼。看一眼你们女儿是怎么做的。她已经在第一条了。自己一个人推进到了第三条的一半。她没有任何人的帮助。没有工资。没有信用卡。她只有一双手。和一套你们从来没教过她的方法。"

林建国拿起那张纸。第一行。止血。他想起妻子删掉的十三个APP。想起冰箱上撕掉的投资宣传单。想起角落里比以前少了的快递盒。第二行。建立应急缓冲。他想起晓星金鹅账户上那一千二百多。那一笔一笔的十块、十五块、二十块。第三行。偿还债务。他想起晓星帮奶奶交的眼镜钱。想起愿望清单上那行"帮父母还清债务"。

第四行。长期储蓄。三十年起。他看了很久这行字。三十年后他七十二岁。晓星四十四岁。到那个时候，这张方案纸上的每一行都会变成一份存折上的数字。只要从今天开始。

王秀兰从旁边伸过手来，拿起那沓四十年银行流水。不是从头看。是看中间某一年。那一年她记得。是晓星出生那年。那一年陈爷爷的存折上有一笔取款，备注写着"孙女生病 住院押金"。旁边还有一笔存款。金额比平时少了。但还在。她在那一年那一页上摸了很久。然后把流水轻轻放回去。

陈爷爷站起来。拿起公文包。把东西一件一件收回去。银行流水收回去。剪报收回去。笔记本收回去。那张方案纸没有收。"这张留给晓星。她比我更清楚怎么执行。"他走到门口。换了鞋。回头看了一眼。林建国从沙发上站起来。想说点什么。嘴张了一下。又合上了。

"小林。"陈爷爷站在门框里说。"你做技术出身，比我懂什么叫复利。每天进步百分之一，一年后是原来的三十七倍。存钱也一样。每个月存一点，几十年后你算不明白。但如果你每个月都亏一点，几十年后你也算不明白。算不明白的窟窿。"他没有等林建国回答，转身往楼下走。

林建国跟下去。两个人一前一后走楼梯。脚步声在水泥台阶上重叠。到一楼门口，陈爷爷转过身看了他一眼。没有说话。点了下头。然后走出了单元门。

林建国站在楼道口。冬天的风灌进来，冷得刺骨头。他看着陈爷爷的背影走远。那个背影和奶奶的背影不太一样。奶奶是弯的。这个背影是直的。直了四十年。

回到楼上。王秀兰还坐在沙发上。面前是那张方案纸。她没有看纸。在看茶几边上那兜苹果和橘子。很普通的苹果。很普通的橘子。超市里论斤卖的。陈爷爷拎了一路。四十年银行行长的礼物。不是贵重的东西。

林建国在她对面坐下来。两个人中间隔着茶几。茶几上摆着他们女儿的两个多月。存折在糖盒里，记账本在旁边，成功日记在存折上面。林建国没有说话。王秀兰也没有说话。客厅里只有冰箱的嗡嗡声。和远处不知道哪家传来的电视声。

坐了很久。苹果和橘子还在兜里。没有人去洗。也没有人挪开。
