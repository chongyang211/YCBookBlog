# 第52章 爸爸扛起了担当

一个人的肩膀什么时候最硬？不是扛得起的时候。是扛不动了还扛着的时候。

——金鹅

工厂裁员的通知是三月中旬下来的。一张A4纸贴在车间公告栏上，名单里第三个就是林建国。没有理由，理由写在纸上也不用看——订单少了，车间要减人，四十二岁的技术员比二十岁的普工贵。贵在哪里，不用别人说。

他把那张通知从公告栏上撕下来，折了两折放进口袋。走出车间的时候，在门口站了几秒。门口有一排铁皮柜子，最右边那个是他的，柜门上的编号磨得看不清了。他拉开柜门，里面只有一副旧手套和半瓶喝剩的茶水。手套拿走，茶水倒了，瓶子扔进垃圾桶。柜门关上。空柜子的铁皮回声比有东西的时候大。他在这个车间干了十二年。走的时候带走了一副手套。

回家路上没有直接进门。他在楼下抽了一根烟。不是那种一口接一口猛吸的抽法——吸一口，把烟夹在手指间看一会儿，再吸一口。烟雾往上走的时候，他在烟雾后面眯着眼睛看对面那个亮着灯的窗户。客厅。里面有三个人的影子。模糊的，但他知道哪个是王秀兰，哪个是晓星。

看了很久。把烟头掐灭在楼下的垃圾桶上。上楼。

进门的时候，王秀兰在厨房炒菜，晓星在茶几上写作业。他把那张折了两折的裁员通知放在茶几上，和记账本放在一排。晓星抬头看了一眼纸上的字，没有问。她拿起通知，从茶几抽屉里翻出透明胶带，贴在电视机旁边的墙上——和塑封的债务清单、冰箱门上的进度条形成了一条线。

墙上的纸越来越多了。每一张都是一个已经翻过去的坎。这一张是新的。林建国站在这面墙前面看了几秒，然后转身进了厨房。他把王秀兰手里的锅铲接过来，翻了两下锅里的青椒。什么也没说。王秀兰也什么都没问。厨房里只有锅铲碰铁锅的声音和油跳起来又落下去的声音。

陈爷爷帮他联系了两份活。一份在城东的物流园，夜班分拣，晚上十点到早上六点，每小时二十五块。一份周末给驾校学员陪练，驾校教练忙不过来时喊他顶上，一个下午两百块。两份加起来月收入将近八千，比原来工厂的工资还高一点。高出来的那部分不是钱，是命——用晚上的觉和周末的下午换的。

物流园分拣线是一条铁灰色的传送带，几百个包裹在上面跑，每个包裹贴着一张白色标签，印着目的地编码。他的工作是站在传送带旁边，看一眼编码，把包裹扔进对应的筐子。同一个动作，一晚上重复几千次。眼睛看编码，手抓包裹，转身，扔进筐。眼睛看编码，手抓包裹，转身，扔进筐。动作不需要脑子。

但脑子不能乱想。想多了眼睛就会跳过一行编码，包裹扔错筐子。扔错一个，整条线的速度卡一下。他以前在工厂是技术员，一根手指按控制面板，另一根手指按咖啡机。现在两只手同时干活，第三只手——脑子——不能用了，只能用来认那串数字。他后来跟晓星说，分拣线上的编码和投资合同上的数字不一样。编码不会骗人，一个码对应一个地方。投资合同上的数字，一个零对着一个坑。

第一天干完，腰直不起来了。不是"有点疼"，是脊椎骨像被人一节一节往反方向拧了一遍。收工的时候他扶着传送带的铁架子站起来，站了好几秒才直起上半身。骑电动车回家的路上，风吹在脸上，凌晨三点的风，凉得像一把剃刀。

他忽然想明白了一件事。以前为什么整夜整夜睡不着。不是因为欠了多少钱，是因为脑子里的事太多了，每一件都在排队等他去焦虑。现在脑子只干一件事——分拣编码。累了只想睡觉。累睡着了，就不会想那些亏掉的钱和欠下的债。纯粹的体力劳动让他没精力焦虑。这是他用腰换来的第一个发现。

第一个周末陪练，驾校教练甩给他一辆手动挡的老捷达和一个二十岁的大学生。大学生刚考过科目二，上路腿发抖，每次红灯起步熄火。林建国坐在副驾驶上重复了一整个下午的那句话："离合慢点松。"

大学生熄了七次火。他在副驾驶上笑了两次。不是嘲笑。在这个大学生身上他看到了另一个版本的自己——怕的不是熄火，是后面按喇叭的那些车。怕别人笑他。林建国不怕后面的喇叭了。以前怕——怕亲戚催债，怕邻居闲话，怕同事知道他白天技术员晚上送快递。现在不怕了。喇叭响就让它响，先把离合稳住。车不熄火了，后面的自然就不响了。

下午结束，驾校教练递给他两张一百块。钞票是旧的，折了很多道，上面有汗渍。他把钱叠好放进口袋。同一个口袋，上个月放的是裁员通知。

回家以后他把第一次夜班工资也拿出来了。夜班工资是微信转账，他提现到银行卡里，又从银行卡里取了两张一百的现金。和陪练的钱放在一起。一共四百。他把四张一百块放在茶几上，正对着晓星的记账本。

"放你的金鹅账户里。"晓星抬起头，没有伸手。"爸，这是你自己挣的。你自己管。"林建国把钱往前推了一下。"不是给你。是让你帮我管。我自己管钱管了二十年，管成了一塌糊涂。"他把烟从耳朵后面取下来，没有点。就夹在手指间，像一支没削的铅笔。"现在我拜你为师。"

晓星伸出手。不是拿钱——是把记账本翻开到新一页，拿起黑笔在最上面写了一行字：爸爸交来/月。然后把四张一百块夹在这一页里。合上本子之前，她在这一页的右下角用蓝笔加了一行小字："这不是投资。是信任。"

又过了一个多月。一个凌晨，将近两点。晓星起来去客厅倒水。灯没开，但她看见了沙发上的影子——林建国靠在沙发扶手上，头歪向一边，嘴微张着，眼睛闭得很紧。饭盒还放在茶几上，盖子打开了，里面的饭只吃了一半。筷子还插在饭里。人已经睡着了。身上还穿着物流园的那件反光背心，荧光黄的，背后印着"XX物流"四个字，反光条被传送带的铁架子磨花了几道。

她轻手轻脚地走进父母卧室，把床上那条毯子抱出来。还是那条墨绿色毯子，奶奶织的，边角有点脱线了。展开，从肩膀盖到膝盖。他的肩膀缩了一下，没醒。她又蹲下来，把他脚上那双解放鞋脱了。鞋带系得很紧，她解了两下才解开。鞋帮上沾着灰白的泥点和细碎的纸屑——物流园的纸箱碎屑。鞋里面是潮的。这双鞋穿了两个月没换过。白天去驾校，夜里去物流园，回家进门脱在鞋柜旁边，第二天原样穿上。

她把两只鞋拎到暖气片旁边。暖气片只有一点点温度——已经是春天了，暖气烧得不旺。但比鞋里面热。她把鞋子并排放在暖气片下面的地板上，鞋口朝着暖气片。热空气从鞋口灌进去，慢慢把里面的潮气往外赶。鞋垫的边缘已经磨得起毛了，右脚那只的鞋垫磨出了一个很深的凹坑。那个凹坑是大脚趾的位置。她用指甲按了一下那个凹坑。硬的。不只是鞋垫，是这双鞋记住了父亲脚趾的形状。

她把鞋举起来，凑近闻了一下。一股混在一起的味——脚汗的味道、仓库的纸箱味、机动车道的尾气味、凌晨两点街边早点铺子第一笼包子的蒸汽味。不是好闻的味道。但她没有皱眉头。她把鞋放回去，记住了这个味道。

回到茶几边上，饭盒里的那半份饭已经凉透了。她拿起来看了看——青椒炒肉片，米饭压得很实。母亲中午多炒了一份留给他的。他把肉片吃了，米饭剩了一半。她盖上饭盒盖子放进冰箱。冰箱门上进度条涂了四段蓝——1.3%、2.8%、4.2%、5.5%。再往前加一截就到百分之六了。

路过客厅时，沙发上的父亲翻了个身。毯子滑下来一角。她又给拉上去。毯子下面是那件反光背心，背心下面是一件洗得发白的工作服。胸口的位置有个口袋，印着以前工厂的标志——一个齿轮的图案。现在齿轮下面多了一块反光条。不是换了一件衣服，是把两件工作穿在了身上。

暖气片旁边那双解放鞋还在。鞋口朝着暖气片。热空气慢慢往里灌，鞋里面的潮气一丝一丝往外走。明天他穿上这双鞋的时候，鞋垫是干的。走了那么多路，第一天干着走总比湿着走好。

第二天是周末。林建国下午有陪练，晚上有夜班。出门之前他在茶几上放了一包烟，没拆封的。以前他一天抽一包，这包烟他拆开了只拿了一根放在耳朵后面。剩下的推给王秀兰。"帮我收着。一天一根。多了不给。"王秀兰把烟收进抽屉——同一个抽屉，放蜡烛、打火机、透明胶带的那个。她说了一句话，声音不大，但林建国在门口换鞋的时候听见了。

"一根也别抽了。换了别的吧。"停了一下。"晚上回来我留一碗汤。不用在楼下抽烟看窗户了。"

林建国把鞋带系好，站起来。门把手拧下去的时候他的手没有停。走到楼下没有再抬头看窗户。直接骑上电动车走了。电动车尾灯在路口拐了个弯。灭了。又重新亮起来。往城东的方向。
