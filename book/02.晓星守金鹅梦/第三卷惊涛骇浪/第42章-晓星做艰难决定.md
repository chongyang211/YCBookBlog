# 第42章 晓星做艰难决定

"有些决定不是你做的。是它自己找上你的。你只不过没有躲。"

——金鹅

天还没亮。晓星已经醒了。不是闹钟叫醒的，是心里揣着事自动醒的。她躺在床上，盯着天花板上的裂纹看了很久。窗外的雪光把那条裂纹照得比平时浅了一点。她翻了个身。枕头底下的平板硬硬地硌着后脑勺，她把平板抽出来放在床尾。没电。屏幕黑着，那只鹅在黑屏后面闭着眼睛。

她坐起来。没有开灯。借着窗外积雪的反光，把衣服一件一件套上。校服在最外面一层，袖口上昨天母亲缝的那道线在微光里看不清楚，但她用手摸了一下。线很整齐。

她穿上拖鞋，走到书桌前。铁皮糖盒打开。存折。记账本。三个颜色信封——金色的装金鹅账户，蓝色的装愿望基金，白色的装日常开销。白色信封已经空了。蓝色信封里有几张十块和五块的纸币，皱皱巴巴的，放学路上捡矿泉水瓶换的。金色信封里没有现金——金鹅账户的钱在存折上。

她把存折从金色信封里抽出来，翻开。两千三百元。下面还有一行很小的字，柜员在备注栏里打的。"零存整取·第七笔"。她把那张对折的白纸夹在存折第一页——上面是她昨晚写的那三行字。然后从书桌抽屉最里面摸出几枚硬币。五角的。一元的。还有一张揉成一团的五块钱。全部塞进蓝色信封里。把三个信封叠在一起，和存折一起放进铁皮糖盒。糖盒的盖子扣上，发出一声轻微的金属脆响。咔嗒。

她端着糖盒走到父母卧室门口。门没有关严。昨天他们太累了，连关门的力气都没有了。

她轻轻推开门，门轴发出一声很细的响声。停了一下。没醒。她侧身进去。房间里很暗。窗帘拉得严严实实，只有窗帘底部漏进来一小截蓝色的雪光，刚好照在床尾的被子上。

父亲仰面躺着，被子只盖到胸口。眉头是皱着的，嘴唇微微张开，呼吸很重。在睡梦里和什么东西搏斗的样子，和在醒着的时候一样。他的一只手搭在被子外面，手掌朝上。手指上还有昨天写账单时圆珠笔在虎口留下来的墨渍，一小团蓝色的印子。

母亲侧躺着，背对着父亲。她的手紧紧攥着被角，攥得指关节一个一个发白。那种攥法不是怕冷。是怕松手。是在梦里也在抓着什么不放。

晓星站在床边看着他们。两个四十多岁的人，睡着的时候看起来比醒着的时候老。父亲的鬓角在雪光的映照下白得发亮，平时不觉得有这么白。母亲的颧骨比几个月前高了一点，枕在枕头上的侧脸陷下去一小块，是瘦的。

她把铁皮糖盒放在父亲那一侧的床头柜上。离枕头很近，伸手就能够到。她弯下腰。靠得很近，能闻到父亲头发里的烟味和母亲脸上的雪花膏味。雪花膏是很久以前买的，香味已经散得差不多了，只剩一点很淡的茉莉花味。

她想凑过去亲一下母亲的脸。嘴唇离母亲的脸颊大概还有一巴掌的距离，她停住了。怕吵醒她。她们难得睡着。这个家难得安静。

她直起身，把一张折好的纸条从糖盒底下抽出来。刚才在房间里写的，用的还是记账本上撕下来的纸。

纸条上是她用蓝色彩铅写的字，笔画很轻，轻到纸的背面几乎看不到印子。

"爸，妈：不要离婚。我的金鹅账户里攒了大半年的钱，还有 2300 元。愿望基金还有 800 元。加起来 3100 元。不够奶奶的押金，但可以先交一部分。剩下的我们一起想办法。晓星。"

纸条下面她画了一只鹅。只有三笔。一笔头一笔翅膀一笔身子。画得比任何一次都小。她把纸条压在糖盒下面。

然后轻手轻脚地退出去。把门带上的时候用手指压住门锁的舌头，让它不要发出咔嗒的声音。门合上了。没有声音。她站在走廊里。心跳得很快。不是后悔。是刚才那个动作太小心了，小心到呼吸都不敢用力，现在终于可以喘口气了。

糖盒里还夹着记账本的最后一页。她提前撕下来的。那页纸比别的纸更皱，因为她写完以后攥在手里攥了很久。上面的字是昨晚写的。

"今天提前写下结尾。目标——让这个家的账本从红色变回黑色。期限：不限。方式：一起。"

早上八点。王秀兰醒了。不是自然醒的。是手松开被角以后忽然空了——那种空像踩楼梯踩空了一级，身体还没反应过来，心已经惊了一下。她翻过身，林建国还在睡。她坐起来。然后看到了床头柜上那个铁皮糖盒。大白兔奶糖的盒子，盒盖上的兔子已经磨掉了半只耳朵。她认得这个盒子。

先是愣了一下。然后拿起来。打开。存折。三个颜色信封。皱皱巴巴的纸币和硬币。她拿起存折，翻开。那张对折的白纸从第一页掉下来，落在被子上。她捡起来。打开。三行字。

"这是我全部的力量。虽然很少。但这是全部。"

她看完这三行字，没有动。然后把存折合上，发现了压在糖盒底下的那张纸条。更小的那张。上面的字比存折里那张更轻，轻得像怕吵醒她。她一个字一个字看完。看到最后那个"晓星"的时候，她的手指在纸上握了一下。纸皱了。

她把手松开，用手指把纸上的褶皱一点一点抹平。抹不平。

她没有叫醒林建国。只是把存折和纸条放在枕头旁边，然后低下头。

肩膀先是抖了一下。然后开始剧烈地抽动。她用手捂住嘴，但眼泪从指缝里渗出来，滴在存折的蓝色封面上。蓝色的封面沾了水以后变成一种很深的颜色——像深海的颜色。眼泪一滴一滴砸在上面。这次不是因为绝望。不是因为恐惧。是因为愧悔。

她十四岁的女儿在用捡垃圾的钱救这个家。她昨天缝校服的时候心里想的是怎么把这一辈子缝过去。而她的女儿在想怎么把这一家子从窟窿里拉出来。她坐在床边哭了很久。没有声音。只有肩膀在抖。窗外又飘起了小雪。一片落在玻璃上，很快就化了。
