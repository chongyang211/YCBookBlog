## 01.书名与定位

- **正式书名**：《现代 Go 由浅入深：从入门到工程精通》
- **副标题**：4 卷本 / 65+ 章 / 140 万字 / 覆盖 Go 1.22
- **定位句**：用一套教材，把 Go 工程师从"会写 Hello World"带到"能在线上系统排故障"。

### 1.1 一句话区别于其他书

| 已有书 | 本书的差异点 |
|-------|------------|
| 《Tour of Go》 | 我们多了项目实战、底层原理、上线排错 |
| 《Go 圣经》 | 我们以 Go 1.22 为基线（圣经停在 Go 1.5），并加了泛型、PGO、`slices`/`maps` |
| 《Go 语言设计与实现》（draveness） | 我们多了卷一语法和卷二项目，新手能直接读 |
| 《100 Go Mistakes》 | 我们把它的"100 个错误"嵌入每章的 **新手陷阱 Top 5** 小节 |
| 极客时间《Go 36 讲》 | 我们多了完整的项目代码与上线实战 |

| 画像编号 | 读者 | 占比预估 | 主要诉求 |
|---------|------|---------|---------|
| **R1** | 大学计算机系大二/大三学生 | 30% | 课内 C 学了，想转 Go 找后端实习 |

- 至少一门强类型语言的基础（Java / C / TypeScript / Rust 任一即可）
- 会用命令行（`cd` / `ls` / `git` 等）
- 装过 Linux 或 macOS 的开发环境


## 03.差异化卖点（与市面教程对比）

### 3.1 五大差异

1. **从第一行代码就用 Go 1.22 的现代写法**
 - 不教 GOPATH 老模式，第 2 章直接 `go mod init`
 - 不教 `interface{}`，第 16 章直接讲 `any` + 泛型
 - 不教手写 sort.Interface，先讲 `slices.SortFunc`

2. **每章末尾有「Go 新手陷阱 Top 5」**
 - 直接告诉你"哪些代码 编译过 / 跑得通 / 但是错的"
 - 例：`for _, v := range slice { go f(&v) }` 共享变量陷阱

3. **每个综合案例都"能跑、能改、能上线"**
 - 卷二 12 个案例，从 100 行的 CLI 通讯录到 5000 行的 KV 引擎
 - 第 12 案例 MiniKVStore 一篇串完卷一 16 章

4. **卷三是 runtime 源码级解析**
 - GMP / GC / channel / map / netpoller 全部带源码行号
 - 用 Go 1.22 的源码（不是 1.5 / 1.10 旧版本）

5. **卷四是真实线上故障复盘**
 - 不是"教 pprof 怎么用"，而是"P0 事故 5 小时复盘"
 - 17 个故障全部基于真实场景脱敏改编

### 3.2 与 C++ 姊妹篇的关系

本书与 [`../08.Cpp入门到精通/`](../08.Cpp入门到精通/) 是**结构对位**的姊妹篇：

| 维度 | C++ 版 | Go 版 |
|------|-------|-------|
| 卷一章节数 | 18 | 18 |
| 卷二案例数 | 12 | 12 |
| 卷三专栏数 | 16 | **22**（重组 + 新增 6 篇）|
| 卷四技巧数 | 17 | 17 |
| 章节命名 | 按 C++ 概念（指针引用、模板、STL） | 按 Go 概念（goroutine、channel、泛型） |
| 案例 | 通讯录 / 银行 / 职工 / 票务 / KV | 同上（用 Go 重写）|
| 语法基线 | C++17 主基线 + C++20 增补 | Go 1.22 主基线 |

**对照阅读建议**：如果你同时学过 C++ / Go，可以用本书做"双语速查"——比如在 C++ 看完"虚函数表"，再来 Go 看"接口的两个指针"，会很快建立对照。

## 附录 A：术语对照表（与 C++ 版交叉对照）

| Go 概念 | C++ 概念 | 备注 |
|--------|----------|------|
| goroutine | std::thread / std::jthread | Go 是 M:N 协程，C++ 是 1:1 内核线程 |
| channel | 无对应 / boost::lockfree::queue | Go 一等公民，C++ 需要库 |
| interface | 抽象基类 + 虚函数 | Go 是结构性子类型，C++ 是名义子类型 |
| receiver | 隐式 this | Go 显式写在方法签名里 |
| defer | RAII / 析构函数 | Go 是函数返回前调用，C++ 是离作用域调用 |
| panic / recover | throw / catch | 但 Go 不鼓励用作正常错误处理 |
| error | std::expected / 返回错误码 | Go 一等公民 |
| 泛型 | template | Go 1.18+ 才有，且故意限制 turing-complete |
| go.mod | CMakeLists.txt + vcpkg/conan | Go 内置，C++ 需要外部工具 |
| escape analysis | 栈上分配 vs 堆上分配 | Go 编译器自动决定，C++ 由语法决定 |
