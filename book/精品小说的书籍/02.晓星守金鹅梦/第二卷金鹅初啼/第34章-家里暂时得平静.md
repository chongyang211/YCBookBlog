# 第34章 家里暂时得平静

陈爷爷走后，茶几上那杯白开水还在——凉透了。水面浮着一层从楼道里涌进来的细灰，像冬天暖气管道漏气之后在空气里悬浮了一整天终于沉下来的极轻沉淀。杯底压着那张试色纸上被水洇开的豆沙色唇印，边缘已经模糊成了一朵淡粉色的霉斑，中间被杯底压得太久，试色纸的涂层和水的化学反应已经不可逆了——这个唇印以后再也擦不掉。

林建国坐在沙发上。电视没开。他手边摊着两样东西——陈爷爷留下来的那叠对账单里最早的一页：1995年存的第一笔定期五百元，金额栏里的手写体墨水已经褪成了褐色；和他自己的手机，屏幕朝下扣在沙发垫子上，壳子边缘那道去年摔了没修的裂口翘着一小片塑料断茬。他用拇指来回压那片断茬——不是想把它按回去，是在找一个可以让手停留的物理理由。一个人不需要想事情的时候，手指必须摸点什么——这是修了二十年机器的习惯。

王秀兰在厨房里洗碗。水龙头拧到了最大，水流砸在搪瓷盆底溅起来的水珠弹到了灶台边的酱油瓶上，瓶子被水珠打得轻轻晃了一下，碰倒了旁边一管还没有拆封的生姜洗发水。洗发水滚到灶台边缘，没有掉下去，靠在燃气灶旋钮上停住了。她想用水声盖住客厅里的沉默，但洗到第三个盘子时把水关了——不是洗完了，是水声覆盖不了沉默，反而让沉默在两次水声之间那零点几秒的间隙里被放大。她把碗摞好，用围裙擦了擦手。围裙上印着某银行信用卡的logo——办卡时送的赠品。她在厨房门口站了一会儿，没有立刻走向沙发。

晓星从走廊里走出来。她把鞋柜上陈爷爷留下的那张纸条捡起来——"靠本事挣"，红蓝双色水彩笔写的，红的那一头写"靠"和"挣"，蓝的那一头写"本事"。写"挣"字最后一竖时笔快没水了，竖的末尾只有半画，被纸的纤维碾断在离完成不到两毫米的地方。她把纸条夹进记账本封面内页，和之前攒下的那些东西放在一起——张叔给她的第一瓶冰水的塑料瓶剪下来的那一小块瓶身、银行的存款回单、奶奶储蓄罐里拿出来的一个一九九二年的五分硬币。

她把记账本合上，放在书桌最靠墙的位置，和台灯底座、断了半截的铅笔、一张用完的公交卡并排靠着。这些东西从左到右按时间顺序排列——最早的在最左边。

接下来的三天，家里安静得出奇。安静到晓星每次推门之前都要在门口站三秒，先听门里面有没有声音。没有争吵，没有催款短信的提示音，没有投资群消息的震动。她终于不用再踮着脚尖进家门了，但她始终没有改掉在门口站三秒的习惯——习惯一旦形成就不容易去掉，就像妈妈习惯了拆快递、爸爸习惯了看投资群、她自己习惯了在进门前先确认安全。

王秀兰没有再拆新快递。沙发旁边那三个上周到的盒子还搁在原来的位置，最上面那个纸箱的胶带已经松了半边，盖子翘起来，露出一套还没撕膜的玻璃保鲜盒。盒子顶端贴着正红色促销标签——"买二送一，最后一天"，标签的"最后一天"是三天前。她走过时看了两眼，走过去，没有停。然后倒退了两步，把盒盖按下去用掌根压了压——盖不严。胶带失效了。她索性不压了，由着那个翘起的角支在沙发扶手旁边，像一个没有完全愈合的伤口。路过第三次时她把促销标签撕下来揉成一团扔进了垃圾桶——扔的时候纸团在桶沿弹了一下，落进去的声音很闷。

林建国把冰箱上那张投资宣传单取下来了。取的时候没把胶带用吹风机吹热就硬撕，透明胶把冰箱白漆带下来一小片，露出底下前年他自己用补漆笔刷过的痕迹——干了以后隆起一道像旧疤的微型山脉。他现在从冰箱前经过时会偏一下头，不看那道疤。但每天还是从同一个位置拿啤酒，手绕过疤从它上方不到一厘米处掠过。

有天晚上他喝到第三口时忽然把啤酒放在茶几上，拿起陈爷爷那叠对账单里自己那张工资收入流水，从第一页翻到最后一页。翻到中间某一页时停下——那一页上有他五年前一个月的加班费记录：两千三。比他上个月被"新能源投资"平台扣掉的那笔预约认购款刚好少了五十块。多了五十块加班费，和少了五十块被骗走的钱——这两个数字不是同一个五十，但都是从同一个口袋里出去的。

晓星恢复了日常。放学接浩浩——从幼儿园门口送到小区铁门前，等着那个穿褪色红花棉袄的奶奶从楼道里走出来。浩浩每次都要回头，倒退着往楼道里走，一只手被奶奶牵着，另一只手朝晓星挥。晓星也挥手——举在胸前，挥三下。

然后她蹬共享单车去废品站帮张叔分拣瓶子。张叔说她最近很准时，"比闹钟还准。"她把塑料瓶按颜色分三堆——白色的矿泉水瓶、绿色的雪碧瓶、透明的酱油瓶，每一堆都码得四四方方。张叔蹲在旁边抽了一根烟，从烟雾后面看了她一眼，说："丫头，你最近码瓶子比以前更齐了——一个人心里有事的时候，手上就特别想控制点什么。能控制的就拼命控制，不能控制的就假装看不见。你码这么齐，心里是不是有事？"

晓星把最后一个怡宝瓶子放进白色堆最上面，瓶底严丝合缝压在下面那排瓶子的瓶口正中，不偏不倚。然后说了三个字："我不知道。"

第三天傍晚，她再次推开社区银行那扇玻璃门。门把手上贴着一张A4纸——"冬季营业时间调整：上午九点至下午五点半"。她把存折从书包最里层抽出来，隔着防弹玻璃递给柜台小周："存一百二十。"小周对她笑了笑，一边敲键盘一边说："又来了呀——你还差两百多就够一千八百了。"存折递回来时，最后一行的余额跳成了1512.50。她把存折放回书包最里面那一层，拉链拉到头。

走出银行门时她在台阶上站了一小会儿——傍晚五点半的天色正在暗下来，路灯刚亮，橘黄色的光打在银行门头上那块已经掉漆掉了两个半字的招牌上。她忽然想起来：三个月前第一次推这扇门时，手里攥着三张揉皱了的五块钱，手心全是汗，在门口站了五分钟没敢进去。一个动作重复十几次之后就不再需要勇气——它变成了肌肉记忆。

回家后晓星把平板从枕头底下抽出来。屏幕亮起，金鹅的手写体一行一行描出来："这次存得比上一次快。不仅仅是因为流程熟了——是因为你不再需要说服自己这件事是对的。"

晓星盘腿坐在床上，手指在输入框里写字："我爸妈这几天没吵架了。我妈没买新东西。我爸把投资群退了。是不是就好了？"

金鹅的回复慢了将近三秒。屏幕上的光标闪了五秒才开始写字，字迹比平时小了一圈，描画速度也降了下来，像一个人开口前深呼吸了一次。

"嗯。"

停了一下，光标又闪起来——

"改变一个习惯需要的时间，比你从学校骑车到废品站要长得多。你用了三个月才学会不去乱花钱。你妈妈花了四十年才学会被广告说服。要求她在三天之内做到你三个月才做到的事，这不公平。给他们时间。"

晓星把手从屏幕上移开，没有回复。平板放在膝盖上，铝合金外壳从冰凉慢慢变温热的过程，隔着校服裤子一层一层渗进皮肤。她记得这个温度——三个月前第一次在金鹅输入框里写"我不知道家里欠了多少钱"的时候，平板也是从凉到温、再从温到凉，来来回回，像一个人在犹豫要不要告诉她真相。今天平板变温了以后没有变凉——她腿上的热量持续传导给铝合金，直到它彻底失去了冰凉的触感。

周五晚上，一家三口坐在客厅看电视。本地台播一个民生节目，记者采访办了预付卡之后店家跑路的老太太。老太太对着镜头擦眼泪，手里攥着一张面值八千的美容卡。"门关了门上贴着转租——说的能用两年，用了不到三个月——"电视外，王秀兰的睫毛动了一下幅度很小，像被冬天的风忽然吹过。她把遥控器从林建国手里拿过来按了两下，换到动物世界。屏幕上非洲草原一只瞪羚被三只鬣狗围住，鬣狗的叫声从喇叭里传出来，尖锐短促，和刚才民生节目里老太太的哭声用了同一个音高。王秀兰把腿从沙发上收拢了一点，脚踩在茶几底下的横梁上。

林建国从裤兜里掏出手机，解锁，拇指划了两下——很快锁屏。锁屏时力道比平时大，拇指按在电源键上的力度让壳子边缘那道裂口又多往外裂了大概零点几毫米。晓星余光扫到屏幕——是个新闻客户端，首页推荐栏里有一行标题，两个字被加粗标红："数字货币"。

他把手机揣回口袋，站起来走到阳台上，没有点烟，没有打电话。就站在寒风里，两只手插在袖子里，头顶横一根不锈钢晾衣杆，上面挂着两件洗了没干的校服和一双滴水的运动袜。校服滴下来的水在瓷砖上洇出两个相连的深色椭圆——一个是他女儿的校服滴的，另一个也是。他低头看了一会儿那两摊水渍，直到校服不再滴水了才转身。

奶奶从厨房端出一碗热红豆汤，放到茶几上。放了冰糖和陈皮，碗底沉着七八颗煮开了花的红豆，被端起来时豆子在碗底轻轻转了一圈，像沉在水底的几条红色小鱼翻了身。晓星用勺子舀了一口——红豆的甜、冰糖的甜、陈皮的回甘，三种甜在嘴里各自待了不同的时长，最久的是回甘。

"奶奶——甜。"

"多喝点。锅里还有。"奶奶把手放在晓星的后脑勺上。那个位置晓星从小被摸到大，手掌心的温度透过薄薄一层白发和更薄的头皮渗进颅骨，是她在这个家里接收到的所有信号里唯一不需要解码的。她低下头又喝了一大口。红豆汤顺着喉咙往下滑，经过胸口时和金鹅刚才说的那句话撞了一下——"给他们时间"——撞完之后两样东西各自散开。红豆汤变凉了，话还是热的。

晚上十点。晓星写完作业，把平板从枕头底下拿出来。翻开记账本到最新一页——收入栏填了：浩浩接送费四十元、废品站帮忙三十五元。她在合计那一行用铅笔写了一个数字——1757.50——金鹅账户里连本带利的全部金额。写完用橡皮擦掉，又写一遍，笔尖在7和5之间停了不到一秒，稳稳画过5的弯钩收笔。新笔迹比第一次重，橡皮没擦干净的铅笔淡痕叠在底下，像一张旧发票的复写纸底层。合上记账本，关台灯，钻进被子。

黑暗中她听见客厅里电视的电流底噪——很轻，是开了一晚上没人看、在信号空窗期自动跳转蓝屏后发出的持续性嗡嗡声。她闭上眼睛，脑子里还在转金鹅那句话："不公平。给他们时间。"道理懂了，但懂了之后反而更堵。她把两件事并排放在心里——公平和不公平、希望和失望——像记账本上收入栏和支出栏各填一个真实的数字。两栏数字不相抵，但都是真的。

半夜被厨房一声极轻的碗柜关门声弄醒。她翻身，从门缝底下看到走廊上一道正在移动的蓝光——手机屏幕。光从走廊这头慢慢移到阳台那头，纱门被推开，滑轮在轨道上发出一声干涩的摩擦——和之前夜晚爸爸去阳台看手机时的声音完全相同。接着是打火机点火的声音，砂轮火石摩擦之后被拇指拨动的持续性沙声：摩擦、点火、停一瞬、松手。林建国在阳台点了一根烟。

他没有打电话。把手机屏幕对着自己，蓝光打在他脸上，把他鼻梁和眉骨之间那一截在吸顶灯下看不见的轮廓打出了整张脸唯一的三维边界。看了一会儿，掐掉烟，锁屏，装进裤兜。转身进屋时纱门滑轮的摩擦声和推出去那一次完全对称，像把一个动作倒放了一遍。他把客厅电视关了——那声持续整晚的电流底噪忽然消失后，屋子安静得像一只被放进水里的耳朵，所有频率都被同一层液体封住。

晓星把手伸到枕头底下——平板还在。指尖摸到那道从右上角斜劈到左下角的裂纹，顺着裂纹往下滑到充电口旁边被反复插拔磨出银色铝边的接口。铝边是凉的——凉的让她踏实。她在心里对自己说了一句话，没出声，只动了动嘴唇："路还长——我知道。"

窗外路灯的光从窗帘缝隙里挤进来——窄窄一条橘黄色，落在书桌上合着的记账本封面上。封面上被她用蓝色圆珠笔反复描过三个月、已经磨出金属般光泽的鹅的轮廓，在钠灯光下泛着一层极淡的金黄色冷光。翅膀边缘被光勾了一道细线——比周围亮一个色号。

再过一周是期末考试。再过一个月是春节。晓星把被子往上拉了拉，盖住肩膀。走廊尽头是父母紧闭的卧室门，厨房里奶奶炖的红豆汤还剩半锅，冰箱门上那道怎么都擦不掉的胶痕在黑暗中什么都看不见。但晓星知道它在那里，就像知道阳台上的烟今晚不是最后一根。她把脸埋进枕头，枕芯里的荞麦壳在耳廓边缘簌簌响了一声——像一只鹅在看不见的地方扇了一下翅膀。
