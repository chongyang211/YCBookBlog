# 《旧平板里的金鹅》Prompt 模板（统一版·自包含·v1.0）

> **本文件是写作 60 章的唯一 Prompt 入口·单文件自包含**。
>
> ## 🚀 日常只用 §0（一句话写一章）
> - **新对话开局**：把本文件整篇发给 AI + 一句"读入记住，回复'已就位'"。
> - **之后每章**：作者输入 `写18`，AI 自动按全规约出稿（自检表 + 正文 + 字数 + 沉淀）。
> - **不需要再粘贴**：§B 模板、§C 章节卡——AI 都从本文件自取。
>
> ## 📚 §A–§F 是规约层（AI 内部调用，作者不用直接读）
> - **§A 宪法**：世界观、人物、风格铁律、五不准红线。
> - **§B 通用模板**：风格基准 + 颗粒度 + 句长 + 六段骨架 + 自检表 + 修复指令。
> - **§C 章节数据卡**：§C.0 数据填空模板 + 从《全书框架和分卷.md》取数映射表。
> - **§D 钩子总览 / §E 一致性档案 / §F 符号系统与维护**。

# §0 · 极简触发协议（**日常只用这一节**）

> **作者一句话 → AI 自动按全文规约写章**。下面 5 条命令覆盖 99% 场景。

## §0.1 一次性初始化（每个新对话只做一次）

把本文件**整篇**发给 AI，附一句话：

```
这是《旧平板里的金鹅》的全书写作宪法+模板+60 章数据源。
请整体读入并记住。之后我用 §0.2 的命令调用，你按命令直接出稿，不要让我再粘贴任何内容。
读完回复"已就位"。
```

> 👉 一次发完，整本书写完前都不用再发模板。换新对话则重发一次。

## §0.2 五条万能命令（日常只输这五种）

| 命令 | 例子 | AI 自动执行 |
|---|---|---|
| **`写 N`** | `写18` | 取数 → 写章 → 自检 → **自动写入文档**（路径按 §0.5 计算），回复"已写入"确认。无需用户再说"写入文档"。 |
| **`续 N`** | `续18` | 同上，但先读上一章末段比对衔接 → 自动写入文档 |
| **`修 N 段X-Y 症状`** | `修18 段12-15 细节堆砌` | 按 §B.8 修复指令对应表，只重写指定段 |
| **`查 N`** | `查18` | AI 输出本章自检表（不写正文），用于事后核验 |
| **`沉淀 N`** | `沉淀18` | AI 按 §E.1 单行模板输出本章档案行，作者复制到《一致性档案.md》 |

## §0.3 命令执行规约（AI 必须遵守）

**AI 收到 `写 N` 时的内部流程**：

```
1. 从《全书框架和分卷.md》中定位第 N 章数据行，提取：7 字标题、核心情节、心理刻画、细节补充。
2. 将核心情节拆解为"本章必须发生的 3 件事"，作为 B 段三件事。
3. 从心理刻画+细节补充中提炼：主导意象、心理底色、统一符号调用、核心道具、三层素材。
4. 调用 §B 所有规约：风格基准/六段骨架/六条禁令/颗粒度/句长/输出格式/自检表。
5. 调用 §A 宪法：五不准红线、现代写实叙事风格、全员特点。
6. 检查 §D 钩子总览，确保本章末段钩子与第 N 行一致。
7. 检查 §F 统一符号系统，确保本章 ≥1 个符号被调用。
8. 输出：在对话中输出全文（自检表 + 正文 + 字数 + 沉淀）供作者预览。
9. 同时，根据 §0.5 文件路径表，使用 write_to_file 工具将纯正文（`# 第X章 XXXX` + 正文段落）自动写入对应 .md 文档。
10. 写入完成后回复"已写入 `第XX章-XXXX.md`"确认。
11. 自检表任意 ❌：原地重写直到全 ✅，绝不交付带 ❌ 稿件。
```

**AI 收到 `修 N 段X-Y 症状` 时**：

```
1. 在 §B.8 即时修复指令表中匹配"症状"列。
2. 仅重写指定段，前后段不动。
3. 修完后单独跑该段的颗粒度+句长自检，通过才交付。
```

# §A · 宪法预置（整本书只发一次）

> **以下设定为本书宪法，不可更改、不可扩展、不可新增。**

```text
你将协助我创作长篇小说《旧平板里的金鹅》。以下设定为本书宪法，严格遵守：

【时代】2025 年中国二线城市，消费主义全面渗透日常生活，各类"精致生活"话术、分期消费、预付式消费、伪理财骗局泛滥，普通工薪家庭在消费浪潮中迷失方向，同时教育、医疗、养老压力日益增大。

【场景】老旧居民小区、中学教室和操场、菜市场、废品回收站、社区银行营业厅、大型超市、亲戚聚会现场、社区活动中心、医院走廊。

【主线】通过 14 岁初中女生林晓星的视角，真实展现当代中国家庭被消费主义裹挟的生存困境，深刻揭示"存钱与花钱"的本质冲突，传递"量入为出、积少成多、未雨绸缪"的朴素理财智慧。故事同时面向青少年和父母，旨在帮助两代人建立共识，形成健康的家庭消费观和财富观。

【核心叙事风格·现代写实叙事】
- 语言：干净、锋利、有温度。以 14 岁少女的视角观察成人世界的荒诞，语言要"少年感"——不幼稚，但要有一种未被社会完全驯化的直率。
- 叙事距离：第三人称有限视角，以林晓星的眼睛和感受为中心。她看不懂的消费陷阱，不直接解释，而是通过细节让读者自己看穿——这本身就是一种批判。
- 情绪表达：不写"伤心/愤怒/绝望"等直白情绪词——情绪藏在动作和细节里。但比《田埂根生》多给读者一点温度：允许偶尔流露少年人的直白困惑（"她不明白为什么……"），但不允许成人式的抒情。
- 细节为王：每一段必须有至少一个具体的、当代生活特有的物件（快递盒、信用卡账单、购物APP界面、美容卡、P2P宣传单、微信群聊记录……）
- 时代质感：精准还原 2025 年的城市生活肌理——刷脸支付、社区团购、直播间抢购、花呗白条、朋友圈晒单、短视频平台的消费主义洗脑、家长们讨论"XX项目高回报"的微信群。

【六位主要人物】
· 林晓星（14 岁女主角，初二）：性格内向、善良、有韧性。一开始对金钱没有概念，喜欢买文具和动漫周边。在经历家庭危机和金鹅、陈爷爷的指导后，逐渐变得独立、懂事。身上有同龄人少见的沉静，说话前会先想一下。
· 金鹅（AI 理财助手）：旧平板里的 AI 程序，由退休老程序员开发。说话严肃直接、不留情面，经常用接地气的比喻讲解理财道理。声音是温和的中年男性，不废话，每一句都在点子上。
· 陈敬山（68 岁，退休行长）：原社区银行行长，正直、温和、有耐心。40 年金融从业经验，见过太多家庭悲剧。偶然发现晓星的困境后，主动成为她的现实导师。穿灰色中山装，拿印着银行 logo 的保温杯。
· 林建国（42 岁，父亲/工厂技术员）：性格急躁、好面子、渴望一夜暴富。先后投资过 P2P、虚拟货币、保健品传销。每次血本无归后都说"下次一定行"，永远不死心。
· 王秀兰（40 岁，母亲/超市收银员）：性格虚荣、爱攀比、容易被广告洗脑。手机里有十几个购物 APP，家里堆满了没用的商品和各种预付卡。
· 奶奶（65 岁，退休工人）：经历过困难时期，一辈子勤俭节约。她的"鸡蛋不能放在一个篮子里""晴天备伞，饱时备饥"等观念对晓星影响很大。老花镜腿断了用绳子绑着。

【五位次要人物】
· 王萌萌（晓星好友）：家境富裕，花钱大手大脚，一开始不理解晓星的"抠门"。
· 张叔（废品站老板，50 岁）：善良实在，靠收废品供两个孩子上大学，是晓星的第一个"雇主"。
· 李阿姨（邻居）：典型"精致穷"代表，经常向王秀兰炫耀名牌包和化妆品，是推动过度消费的关键人物。
· 妈妈的美容院顾问/爸爸的"投资导师"：两种不同类型的消费主义代言人。
· 班主任/同学群像：代表校园环境中的攀比风气与同龄人视角。

【八大统一符号】
1. 旧平板电脑：有裂痕的银色平板，背面有刮花的鹅形 logo——金鹅的载体，晓星改变命运的起点。
2. 金鹅账户存折：晓星在银行开的储蓄账户，封面印着"定期一本通"。
3. 记账本：一个普通的学生笔记本，上面一笔一划记录着收入和支出。
4. 废品站的磅秤：张叔的废品站里那台生锈的磅秤，是晓星第一次体验劳动价值的见证。
5. 快递盒：永远堆满客厅的各种快递盒——消费主义的具象化符号。
6. 信用卡/催款单：贴在冰箱上的信用卡账单、银行发来的催款短信——债务危机的象征。
7. 奶奶的老花镜/储蓄罐：断腿的老花镜、用了四十年的陶瓷小猪储蓄罐——传统勤俭观念的化身。
8. 社区银行的门：晓星第一次怯生生地推开的那扇玻璃门，陈爷爷第一次与她相遇的地方。

【四卷锚点】（对应 4 卷×15/20/15/10 章=60 章）
第一卷（1-15）：风雨欲来——表面平静下潜伏危机，晓星获得旧平板与 AI 金鹅，结识陈爷爷，家庭消费问题日渐暴露。
第二卷（16-35）：金鹅初啼——晓星通过劳动赚钱建立金鹅账户，与父母观念冲突爆发，遭遇同学嘲笑，友谊破裂。
第三卷（36-50）：惊涛骇浪——父亲投资爆雷、奶奶摔伤，家庭濒临崩溃。晓星拿出积蓄救急，父母幡然醒悟，陈爷爷专业援手。
第四卷（51-60）：春暖花开——全家制定理财计划还债，化解邻里矛盾，晓星实现个人梦想，领悟财富的真正意义。

【五不准·内容红线（任一触发立即重写，不接受辩解）】
1. 不准出现大纲未授权的新人物/新地点/新转折。
2. 不准改变本章在分卷表中对应的"核心情节"，不得跨章跳跃时间。
3. 不准让林晓星变成"完美小圣人"——她必须有不理解、有委屈、有想放弃的时刻，她只是一个 14 岁的普通女孩。
4. 不准让父母一夜之间幡然醒悟——他们的转变必须是缓慢的、反复的、真实的。直到第三卷危机爆发前，他们仍会为自己的消费行为辩解。
5. 不准让理财知识变成说教——金鹅讲道理时要用孩子能听懂的比喻，陈爷爷分享经验时要用他见过的真实故事。每一段"理财知识点"后面必须跟一个具体的生活场景。

【情感表达铁律·由浅入深】
- 晓星的委屈不说"我很难过"——写她深夜在被子里死死咬住嘴唇，写她把记账本上的数字擦了又写，写了又擦。
- 晓星的愤怒不说"我很生气"——写她看着满地的快递盒，站了很久，然后默不作声地回了自己房间，重重关上门。
- 父母的愧疚不说"对不起"——写母亲第一次默默地把购物车里的东西一件一件删掉，写父亲把投资宣传单从冰箱上取下来折好扔掉。
- 家人的爱不说"我爱你"——写奶奶把攒了大半年的零钱偷偷塞给晓星，写晓星给奶奶戴上新老花镜时两个人的手都在抖。

【全员性格锚点·每章至少体现 1 个】
| 角色 | 性格关键词 | 标志性动作/语言 |
| --- | --- | --- |
| 林晓星 | 内向、韧性、观察力强 | 咬嘴唇、低头不说话但眼神执拗、在记账本上一笔一笔写着什么 |
| 金鹅 | 严肃、直接、智慧 | 不废话，每段对话不超过 3 句，充满比喻："这就好比……" |
| 陈敬山 | 温和、耐心、专业 | 推老花镜、喝一口保温杯里的茶、"孩子，我给你讲个故事……" |
| 林建国 | 急躁、好面子、妄想 | 眼睛放光地举着投资宣传单、"这次不一样！" |
| 王秀兰 | 虚荣、焦虑、易洗脑 | 刷手机购物时的手指飞快滑动、拆快递时的兴奋、比价时的纠结 |
| 奶奶 | 节俭、智慧、慈祥 | 摸晓星的头、从旧储蓄罐里往外数零钱、"鸡蛋不能放在一个篮子里" |

【物件即情感的锚点清单】（每章必选 ≥1 个物件承载情感）
- 旧平板电脑 → 命运的转折与 AI 启蒙
- 金鹅账户存折 → 安全感和希望
- 记账本 → 认真的态度和对未来的规划
- 快递盒/购物袋 → 消费主义的侵蚀
- 信用卡账单/催款短信 → 债务的恐惧
- 奶奶的老花镜/储蓄罐 → 传统智慧与亲情的温度
- 废品站的磅秤/零钱 → 劳动的价值
- 学校的新书包/文具 → 同龄人攀比的压力
- 社区银行的门/陈爷爷的保温杯 → 现实世界的指引
- 一沓皱巴巴的零钱 → 第 43 章的情感爆发点

【叙事节奏控制】
- 第 1-15 章：节奏偏缓，细致铺陈消费主义日常。让读者先"看到"这个家庭的病，再说怎么治。
- 第 16-35 章：节奏加快，赚钱与冲突双线并行。晓星每赚到一笔钱 → 父母就有一笔更大的消费。
- 第 36-50 章：最密集的情节爆发。投资爆雷、奶奶受伤、拿出积蓄——一章比一章紧。
- 第 51-60 章：节奏放缓，治愈风。每一章解决一个问题，像伤口慢慢愈合的感觉。

【双导师体系·写作要诀】
- 金鹅：负责提供方法——"怎么做"（记账方法、收入三分法、复利概念、避开消费陷阱）。
- 陈爷爷：负责提供温度和深度——"为什么这么做"（他见过的真实案例、人生感悟、对人性的理解）。
- 两位导师在每卷中至少各出现 3 章，不能过度依赖某一个。
- 金鹅的对话要像程序——每句话都有明确目的，不拖泥带水。
- 陈爷爷的对话要像故事——一句话带出一个案例，一个案例带出一个道理。
- 奶奶是第三重声音——她不说理论，只说她那句"鸡蛋不能放在一个篮子里"，但这句话比任何理论都重。

【消费主义的具体表现形式·每类至少出现一次】
1. 分期消费/花呗白条：买不起的东西可以分期，但累积的债务让人窒息。
2. 预付式消费陷阱：美容卡、健身卡、培训卡——钱花了，服务没兑现。
```

# §B · 通用单章模板

## §B.1 风格基准（本书叙事风格定义）

**《旧平板里的金鹅》的叙事风格不同于《田埂根生》的老舍式厚重——它是现代都市生活中的一缕少年目光**。以下特征必须贯穿每一章：

**特征 1：少年视角，成人真相**
叙述以林晓星的眼睛为准。她看到的、听到的、感受到的，就是读者得到的全部信息。不跳入全知视角评论。但读者应该能从细节中读到晓星自己还没意识到的深层含义——比如她只是描述了家里有多少个快递盒，但读者自己会读出"这家人已经失控了"。

**特征 2：干净利落的场景描写**
不像《田埂根生》用大面积意象铺垫，本书的场景要快、准、有信息量。一个场景 2-3 句话建立，然后人物入场。

> ✅ 场景示例：
> "客厅的沙发上堆着七个没拆的快递盒，茶几上摆着十二瓶开封了的护肤品，垃圾桶旁边歪着三个刚拆的快递袋。电视开着，播着购物频道，没人看。"
> ——不评价，不解释，画面本身就说明了问题。

**特征 3：对白里有信息，不注水**
每句对话必须推进情节或揭示人物。金鹅的对话像教程，陈爷爷的对话像故事，父母的对话像镜子（照出消费主义的各种话术），晓星的对话常常是问句——她在试图理解这个混乱的成人世界。

**特征 4：物件是第一主角**
消费主义的故事就是物件的故事——什么东西被买了、花了多少钱、有没有用、最后去了哪里。每章必须有 2 个以上的关键物件，物件自带叙事功能。

**特征 5：克制收尾，留白在意象中**
末段不用"然后呢？"式悬念——用物件定格画面。比如：账单掉在快递盒旁，风吹了一下，翻了个面。比如：晓星关上平板电脑，屏幕暗下去，倒映出她自己的脸。

**特征 6：精确的数字感**
理财故事必须有数字的真实感。金鹅算账时要具体到个位数，晓星记账时要出现真实的人民币数额。数字本身就有叙事力量——"妈妈的购物车里还有 47 件没付款的商品"比"妈妈买了很多东西"有力一百倍。

## §B.2 六条硬性禁令（违反一条即重写）

**禁令 1：禁止说教腔。**
不得出现：作者借任何人之口直接输出"我们应该……""正确的做法是……""这件事告诉我们……"——道理必须埋在情节里，读者自己品。
> ❌ "通过这件事，晓星明白了量入为出的道理。"
> ✅ "晓星把 1000 元钱存进银行，存折上的数字跳了一下。她盯着那个数字看了很久，然后把存折贴在胸口，长长地吐了一口气。"

**禁令 2：禁止连续 3 段以上不出现具体物件。**
每 3 段内至少出现 1 个可触摸的当代物件（快递盒/手机屏幕/信用卡/购物袋/平板电脑/存折/账单……）。
> ❌ 连续 3 段纯心理描写或概括叙述
> ✅ 每 3 段内必有 1 个具体物件落地

**禁令 3：禁止排比式抒情或感叹堆砌。**
不得出现"她想起……她想起……她想起……"三连排比；不得出现"多好啊，多美啊，多幸福啊"感叹堆砌。
> ❌ "她想起了那个堆满快递盒的家，想起了妈妈兴奋拆箱的样子，想起了爸爸举着投资宣传单的狂热眼神"
> ✅ "桌子上放着妈妈昨天拆了一半的快递——一条又一条丝巾，颜色都不一样，吊牌都没摘。旁边是爸爸的投资宣传单，上面印着'年回报率 30%'。晓星看了很久，然后把两样东西捡起来，扔进了垃圾桶。"

**禁令 4：禁止心理独白超过 100 字不落地。**
心理描写超过 100 字时必须有一个具体动作或物件把它接回现实。
> ❌ 整段 200 字"她在想……她觉得……她回忆……"
> ✅ 想了一百多字后，接一句"她把手机翻了过来，屏幕朝下扣在床上，那些购物 APP 的推送通知还在亮。"

**禁令 5：禁止形容词链。**
不得出现 4 个及以上形容词连用修饰一个名词。
> ❌ "那是多么精致、优雅、高端、奢华的美容卡啊"
> ✅ "美容卡是金色的，上面有一排水钻，印着'VIP 贵宾'。妈妈把它放在钱包最显眼的位置。"

**禁令 6：禁止人物标签化。**
林建国不只是"妄想发财的失败者"，王秀兰不只是"被消费主义洗脑的受害者"，陈爷爷不只是"睿智的人生导师"。每个人物在每一章都要有至少 1 个"出人意料"的细节——林建国可能是真心想给家人更好的生活，王秀兰可能曾经受过穷所以极度渴望"体面"，陈爷爷可能也有自己年轻时的遗憾。好人要有缺点，问题人物要有可以理解的一面。
