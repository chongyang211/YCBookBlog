# 第81章 疫后归家解心结

解封后的武汉还在恢复——街上的人多了，可比起封城前还是少了大半。店铺开了一半，卷帘门上的封条撕掉了可胶痕还留在铁皮上，一道一道的竖白横在暗红色的铁锈中间，像一架弹了一半就停了下来的梯子。

根生和秀莲回河南老家的日子定在四月十六号。陈凯帮他们买的票——不是火车票，是长途大巴。武汉到周口的线路刚恢复运营，一天只有一班，早上七点从汉口发车。陈凯把两张车票从打印机里抽出来的时候手指在票面上停了一下——票是两张，一张全票一张半票，全票上印的名字是陈根生，半票上印的名字是李秀莲。他把两张票并排放在茶几上，忽然想起二十三年前——一九九三年正月初六，他爹也是从这个方向走的，只不过那次是从周口往武汉，这次是从武汉回周口。方向反了，路是同一条。

秀莲从封城第一天就念叨回家。后来当志愿者顾不上念叨了，后来住院不敢念叨了，后来出院了念叨又回来了——每天早上给泡沫箱浇水的时候说一句，吃饭的时候说一句，睡觉前还要说一句。根生说你跟我说了多少遍了我知道了。秀莲说你知道了你不买票。根生说我让凯凯买。秀莲说凯凯忙。根生说再忙买两张票的时间总有。两个人为这件事在茶几前面拌了三天嘴——不是吵架，是那种过了大半辈子的两个人之间已经不需要情绪只需要惯性就能往下接的对话。

临走前一天晚上，秀莲把该收拾的东西摊了一客厅。从武汉带回去的东西不多——她的药，他的药单，那只搪瓷缸子，那件在医院走廊上披了半个月的旧毛衣，三颗只剩一颗了的小白兔糖。其余的不带了——泡沫箱带不走，刨子凿子墨斗带得走可太重了留给陈凯，那张全家福留在墙上不摘了，摘下来墙上有个印，印在那里比带回去好。

她把团团的画从泡沫箱旁边拿下来——一共三张：一张是穿白衣服的人衣服上画了一颗心，一张是泡沫箱的菜底下一条棕色土线，一张是用酱油在饺子皮上画的菜连着土。她把这三张画叠好放进那个绣着红花的布包袱里——这个包袱是她结婚时从娘家带过来的嫁妆布，六十年了，里面的红棉花从大红褪成了粉白。她把包袱口扎好，用手指在包袱的布面上顺了一遍——顺到她指腹上那些老茧划过布面时能发出沙沙的声音为止。

四月十六号凌晨五点半，根生站在阳台上浇了最后一次水。他把矿泉水瓶盖子上的五个眼都堵住了——不是被水垢堵的，是自己拿手指把三个眼按住了只留两个往下淋。淋完了把瓶子放在泡沫箱旁边，那棵野草已经长到半臂高了——他把最顶端那片叶子上最后一点路灯光照出来的银圈用手指擦了一下，擦完叶子弹回来在他手指上留下了一小道极淡的绿痕。他说长得好。把它留给团团。

陈凯开车送他们去车站。一路上四个人坐在车里——根生坐副驾，秀莲和晓雅抱着团团坐后排。晓雅把一只塑料袋递给秀莲说里面是她买的两盒降压药和一瓶拜新同，够吃三个月。秀莲接过去说又花钱。晓雅说没多少钱。秀莲把塑料袋放在腿上，一只手攥着袋口一只手放在团团的头顶上。团团靠在秀莲身上睡着了——小孩子起太早，上车颠了两下就把脸埋在秀莲的棉袄里开始打起了小呼。

汉口长途汽车站的人不多。解封才八天，长途线路刚恢复，候车厅里稀稀拉拉坐了不到二十个人，都戴着口罩隔着一排座位坐着。陈凯把两张车票从口袋里掏出来递给根生——根生接票的时候手指在老茧的位置上滑了一下没接住，票掉在了地上。陈凯弯腰捡起来重新递了一遍——这一次他用手把票压进了父亲的掌心里，等父亲把手指合拢了才松开。这个递票的方式跟他小时候根生往他手里塞零花钱一模一样：把东西塞进掌心，等对方的手指合拢了再松手。

秀莲已经蹲下去在跟团团告别了。她把团团的头发从前往后顺着撸了三下，说奶奶回家了你听爸爸妈妈的话。团团说奶奶你不要走。秀莲说奶奶要回去种地了，等麦子熟了叫你爸带你回来看。团团低下头从自己的小书包里掏了半天掏出来一样东西——不是玩具不是糖，是那支被他咬过牙印的铅笔。他说奶奶这个给你，你回家给我画菜。秀莲把铅笔接过来放进自己围裙口袋里——口袋的位置在心口。

陈凯站在候车厅的柱子旁边——不是故意挑那个位置，是无意识地走到了一个能跟父亲单独说话的角落。这根柱子是圆柱形的，表面贴了一层银灰色的铝塑板，铝塑板的接缝上有道半指宽的缝，缝里面塞着一小团被捏扁了的纸巾。他看着那道缝沉默了一会儿——他知道今天不说就再没有更合适的时机了。不是空间没有了——候车厅比封城那八十多天的客厅大了几十倍——是这根柱子提供的那个只有两个人能被彼此完整听见对方呼吸的声学距离，以后再也不会有了。

他说爸。根生抬起头。儿子三十三岁了——他记忆里上一次用这种正式的语调叫他爸还是凯凯七岁刚上小学那天，站在村口那棵大槐树底下仰着头说爸你帮我削个铅笔。之后二十年里，这个"爸"字变成了电话里急匆匆的头一个字——爸我生活费不够了，爸我加班不回来吃饭了，爸你自己保重身体。没有一个"爸"字是完整的，每一个都被后面的内容压成了前缀。

今天这个"爸"字后面没有内容。它自己就是全部内容。所有的字都堵在这个"爸"字的出口上——他准备了无数次的道歉词在这个空旷的候车厅里忽然全忘光了。他记起来的是十七岁那年高三教室窗口外面他爹穿着沾满水泥的工作服蹲在校门口不敢进来的背影，是大学报到那天火车站站台上他爹把自己沾灰的解放鞋往身后藏的那个动作，是封城第七十天他爹穿着不透气的防护服把最后一把葱挂在门把手上的那只被消毒水泡得发白的手。

他张了张嘴，说爸，我这辈子最对不起的人就是你。以前我不懂事，嫌你穷嫌你没本事嫌你给我丢人，我在校门口装作不认识你，在电话里骂你，喝了酒跟你说你没给我好的起点。

他把话停在这儿——不是说不下去了，是把喉咙里那团哽着的东西往下咽了一下。咽下去的声音在安静的候车厅里格外清楚。

停了一会儿他接着说：我知道我说什么都没用了，我欠你的是二十年，还不清了。

根生没有马上说话，把两张车票从口袋里掏出来攥在手心里攥了两秒钟，然后抬起头看着陈凯。儿子比他高了半个头——是什么时候比他高的他不记得了，可能是高二那年春天。反正有一天他忽然发现跟儿子说话不用低头了，得仰头。

他说了一句话——不是想了二十年才想出来的，是二十年前就放在嗓子口等着了，只是儿子一直没给他开口的机会。傻孩子，爸从来没怪过你。你过得好，爸就高兴。他说话的时候还是用那种蹲在田埂上看着麦地的口气——不急不缓，撒种子一样每个字都掂过分量才往外漏。

陈凯的眼眶——不是湿，是整个视线忽然模糊了一下。他这二十年一直在等这句话，又怕听到这句话。怕的不是父亲怪他，是父亲不怪他。他把手臂伸出去把父亲抱住了——这一次跟在泡沫箱前那次不一样。那次是在逼仄的客厅里忽然把父亲的后背拉了过来。这一次是在宽敞得漏风的候车厅里，两个人面对面站着，把二十年所有的嫌弃、愧疚、等待和沉默，用一个拥抱塞进了对方的肋骨之间。

根生抬手拍了拍陈凯的后背——不是摸，是拍。左一下，右一下，左一下。三下。第一下拍在肩胛骨上，陈凯的肩胛骨硬邦邦的——不像是农民的儿子，是个坐办公室的；第二下拍在脊椎旁边，儿子的脊梁骨直直的，比他强——他这句话在心里说了几十年了今天没有用嘴巴说；第三下拍在后心的位置，也就是那个他每天被防护服帽子箍出凹痕的位置对应的那个地方——这一下极轻，轻到像是在拍一个还在襁褓里裹着的婴儿。

松开的时候两个人都没有看对方的眼睛。不是不敢看，是看了就会收不住。陈凯转过身背对着父亲把N95往上推了一下——不是口罩滑了，是想把两个眼眶边上那股热乎乎的东西用口罩的金属条压回去。根生站在原地把手里那两张车票又掏出来看了一眼——票被他的手汗洇湿了两个角，上面印着"武汉""周口"六个黑体字，字的边缘被手指的汗汽模糊了一层。

检票的广播响了。陈凯转过身帮父亲拎起那个蓝底碎花的布包袱——就是秀莲当年打的那床棉被的里子。包袱有点重，不是东西多，是里面的粗瓷碗和搪瓷缸子叠在一起随着包袱被拎起来的动作互相磕了一下，发出一声瓷碰瓷的脆响。他把包袱递到根生手里——这一次没有掉，根生接包袱的动作跟他扛了几十年的水泥袋子一样：手掌从底下往上一托，包袱的重量从掌心传到了肩膀。

秀莲已经走到检票口了，回头看了一眼陈凯和晓雅。她朝团团挥了挥手，团团还睡着——歪在晓雅肩膀上张着小嘴，口水流到了晓雅的袖口上。秀莲从口袋里掏出那支被团团咬过牙印的铅笔，在检票员递来的登记本上签了自己的名字。三个字——李秀莲。每一笔都是歪的，跟三十年前她在结婚登记表上签的那三个字一模一样。签完她把铅笔又放回围裙口袋里，转身往闸机里走。

根生在闸机口停了一下。他回头看了一眼候车厅——不是看陈凯，是透过候车厅的落地玻璃看见了远处光谷广场上那匹白色飞马。飞马在正午的阳光里从雾气里露了全身——不是封城第一天他趴在窗台上看见的那种模糊轮廓，是清楚的，连翅膀上那根最细的翎毛都被阳光勾勒出了一道金色的边。他把这只飞马的画面收进脑子里那个专门贴标签的位置——跟女儿头发的味道、秀莲白头发上的银光、泡沫箱里野草叶尖的夜露一起，贴在同一张标签上。标签上写的是"武汉"。

他转过身上了车。大巴车发动了——轰的一声，跟二十七年前他从村口坐走的这班车的发动机是一种声音。方向是反的，当时是离开陈家村，现在是回去。他把秀莲的包袱放在行李架上，自己坐靠窗的位置——窗玻璃是干净的，没有裂纹没有泥浆干透之后的花纹。他把窗户推开半扇，外面的风吹进来——不是正月的北风了，是四月中旬的东南风，暖的，带着江汉平原上刚翻过的水稻田的泥味。

车开动了。从武汉市区的街道上慢慢往外开——经过了陈凯的公司、经过了秀莲住了半个月医院的那栋楼、经过了封城期间根生跑过上百趟楼梯的小区。车从长江大桥上开了过去，江面在正午的阳光下铺成了一整块被风揉皱了又摊开的碎金。

根生看着窗外的江水，忽然从口袋里掏出那张被手汗洇湿了角的车票——背面是空白的。他把铅笔从胸口口袋里拿出来，用舌头把笔尖抿了一下，在背面写了七个字。不是写——是画，一笔一画地用那只老手把自己这辈子写给儿子的最后一句话描了出来：好好过日子别惦记家。七个字，一个句号。他点句号的时候笔尖把车票戳了一个比米粒还小的小洞。

他把车票重新折好放进口袋里——不是扔掉，是留着。留着在陈家村那间土坯房的枕头底下压着，等哪天想儿子了再拿出来，用那个屏幕被磨得只剩巴掌大的旧手机对着裂纹给凯凯打电话。

秀莲靠在椅背上歪着头睡着了——头靠着根生的肩膀，枕在肩窝那个刚好能嵌进她额头的凹槽里。根生把外套脱下来盖在她的膝盖上，把窗帘拉上半扇，又推开了一点窗。四月中旬的风从麦田的方向吹过来，灌满了整个车厢。
