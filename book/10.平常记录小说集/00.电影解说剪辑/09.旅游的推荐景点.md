# 荆州游

根据您的要求，为您整理了荆州五大类热门打卡地的信息，并附上开放时间，方便您规划行程。

### **1. 荆州热门旅游景点**

| 景点名称 | 开放时间 |
| :--- | :--- |
| **荆州古城（含宾阳楼、张居正故居、关帝庙等）** | 旅游区整体：周一至周四 08:00-17:30，周五至周日 08:00-20:00；宾阳楼光影秀：每周五、六、日 19:00, 19:30 |
| **洈水景区** | 08:30-17:00 |
| **洪湖悦兮半岛国际温泉度假村** | 12:00-22:00（以当日为准） |
| **瞿家湾（湘鄂西革命根据地旧址）** | 全天开放 |
| **楚王车马阵景区** | 冬令时（11月1日起）：08:30-17:00 |
| **荆州方特东方神画** | 周一至周五 09:30-17:30，周六至周日 09:00-18:00（冬季运营时间可能调整，请以官方公告为准） |
| **元妙观** | 08:30-17:30（17:30停止入园） |
| **曲尺河温泉度假村** | 通常11月10日开园，具体时间请咨询景区 |
| **船奇荆江游船** | 20:00-21:30（以当日航班为准） |
