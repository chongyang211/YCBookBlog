别在熬夜中自豪，平安和健康

根据这个话题，帮我写一篇口播视频的文案，要顺畅。文案大概500字左右，最多不超过550字。

1. 开头要吸引人，要求观点鲜明，可以下个钩子
2. 有点争议但是正能量
3. 要有反差，观点鲜明，带点口语化，不要有1，2，3这种说教做法
4. 最后保证话题足够新颖，正能量
5. 要揭露人性，可以写的有争议点
6. 结尾需要互动引导
7. 主要文案画风，需要接地气
