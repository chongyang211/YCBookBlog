## 50 条方法论速览

本专栏覆盖了毛选中最核心的 50 条方法论，按五层结构组织：

```
哲学层（看世界）→ 战略层（定方向）→ 策略层（选打法）→ 组织层（带队伍）→ 修养层（修自己）
```

## 建议阅读路径

1. **速通路线**（2小时）：01 框架地图 → 01 方法论地图 → 各卷导读 → 完成
2. **精读路线**（2周）：每天一篇，从 02 到 06 按顺序读
3. **按需查阅**（工具书式）：遇到具体问题对号入座，翻对应那层的方法论
