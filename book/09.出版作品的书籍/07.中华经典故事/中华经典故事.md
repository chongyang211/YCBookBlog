# 《古事照今：中华经典里的人生答案》全书完整框架设计

> 适配 40–55 万字体量。一句话讲清这本书：**不做古文翻译工，只做经典与当代的搭桥人——用中华千年经典故事，回答当代人过不去的那几道坎。**

---

## 一、全书核心定位与差异化

### 核心定位

国内首套**「以中华经典故事为锚，回应当代人现实困境」**的大众人文读物。不注释、不搬运、不说教，只做一件事——**把沉睡在古籍里的故事，变成可以照进当下人生的一束光**。让中华经典从"博物馆里的陈列品"，变成"书桌上的人生工具书 + 深夜里的精神栖息地"。

### 目标读者

20–45 岁的都市人群（职场人、父母、青年学生、传统文化爱好者）——他们有自我成长的渴望，被现实困境反复拉扯，对传统文化心向往之，却被晦涩古籍挡在门外。

### 核心差异化（五条硬壁垒）

| 差异点 | 市面同类书 | 本书的做法 |
| :--- | :--- | :--- |
| 内容逻辑 | 原文 + 白话翻译的流水线 | 每个故事精准对应一个当代困境，只做「故事 → 解法」的搭桥 |
| 人物塑造 | 脸谱化、非黑即白（完美/纯恶） | 深挖两难、挣扎、人性灰度，让古人有呼吸感 |
| 叙事视角 | 宏大叙事、王朝兴衰 | 聚焦普通人日常——友情、婚姻、职场、内耗、选择 |
| 阅读结构 | 按朝代 / 题材死板分类 | 按当代人生路径分卷，神话 / 历史 / 诸子 / 文人 / 成语全打通 |
| 使用方式 | 一次性读物 | 既可通读系统成长，也可按困境随手翻——一章一解法 |

## 二、全书叙事主线：六卷一气贯通

这本书不是 48 个零散故事的拼盘，而是一条贯穿当代人完整生命历程的**成长暗线**：

> **认识自己 → 看懂他人 → 成事立足 → 安顿家庭 → 修炼内心 → 抵达自由**

- **卷一 认识自己**：一切修行的起点——先读懂自己这个人
- **卷二 人心江湖**：走出自我，开始与他人共处
- **卷三 成事生存**：在真实世界里立足、谋生、长出能力
- **卷四 家庭心安**：从外部厮杀回到温暖港湾，经营最亲的关系
- **卷五 情绪修行**：向内对付自己最难缠的敌人——情绪与执念
- **卷六 终极选择**：走到人生岔路，在生死荣辱间给出自己的答案

每一卷都有一段"卷引"承上启下，六卷连起来，就是中国人千百年来默认走完的一条完整人生路径。

## 三、全书体量与整体结构

### 体量规划

全书锁定 **45 万字**（可在 40–55 万区间灵活调整），共分「序篇 + 六大主体卷 + 跋篇」。

- 每卷 **12 章**（较原 8 章扩充 50%），全书共 **72 章**
- 单章正文约 5500–6000 字，卷首语 1500 字
- 序篇 1.5 万字，跋篇 5000 字

### 单章固定结构（5 段式）

**故事重构（2000 字）→ 古事今解（1500 字）→ 现实映射（1500 字）→ 当代案例（500 字）→ 心有所悟（500 字）**

## 四、分卷详细框架

### 序篇：我们为什么在今天，还要读中华经典故事？（1.5 万字）

1. **戳破三个误区**：经典不是老古董、不是考试素材、不是文化装饰——它是中国人写了几千年的人生答案
2. **本书的核心逻辑**：以千年古事，照当下人生；不做翻译，只做搭桥
3. **本书的两种读法**：通读完成一次人生系统升级 / 按困境随手翻解决此刻的难题
4. **写给读者的一封信**：愿你在千年故事里，找到属于自己的那个答案

### 卷一：认识你自己——经典里的自我成长课（7.2 万字 / 12 章）

**卷引**：人这一生，最难的从来不是读懂世界，而是读懂自己。你有没有过这样的时刻——被外界的评价裹挟、被原生家庭的期待绑架、被同龄人的节奏逼到喘不过气？两千多年前，愚公、哪吒、周处、颜回们都曾在这里挣扎过。他们的故事，是我们照见自己的第一面镜子。

**核心映射**：自我认知、自卑内耗、成长焦虑、原生家庭、天赋焦虑、自我否定。

| 章 | 章节标题 | 中华经典故事与情节 | 故事核心（破局解读） | 现实映射（以史为鉴） |
| :--- | :--- | :--- | :--- | :--- |
| 1.1 | 《愚公移山》：不是教你死磕，是教你稳住自己 | 愚公年近九十，带子孙凿太行、王屋二山，面对智叟"汝之不惠甚矣"的嘲讽，笑答"子子孙孙无穷匮也"。 | 不被外界评价牵着走，锚定自己的目标节奏 | 35 岁危机、同龄人碾压下的自我怀疑，如何建立稳定内核 |
| 1.2 | 《哪吒闹海》：从"乖孩子"到"我是谁"的觉醒 | 哪吒闯祸闹海、杀敖丙，父亲李靖为息祸逼其自戕，哪吒剔骨还父、莲花重生。 | 挣脱"被定义的人生"，与父母、与自己真正和解 | 被原生家庭期待绑架的年轻人，如何活出独立的自己 |
| 1.3 | 《邯郸学步》：模仿到最后，弄丢了自己 | 寿陵少年羡慕邯郸人走路姿态优雅，一味模仿，最终连原来的走法都忘了，只能爬回故乡。 | 盲目崇拜优秀他人，会把自己连根拔起 | 跟风网红职业、模仿他人生活方式的焦虑，如何找回自己的节奏 |
| 1.4 | 《周处除三害》：和不堪的过去握手言和 | 周处年少横行乡里，被列为"南山虎、长桥蛟、周处"三害之首，后投军、改过自新，官至御史中丞。 | 真正的成长，是敢于回头面对不堪的自己 | 过往失误、人生污点带来的自我否定，如何重启人生 |
| 1.5 | 《东施效颦》：你的"不完美"才是光芒 | 东施效仿西施捧心蹙眉，反被乡人惊恐躲避。 | 向外求美，只会暴露向内的空洞 | 容貌焦虑、身材焦虑、身份焦虑，如何建立内在价值体系 |
| 1.6 | 《夸父逐日》：意义从来不在终点 | 夸父与日竞走，渴饮河渭，水不足，北饮大泽，未至道渴而死，弃其杖化为邓林。 | 过程即答案，热爱本身就是意义 | 考研、考公、升职失败后的崩塌，如何与"不完美的结果"和解 |
| 1.7 | 《伤仲永》：天赋是礼物，也可能是枷锁 | 方仲永五岁能诗，父亲每日带他四处拜访邀赏，不使学；十二三岁诗作已不如前，二十岁"泯然众人矣"。 | 没有长期主义，任何天赋都是耗材 | 天赋焦虑、起点焦虑，普通人靠什么抵达远方 |
| 1.8 | 《孔子见老子》：承认"无知"才是真成熟 | 孔子赴周问礼于老子，老子以"良贾深藏若虚，君子盛德容貌若愚"相赠，孔子归而三日不言，叹老子"其犹龙邪"。 | 越有分量的人，越懂得空杯 | 认知闭环、固执己见、知识焦虑，如何保持终身成长 |
| 1.9 | 《颜回问仁》：向内求，不向外争 | 孔子问弟子之志，子路争先言勇，颜回只答"愿无伐善，无施劳"，甘守陋巷好学不迁怒。 | 不攀比、不邀功，把自己活扎实 | 朋友圈精致焦虑、社交表演，如何回到自己的节奏 |
| 1.10 | 《庄子·井底之蛙》：打破认知的那口井 | 井蛙自夸一井之乐，东海之鳖以大海千里之阔相告，井蛙愕然自失。 | 真正的成长，是亲手凿破头顶那块天 | 小圈子信息茧房、"以为见过世界"，如何主动走出舒适区 |
| 1.11 | 《范仲淹划粥断齑》：起点低不是宿命 | 范仲淹少时家贫，在长白山醴泉寺苦读，每日煮粥一盆隔夜划四块，佐咸菜数茎，寒冬不怠。 | 真正的翻盘，是把低起点活成长跑 | 小镇做题家、普通家庭出身的逆袭焦虑，如何用长期主义破局 |
| 1.12 | 《苏秦刺股》：从被人耻笑到六国封相 | 苏秦初出游说秦王十次不用，归家妻不下纴、嫂不为炊、父母不与言，闭门苦读一年，以锥刺股，再出佩六国相印。 | 最深的耻辱，是自我重建最好的燃料 | 被否定、被看不起后的内耗，如何把羞耻感转化为行动力 |

### 卷二：人心与江湖——经典里的人际相处课（7.2 万字 / 12 章）

**卷引**：读懂了自己，才真正开始走入人群。有人的地方就有江湖——友情会散，爱人会变，同事会算计，邻里会摩擦。管鲍、蔺廉、伯牙子期、六尺巷的那堵墙，中国人关于人与人之间的所有答案，早就写在故事里了。

**核心映射**：友情边界、社交内耗、讨好型人格、识人辨人、冲突和解、让步哲学。

| 章 | 章节标题 | 中华经典故事与情节 | 故事核心（破局解读） | 现实映射（以史为鉴） |
| :--- | :--- | :--- | :--- | :--- |
| 2.1 | 《管鲍之交》：最好的友情是边界 | 管仲与鲍叔牙早年合伙经商，管仲多取不义之财，鲍不以为贪；后管仲辅公子纠败，鲍叔牙反举荐其相齐。 | 最深的友情，是相信对方有"底" | 闺蜜 / 兄弟反目、情感绑架，如何建立健康的友情边界 |
| 2.2 | 《负荆请罪》：成年人的和解不丢人 | 廉颇不服蔺相如位居其上，多次挑衅；蔺"引车避匿"而语"先国家之急而后私仇也"，廉闻之负荆请罪，终成刎颈之交。 | 低头不是认输，是看见比自己更大的事 | 冷战、面子困境，职场/家庭冲突，如何完成高质量和解 |
| 2.3 | 《高山流水》：懂你的人可遇不可求 | 伯牙鼓琴志在高山，钟子期曰"巍巍乎若泰山"；志在流水，子期曰"洋洋乎若江河"。子期死，伯牙破琴绝弦，终身不复鼓。 | 懂比爱更难得，同频本身就是奢侈品 | "朋友圈千人，知己无一"的当代孤独，如何珍惜真正的懂得 |
| 2.4 | 《华歆王朗乘船》：细节里见人品 | 华歆王朗同船避难，一人欲附船，王朗欣然纳之，贼至王欲弃之，华歆曰"既已纳其自托，宁可相弃耶"。 | 人品不在顺境的豪言里，在逆境的一念间 | 酒肉朋友遍地、真朋友难寻，如何通过细节识人 |
| 2.5 | 《晏子使楚》：高情商是不卑不亢 | 楚王三次羞辱齐国使臣晏子——小门入城、诘问齐无人、指齐人为盗，晏子分别以"使狗国入狗门""不肖者使不肖国""橘生淮南则为橘"回应。 | 高情商不是讨好，是底气的优雅释放 | 职场被冒犯、被 PUA，如何不撕破脸又守住底线 |
| 2.6 | 《三个和尚没水喝》：付出失衡的心理学 | 一个和尚挑水喝，两个和尚抬水喝，三个和尚反而没水喝。 | 人际崩塌的根源不是懒，是"凭什么是我" | 合租、合作、家务分配的失衡消耗，如何化解"理所当然" |
| 2.7 | 《孔融让梨 → 孔融之死》：善良必须带锋芒 | 孔融四岁让梨传为美谈；成年后恃才傲物，屡次顶撞曹操终遭诛灭，连累满门。 | 无底线的"让"与无边界的"刚"，是同一种失控 | 讨好型人格、无底线退让，如何做有锋芒的善良人 |
| 2.8 | 《六尺巷》：让步是顶级智慧 | 清代张英家人为宅基与邻争，千里书至京问相爷，张英回诗："千里来书只为墙，让他三尺又何妨。长城万里今犹在，不见当年秦始皇。"邻闻亦让三尺，遂成六尺巷。 | 让出去的三尺，是自己更高的格局 | 邻里、婆媳、同事鸡毛蒜皮，如何用格局化解内耗 |
| 2.9 | 《子路问津》：身段放低，路才宽 | 子路随孔子周游，问路于长沮、桀溺两位隐者，被冷嘲热讽，子路默然不辩。 | 遇到看不起你的人，沉默本身就是修养 | 被同龄人、同行贬低，如何不被鄙视链情绪化 |
| 2.10 | 《范式张劭鸡黍之约》：守信者得天下 | 东汉范式与张劭相约两年后某日登门拜访其母，届期风雨无阻赴约；后劭卒，式梦劭告别，星夜奔丧，及至棺不肯入，式至方入。 | 一个人最硬的通行证，是说到做到 | 应酬式朋友圈、随口承诺文化，如何成为被信赖的人 |
| 2.11 | 《杨震四知》：对自己的底线狠一点 | 杨震赴任途中，旧日举荐的王密夜怀十斤金相赠，言"暮夜无知者"，震厉色曰"天知、神知、我知、子知，何谓无知"，却金不受。 | 没人看见的时候，才是你真正的样子 | 灰色地带的人情往来、职场潜规则，如何守住底线 |
| 2.12 | 《程门立雪》：向他人求教的姿态 | 杨时、游酢冒雪往见程颐，程瞑目而坐，二人侍立不去，及程觉，门外雪已一尺。 | 真正的尊重，藏在你肯等的那段时间里 | 职场人脉焦虑、请教无门，如何用姿态换来真关系 |

### 卷三：职场与生存——经典里的成事智慧课（7.2 万字 / 12 章）

**卷引**：走出家门、走入人群之后，你得靠自己立足。职场即江湖，成事先成人。田忌的赛马、庖丁的解牛、范蠡的急流勇退，中国人关于"怎么把事做成"的所有压箱底智慧，都在这一卷里。

**核心映射**：职场生存、上下级、团队管理、创业破局、长期主义、35 岁危机、急流勇退。

| 章 | 章节标题 | 中华经典故事与情节 | 故事核心（破局解读） | 现实映射（以史为鉴） |
| :--- | :--- | :--- | :--- | :--- |
| 3.1 | 《田忌赛马》：成事靠策略不靠硬拼 | 田忌与齐威王赛马屡输，孙膑献计"以下驷对上驷、上驷对中驷、中驷对下驷"，田忌三局两胜。 | 资源有限时，重构规则比增量更重要 | 职场资源弱、创业势单力薄，如何用逆向思维破局 |
| 3.2 | 《挥泪斩马谡》：情绪要给结果让路 | 诸葛亮北伐用马谡守街亭，谡不听王平谏舍水上山，大败；诸葛亮按军令斩之，复为之流涕。 | 真正的管理者，是替结果负责的那个人 | 管理中的人情与规则冲突，如何做理性决策者 |
| 3.3 | 《曹刿论战》：努力不如抓准时机 | 齐鲁长勺之战，齐三鼓毕，曹刿方请击之，曰"一鼓作气，再而衰，三而竭"，鲁师大败齐军。 | 蓄势是最被低估的能力 | 无效努力、盲目内卷，如何抓职业 / 行业时机 |

## 五、写作落地与字数调整建议

1. **写作顺序**：先精雕 2–3 章样章（建议从 1.1《愚公移山》+ 3.1《田忌赛马》+ 5.3《定风波》起步），锁死 5 段式写作风格，再按卷铺开，避免后期偏离。
2. **字数弹性**：
   - 压缩至 40 万：单章压到 5000 字，72 章合计 36 万，加序跋 40 万
   - 保持 45 万（推荐）：单章 5500–6000 字
   - 扩展至 55 万：单章 7000 字，72 章合计 50.4 万，加序跋 55 万
3. **内容强化**：每章「现实映射」模块嵌入 1–2 个当代真实案例 / 社会热点（35 岁被优化、小镇做题家、两头婚、AI 替代焦虑、微信删好友等），让故事不只停留在感悟，而是真正戳中此刻。
4. **避坑三原则**：
   - **尊重史实**：核心情节、人物命运不虚无主义改写
   - **克制说教**：用故事本身说话，把"感悟权"交还给读者
   - **保持温度**：不高高在上，不冷嘲热讽，站在读者身边一起读故事
