# 合纵连横：利益重构

# 一、开篇锚点

## 1.三顿饭化解三方博弈

2023 年林总是一家高端定制服务公司创始人，陷入极其难解的三方对立——技术大拿 A 和业务老臣 C 互相看不起，投资人 B 对两人都不满但倾向支持 C 制衡 A。每一方都能让她崩盘：A 走了核心技术全带走，B 闹起来可能清算公司，C 倒戈了客户资源瞬间转走。我让她花三小时把每个人的"恐惧—欲望—底线"写出来。她看着白板说："他们的诉求并不冲突，是我没把它们结构化。"

第二周她请三个人单独吃了三顿饭。第一顿给 A 算账："B 要退出需要稳定现金流，钥匙在 C 手里。你把技术决策权保住，C 管老业务互不打架，B 看到稳定就不闹了。"A 点头。第二顿给 C 算账："A 一走技术崩盘，你最怕被边缘化。让 A 不过问你的业务，你也别在 B 面前说 A 坏话。"C 点头。第三顿给 B 算账："A 和 C 已达成默契，现金流稳了。等下一轮融资再退回报率比现在高 30%。"B 点头。三顿饭吃完没人多拿一分钱，林总只是把每个人怕什么想什么重新整合到新结构里。三个月后公司完成新一轮融资估值翻一倍。林总说："我那三顿饭不是在请客，是在给三个人重新算账。"

苏秦当年游说六国不是讲"团结就是力量"的鸡汤，是给六个国君每个人都算一笔账，让每个人都觉得"加入合纵对自己最有利"。苏秦靠合纵挂六国相印让秦国十五年不敢出函谷关；张仪靠连横拆掉六国联盟让秦国逐个击破。两个人用的都是同一套底层能力——不是嘴皮子厉害，是"算账能力"强到能同时给六个国君算六本不同的账。

# 二、史实还原

## 2.锥刺股与合纵六国

苏秦是东周洛阳人，从鬼谷子学成下山后第一次去秦国游说，秦惠王理都不理——这一年商鞅刚被处死，秦王对游说之士有强烈逆反心理。苏秦钱花光衣服破烂回到洛阳老家。《战国策》写得极其生动："妻不下纴，嫂不为炊，父母不与言。"——妻子在织布机上不肯下来，嫂子不肯做饭，父母不和他说话。受此羞辱他没有抱怨，闭门翻出《阴符》读了整整一年，夜里犯困就用锥子扎大腿——"读书欲睡，引锥自刺其股，血流至足"——这就是"锥刺股"。

但这一年真正在做的是重构游说逻辑。第一次去秦国他用的是"怎么帮你称霸"——供给方逻辑，把自己方案当主角。读完之后换成"你最怕什么、最想要什么"——需求方逻辑，把对方的恐惧和欲望当主角。一年后带着新逻辑反向出山：不去秦国，专找秦国的对立面。

苏秦先到燕国对燕文侯说："燕国不被侵犯是因为赵国在南边替你挡着秦军，赵国一倒你就是下一个。所以你最该做的不是和秦国结好，而是花钱让赵国挡得更稳。"燕文侯被说服。到赵国对赵肃侯说："秦攻赵必须先取韩魏，韩魏是赵国天然屏障——拉他们一起抗秦。"赵肃侯被说服。然后依次到韩、魏、齐、楚——对韩王用面子激将，对魏王用恐惧驱动，对齐王用利益重构，对楚王用野心催化。六国全部被说服，公元前 333 年会盟洹水签下合纵盟约，苏秦同时挂六国相印——秦国整整十五年不敢出函谷关。

## 3.舌在足矣连横拆盟

张仪比苏秦更惨——第一次游说时被楚国令尹怀疑偷玉璧，痛打一顿几乎丧命。回家后躺在床上问妻子："视吾舌尚在不？"妻子笑答："舌在也。"张仪说："足矣。"——只要嘴还在，一切都能翻盘。

张仪去秦国时苏秦已搞定六国合纵，秦惠王正在头疼。张仪的策略和苏秦完全相反——苏秦团结弱者打强者，张仪拆散弱者归附强者。第一步拆楚国——楚国是合纵最关键一环，一倒合纵立刻崩。张仪对楚怀王说："秦愿把商於六百里土地割让给楚国，条件是楚国和齐国绝交。"楚怀王欣喜若狂立刻和齐国绝交，派人去秦国接收土地，张仪笑着说："我答应的是商於六里不是六百里——是楚王听错了。"楚怀王气得当场吐血，出兵伐秦在丹阳大败，楚国从此一蹶不振。

第二步依次游说五国——对韩王用恐惧驱动，对赵王用现实驱动，对魏王用安全驱动，对燕王用次级威胁驱动，对齐王用稳定驱动。五国全部被说服，合纵联盟被几年拆光。秦国从此逐个击破直到秦始皇完成统一。苏秦搭起了六国联盟，张仪拆掉了六国联盟——两个人的本事都在那张嘴背后的"算账能力"上。

# 三、破局解读

## 4.为每人定制画像

第一层，他们有完整的"对方画像"——把每个国君当独立用户来研究。苏秦对燕文侯讲赵国挡刀（恐惧型），对齐宣王讲市场利益（利益型），对楚威王讲野心（欲望型）——每个国君的话术都是定制的。张仪也一样——对楚怀王用利诱、对韩王用威胁、对齐王用安抚，每一句话精确瞄准了那个国君脑子里最大的那根神经。

今天的销售、谈判最大错误就是"一套话术打天下"——同样的话讲给所有人听，结果谁都没说服。回到林总——她那三顿饭之所以管用，正是因为事先把 A、B、C 的恐惧、欲望、底线摸透，然后给每个人讲一套属于他自己的话术：对A讲技术决策权，对C讲地盘稳固，对B讲退出回报率。同样一个目标——让三方合作——对不同人用完全不同的钩子。

## 5.利益重构代替说教

第二层，用"利益重构"取代"道理说服"——不讲对错只讲利益。苏秦合纵的核心句式是："你现在局面是 X，继续下去会失去 Y，加入合纵会得到 Z，所以加入合纵对你最有利。"从来讲"团结抗秦是正义的"，他只讲"抗秦对你最有利"。张仪连横用同样句式，只是把"加入合纵"换成"归附秦国"。这才是顶级游说者的看家本领——不和对方辩论"什么是对的"，只算账"什么是对你最有利的"。

回到林总——她和 A、B、C 讲话时从来没有讲过"要顾全大局、要互相理解"，她讲的全部是利益账。在职场里你想说服一个人：不要说"这样做对公司好"，要说"这样做对你好"。翻译能力决定说服效率。

## 6.恐惧胜于利益驱动

第三层，恐惧驱动大于利益驱动——人对损失的敏感度是对收益的两倍。苏秦对每个国君讲的第一段都是"不加入合纵你会失去什么"，不是"加入合纵你会得到什么"。张仪也一样，"不归附秦国你会被怎样"永远放在"归附秦国你会得到什么"前面。张仪对楚怀王那一招表面是利诱六百里，背后真正的钩子是"错过这次再也得不到"——让楚怀王从"得到"的兴奋里进入"怕错过"的焦虑里。苏秦张仪直觉地用了前景理论——用"失去"开头对方肾上腺素立刻飙升，用"得到"开头对方半信半疑。

第四层，信誉复利——一个人能说服多大的局取决于他已被证明过多少次。苏秦先搞定燕赵，再去韩国时韩王心理压力已很大——"燕赵都加入了"。等到齐楚时身份本身就是最大说服力。张仪先打废楚国，剩下五国面前的可信度直接拉满。当你要做一件大事时，永远不要同时拉所有人到一桌，按信誉传递顺序一个一个搞定——前一场的胜利是后一场的最大筹码。

## 7.利益结构定一切

第五层，利益结构大于个人魅力。苏秦合纵之所以成立，是因为那时六国对秦国的恐惧足够大，利益结构支持合纵。合纵之所以瓦解，不是张仪嘴巴比苏秦更厉害，而是利益结构变了——秦国开始给每个国家单独甜头，当每个国家都觉得"我自己单独和秦谈更划算"时合纵就崩了。

任何联盟的本质都是利益结构。一旦利益结构变化，再好的盟友也会反目；利益结构稳，再大的矛盾都打不散。林总那三方对立之所以能解开，是因为她重新设计了一个三方都能受益的利益结构：A 拿决策权、C 拿地盘、B 拿稳定退出。只有当每个人都在新结构里活得更好时，他们才愿意放下旧的对立。没有永恒的盟友，只有永恒的利益结构。

# 四、现实映射

## 8.并购中的分而治之

第一个场景是商业谈判中的"分而治之"。我一位做并购的朋友想收购一家行业老二，对方七个创始合伙人每人持股 10%-20%。如果同时和七个人谈，七人会立刻抱团涨价——这就是合纵。他用的是连横策略：先找最悲观的那个合伙人给远高于市场价的退出价格让他先签字；然后拿着第一个签字去找第二个——"已有人卖了，剩下的人股价会被稀释，你越早卖越值钱"。每签一个，剩下人的卖出价就降一档。最后剩下的两个老大手里只剩不到 30%，完全失去谈判筹码只能接受最低价。这就是张仪连横在现代商业的翻版——永远不要让对手抱团，要把他们一个一个拆开。

## 9.职场利益重构破局

第二个场景是职场用利益重构破解多方博弈。我当年带团队时一个项目里有老张（业务老臣）、小李（技术骨干）、阿强（销售明星），三人因分工不清互相打小报告。我没开"团队建设大会"而是单独找他们吃饭。对老张讲："项目失败你要担最大责，所以你最该做的是让小李技术稳、阿强销售旺。"用风险驱动。对小李讲："你想升技术总监需要业务和销售背书，越对着干他们越不会替你说话。"用前途驱动。对阿强讲："想保住销售第一需要老张的客户资源和小李的产品支持，这两条线一断你明年就不是第一了。"用现实驱动。三顿饭吃完默契分了边界，项目做成三个人都升了。这就是不讲对错只算利益——让每一方都觉得合作对自己最有利。

## 10.合伙人利益再构造

第三个场景是合伙人利益结构再造。一个团队最容易散伙的是开始赚钱的时候——利益结构变了，原来公平的分配不再公平。我见过最高明的一次重构：三个合伙人原来 1:1:1 平分股权，三年后贡献变成 70%、20%、10%。创始人没有强行调股权，而是设计了一套"动态分红加静态股权"的混合方案——股权比例不变（保住情谊和退出预期），当年现金分红按贡献分（保住公平和激励）。三个人都觉得"对我更有利"，这就是利益结构再造。当旧的利益结构失衡时，不要去讲"情谊"，要去重新设计一套人人都能接受的利益分配方案。

# 五、史镜启示录

## 11.利益重构五法则

永远不要一套话术打天下——给每个人定制他的话术。对方最怕什么、最想要什么、最不愿失去什么，这三件事不弄清楚你说什么都没用。永远不要讲道理只算利益账——任何说服的本质是把"我希望你这样做"翻译成"你这样做对你最有利"。永远把恐惧放在利益前面讲——损失痛感是收益感的两倍，不要说"做你会得到什么"，要说"不做你会失去什么"。

说服是一个信誉复利游戏——永远不要把所有人同时拉到一桌，按信誉传递顺序一个一个搞定。从最容易突破的那个人开始，用他的认同作为说服下一个人的最大筹码。苏秦用"燕赵已加入"压韩魏，前一场的胜利是后一场的最大筹码。没有永恒的盟友只有永恒的利益结构——任何联盟一旦发生矛盾根本原因是利益结构变了，重新设计让每一方都能在新结构里得到他想要的，联盟才能重建。

## 12.看透局不被合纵连横

苏秦张仪给我们的不只是说服别人的方法，更是看透自己被说服的方法。当你下次被某个销售、领导、合伙人轻易说服时，停下来想一想：他是不是在用恐惧驱动操控我？他是不是在给我定制话术？他是不是在用信誉复利压我——"你信任的 X 也已经加入了"？他给我的方案，真的对我最有利，还是对他最有利？会用合纵连横的人，最先学会的是不被合纵连横——看得透别人的局，自己才不会掉进去。两千多年前两张嘴改写了战国格局，今天你能做的，是用这双眼睛看清每一场博弈里，谁在给你算账、算的是什么账、那笔账最后到底是谁在赚。
