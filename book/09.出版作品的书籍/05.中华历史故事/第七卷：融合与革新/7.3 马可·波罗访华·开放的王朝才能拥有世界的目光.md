# 第七卷·第三章 马可·波罗访华——开放的王朝才能拥有世界的目光

## 一、开篇锚点：那个"被外国博主拍火了的国产品牌"

我老婆有个闺蜜在做国货美妆，2020 年公司还很小，年销售额几百万。她们的产品在国内的电商平台一直处于"中等不温不火"的状态——国内消费者对"国货美妆"普遍有刻板印象，觉得包装俗、成分廉价、没什么高级感，无论她们在抖音和小红书上怎么讲产品的真实优点，转化率始终上不去。2021 年发生了一件她们自己都没想到的事——一个法国的美妆博主在巴黎的中超市场偶然买到了她们的产品，回家试了之后惊为天人，在 YouTube 上专门做了一期视频，标题大致是《法国人测试中国小众美妆，居然完爆我用过的一线大牌》。这条视频在 YouTube 拿了三百万播放，又被搬运到 B 站、小红书、微博，突然在国内火起来。国内消费者的反应非常戏剧化——"原来法国博主都说我们好，那肯定是真的好"，当年这家公司的销售额翻了八倍。

我老婆的闺蜜（也就是这家公司的创始人）后来跟我们吃饭，说了一句很扎心的话——最讽刺的是这条视频里说的所有产品优点，她们自己在抖音、小红书上讲了三年一直没人信，一个法国人随便讲几句突然全国人民都觉得她们牛了。我问她怎么看这件事，她说这件事让她学到了一件特别重要的事：你自己讲一万遍，不如让一个第三方讲一遍——中国人对"外国人怎么看中国"有特别强的反馈机制，她以前觉得"让外国博主来体验我们的产品"是面子工程，后来发现这是最有效的传播路径。从那以后她们公司专门做了一件事——主动邀请欧洲、东南亚、北美的美妆博主来中国实地体验，每年要接待五十到一百个国外博主，让他们看工厂、看实验室、看创始团队，这些博主回去后写出来的东西比她们自己花一千万投流量的效果都好。

我和她聊到这件事的时候提到了一个名字——马可·波罗。她笑了——她做的就是当代版的"马可·波罗"，只不过她的"忽必烈"是中国制造业，她请来的"马可·波罗"是 YouTube 上的美妆博主。七百多年前，一个意大利的少年来到大都，在元朝待了十七年，回国之后口述了一本《马可·波罗游记》（也叫《东方见闻录》），让整个欧洲第一次系统地、真实地、震撼地知道——东方有一个叫"契丹"的国家，那里有比欧洲所有城市加起来还要繁华的大都市、有用煤而不是木柴取暖的奇特燃料、有用纸做的钱、有比威尼斯还要发达的水路交通。这本书对欧洲的影响有多大？两百年后哥伦布出海的时候随身带的就是一本《马可·波罗游记》，他想找的"东方契丹"就是马可·波罗书里描述的那个遍地黄金的国度。忽必烈和元朝并不知道这本书的存在，他们没有花一分钱"出口宣传"，他们只做了一件事：开放——让一个外国人能进来、能看见、能写下、能带回去。这一章我们讲一个简单到令人震惊的命题——开放本身就是最大的软实力，封闭让你以为自己很强，开放让你真的很强。

## 二、史实还原：一个意大利少年在元朝的十七年

马可·波罗（Marco Polo），1254 年生于意大利威尼斯共和国，1324 年卒于威尼斯，享年七十岁。他不是贵族、不是学者、不是国王，只是一个商人家庭的儿子，能在历史上留名靠的不是出身而是一段难以复制的人生经历。要讲马可·波罗必须先讲他的父亲尼科洛和叔叔马泰奥。1260 年（这一年马可·波罗只有六岁），他的父亲和叔叔从威尼斯出发到黑海北岸的金帐汗国境内做生意。兄弟俩一路向东，经过中亚最终到达了忽必烈的大都，忽必烈对这两个"远方来客"非常感兴趣——因为他对欧洲一无所知，便向兄弟俩详细询问欧洲、罗马教廷、基督教的事情，最后还托他们带一封信给罗马教皇，希望教皇能派一百个传教士来元朝交流。兄弟俩 1269 年回到威尼斯，这是他们第一次去东方，已经过了九年，当时马可·波罗十五岁。1271 年，尼科洛兄弟决定再次东行，这一次带上了十七岁的马可·波罗，他们从威尼斯出发走丝绸之路的"南道"——经地中海到阿卡（今以色列境内），再经过中东到波斯，翻过帕米尔高原，沿丝绸之路一路东行。这趟路足足走了三年半——六千多公里的陆路，经过沙漠、雪山、戈壁、绿洲，沿途至少要换四到五种语言应付不同的政权、不同的关卡，要躲避盗匪、瘟疫、自然灾害、官方盘问，很多人走到一半就死在路上了，兄弟三人活着到了大都本身就是一个奇迹。1275 年马可·波罗终于和父亲、叔叔到达了忽必烈在上都的避暑行宫，这一年他二十一岁。

到达大都之后，忽必烈对这个聪明、健谈、会多种语言的意大利年轻人非常欣赏，把他留了下来——这一留就是十七年。马可·波罗在元朝担任过的具体职务在《游记》里说得不太清楚，后世学者根据各种线索推测他大致做过大都的"接待官员"（负责接待外国使节和商人）、巡查使（被忽必烈派往全国各地考察民情，他自己说去过云南、四川、江南、福建、扬州、泉州、苏州、杭州）、扬州的某种官员（《游记》里说他"治理扬州三年"但中文史料里没有任何记载）、代表忽必烈出使周边国家（他自己说去过印度、缅甸、占城、爪哇）。不管这些具体职务的真假，有一点是确定的——他在元朝待了整整十七年，期间走遍了元朝大部分疆域，看到了一个让他震惊的世界。他描述大都"周长 24 英里、有 12 个城门、每个城门 1000 名守卫、街道宽阔笔直如棋盘、全城有数不清的客栈和餐馆"，他说这个城市的财富超过了世界上任何一个城市；他称杭州为"行在"（Quinsai，南宋故都临安），描述这座城有 12000 座桥梁、街上人多到走路要侧身、全城有上千个澡堂，是世界上最美丽、最华贵的城市；他描述全国有超过 10000 个驿站、200000 匹驿马，信件可以在帝国境内一天传 250 英里；他详细描述了元朝的"交钞"（纸做的钱），说"忽必烈相当于把树皮变成了金子"；他描述了"用一种黑色的石头取暖"——这就是煤，欧洲人在 14 世纪还在用木头取暖；他描述泉州（Zayton）是世界上最大的港口之一，泊船数量是亚历山大港的一百倍。这十七年的经历装满了马可·波罗的脑子，也装满了他的笔记本。

1291 年，忽必烈准备把一位蒙古公主嫁给伊利汗国（在波斯）的阿鲁浑汗，陆路太危险必须走海路，马可·波罗一家三口正好有航海经验便被指派护送公主出海。他们从泉州出发，沿海路经马六甲、印度南端，两年多之后才把公主送到伊利汗国，顺势继续西行，1295 年终于回到了威尼斯。兄弟三人离开威尼斯二十四年，回家的时候亲戚朋友几乎都不认识他们了——一身陌生的东方服饰、一口威尼斯人听不懂的口音和一大堆"匪夷所思的故事"。最初没人相信他们说的，大家觉得这一家三口在外面胡说八道。1298 年威尼斯和热那亚之间发生海战，马可·波罗作为威尼斯一艘战船的指挥参战被俘虏，在热那亚的监狱里他遇到了一个写小说的同狱犯人鲁斯蒂谦（Rusticello da Pisa）。鲁斯蒂谦是职业作家，听马可·波罗讲东方的故事听得目瞪口呆，说服马可·波罗把这些故事写下来，两个人在监狱里花了一年多时间——马可·波罗口述、鲁斯蒂谦执笔——最终完成了《马可·波罗游记》（原名《Le Devisement du Monde》，意为"世界叙述"），1299 年正式问世，用古法语写成。游记一出版立刻在欧洲引起轰动也引起了巨大争议——相信的人说这本书让欧洲第一次知道东方的真实面貌，不相信的人说这都是吹牛，什么"一座城有 12000 座桥"、什么"用纸做钱"、什么"用石头烧火"绝对是骗局。马可·波罗到死之前都在为游记辩护，1324 年他临终时朋友们劝他"说出真相不要骗到死后"，他说："我所讲的，连一半都没有讲。"这句话后来成了《马可·波罗游记》最大的反向背书。游记在马可·波罗死后才慢慢被认真对待，14—15 世纪被翻译成多种欧洲语言传遍整个西方，到 15 世纪后期已成为所有想去东方的欧洲探险家的"标配"——哥伦布的航海日记里有 366 处提到《马可·波罗游记》，达·伽马的航海路线参考了游记中的印度描述，整个欧洲"地理大发现"时代的开端本质上是被这本游记点燃的。一个十七岁出门、三十八岁回家的威尼斯少年，用一本书改变了世界历史的方向。

## 三、破局解读：马可·波罗这件事到底成就了谁——四层"开放红利"的底层逻辑

读到这里你可能会想，马可·波罗这件事受益最大的不就是他自己吗——一个普通商人写本书让自己出名了。这个理解是错的。马可·波罗这件事的真正受益者是元朝，而且元朝并没有意识到自己在受益。第一层底层逻辑是：开放本身就是品牌——你愿意让人看，世界就愿意看你。元朝有一个被低估的特点，它是中国历史上对外国人最友好的王朝——外国商人不需要繁琐审批就可以进入中国（比起明清的"海禁"，元朝几乎是全开放）；外国人可以在中国做官（马可·波罗、阿合马、伊本·白图泰这位摩洛哥旅行家都在元朝有过职务）；外国宗教在中国可以自由传播（基督教、伊斯兰教、犹太教、藏传佛教、汉地佛教、道教都允许并存）；外国学者可以参与官方项目（元朝天文学家郭守敬使用了波斯天文学家的星表，忽必烈还专门设立了"回回司天台"）。这种程度的开放在中国历史上极其罕见——前面只有大唐能比，后面要等到改革开放才再次出现。开放最大的红利就是被世界看见——马可·波罗不是元朝花钱请来的，他是被元朝的开放氛围自然吸引过来的，这种"自然吸引"的效果远远大于刻意宣传，因为它真实所以可信。李总朋友的国货美妆也是这个逻辑——她不是花钱让法国博主夸她，她做的是把工厂、实验室、产品都开放给博主看，让博主自己得出结论，这种"自然产生的好评"在传播学上叫 earned media，比 paid media（付费宣传）的效果强五到十倍。

第二层底层逻辑是：第三方叙事大于自我叙事——你自己讲一万遍不如别人讲一遍。中国人有一个根深蒂固的心理特征，对"外人怎么看我们"特别敏感——这不是新鲜事，明清时期对"洋人怎么看天朝"也极其在意，今天我们对"外国人在中国"的视频依然有特别高的关注度。这种心理在传播学上叫"第三方背书效应"——人对"自己人讲自己好"是天然怀疑的，对"外人讲我们好"反而更容易相信。马可·波罗游记的杀伤力就在这里，它不是元朝的官方宣传而是一个外国人的自发记录，这种自发性让它在欧洲的可信度远远超过任何官方文书。放到今天的企业里——你的公司讲自己的产品好没人信，但你能让一个客户、一个合作伙伴、一个媒体记者讲你的产品好，可信度立刻翻十倍，这就是为什么"客户案例 + 媒体报道 + 第三方测评"是任何企业最好的营销资产。第三层底层逻辑是：开放带来的"信息基础设施"——驿站不只是给自己人用。元朝的驿站系统是全世界古代史上最庞大的"通讯 + 物流"网络，但它的真正价值不只是给元朝官员传递文书，而是给整个亚欧大陆开放的"信息高速公路"——外国商人可以借用驿站、外国传教士可以借用驿站、外国学者可以借用驿站，整个亚欧大陆的信息流通成本被这一套驿站系统降到了历史最低点，没有这套基础设施马可·波罗、伊本·白图泰、鄂多立克这些跨文明旅行者一个都来不了。放到今天的企业里对应的是"开放 API、开放接口、开放生态"——一个公司愿不愿意对外提供开放接口、愿不愿意把数据和工具开放给合作伙伴，决定了它能不能形成生态，而生态的杀伤力远远大于单一产品，苹果的 App Store、Salesforce 的 AppExchange、字节的小程序生态，它们的成功本质都是"开放红利"。

第四层底层逻辑是最深的——开放是文明的"自我升级机制"，元朝在开放过程中学到了大量自己原来没有的东西。元朝从波斯学到了天文学（郭守敬的《授时历》是中国历史上最精确的历法，比格里高利历早了三百年，背后融入了波斯天文学的成就）；从西域学到了数学（阿拉伯数字、代数学、几何学的部分内容是这个时期传入中国的）；从伊斯兰世界学到了医药（元朝的"回回药方"汇集了大量中亚、西亚的医药知识）；从藏地学到了宗教仪轨（藏传佛教的"喇嘛教"成为元朝皇室的精神纽带）；从蒙古汗国之间学到了地理学（元朝绘制的疆域图涵盖整个亚洲，这种全局视野欧洲在哥伦布之前都没有）。反过来欧洲也在大量学习元朝——欧洲学会了纸币（威尼斯、热那亚的银行体系受元朝交钞启发），学会了驿站邮政（14—15 世纪欧洲各国陆续建立驿站系统），学会了煤炭使用（14—15 世纪英国、德国开始大规模使用煤炭，是后来工业革命的能源基础），学会了火药、印刷术、指南针（这三大发明经由蒙古帝国传播到欧洲，直接催生了文艺复兴、宗教改革、地理大发现）。这就是开放最大的红利——双向升级，元朝在开放中获得了西方的智慧，欧洲在开放中获得了东方的技术，双方都因为这次大规模的"文明交流"而升级。放到今天的个人成长，这是一个最朴素但最深刻的真理——封闭让你以为自己很强，开放让你真的很强；你不和别人交流以为自己的方法很厉害，这是错觉，真正强的人都是被各种"陌生 / 异己 / 差异"反复打磨升级出来的。

## 四、现实映射：让你和你的组织"被世界看见 + 不断升级"的三条铁律

马可·波罗这件事给我们的启示可以转化成今天的三条具体行动指南。第一条铁律是：让真实的"第三方"看见你大于自己花钱讲一万遍。很多人或企业犯的最大错是只投放自己的"自我叙事"——你的产品好你自己讲、你的能力强你自己写简历、你的文化棒你自己拍宣传片，这种"自我叙事"的可信度天然有一个上限，因为任何人都知道自我叙事是有偏差的。真正的破局是让"第三方"自然地讲你——主动开放给"愿意讲真话的人"看，客户、媒体、博主、行业研究员只要他们愿意来看、愿意写真实评价你都欢迎，不要害怕负面反馈，偶尔一两条负面反馈反而会让所有正面评价更可信；投资在"案例 / 证据 / 记录"上，每一个客户的成功故事、每一个产品的迭代记录、每一个团队的真实日常都把它沉淀下来，让"第三方"想引用的时候有素材可用；不要"控制叙事"，马可·波罗的游记里有大量对元朝的客观描述——既有赞美也有抱怨，正是这种"不完美"让它可信，你越想"统一口径""控制叙事"反而越没有传播力。

第二条铁律是：把"开放"做成基础设施而不是一次性活动。很多企业把"开放"理解成一次性的 PR 活动——邀请几个媒体来参观、办一场发布会、做一次大客户体验日，这种零散的开放效果有限，因为它不是系统性的。真正的开放是把开放做成基础设施：开放产品的 API，让别人可以基于你的产品搭建自己的应用；开放数据的"安全部分"，比如行业报告、市场观察、产品白皮书，免费或低门槛地给任何人下载；开放团队的"参与机会"，开源项目、社区贡献、行业会议，让你的工程师、设计师、产品经理在外部社区里活跃。苹果不是举办了一次开发者大会，苹果是长期运营了一个 App Store + Developer 社区——这是基础设施，不是活动。第三条铁律是：不要怕"差异"——差异是升级的入口。很多人或企业的成长上限不是"能力不够"而是"接触面太窄"——你只和"和自己一样的人"打交道，你只能获得"和自己差不多的认知"。具体做法有三步：第一是主动和"不同行业、不同代际、不同国家"的人交流，每个月至少做一次"陌生人对话"，和你日常工作完全不沾边的人聊一小时；第二是主动学习"不舒服"的内容，如果你是技术人主动学一些营销、人文、艺术，如果你是文科生主动学一些工程、统计、AI，不舒服的内容是真正升级你的内容；第三是主动寻找"打脸自己"的机会，对自己的判断主动找反对意见、对自己的方案主动找漏洞、对自己的认知主动找证伪，愿意被打脸的人升级速度比别人快十倍。元朝在开放中升级、欧洲在开放中升级，双方都因为"接触了差异"而进化——一个个体、一个团队、一个公司、一个国家，升级的本质都是同一个公式：接触差异→消化差异→转化差异。

## 五、史镜启示录

开放本身就是最大的软实力——你愿意被人看世界才愿意看你，你藏着掖着世界就懒得理你。元朝的开放并不是为了"宣传自己"，它只是不刻意阻拦——一个意大利少年能进来、能看见、能写下、能带回去，结果催生了人类历史上最具影响力的一本"东方游记"。第三方叙事永远大于自我叙事——你讲一万遍不如让别人讲一遍，可信度的背书逻辑天生如此。earned media 的杀伤力远高于 paid media——前者是真实，后者是广告，做企业、做品牌、做个人 IP 都不能忘记这条铁律。把"开放"做成基础设施而不是一次性活动——基础设施有复利、活动只有当时的热闹，驿站系统的红利不只是给自己人用，它是给所有亚欧旅行者用的，最终的最大受益者依然是搭建它的人。

开放最大的红利不是被看见而是自己升级——这是马可·波罗这一章最深的一层启示。你接触的差异越多、越深、越久，你升级的速度越快——元朝因为开放学到了波斯的天文、阿拉伯的数学、伊斯兰世界的医药；欧洲因为开放学到了中国的纸币、驿站、煤炭、火药、印刷术、指南针，最终催生了文艺复兴和地理大发现。封闭让你以为自己很强，开放让你真的很强——这是个体、组织、文明都共通的铁律。一个王朝可以封闭、可以自得其乐、可以"天朝上国"——但封闭一旦开始，被时代抛下就只是时间问题；明清两代的衰落与元朝的繁荣形成对照，这一对照本身就是最有力的史镜。下一章我们讲元末农民起义——元朝的开放为它带来了空前繁荣，但开放的代价是它没沉下心来治理民生，蒙古统治者把更多精力放在对外扩张和商业流通而忽视了底层农民的实际生活，再加上元朝晚期民族分等政策、苛捐杂税、黄河水患——元朝的"民心账"越欠越多，最终在元朝建立不到一百年的时候，一群最底层的农民站了起来。一个再开放、再强大、再繁荣的王朝，只要忘记了底层老百姓，就一定会被底层老百姓掀翻。
