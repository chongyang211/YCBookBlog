### 6.1 符合数据类型

### 6.1.1 Object

**`Object`**：创建和操作对象。

方法：`Object.keys()`、`Object.values()`、`Object.assign()`。



### 6.1.2 Array

**`Array`**：创建和操作数组。

**Array 的底层原理**：V8 引擎中的数组并非简单的连续内存。当数组元素类型一致（如全是整数）时，V8 使用**快速模式（Fast Elements）**，以 C++ 数组方式存储，访问效率接近 O(1)；当数组包含不同类型元素、存在空洞（hole）或非常稀疏时，V8 切换为**字典模式（Dictionary Elements）**，以哈希表存储，节省空间但访问变慢。常用方法的时间复杂度：`push/pop` 为 O(1)，`shift/unshift` 为 O(n)（需移动元素），`map/filter/reduce` 为 O(n)。

方法：`push()`、`pop()`、`map()`、`filter()`、`reduce()`。

### 6.1.3 Map

**`Map`**：存储键值对。

方法：`set()`、`get()`、`has()`。

### 6.1.4 Set

**`Set`**：存储唯一值。

方法：`add()`、`delete()`、`has()`。

### 6.1.5 WeakMap

**`WeakMap` 和 `WeakSet`**：弱引用版本的 `Map` 和 `Set`。

## 6.8 综合案例

**案例：数据处理管道**

综合运用 Array、Map、Set、JSON 等标准库方法实现数据处理管道：

```javascript
// 原始数据：模拟用户订单
const orders = [
  { id: 1, user: 'Alice', product: 'iPhone', price: 999, date: '2024-01-15' },
  { id: 2, user: 'Bob', product: 'MacBook', price: 1999, date: '2024-01-20' },
  { id: 3, user: 'Alice', product: 'AirPods', price: 249, date: '2024-02-01' },
  { id: 4, user: 'Charlie', product: 'iPad', price: 799, date: '2024-02-10' },
  { id: 5, user: 'Bob', product: 'iPhone', price: 999, date: '2024-02-15' },
  { id: 6, user: 'Alice', product: 'MacBook', price: 1999, date: '2024-03-01' },
];

// 1. 获取所有不重复的用户（Set）
const uniqueUsers = [...new Set(orders.map(o => o.user))];
console.log('用户列表:', uniqueUsers);

// 2. 按用户分组统计消费（Map + reduce）
const userSpending = orders.reduce((map, order) => {
  const current = map.get(order.user) || 0;
  map.set(order.user, current + order.price);
  return map;
}, new Map());
console.log('用户消费统计:');
userSpending.forEach((total, user) => console.log(`  ${user}: $${total}`));

// 3. 按月统计订单数量
const monthlyOrders = orders.reduce((acc, order) => {
  const month = order.date.slice(0, 7);
  acc[month] = (acc[month] || 0) + 1;
  return acc;
}, {});
console.table(monthlyOrders);

// 4. 找出消费最高的用户
const topSpender = [...userSpending.entries()]
  .sort((a, b) => b[1] - a[1])[0];
console.log(`消费最高: ${topSpender[0]}，共消费 $${topSpender[1]}`);

// 5. 数据序列化与反序列化（JSON）
const jsonData = JSON.stringify(orders, null, 2);
const parsedData = JSON.parse(jsonData);
console.log('JSON 序列化大小:', jsonData.length, '字节');
```
