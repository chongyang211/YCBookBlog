## 01.前言介绍

### 1.1 JavaScript类型系统的特殊性

JavaScript是**动态弱类型**语言：

- **动态**：变量在运行时可以持有任何类型的值
- **弱类型**：不同类型的值可以隐式转换后参与运算

```javascript
1 + "2"       // "12" （数字被转为字符串）
true + 1      // 2    （布尔被转为数字）
[] + {}       // "[object Object]"
{} + []       // 0    （取决于解析方式）
```

这些看似诡异的结果背后，有一套严格的转换规则。本文将彻底拆解这套规则。

### 1.2 疑惑：为什么JavaScript要做隐式转换

**答疑**：作为一种面向Web的脚本语言，JavaScript在设计之初就追求**宽容性**——用户输入的表单数据都是字符串，如果不能隐式转换，每个运算前都需要手动类型转换，编码体验很差。

**论证**：

```javascript
// 表单输入总是字符串
const age = document.getElementById("age").value;  // "25"

// 如果没有隐式转换，每次都要手动转换
if (parseInt(age) > 18) { ... }  // 繁琐

// 有了隐式转换
if (age > 18) { ... }  // age被隐式转为数字
```

**结果**：便利性的代价是复杂性。理解转换规则是避免bug的关键。


## 02.JavaScript的类型体系

### 2.1 八种数据类型

ES2024规范定义了8种数据类型：

**7种原始类型（Primitive）**：

```javascript
typeof undefined;    // "undefined"
typeof true;         // "boolean"
typeof 42;           // "number"
typeof "hello";      // "string"
typeof 42n;          // "bigint"
typeof Symbol();     // "symbol"
typeof null;         // "object" ← 历史bug！实际是primitive
```

**1种引用类型（Reference）**：

```javascript
typeof {};            // "object"
typeof [];            // "object"
typeof function(){};  // "function" ← 特殊处理
typeof new Date();    // "object"
typeof /regex/;       // "object"
```

### 2.2 原始类型 vs 引用类型

```javascript
// 原始类型：值存在栈上（或Smi直接编码在指针中）
let a = 10;
let b = a;      // 复制值
b = 20;
console.log(a); // 10（a不受影响）

// 引用类型：引用存在栈上，对象存在堆上
let obj1 = { x: 1 };
let obj2 = obj1;   // 复制引用（不是对象）
obj2.x = 99;
console.log(obj1.x); // 99（obj1被影响了，因为指向同一个对象）
```

### 2.3 值的不可变性

原始类型的值是**不可变的（Immutable）**：

```javascript
let str = "hello";
str[0] = "H";        // 静默失败
console.log(str);     // "hello"（未改变）

// 字符串方法总是返回新字符串
str.toUpperCase();    // "HELLO"
console.log(str);     // "hello"（原始值未改变）
```

引用类型的值是**可变的（Mutable）**：

```javascript
const arr = [1, 2, 3];
arr.push(4);          // 修改了原数组
console.log(arr);     // [1, 2, 3, 4]

// 注意：const只是绑定不可变，值仍可变
const obj = { x: 1 };
obj.x = 2;            // 合法，修改属性
obj = { y: 3 };       // TypeError! 不能重新绑定
```


## 03.原始类型的底层表示

### 3.1 V8中的值编码

V8使用**指针标记（Pointer Tagging）**技术来区分值的类型：

```
在64位系统中:

Smi（小整数）:
  [63位整数值][0]     ← 最低位为0表示Smi

HeapObject（堆对象引用）:
  [63位指针][1]       ← 最低位为1表示指针
```

利用指针对齐的特性（堆对象地址总是偶数），用最低位来区分是Smi还是堆对象指针。这样判断类型只需一次位运算。

### 3.2 Smi的范围

```javascript
// 64位平台：Smi范围 -2^31 ~ 2^31-1
const max = 2 ** 31 - 1;   // 2147483647
const min = -(2 ** 31);    // -2147483648

// 范围内：Smi，直接编码在指针中，无堆分配
let a = 42;          // Smi

// 超出范围：HeapNumber，分配在堆上
let b = 2147483648;  // HeapNumber
let c = 1.5;         // HeapNumber（浮点数不是Smi）
```

### 3.3 Oddball对象

`null`、`undefined`、`true`、`false`在V8中是预分配的**Oddball**单例对象：

```
V8堆中的Oddball:
  undefined_value → 地址固定，全局唯一
  null_value      → 地址固定，全局唯一
  true_value      → 地址固定，全局唯一
  false_value     → 地址固定，全局唯一
  the_hole_value  → 内部使用，表示"空洞"
```

比较`undefined === undefined`本质上是**指针比较**，所以非常快。

### 3.4 字符串的多种内部表示

```
V8字符串类型:
├── SeqOneByteString    // ASCII/Latin-1，每字符1字节
├── SeqTwoByteString    // UTF-16，每字符2字节
├── ConsString           // 拼接字符串，存两个指针
├── SlicedString         // 切片引用
└── InternalizedString   // 内部化（去重）字符串

// V8会自动选择最优的表示
let a = "hello";           // SeqOneByteString (ASCII)
let b = "你好";            // SeqTwoByteString (包含中文)
let c = a + " world";      // 可能是ConsString
let d = c.slice(0, 5);     // 可能是SlicedString
```


## 04.typeof的实现原理

### 4.1 typeof的历史包袱

```javascript
typeof null === "object"  // true —— 这是公认的bug
```

**疑惑**：为什么typeof null是"object"？

**答疑**：这是JavaScript第一版实现中的bug，至今无法修复（修复会破坏太多现有代码）。

**论证**：在第一版JavaScript引擎（1995年，由Brendan Eich用C编写）中，值用32位存储，前3位作为类型标签：

```
000: object  — 对象
001: int     — 31位整数
010: double  — 双精度浮点
100: string  — 字符串
110: boolean — 布尔

null的表示: 全零（NULL指针，0x00000000）
```

typeof的实现检查前3位，null的前3位是000，和object相同。

**结果**：这个bug在ES6的提案中曾试图修复（typeof null === "null"），但因为向后兼容性问题被TC39否决。我们必须与它共存。

### 4.2 typeof的完整返回值表

```javascript
// 原始类型
typeof undefined;     // "undefined"
typeof true;          // "boolean"
typeof 42;            // "number"
typeof "hello";       // "string"
typeof 42n;           // "bigint"
typeof Symbol();      // "symbol"
typeof null;          // "object" ← bug

// 引用类型
typeof {};            // "object"
typeof [];            // "object" ← 数组也是"object"
typeof new Date();    // "object"
typeof /regex/;       // "object"
typeof new Map();     // "object"
typeof function(){};  // "function" ← 特殊处理
typeof class {};      // "function" ← class也是function
```

### 4.3 typeof的实现机制

V8中typeof的实现伪代码：

```
typeof(value):
  if value is undefined → return "undefined"
  if value is null      → return "object"  // 历史bug
  if value is boolean   → return "boolean"
  if value is number    → return "number"
  if value is string    → return "string"
  if value is symbol    → return "symbol"
  if value is bigint    → return "bigint"
  if value is callable  → return "function"  // 有[[Call]]内部方法
  else                  → return "object"
```

### 4.4 typeof的安全性

typeof是安全的——即使变量未声明也不会报错：

```javascript
// 未声明的变量
console.log(x);         // ReferenceError
typeof x;               // "undefined"（不报错）

// 但TDZ中的变量会报错（ES6改变）
typeof y;               // ReferenceError
let y;
```

这使得typeof成为检测全局变量是否存在的安全方式：

```javascript
if (typeof jQuery !== "undefined") {
    // jQuery可用
}
```


## 05.ToPrimitive抽象操作

### 5.1 什么是ToPrimitive

当一个对象需要转换为原始值时，引擎会调用**ToPrimitive**抽象操作。这是所有隐式类型转换的核心。

```
ToPrimitive(input, preferredType)

preferredType: "number" 或 "string" 或 "default"
```

### 5.2 转换算法

```
ToPrimitive(obj, hint):
  1. 如果obj有 [Symbol.toPrimitive] 方法：
     → 调用 obj[Symbol.toPrimitive](hint)
     → 如果返回原始值，结束
     → 否则抛出 TypeError

  2. 如果hint是"string"：
     → 先尝试 obj.toString()
     → 如果返回原始值，结束
     → 再尝试 obj.valueOf()
     → 如果返回原始值，结束
     → 抛出 TypeError

  3. 如果hint是"number"或"default"：
     → 先尝试 obj.valueOf()
     → 如果返回原始值，结束
     → 再尝试 obj.toString()
     → 如果返回原始值，结束
     → 抛出 TypeError
```

### 5.3 不同操作的hint

```javascript
// hint = "number"
+obj         // 一元加号
obj - 1      // 减法
obj * 2      // 乘法
obj > 0      // 比较

// hint = "string"
`${obj}`     // 模板字面量
String(obj)  // 显式转换

// hint = "default"
obj + 1      // 加号（可能是拼接也可能是加法）
obj == 1     // 宽松相等
```

### 5.4 Symbol.toPrimitive

```javascript
const obj = {
    [Symbol.toPrimitive](hint) {
        switch(hint) {
            case "number":  return 42;
            case "string":  return "forty-two";
            case "default": return "default-value";
        }
    }
};

+obj;         // 42         (hint: "number")
`${obj}`;     // "forty-two" (hint: "string")
obj + "";     // "default-value" (hint: "default")
```

### 5.5 常见对象的valueOf和toString

```javascript
// 普通对象
({}).valueOf();    // {} (返回对象本身，不是原始值)
({}).toString();   // "[object Object]"

// 数组
[1,2,3].valueOf();   // [1,2,3] (对象本身)
[1,2,3].toString();  // "1,2,3"

// Date（特殊！hint为"default"时优先toString）
new Date().valueOf();   // 1702000000000 (时间戳)
new Date().toString();  // "Thu Dec 07 2023..."

// Number包装对象
new Number(42).valueOf();   // 42
new Number(42).toString();  // "42"
```

### 5.6 Date对象的特殊行为

```javascript
const d = new Date();

// 大多数对象：hint="default"时按"number"处理（先valueOf）
// Date对象：hint="default"时按"string"处理（先toString）

d + 1;      // "Thu Dec 07 2023...1"（字符串拼接）
// 如果Date不特殊处理，d+1会返回时间戳+1的数字

d - 1;      // 1702000000000（hint是number，valueOf返回时间戳）
```


## 06.ToNumber转换规则

### 6.1 完整转换规则表

| 输入 | 输出 |
|------|------|
| undefined | NaN |
| null | 0 |
| true | 1 |
| false | 0 |
| "" (空字符串) | 0 |
| "123" | 123 |
| "12.3" | 12.3 |
| "0x1A" | 26 (十六进制) |
| "0b101" | 5 (二进制) |
| "0o17" | 15 (八进制) |
| "12abc" | NaN |
| " 42 " | 42 (忽略首尾空白) |
| "Infinity" | Infinity |
| 对象 | ToPrimitive(obj, "number") → ToNumber |

### 6.2 容易出错的转换

```javascript
Number(undefined);   // NaN   ← 不是0！
Number(null);        // 0
Number("");          // 0     ← 空字符串是0
Number(" ");         // 0     ← 空白字符串也是0
Number("0x");        // NaN   ← 不完整的十六进制
Number(true);        // 1
Number(false);       // 0
Number([]);          // 0     ← [].toString()="" → 0
Number([1]);         // 1     ← [1].toString()="1" → 1
Number([1,2]);       // NaN   ← [1,2].toString()="1,2" → NaN
Number({});          // NaN   ← ({}).toString()="[object Object]" → NaN
```

### 6.3 Number vs parseInt vs parseFloat

```javascript
Number("123abc");     // NaN（必须整个字符串都是数字）
parseInt("123abc");   // 123（从头解析到非数字字符就停止）
parseFloat("1.2.3");  // 1.2（解析到第二个小数点就停止）

// parseInt的基数陷阱
parseInt("010");      // 10（现代引擎默认十进制）
parseInt("010", 8);   // 8（明确指定八进制）
parseInt("0xF");      // 15（自动检测十六进制前缀）

// 最佳实践：总是指定基数
parseInt("10", 10);   // 10
```

### 6.4 一元加号操作符

一元`+`是调用`ToNumber`的简写：

```javascript
+"42"       // 42
+""         // 0
+true       // 1
+null       // 0
+undefined  // NaN
+[]         // 0
+{}         // NaN
```


## 07.ToString转换规则

### 7.1 完整转换规则表

| 输入 | 输出 |
|------|------|
| undefined | "undefined" |
| null | "null" |
| true | "true" |
| false | "false" |
| 0 | "0" |
| -0 | "0" ← 注意！ |
| Infinity | "Infinity" |
| NaN | "NaN" |
| 42 | "42" |
| 对象 | ToPrimitive(obj, "string") |

### 7.2 数字到字符串的特殊情况

```javascript
String(-0);           // "0"  ← -0变成"0"
(-0).toString();      // "0"
JSON.stringify(-0);   // "0"

// 但其他方式能保留-0
`${-0}`;              // "0"

// 检测-0
Object.is(-0, 0);     // false
1/-0 === -Infinity;   // true

// 极大/极小数字用科学记号
String(1e20);         // "100000000000000000000"
String(1e21);         // "1e+21"（超过某个阈值后用科学记号）
String(0.0000001);    // "1e-7"
```

### 7.3 对象到字符串

```javascript
String({});                // "[object Object]"
String([1,2,3]);           // "1,2,3"
String(function(){});      // "function(){}"
String(/regex/gi);         // "/regex/gi"
String(new Date());        // "Mon Dec 07 2023 ..."
String(new Error("oops")); // "Error: oops"
```

### 7.4 自定义toString

```javascript
class Money {
    constructor(amount, currency) {
        this.amount = amount;
        this.currency = currency;
    }
    toString() {
        return `${this.currency} ${this.amount.toFixed(2)}`;
    }
}

const price = new Money(42.5, "¥");
console.log(`价格: ${price}`);  // "价格: ¥ 42.50"
alert(price);                    // "¥ 42.50"
```


## 08.ToBoolean转换规则

### 8.1 Falsy值（完整列表）

JavaScript中**只有8个falsy值**：

```javascript
Boolean(false);       // false
Boolean(0);           // false
Boolean(-0);          // false
Boolean(0n);          // false（BigInt零）
Boolean("");          // false（空字符串）
Boolean(null);        // false
Boolean(undefined);   // false
Boolean(NaN);         // false
```

**其他所有值都是truthy**，包括：

```javascript
Boolean("0");         // true  ← 非空字符串
Boolean("false");     // true  ← 非空字符串
Boolean([]);          // true  ← 空数组是truthy！
Boolean({});          // true  ← 空对象是truthy！
Boolean(function(){}); // true
Boolean(new Boolean(false)); // true ← 包装对象是truthy！
```

### 8.2 疑惑：为什么空数组是truthy

```javascript
if ([]) { console.log("truthy"); }  // "truthy"
[] == false;                          // true
```

同一个`[]`，在if中是truthy，但`== false`又是true。这不矛盾吗？

**答疑**：这两个操作使用不同的规则：

- `if([])`：直接调用ToBoolean，对象总是true
- `[] == false`：触发Abstract Equality Comparison算法，经过多步转换

**论证**：

```
[] == false
→ [] == 0              (false转为0)
→ "" == 0              ([]转为原始值"")
→ 0 == 0               (""转为0)
→ true
```

### 8.3 逻辑运算符的本质

逻辑运算符不返回布尔值，而是返回操作数本身：

```javascript
// || 返回第一个truthy值，或最后一个值
0 || "" || null || "hello" || 42;   // "hello"
0 || "" || null || undefined;        // undefined

// && 返回第一个falsy值，或最后一个值
1 && "hello" && [] && 42;           // 42
1 && "" && 42;                       // ""

// ?? 空值合并（只检查null和undefined）
0 ?? 42;           // 0（0不是null/undefined）
null ?? 42;        // 42
undefined ?? 42;   // 42
"" ?? "default";   // ""（空字符串不是null/undefined）
```


## 09.隐式类型转换的完整规则

### 9.1 加号运算符的特殊性

加号`+`是唯一同时支持**数字加法**和**字符串拼接**的运算符：

```
a + b 的规则:
  1. lprim = ToPrimitive(a)
  2. rprim = ToPrimitive(b)
  3. 如果lprim或rprim是字符串 → 字符串拼接
  4. 否则 → 数字加法
```

```javascript
1 + 2;          // 3（数字加法）
"1" + 2;        // "12"（字符串拼接）
1 + "2";        // "12"（字符串拼接）
1 + true;       // 2（数字加法，true→1）
1 + null;       // 1（数字加法，null→0）
1 + undefined;  // NaN（数字加法，undefined→NaN）

// 对象参与的加法
[] + [];         // ""（两边都toString为""）
[] + {};         // "[object Object]"
{} + [];         // 0（{}被解析为空块，+[]是一元加号）
                 // 在括号中：({} + []) 是 "[object Object]"
```

### 9.2 其他算术运算符

减法、乘法、除法、取模**总是**做数字运算（不会拼接字符串）：

```javascript
"6" - 1;      // 5
"6" * 2;      // 12
"6" / 2;      // 3
"6" % 4;      // 2
"abc" - 1;    // NaN
true * 3;     // 3
null * 3;     // 0
```

### 9.3 比较运算符

```javascript
// 字符串比较：按Unicode码点逐字符比较
"b" > "a";        // true
"abc" > "abd";    // false（第三位c < d）
"10" > "9";       // false（"1" < "9"，字符串比较！）

// 混合类型比较：转为数字
"10" > 9;         // true（"10"→10，数字比较）
null > 0;         // false（null→0，0 > 0 = false）
null == 0;        // false（特殊规则，null只等于undefined）
null >= 0;        // true（null→0，0 >= 0 = true）

// 这就产生了一个诡异的结果
null > 0;   // false
null == 0;  // false
null >= 0;  // true ← 既不大于也不等于，但大于等于？
// 原因：>=用的是数字比较（null→0），==用的是特殊规则
```

### 9.4 逻辑上下文中的转换

```javascript
// if、while、for、&&、||、!、?:
// 都使用ToBoolean进行转换

if ("") { ... }          // 不执行（falsy）
while (1) { ... }        // 无限循环（truthy）
"" ? "yes" : "no";       // "no"
!!"hello";               // true（双重否定转布尔）
```

### 9.5 位运算的转换

位运算符将操作数转为**32位整数**：

```javascript
"5" | 0;        // 5（快速取整技巧）
3.9 | 0;        // 3（截断小数）
-3.9 | 0;       // -3
NaN | 0;        // 0
Infinity | 0;   // 0

~~3.9;          // 3（双重取反，等效于Math.trunc的快速版本）
~~-3.9;         // -3
```


## 10.相等比较的底层算法

### 10.1 严格相等（===）

严格相等不做类型转换：

```
x === y:
  1. 如果Type(x) ≠ Type(y)，返回false
  2. 如果x是number:
     a. 如果x是NaN，返回false
     b. 如果y是NaN，返回false
     c. 如果x和y相同数值，返回true
     d. 如果x是+0且y是-0，返回true
     e. 如果x是-0且y是+0，返回true
     f. 返回false
  3. 如果x是string：逐字符比较
  4. 如果x是boolean/null/undefined/symbol/bigint：相同值则true
  5. 如果x是object：相同引用则true
```

### 10.2 Object.is —— 真正的严格相等

```javascript
// === 的两个"bug"
NaN === NaN;     // false（NaN不等于自己）
+0 === -0;       // true（正负零相等）

// Object.is修复了这两个问题
Object.is(NaN, NaN);   // true
Object.is(+0, -0);     // false
```

### 10.3 宽松相等（==）

宽松相等会做类型转换，规则很复杂。以下是**完整算法**（ECMA-262 §7.2.14）：

```
x == y:
  1. 如果Type(x) === Type(y)，执行严格相等比较
  
  2. null == undefined → true
  3. undefined == null → true
  
  4. 如果x是number且y是string → x == ToNumber(y)
  5. 如果x是string且y是number → ToNumber(x) == y
  
  6. 如果x是bigint且y是string → x == StringToBigInt(y)
  7. 如果x是string且y是bigint → StringToBigInt(x) == y
  
  8. 如果x是boolean → ToNumber(x) == y
  9. 如果y是boolean → x == ToNumber(y)
  
  10. 如果x是object且y是string/number/bigint/symbol
      → ToPrimitive(x) == y
  11. 如果y是object且x是string/number/bigint/symbol
      → x == ToPrimitive(y)
  
  12. 如果x是bigint且y是number（或反过来）→ 数值比较
  
  13. 否则返回false
```

### 10.4 经典面试题逐步推导

```javascript
// [] == ![]
// 步骤分析：
// ![] → false（!对象总是false）
// [] == false
// [] == 0              （规则8：boolean→number）
// "" == 0              （规则10：ToPrimitive([]) → ""）
// 0 == 0               （规则5：string→number）
// true

[] == ![];  // true
```

```javascript
// {} == "[object Object]"
// ToPrimitive({}) → "[object Object]"
// "[object Object]" == "[object Object]"
// true

({}) == "[object Object]";  // true
```

```javascript
// 让a同时等于1、2、3
const a = {
    value: 1,
    valueOf() {
        return this.value++;
    }
};

a == 1 && a == 2 && a == 3;  // true!
// 每次==比较都会调用valueOf，value递增
```

### 10.5 相等比较总结

| 特性 | == | === | Object.is |
|------|----|----|-----------|
| 类型转换 | 有 | 无 | 无 |
| NaN === NaN | - | false | true |
| +0 === -0 | true | true | false |
| null == undefined | true | false | false |
| 推荐程度 | ⚠️少用 | ✅推荐 | 特殊场景 |


## 11.特殊值的设计原理

### 11.1 NaN的设计

```javascript
typeof NaN;           // "number" ← NaN是一个number
NaN === NaN;          // false ← 不等于自己
NaN !== NaN;          // true  ← 唯一一个不等于自己的值
```

**疑惑**：为什么NaN不等于自己？

**答疑**：这是IEEE 754标准的规定。NaN代表"不是一个数字"，它表示的是一种**无效状态**，而不是一个具体的值。两个无效状态不应该被认为相等。

```javascript
0/0;                  // NaN
Infinity - Infinity;  // NaN
Math.sqrt(-1);        // NaN
parseInt("abc");      // NaN
```

检测NaN的方法：

```javascript
isNaN("hello");         // true ← 先转Number，"hello"→NaN
Number.isNaN("hello");  // false ← 不转换，直接判断是否是NaN
Number.isNaN(NaN);      // true

// 利用NaN !== NaN的特性
function isNaNValue(x) {
    return x !== x;  // 只有NaN满足这个条件
}
```

### 11.2 正零与负零

```javascript
+0 === -0;          // true
Object.is(+0, -0);  // false

// 产生负零
-0;
0 / -Infinity;
-1 * 0;

// 负零的意义
// 在数学和物理中，-0表示"从负方向趋近零"
// 在图形编程中用于表示方向
```

### 11.3 undefined vs null

```javascript
// undefined: 声明了但没赋值
let x;
console.log(x);  // undefined

// null: 显式表示"空值"
let y = null;

// typeof差异
typeof undefined;  // "undefined"
typeof null;       // "object" (bug)

// 相等性
null == undefined;   // true
null === undefined;  // false
```

**设计哲学**：

- `undefined`表示"缺失"——变量未赋值、函数无返回值、访问不存在的属性
- `null`表示"空"——有意将值设为空

## 12.类型判断的最佳实践

### 12.1 综合类型判断函数

```javascript
function typeOf(value) {
    // null特殊处理
    if (value === null) return 'null';
    
    // 原始类型用typeof
    const type = typeof value;
    if (type !== 'object' && type !== 'function') return type;
    
    // 对象类型用Object.prototype.toString
    const tag = Object.prototype.toString.call(value).slice(8, -1);
    
    // 普通对象返回小写
    if (tag === 'Object') {
        // 检查是否是自定义类的实例
        const ctor = value.constructor;
        if (ctor && ctor.name !== 'Object') {
            return ctor.name;
        }
        return 'Object';
    }
    
    return tag;
}

typeOf(null);           // "null"
typeOf(42);             // "number"
typeOf("hello");        // "string"
typeOf(true);           // "boolean"
typeOf(undefined);      // "undefined"
typeOf(Symbol());       // "symbol"
typeOf(42n);            // "bigint"
typeOf([]);             // "Array"
typeOf({});             // "Object"
typeOf(/regex/);        // "RegExp"
typeOf(new Map());      // "Map"
typeOf(new Set());      // "Set"
typeOf(new Date());     // "Date"
typeOf(new Error());    // "Error"
typeOf(function(){});   // "function"
typeOf(Promise.resolve()); // "Promise"
```

### 12.2 类型守卫模式

```javascript
// 检查特定类型的安全函数
function isString(value) {
    return typeof value === 'string';
}

function isNumber(value) {
    return typeof value === 'number' && !Number.isNaN(value);
}

function isObject(value) {
    return value !== null && typeof value === 'object';
}

function isPlainObject(value) {
    if (!isObject(value)) return false;
    const proto = Object.getPrototypeOf(value);
    return proto === null || proto === Object.prototype;
}

function isArray(value) {
    return Array.isArray(value);
}

function isFunction(value) {
    return typeof value === 'function';
}

function isNil(value) {
    return value === null || value === undefined;
}
```

### 12.3 Duck Typing（鸭子类型）

```javascript
// "如果它走路像鸭子、叫声像鸭子，那它就是鸭子"
function isIterable(value) {
    return value != null && typeof value[Symbol.iterator] === 'function';
}

function isArrayLike(value) {
    return value != null && typeof value.length === 'number' && !isFunction(value);
}

function isPromiseLike(value) {
    return value != null && typeof value.then === 'function';
}

isIterable([1, 2, 3]);        // true
isIterable("hello");           // true
isIterable(new Map());         // true
isIterable({});                // false

isArrayLike([1, 2, 3]);       // true
isArrayLike("hello");          // true
isArrayLike({ length: 3 });   // true（类数组对象）
```

### 12.4 类型转换最佳实践

```javascript
// 显式转换（推荐）
String(value);         // 转字符串
Number(value);         // 转数字
Boolean(value);        // 转布尔

// 快捷方式（了解即可）
value + "";            // 转字符串（触发ToPrimitive）
+value;                // 转数字
!!value;               // 转布尔
value | 0;             // 转32位整数
value >>> 0;           // 转无符号32位整数

// 最佳实践
// 1. 始终使用 === 而不是 ==
// 2. 需要转换时使用显式转换函数
// 3. 使用 Number.isNaN() 而不是 isNaN()
// 4. 使用 Number.isFinite() 而不是 isFinite()
// 5. 对象比较始终是引用比较
// 6. 使用 Object.is() 处理 NaN 和 -0 的比较
```
