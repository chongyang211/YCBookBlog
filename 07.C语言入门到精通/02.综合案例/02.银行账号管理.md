## 01.项目需求和功能

### 1.1 需求介绍

银行账户管理系统，满足你提出的功能需求。该系统支持开户、存款、取款、查询余额、转账、保存数据到文件以及从文件读取数据。

### 1.2 功能要求

**功能要求**：

- 开户（账户号、姓名、余额等）。
- 存款、取款。
- 查询余额。
- 转账功能。
- 保存数据到文件，从文件读取数据。

### 1.3 涉及知识点

**涉及知识点**：结构体、文件操作、指针、条件判断。

## 02.菜单功能开发

### 2.1 菜单显示

在头文件中定义`void Menu()`函数

```c
//菜单展示
void Menu();
```

在c文件中实现头文件方法

```
void showMenu() {
    printf("\n银行账户管理系统\n");
    printf("1. 开户\n");
    printf("2. 存款\n");
    printf("3. 取款\n");
    printf("4. 查询余额\n");
    printf("5. 转账\n");
    printf("6. 保存数据到文件\n");
    printf("7. 退出\n");
    printf("请输入您的选择: ");
}
```

### 2.2 打印菜单

```c
int main() {
    int choice;
    while (1) {
        showMenu();
        scanf("%d", &choice);
        switch (choice) {
            case 1:
                printf("开户\n");
                break;
            case 2:
                printf("存款\n");
                break;
            case 3:
                printf("取款\n");
                break;
            case 4:
                printf("查询余额\n");
                break;
            case 5:
                printf("转账\n");
                break;
            case 6:
                printf("保存数据到文件\n");
                break;
            case 7:
                printf("退出系统，再见！\n");
                break;
            default:
                printf("无效的选择，请重新输入！\n");
                break;
        }
    }
    return 0;
}
```
