## 02.设计核心思路

### 2.1 核心目标

实现一个基于文件的简易数据库系统，支持以下功能：

- 创建表结构。
- 插入、删除、更新数据。
- 查询数据。
- 将数据保存到文件，并从文件加载数据。

### 2.2 设计原则

- **模块化**：将功能划分为不同的模块（如数据库管理、表管理、文件操作等），便于维护和扩展。
- **面向对象思想**：使用结构体和函数封装数据和操作，模拟面向对象的设计。
- **数据持久化**：通过文件存储数据，确保程序关闭后数据不丢失。
- **用户交互**：通过命令行界面与用户交互，提供简单的操作菜单。

### 2.3 技术选型

- **C 语言**：作为底层语言，适合实现高效的文件操作和数据结构。
- **文件操作**：使用 `fopen`、`fread`、`fwrite` 等函数实现数据的读写。
- **动态内存管理**：使用 `malloc` 和 `free` 动态分配和释放内存。
- **数据结构**：使用结构体表示表、列和行，使用数组存储多行数据。

## 03.定义数据结构

- **Column 结构体**：表示表中的列，包含列名和数据类型。
- **Row 结构体**：表示表中的一行数据，使用指针数组存储每列的数据。
- **Table 结构体**：表示表，包含表名、列信息、行数据和行数。
- **Database 结构体**：表示数据库，包含多个表和表数。

不管是行数据，还是列数据，都有相似的数据。我们可以把这部门抽出来，定义通用数据类型。如下所示：

```c
// 数据类型枚举
typedef enum {
    //int类型数据
    TYPE_INT,
    //float类型数据
    TYPE_FLOAT,
    //字符串类型数据
    TYPE_STRING
} DataType;
```

### 3.1 列结构体

```c
// 列结构体
typedef struct {
    char name[MAX_NAME_LENGTH];
    DataType type;
} Column;
```

### 3.2 行结构体

```c
typedef struct {
    void *data[MAX_COLUMNS]; // 存储每列的数据
} Row;
```

### 3.3 表结构体

```c
typedef struct {
    char name[MAX_NAME_LENGTH];
    Column columns[MAX_COLUMNS];
    int columnCount;
    Row rows[MAX_ROWS];
    int rowCount;
} Table;
```

### 3.4 数据库结构体

```c
typedef struct {
    Table tables[MAX_COLUMNS];
    int tableCount;
} Database;
```

## 04.核心功能实现

### 4.1 创建表

**创建表**：接收表名和列信息，初始化表结构。将表添加到数据库中。

首先定义函数

```c
void createTable(Database *db, const char *tableName, Column *columns, int columnCount);
```

然后在.c文件中做具体的实现，代码如下所示：

```c
void createTable(Database *db, const char *tableName, Column *columns, int columnCount) {
    if (db->tableCount >= MAX_COLUMNS) {
        printf("无法创建表：数据库表数量已达上限！\n");
        return;
    }
    //获取索引
    int tableCount = db->tableCount;
    //获取目标表指针
    Table *table = &db->tables[tableCount];
    strncpy(table->name, tableName, MAX_NAME_LENGTH);
    table->columnCount = columnCount;
    for (int i = 0; i < columnCount; i++) {
        strncpy(table->columns[i].name, columns[i].name, MAX_NAME_LENGTH);
        table->columns[i].type = columns[i].type;
    }
    table->rowCount = 0;
    db->tableCount++;
    printf("表 '%s' 创建成功！\n", tableName);
}
```

### 4.2 插入行数据

**插入行**：根据表名找到目标表。将数据插入到表的行数组中。

```c
void insertRow(Database *db, const char *tableName, void **data);
```

根据定义，实现插入行的逻辑。代码：

```c
void insertRow(Database *db, const char *tableName, void **data) {
    Table *table = NULL;
    //遍历查找目标表
    for (int i = 0; i < db->tableCount; i++) {
        if (strcmp(db->tables[i].name, tableName) == 0) {
            table = &db->tables[i];
            break;
        }
    }

    if (!table) {
        printf("表 '%s' 不存在！\n", tableName);
        return;
    }
    if (table->rowCount >= MAX_ROWS) {
        printf("无法插入行：表 '%s' 行数已达上限！\n", tableName);
        return;
    }

    Row *row = &table->rows[table->rowCount];
    for (int i = 0; i < table->columnCount; i++) {
        switch (table->columns[i].type) {
            case TYPE_INT:
                row->data[i] = malloc(sizeof(int));
                *(int *)row->data[i] = *(int *)data[i];
                break;
            case TYPE_FLOAT:
                row->data[i] = malloc(sizeof(float));
                *(float *)row->data[i] = *(float *)data[i];
                break;
            case TYPE_STRING:
                row->data[i] = malloc(MAX_STRING_LENGTH);
                strncpy((char *)row->data[i], (char *)data[i], MAX_STRING_LENGTH);
                break;
        }
    }
    table->rowCount++;
    printf("行插入成功！\n");
}
```

### 4.3 删除行数据

```c
void deleteRow(Database *db, const char *tableName, int rowIndex);
```

**删除行**：根据表名和行索引删除指定行。将后续行前移，覆盖被删除的行。

```c
void deleteRow(Database *db, const char *tableName, int rowIndex) {
    Table *table = NULL;
    for (int i = 0; i < db->tableCount; i++) {
        if (strcmp(db->tables[i].name, tableName) == 0) {
            table = &db->tables[i];
            break;
        }
    }
    if (!table) {
        printf("表 '%s' 不存在！\n", tableName);
        return;
    }
    if (rowIndex < 0 || rowIndex >= table->rowCount) {
        printf("行索引无效！\n");
        return;
    }
    for (int i = rowIndex; i < table->rowCount - 1; i++) {
        table->rows[i] = table->rows[i + 1];
    }
    table->rowCount--;
    printf("行删除成功！\n");
}
```

### 4.5 查询表操作

**查询表**：根据表名找到目标表。遍历表的所有行，打印数据。

```c
void queryTable(Database *db, const char *tableName);
```

具体实现如下所示：

```c
void queryTable(Database *db, const char *tableName) {
    Table *table = NULL;
    for (int i = 0; i < db->tableCount; i++) {
        if (strcmp(db->tables[i].name, tableName) == 0) {
            table = &db->tables[i];
            break;
        }
    }
    if (!table) {
        printf("表 '%s' 不存在！\n", tableName);
        return;
    }
    printf("表 '%s' 数据：\n", tableName);
    for (int i = 0; i < table->columnCount; i++) {
        printf("%-20s", table->columns[i].name);
    }
    printf("\n");
    for (int i = 0; i < table->rowCount; i++) {
        Row *row = &table->rows[i];
        for (int j = 0; j < table->columnCount; j++) {
            switch (table->columns[j].type) {
                case TYPE_INT:
                    printf("%-20d", *(int *)row->data[j]);
                    break;
                case TYPE_FLOAT:
                    printf("%-20.2f", *(float *)row->data[j]);
                    break;
                case TYPE_STRING:
                    printf("%-20s", (char *)row->data[j]);
                    break;
            }
        }
        printf("\n");
    }
}
```
