## 10.1 流基础介绍

### 10.1.1 什么是流

在 C 语言中，流（Stream） 是一个抽象的概念，用于表示数据的输入和输出。流可以是文件、键盘、屏幕、网络等数据源或目标的抽象。

C 标准库提供了一系列函数来操作流，使得程序可以方便地处理输入和输出。


### 10.1.2 流基本概念

流：流是数据在程序和外部设备之间传输的抽象。它可以是输入流（数据从外部设备到程序）或输出流（数据从程序到外部设备）。

- **文本流（Text Stream）**：由字符组成，通常用于处理文本文件。
- **二进制流（Binary Stream）**：由字节组成，通常用于处理二进制文件。

### 10.1.3 标准流

C 标准库中定义了三种标准流：

- `stdin`：标准输入流（通常指键盘）。
- `stdout`：标准输出流（通常指屏幕）。
- `stderr`：标准错误流（通常指屏幕）。

### 10.2.2 文件操作

文件是存储在磁盘上的数据集合。C 语言通过文件指针（`FILE *`）来操作文件。文件操作的基本步骤包括：

1. 打开文件。
2. 读写文件。
3. 关闭文件。

## 10.3 文件操作函数

### 10.3.1 打开文件

使用 `fopen` 函数打开文件：

```c
FILE *fopen(const char *filename, const char *mode);
```

- `filename`：文件名。
- `mode`：打开模式，如 `"r"`（只读）、`"w"`（只写）、`"a"`（追加）、`"rb"`（二进制只读）等。

**示例：**
```c
FILE *file = fopen("example.txt", "r");
if (file == NULL) {
    perror("Failed to open file");
    return 1;
}
```

### 10.3.2 关闭文件

使用 `fclose` 函数关闭文件：

```c
int fclose(FILE *stream);
```

**示例：**

```c
fclose(file);
```

### 10.3.3 读取文件

**字符读取**：`fgetc`

```c
int fgetc(FILE *stream);
```

**行读取**：`fgets`

```c
char *fgets(char *str, int n, FILE *stream);
```

**格式化读取**：`fscanf`

```c
int fscanf(FILE *stream, const char *format, ...);
```

**示例：**

```c
char buffer[100];
while (fgets(buffer, sizeof(buffer), file) != NULL) {
    printf("%s", buffer);
}
```
