### **1. 算术运算符**
用于执行基本的数学运算。

| 运算符 | 描述           | 示例           |
|--------|----------------|----------------|
| `+`    | 加法           | `a + b`        |
| `-`    | 减法           | `a - b`        |
| `*`    | 乘法           | `a * b`        |
| `/`    | 除法           | `a / b`        |
| `%`    | 取模（取余）   | `a % b`        |
| `++`   | 自增（前/后）  | `a++` 或 `++a` |
| `--`   | 自减（前/后）  | `a--` 或 `--a` |

#### **示例：**
```c
int a = 10, b = 3;
printf("%d\n", a + b); // 输出 13
printf("%d\n", a % b); // 输出 1
```

---

### **2. 关系运算符**
用于比较两个值的大小关系，返回 `1`（真）或 `0`（假）。

| 运算符 | 描述           | 示例           |
|--------|----------------|----------------|
| `==`   | 等于           | `a == b`       |
| `!=`   | 不等于         | `a != b`       |
| `>`    | 大于           | `a > b`        |
| `<`    | 小于           | `a < b`        |
| `>=`   | 大于等于       | `a >= b`       |
| `<=`   | 小于等于       | `a <= b`       |

#### **示例：**
```c
int a = 10, b = 20;
printf("%d\n", a > b);  // 输出 0（假）
printf("%d\n", a != b); // 输出 1（真）
```

---

### **3. 逻辑运算符**
用于组合多个条件，返回 `1`（真）或 `0`（假）。

| 运算符 | 描述           | 示例           |
|--------|----------------|----------------|
| `&&`   | 逻辑与（AND）  | `a && b`       |
| `||`   | 逻辑或（OR）   | `a || b`       |
| `!`    | 逻辑非（NOT）  | `!a`           |

#### **示例：**
```c
int a = 1, b = 0;
printf("%d\n", a && b); // 输出 0（假）
printf("%d\n", a || b); // 输出 1（真）
printf("%d\n", !a);     // 输出 0（假）
```

---

### **4. 位运算符**
用于对二进制位进行操作。

| 运算符 | 描述           | 示例           |
|--------|----------------|----------------|
| `&`    | 按位与         | `a & b`        |
| `|`    | 按位或         | `a | b`        |
| `^`    | 按位异或       | `a ^ b`        |
| `~`    | 按位取反       | `~a`           |
| `<<`   | 左移           | `a << 1`       |
| `>>`   | 右移           | `a >> 1`       |

#### **示例：**
```c
int a = 5, b = 3; // 5: 0101, 3: 0011
printf("%d\n", a & b);  // 输出 1 (0001)
printf("%d\n", a | b);  // 输出 7 (0111)
printf("%d\n", a << 1); // 输出 10 (1010)
```

---

### **5. 赋值运算符**
用于给变量赋值。

| 运算符 | 描述           | 示例           |
|--------|----------------|----------------|
| `=`    | 简单赋值       | `a = b`        |
| `+=`   | 加后赋值       | `a += b`       |
| `-=`   | 减后赋值       | `a -= b`       |
| `*=`   | 乘后赋值       | `a *= b`       |
| `/=`   | 除后赋值       | `a /= b`       |
| `%=`   | 取模后赋值     | `a %= b`       |
| `&=`   | 按位与后赋值   | `a &= b`       |
| `|=`   | 按位或后赋值   | `a |= b`       |
| `^=`   | 按位异或后赋值 | `a ^= b`       |
| `<<=`  | 左移后赋值     | `a <<= b`      |
| `>>=`  | 右移后赋值     | `a >>= b`      |

#### **示例：**
```c
int a = 10;
a += 5; // a = a + 5
printf("%d\n", a); // 输出 15
```

---

### **6. 条件运算符（三元运算符）**
用于简化 `if-else` 语句。

| 运算符 | 描述           | 示例           |
|--------|----------------|----------------|
| `? :`  | 条件运算符     | `a > b ? a : b` |

#### **示例：**
```c
int a = 10, b = 20;
int max = (a > b) ? a : b;
printf("%d\n", max); // 输出 20
```

---

### **7. 逗号运算符**
用于分隔多个表达式，返回最后一个表达式的值。

| 运算符 | 描述           | 示例           |
|--------|----------------|----------------|
| `,`    | 逗号运算符     | `a = (b=3, b+2)` |

#### **示例：**
```c
int a = (b = 3, b + 2);
printf("%d\n", a); // 输出 5
```

---

### **8. 其他运算符**
| 运算符 | 描述           | 示例           |
|--------|----------------|----------------|
| `sizeof` | 获取变量或类型的大小 | `sizeof(int)` |
| `&`    | 取地址         | `&a`           |
| `*`    | 指针解引用     | `*ptr`         |
| `->`   | 结构体指针成员访问 | `ptr->member` |

#### **示例：**
```c
int a = 10;
int *ptr = &a;
printf("%d\n", *ptr); // 输出 10
```

---

### **9. 运算符优先级**
运算符的优先级决定了表达式中运算的顺序。以下是一些常见运算符的优先级（从高到低）：

1. `()`（括号）
2. `++`、`--`（自增、自减）
3. `*`、`/`、`%`（乘法、除法、取模）
4. `+`、`-`（加法、减法）
5. `<<`、`>>`（位左移、位右移）
6. `<`、`<=`、`>`、`>=`（关系运算符）
7. `==`、`!=`（相等性运算符）
8. `&`、`|`、`^`（位运算符）
9. `&&`、`||`（逻辑运算符）
10. `? :`（条件运算符）
11. `=`、`+=`、`-=` 等（赋值运算符）

#### **示例：**
```c
int a = 10, b = 20, c = 30;
int result = a + b * c; // 先计算 b * c，再计算 a + (b * c)
printf("%d\n", result); // 输出 610
```

C 语言的运算符是编写程序的基础工具，熟练掌握它们的用法和优先级对于编写高效、清晰的代码至关重要。通过合理使用运算符，可以实现复杂的逻辑和计算。
