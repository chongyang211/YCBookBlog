## 6.1 概述和定义

在 C 语言中，**函数**是程序的基本构建块，用于将代码组织成可重用的模块。函数可以接收输入参数，执行特定任务，并返回结果。通过使用函数，可以提高代码的可读性、可维护性和复用性。

### 6.1.1 函数概念

**函数的基本概念**

- **函数定义**：实现函数功能的代码块。
- **函数声明**：告诉编译器函数的名称、返回类型和参数列表。
- **函数调用**：执行函数中的代码。

### 6.1.2 函数的定义

**语法**

```c
返回类型 函数名(参数列表) {
    // 函数体
    return 返回值; // 如果返回类型不是 void
}
```

**示例**

```c
int add(int a, int b) {
    return a + b;
}
```

### 6.1.3 函数声明

函数声明（也称为函数原型）告诉编译器函数的名称、返回类型和参数列表。

**语法**

```c
返回类型 函数名(参数列表);
```

**示例**

```c
int add(int a, int b);
```

## 6.2 函数调用

### 6.2.1 调用函数语法

通过函数名和参数列表调用函数。

**语法**

```c
函数名(参数列表);
```

**示例**

```c
int result = add(3, 5);
```

### 6.2.2 理解栈帧

当函数被调用时，系统会在 stack 空间上申请一块内存，用来给函数调用提供空间。存储 形参 和 局部变量（定义在函数内部的变量）。

函数调用结束时，这块内存空间，会被自动释放 (消失) 。

## 6.4 函数返回值

- 使用 `return` 语句返回函数的结果。
- 如果返回类型是 `void`，则不需要 `return` 语句。

### 6.4.1 void返回

```c
void printHello() {
    printf("Hello, World!\n");
}
```

### 6.4.2 return返回

```c
int add(int a, int b) {
    return a + b;
}
```

## 6.5 函数分类

**(1) 无参数无返回值函数**
```c
void printHello() {
    printf("Hello, World!\n");
}
```

**(2) 有参数无返回值函数**

```c
void printSum(int a, int b) {
    printf("Sum: %d\n", a + b);
}
```

**(3) 无参数有返回值函数**

```c
int getRandomNumber() {
    return rand();
}
```

**(4) 有参数有返回值函数**

```c
int add(int a, int b) {
    return a + b;
}
```

## 6.6 函数与数组
### 6.6.1 数组作为函数参数

数组可以作为函数参数传递，实际传递的是数组的首地址。

```c
void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    printArray(arr, 5);
    return 0;
}
```

### 6.6.2 多维数组作为函数参数

```c
void printMatrix(int mat[3][3], int rows, int cols) {
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            printf("%d ", mat[i][j]);
        }
        printf("\n");
    }
}
```

## 6.7 安全函数

C 语言的安全函数通过引入边界检查机制，可以有效避免缓冲区溢出等安全问题。常见的函数包括：
- 字符串操作：`strcpy_s`、`strcat_s`、`strncpy_s`。
- 输入输出：`gets_s`、`scanf_s`。
- 内存操作：`memcpy_s`、`memset_s`。
- 文件操作：`fopen_s`。

### 6.7.1 字符串安全函数

#### **1.1 `strcpy_s`**
- **功能**：安全地复制字符串。
- **原型**：
  ```c
  errno_t strcpy_s(char *dest, rsize_t dest_size, const char *src);
  ```
- **参数**：
    - `dest`：目标字符串。
    - `dest_size`：目标字符串的缓冲区大小。
    - `src`：源字符串。
- **返回值**：成功返回 0，失败返回非 0 值。
- **示例**：
  ```c
  char dest[10];
  strcpy_s(dest, sizeof(dest), "Hello");
  ```

#### **1.2 `strcat_s`**
- **功能**：安全地连接字符串。
- **原型**：
  ```c
  errno_t strcat_s(char *dest, rsize_t dest_size, const char *src);
  ```
- **参数**：
    - `dest`：目标字符串。
    - `dest_size`：目标字符串的缓冲区大小。
    - `src`：源字符串。
- **返回值**：成功返回 0，失败返回非 0 值。
- **示例**：
  ```c
  char dest[10] = "Hello";
  strcat_s(dest, sizeof(dest), "World");
  ```

#### **1.3 `strncpy_s`**
- **功能**：安全地复制指定长度的字符串。
- **原型**：
  ```c
  errno_t strncpy_s(char *dest, rsize_t dest_size, const char *src, rsize_t count);
  ```
- **参数**：
    - `dest`：目标字符串。
    - `dest_size`：目标字符串的缓冲区大小。
    - `src`：源字符串。
    - `count`：要复制的最大字符数。
- **返回值**：成功返回 0，失败返回非 0 值。
- **示例**：
  ```c
  char dest[10];
  strncpy_s(dest, sizeof(dest), "HelloWorld", 5);
  ```

### 6.7.2 内存操作安全函数

#### **3.1 `memcpy_s`**
- **功能**：安全地复制内存块。
- **原型**：
  ```c
  errno_t memcpy_s(void *dest, rsize_t dest_size, const void *src, rsize_t count);
  ```
- **参数**：
    - `dest`：目标内存块。
    - `dest_size`：目标内存块的大小。
    - `src`：源内存块。
    - `count`：要复制的字节数。
- **返回值**：成功返回 0，失败返回非 0 值。
- **示例**：
  ```c
  char dest[10];
  char src[] = "Hello";
  memcpy_s(dest, sizeof(dest), src, sizeof(src));
  ```

#### **3.2 `memset_s`**
- **功能**：安全地设置内存块的值。
- **原型**：
  ```c
  errno_t memset_s(void *dest, rsize_t dest_size, int value, rsize_t count);
  ```
- **参数**：
    - `dest`：目标内存块。
    - `dest_size`：目标内存块的大小。
    - `value`：要设置的值。
    - `count`：要设置的字节数。
- **返回值**：成功返回 0，失败返回非 0 值。
- **示例**：
  ```c
  char buffer[10];
  memset_s(buffer, sizeof(buffer), 0, sizeof(buffer));
  ```

### 6.7.3 文件操作安全函数

#### **4.1 `fopen_s`**
- **功能**：安全地打开文件。
- **原型**：
  ```c
  errno_t fopen_s(FILE **file, const char *filename, const char *mode);
  ```
- **参数**：
    - `file`：指向文件指针的指针。
    - `filename`：文件名。
    - `mode`：打开模式（如 "r"、"w" 等）。
- **返回值**：成功返回 0，失败返回非 0 值。
- **示例**：
  ```c
  FILE *file;
  fopen_s(&file, "test.txt", "r");
  ```

### 6.7.4 输入输出安全函数

#### **2.1 `gets_s`**
- **功能**：安全地从标准输入读取字符串。
- **原型**：
  ```c
  char *gets_s(char *buffer, rsize_t size);
  ```
- **参数**：
    - `buffer`：存储输入字符串的缓冲区。
    - `size`：缓冲区的大小。
- **返回值**：成功返回 `buffer`，失败返回 `NULL`。
- **示例**：
  ```c
  char buffer[10];
  gets_s(buffer, sizeof(buffer));
  ```

#### **2.2 `scanf_s`**
- **功能**：安全地从标准输入读取格式化数据。
- **原型**：
  ```c
  int scanf_s(const char *format, ...);
  ```
- **参数**：
    - `format`：格式化字符串。
    - `...`：可变参数列表。
- **返回值**：成功返回读取的项数，失败返回 `EOF`。
- **示例**：
  ```c
  char buffer[10];
  scanf_s("%9s", buffer, sizeof(buffer));
  ```


## 6.8 标准库函数

C 语言提供了丰富的标准库函数，如：

- **输入输出**：`printf`、`scanf`
- **字符串操作**：`strcpy`、`strlen`
- **数学函数**：`sqrt`、`pow`
- **内存管理**：`malloc`、`free`

**示例**

```c
#include <stdio.h>
#include <string.h>
#include <math.h>

int main() {
    char str[50];
    strcpy(str, "Hello, World!");
    printf("%s\n", str);

    double result = sqrt(16.0);
    printf("Square root: %f\n", result);

    return 0;
}
```

## 6.9 函数注意事项 

1. **函数声明**：
    - 如果函数定义在调用之后，需要先声明函数。

2. **参数传递**：
    - C 语言中，参数是按值传递的（指针除外）。

3. **返回值**：
    - 如果函数有返回值，必须使用 `return` 语句。

4. **递归**：
    - 递归函数必须有终止条件，否则会导致栈溢出。

5. **函数命名**：
    - 函数名应具有描述性，遵循命名规范。
