### **4. 指针的类型**
指针的类型决定了指针指向的数据类型以及指针的算术运算方式。

| 指针类型       | 说明                     |
|----------------|--------------------------|
| `int *`        | 指向 `int` 类型的指针     |
| `float *`      | 指向 `float` 类型的指针   |
| `char *`       | 指向 `char` 类型的指针    |
| `void *`       | 通用指针，可以指向任何类型 |

---

### **5. 指针的算术运算**
指针的算术运算基于指针指向的数据类型的大小。

#### **(1) 指针加减整数**
```c
int arr[] = {1, 2, 3, 4, 5};
int *p = arr;

p++; // p 指向 arr[1]
p += 2; // p 指向 arr[3]
```

#### **(2) 指针相减**
```c
int *p1 = &arr[1];
int *p2 = &arr[4];
int diff = p2 - p1; // diff = 3
```

---

### **6. 指针与数组的关系**
- 数组名是数组首元素的地址。
- 指针可以像数组一样使用下标访问元素。

#### **示例**
```c
int arr[] = {1, 2, 3, 4, 5};
int *p = arr;

printf("arr[2] = %d\n", arr[2]);
printf("*(p + 2) = %d\n", *(p + 2));
```

**输出：**
```
arr[2] = 3
*(p + 2) = 3
```

---

### **7. 指针与字符串**
- 字符串是字符数组，可以用字符指针表示。

#### **示例**
```c
char str[] = "Hello";
char *p = str;

printf("String: %s\n", p);
printf("First character: %c\n", *p);
```

**输出：**
```
String: Hello
First character: H
```

---

### **8. 指针数组与数组指针**
#### **(1) 指针数组**
- 数组中的每个元素都是指针。

```c
int *arr[3]; // 指针数组
int a = 1, b = 2, c = 3;
arr[0] = &a;
arr[1] = &b;
arr[2] = &c;
```

#### **(2) 数组指针**
- 指向数组的指针。

```c
int arr[3] = {1, 2, 3};
int (*p)[3] = &arr; // 数组指针
```

### **10. 动态内存分配**
- 使用 `malloc`、`calloc`、`realloc` 和 `free` 函数动态分配和释放内存。

#### **示例**
```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *p = (int *)malloc(5 * sizeof(int)); // 分配 5 个 int 的内存
    if (p == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }

    for (int i = 0; i < 5; i++) {
        p[i] = i + 1;
    }

    for (int i = 0; i < 5; i++) {
        printf("%d ", p[i]);
    }

    free(p); // 释放内存
    return 0;
}
```

**输出：**
```
1 2 3 4 5
```

### **11. 指针的注意事项**
1. **空指针**：
    - 指针未初始化时，应将其设置为 `NULL`。
    - 示例：
      ```c
      int *p = NULL;
      ```

2. **野指针**：
    - 指向已释放或无效内存的指针。
    - 示例：
      ```c
      int *p = (int *)malloc(sizeof(int));
      free(p);
      // p 现在是野指针
      ```

3. **指针类型匹配**：
    - 指针的类型必须与指向的数据类型匹配。
    - 示例：
      ```c
      int x = 10;
      float *p = &x; // 错误：类型不匹配
      ```

4. **指针的算术运算**：
    - 指针的算术运算基于指向的数据类型的大小。
    - 示例：
      ```c
      int arr[5];
      int *p = arr;
      p++; // p 指向 arr[1]
      ```
