## 6.1 概述和定义

在 C 语言中，**函数**是程序的基本构建块，用于将代码组织成可重用的模块。函数可以接收输入参数，执行特定任务，并返回结果。通过使用函数，可以提高代码的可读性、可维护性和复用性。

### 6.1.1 函数概念

**函数的基本概念**

- **函数定义**：实现函数功能的代码块。
- **函数声明**：告诉编译器函数的名称、返回类型和参数列表。
- **函数调用**：执行函数中的代码。

### 6.1.2 函数的定义

**语法**

```c
返回类型 函数名(参数列表) {
    // 函数体
    return 返回值; // 如果返回类型不是 void
}
```

**示例**

```c
int add(int a, int b) {
    return a + b;
}
```

### 6.1.3 函数声明

函数声明（也称为函数原型）告诉编译器函数的名称、返回类型和参数列表。

**语法**

```c
返回类型 函数名(参数列表);
```

**示例**

```c
int add(int a, int b);
```

## 6.3 函数参数
### 6.3.1 参数

- **形式参数**：函数定义中的参数。
- **实际参数**：函数调用时传递的参数。

**示例**

```c
int add(int a, int b) { // a 和 b 是形式参数
    return a + b;
}

int result = add(3, 5); // 3 和 5 是实际参数
```

## 6.4 函数返回值

- 使用 `return` 语句返回函数的结果。
- 如果返回类型是 `void`，则不需要 `return` 语句。

### 6.4.1 void返回

```c
void printHello() {
    printf("Hello, World!\n");
}
```

### 6.4.2 return返回

```c
int add(int a, int b) {
    return a + b;
}
```

## 6.5 函数分类

**(1) 无参数无返回值函数**
```c
void printHello() {
    printf("Hello, World!\n");
}
```

**(2) 有参数无返回值函数**

```c
void printSum(int a, int b) {
    printf("Sum: %d\n", a + b);
}
```

**(3) 无参数有返回值函数**

```c
int getRandomNumber() {
    return rand();
}
```

**(4) 有参数有返回值函数**
```c
int add(int a, int b) {
    return a + b;
}
```

## 6.6 函数与数组
### 6.6.1 数组作为函数参数

数组可以作为函数参数传递，实际传递的是数组的首地址。

```c
void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    printArray(arr, 5);
    return 0;
}
```

### 6.6.2 多维数组作为函数参数

```c
void printMatrix(int mat[3][3], int rows, int cols) {
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            printf("%d ", mat[i][j]);
        }
        printf("\n");
    }
}
```

## 6.8 标准库函数

C 语言提供了丰富的标准库函数，如：

- **输入输出**：`printf`、`scanf`
- **字符串操作**：`strcpy`、`strlen`
- **数学函数**：`sqrt`、`pow`
- **内存管理**：`malloc`、`free`

**示例**

```c
#include <stdio.h>
#include <string.h>
#include <math.h>

int main() {
    char str[50];
    strcpy(str, "Hello, World!");
    printf("%s\n", str);

    double result = sqrt(16.0);
    printf("Square root: %f\n", result);

    return 0;
}
```

## 6.9 函数注意事项 

1. **函数声明**：
    - 如果函数定义在调用之后，需要先声明函数。

2. **参数传递**：
    - C 语言中，参数是按值传递的（指针除外）。

3. **返回值**：
    - 如果函数有返回值，必须使用 `return` 语句。

4. **递归**：
    - 递归函数必须有终止条件，否则会导致栈溢出。

5. **函数命名**：
    - 函数名应具有描述性，遵循命名规范。
