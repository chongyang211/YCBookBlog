## 6.1 概述和定义

在 C 语言中，**函数**是程序的基本构建块，用于将代码组织成可重用的模块。函数可以接收输入参数，执行特定任务，并返回结果。通过使用函数，可以提高代码的可读性、可维护性和复用性。

### 6.1.1 函数概念

**函数的基本概念**

- **函数定义**：实现函数功能的代码块。
- **函数声明**：告诉编译器函数的名称、返回类型和参数列表。
- **函数调用**：执行函数中的代码。

### 6.1.2 函数的定义

**语法**

```c
返回类型 函数名(参数列表) {
    // 函数体
    return 返回值; // 如果返回类型不是 void
}
```

**示例**

```c
int add(int a, int b) {
    return a + b;
}
```

### 6.1.3 函数声明

函数声明（也称为函数原型）告诉编译器函数的名称、返回类型和参数列表。

**语法**

```c
返回类型 函数名(参数列表);
```

**示例**

```c
int add(int a, int b);
```

## 6.2 函数调用

通过函数名和参数列表调用函数。

**语法**

```c
函数名(参数列表);
```

**示例**

```c
int result = add(3, 5);
```


## 6.3 函数参数
### 6.3.1 参数

- **形式参数**：函数定义中的参数。
- **实际参数**：函数调用时传递的参数。

**示例**

```c
int add(int a, int b) { // a 和 b 是形式参数
    return a + b;
}

int result = add(3, 5); // 3 和 5 是实际参数
```

## 6.4 函数返回值

- 使用 `return` 语句返回函数的结果。
- 如果返回类型是 `void`，则不需要 `return` 语句。

### 6.4.1 void返回

```c
void printHello() {
    printf("Hello, World!\n");
}
```

### 6.4.2 return返回

```c
int add(int a, int b) {
    return a + b;
}
```

## 6.5 函数分类

**(1) 无参数无返回值函数**
```c
void printHello() {
    printf("Hello, World!\n");
}
```

**(2) 有参数无返回值函数**
```c
void printSum(int a, int b) {
    printf("Sum: %d\n", a + b);
}
```

**(3) 无参数有返回值函数**
```c
int getRandomNumber() {
    return rand();
}
```

**(4) 有参数有返回值函数**
```c
int add(int a, int b) {
    return a + b;
}
```
