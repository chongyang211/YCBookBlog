## 5.1 输入输出库

C 语言的输入输出函数定义在 `<stdio.h>` 头文件中，使用前需要包含该头文件。

```c
#include <stdio.h>
```

## 5.2 格式化输出

`printf` 函数用于将格式化的数据输出到标准输出设备（通常是屏幕）。

**语法**

```c
int printf(const char *format, ...);
```

**示例**

```c
int age = 25;
printf("My age is %d\n", age);
```

**常用格式说明符**

| 格式符 | 说明               |
|--------|--------------------|
| `%d`   | 输出整数           |
| `%f`   | 输出浮点数         |
| `%c`   | 输出字符           |
| `%s`   | 输出字符串         |
| `%p`   | 输出指针地址       |
| `%x`   | 输出十六进制整数   |
