## 4.2 选择结构

### 4.2.1 if语句

`if` 语句用于在条件为真时执行代码块。

**语法**

```c
if (条件) {
    // 条件为真时执行的代码
}
```

**示例**

```c
int age = 18;
if (age >= 18) {
    printf("You are an adult.\n");
}
```

### 4.2.2 if-else语句

`if-else` 语句用于在条件为真时执行一个代码块，否则执行另一个代码块。

**语法**

```c
if (条件) {
    // 条件为真时执行的代码
} else {
    // 条件为假时执行的代码
}
```

**示例**

```c
int age = 16;
if (age >= 18) {
    printf("You are an adult.\n");
} else {
    printf("You are a minor.\n");
}
```
