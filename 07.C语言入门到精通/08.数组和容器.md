## 8.1 数组的概念

在 C 语言中，**数组**是一种用于存储相同类型数据的集合。数组中的每个元素通过索引访问，索引从 `0` 开始。

**数组的基本概念**

- **数组**：一组相同类型的数据元素。
- **元素**：数组中的每个数据项。
- **索引**：用于访问数组元素的下标，从 `0` 开始。

## 8.2 数组使用
### 8.2.1 数组的声明

**语法**

```c
数据类型 数组名[数组大小];
```

**示例**

```c
int arr[5]; // 声明一个包含 5 个整数的数组
```

### 8.2.2 数组初始化

可以在声明时初始化数组。

**语法**

```c
数据类型 数组名[数组大小] = {值1, 值2, ...};
```

**示例**

```c
int arr[5] = {1, 2, 3, 4, 5};
```

**部分初始化**，未初始化的元素默认为 `0`。

```c
int arr[5] = {1, 2}; // arr = {1, 2, 0, 0, 0}
```

**省略数组大小**，如果初始化时指定了所有元素，可以省略数组大小。

```c
int arr[] = {1, 2, 3, 4, 5}; // 数组大小为 5
```

### 8.2.3 数组访问

通过索引访问数组元素。

**语法**

```c
数组名[索引];
```

**示例**

```c
int arr[5] = {1, 2, 3, 4, 5};
printf("%d\n", arr[0]); // 输出 1
arr[2] = 10; // 修改第三个元素
```

### 8.2.4 数组的遍历

使用循环遍历数组。**示例**

```c
int arr[5] = {1, 2, 3, 4, 5};
for (int i = 0; i < 5; i++) {
    printf("%d ", arr[i]);
}
```

**输出：**

```
1 2 3 4 5
```


## 8.4 多维数组

### 8.4.1 二维数组

多维数组是数组的数组，常见的是二维数组。

**语法**

```c
数据类型 数组名[行数][列数];
```

**示例**

```c
int mat[3][3] = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
```

### 8.4.2 访问多维数组

```c
printf("%d\n", mat[1][2]); // 输出 6
```

## 8.6 数组和指针

数组名是数组首元素的地址。

**示例**

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr; // p 指向 arr[0]
printf("%d\n", *p); // 输出 1
```

**指针算术**

```c
printf("%d\n", *(p + 2)); // 输出 3
```


## 8.8 数组注意事项

1. **索引越界**：
    - 访问超出数组范围的索引会导致未定义行为。
    - 示例：
      ```c
      int arr[5] = {1, 2, 3, 4, 5};
      printf("%d\n", arr[5]); // 错误：索引越界
      ```

2. **数组大小**：
    - 数组大小必须是常量表达式。
    - 示例：
      ```c
      int size = 5;
      int arr[size]; // 错误：C89 标准不支持变量作为数组大小
      ```

3. **数组名是常量指针**：
    - 数组名是数组首元素的地址，不能修改。
    - 示例：
      ```c
      int arr[5] = {1, 2, 3, 4, 5};
      arr++; // 错误：数组名是常量指针
      ```

4. **数组初始化**：
    - 未初始化的数组元素值是未定义的。

## 8.9 数组常见算法
### 8.9.1 查最大值
```c
int findMax(int arr[], int size) {
    int max = arr[0];
    for (int i = 1; i < size; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}
```


### 8.9.2 数组排序

```c
void bubbleSort(int arr[], int size) {
    for (int i = 0; i < size - 1; i++) {
        for (int j = 0; j < size - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```
