# 项目结构说明

# 项目框架和版本

- framework: Qt 5.14.2
- cpp_standard: C++11
- platform: Linux (RV1126设备)
- build_system: aikit

## 项目架构概述

掌纹识别模块采用分层架构设计：

- architecture: 分层架构(UI层/业务逻辑层/设备层/网络服务层)
- design_pattern: 单例模式,状态机(HFSM),观察者模式(信号槽)

1. **UI层** - QML界面和UI控制器
2. **业务逻辑层** - PalmService和状态机(FSM)
3. **设备层** - PalmManager SDK与硬件交互
4. **网络服务层** - 设备注册/认证/同步

### 关键组件

- **PalmService**: 掌纹服务核心类，作为单例提供给QML使用
- **PalmModuleBridge**: 调试视图使用的模组桥接类，与PalmService保持功能分离
- **PalmContext**: 协调Palm服务和状态机之间的通信
- **Palm状态机(HFSM)**: 管理掌纹流程的各个状态和转换

## 核心流程

1. **初始化流程**: 应用启动 → 初始化服务 → 授权验证 → 工作状态
2. **注册流程**: 设置注册模式 → 掌纹采集 → 特征提取 → 绑定用户
3. **识别流程**: 设置识别模式 → 掌纹采集 → 特征匹配 → 身份验证

## 开发建议

- 核心业务功能通过PalmService实现
- 调试和测试功能通过PalmModuleBridge实现
- 新功能开发时遵循状态机设计模式
- 音频反馈参考audio_migration_guide文档
