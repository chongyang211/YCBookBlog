# 第二卷·第七章 合纵连横：顶级博弈不是嘴皮子的胜利，是利益结构的胜利

## 一、开篇锚点：那个用一顿饭把"三方对立"改成"三方结盟"的女合伙人

我先讲一个 2023 年的真实案例。我有一位客户叫她林总，是一家做高端定制服务的公司创始人，她当时陷入了一个极其难解的三方对立——第一方是她公司里最值钱的合伙人 A，技术大拿、客户死忠、出走风险高；第二方是她最重要的战略投资人 B，拿着 30% 股权，对她当前路线极度不满；第三方是她公司里资历最老的副总 C，业务老臣、人脉关系都在他手里、最怕被边缘化。这三个人之间的恩怨结构是 A 看不起 C 觉得他"老古董"、C 嫉妒 A 觉得"凭什么他后来居上股份还高"、B 对 A 和 C 都不满但更倾向于支持 C 来制衡 A。林总夹在中间每一方都可能让她崩盘——如果 A 走了公司核心技术和客户全部带走估值瞬间砍半；如果 B 闹起来可能直接撕股东协议要求清算公司账面立刻雪崩；如果 C 倒戈她原来积累的所有外部资源和老客户会被瞬间转走。她找我咨询那天已经焦虑到失眠两周。

我让她先停下来，不要急着解决问题，先把每个人的"恐惧—欲望—底线"在白板上写出来。我们花了三个小时，最后白板上写得清清楚楚：A 的恐惧是被 C 挤走、股份被稀释，欲望是更高的话语权和分红，底线是技术决策权；B 的恐惧是投资打水漂，欲望是稳定的退出预期，底线是年化回报不能低于某个水平；C 的恐惧是被边缘化、被淘汰，欲望是保住业务地盘和老臣地位，底线是不能让 A 管他。林总看着这个白板看了五分钟，突然说："我懂了，其实他们三个人的诉求并不冲突，是我没把它们结构化。"第二周林总做了一个非常关键的动作——她请这三个人单独吃了三顿饭。第一顿请 A，她说："公司最大的风险是 B 退出，要让 B 不退出需要稳定的业务现金流，现金流的钥匙在 C 手里，所以你要不要主动把和 C 的边界划清楚？技术决策给你，老业务地盘给 C，互不打架，这样 B 看到稳定现金流就不会闹了，而你保住的是技术决策权——这正是你的底线。"A 听完点头。第二顿请 C，她说："公司最大的风险是 A 走人，A 一走技术崩盘，你最怕的是被边缘化，只要你的老业务地盘稳着你就永远不会被边缘化，我会让 A 不再过问你的业务，但作为交换，你也不要在 B 面前说他坏话，B 那边稳定了公司股权稳了你的地盘才能继续稳。"C 听完点头。第三顿请 B，她说："A 和 C 现在已经达成默契，A 管技术 C 管老业务，互不干涉，这意味着公司未来三年现金流稳定，我希望你能延后退出窗口等公司下一轮融资再退，那时候估值会高很多，你的回报率比现在高 30%。"B 听完点头。三顿饭吃完三方都觉得"这个方案对自己最有利"，但实际上林总没有给任何人多分一分钱、没有让任何一个人改变股权结构、没有动公司的任何制度，她只是把"每个人怕什么、想什么、底线是什么"重新整合到一起，让每一方都觉得"和另外两方合作比和他们对抗更划算"。三个月后公司完成了新一轮融资估值翻了一倍。林总后来跟我说："我那三顿饭吃得是真的累，我不是在请客，我是在给三个人重新算账。"我当时听完第一反应是——这不就是苏秦合纵的当代版本吗？苏秦当年游说六国不是去讲什么"团结就是力量"的鸡汤，他是去给六个国君每一个人都算一笔账，让每个人都觉得"加入合纵对自己最有利"。

## 二、史实还原：从锥刺股到挂六国相印，从被弃徒弟到诡道宗师

苏秦和张仪都出自一个传奇的师门——鬼谷子门下。鬼谷子这个人正史里几乎没记载，但在战国时期的影响力是恐怖的——他门下出了苏秦、张仪、孙膑、庞涓，四个人两两对决，一组打仗一组打嘴仗，一手改写了整个战国走向。我们先讲苏秦。苏秦是东周洛阳人出身寒微，他从鬼谷子那里学成下山之后第一次去秦国推销自己——他给秦惠王写了一份长篇大论的"称霸方案"，前后游说了一年多，结果秦惠王理都不理他。为什么？因为这一年是公元前 333 年左右，秦惠王刚刚处死了商鞅，他对"游说之士"有强烈的逆反心理——所有想用嘴皮子来谋富贵的人他一个都不想见。苏秦在秦国待到钱花光、衣服破烂、皮鞋穿透，最后狼狈地回到了洛阳老家。他回家的那一幕《战国策》写得极其生动："妻不下纴，嫂不为炊，父母不与言。"——他妻子在织布机上不肯下来给他打招呼，嫂子不肯给他做饭，父母直接不和他说话。苏秦受到了平生最大的羞辱，他没有发火也没有抱怨，做了一件让所有人意外的事——闭门读书。他从书堆里翻出了一本姜太公留下的《阴符》，关起门来读了整整一年，夜里读书犯困就用锥子扎自己的大腿——"读书欲睡，引锥自刺其股，血流至足"——这就是"锥刺股"的典故。

但这一年里苏秦真正在做的不只是"刻苦"——他在重构自己的整个游说逻辑。第一次去秦国他用的是"怎么帮你称霸"的逻辑——这是一个供给方逻辑，把自己的方案当主角；读完《阴符》之后他换成了"你最怕什么、最想要什么、最不愿失去什么"的逻辑——这是一个需求方逻辑，把对方的恐惧和欲望当主角。这一年的差别有多大？它直接把苏秦从一个"卖方推销员"变成了一个"买方心理操盘手"。一年后苏秦带着这套新逻辑第二次出山，这一次他不再去秦国，而是反其道而行——他要去秦国的对立面找客户。他先去了燕国见燕文侯，对燕文侯说："燕之所以不犯寇被甲兵者，以赵之为蔽其南也。"——燕国之所以不被外敌侵扰是因为赵国在南边挡着秦军。这一句话直接戳中了燕文侯的认知盲点——燕国国君一直觉得"秦国离得远威胁小"，但苏秦告诉他："你以为秦国威胁不到你，是因为赵国在替你挡刀，一旦赵国倒了你就是下一个。"然后苏秦进一步说："所以你最该做的不是和秦国结好，而是花钱让赵国挡得更稳——你和我（赵）联盟比你和秦国联盟划算一百倍。"燕文侯被说服立即给苏秦提供车马金帛让他去赵国。

苏秦到了赵国见赵肃侯，又用了一套完全不同的话术——"秦攻赵，唯一的办法是先取韩、魏，再取赵，所以韩魏就是赵国的天然屏障，如果韩魏倒了赵国必亡，所以你最该做的不是和韩魏争利，而是把韩魏拉过来一起抗秦。"赵肃侯被说服。然后苏秦依次去了韩、魏、齐、楚——每到一国他都用一套不同的话术给那个国君算一笔属于他自己的账：对韩宣王算的是"韩国土地虽小但地利极强，握有铁山，铁山产精兵——你不抗秦谁抗秦"，用面子激将；对魏襄王算的是"魏国是中原核心，秦不取魏不能东进——你才是秦国的眼中钉"，用恐惧驱动；对齐宣王算的是"齐国富甲天下，地势险要，你不需要怕秦国，但你需要确保中原的市场不落入秦国之手"，用利益重构；对楚威王算的是"秦楚不能并立，要么你吃他、要么他吃你，合纵就是要联合所有人吃秦国"，用野心催化。六国全部被说服，公元前 333 年六国会盟于洹水签下合纵盟约，苏秦同时担任六国相国挂六国相印。这一刻是苏秦人生的巅峰，整个战国格局因为他一个人的嘴发生了根本性的扭转——秦国吓坏了，整整十五年秦兵不敢出函谷关一步。苏秦回洛阳路过家乡时，那个曾经"嫂不为炊、妻不下纴"的家庭全家跪在路边迎接他，他的嫂子甚至蛇行而前伏地不敢抬头，苏秦笑着问："嫂何前倨而后卑也？"嫂子回答："以季子之位尊而多金。"苏秦长叹一声："嗟乎！贫穷则父母不子，富贵则亲戚畏惧——人生世上，势位富厚，盖可忽乎哉！"这一句饱含血泪的人生总结，是中国历史上对"人情冷暖"最真实、最透彻的一段话。但苏秦的辉煌只持续了十五年，他最后死于齐国的一场政治暗杀。苏秦死后合纵盟约开始一点一点松动，而专门负责拆这个盟约的就是苏秦的"师弟"张仪。

张仪和苏秦同出鬼谷子门下，但张仪的出身比苏秦还惨——他第一次出门游说时被楚国令尹昭阳怀疑偷了一块玉璧痛打了一顿几乎丧命。回家之后张仪躺在床上问妻子："视吾舌尚在不？"妻子笑着回答："舌在也。"张仪说："足矣。"——这个"舌在足矣"的典故奠定了张仪一生的人格底色：只要嘴还在一切都能翻盘。张仪去秦国的时间比苏秦稍晚，当时苏秦已经搞定六国合纵秦国正在头疼怎么破，张仪一到秦国秦惠王眼前一亮——这是他等了十五年的人。张仪的策略和苏秦完全相反——苏秦是"团结弱者打强者"，张仪是"拆散弱者归附强者"。张仪的连横分两步走。第一步把楚国从合纵里拆出来——楚国是六国合纵里最强、最关键的一环，楚国一倒合纵立刻崩。张仪去楚国对楚怀王说："秦愿意把商於六百里的土地割让给楚国，条件是楚国和齐国绝交。"楚怀王听完欣喜若狂——六百里土地不要白不要——立刻和齐国绝交。绝交完之后楚怀王派人去秦国接收土地，张仪笑着对使者说："我答应给的是商於六里，不是六百里——是楚王听错了。"楚怀王气得当场吐血，他不仅没拿到地还把齐国这个最大的盟友丢了，怒之下楚国出兵伐秦结果在丹阳大败——楚国从此一蹶不振。张仪用一句话把六国合纵里最关键的一环楚国彻底打废了。第二步依次游说五国，每个都给一套定制话术——对韩王强调韩国土地贫瘠兵弱粮少"你不归附秦国秦国第一个吃的就是你"，用恐惧驱动；对赵王强调齐楚已散合纵已废"继续坚持合纵就是给死人当殉葬品"，用现实驱动；对魏王强调魏国地处四战之地"你和秦国结盟秦国就替你挡其他国家"，用安全驱动；对燕王强调齐国威胁"你不归附秦国齐国就要吞你"，用次级威胁驱动；对齐王强调"秦不会动齐——只要你不掺和合纵"，用稳定驱动。五国全部被说服，苏秦花十几年攒起来的合纵联盟被张仪用几年时间全部拆光。到张仪死的时候（公元前 309 年）战国格局已经基本定型：秦国独大；六国互相猜忌；任何一国都不再相信"集体抗秦"；秦国可以逐个击破、一步步蚕食——直到秦始皇时代完成统一。张仪和苏秦——一个用嘴搭起了六国联盟，一个用嘴拆掉了六国联盟，两个人的本事都在那张嘴上，但更深一层都在那张嘴背后的"算账能力"上。

## 三、破局解读：合纵和连横到底靠什么逻辑成立？

读到这里你可能会觉得苏秦张仪很神奇——怎么一张嘴就能改变国家命运？但如果你只看到嘴你就把他们看小了，我们必须把他们的"嘴功"拆解到底层，看他们到底用了什么方法。

**第一层，他们有完整的"对方画像"——把每个国君当一个独立的"用户"来研究**。苏秦张仪游说六国每一国都用了不同的话术，这不是凑巧，是他们事先做了非常深入的"用户画像"。每一个国君都有自己的当下处境（土地、兵力、外部威胁）、核心恐惧（最怕的是什么）、核心欲望（最想得到的是什么）、底线红线（绝对不能让步的是什么）、决策风格（情绪型、利益型、权威型）。苏秦对燕文侯讲赵国挡刀（恐惧型话术），对齐宣王讲市场利益（利益型话术），对楚威王讲野心（欲望型话术）——每一国君的话术都是定制的。张仪也是一样，对楚怀王用"利诱"（六百里土地），对韩王用"威胁"（你第一个被吃），对齐王用"安抚"（你不掺和我就不动你）——每一句话都精确瞄准了那个国君脑子里最大的那根神经。这就是博弈论里的信号定制——同样一个目标对不同的人要用不同的话。回到林总的故事，她那三顿饭之所以管用正是因为她事先把 A、B、C 的"恐惧—欲望—底线"摸得一清二楚，然后给每个人讲一套属于他自己的话术。这条铁律在今天极其重要——今天大多数销售、谈判、说服的人犯的最大错误就是"一套话术打天下"，同样的话讲给所有人听，结果谁都没说服，因为不同的人脑子里关心的事完全不同。

**第二层，他们用"利益重构"取代"道理说服"——不讲对错只讲利益**。苏秦合纵的核心论证是什么？不是"团结起来抗秦是正义的"——他从来不讲正义；是"抗秦对你最有利"——他只讲利益。苏秦对每个国君讲的核心句式都是："你现在的局面是 X，如果继续这样下去你会失去 Y；如果加入合纵你会得到 Z；所以加入合纵对你来说是最优选。"这是一个典型的利益重构句式——现状描述（拉对方进当前情境）、后果放大（描绘最可怕的下行场景）、替代方案（给出最优选）、临门一脚（强调"对你来说"是最优选）。张仪连横用的是同样的句式只不过把"加入合纵"换成"和秦国结盟"。这才是顶级游说者真正的看家本领——不和对方辩论"什么是对的"，只算账"什么是对你最有利的"。回到林总，她和 A、B、C 三个人讲话时从来没有讲过"你应该顾全大局、要互相理解、要有团队精神"——这种讲道理的话谁都不会听，她讲的全部是利益账。这条铁律在今天职场里同样关键——当你想说服任何人时永远不要讲道理，永远讲他的利益。"你这样做，公司能怎样"——没用；"你这样做，你能怎样"——才有用。

**第三层，他们用"恐惧驱动 大于 利益驱动"——人对损失的敏感度是对收益的两倍**。这是行为经济学里早就证明过的一条铁律——人对损失的痛感是同等收益的两倍（卡尼曼的"前景理论"）。苏秦张仪虽然不知道前景理论但他们直觉地用了。苏秦对每个国君讲的第一段都是"如果不加入合纵你会失去什么"，而不是"如果加入合纵你会得到什么"；张仪对每个国君讲的第一段也是"如果不归附秦国你会被怎样"，而不是"如果归附秦国你会得到什么"。为什么？因为用"失去"开头对方的肾上腺素会立刻飙升，用"得到"开头对方会半信半疑。张仪对楚怀王那一招——"商於六百里"——表面看是利诱，实际上背后还有一句潜台词："你和齐国合纵也得不到这么多，错过这次你以后再也得不到"，这一句"错过这次再也得不到"才是真正的钩子——让楚怀王从"得到"的兴奋里进入"怕错过"的焦虑里。这条铁律在今天的销售、谈判、说服里几乎是黄金定律——不要说"买这个产品你会得到什么"要说"不买这个产品你会失去什么"，不要说"接受这个方案你会有什么收益"要说"拒绝这个方案你会有什么损失"，不要说"加入我们你会得到机会"要说"不加入我们你会错过机会"。永远把"恐惧"放在"利益"前面讲，这是顶级说服者从苏秦张仪那里继承下来的、最有用的一条心法。

**第四层，他们都懂"可信度的稀缺性"——一个人能说服多大的局，取决于他被证明过多少次**。苏秦能挂六国相印背后有一个被忽略的关键——他先搞定了燕国和赵国，搞定了这两个之后他去韩国时韩王心里已经在想"燕赵都加入了那我也得加入"，搞定韩国之后他去魏国魏王的心理压力更大"韩赵燕都加入了"，等他到齐楚的时候他已经不需要游说了，他的身份本身就是最大的说服力——这就是博弈中"信誉的复利效应"，一个人前期搞定的局越多后期搞定新局的难度越低。张仪也是同样的逻辑，他先打废了楚国，这一仗下来他在剩下五国国君面前的可信度直接拉满。回到林总，她为什么能在三顿饭之内搞定 A、B、C 三个人？因为她不是按"难易度"顺序请的，她是按"信誉传递"顺序请的——第一顿请 A（最容易动的人），拿到 A 的认同之后第二顿请 C 可以暗示"A 已经表态愿意分边界了"，拿到 C 的认同之后第三顿请 B 可以告诉"A 和 C 已经达成默契"——B 看到的是一个已经稳定的局，三场谈话之间是有"信誉传递"的，前一场的胜利是后一场的最大筹码。这条铁律的现代启示极其重要——当你要做一件大事时永远不要把所有人同时拉到一桌，而是按信誉传递的顺序一个一个搞定。

**第五层，他们都懂"利益结构 大于 个人魅力"——一旦利益结构变化，再好的盟友也会反目**。这是合纵连横最深的一层逻辑。苏秦合纵之所以能成立不是因为他嘴巴多厉害，是因为那个时候六国对秦国的恐惧足够大，利益结构支持合纵；苏秦合纵之所以会瓦解也不是张仪嘴巴比苏秦更厉害，是因为利益结构变了——秦国开始用"分而治之"的策略给每个国家单独的甜头，当每个国家都觉得"我自己单独和秦国谈更划算"的时候合纵就崩了。任何联盟的本质都是利益结构，利益结构稳联盟稳，利益结构变联盟散——没有永恒的盟友只有永恒的利益结构。这一条放到今天同样适用，公司里的派系、行业里的联盟、政治里的同盟全部都建立在利益结构上：当利益结构不变时再大的矛盾都打不散；当利益结构变了时再深的友谊都会破碎。林总那个三方对立的局之所以能解开根本不是因为她的三顿饭，是因为她重新设计了一个"三方都能受益"的利益结构——A 拿决策权、C 拿地盘、B 拿稳定退出，只有当三个人都能在新结构里活得更好时他们才愿意放下旧的对立。

## 四、现实映射：今天哪些场景里你会遇到"合纵连横"？

读到这里你会发现——合纵连横不是历史，是每天都在发生的现实。我给你看四个真实场景。

第一个是商业谈判中的"分而治之"。我有一位做并购的朋友，他们公司想收购一家行业老二，但老二的股权结构非常分散——七个创始合伙人每人 10%-20%，如果直接和七个人谈"被收购"七个人会立刻抱团涨价，这就是合纵。他用的是连横策略：先单独找最弱的那一个——一个对公司未来最悲观的合伙人——给他一个远高于市场价的退出价格让他先签字；然后拿着第一个人的签字去找第二个，告诉第二个人"已经有人卖了，剩下的人股价会被稀释，你越早卖越值钱"；第三个、第四个、第五个，每签一个剩下的人卖出价就降一档，最后剩下的两个老大手里只剩 30% 不到的股权，完全失去了谈判筹码，只能接受最低价。这就是张仪的连横在现代商业里的经典翻版——永远不要让对手抱团，要把他们一个一个拆开。

第二个是职场里的"利益重构"破解多方博弈。我自己当年带团队时遇到过一次。一个项目里有三个核心干将——老张（业务老臣）、小李（技术骨干）、阿强（销售明星），三个人因为分工不清互相争抢功劳，已经到了互相打小报告的程度。我没有去开"团队建设大会"，也没有去讲"团队精神"，做的事和林总一样——单独找他们三个吃饭，每个人讲一套属于他自己的"利益账"：对老张讲"项目失败你要担最大的责，所以你最该做的是让小李的技术稳、阿强的销售旺"，用风险驱动；对小李讲"你想升技术总监但你需要业务和销售背书你的方案，你越和老张阿强对着干他们越不会替你说话"，用前途驱动；对阿强讲"你想保住销售第一的位置需要老张的客户资源和小李的产品支持，这两条线一断你下一年就不是第一了"，用现实驱动。三顿饭吃完他们三个之间默契地分了边界，项目当年做成，三个人都升了。这就是合纵连横在职场里的应用——不讲对错只算利益，让每一方都觉得"和另外两方合作对我最有利"。

第三个是跨部门协作中的"恐惧驱动"。很多职场人发现一个现象——跨部门请人帮忙讲"这事对公司有好处"基本没用，为什么？因为对方根本不在乎"对公司"，他在乎的是"对我"。会用合纵连横的人怎么讲？不讲"这事对公司有好处"——讲"这事如果搞砸老板会怎么看你"；不讲"你帮我一下吧"——讲"这事如果你不帮，到时候出问题背锅的可能是你"。不是让你阴险，是让你换个语言——把"利益驱动"换成"恐惧驱动"，效率立刻翻倍。

第四个是合伙人或股东之间的"利益结构再造"。这是最高阶的应用，一个团队最容易散伙的时候不是穷的时候是开始赚钱的时候——因为利益结构变了原来的分配方案不再公平。聪明的合伙人懂得：当利益结构发生变化时必须重新设计利益分配方案，而且要让"每一方都觉得新方案对自己更有利"。我见过最高明的一次合伙人重构是这样的——三个合伙人原来 1:1:1 平分股权，三年后业务发展不平衡：一个人贡献 70%，另一个 20%，第三个 10%；创始人没有强行调股权，而是设计了一套"动态分红 + 静态股权"的混合方案——股权比例不变（保住情谊和退出预期），但当年的现金分红按贡献分（保住公平和激励），三个人都觉得"对我更有利"，这就是利益结构再造。

## 五、史镜启示录：写给当下的你

苏秦张仪给我们的不是"嘴皮子要利"，是"算账能力要强"——真正的说服从来不靠嘴，靠的是你能不能在三秒之内把对方脑子里所有的恐惧、欲望、利益、面子全部算清楚。我提炼成五条铁律。第一条，永远不要"一套话术打天下"——给每个人定制属于他的话术，苏秦给六个国君用了六套话术，今天你想说服任何一个人先做画像再开口，对方最怕什么、最想要什么、最不愿失去什么，这三件事不弄清楚你说什么都没用。第二条，永远不要"讲道理"——只算利益账，没有人愿意听道理，所有人都在乎"对我"两个字，任何说服的本质是把"我希望你这样做"翻译成"你这样做对你最有利"，翻译能力决定说服效率。第三条，永远把"恐惧"放在"利益"前面讲——损失痛感是收益感的两倍，不要说"做这件事你会得到什么"要说"不做这件事你会失去什么"，人对失去的敏感度永远比对得到的高，顶级说服者从苏秦张仪到当代销售大师全部都是先讲恐惧再讲收益。第四条，说服是一个"信誉复利"游戏——按顺序搞定不要一锅端，当你要搞定一个多方博弈时永远从最容易的那个开始然后用他的认同去搞下一个，不要把所有人同时拉到一桌——同时拉到一桌每个人都在观察"别人怎么反应"，所有人都不敢先表态，一对一谈、逐个突破，这是合纵连横最古老也最有用的智慧。第五条，没有永恒的盟友只有永恒的利益结构——重建联盟先重建结构，任何联盟一旦发生矛盾根本原因永远是利益结构变了，不要试图用"情怀"修复矛盾，情怀修复不了利益不平衡，重新设计利益结构让每一方都能在新结构里得到他想要的——联盟才能重建。

最后我必须再加一句——苏秦张仪给我们的不只是"说服别人的方法"，更是"看透自己被人说服的方法"。当你下一次被某个销售、某个领导、某个合伙人轻易说服的时候，请你停下来想一想：他是不是在用"恐惧驱动"操控我？他是不是在给我"定制话术"？他是不是在用"信誉复利"压我？他给我的方案，真的对我最有利，还是对他最有利？会用合纵连横的人，最先学会的是不被合纵连横。
