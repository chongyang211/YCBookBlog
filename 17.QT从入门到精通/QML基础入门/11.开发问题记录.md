## 11.1 监听网络状态


在 QML 中，可以通过 `Qt.network` 模块中的 `QNetworkAccessManager` 或 `QNetworkConfigurationManager` 来监听网络状态变化。以下是实现监听网络状态变化的常见方法：

---

### 方法 1：使用 `QNetworkConfigurationManager`
`QNetworkConfigurationManager` 是一个专门用于管理网络配置的类，它可以监听网络状态的变化。

#### 步骤：
1. 在 QML 中使用 `Connections` 绑定信号。
2. 通过 `QNetworkConfigurationManager` 的 `onlineStateChanged` 信号监听网络状态变化。

#### 示例代码：
```qml
import QtQuick 2.15
import QtQuick.Controls 2.15
import Qt.network 1.0

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "网络状态监听"

    // 网络状态管理器
    NetworkConfigurationManager {
        id: networkManager
    }

    Text {
        id: statusText
        text: networkManager.online ? "网络在线" : "网络离线"
        anchors.centerIn: parent
    }

    Connections {
        target: networkManager
        onOnlineStateChanged: {
            if (networkManager.online) {
                statusText.text = "网络在线"
            } else {
                statusText.text = "网络离线"
            }
        }
    }
}
```

#### 说明：
- `NetworkConfigurationManager` 是 QML 对 `QNetworkConfigurationManager` 的封装。
- `online` 属性表示当前网络是否在线。
- `onlineStateChanged` 信号会在网络状态变化时触发。

---

### 方法 2：使用 `QNetworkAccessManager` 和定时器轮询
如果需要更灵活的方式，可以使用 `QNetworkAccessManager` 定期发送请求来检测网络状态。

#### 示例代码：
```qml
import QtQuick 2.15
import QtQuick.Controls 2.15
import Qt.network 1.0

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "网络状态监听"

    // 网络访问管理器
    NetworkAccessManager {
        id: networkManager
    }

    Timer {
        interval: 5000 // 每5秒检查一次网络状态
        running: true
        repeat: true
        onTriggered: {
            var request = new XMLHttpRequest()
            request.open("GET", "https://www.google.com", true)
            request.onreadystatechange = function() {
                if (request.readyState === XMLHttpRequest.DONE) {
                    if (request.status === 200) {
                        statusText.text = "网络在线"
                    } else {
                        statusText.text = "网络离线"
                    }
                }
            }
            request.send()
        }
    }

    Text {
        id: statusText
        text: "正在检测网络状态..."
        anchors.centerIn: parent
    }
}
```

#### 说明：
- 使用 `Timer` 定时发送 HTTP 请求来检测网络状态。
- 根据请求的返回状态码判断网络是否在线。

---

### 方法 3：结合 C++ 实现更复杂的网络监听
如果需要更复杂的网络状态监听（例如监听具体的网络接口状态），可以在 C++ 中使用 `QNetworkConfigurationManager` 或 `QNetworkInterface`，然后通过 `QML` 与 C++ 交互。

#### C++ 示例：
```cpp
#include <QNetworkConfigurationManager>
#include <QNetworkSession>
#include <QObject>

class NetworkMonitor : public QObject {
    Q_OBJECT
public:
    explicit NetworkMonitor(QObject *parent = nullptr) : QObject(parent) {
        connect(&manager, &QNetworkConfigurationManager::onlineStateChanged, this, &NetworkMonitor::onOnlineStateChanged);
    }

signals:
    void networkStateChanged(bool online);

private slots:
    void onOnlineStateChanged(bool online) {
        emit networkStateChanged(online);
    }

private:
    QNetworkConfigurationManager manager;
};
```

#### QML 示例：
```qml
import QtQuick 2.15
import QtQuick.Controls 2.15

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "网络状态监听"

    Text {
        id: statusText
        text: "正在检测网络状态..."
        anchors.centerIn: parent
    }

    Connections {
        target: networkMonitor
        onNetworkStateChanged: {
            statusText.text = online ? "网络在线" : "网络离线"
        }
    }
}
```

#### 说明：
- 在 C++ 中监听网络状态变化，并通过信号将状态传递到 QML。
- 这种方式适合需要更复杂的网络状态监控场景。

---

### 总结
- 如果只是简单地监听网络在线/离线状态，推荐使用 `QNetworkConfigurationManager` 的 `onlineStateChanged` 信号。
- 如果需要更灵活的检测方式，可以使用 `QNetworkAccessManager` 和定时器轮询。
- 对于复杂的网络状态监控，可以结合 C++ 实现更高级的功能。

根据具体需求选择合适的方法即可！
