## 11.1 监听网络状态

在 QML 中，监听网络状态变化（例如 Wi-Fi连接和断开、以太网、移动网络、有网络和无网络）需要结合 Qt 的 C++ 网络模块（如 `QNetworkConfigurationManager` 和 `QNetworkInterface`）来实现。

### 11.1.1 QNetworkConfigurationManager

`QNetworkConfigurationManager` 是 Qt 提供的类，用于监听网络状态变化，包括网络在线/离线状态以及网络配置的变化。

1. 创建一个 C++ 类 `NetworkMonitor` 来监听网络状态变化，并将状态信息传递到 QML。
2. 在 `main.cpp` 中注册 `NetworkMonitor` 类到 QML。
3. 在 QML 中使用 `NetworkMonitor` 来监听网络状态变化。使用 `Connections` 绑定信号。

C++ 实现。在这个里面，做网络监听的逻辑。

```cpp
#include <QNetworkConfigurationManager>
#include <QNetworkConfiguration>
#include <QObject>

class NetworkMonitor : public QObject {
    Q_OBJECT
public:
    explicit NetworkMonitor(QObject *parent = nullptr) : QObject(parent) {
        connect(&manager, &QNetworkConfigurationManager::onlineStateChanged, this, &NetworkMonitor::onOnlineStateChanged);
        connect(&manager, &QNetworkConfigurationManager::configurationChanged, this, &NetworkMonitor::onConfigurationChanged);
    }

    Q_INVOKABLE bool isOnline() const {
        return manager.isOnline();
    }

    Q_INVOKABLE QString getActiveNetworkType() const {
        for (const QNetworkConfiguration &config : manager.allConfigurations(QNetworkConfiguration::Active)) {
            if (config.bearerType() == QNetworkConfiguration::BearerWLAN) {
                return "Wi-Fi";
            } else if (config.bearerType() == QNetworkConfiguration::BearerEthernet) {
                return "Ethernet";
            } else if (config.bearerType() == QNetworkConfiguration::Bearer2G ||
                       config.bearerType() == QNetworkConfiguration::Bearer3G ||
                       config.bearerType() == QNetworkConfiguration::Bearer4G ||
                       config.bearerType() == QNetworkConfiguration::Bearer5G) {
                return "Mobile Network";
            }
        }
        return "No Network";
    }

signals:
    void onlineStateChanged(bool online);
    void configurationChanged();

private slots:
    void onOnlineStateChanged(bool online) {
        emit onlineStateChanged(online);
    }

    void onConfigurationChanged() {
        emit configurationChanged();
    }

private:
    QNetworkConfigurationManager manager;
};
```

注册到 QML。在 `main.cpp` 中注册 `NetworkMonitor` 类到 QML。

```cpp
int main(int argc, char *argv[]) {
    NetworkMonitor networkMonitor;
    engine.rootContext()->setContextProperty("networkMonitor", &networkMonitor);
    return app.exec();
}
```

QML 使用。在 QML 中使用 `NetworkMonitor` 来监听网络状态变化。

```qml
import QtQuick 2.15
import QtQuick.Controls 2.15

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "网络状态监听"

    Text {
        id: statusText
        text: networkMonitor.isOnline() ? "网络在线" : "网络离线"
        anchors.centerIn: parent
    }

    Text {
        id: networkTypeText
        text: "当前网络类型: " + networkMonitor.getActiveNetworkType()
        anchors.top: statusText.bottom
        anchors.horizontalCenter: parent.horizontalCenter
        anchors.topMargin: 10
    }

    Connections {
        target: networkMonitor
        onOnlineStateChanged: {
            statusText.text = online ? "网络在线" : "网络离线"
        }
        onConfigurationChanged: {
            networkTypeText.text = "当前网络类型: " + networkMonitor.getActiveNetworkType()
        }
    }
}
```

说明

- `onlineStateChanged` 信号会在网络在线/离线状态变化时触发。
- `configurationChanged` 信号会在网络配置发生变化时触发（例如切换 Wi-Fi 或以太网）。
- `getActiveNetworkType` 方法返回当前活动的网络类型（如 Wi-Fi、以太网或移动网络）。

### 11.1.2 QNetworkAccessManager

如果需要更灵活的方式，可以使用 `QNetworkAccessManager` 定期发送请求来检测网络状态。 示例代码：

```qml
import QtQuick 2.15
import QtQuick.Controls 2.15
import Qt.network 1.0

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "网络状态监听"

    // 网络访问管理器
    NetworkAccessManager {
        id: networkManager
    }

    Timer {
        interval: 5000 // 每5秒检查一次网络状态
        running: true
        repeat: true
        onTriggered: {
            var request = new XMLHttpRequest()
            request.open("GET", "https://www.google.com", true)
            request.onreadystatechange = function() {
                if (request.readyState === XMLHttpRequest.DONE) {
                    if (request.status === 200) {
                        statusText.text = "网络在线"
                    } else {
                        statusText.text = "网络离线"
                    }
                }
            }
            request.send()
        }
    }

    Text {
        id: statusText
        text: "正在检测网络状态..."
        anchors.centerIn: parent
    }
}
```

说明：

- 使用 `Timer` 定时发送 HTTP 请求来检测网络状态。
- 根据请求的返回状态码判断网络是否在线。


### 11.1.3 QNetworkInterface网络监听

如果需要更复杂的网络状态监听（例如监听具体的网络接口状态），可以在 C++ 中使用 `QNetworkConfigurationManager` 或 `QNetworkInterface`，然后通过 `QML` 与 C++ 交互。

C++ 实现，使用 `QNetworkInterface` 检测具体网络接口状态。

```cpp
#include <QNetworkInterface>
#include <QObject>

class NetworkMonitor : public QObject {
    Q_OBJECT
public:
    explicit NetworkMonitor(QObject *parent = nullptr) : QObject(parent) {}

    Q_INVOKABLE QString getActiveNetworkType() const {
        for (const QNetworkInterface &interface : QNetworkInterface::allInterfaces()) {
            if (interface.flags().testFlag(QNetworkInterface::IsUp) &&
                interface.flags().testFlag(QNetworkInterface::IsRunning)) {
                if (interface.type() == QNetworkInterface::Wifi) {
                    return "Wi-Fi";
                } else if (interface.type() == QNetworkInterface::Ethernet) {
                    return "Ethernet";
                } else if (interface.type() == QNetworkInterface::Loopback) {
                    return "Loopback";
                }
            }
        }
        return "No Network";
    }
};
```

注册到 QML 。在 `main.cpp` 中注册 `NetworkMonitor` 类。

```cpp
int main(int argc, char *argv[]) {
    NetworkMonitor networkMonitor;
    engine.rootContext()->setContextProperty("networkMonitor", &networkMonitor);
}
```

在 QML 中调用 `getActiveNetworkType` 来获取当前网络类型。

```qml
import QtQuick 2.15
import QtQuick.Controls 2.15

ApplicationWindow {
    visible: true
    width: 400
    height: 300
    title: "网络状态监听"

    Text {
        id: statusText
        text: "当前网络类型: " + networkMonitor.getActiveNetworkType()
        anchors.centerIn: parent
    }

    Timer {
        interval: 5000 // 每5秒检查一次网络状态
        running: true
        repeat: true
        onTriggered: {
            statusText.text = "当前网络类型: " + networkMonitor.getActiveNetworkType()
        }
    }
}
```

说明

- `getActiveNetworkType` 方法会返回当前活动的网络类型（例如 Wi-Fi 或以太网）。
- 使用 `Timer` 定时检查网络状态。


### 11.1.4 监听网络状态总结一下

- **监听网络在线/离线状态**：使用 `QNetworkConfigurationManager` 的 `onlineStateChanged` 信号。
- **检测具体网络接口状态**：使用 `QNetworkInterface` 获取活动网络类型（例如 Wi-Fi 或以太网）。
- **检测网络连通性**：使用 `QNetworkAccessManager` 或 `XMLHttpRequest` 定期发送请求。
