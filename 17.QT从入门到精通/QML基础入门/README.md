## 09.QML和C++

- 9.1.1 QML和C++概念：开发者将 QML 的灵活性和易用性与 C++ 的强大功能结合起来。qml专注UI，c++专注业务逻辑。
- 9.1.2 两者为何集成：通过集成，QML 可以专注于界面设计，而 C++ 负责处理复杂的逻辑和性能优化。
