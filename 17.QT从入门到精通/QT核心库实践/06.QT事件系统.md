## 6.1 事件系统

Qt 的事件系统基于事件循环（Event Loop）和事件过滤器（Event Filter），开发者可以通过重写事件处理函数或安装事件过滤器来拦截和处理事件。

## 6.2 QT事件处理

### 6.2.1 事件循环

Qt 应用程序的核心是事件循环，它负责接收和分发事件。事件循环由 `QCoreApplication::exec()` 启动。

```cpp
#include <QApplication>
#include <QDebug>

int main(int argc, char *argv[]) {
    QApplication app(argc, argv);
    qDebug() << "Event loop started";
    return app.exec(); // 启动事件循环
}
```

### 6.2.2 事件处理函数

Qt 中的事件处理函数是 `QObject` 的成员函数，可以通过重写这些函数来处理特定事件。

**1.常用事件处理函数**

- **`mousePressEvent(QMouseEvent *)`**：处理鼠标按下事件。
- **`mouseMoveEvent(QMouseEvent *)`**：处理鼠标移动事件。
- **`keyPressEvent(QKeyEvent *)`**：处理键盘按下事件。
- **`paintEvent(QPaintEvent *)`**：处理绘制事件。
- **`resizeEvent(QResizeEvent *)`**：处理窗口大小调整事件。
- **`closeEvent(QCloseEvent *)`**：处理窗口关闭事件。

**2.示例：重写事件处理函数**

```cpp
#include <QWidget>
#include <QMouseEvent>
#include <QDebug>

class MyWidget : public QWidget {
protected:
    void mousePressEvent(QMouseEvent *event) override {
        qDebug() << "Mouse pressed at:" << event->pos();
    }

    void keyPressEvent(QKeyEvent *event) override {
        qDebug() << "Key pressed:" << event->text();
    }
};

int main(int argc, char *argv[]) {
    QApplication app(argc, argv);
    MyWidget widget;
    widget.resize(200, 200);
    widget.show();
    return app.exec();
}
```

### **3. 事件过滤器（Event Filter）**
事件过滤器允许一个对象拦截并处理另一个对象的事件。

#### **3.1 安装事件过滤器**
```cpp
#include <QApplication>
#include <QWidget>
#include <QDebug>

class EventFilter : public QObject
{
protected:
    bool eventFilter(QObject *obj, QEvent *event) override {
        if (event->type() == QEvent::MouseButtonPress) {
            qDebug() << "Mouse pressed in:" << obj->objectName();
            return true; // 事件已被处理
        }
        return QObject::eventFilter(obj, event);
    }
};

int main(int argc, char *argv[])
{
    QApplication app(argc, argv);

    QWidget widget;
    widget.setObjectName("MainWidget");

    EventFilter filter;
    widget.installEventFilter(&filter); // 安装事件过滤器

    widget.resize(200, 200);
    widget.show();

    return app.exec();
}
```

### **4. 自定义事件**
Qt 允许开发者创建和发送自定义事件。

#### **4.1 定义自定义事件**
```cpp
#include <QEvent>

const QEvent::Type MyCustomEventType = static_cast<QEvent::Type>(QEvent::User + 1);

class MyCustomEvent : public QEvent
{
public:
    MyCustomEvent(const QString &message)
        : QEvent(MyCustomEventType), m_message(message) {}

    QString message() const { return m_message; }

private:
    QString m_message;
};
```

#### **4.2 发送自定义事件**
```cpp
#include <QApplication>
#include <QWidget>
#include <QDebug>

class MyWidget : public QWidget
{
protected:
    void customEvent(QEvent *event) override {
        if (event->type() == MyCustomEventType) {
            MyCustomEvent *customEvent = static_cast<MyCustomEvent *>(event);
            qDebug() << "Custom event received:" << customEvent->message();
        }
    }
};

int main(int argc, char *argv[])
{
    QApplication app(argc, argv);

    MyWidget widget;
    widget.resize(200, 200);
    widget.show();

    // 发送自定义事件
    MyCustomEvent event("Hello, Custom Event!");
    QApplication::postEvent(&widget, &event);

    return app.exec();
}
```

### **5. 定时器事件**
Qt 提供了定时器功能，可以通过重写 `timerEvent()` 来处理定时器事件。

#### **5.1 使用定时器**
```cpp
#include <QWidget>
#include <QDebug>

class MyWidget : public QWidget
{
public:
    MyWidget() {
        // 启动定时器，间隔 1000 毫秒
        startTimer(1000);
    }

protected:
    void timerEvent(QTimerEvent *event) override {
        qDebug() << "Timer event triggered";
    }
};

int main(int argc, char *argv[])
{
    QApplication app(argc, argv);

    MyWidget widget;
    widget.resize(200, 200);
    widget.show();

    return app.exec();
}
```

### **3. 事件处理**
Qt 提供了多种方式来处理事件：

#### **方法 1：重写事件处理函数**
在自定义的 `QWidget` 或 `QObject` 子类中，重写特定的事件处理函数。例如：
```cpp
class MyWidget : public QWidget {
protected:
    void mousePressEvent(QMouseEvent *event) override {
        qDebug() << "Mouse pressed at:" << event->pos();
    }

    void keyPressEvent(QKeyEvent *event) override {
        qDebug() << "Key pressed:" << event->text();
    }
};
```

#### **方法 2：重写 `event()` 函数**
通过重写 `QObject::event()` 函数，可以处理所有事件：
```cpp
class MyWidget : public QWidget {
protected:
    bool event(QEvent *event) override {
        if (event->type() == QEvent::MouseButtonPress) {
            qDebug() << "Mouse press event detected!";
            return true; // 事件已处理
        }
        return QWidget::event(event); // 其他事件交给父类处理
    }
};
```

#### **方法 3：安装事件过滤器**
通过 `QObject::installEventFilter()`，可以监听其他对象的事件：
```cpp
class MyFilter : public QObject {
protected:
    bool eventFilter(QObject *obj, QEvent *event) override {
        if (event->type() == QEvent::KeyPress) {
            qDebug() << "Key press event filtered!";
            return true; // 事件已处理
        }
        return QObject::eventFilter(obj, event); // 其他事件交给父类处理
    }
};

// 使用事件过滤器
MyFilter filter;
myWidget->installEventFilter(&filter);
```

#include <QEvent>

QCoreApplication::postEvent(&widget, new MyCustomEvent());

### **5. 事件传播**
- **事件传播**：事件会从子对象向父对象传播，直到被处理或到达顶层对象。

            在 Qt 中，`QCoreApplication` 是 Qt 应用程序框架的核心类之一，用于管理应用程序的控制流、事件循环和全局设置。它是所有基于 Qt 的应用程序的基础，无论是控制台应用程序还是 GUI 应用程序（`QApplication` 是 `QCoreApplication` 的子类，专门用于 GUI 应用程序）。

以下是关于 `QCoreApplication` 的详细说明和常见用法：

---

### **1. `QCoreApplication` 的作用**
- **事件循环管理**：`QCoreApplication` 负责启动和管理事件循环，处理事件（如定时器事件、网络事件、自定义事件等）。
- **应用程序生命周期**：管理应用程序的启动、运行和退出。
- **全局设置**：提供对应用程序名称、版本、路径等全局属性的访问。
- **信号与槽机制**：支持 Qt 的信号与槽机制，用于对象之间的通信。

---

### **2. 基本用法**
#### **创建一个控制台应用程序**
```cpp
#include <QCoreApplication>
#include <QDebug>

int main(int argc, char *argv[])
{
    QCoreApplication app(argc, argv);

    qDebug() << "Hello, this is a Qt console application!";

    return app.exec(); // 进入事件循环
}
```
- `QCoreApplication app(argc, argv);`：创建应用程序对象。
- `app.exec();`：启动事件循环，直到应用程序退出。

### **4. 事件循环**
`QCoreApplication` 的核心功能是管理事件循环。事件循环通过 `exec()` 启动，直到调用 `quit()` 或 `exit()` 时结束。

#### **手动处理事件**
在事件循环中，可以手动处理未处理的事件：
```cpp

```

#### **定时退出**
```cpp

```

### **5. 信号与槽**
`QCoreApplication` 支持信号与槽机制。例如，可以连接信号到槽函数以处理特定事件：
```cpp
#include <QCoreApplication>
#include <QTimer>
#include <QDebug>

int main(int argc, char *argv[])
{
    QCoreApplication app(argc, argv);

    QTimer timer;
    QObject::connect(&timer, &QTimer::timeout, []() {
        qDebug() << "Timer triggered!";
        QCoreApplication::quit();
    });

    timer.start(3000); // 3 秒后触发定时器

    return app.exec();
}
```

### **6. 自定义事件处理**
可以通过重写 `QCoreApplication::notify()` 或使用事件过滤器来处理事件：
```cpp
class MyCoreApplication : public QCoreApplication {
public:
    MyCoreApplication(int &argc, char **argv) : QCoreApplication(argc, argv) {}

    bool notify(QObject *receiver, QEvent *event) override {
        if (event->type() == QEvent::KeyPress) {
            qDebug() << "Key press event intercepted!";
        }
        return QCoreApplication::notify(receiver, event);
    }
};

int main(int argc, char *argv[])
{
    MyCoreApplication app(argc, argv);
    return app.exec();
}
```

### **7. 与 `QApplication` 的区别**
- `QCoreApplication` 用于非 GUI 应用程序（如控制台应用程序、服务程序）。
- `QApplication` 是 `QCoreApplication` 的子类，用于 GUI 应用程序，提供了对窗口、绘图、输入设备等的支持。

- 可以通过信号与槽机制、事件过滤器或重写 `notify()` 函数来处理事件。
