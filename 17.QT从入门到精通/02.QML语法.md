## 2.1 QML语法基础

### 2.1.1 QML是什么

QML（Qt Meta-Object Language）是 Qt Quick 的核心语言，用于描述用户界面和交互逻辑。

它是一种声明式语言，语法简洁直观，类似于 JSON 和 JavaScript。

### 2.1.2 QML文件结构

一个 QML 文件通常由以下部分组成：

- **导入语句**：导入所需的模块。
- **根元素**：定义 UI 的根对象。
- **子元素**：定义 UI 的子组件。

示例：
```qml
import QtQuick 2.15 // 导入 QtQuick 模块

Rectangle { // 根元素
    width: 200
    height: 100
    color: "lightblue"

    Text { // 子元素
        text: "Hello, QML!"
        anchors.centerIn: parent
    }
}
```

## 2.2 import导入

### 2.2.1 基本语法

QML 的 `import` 语句通常遵循以下格式：

```qml
import <模块名> [版本号] [as <别名>]
```

- **模块名**：要导入的模块或库的名称。
- **版本号**（可选）：指定模块的版本号，确保使用正确的版本。
- **别名**（可选）：为导入的模块指定一个别名，避免命名冲突或简化使用。


### 2.2.2 导入标准QML模块

QML 提供了一些标准模块，例如 `QtQuick` 和 `QtQuick.Controls`。这些模块通常包含常用的 QML 类型和组件。

```qml
import QtQuick 2.15
import QtQuick.Controls 2.15
```

- `QtQuick`：包含基本的 QML 类型，例如 `Rectangle`、`Text`、`Image` 等。
- `QtQuick.Controls`：包含 UI 控件，例如 `Button`、`Slider`、`TextField` 等。

- 如果未指定版本号，QML会使用默认版本。 指定版本号可以避免因版本差异导致的兼容性问题。

### 2.2.3 导入自定义QML文件

可以导入自定义的 QML 文件或模块，通常用于组织项目中的代码。

假设有一个名为 `MyComponent.qml` 的文件，可以这样导入：

```qml
import "components"
```

- `"components"`：表示文件所在的目录路径。
- 导入后可以直接使用 `MyComponent` 类型。

### 2.2.4 使用别名导入模块

通过 `as` 关键字为模块指定别名，避免命名冲突或简化使用。

```qml
import QtQuick.Controls 2.15 as Controls

Controls.Button {
    text: "Click Me"
}
```

- 使用别名后，必须通过 `Controls` 前缀来访问模块中的类型。

### 2.2.5 导入JavaScript文件

QML 支持导入 JavaScript 文件，以便在 QML 中使用 JavaScript 函数。

假设有一个名为 `utils.js` 的文件，可以这样导入：

```qml
import "utils.js" as Utils

Rectangle {
    width: Utils.calculateWidth()
}
```

- `Utils` 是导入的 JavaScript 文件的别名。
- 可以通过 `Utils` 调用 JavaScript 文件中的函数。

### 2.2.6 import综合示例


以下是一个综合示例，展示了多种导入方式：

```qml
import QtQuick 2.15
import QtQuick.Controls 2.15 as Controls
import "utils.js" as Utils
import "components"

Rectangle {
    width: Utils.calculateWidth()
    height: 200

    Controls.Button {
        text: "Click Me"
    }

    MyComponent {
        id: customComponent
    }
}
```

## 2.3 QML类型系统

### 2.3.1 基本类型

QML 提供了一些基本的内置类型，用于表示常见的数据类型和 UI 组件。

**基本数据类型**：

- `int`：整数类型。
- `double`：双精度浮点数。
- `bool`：布尔类型。
- `string`：字符串类型。
- `color`：颜色类型。
- `var`：动态类型，可以存储任意值。
- `list`：列表类型，用于存储多个值。

**几何类型**：

- `point`：表示一个点，包含 `x` 和 `y` 属性。
- `size`：表示一个尺寸，包含 `width` 和 `height` 属性。
- `rect`：表示一个矩形，包含 `x`、`y`、`width` 和 `height` 属性。

```qml
Rectangle {
    width: 200
    height: 100
    color: "red"

    property int count: 10
    property string message: "Hello, QML!"
    property color backgroundColor: Qt.rgba(0.5, 0.5, 0.5, 1.0)
}
```

## 2.4 对象特性

对象特性包括属性、信号、方法、绑定、状态等。

### 2.4.1 id特性


### 2.4.2 属性特性

属性是对象的核心特性，用于存储数据或配置对象的行为。每个 QML 类型都有一组内置属性，开发者也可以定义自定义属性。

**内置属性**

- `width`：对象的宽度。
- `height`：对象的高度。
- `color`：对象的颜色。
- `visible`：对象是否可见。

**自定义属性**，可以通过 `property` 关键字定义自定义属性。

```qml
Rectangle {
    property int customWidth: 300
    width: customWidth
    height: 200
    color: "green"
}
```

### 2.4.3 信号和信号处理器特性

信号是 QML 对象的事件机制，用于通知其他对象某些事件发生。QML 类型通常有内置信号，例如 `onClicked`、`onCompleted` 等，开发者也可以定义自定义信号。

**内置信号**

- `onClicked`：鼠标点击事件。
- `onCompleted`：对象初始化完成时触发。

**自定义信号**，可以通过 `signal` 关键字定义信号。

```qml
Rectangle {
    signal customSignal(string message)

    MouseArea {
        anchors.fill: parent
        onClicked: {
            customSignal("Mouse clicked!")
        }
    }

    Connections {
        target: parent
        onCustomSignal: console.log(message)
    }
}
```

### 2.4.4 方法特性

方法是对象的行为特性，用于定义可执行的操作。可以通过 `function` 关键字定义方法。

**示例：定义和调用方法**

```qml
Rectangle {
    width: 200
    height: 100
    color: "blue"

    function changeColor(newColor) {
        color = newColor
    }

    MouseArea {
        anchors.fill: parent
        onClicked: parent.changeColor("red")
    }
}
```

### 2.4.7 状态控制

状态是 QML 对象的特性之一，用于定义对象的不同配置。通过状态，可以轻松切换对象的属性值或行为。

**示例：定义和切换状态**

```qml
Rectangle {
    width: 200
    height: 100
    color: "blue"

    states: [
        State {
            name: "redState"
            PropertyChanges { target: parent; color: "red" }
        },
        State {
            name: "greenState"
            PropertyChanges { target: parent; color: "green" }
        }
    ]

    MouseArea {
        anchors.fill: parent
        onClicked: {
            parent.state = parent.state === "redState" ? "greenState" : "redState"
        }
    }
}
```

## 2.5 集成JavaScript

QML 是一种声明式语言，用于构建用户界面，而 JavaScript 是一种强大的脚本语言，用于处理逻辑和动态行为。

在 QML 中，JavaScript 可以无缝集成，用于增强 QML 的功能和灵活性。通过集成 JavaScript，开发者可以实现复杂的逻辑、动态数据处理以及与 QML 对象的交互。

### 2.5.1 在QML中使用JavaScript


#### 2.5.1.1 内联JavaScript

QML 支持直接在属性、信号处理器和方法中编写 JavaScript 代码。**示例：内联 JavaScript**

```qml
Rectangle {
    width: 200
    height: 100
    color: "blue"

    MouseArea {
        anchors.fill: parent
        onClicked: {
            console.log("Rectangle clicked!")
            parent.color = parent.color === "blue" ? "red" : "blue"
        }
    }
}
```

在这个示例中，`onClicked` 信号处理器中直接使用了 JavaScript 代码。

#### 2.5.1.2 定义JavaScript函数

可以在 QML 对象中定义 JavaScript 函数，用于封装逻辑。**示例：定义和调用 JavaScript 函数**

```qml
Rectangle {
    width: 200
    height: 100
    color: "blue"

    function toggleColor() {
        color = color === "blue" ? "red" : "blue"
    }

    MouseArea {
        anchors.fill: parent
        onClicked: toggleColor()
    }
}
```

在这个示例中，`toggleColor` 是一个 JavaScript 函数，用于切换颜色。

#### 2.5.1.3 使用JavaScript表达式

QML 属性可以绑定到 JavaScript 表达式，动态更新属性值。**示例：绑定到 JavaScript 表达式**

```qml
Rectangle {
    width: 100
    height: width * 2 // 使用 JavaScript 表达式
    color: "green"

    MouseArea {
        anchors.fill: parent
        onClicked: parent.width += 10 // 动态更新宽度
    }
}
```

在这个示例中，`height` 属性绑定到 `width * 2`，并随着 `width` 的变化自动更新。


### 2.5.2 导入外部JavaScript文件

QML 支持加载外部 JavaScript 文件，便于组织代码和复用逻辑。

#### 2.5.2.1 外部JavaScript文件

创建一个 `.js` 文件，例如 `utils.js`：

```javascript
function calculateArea(width, height) {
    return width * height;
}

function toggleColor(currentColor) {
    return currentColor === "blue" ? "red" : "blue";
}
```

#### 2.5.2.2 导入JavaScript文件

使用 `import` 关键字导入外部 JavaScript 文件。

```qml
import "utils.js" as Utils

Rectangle {
    MouseArea {
        anchors.fill: parent
        onClicked: {
            parent.color = Utils.toggleColor(parent.color)
            console.log("Area:", Utils.calculateArea(parent.width, parent.height))
        }
    }
}
```

### 2.5.3 JavaScript与QML交互

JavaScript 可以直接访问 QML 对象的属性和方法，也可以通过信号与 QML 对象交互。

#### 2.5.3.1 访问QML对象属性

JavaScript 可以读取和修改 QML 对象的属性。**示例：访问属性**

```qml
Rectangle {
    width: 200
    height: 100
    color: "blue"

    MouseArea {
        anchors.fill: parent
        onClicked: {
            console.log("Width:", parent.width)
            parent.color = "red"
        }
    }
}
```

#### 2.5.3.2 调用QML对象方法

JavaScript 可以调用 QML 对象定义的方法。**示例：调用方法**

```qml
Rectangle {
    width: 200
    height: 100
    color: "blue"

    function changeColor(newColor) {
        color = newColor
    }

    MouseArea {
        anchors.fill: parent
        onClicked: parent.changeColor("red")
    }
}
```

#### 2.5.3.3 信号与JavaScript交互

QML 信号可以触发 JavaScript 函数。**示例：信号与 JavaScript 交互**

```qml
Rectangle {
    width: 200
    height: 100
    color: "blue"

    signal colorChanged(string newColor)

    MouseArea {
        anchors.fill: parent
        onClicked: {
            parent.color = "red"
            parent.colorChanged(parent.color)
        }
    }

    Connections {
        target: parent
        onColorChanged: console.log("Color changed to:", newColor)
    }
}
```

### 2.5.4 JavaScript模块化

通过外部 JavaScript 文件，可以实现模块化开发，将逻辑分离到不同的文件中。

**math.js**

```javascript
function add(a, b) {
    return a + b;
}

function subtract(a, b) {
    return a - b;
}
```

**color.js**

```javascript
function toggleColor(currentColor) {
    return currentColor === "blue" ? "red" : "blue";
}
```

**main.qml**

```qml
import "math.js" as Math
import "color.js" as Color

Rectangle {
    width: 200
    height: 100
    color: "blue"

    MouseArea {
        anchors.fill: parent
        onClicked: {
            parent.color = Color.toggleColor(parent.color)
            console.log("Sum:", Math.add(5, 3))
        }
    }
}
```


### 2.5.5 JavaScript作用域

在 QML 中，JavaScript 的作用域分为以下几种：

- **局部作用域**：函数内部定义的变量只能在函数内访问。
- **全局作用域**：外部 JavaScript 文件中的函数和变量可以被 QML 全局访问。
- **QML 对象作用域**：QML 对象的属性和方法可以被其子对象访问。

```qml
Rectangle {
    width: 200
    height: 100
    color: "blue"

    function localFunction() {
        var localVar = "I am local"
        console.log(localVar)
    }

    MouseArea {
        anchors.fill: parent
        onClicked: {
            localFunction()
            // console.log(localVar) // 错误：localVar 不在作用域内
        }
    }
}
```

### 2.5.6 JavaScript性能优化

在 QML 中使用 JavaScript 时，需要注意性能问题：

- 避免复杂的计算逻辑放在属性绑定中。
- 使用 `Timer` 或信号处理器来处理耗时操作。
- 尽量将复杂逻辑移到外部 JavaScript 文件中。

## 2.6 QML文档

### 2.6.1 理解QML文档

在 QML 中，**QML 文档**是一个独立的文件，用于描述用户界面和交互逻辑。

每个 QML 文件通常对应一个 UI 组件或界面，文件扩展名为 `.qml`。QML 文档的结构清晰，语法简洁，易于阅读和维护。

### 2.6.2 QML文档结构

一个典型的 QML 文档包含以下部分：

1. **导入语句**：导入所需的模块。
2. **根元素**：定义文档的根对象。
3. **子元素**：定义根对象的子组件。

```qml
// 导入 QtQuick 模块
import QtQuick 2.15

// 根元素：一个矩形
Rectangle {
    width: 200
    height: 100
    color: "lightblue"

    // 子元素：文本
    Text {
        text: "Hello, QML!"
        anchors.centerIn: parent
    }
}
```

### 2.6.3 资源加载

#### 2.6.3.1 加载图片

使用 `Image` 元素加载图片。图片可以来自文件系统或应用程序资源。

**从文件系统加载**

```qml
Image {
    source: "file:///path/to/image.png" // 绝对路径
    width: 100
    height: 100
}
```

如果图片被打包到应用程序资源中（例如 Qt 的资源系统），可以使用相对路径：

```qml
Image {
    source: "images/logo.png" // 相对路径，资源文件
    width: 100
    height: 100
}
```

#### 2.6.3.2 加载字体

使用 `FontLoader` 加载自定义字体。**加载字体文件**

```qml
import QtQuick 2.15

FontLoader {
    id: customFont
    source: "fonts/CustomFont.ttf" // 字体文件路径
}

Text {
    text: "Hello, QML!"
    font.family: customFont.name
    font.pixelSize: 24
}
```

可以直接使用系统字体：

```qml
Text {
    text: "Hello, QML!"
    font.family: "Arial"
    font.pixelSize: 24
}
```

#### 2.6.3.3 加载音频

使用 `MediaPlayer` 和 `Audio` 元素加载和播放音频。

**使用 MediaPlayer**

```qml
import QtQuick 2.15
import QtMultimedia 5.15

MediaPlayer {
    id: player
    source: "audio/sound.mp3" // 音频文件路径
}

Button {
    text: "Play"
    onClicked: player.play()
}
```

**使用 Audio**

```qml
import QtQuick 2.15
import QtMultimedia 5.15

Audio {
    id: audio
    source: "audio/sound.mp3"
}

Button {
    text: "Play"
    onClicked: audio.play()
}
```

#### 2.6.3.4 加载QML组件

使用 `Loader` 动态加载其他 QML 文件或组件。

**加载 QML 文件**

```qml
Loader {
    source: "MyComponent.qml" // QML 文件路径
}
```

**动态切换组件**，可以通过绑定属性动态切换加载的组件：

```qml
Loader {
    source: componentPath
}

property string componentPath: "ComponentA.qml"

Button {
    text: "Switch Component"
    onClicked: componentPath = "ComponentB.qml"
}
```


#### 2.6.3.5 加载网络资源

QML 支持从网络加载资源，例如图片、音频、视频等。

**加载网络图片**

```qml
Image {
    source: "https://example.com/image.png" // 网络图片 URL
    width: 100
    height: 100
}
```

**加载网络视频**

```qml
MediaPlayer {
    id: player
    source: "https://example.com/video.mp4" // 网络视频 URL
}
```

#### 2.6.3.6 加载本地文件

使用 `FileDialog` 或 `Qt.resolvedUrl` 加载本地文件。

**使用Qt.resolvedUrl**

```qml
Image {
    source: Qt.resolvedUrl("images/logo.png") // 解析相对路径
    width: 100
    height: 100
}
```
