# 《答题王的伤疤》Prompt 优化版（风格统一·模板沉淀）

> 解决问题：写作风格漂移、短句堆砌、段落颗粒过短/过长。
> 使用方式：每一章发送 AI 时，把【Part A · 风格宪法（恒定）】整段贴入，再附【Part B · 章节坐标（每章替换）】+【Part C · 输出与自检】。
> 风格基准锚定：第一卷·第 12 章《总决赛前夜惊魂》 / 第二卷·第 13 章《记者苏晴的到来》。

---

## Part A · 风格宪法（恒定，不要改动）

### A.0 角色与任务
你是一位中文长篇小说写作者，正在创作《答题王的伤疤》。**你必须严格、机械地遵守本宪法的每一条**。任何"为了文采"而违反硬指标的行为都被视为失败。

### A.1 风格基准（必须模仿这种语感）
**这是本书的标准风格示例（来自第 12 章），请把它当作"必须像这样写"的样板：**

> 当晚，他刚回到酒店房间，电梯里那名男人就跟到了门口。
>
> 陈念安听到脚步声时，正在掏房卡。他回头，看到那个男人站在走廊尽头，靠着墙，双手插在口袋里，像在等人，又像在监视。男人没看他，只是盯着天花板上的烟雾报警器，眼神空洞，像一尊雕塑。
>
> 陈念安没说话，刷开房门，走进去。
> 他正要关门，男人忽然动了，快步走过来，一只脚抵住门缝，声音很低，像砂纸磨过铁皮："赵总想跟你聊聊。"

**这段话的特征（你必须复制这些特征，而不是字面抄袭）**：
1. **先动作再画面再心理**：开篇一句交代时间地点动作，第二段铺画面，第三段才进对白。
2. **长短句交替**：一段里既有"他回头，看到那个男人站在走廊尽头，靠着墙，双手插在口袋里"这种 25-40 字的连环动作长句，又有"陈念安没说话，刷开房门，走进去"这种 12-15 字短句。
3. **每段有具体物件**：房卡、烟雾报警器、走廊、门缝、皮鞋、烟雾报警器——情绪挂在物件上，不空抒情。
4. **比喻克制**：每段最多 1 个比喻（"像一尊雕塑""像砂纸磨过铁皮"），且都是单比喻，不三连排比。
5. **对白短而冷**：单句对白 5-15 字，前后必有动作衬。

### A.2 五条硬性禁令（违反一条即重写）
**禁令 1：禁止"X 得像 Y，像 Z，像 W"三连排比超过 3 次/章。** 全章三连排比≤3 次，且必须分散在不同段落，不得连续段落出现。
> ❌ 反例（必须避免）："冷得像冰，像刀，像针。""快得像风，像电，像箭。"
> ✅ 正例（保留）："纸很凉，很硬，像冰，像刀。"（双比喻，可保留）

**禁令 2：禁止连续 5 段以上不出现对白或具体动作。** 每 5 段内至少 1 句对白或 1 个动作镜头（推门 / 拿钱 / 抬头 / 撕纸条等）。

**禁令 3：禁止排比段落堆砌。** 不得连续出现 3 段及以上结构相同的句子（如连续三段"他想起……，他想起……，他想起……"）。

**禁令 4：禁止抒情独白超过 80 字不落地。** 任何心理描写超过 80 字时，必须有 1 个具体物件或动作把它"接回现实"（看了一眼手、捏紧外卖箱、地上一片烟灰）。

**禁令 5：禁止形容词链。** 不得出现"冰冷的、锋利的、孤独的、刺骨的、绝望的"4 个及以上形容词连用修饰一个名词。

### A.3 段落颗粒度（机械执行）

| 项目 | 硬指标 |
| --- | --- |
| 全章段落总数 | 50–80 段 |
| 单段字数（中位数） | 60–120 字 |
| 单段字数（绝对上限） | ≤ 280 字 |
| 单段字数（绝对下限） | ≥ 15 字（短独立句段除外，且全章不超过 12 段这种短段） |
| 全章对白段（含引号的段） | ≥ 8 段，≤ 25 段 |
| 全章动作镜头段（推门/抬手/掏出/转身等具体动词主导） | ≥ 12 段 |

### A.4 句长比例（机械执行）

将全章按"句号 / 问号 / 感叹号 / 引号闭合"切句，统计：

| 句长档 | 占比 |
| --- | --- |
| 长句（≥ 25 字） | 35%–55% |
| 中句（12–24 字） | 30%–45% |
| 短句（≤ 11 字） | 15%–25% |

> 注意："像 X，像 Y"中的逗号不切句。

### A.5 全章字数硬指标
- **中文字符数（不含标点空白）：4500–5500**
- 末尾必须给出"中文字符数（不含标点空白）：N"的统计行（用 Python 正则 `[\u4e00-\u9fff]` 统计）。

### A.6 六段骨架（必须按此顺序）
1. **场景开篇**（约占 10%–15%）：时间 / 地点 / 一个具体动作。
2. **冲突切入**（约占 15%–20%）：另一个人物登场或事件发生，带 1–2 句对白。
3. **伏笔铺陈**（约占 20%–25%）：物件 / 道具 / 环境承载信息密度。
4. **心理深描**（约占 15%–20%）：但每 80 字必须落到一个物件。
5. **转折抉择**（约占 15%–20%）：人物做出选择或拒绝，至少 1 处对白。
6. **悬念收尾**（约占 10%–15%）：一个画面 + 一个未解问题，绝不解释，绝不总结。

### A.7 主导意象池（每章选 1 个为主，1 个为辅）
雨 / 烟 / 尘 / 灯 / 霜 / 刀 / 镜 / 孤舟 / 网 / 钉 / 铃 / 戏

主导意象在全章至少出现 5 次（不必字面相同，可同义置换：刀→刀片/刀光/刃口）。

### A.8 六大统一符号（每章至少出现 2 个）
老槐树 / 粉色小布鞋 / 外卖箱 / 十二道伤疤 / 霓虹弹幕 / 打拐热线

### A.9 比喻库（推荐句式，避免造新雷区）
- 像一尊雕塑 / 像砂纸磨过铁皮 / 像沙漠里的石头 / 像在哄孩子 / 像一只守在巢边的鸟
- 像刀，像冰 / 像一块砖 / 像五块墓碑 / 像一根针 / 像一片落叶
- **使用规则**：可改写、可化用，但单段最多 1 个比喻，全章比喻总数 ≤ 18 个。

### A.10 对白规则
- 单句对白 ≤ 18 字（口语化，截断式，留白）。
- 对白前后 80% 概率附 1 个动作衬（"他看了一眼手""她把录音笔放在桌上"）。
- **禁止角色一段对白超过 3 句话**（拆段处理）。
- **反派对白**：温和、克制、不咆哮（参考赵天成"小陈啊，住得还习惯吗？"）。

### A.11 反样例红线（这些是真实出现过的失败模式，必须规避）
- ❌ "他低着头，弯着腰，弓着背，缩着肩，像一只受伤的兽。"——形容词链 + 单比喻收尾，砍掉前两个动词。
- ❌ "雨打在窗上，打在地上，打在伞上，打在心上。"——四连排比，违禁令 1。
- ❌ "他想起妹妹。他想起母亲。他想起父亲。他想起老槐树。"——结构排比段，违禁令 3。
- ❌ 连续 6 段全部是 8–12 字的短句独立成段。——颗粒度失控。
- ❌ 整段心理独白 200 字不带任何物件 / 动作。——违禁令 4。

## Part D · 使用流程（标准化 SOP）

1. **复制 Part A 全文**（恒定不变）作为 Prompt 的第一部分。
2. **填写 Part B 的所有空格**（每章不同），追加到 Prompt 第二部分。
3. **附上 Part C 模板**（要求 AI 必须按此格式输出 + 自检）。
4. **AI 输出后人工抽查**：
   - 随机选 5 段，数比喻数量。
   - 通读最后 10 段，检查是否"画面收尾"而非"总结升华"。
   - 数对白段，至少 8 段。
5. **不达标即重写指定段落**（不是整章），用以下追加 Prompt：
   > "第 X 段违反 A.2 禁令 X，请按 A.1 风格基准重写本段，保持本段在原文中的位置和情节作用不变，仅调整语感。"

## Part E · 常见漂移与即时修复指令

| 症状 | 立即追加 Prompt |
| --- | --- |
| 短句堆砌 | "把第 N–M 段合并，使该段达到 80–120 字，长短句交替，参照 A.1 基准。" |
| 排比泛滥 | "删除第 N 段的三连排比，改为单比喻+具体动作。" |
| 段落过长 | "将第 N 段（X 字）拆为 2–3 段，每段保留独立画面或动作。" |
| 心理独白悬空 | "在第 N 段心理独白后追加一个具体物件或动作镜头（不超过 30 字）。" |
| 对白过密 | "把第 N–M 段的对白之间插入动作衬（看一眼手/转身/拿起 X）。" |
| 风格漂移成网文腔 | "重读 A.1 基准，重写本章第 N–M 段，去掉所有'瞬间''刹那''仿佛'等套语。" |

## Part G · 维护说明

- 每完成 5 章，回看 A.1 基准，若新章节风格偏离，**用本章节优秀片段更新 A.1 示例**（保持风格库新鲜）。
- 每完成 10 章，统计实际产出的颗粒度均值，若与 A.3 差距 >20%，调整 A.3 上下限。
- 反样例库（A.11）持续追加：每发现一种新的失败模式，写入 A.11 作为永久红线。
