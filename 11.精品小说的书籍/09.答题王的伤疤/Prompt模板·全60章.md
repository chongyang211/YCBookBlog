# 《答题王的伤疤》全 60 章 AI 协作 Prompt 模板

> 本文件提供 **1 份宪法预置 Prompt**（整本书只发一次） + **60 份章节生成 Prompt**（每章一份，已按《全书框架和分卷.md》逐行机械填好）。
>
> 配套文档：《全书方案的设计.md》§9–§11、《全书框架和分卷.md》。
>
> **使用步骤**：
>
> 1. 开新对话窗口 → 复制【§0 宪法 Prompt】发给 AI → 等回复"宪法已收"。
> 2. 写第 N 章 → 复制【§N 章节 Prompt】发给 AI → 收正文。
> 3. 用《全书方案的设计.md》§9.9 单章交付清单核验 → 在《一致性档案.md》追加 1 行沉淀。
> 4. 中途换对话窗口 → 重发宪法 + 最近 3 章一致性档案。

## §0 · 宪法预置 Prompt（整本书只发一次）

```text
你将协助我创作长篇小说《答题王的伤疤》。以下世界观与人物设定为本书宪法，**不可更改、不可扩展、不可新增**。

【时代】2024 年中国，直播答题爆火，留守儿童与打拐议题凸显。
【场景】深圳白石洲城中村 / 《全民答题王》直播演播厅 / 贵州黔东南山区。
【主线】22 岁深圳外卖员陈念安身上 12 道伤疤对应 12 道答题题目，闯入总决赛，目标是寻找失散十年的妹妹陈念希。
【三条副线】① 寻亲线（妹妹陈念希）  ② 黑幕线（赵天成/平台）  ③ 感情线（林小满）
【五位主要人物】
  · 陈念安（男主，22岁，外卖员，沉默坚韧、自卑愧疚，身上 12 道伤疤）
  · 陈念希（妹妹，17岁，平台不露脸的声音主播"小希"，被赵天成隐瞒身份）
  · 林小满（女主，22岁，深圳护士，青梅竹马，温柔但隐有"怕被妹妹挤走"的私心）
  · 赵天成（反派，45岁，平台老板，底层出身后复制施害逻辑，非"为坏而坏"）
  · 苏晴（28岁，调查记者，借此案重建职业信仰）
【六大统一符号】老槐树 / 粉色小布鞋 / 外卖箱 / 十二道伤疤 / 霓虹弹幕 / 打拐热线
【主导意象池】雨 / 烟 / 尘 / 灯 / 霜 / 刀 / 镜 / 孤舟（每章选 1 个，全章不可换）
【五卷大钩子】
  卷一：被软禁 + 苏晴敲门
  卷二：伤疤揭尽 + 妹妹声线浮现
  卷三：林小满被绑 + 警方介入
  卷四：弹幕认人 + 兄妹连线
  卷五：老槐树下归来 + 终章留白
【写作风格】古龙式句法 + 古典意象现代化 + 每章 ≤ 2 句古诗词点睛。

【硬性写作规约】
- 字数 4500–5500（中文字符数，不含标点空白）；段落 60–90 段；每段 10–300 字。
- 严格按【六段骨架】依序推进：①场景开篇(8-12%) ②冲突切入(12-18%，新于上章) ③伏笔铺陈(10-15%，落统一符号) ④心理深描(20-30%，借物喻心) ⑤转折抉择(15-20%，必须有动作变化) ⑥悬念收尾(8-12%，与下章首段呼应)。
- 风格七律：长短句交替；古诗词 ≤ 2 句；禁用"难过/愤怒/绝望/无助/痛苦"等情绪直白词，必须用身体反应或道具承载；1 个主导意象贯穿全章。
- 关键段（200 字以上）必须三层齐备：环境层（天气/光线/声音/气味）+ 道具层（命运物件）+ 身体层（颤抖/屏息/攥拳/伤疤隐痛）。
- 全员双面：每章主角展现 1 次双面性；反派不写"为坏而坏"；保留灰度与遗憾。
- 对话占比 10%–30%；倒叙/回忆 ≤ 25%。

【七不准·通用剧情红线】
1. 不准出现大纲未授权的新人物 / 新地点 / 新转折。
2. 不准改变本章对应的"那一题 / 那一道伤疤 / 那一段流浪史"。
3. 不准让陈念安变成"爽文式逆袭"，必须保留自卑愧疚底色。
4. 不准让赵天成"为坏而坏"，每个恶都要有人性来路。
5. 不准提前揭穿——重大节点（赵天成知情、兄妹相认、警方收网）必须严格按分卷表章号触发，不得跨章泄露。
6. 不准与已写章节矛盾（伤疤数量、人物记忆、物件归属、时间线）。
7. 不准字数超出 4500–5500 区间。

【输出格式】每章一律：先输出【本章自检表】（9 项 ✅/❌） → 再输出正文（纯中文叙述，不加章节小标题、不加分隔符） → 最后输出【字数统计】（中文字符数，不含标点空白）。

收到此设定后，请回复"宪法已收"，并等待我下发章节 Prompt。
```
