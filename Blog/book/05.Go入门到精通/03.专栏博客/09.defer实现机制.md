# 09.defer 实现机制

> `defer` 看起来只是"函数返回前执行"的语法糖，但背后是 Go runtime 三代演进的精彩故事——从 Go 1.0 的堆分配（~50ns），到 1.13 的栈分配（~35ns），再到 1.14 的开放编码（~1ns）。本篇拆三代实现，讲清 `_defer` 链表、`deferreturn`、`recover` 协作。
> 关键词：`_defer` 链表、`deferproc`/`deferreturn`、栈分配 defer（1.13）、**开放编码 defer**（1.14+）、recover 栈展开、编译器决策机制
