## 01.简易线程池设计
### 1.1 核心设计思想

线程池是一种典型的池化技术，核心思想是预先创建一组线程，当有任务到来时直接分配给已有线程执行，避免频繁创建和销毁线程的开销。

C语言没有类、模板、`std::future`等高级特性，需要使用POSIX线程库`pthread`和函数指针来实现。本案例从零实现一个简易线程池，对标C++版本的设计。

### 1.2 核心设计目标

1. 资源管理优化：避免频繁创建/销毁线程的开销；实现线程复用，提高资源利用率；控制并发线程数量，防止资源耗尽。
2. 任务调度机制：支持任务优先级（普通任务 vs 优先任务）；实现公平的任务分配；确保任务执行顺序可控
3. 线程安全保证：确保多线程环境下数据访问安全；避免竞态条件和死锁；提供异常安全保证

### 1.3 开发设计步骤

1. 步骤1：定义线程池结构体及成员变量
2. 步骤2：定义任务结构体（链表节点）
3. 步骤3：实现初始化函数（带名称和最大线程数）
4. 步骤4：实现销毁函数（对应C++析构函数）
5. 步骤5：实现清理任务队列的函数（普通任务、优先任务、全部任务）
6. 步骤6：实现线程主循环函数（taskLoop）
7. 步骤7：实现任务提交接口（普通任务和优先任务）
8. 步骤8：实现获取任务数量和线程数量的接口
9. 步骤9：编写示例任务函数和主函数测试

### 1.4 技术栈说明

| 技术类别 | 具体技术 | 应用场景 |
|---------|---------|---------|
| **并发基础** | pthread_create, pthread_mutex | 线程创建和同步 |
| **任务管理** | 函数指针, void*参数 | 任务封装 |
| **结果处理** | 回调函数, 共享变量 | 结果获取 |
| **容器** | 链表（手动实现） | 任务队列存储 |
| **同步机制** | pthread_cond, pthread_mutex | 线程协调 |
| **内存管理** | malloc, free | 动态分配任务节点 |

**对比C++**：C++使用`std::thread`/`std::mutex`/`std::future`/`std::packaged_task`/变长模板；C语言使用`pthread`/`pthread_mutex`/回调函数/函数指针/`void*`。C++的模板和`std::future`使得任务提交接口更通用，C语言需要通过`void*`实现类型擦除。

### 1.5 核心组件说明

1. 并发编程组件

- **pthread_t**：线程标识（对应C++ `std::thread`）
- **pthread_mutex_t**：互斥锁（对应C++ `std::mutex`）
- **pthread_cond_t**：条件变量（对应C++ `std::condition_variable`）
- **函数指针+void***：任务封装（对应C++ `std::packaged_task`）

2. 条件变量模式

- 等待条件：`while(!condition) pthread_cond_wait(&cond, &mutex)`
- 通知机制：`pthread_cond_signal()` / `pthread_cond_broadcast()`

**对比C++**：C++的`condition_variable::wait`可以直接传入lambda谓词，自动处理虚假唤醒。C语言必须手动用while循环检查条件。

### 1.6 对比C++高级特性

C++版本使用了大量高级特性，C语言的对应方案如下：

1. C++变长参数模板 → C语言函数指针 + `void*`

```cpp
// C++: 变长参数模板，支持任意参数
template<class F, class... Args>
auto submit(F&& f, Args&&... args)
```

```c
// C: 函数指针 + void*参数，通用但类型不安全
typedef int (*TaskFunc)(void *arg);
void thread_pool_post(ThreadPool *pool, TaskFunc func, void *arg);
```

2. C++完美转发 → C语言不需要（没有值语义区分）

3. C++类型萃取 → C语言`void*`类型擦除

```cpp
// C++: 编译期类型推导
typename std::result_of<F(Args...)>::type
```

```c
// C: 统一用int返回值 + void*参数
typedef int (*TaskFunc)(void *arg);
```

4. C++智能指针 → C语言手动`malloc`/`free`

```cpp
// C++: shared_ptr自动管理生命周期
auto task = std::make_shared<std::packaged_task<return_type()>>(...);
```

```c
// C: 手动管理
TaskNode *node = (TaskNode*)malloc(sizeof(TaskNode));
// ... 使用后
free(node);
```

## 02.定义线程池结构

实现要点：

1. 定义任务节点结构（链表实现队列）
2. 定义线程池核心数据结构
3. 声明公共接口
4. 使用函数指针支持通用任务

### 2.1 包含必要头文件

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <pthread.h>
#include <unistd.h>

// 任务函数类型：接收void*参数，返回int结果
typedef int (*TaskFunc)(void *arg);

// 任务节点（链表实现FIFO队列）
// 对应C++的 std::shared_ptr<std::packaged_task<int()>>
typedef struct TaskNode {
    TaskFunc func;              // 任务函数指针
    void *arg;                  // 任务参数
    int *result;                // 结果存放地址（模拟future）
    int *done;                  // 完成标志
    pthread_mutex_t *doneMutex; // 保护done标志的锁
    pthread_cond_t *doneCond;   // 通知完成的条件变量
    struct TaskNode *next;      // 下一个节点
} TaskNode;
```

**对比C++**：C++使用`std::queue<std::shared_ptr<std::packaged_task<int()>>>`，底层由标准库管理。C语言使用手写链表实现FIFO队列，每个节点包含任务函数指针和参数。

### 2.2 声明公有接口

```c
// 线程池结构体（对应C++ ThreadPool类）
typedef struct {
    // 存储线程池中的线程（对应C++ std::vector<std::thread>）
    pthread_t *threads;
    int threadCount;
    // 普通任务队列（链表，对应C++ std::queue mTasks）
    TaskNode *tasksHead;
    TaskNode *tasksTail;
    int tasksSize;
    // 优先任务队列（链表，对应C++ std::queue mPrepTasks）
    TaskNode *preTasksHead;
    TaskNode *preTasksTail;
    int preTasksSize;
    // 保护任务队列的互斥锁（对应C++ std::mutex）
    pthread_mutex_t queueMutex;
    // 条件变量（对应C++ std::condition_variable）
    pthread_cond_t cv;
    // 标志位（对应C++ volatile bool mStop）
    volatile int stop;
    // 线程池名称
    char name[64];
} ThreadPool;

// 公共接口声明
void thread_pool_init(ThreadPool *pool, const char *name, int maxThreads);
void thread_pool_init_default(ThreadPool *pool, int maxThreads);
void thread_pool_destroy(ThreadPool *pool);

// 任务提交（返回TaskHandle用于获取结果）
typedef struct {
    int *result;
    int *done;
    pthread_mutex_t *doneMutex;
    pthread_cond_t *doneCond;
} TaskHandle;

TaskHandle thread_pool_post_task(ThreadPool *pool, TaskFunc func, void *arg);
TaskHandle thread_pool_post_pre_task(ThreadPool *pool, TaskFunc func, void *arg);

// 获取任务结果（阻塞等待，模拟C++ future.get()）
int task_handle_get(TaskHandle *handle);
void task_handle_cleanup(TaskHandle *handle);

void thread_pool_clear_tasks(ThreadPool *pool);
void thread_pool_clear_pre_tasks(ThreadPool *pool);
void thread_pool_clear_all_tasks(ThreadPool *pool);

int thread_pool_task_size(ThreadPool *pool);
int thread_pool_pre_task_size(ThreadPool *pool);
int thread_pool_all_task_size(ThreadPool *pool);
int thread_pool_thread_count(ThreadPool *pool);
```

**对比C++**：C++使用`std::future<T>`获取任务结果，类型安全且支持异常传播。C语言使用自定义`TaskHandle`结构体模拟，包含结果指针、完成标志和同步原语。C++的模板`postTask<F, Args...>`支持任意类型任务，C语言统一使用`int (*TaskFunc)(void*)`。

## 03.实现构造函数

实现要点：

1. 初始化stop为0，表示线程池运行状态
2. 创建线程数组并启动线程
3. 每个线程执行taskLoop函数
4. 提供带名称和默认名称两种初始化方式

### 3.1 带名称构造

```c
// 线程主循环函数（前向声明）
static void* task_loop(void *arg);

// 初始化线程池（对应C++带名称的构造函数）
void thread_pool_init(ThreadPool *pool, const char *name, int maxThreads) {
    strncpy(pool->name, name, sizeof(pool->name) - 1);
    pool->name[sizeof(pool->name) - 1] = '\0';
    pool->stop = 0;
    pool->threadCount = maxThreads;
    // 初始化任务队列
    pool->tasksHead = pool->tasksTail = NULL;
    pool->tasksSize = 0;
    pool->preTasksHead = pool->preTasksTail = NULL;
    pool->preTasksSize = 0;
    // 初始化同步原语
    pthread_mutex_init(&pool->queueMutex, NULL);
    pthread_cond_init(&pool->cv, NULL);
    // 创建线程数组（对应C++ mThreads.emplace_back）
    pool->threads = (pthread_t*)malloc(maxThreads * sizeof(pthread_t));
    for (int i = 0; i < maxThreads; i++) {
        pthread_create(&pool->threads[i], NULL, task_loop, pool);
    }
}
```

**对比C++**：C++使用`mThreads.emplace_back(&ThreadPool::taskLoop, this, name)`直接在vector中构造线程。C语言需要先`malloc`线程数组，再用`pthread_create`逐个创建。

### 3.2 默认构造函数

```c
// 默认初始化（对应C++默认构造函数）
void thread_pool_init_default(ThreadPool *pool, int maxThreads) {
    thread_pool_init(pool, "yt_thread_pool", maxThreads);
}
```

**对比C++**：C++使用`std::thread::hardware_concurrency()`获取CPU核心数，C语言可以使用`sysconf(_SC_NPROCESSORS_ONLN)`获取。

### 3.3 实现销毁函数

作用：销毁线程池，确保所有线程安全退出。对应C++的析构函数。

```c
// 销毁线程池（对应C++析构函数）
void thread_pool_destroy(ThreadPool *pool) {
    // 设置停止标志
    pthread_mutex_lock(&pool->queueMutex);
    pool->stop = 1;
    pthread_mutex_unlock(&pool->queueMutex);
    // 唤醒所有等待的线程（对应C++ mCv.notify_all()）
    pthread_cond_broadcast(&pool->cv);
    // 等待所有线程结束（对应C++ thread.join()）
    for (int i = 0; i < pool->threadCount; i++) {
        pthread_join(pool->threads[i], NULL);
    }
    // 释放线程数组
    free(pool->threads);
    pool->threads = NULL;
    // 清理剩余任务节点
    thread_pool_clear_all_tasks(pool);
    // 销毁同步原语
    pthread_mutex_destroy(&pool->queueMutex);
    pthread_cond_destroy(&pool->cv);
}
```

**对比C++**：
- C++析构函数自动调用（RAII），C语言需要显式调用`thread_pool_destroy`
- C++的`std::unique_lock`在作用域结束时自动释放锁，C语言用`pthread_mutex_lock/unlock`手动管理
- C++不需要检查`thread.joinable()`（析构时已确保），C语言的`pthread_join`本身是安全的
- C语言需要额外释放`malloc`分配的内存

## 04.实现清理任务

### 4.1 清空普通任务

作用：清空普通任务队列。

```c
// 内部函数：释放链表所有节点
static void free_task_list(TaskNode **head, TaskNode **tail, int *size) {
    TaskNode *current = *head;
    while (current != NULL) {
        TaskNode *next = current->next;
        free(current);
        current = next;
    }
    *head = *tail = NULL;
    *size = 0;
}

void thread_pool_clear_tasks(ThreadPool *pool) {
    pthread_mutex_lock(&pool->queueMutex);
    free_task_list(&pool->tasksHead, &pool->tasksTail, &pool->tasksSize);
    pthread_mutex_unlock(&pool->queueMutex);
}
```

**对比C++**：C++使用`while(!mTasks.empty()) mTasks.pop()`逐个弹出，`std::shared_ptr`自动释放内存。C语言需要遍历链表手动`free`每个节点。

### 4.2 清空优先任务

```c
void thread_pool_clear_pre_tasks(ThreadPool *pool) {
    pthread_mutex_lock(&pool->queueMutex);
    free_task_list(&pool->preTasksHead, &pool->preTasksTail, &pool->preTasksSize);
    pthread_mutex_unlock(&pool->queueMutex);
}
```

### 4.3 清空所有任务

```c
void thread_pool_clear_all_tasks(ThreadPool *pool) {
    pthread_mutex_lock(&pool->queueMutex);
    free_task_list(&pool->tasksHead, &pool->tasksTail, &pool->tasksSize);
    free_task_list(&pool->preTasksHead, &pool->preTasksTail, &pool->preTasksSize);
    pthread_mutex_unlock(&pool->queueMutex);
}
```

## 05.线程主循环函数

实现要点：

1. 使用条件变量等待任务或停止信号
2. 优先处理优先任务队列
3. 任务执行在锁外进行，避免阻塞其他线程

### 5.1 线程启动时

```c
static void* task_loop(void *arg) {
    ThreadPool *pool = (ThreadPool*)arg;
    // 线程启动（对应C++ onThreadAttached()）
}
```

### 5.2 线程执行任务

```c
// 从链表头部取出一个任务
static TaskNode* dequeue_task(TaskNode **head, TaskNode **tail, int *size) {
    if (*head == NULL) return NULL;
    TaskNode *node = *head;
    *head = node->next;
    if (*head == NULL) *tail = NULL;
    node->next = NULL;
    (*size)--;
    return node;
}

static void* task_loop(void *arg) {
    ThreadPool *pool = (ThreadPool*)arg;
    while (1) {
        TaskNode *preTask = NULL;
        TaskNode *task = NULL;
        pthread_mutex_lock(&pool->queueMutex);
        // 等待条件：停止信号或任务可用
        // 对应C++: mCv.wait(lock, [this]{ return mStop || !mTasks.empty() || !mPrepTasks.empty(); });
        while (!pool->stop && pool->tasksHead == NULL && pool->preTasksHead == NULL) {
            pthread_cond_wait(&pool->cv, &pool->queueMutex);
        }
        // 检查停止信号
        if (pool->stop) {
            pthread_mutex_unlock(&pool->queueMutex);
            break; // 对应C++ onThreadDetached() + return
        }
        // 优先取优先任务
        if (pool->preTasksHead != NULL) {
            preTask = dequeue_task(&pool->preTasksHead, &pool->preTasksTail, &pool->preTasksSize);
        }
        // 再取普通任务
        if (pool->tasksHead != NULL) {
            task = dequeue_task(&pool->tasksHead, &pool->tasksTail, &pool->tasksSize);
        }
        pthread_mutex_unlock(&pool->queueMutex);

        // 执行任务（在锁外执行，避免阻塞其他线程）
        if (preTask != NULL) {
            int result = preTask->func(preTask->arg);
            // 设置结果和完成标志（模拟future）
            if (preTask->result) *(preTask->result) = result;
            if (preTask->done) {
                pthread_mutex_lock(preTask->doneMutex);
                *(preTask->done) = 1;
                pthread_cond_signal(preTask->doneCond);
                pthread_mutex_unlock(preTask->doneMutex);
            }
            free(preTask);
        }
        if (task != NULL) {
            int result = task->func(task->arg);
            if (task->result) *(task->result) = result;
            if (task->done) {
                pthread_mutex_lock(task->doneMutex);
                *(task->done) = 1;
                pthread_cond_signal(task->doneCond);
                pthread_mutex_unlock(task->doneMutex);
            }
            free(task);
        }
    }
    return NULL;
}
```

**对比C++**：
- C++使用`mCv.wait(lock, predicate)`传入lambda谓词，C语言使用`while(!condition) pthread_cond_wait`
- C++取出任务使用`front() + pop()`，C语言使用自定义`dequeue_task`操作链表
- C++的`(*preTask)()`直接执行packaged_task，C语言通过`preTask->func(preTask->arg)`调用函数指针
- C++的future自动设置结果，C语言需要手动设置result指针和通知条件变量

### 5.3 一些边界条件

1. **虚假唤醒**：`pthread_cond_wait`可能出现虚假唤醒，因此必须用while循环而非if判断
2. **内存释放**：任务执行完毕后必须`free(node)`，否则会内存泄漏
3. **停止顺序**：设置`stop=1`后先检查停止信号，确保不会在停止后继续取任务

## 06.任务提交实现

实现要点：

1. 创建任务节点，封装函数指针和参数
2. 分配结果存储空间和同步原语
3. 将节点加入队列尾部
4. 唤醒一个等待线程
5. 返回TaskHandle用于获取结果

### 6.1 提交普通任务

```c
// 将任务加入链表尾部
static void enqueue_task(TaskNode **head, TaskNode **tail, int *size, TaskNode *node) {
    node->next = NULL;
    if (*tail == NULL) {
        *head = *tail = node;
    } else {
        (*tail)->next = node;
        *tail = node;
    }
    (*size)++;
}

TaskHandle thread_pool_post_task(ThreadPool *pool, TaskFunc func, void *arg) {
    TaskHandle handle;
    // 分配结果存储和同步原语（模拟C++ future/promise）
    handle.result = (int*)malloc(sizeof(int));
    handle.done = (int*)malloc(sizeof(int));
    handle.doneMutex = (pthread_mutex_t*)malloc(sizeof(pthread_mutex_t));
    handle.doneCond = (pthread_cond_t*)malloc(sizeof(pthread_cond_t));
    *(handle.result) = 0;
    *(handle.done) = 0;
    pthread_mutex_init(handle.doneMutex, NULL);
    pthread_cond_init(handle.doneCond, NULL);

    // 创建任务节点
    TaskNode *node = (TaskNode*)malloc(sizeof(TaskNode));
    node->func = func;
    node->arg = arg;
    node->result = handle.result;
    node->done = handle.done;
    node->doneMutex = handle.doneMutex;
    node->doneCond = handle.doneCond;
    node->next = NULL;

    pthread_mutex_lock(&pool->queueMutex);
    if (pool->stop) {
        pthread_mutex_unlock(&pool->queueMutex);
        fprintf(stderr, "Error: enqueue on stopped ThreadPool\n");
        free(node);
        return handle;
    }
    enqueue_task(&pool->tasksHead, &pool->tasksTail, &pool->tasksSize, node);
    pthread_cond_signal(&pool->cv); // 唤醒一个线程
    pthread_mutex_unlock(&pool->queueMutex);
    return handle;
}
```

**对比C++**：
- C++使用`std::packaged_task<return_type()>`封装任务，`task->get_future()`获取future
- C语言手动分配结果存储、完成标志和同步原语，组成TaskHandle
- C++抛出`std::runtime_error`，C语言打印错误信息并返回
- C++的notify_one对应C语言的`pthread_cond_signal`

### 6.2 提交优先任务

```c
TaskHandle thread_pool_post_pre_task(ThreadPool *pool, TaskFunc func, void *arg) {
    TaskHandle handle;
    handle.result = (int*)malloc(sizeof(int));
    handle.done = (int*)malloc(sizeof(int));
    handle.doneMutex = (pthread_mutex_t*)malloc(sizeof(pthread_mutex_t));
    handle.doneCond = (pthread_cond_t*)malloc(sizeof(pthread_cond_t));
    *(handle.result) = 0;
    *(handle.done) = 0;
    pthread_mutex_init(handle.doneMutex, NULL);
    pthread_cond_init(handle.doneCond, NULL);

    TaskNode *node = (TaskNode*)malloc(sizeof(TaskNode));
    node->func = func;
    node->arg = arg;
    node->result = handle.result;
    node->done = handle.done;
    node->doneMutex = handle.doneMutex;
    node->doneCond = handle.doneCond;
    node->next = NULL;

    pthread_mutex_lock(&pool->queueMutex);
    // 优先队列限流（对应C++的500上限检查）
    if (pool->preTasksSize > 500) {
        pthread_mutex_unlock(&pool->queueMutex);
        *(handle.done) = 1; // 标记为已完成
        free(node);
        return handle;
    }
    if (pool->stop) {
        pthread_mutex_unlock(&pool->queueMutex);
        fprintf(stderr, "Error: enqueue on stopped ThreadPool\n");
        free(node);
        return handle;
    }
    enqueue_task(&pool->preTasksHead, &pool->preTasksTail, &pool->preTasksSize, node);
    pthread_cond_signal(&pool->cv);
    pthread_mutex_unlock(&pool->queueMutex);
    return handle;
}
```

### 6.3 函数指针总结

获取任务结果（模拟C++ `future.get()`）：

```c
// 阻塞等待任务完成并获取结果
int task_handle_get(TaskHandle *handle) {
    pthread_mutex_lock(handle->doneMutex);
    while (!*(handle->done)) {
        pthread_cond_wait(handle->doneCond, handle->doneMutex);
    }
    pthread_mutex_unlock(handle->doneMutex);
    return *(handle->result);
}

// 清理TaskHandle资源
void task_handle_cleanup(TaskHandle *handle) {
    pthread_mutex_destroy(handle->doneMutex);
    pthread_cond_destroy(handle->doneCond);
    free(handle->result);
    free(handle->done);
    free(handle->doneMutex);
    free(handle->doneCond);
}
```

**对比C++与C函数指针**：

| 特性 | C++ | C语言 |
|------|-----|-------|
| 通用机制 | `template<class F, class... Args>` | `int (*TaskFunc)(void *arg)` |
| 参数传递 | 完美转发 `std::forward` | `void*`参数，类型不安全 |
| 返回类型 | 泛型T自动推导 | 统一返回`int` |
| 任务封装 | `std::packaged_task` | `TaskNode`链表节点 |
| 结果获取 | `std::future::get()` | `task_handle_get()`手动实现 |
| 可变参数 | 变长模板 `Args...` | `void*`统一参数 |

### 8.3 提交普通任务和优先任务

```c
// 提交普通任务（使用lambda模拟 - C语言用独立函数）
int normal_task(void *arg) {
    printf("打印3：提交普通任务\n");
    sleep(1);
    printf("打印3：提交普通任务执行结束\n");
    return 42;
}

int priority_task(void *arg) {
    printf("打印4：提交优先任务\n");
    sleep(1);
    printf("打印4：提交优先任务执行结束\n");
    return 100;
}

int main() {
    ThreadPool pool;
    thread_pool_init(&pool, "test_pool", 4);

    // 提交普通任务
    TaskHandle future3 = thread_pool_post_task(&pool, normal_task, NULL);
    // 提交优先任务
    TaskHandle future4 = thread_pool_post_pre_task(&pool, priority_task, NULL);

    // 获取结果
    printf("普通任务结果：%d\n", task_handle_get(&future3));
    printf("优先任务结果：%d\n", task_handle_get(&future4));

    // 清理
    task_handle_cleanup(&future3);
    task_handle_cleanup(&future4);

    // 销毁线程池
    thread_pool_destroy(&pool);
    return 0;
}
```

**对比C++**：C++可以使用lambda表达式`[]() { ... }`内联定义任务，C语言必须定义独立的函数。这是C语言最大的局限之一——没有闭包，无法捕获局部变量。

## 09.核心设计思想

### 9.1 生产者-消费者

- **生产者**：调用 `thread_pool_post_task`/`thread_pool_post_pre_task` 提交任务的线程
- **消费者**：线程池中的工作线程
- **缓冲区**：任务队列（tasksHead链表 / preTasksHead链表）
- **同步机制**：`pthread_mutex_t` + `pthread_cond_t`

这种模式解耦了任务提交和执行，提高了系统的吞吐量和响应能力。

### 9.2 资源管理

C语言没有RAII机制，必须手动管理所有资源：

```c
// 创建（对应C++构造函数）
thread_pool_init(&pool, "test_pool", 4);

// 使用...

// 销毁（对应C++析构函数）
thread_pool_destroy(&pool);
```

每个TaskHandle也需要手动清理：

```c
TaskHandle handle = thread_pool_post_task(&pool, func, arg);
int result = task_handle_get(&handle);
task_handle_cleanup(&handle); // 必须手动清理！
```

**对比C++**：C++的RAII确保资源在对象生命周期结束时自动释放，`std::future`不需要手动清理。

### 9.3 双队列优先级设计

- **普通任务队列(tasksHead)**：先进先出(FIFO)
- **优先任务队列(preTasksHead)**：高优先级任务
- **调度策略**：

```c
if (pool->preTasksHead != NULL) { // 优先处理优先任务
    preTask = dequeue_task(&pool->preTasksHead, &pool->preTasksTail, &pool->preTasksSize);
}
if (pool->tasksHead != NULL) { // 再处理普通任务
    task = dequeue_task(&pool->tasksHead, &pool->tasksTail, &pool->tasksSize);
}
```

设计与C++版本完全一致。

### 9.4 任务结果获取

C语言通过TaskHandle模拟C++的`std::future`：

```c
// C: 手动管理的"future"
TaskHandle handle = thread_pool_post_task(&pool, func, arg);
int result = task_handle_get(&handle); // 阻塞等待
task_handle_cleanup(&handle);          // 手动清理
```

```cpp
// C++: 标准库的future
auto future = pool.postTask(func, args...);
auto result = future.get(); // 阻塞等待，自动清理
```

### 9.5 线程生命周期

- **线程创建**：`thread_pool_init`中创建固定数量线程
- **线程回收**：`thread_pool_destroy`中安全停止并回收

### 9.6 锁粒度优化

- **细粒度锁**：只在访问共享数据时加锁
- **锁外执行**：任务执行在锁范围外进行

```c
pthread_mutex_lock(&pool->queueMutex);
// 取出任务（访问共享数据）
pthread_mutex_unlock(&pool->queueMutex);
// 执行任务（在锁外执行）
if (task != NULL) {
    int result = task->func(task->arg);
}
```

### 9.7 可扩展性设计

- **函数指针任务**：支持任意任务函数
- **`void*`参数**：支持任意类型参数
- **TaskHandle**：提供异步结果获取
- **状态查询接口**：便于监控

### 9.8 潜在改进方向

1. **动态线程调整**：根据负载自动增减线程
2. **任务窃取机制**：提高负载均衡
3. **任务超时处理**：使用`pthread_cond_timedwait`实现
4. **类型安全**：使用宏或代码生成实现泛型任务接口
5. **线程本地队列**：减少锁竞争

## 10.对比C++线程池

### 10.1 唤醒策略优化

- `pthread_cond_signal()`：提交单个任务时只唤醒一个线程（对应C++ `notify_one()`）
- `pthread_cond_broadcast()`：停止时唤醒所有线程（对应C++ `notify_all()`）

### 10.2 异常安全

C语言没有异常机制，使用返回值和错误打印：

```c
if (pool->stop) {
    fprintf(stderr, "Error: enqueue on stopped ThreadPool\n");
    free(node);
    return handle;
}
```

**对比C++**：C++使用`throw std::runtime_error("enqueue on stopped ThreadPool")`，异常通过future自动传播。

### 10.3 资源清理

```c
void thread_pool_clear_tasks(ThreadPool *pool);
void thread_pool_clear_pre_tasks(ThreadPool *pool);
void thread_pool_clear_all_tasks(ThreadPool *pool);
```

提供任务队列清理机制，需要遍历链表逐个`free`节点。

### 10.4 并发编程技术

1. 锁粒度控制：最小化临界区范围；任务执行在锁外进行
2. 线程安全队列：`pthread_mutex`保护队列操作；`pthread_cond`同步访问
3. 优雅停止机制：stop标志位；`pthread_cond_broadcast`唤醒所有线程；`pthread_join`等待线程结束
4. 任务优先级管理：双队列设计（普通/优先）；优先任务优先调度

### 10.5 性能优化技术

1. 避免虚假唤醒：条件变量使用while循环检查

```c
while (!pool->stop && pool->tasksHead == NULL && pool->preTasksHead == NULL) {
    pthread_cond_wait(&pool->cv, &pool->queueMutex);
}
```

2. 唤醒优化：提交单个任务时使用signal；停止时使用broadcast
3. 内存管理：任务节点在执行完毕后立即free，不会累积
4. 链表操作：O(1)的入队和出队操作

### 10.6 对比C++总结

| 对比维度 | C语言线程池 | C++线程池 |
|---------|-----------|----------|
| **线程创建** | `pthread_create` + 函数指针 | `std::thread` + lambda/成员函数 |
| **互斥锁** | `pthread_mutex_lock/unlock` 手动 | `std::unique_lock` RAII自动 |
| **条件变量** | `while(!cond) pthread_cond_wait` | `cv.wait(lock, lambda)` 内置谓词 |
| **任务封装** | `TaskNode`链表 + 函数指针 | `std::packaged_task` |
| **异步结果** | `TaskHandle` + 手动同步 | `std::future` 自动管理 |
| **类型通用** | `void*` 类型擦除（不安全） | 变长模板（类型安全） |
| **参数传递** | 结构体打包 + `void*` | 完美转发 `std::forward` |
| **类型推导** | 无，统一int返回 | `std::result_of` 编译期推导 |
| **内存管理** | `malloc`/`free` 手动 | `shared_ptr` 自动引用计数 |
| **资源释放** | 显式`destroy` + `cleanup` | 析构函数自动（RAII） |
| **异常处理** | 返回值 + `fprintf(stderr)` | `throw` + `try-catch` |
| **队列实现** | 手写链表 | `std::queue` 标准容器 |
| **原子操作** | 无（互斥锁保护） | `std::atomic` 无锁 |
| **拷贝控制** | 无机制（手动避免） | `= delete` 禁止拷贝 |
| **闭包/Lambda** | 不支持（独立函数） | Lambda捕获上下文 |
| **代码行数** | 约多50-80% | 更简洁 |
| **编译依赖** | `-pthread`链接选项 | `<thread>` 头文件 |
