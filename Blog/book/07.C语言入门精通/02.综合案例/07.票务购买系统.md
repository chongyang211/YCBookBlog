## 01.票务购买系统

### 1.1 产品需求

模拟多个窗口售票、多人购票的场景。系统包括票务管理、窗口管理、顾客管理、交易日志等功能。不需要UI窗口，命令行操作即可。

1. 多窗口（线程）售票
2. 用户购票行为模拟
3. 票务查询和统计
4. 日志和错误处理
5. 系统配置管理

### 1.2 程序功能

1. **初始化阶段**：加载配置；创建日志系统；初始化票务系统
2. **窗口启动**：创建售票窗口线程；每个窗口开始售票
3. **顾客购票**：顾客线程发起购票请求；系统处理购票事务
4. **动态调整**：监控票数并预警；动态增加票数
5. **关闭系统**：停止售票窗口；生成统计报告

### 1.3 开发设计步骤

1. 步骤1：实现日志系统（线程安全的文件+控制台输出）
2. 步骤2：实现配置管理（从文件读取配置）
3. 步骤3：实现票务系统核心（售票、加票、线程安全）
4. 步骤4：实现售票窗口（独立线程售票）
5. 步骤5：实现顾客系统（独立线程购票）
6. 步骤6：整合主程序
7. 步骤7：添加动态票务监控
8. 步骤8：添加性能监控与统计

### 1.4 技术栈说明

| 技术类别 | 具体技术 | 应用场景 |
|---------|---------|---------|
| **并发基础** | pthread_create, pthread_mutex | 线程创建和同步 |
| **条件变量** | pthread_cond_wait, pthread_cond_signal | 线程协调 |
| **原子操作** | 手动加锁模拟 | 计数器保护 |
| **文件操作** | fopen, fprintf, fscanf | 日志和配置 |
| **随机数** | rand, srand | 模拟随机购票 |
| **内存管理** | malloc, free | 动态内存分配 |

| **时间** | time, usleep | 模拟耗时和时间戳 |

**对比C++**：C++使用`std::thread`/`std::mutex`/`std::condition_variable`/`std::atomic`等RAII风格的并发工具，代码更简洁安全。C语言使用POSIX线程库`pthread`，需要手动管理锁的获取和释放，更底层但也更灵活。

```c
#include <stdio.h>

```

**对比C++**：C++使用`enum class LogLevel`，有作用域限制，访问时需要`LogLevel::INFO`。C语言的`enum`没有作用域，通常用前缀`LOG_`来避免命名冲突。

### 2.2 日志系统实现

```c
// 日志系统结构体（对应C++ Logger类）
typedef struct {
    FILE *logFile;              // 日志文件（对应C++ std::ofstream）
    pthread_mutex_t logMutex;   // 日志锁（对应C++ std::mutex）
} Logger;

// 初始化日志系统（对应C++构造函数）
int logger_init(Logger *logger, const char *fileName) {
    logger->logFile = fopen(fileName, "a");
    if (logger->logFile == NULL) {
        fprintf(stderr, "Failed to open log file: %s\n", fileName);
        return -1;
    }
    pthread_mutex_init(&logger->logMutex, NULL);
    return 0;
}

// 销毁日志系统（对应C++析构函数）
void logger_destroy(Logger *logger) {
    if (logger->logFile != NULL) {
        fclose(logger->logFile);
        logger->logFile = NULL;
    }
    pthread_mutex_destroy(&logger->logMutex);
}

// 获取日志级别字符串
const char* log_level_str(LogLevel level) {
    switch (level) {
        case LOG_INFO:    return "INFO";
        case LOG_DEBUG:   return "DEBUG";
        case LOG_WARNING: return "WARNING";
        case LOG_ERROR:   return "ERROR";
        default:          return "UNKNOWN";
    }
}

// 打印日志（对应C++ Logger::log方法）
void logger_log(Logger *logger, const char *message, LogLevel level) {
    pthread_mutex_lock(&logger->logMutex);
    char logMessage[512];
    snprintf(logMessage, sizeof(logMessage), "[%s] %s", log_level_str(level), message);
    fprintf(logger->logFile, "%s\n", logMessage);
    fflush(logger->logFile);
    printf("%s\n", logMessage);
    pthread_mutex_unlock(&logger->logMutex);
}
```

**对比C++**：
- C++用构造函数/析构函数自动管理资源（RAII），C语言需要显式调用`init`/`destroy`
- C++用`std::lock_guard<std::mutex>`自动加解锁，C语言需要手动`pthread_mutex_lock`/`unlock`
- C++用`std::string`和流操作拼接字符串，C语言用`snprintf`格式化

### 2.4 配置管理系统

C语言没有`std::unordered_map`，使用简单的键值对数组存储配置。

```c
// 配置项结构（对应C++ std::unordered_map<std::string, int>）
#define MAX_CONFIG_ITEMS 20
#define MAX_KEY_LEN 64

typedef struct {
    char key[MAX_KEY_LEN];
    int value;
} ConfigItem;

typedef struct {
    ConfigItem items[MAX_CONFIG_ITEMS];
    int count;
} ConfigManager;

// 初始化配置管理器（对应C++构造函数）
void config_init(ConfigManager *config, const char *fileName) {
    config->count = 0;
    FILE *file = fopen(fileName, "r");
    if (file != NULL) {
        char key[MAX_KEY_LEN];
        int value;
        while (fscanf(file, "%s %d", key, &value) == 2) {
            if (config->count < MAX_CONFIG_ITEMS) {
                strncpy(config->items[config->count].key, key, MAX_KEY_LEN - 1);
                config->items[config->count].key[MAX_KEY_LEN - 1] = '\0';
                config->items[config->count].value = value;
                config->count++;
            }
        }
        fclose(file);
    } else {
        // 默认配置
        strcpy(config->items[0].key, "total_tickets");    config->items[0].value = 100;
        strcpy(config->items[1].key, "num_windows");       config->items[1].value = 3;
        strcpy(config->items[2].key, "num_customers");     config->items[2].value = 10;
        strcpy(config->items[3].key, "max_tickets_per_customer"); config->items[3].value = 5;
        config->count = 4;
    }
}

// 获取配置值（对应C++ ConfigManager::get）
int config_get(const ConfigManager *config, const char *key) {
    for (int i = 0; i < config->count; i++) {
        if (strcmp(config->items[i].key, key) == 0) {
            return config->items[i].value;
        }
    }
    fprintf(stderr, "Config key not found: %s\n", key);
    return -1;
}
```

**对比C++**：C++使用`std::unordered_map`实现O(1)查找，C语言用数组线性查找O(n)。对于少量配置项，性能差异可忽略。

## 03.票务系统实现

实现票务系统核心功能，包括票数管理和线程安全操作。

### 3.1 设计票务系统结构

```c
// 票务系统结构体（对应C++ TicketSystem类）
typedef struct {
    int totalTickets;               // 总票数
    int remainingTickets;           // 剩余票数（C++用std::atomic<int>）
    pthread_mutex_t ticketMutex;    // 票务锁（对应C++ std::mutex）
    pthread_cond_t cv;              // 条件变量（对应C++ std::condition_variable）
    Logger *logger;                 // 日志系统指针（对应C++引用）
} TicketSystem;

// 初始化票务系统（对应C++构造函数）
void ticket_system_init(TicketSystem *ts, int total, Logger *logger) {
    ts->totalTickets = total;
    ts->remainingTickets = total;
    ts->logger = logger;
    pthread_mutex_init(&ts->ticketMutex, NULL);
    pthread_cond_init(&ts->cv, NULL);
    char msg[128];
    snprintf(msg, sizeof(msg), "Ticket system created with %d tickets", total);
    logger_log(logger, msg, LOG_INFO);
}

// 销毁票务系统（对应C++析构函数）
void ticket_system_destroy(TicketSystem *ts) {
    pthread_mutex_destroy(&ts->ticketMutex);
    pthread_cond_destroy(&ts->cv);
}
```

**对比C++**：C++使用`std::atomic<int>`保证原子操作，C语言必须用互斥锁保护所有对`remainingTickets`的访问。C++的引用`Logger&`在C语言中用指针`Logger*`替代。

### 3.2 实现售票方法

```c
// 售票方法（对应C++ TicketSystem::sellTicket）
int ticket_system_sell(TicketSystem *ts, int num, const char *windowName) {
    pthread_mutex_lock(&ts->ticketMutex);
    // 等待条件：票数足够或票数为0（对应C++ cv.wait(lock, predicate)）
    while (ts->remainingTickets < num && ts->remainingTickets > 0) {
        pthread_cond_wait(&ts->cv, &ts->ticketMutex);
    }
    char msg[256];
    if (ts->remainingTickets >= num) {
        ts->remainingTickets -= num;
        snprintf(msg, sizeof(msg), "%s sold %d tickets. Remaining tickets: %d",
                 windowName, num, ts->remainingTickets);
        logger_log(ts->logger, msg, LOG_INFO);
        pthread_cond_broadcast(&ts->cv);
        pthread_mutex_unlock(&ts->ticketMutex);
        return 1; // 成功
    } else {
        snprintf(msg, sizeof(msg), "%s failed to sell %d tickets. Not enough tickets available.",
                 windowName, num);
        logger_log(ts->logger, msg, LOG_WARNING);
        pthread_mutex_unlock(&ts->ticketMutex);
        return 0; // 失败
    }
}
```

**对比C++**：
- C++使用`std::unique_lock`配合`cv.wait(lock, lambda)`，lambda表达式作为等待谓词
- C语言使用`while`循环 + `pthread_cond_wait`手动检查条件
- C++的`cv.notify_all()`对应C语言的`pthread_cond_broadcast`
- C++用`std::stringstream`拼接字符串，C语言用`snprintf`

### 3.3 实现加票方法

```c
// 加票方法（对应C++ TicketSystem::addTickets）
void ticket_system_add(TicketSystem *ts, int num) {
    if (num <= 0) {
        char msg[128];
        snprintf(msg, sizeof(msg), "Failed to add tickets. Invalid number: %d", num);
        logger_log(ts->logger, msg, LOG_WARNING);
        return;
    }
    pthread_mutex_lock(&ts->ticketMutex);
    ts->remainingTickets += num;
    char msg[128];
    snprintf(msg, sizeof(msg), "Added %d tickets. Remaining tickets: %d",
             num, ts->remainingTickets);
    logger_log(ts->logger, msg, LOG_INFO);
    pthread_cond_broadcast(&ts->cv);
    pthread_mutex_unlock(&ts->ticketMutex);
}

// 获取剩余票数
int ticket_system_remaining(TicketSystem *ts) {
    pthread_mutex_lock(&ts->ticketMutex);
    int remaining = ts->remainingTickets;
    pthread_mutex_unlock(&ts->ticketMutex);
    return remaining;
}
```

## 04.售票窗口实现

目标：实现售票窗口及其多线程售票功能。

**对比C++设计原理**：
- C++使用`std::thread`创建线程，C语言使用`pthread_create`
- C++使用`std::atomic<bool>`控制运行状态，C语言使用`volatile int` + 互斥锁
- C++使用`std::unique_ptr`管理窗口对象生命周期，C语言使用`malloc`/`free`

### 4.1 售票窗口结构

```c
// 售票窗口结构（对应C++ TicketWindow类）
typedef struct {
    char name[64];                  // 窗口名称
    TicketSystem *ticketSystem;     // 票务系统指针（对应C++引用）
    Logger *logger;                 // 日志指针
    volatile int running;           // 运行标志（对应C++ std::atomic<bool>）
    int ticketsSold;                // 售出票数（对应C++ std::atomic<int>）
    pthread_t workerThread;         // 工作线程（对应C++ std::thread）
    pthread_mutex_t soldMutex;      // 保护ticketsSold的锁
} TicketWindow;

// 初始化售票窗口（对应C++构造函数）
void window_init(TicketWindow *win, const char *name, TicketSystem *ts, Logger *logger) {
    strncpy(win->name, name, sizeof(win->name) - 1);
    win->name[sizeof(win->name) - 1] = '\0';
    win->ticketSystem = ts;
    win->logger = logger;
    win->running = 1;
    win->ticketsSold = 0;
    pthread_mutex_init(&win->soldMutex, NULL);
    char msg[128];
    snprintf(msg, sizeof(msg), "Ticket window %s created", name);
    logger_log(logger, msg, LOG_INFO);
}

// 销毁售票窗口
void window_destroy(TicketWindow *win) {
    pthread_mutex_destroy(&win->soldMutex);
}
```

### 4.2 启动售票线程

```c
// 售票线程函数（对应C++ TicketWindow::start中的lambda）
void* window_thread_func(void *arg) {
    TicketWindow *win = (TicketWindow*)arg;
    char msg[128];
    snprintf(msg, sizeof(msg), "%s started selling tickets", win->name);
    logger_log(win->logger, msg, LOG_INFO);
    // 初始化随机种子
    unsigned int seed = (unsigned int)time(NULL) ^ (unsigned int)pthread_self();
    while (win->running) {
        int numTickets = (rand_r(&seed) % 5) + 1; // 1-5张
        if (ticket_system_sell(win->ticketSystem, numTickets, win->name)) {
            pthread_mutex_lock(&win->soldMutex);
            win->ticketsSold += numTickets;
            pthread_mutex_unlock(&win->soldMutex);
            usleep(100000); // 模拟出票时间100ms
        } else {
            snprintf(msg, sizeof(msg), "%s failed to sell tickets. Not enough tickets available.",
                     win->name);
            logger_log(win->logger, msg, LOG_WARNING);
            break;
        }
    }
    snprintf(msg, sizeof(msg), "%s stopped selling tickets", win->name);
    logger_log(win->logger, msg, LOG_INFO);
    return NULL;
}

// 启动售票窗口
void window_start(TicketWindow *win) {
    pthread_create(&win->workerThread, NULL, window_thread_func, win);
}
```

**对比C++**：
- C++的`std::thread`构造时直接启动线程，可以传入lambda或成员函数
- C语言的`pthread_create`需要传入函数指针和`void*`参数，需要手动类型转换
- C++使用`std::random_device`和`std::mt19937`生成随机数，C语言使用`rand_r`（线程安全版本）
- C++使用`std::this_thread::sleep_for`，C语言使用`usleep`

```c
// 顾客购票线程函数（对应C++ Customer::buyTickets中的lambda）
void* customer_thread_func(void *arg) {
    Customer *cust = (Customer*)arg;
    char msg[256];
    snprintf(msg, sizeof(msg), "%s is trying to buy %d tickets.", cust->name, cust->numTickets);
    logger_log(cust->logger, msg, LOG_INFO);
    if (ticket_system_sell(cust->ticketSystem, cust->numTickets, cust->name)) {
        snprintf(msg, sizeof(msg), "%s successfully bought %d tickets.",
                 cust->name, cust->numTickets);
        logger_log(cust->logger, msg, LOG_INFO);
    } else {
        snprintf(msg, sizeof(msg), "%s failed to buy %d tickets. Not enough tickets available.",
                 cust->name, cust->numTickets);
        logger_log(cust->logger, msg, LOG_WARNING);
    }
    return NULL;
}

// 发起购票（对应C++ Customer::buyTickets）
void customer_buy(Customer *cust, int num) {
    cust->numTickets = num;
    pthread_create(&cust->purchaseThread, NULL, customer_thread_func, cust);
}
```

## 06.主程序整合

### 6.1 基本购票流程

```c
int main() {
    // 读取配置文件
    ConfigManager config;
    config_init(&config, "config.txt");
    int totalTickets = config_get(&config, "total_tickets");
    int numWindows = config_get(&config, "num_windows");
    int numCustomers = config_get(&config, "num_customers");
    int maxTicketsPerCustomer = config_get(&config, "max_tickets_per_customer");

    // 初始化日志系统
    Logger logger;
    logger_init(&logger, "ticket_system.log");

    // 初始化票务系统
    TicketSystem ticketSystem;
    ticket_system_init(&ticketSystem, totalTickets, &logger);

    // 创建售票窗口
    TicketWindow *windows = (TicketWindow*)malloc(numWindows * sizeof(TicketWindow));
    for (int i = 0; i < numWindows; i++) {
        char name[64];
        snprintf(name, sizeof(name), "Window %d", i + 1);
        window_init(&windows[i], name, &ticketSystem, &logger);
    }

    // 启动售票窗口
    for (int i = 0; i < numWindows; i++) {
        window_start(&windows[i]);
    }

    // 创建顾客并购票
    unsigned int seed = (unsigned int)time(NULL);
    Customer *customers = (Customer*)malloc(numCustomers * sizeof(Customer));
    for (int i = 0; i < numCustomers; i++) {
        char name[64];
        snprintf(name, sizeof(name), "Customer %d", i + 1);
        customer_init(&customers[i], name, &ticketSystem, &logger);
        int numTickets = (rand_r(&seed) % maxTicketsPerCustomer) + 1;
        customer_buy(&customers[i], numTickets);
        usleep(200000); // 模拟顾客购票间隔200ms
    }

    // 动态增加票数
    sleep(2);
    ticket_system_add(&ticketSystem, 50);

    // 等待所有顾客购票完成
    for (int i = 0; i < numCustomers; i++) {
        customer_wait(&customers[i]);
    }

    // 等待并停止售票窗口
    sleep(5);
    for (int i = 0; i < numWindows; i++) {
        window_stop(&windows[i]);
    }

    // 输出统计信息
    char msg[256];
    snprintf(msg, sizeof(msg), "All done. Remaining tickets: %d",
             ticket_system_remaining(&ticketSystem));
    logger_log(&logger, msg, LOG_INFO);
    for (int i = 0; i < numWindows; i++) {
        snprintf(msg, sizeof(msg), "%s sold %d tickets", windows[i].name,
                 window_get_sold(&windows[i]));
        logger_log(&logger, msg, LOG_INFO);
    }

    // 清理资源
    for (int i = 0; i < numWindows; i++) {
        window_destroy(&windows[i]);
    }
    free(windows);
    free(customers);
    ticket_system_destroy(&ticketSystem);
    logger_destroy(&logger);
    return 0;
}
```

**对比C++**：C++的main函数中使用RAII，对象离开作用域时自动销毁。C语言必须在最后显式释放所有资源（`free`、`destroy`），一旦遗漏就会导致内存泄漏或资源未释放。

```c
// 监控线程参数
typedef struct {
    TicketSystem *ticketSystem;
    Logger *logger;
} MonitorArgs;

// 监控线程函数（对应C++ TicketSystem::monitorTickets中的lambda）
void* monitor_thread_func(void *arg) {
    MonitorArgs *args = (MonitorArgs*)arg;
    while (1) {
        sleep(1);
        int remaining = ticket_system_remaining(args->ticketSystem);
        if (remaining < args->ticketSystem->totalTickets / 4) {
            char msg[128];
            snprintf(msg, sizeof(msg), "Warning: Only %d tickets remaining!", remaining);
            logger_log(args->logger, msg, LOG_WARNING);
        }
        if (remaining == 0) break;
    }
    return NULL;
}
```

**对比C++**：C++使用`std::thread(...).detach()`创建分离线程，C语言使用`pthread_detach`或分离属性。C++的lambda可以直接捕获`this`指针，C语言需要通过`void*`参数传递结构体指针。

### 9.2 添加错误处理

C语言没有`try-catch`异常机制，使用返回值和`errno`进行错误处理。

```c
// 安全售票（带错误恢复）
int ticket_system_sell_safe(TicketSystem *ts, int num, const char *windowName) {
    if (num <= 0) {
        char msg[128];
        snprintf(msg, sizeof(msg), "Invalid ticket count: %d", num);
        logger_log(ts->logger, msg, LOG_ERROR);
        return -1; // 错误
    }
    int result = ticket_system_sell(ts, num, windowName);
    if (!result) {
        // 售票失败，尝试恢复
        char msg[256];
        snprintf(msg, sizeof(msg), "%s encountered sell failure for %d tickets", windowName, num);
        logger_log(ts->logger, msg, LOG_ERROR);
    }
    return result;
}
```

**对比C++**：C++使用`try-catch`捕获异常，可以在catch块中执行恢复逻辑。C语言必须检查每个函数的返回值，手动处理错误。

## 10.对比C++实现

### 10.1 性能监控结构

```c
// 性能监控结构（对应C++ PerformanceMonitor类）
typedef struct {
    int totalSales;
    int successfulSales;
    int failedSales;
    time_t startTime;
    Logger *logger;
    pthread_mutex_t monMutex;
} PerformanceMonitor;

void monitor_init(PerformanceMonitor *pm, Logger *logger) {
    pm->totalSales = 0;
    pm->successfulSales = 0;
    pm->failedSales = 0;
    pm->startTime = time(NULL);
    pm->logger = logger;
    pthread_mutex_init(&pm->monMutex, NULL);
}

void monitor_destroy(PerformanceMonitor *pm) {
    pthread_mutex_destroy(&pm->monMutex);
}

void monitor_record(PerformanceMonitor *pm, int success) {
    pthread_mutex_lock(&pm->monMutex);
    pm->totalSales++;
    if (success) pm->successfulSales++;
    else pm->failedSales++;
    pthread_mutex_unlock(&pm->monMutex);
}

void monitor_report(PerformanceMonitor *pm) {
    time_t endTime = time(NULL);
    double duration = difftime(endTime, pm->startTime);
    char msg[512];
    snprintf(msg, sizeof(msg),
        "\n==== PERFORMANCE REPORT ====\n"
        "Total sales attempts: %d\n"
        "Successful sales: %d\n"
        "Failed sales: %d\n"
        "Success rate: %.1f%%\n"
        "Simulation duration: %.0f seconds\n"
        "Transactions per second: %.1f",
        pm->totalSales,
        pm->successfulSales,
        pm->failedSales,
        pm->totalSales > 0 ? 100.0 * pm->successfulSales / pm->totalSales : 0.0,
        duration,
        duration > 0 ? pm->totalSales / duration : 0.0);
    logger_log(pm->logger, msg, LOG_INFO);
}
```

**对比C++**：C++使用`std::atomic<int>`进行无锁计数，C语言必须用互斥锁保护。C++使用`std::chrono::steady_clock`精确计时，C语言使用`time()`精度为秒级。

### 10.2 使用监控处理

```c
int main() {
    // ... 初始化后
    PerformanceMonitor monitor;
    monitor_init(&monitor, &logger);
    // 在售票成功/失败时: monitor_record(&monitor, 1/0);
    // 结束时报告
    monitor_report(&monitor);
    monitor_destroy(&monitor);
}
```

### 10.4 对比C++总结

| 对比维度 | C语言实现 | C++实现 |
|---------|----------|---------|
| **线程创建** | `pthread_create` + 函数指针 | `std::thread` + lambda |
| **互斥锁** | `pthread_mutex_lock/unlock` 手动管理 | `std::lock_guard` RAII自动管理 |
| **条件变量** | `pthread_cond_wait` + while循环 | `cv.wait(lock, lambda)` 内置谓词 |
| **原子操作** | 互斥锁保护普通变量 | `std::atomic<int>` 无锁操作 |
| **字符串操作** | `snprintf`/`strcmp` 固定缓冲区 | `std::string` + `std::stringstream` |
| **内存管理** | `malloc`/`free` 手动管理 | `std::unique_ptr` 智能指针 |
| **容器** | 固定数组 / `malloc`动态数组 | `std::vector` 动态容器 |
| **配置存储** | 结构体数组线性查找 | `std::unordered_map` 哈希查找 |
| **随机数** | `rand_r` (线程安全) | `std::mt19937` + 分布 |
| **时间操作** | `time()`/`usleep()` 秒级 | `std::chrono` 纳秒级 |
| **错误处理** | 返回值 + `errno` | `try-catch` 异常机制 |
| **资源管理** | 显式init/destroy | RAII构造/析构自动 |
| **面向对象** | 结构体 + 函数指针模拟 | 类 + 继承 + 多态 |
| **日志线程安全** | `pthread_mutex` 手动锁 | `std::lock_guard` 自动锁 |
| **代码行数** | 约多30-50% | 更简洁 |
| **可读性** | 需要更多样板代码 | 更接近自然语言 |
