## 02.搞懂内存属性

### 2.1 基础概念说明

1. VSS：Virtual Set Size 虚拟耗用内存（包含共享库占用的内存）
2. RSS：Resident Set Size 实际使用物理内存（包含共享库占用的内存）
3. PSS：Proportional Set Size 实际使用的物理内存（比例分配共享库占用的内存）
4. USS：Unique Set Size 进程独自占用的物理内存（不包含共享库占用的内存）

大小规律：一般来说内存占用大小有如下规律：VSS >= RSS >= PSS >= USS

## 03.内存监控核心

**内存监控**：使用`/proc`文件系统获取详细内存信息。脚本定期采集并记录关键指标

### 3.1 内存监控原理

在嵌入式Linux系统中，内存信息主要通过`/proc`文件系统获取：

- `/proc/meminfo`：系统整体内存使用情况
- `/proc/[pid]/status`：特定进程内存使用情况
- `/proc/[pid]/statm`：进程内存状态（更简洁）

关键指标：

- **VmSize**：虚拟内存大小
- **VmRSS**：实际使用的物理内存
- **VmData**：数据段大小
- **VmStk**：栈大小

## 04.内存监控方案

### 4.2 进程级内存统计

```shell
stats=$(ps -o pid,pcpu,pmem,rss,vsz -p "$pid" 2>/dev/null | tail -n1)
echo "$stats" | tr -s ' ' | awk '{print $2","$3","int($4/1024)","int($5/1024)}'
```

统计指标详解：

- pmem (%): 进程内存使用百分比 = (进程RSS / 系统总内存) × 100
- rss (MB): 实际物理内存占用，单位从KB转换为MB
- vsz (MB): 虚拟内存大小，包括共享库、堆栈等，单位从KB转换为MB

数据来源：/proc/[pid]/stat 和 /proc/[pid]/status

### 4.3 系统级内存统计

```shell
mem_info=$(free -m | awk 'NR==2{print $3 * 100/$2","$3","$2}')
```

统计指标详解：

- sys_mem_usage(%): 系统内存使用率 = (已用内存 / 总内存) × 100
- sys_mem_used(MB): 系统已使用内存，单位MB
- sys_mem_total(MB): 系统总内存，单位MB

数据来源：/proc/meminfo (通过free命令解析)
