# 项目 12：GitHub Trending 追踪 Agent —— 每日个性化开源推荐

> 📝 **本文待写作**。专栏二第 12 篇。技术人想跟踪开源趋势，但每天刷 GitHub 太耗时。

---

## 摘要

**能做什么**：抓 Trending → 分析 → 分类 → 个性化推荐 → 生成日报。
**技术栈**：GitHub API + LangChain + 用户画像
**代码量**：约 600 行
**对标产品**：无直接对标（差异化机会）

---

## 一、这个项目能做什么

- 每天推送 5 个值得关注的开源项目
- 附一句话解读 + 与你收藏项目的相似度
- 支持按语言 / 领域筛选

---

## 二、技术选型与架构

### 架构图

```mermaid
graph LR

    A --> P[个人偏好]
```

### 核心 Agent 能力

- Tool：`fetch_trending`
- Tool：`repo_summary`
- Tool：`match_user_profile`
