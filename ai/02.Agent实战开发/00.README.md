# Agent 实战项目集：从 0 到 1 打造真实应用

> 15 个经典项目，每篇 = 一个完整可运行的 Agent 项目 + GitHub 仓库。弱化理论，强化代码走读，让开发者从 0 到 1 快速进入 Agent 开发。

---

## 专栏定位

- **读者定位**：想动手做 Agent 项目、追求副业变现、想用 AI 提升生产力的开发者
- **核心价值**：教会"怎么做"，每个项目都能独立部署运行，具备真实业务价值
- **写作风格**：项目导向、代码优先、贴合真实场景

---

## 项目选型的四个原则

1. **真实痛点驱动**：解决开发者/工作者每天真实遇到的问题，不做玩具
2. **能力覆盖全面**：15 个项目串联起来覆盖 Agent 全部核心能力（Tool、Memory、RAG、多 Agent、MCP、部署）
3. **难度阶梯递进**：从简单到复杂，读者可循序渐进
4. **技术栈典型代表**：每类经典 Agent 场景都有一个代表作，有明确的对标产品
5. **可扩展可复用**：项目基础版是最小可跑 Demo，扩展版可直接用于实际工作

---

## 四阶段学习路径

```
🔰 第一阶段：入门项目（3 个）—— 单 Agent + 基础工具
🚀 第二阶段：进阶项目（4 个）—— Agent + RAG + Memory
🎯 第三阶段：高级项目（5 个）—— 多 Agent + 复杂编排
🏆 第四阶段：综合项目（3 个）—— 生产级完整应用
```

## 项目详细设计

### 🔰 第一阶段：入门项目

#### 项目 01：智能命令行助手 TermGPT

> **痛点**：程序员每天用命令行，但记不住 `find/awk/sed/git` 复杂参数

- **能力**：自然语言 → Shell 命令 → 安全执行 → 结果解释
- **技术栈**：OpenAI Function Calling + subprocess 沙箱
- **典型场景**：
  - "找出这个目录下最近 3 天修改的所有 .py 文件"
  - "把当前分支的最后 5 次提交生成一个 changelog"
- **核心亮点**：Tool 设计 + 危险命令拦截（`rm -rf` 类）
- **代码量**：约 300 行
- **对标产品**：GitHub Copilot CLI、Warp AI

#### 项目 02：PDF 论文速读 Agent

> **痛点**：科研/技术人员每周要读大量论文、白皮书

- **能力**：PDF 解析 → 章节切分 → 摘要生成 → 追问 Q&A
- **技术栈**：PyPDF + LangChain + OpenAI
- **典型场景**：
  - 上传一篇 Transformer 论文，5 分钟出思维导图
  - "作者的核心创新点是什么？和 BERT 有什么区别？"
- **核心亮点**：长文本处理、章节化摘要
- **代码量**：约 400 行
- **对标产品**：ChatPDF、AI PDF

#### 项目 03：自然语言转 SQL Agent（Text2SQL）

> **痛点**：产品/运营不会写 SQL，每次找开发要数据

- **能力**：读取数据库 Schema → 理解自然语言 → 生成 SQL → 执行 → 可视化
- **技术栈**：SQLAlchemy + LangChain SQL Agent
- **典型场景**：
  - "查询上个月销售额 top 10 的商品"
  - "对比 Q1 和 Q2 各产品线的增长率"
- **核心亮点**：Schema Prompt 工程 + SQL 安全审查（防注入/删表）
- **代码量**：约 500 行
- **对标产品**：Vanna.AI、DB-GPT

---

### 🚀 第二阶段：进阶项目

#### 项目 04：个人知识库助手（第二大脑）

> **痛点**：Notion/Obsidian 里几千篇笔记，找不到自己写过什么

- **能力**：多格式文档索引（MD/PDF/DOCX）→ 向量检索 → Agent 问答 → 溯源引用
- **技术栈**：ChromaDB + LangChain + Streamlit
- **典型场景**：
  - "我之前写过关于 Kubernetes 网络的笔记吗？"
  - "把我笔记里关于 GC 的内容整理成一篇博客大纲"
- **核心亮点**：本地向量库 + 引用溯源 + 增量更新
- **代码量**：约 600 行
- **对标产品**：Cursor Rules、Notion AI、Mem

#### 项目 05：代码 Review Agent

> **痛点**：小团队没人力做严格 Code Review，PR 质量参差不齐

- **能力**：读取 Git Diff → 静态分析 → 风格审查 → 安全隐患 → 输出报告
- **技术栈**：GitPython + Tree-sitter + OpenAI + GitHub Actions
- **典型场景**：
  - PR 提交后自动评审并在 GitHub 评论区留言
  - 检测 SQL 注入、硬编码密钥、性能陷阱
- **核心亮点**：多维度评审 Prompt + CI/CD 集成
- **代码量**：约 700 行
- **对标产品**：CodeRabbit、Sourcery、Qodo

#### 项目 06：竞品调研 Agent

> **痛点**：产品经理/创业者做竞品分析要花几天时间搜集资料

- **能力**：给定产品名 → 搜索官网/公众号/知乎 → 结构化输出 → PPT/Word 报告
- **技术栈**：Tavily Search + Playwright + Agent Planning
- **典型场景**：
  - 输入 "Notion"，产出「产品定位/核心功能/定价策略/用户评价/差异化机会」报告
- **核心亮点**：Plan-and-Execute 规划 + 多源信息融合 + 结构化输出
- **代码量**：约 800 行
- **对标产品**：Perplexity、Genspark

#### 项目 07：智能客服 Agent（企业级）

> **痛点**：SaaS/电商团队客服人力成本高，重复问题占 80%

- **能力**：意图识别 → 知识库检索 → 工单查询 → 人工转接
- **技术栈**：LangGraph + RAG + 工单 API + Redis 会话管理
- **典型场景**：
  - "我的订单 #12345 什么时候发货？"（工单系统查询）
  - "怎么开发票？"（知识库回答）
  - 复杂问题自动转人工，附上 Agent 收集的上下文
- **核心亮点**：多轮对话状态管理 + 优雅转人工 + 满意度评估
- **代码量**：约 1000 行
- **对标产品**：Intercom Fin、Zendesk AI

### 🎯 第三阶段：高级项目

#### 项目 08：博客写作助手 Agent

> **痛点**：技术人想写博客，但选题难、大纲乱、初稿慢

- **能力**：热点抓取 → 选题建议 → 大纲生成 → 分段撰写 → SEO 优化
- **技术栈**：CrewAI 多 Agent（研究员 + 撰稿人 + 编辑）+ 搜索工具
- **典型场景**：
  - 输入"我想写 LangGraph 相关的文章"，产出 5 个选题 + 目标读者分析
  - 选定选题后自动生成大纲、正文、封面图 Prompt
- **核心亮点**：多 Agent 协作、角色扮演、内容质量评估
- **代码量**：约 900 行
- **对标产品**：Jasper、Notion AI、Copy.ai

#### 项目 09：会议纪要 Agent

> **痛点**：每天开一堆会，会后没人整理纪要，行动项常常被遗忘

- **能力**：录音转写 → 说话人分离 → 摘要生成 → 提取行动项 → 推送到日历/飞书
- **技术栈**：Whisper + pyannote + LangChain + 飞书 API
- **典型场景**：
  - 会议结束 5 分钟内，飞书群自动收到「会议摘要 + 每个人的 TODO + 截止日期」
- **核心亮点**：多模态输入、结构化 TODO 抽取、企业工具集成
- **代码量**：约 800 行
- **对标产品**：Otter.ai、飞书妙记、腾讯会议 AI

#### 项目 10：股票/加密货币日报 Agent

> **痛点**：投资者想每天了解持仓动态，但信息源分散

- **能力**：抓取行情 → 抓取新闻 → 情绪分析 → 生成日报 → 邮件推送
- **技术栈**：Akshare/yfinance + 新闻 API + 定时任务 + SMTP
- **典型场景**：
  - 每天早 8 点，收到一份「关注股票的涨跌 + 相关新闻摘要 + AI 情绪判断」邮件
- **核心亮点**：定时任务调度、多数据源融合、Agent 主动推送
- **代码量**：约 700 行
- **对标产品**：BloombergGPT、聚宽 AI

#### 项目 11：自动化测试 Agent

> **痛点**：QA/开发写测试用例耗时长，接口一改测试就全崩

- **能力**：读取 API 文档 → 生成测试用例 → 执行 → 失败分析 → 修复建议
- **技术栈**：Swagger 解析 + pytest + Agent 反思机制
- **典型场景**：
  - 给一个 OpenAPI YAML，自动产出覆盖正常/异常/边界的测试代码并执行
- **核心亮点**：Agent 自我反思修正、测试报告可视化
- **代码量**：约 1000 行
- **对标产品**：Testim、Mabl

#### 项目 12：GitHub Trending 追踪 Agent

> **痛点**：技术人想跟踪开源趋势，但每天刷 GitHub 太耗时

- **能力**：每日抓取 Trending → 项目分析 → 分类聚合 → 个性化推荐 → 生成日报
- **技术栈**：GitHub API + LangChain + 个人兴趣画像
- **典型场景**：
  - 每天推送「今日值得关注的 5 个开源项目 + 一句话解读 + 与你收藏相似度」
- **核心亮点**：个性化推荐、Agent 主动学习用户偏好
- **代码量**：约 600 行
- **对标产品**：无直接对标，是差异化机会

### 🏆 第四阶段：综合项目

#### 项目 13：面试模拟 Agent（多 Agent 系统）

> **痛点**：求职者缺少真实面试练习，模拟面试 App 千篇一律

- **能力**：简历分析 → 面试官 Agent 提问 → 追问 → 评分 → 复盘报告
- **技术栈**：AutoGen 多 Agent（面试官 + HR + 技术专家 + 评委）
- **典型场景**：
  - 上传简历后，多个 Agent 扮演不同角色轮流追问
  - 面试结束后收到「优势/劣势/改进建议 + 面试录像回放」
- **核心亮点**：多 Agent 角色扮演、深度追问、心理评估
- **代码量**：约 1200 行
- **对标产品**：Interview Warmup（Google）、Karat

#### 项目 14：跨境电商运营 Agent 全家桶

> **痛点**：跨境卖家一个人要做选品/上架/客服/营销，忙不过来

- **能力**：选品 Agent + Listing 撰写 Agent + 客服 Agent + 广告优化 Agent，共享一个知识库
- **技术栈**：LangGraph 主编排 + 多个专业 Agent + Shopify/亚马逊 API
- **典型场景**：
  - 一个 Agent 团队为一款新品完成从选品到上架到客服的完整流程
- **核心亮点**：真实商业闭环、复杂 Agent 编排、生产级部署
- **代码量**：约 2000 行
- **对标产品**：无完整对标，是蓝海方向

#### 项目 15：个人 AI 助理终极版（毕业设计）

> **痛点**：把前面 14 个项目串成一个 24 小时陪伴的个人助手

- **能力**：日程 + 邮件 + 笔记 + 提醒 + 搜索 + 写作，通过语音/文字/微信交互
- **技术栈**：MCP 协议 + LangGraph + 微信机器人 + 所有前面项目的能力复用
- **典型场景**：
  - 微信里说："帮我准备一下明天和小王的会议"
  - Agent 自动：查日程 → 找历史沟通记录 → 拉取相关文档 → 生成议题清单
- **核心亮点**：MCP 标准化、多入口、真正的"贾维斯"
- **代码量**：约 3000 行 + 完整部署
- **对标产品**：Rewind、Personal.ai
