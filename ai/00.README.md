# AI 专栏总览

> 覆盖 AI 应用开发全栈体系，聚焦 Agent 方向，从原理到实战，从 0 到 1 打造真实可用的 AI 产品。

---

## 专栏路线图

```
14.AI/
├── 01.Agent/           (12篇 📝) ── Agent 开发原理与体系化实战
└── 02.AgentProject/    (15篇 📝) ── Agent 实战项目集：从 0 到 1 打造真实应用
```

---

## 双专栏定位

本方向采用「**原理 + 实战**」双专栏并行的形式，形成完整闭环：

| 维度 | 专栏一：Agent 原理 | 专栏二：Agent 实战项目 |
|------|-------------------|----------------------|
| **专栏名** | Agent 开发原理与体系化实战 | Agent 实战项目集 |
| **核心价值** | 讲透"为什么" | 教会"怎么做" |
| **内容形式** | 长文 + 架构图 + 对比表 | 完整项目 + 源码 + 部署文档 |
| **读者收获** | 建立知识体系，能设计 Agent 架构 | 能独立交付一个可用 Agent 产品 |
| **每篇字数** | 8000-12000 字 | 5000-7000 字（配代码仓库） |
| **目录路径** | `14.AI/01.Agent/` | `14.AI/02.AgentProject/` |
| **发布节奏** | 每 2 周 1 篇 | 每 2 周 1 篇 |

---

## 两个专栏的协同关系

```
专栏一（理论）  ←──── 相互引用 ────→  专栏二（实战）
    ↓                                    ↓
"Agent 记忆系统"    ←── 案例引用 ──   "个人知识库助手"
"Tool Calling"      ←── 案例引用 ──   "命令行智能助手"
"多 Agent 协作"     ←── 案例引用 ──   "会议纪要助手"
"RAG + Agent"       ←── 案例引用 ──   "智能客服 Agent"
"MCP 协议"          ←── 案例引用 ──   "个人 AI 助理终极版"
```

**读者的两条学习路径**：
- **理论派**：先读专栏一建立体系 → 再读专栏二完成实操
- **实战派**：直接跟专栏二动手 → 遇到疑惑时回专栏一补原理

第 1 周   [专栏一] 01.智能体全景认知入门
