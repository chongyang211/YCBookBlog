## 🧠 贯穿全书的思维方法（必看）

```mermaid
flowchart LR
    A[现象<br/>遇到 Bug 或性能问题] --> B[矛盾<br/>这个技术在解决什么矛盾]
    B --> C[设计<br/>核心思想是什么]
    C --> D[实现<br/>各语言为何选择不同]
    D --> E[演进<br/>未来还会怎么变]
    E -.复盘.-> A
```

**理解矛盾 → 理解设计 → 理解实现 → 理解演进**——这条闭环在后续每一卷都会反复出现。
