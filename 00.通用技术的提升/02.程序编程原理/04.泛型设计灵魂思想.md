## 1.泛型编程概述

### 1.1 泛型概述说明

**泛型编程（Generic Programming）**是一种编程范式，它允许程序员编写与类型无关的代码，通过参数化类型来实现代码的复用性和类型安全性。泛型的核心在于将类型作为参数，使得同一套代码可以处理多种不同的数据类型。

### 1.2 为何设计泛型

**真实案例引入**：2010年某金融交易系统因类型错误导致数百万损失。系统使用Object存储交易数据，一个整数被错误转换为字符串，最终导致交易金额计算错误。

```java
// Java 1.4时代的"通用"集合 - 这是事故的根源
List tradeList = new ArrayList();
tradeList.add(new Trade("order123", 1000));  // 正常交易
tradeList.add("invalid_data");              // 错误数据混入！编译通过！

// 处理时发生ClassCastException，系统崩溃
Trade trade = (Trade) tradeList.get(1);      // 运行时崩溃！
```

**事故分析**：这个案例暴露了Object/void*方案的**3个致命缺陷**：

- **类型安全缺失**：任何类型都能放入，运行时强转可能崩溃（直接导致金融损失）
- **代码重复**：为每种交易类型都要写重复的逻辑（维护成本高）
- **性能损耗**：基本类型必须装箱，产生额外的堆分配（影响交易系统性能）

**泛型解决方案**：

```java
// 有泛型后 - 编译期就杜绝此类错误
List<Trade> tradeList = new ArrayList<>();
tradeList.add(new Trade("order123", 1000));  // 正常交易
// tradeList.add("invalid_data");           // 编译错误！类型安全！

Trade trade = tradeList.get(0);              // 无需强转，类型安全
```

### 1.4 泛型基本定义

**泛型基本概念案例**：某数据库框架通过泛型实现类型安全的ORM。

```java
// 泛型基本定义
public class Repository<T> {
    private List<T> entities = new ArrayList<>();
    
    // 泛型方法：类型参数T
    public void add(T entity) {
        entities.add(entity);
    }
    
    // 泛型方法：类型参数T
    public T findById(Long id) {
        return entities.stream()
            .filter(e -> e.getId().equals(id))
            .findFirst()
            .orElse(null);
    }
    
    // 泛型接口：类型参数T
    public interface Mapper<T> {
        T map(ResultSet rs) throws SQLException;
    }
}

// 使用示例：类型安全
Repository<User> userRepo = new Repository<>();
userRepo.add(new User("Alice"));  // 类型安全
User user = userRepo.findById(1L); // 无需强转
```

    public static <T extends Number> T add(T a, T b) {
        if (a instanceof Integer) {
            return (T) Integer.valueOf(a.intValue() + b.intValue());

// 泛型方法设计：方法级别类型参数
public class AlgorithmUtils {
    
    // 泛型方法：类型参数T
    public static <T> T findMax(T[] array, Comparator<T> comparator) {
        if (array.length == 0) return null;
        
        T max = array[0];
        for (int i = 1; i < array.length; i++) {
            if (comparator.compare(array[i], max) > 0) {
                max = array[i];
            }
        }
        return max;
    }
    
    // 泛型方法：类型推断
    public static <T> List<T> filter(List<T> list, Predicate<T> predicate) {
        return list.stream()
            .filter(predicate)
            .collect(Collectors.toList());
    }
    
    // 泛型方法：多类型参数
    public static <T, U> U transform(T input, Function<T, U> transformer) {
        return transformer.apply(input);
    }
}

// 使用示例：类型推断
String[] names = {"Alice", "Bob", "Charlie"};
String maxName = AlgorithmUtils.findMax(names, String::compareTo);
