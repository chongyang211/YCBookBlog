## 写作约定

- **文件名**：5–8 字
- **二级、三级标题**：≤ 9 字
- **每章结构**：案例引入 → 原理拆解 → 代码示例 → Mermaid 图 → 工程取舍 → 与下一章衔接
- **由浅入深**：从一个具体翻车现场出发，先讲 what，再讲 why 与 how，最后给边界与延伸

## 系列三段式

```mermaid
flowchart TB
    A[01-02 对象怎么写<br/>语言层] --> B[03-05 对象怎么连<br/>结构层]
    B --> C[06-07 写得好+救得回<br/>工程层]
```

- **03–05**：对象怎么连（接口 / 抽象类 / 组合）
