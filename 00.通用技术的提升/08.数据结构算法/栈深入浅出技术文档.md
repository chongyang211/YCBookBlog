```mermaid

    Stack->>Memory: 申请新节点
    Memory-->>Node: 创建节点
    Node->>Node: 设置data
    Node->>OldTop: 设置next指向原栈顶
    Stack->>Node: 更新top指向新节点
    Stack->>Stack: size++
    Stack-->>User: 操作完成

    User->>Stack: pop()
    Stack->>Stack: 检查是否为空
    Stack->>OldTop: 获取栈顶数据
    Stack->>Stack: top = top.next
    Stack->>Memory: 释放原栈顶节点
    Stack->>Stack: size--
    Stack-->>User: 返回数据
```

### 6.3 摊销分析详解

```mermaid
sequenceDiagram
    participant User as 用户
    participant Stack as 动态栈
    participant Analysis as 摊销分析
    
    Note over User,Analysis: n次push操作的摊销分析
    
    loop n次操作
        User->>Stack: push(element)
        
        alt 需要扩容 (log n次)
            Stack->>Stack: 扩容操作 O(当前大小)
            Analysis->>Analysis: 记录扩容成本
        else 正常操作 (n-log n次)
            Stack->>Stack: 直接插入 O(1)
            Analysis->>Analysis: 记录常数成本
        end
    end
    
    Analysis->>Analysis: 总成本 = n + Σ扩容成本
    Analysis->>Analysis: 扩容成本 ≤ 2n
    Analysis->>Analysis: 摊销成本 = (n + 2n) / n = O(1)
```

### 栈的设计哲学

栈体现了计算机科学中的重要设计原则：

1. **约束即力量**：通过限制访问方式，栈提供了强大的抽象能力
2. **简单即美**：简单的LIFO原则支撑了复杂的应用场景
3. **效率优先**：O(1)的基本操作保证了高效的性能表现
4. **自然映射**：栈的概念与现实世界和计算模型自然对应

### 实际应用指导

1. **选择合适的实现**：根据使用场景选择数组栈、链表栈或动态栈
2. **注意内存管理**：特别是在C/C++中，要正确处理栈的内存分配和释放
3. **处理边界条件**：空栈操作、栈满等情况需要适当处理
4. **考虑性能需求**：在内存使用、操作效率和实现复杂度之间找到平衡

### 栈的现代发展

1. **线程安全栈**：支持多线程并发访问的栈实现
2. **无锁栈**：使用原子操作实现的高性能并发栈
3. **持久化栈**：支持数据持久化的栈结构
4. **分布式栈**：在分布式系统中的栈应用

栈作为最基础的数据结构之一，不仅在算法和数据结构学习中占据重要地位，更在实际的软件开发中发挥着关键作用。从函数调用到浏览器导航，从表达式求值到撤销重做，栈的应用无处不在。深入理解栈的原理和实现，有助于我们更好地设计和优化程序，解决实际的工程问题。
