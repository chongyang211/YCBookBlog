# 数据结构与算法系列

## 系列概述

本系列共 **20 篇**，从核心原理出发，由浅入深剖析常见数据结构的设计思想、实现原理和工业级应用。每篇都遵循统一风格：

- **从一个工作案例说起**：真实线上事故 / 踩坑场景引入问题
- **连贯二级编号**：01、02、03... 保证骨架清晰
- **代码精简**：只保留核心可读逻辑，去除冗余
- **mermaid 按需辅助**：复杂结构用图胜于文字
- **案例回扣收获**：每篇末尾回答"这篇解决了哪些开头的问题"
- **思考题 + 课后作业**：含 LeetCode 刷题清单，把阅读变成行动

不限定具体语言，采用 **疑惑 → 答疑 → 论证 → 结果** 的叙事方式。

## 核心知识图谱

```
数据结构
├── 线性结构
│   ├── 数组 ── 随机访问 O(1)，插入删除 O(N)
│   ├── 链表 ── 插入删除 O(1)（已知节点），随机访问 O(N)
│   ├── 栈   ── LIFO，函数调用 / 表达式求值
│   └── 队列 ── FIFO，任务调度 / BFS
├── 树形结构
│   ├── 二叉搜索树 ── 有序，查找 O(log N) ~ O(N)
│   ├── AVL 树     ── 严格平衡，查找 O(log N)
│   ├── 红黑树     ── 近似平衡，插入删除更快
│   └── 堆         ── 优先队列，堆排序
├── 散列结构
│   ├── 哈希表     ── 查找 O(1)，冲突解决
│   ├── 布隆过滤器 ── 概率型，空间极省
│   └── 一致性哈希 ── 分布式数据分片
└── 算法基础
    ├── 复杂度分析 ── 大 O / 均摊 / 最好最坏
    └── 递归       ── 分治 / 回溯 / 动态规划
```

## 学习方法建议

> 每篇都是一个独立的"问题—原理—结论"闭环，建议下面这套组合拳。

- **先看开篇案例**：每篇 §01 都是一个真实事故/踩坑，先想"假如是我，怎么解？"
- **画图比读代码更高效**：扰动函数、扩容拆分、COW 时序、红黑树修复，统统画到纸上
- **手敲不抄代码**：核心 30 行（HashMap put / ConcurrentHashMap put / LRU 5 行）务必手写一遍
- **思考题独立做**：5 道思考题先答 5 分钟再看参考；20 篇 100 道题，做完功底直升一档
- **作业要落地**：JMH 跑实测、画选型决策树、LeetCode 必刷清单——读不如写，写不如改


## 专栏特色

- **真实事故驱动**：每篇开头都是一个真实的线上踩坑，不是"为了讲而讲"
- **首尾呼应**：开头提出问题，中间拆解原理，末尾回扣"本篇解决了什么"
- **风格统一**：20 篇同一个骨架，阅读节奏可预期
- **思考可落地**：每篇 5 道思考题 + 3 份作业（含 LeetCode 清单），覆盖 100+ 题
- **跨语言视野**：Java/Go/Python/Rust/C++/Swift 对比，拒绝"Java 中心主义"
