### 2.3 核心接口设计

**LanguageManager 职责**：
- 管理当前语言设置
- 加载和缓存语言配置文件
- 提供文本查询接口
- 处理语言切换逻辑

**接口设计**：
```cpp
class LanguageManager {
public:
    // 单例获取
    static LanguageManager& GetInstance();
    
    // 初始化
    bool Initialize();
    
    // 语言设置
    void SetCurrentLanguage(const std::string& language_code);
    std::string GetCurrentLanguage() const;
    
    // 文本获取
    std::string GetText(const std::string& key) const;
    
    // TTS支持
    std::string GetTTSLanguageCode() const;
    std::string GetTTSAudioFile(const std::string& audio_key) const;
    
    // 配置管理
    bool LoadLanguageConfig(const std::string& language_code);
    void SaveCurrentLanguage() const;
    
private:
    std::string current_language_;
    std::unordered_map<std::string, std::string> text_map_;
    std::unordered_map<std::string, std::string> tts_language_map_;
};
```

### 2.4 数据流设计

```
用户操作 → UI组件 → LanguageManager → 配置文件
    ↓           ↓           ↓            ↓
语言切换 → 调用SetLanguage → 加载新配置 → 更新文本映射
    ↓           ↓           ↓            ↓
界面更新 ← 获取新文本 ← GetText调用 ← 返回本地化文本
```

### 3.4 文本查询算法

```cpp
std::string LanguageManager::GetText(const std::string& key) const {
    // 1. 在当前语言映射中查找
    auto it = text_map_.find(key);
    if (it != text_map_.end()) {
        return it->second;
    }
    
    // 2. 回退到英文
    if (current_language_ != "en") {
        // 临时加载英文配置进行查找
        auto english_map = LoadEnglishFallback();
        auto en_it = english_map.find(key);
        if (en_it != english_map.end()) {
            return en_it->second;
        }
    }
    
    // 3. 返回键名作为最后回退
    LOG_W("Text not found for key: {}", key);
    return key;
}
```

### 3.5 配置文件解析算法

```cpp
bool LanguageManager::LoadLanguageConfig(const std::string& language_code) {
    std::string config_path = "config/lang_" + language_code + ".txt";
    std::ifstream file(config_path);
    
    if (!file.is_open()) {
        return false;
    }
    
    text_map_.clear();
    std::string line;
    
    while (std::getline(file, line)) {
        // 跳过注释和空行
        if (line.empty() || line[0] == '#') {
            continue;
        }
        
        // 解析key=value格式
        size_t pos = line.find('=');
        if (pos != std::string::npos) {
            std::string key = line.substr(0, pos);
            std::string value = line.substr(pos + 1);
            
            // 去除首尾空格
            key = Trim(key);
            value = Trim(value);
            
            text_map_[key] = value;
        }
    }
    
    return true;
}
```


## 4. 使用指南
