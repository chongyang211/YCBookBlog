## 02.CPU使用率

### 2.1 理解CPU使用率

在Linux系统下CPU分为：CPU利用率分为用户态、系统态、空闲态，分别表示CPU处于用户态执行的时间，系统内核执行的时间，和空闲系统进程执行的时间。

平时所说的CPU利用率是指：CPU执行非系统空闲进程的时间 / CPU总的执行时间。

先介绍几个和Linux时间有关的名词：HZ、tick与jiffies。

- HZ：Linux 核心每隔固定周期会发出timer interrupt (IRQ 0)，HZ是用来定义每一秒有几次timer interrupts。例如HZ为1000，就代表每秒有1000次timer interrupts。
- Tick ：Tick是HZ的倒数，Tick = 1/HZ 。即timer interrupt每发生一次中断的时间。如HZ为250时，tick为4毫秒(millisecond)。
- Jiffies ：在Linux的内核中，有一个全局变量：Jiffies。 Jiffies代表时间。它的单位随硬件平台的不同而不同。jiffies的单位就是 1/HZ。Intel平台jiffies的单位是1/100秒，这就是系统所能分辨的最小时间间隔了。每个CPU时间片，Jiffies都要加1。 CPU的利用率就是用执行用户态+系统态的Jiffies除以总的Jifffies来表示。

CPU利用率计算公式也就是： CPU使用率＝（用户态Jiffies＋系统态Jiffies）／总Jiffies

### 2.2 CPU使用率分类

在 终端应用（Android应用，iOS应用，嵌入式应用APP等） 中，CPU 使用率可以分为：

1. 应用 CPU 使用率：应用占用的 CPU 资源。
2. 系统 CPU 使用率：系统进程占用的 CPU 资源。

## 03.CPU监控核心

**CPU监控**：基于`/proc/stat`和`/proc/[pid]/stat`计算使用率

### 3.1 CPU监控原理

CPU使用率计算基于`/proc/stat`和`/proc/[pid]/stat`：

- 总CPU时间 = user + nice + system + idle + iowait + irq + softirq
- 进程CPU时间 = utime + stime
- CPU使用率 = (进程CPU时间增量 / 总CPU时间增量) * 100%

get_system_info() {
    echo "========== 系统信息 =========="
    if [ -f "/proc/device-tree/model" ]; then
        model=$(cat /proc/device-tree/model)
        echo "主板: ${model%%$'\0'*}"
    else
        echo "主板: RV1109/RV1126"
    fi
    echo "内核: $(uname -r)"
    echo "总内存: $(free -m | awk 'NR==2{print $2}')MB"

    if [ -f "/sys/devices/system/cpu/cpu0/cpufreq/cpuinfo_cur_freq" ]; then

        echo "CPU频率: $((FREQ/1000))MHz"
    else

### 4.4 进程资源获取

```shell
get_process_resources() {
    pid=$1
    stats=$(ps -o pid,pcpu,pmem,rss,vsz -p "$pid" 2>/dev/null | tail -n1)
    
    if [ -n "$stats" ]; then
        # 使用tr和awk代替<<<
        echo "$stats" | tr -s ' ' | awk '{print $2","$3","int($4/1024)","int($5/1024)}'
    else
        echo "0,0,0,0"
        return 1
    fi
}
```


原理解析：

```text
使用ps命令的特定格式化输出获取进程统计信息
pcpu：进程CPU使用百分比
pmem：进程内存使用百分比
rss：实际物理内存占用(KB) → 转换为MB
vsz：虚拟内存大小(KB) → 转换为MB
使用tr -s ' '压缩多余空格，确保awk字段解析准确
```

### 4.5 系统负载计算

```shell
cores=$(nproc 2>/dev/null || grep -c processor /proc/cpuinfo)
load=$(awk '{print $1}' /proc/loadavg)
cpu_usage=$(awk -v c="$cores" -v l="$load" 'BEGIN{print int(l*100/c)}')
```

原理解析：

```text
读取/proc/loadavg的1分钟平均负载
通过负载值 × 100 / CPU核心数计算CPU使用率百分比
这种方法比传统的/proc/stat采样更稳定，避免瞬时波动
```

## 05.CPU监控脚本

### 5.1 总监控脚本

```shell
#!/bin/sh

# =============================================================================
# RV1109掌纹识别系统资源监控脚本 v2.2 (Busybox完全兼容版)
# 已修复所有语法兼容性问题
# =============================================================================

# 配置参数
APP_NAME="yt-palm"
LOG_DIR="/userdata/Apptest/perf_logs"
INTERVAL=5
MAX_LOG_SIZE=10485760

# 阈值配置
MEMORY_LEAK_THRESHOLD=5      # MB
CPU_HIGH_THRESHOLD=80        # %
MEMORY_HIGH_THRESHOLD=80     # %

# 创建日志目录
mkdir -p "$LOG_DIR" || {
    echo "无法创建日志目录: $LOG_DIR"
    exit 1
}

# 获取系统信息
get_system_info() {
    echo "========== 系统信息 =========="
    if [ -f "/proc/device-tree/model" ]; then
        model=$(cat /proc/device-tree/model)
        echo "主板: ${model%%$'\0'*}"
    else
        echo "主板: RV1109/RV1126"
    fi
    echo "内核: $(uname -r)"
    echo "总内存: $(free -m | awk 'NR==2{print $2}')MB"
    echo "CPU核心: $(nproc 2>/dev/null || grep -c processor /proc/cpuinfo)"
    
    # CPU频率检测
    if [ -f "/sys/devices/system/cpu/cpu0/cpufreq/cpuinfo_cur_freq" ]; then
        FREQ=$(cat /sys/devices/system/cpu/cpu0/cpufreq/cpuinfo_cur_freq)
        echo "CPU频率: $((FREQ/1000))MHz"
    else
        echo "CPU频率: N/A"
    fi
    echo "=============================="
}

# 获取应用程序PID
get_app_pid() {
    pid=""
    for i in 1 2 3; do
        pid=$(pgrep -x "$APP_NAME" | head -n1)
        [ -n "$pid" ] && break
        sleep 1
    done
    echo "$pid"
}

# 获取进程资源占用（完全兼容BusyBox）
get_process_resources() {
    pid=$1
    stats=$(ps -o pid,pcpu,pmem,rss,vsz -p "$pid" 2>/dev/null | tail -n1)
    
    if [ -n "$stats" ]; then
        # 使用tr和awk代替<<<
        echo "$stats" | tr -s ' ' | awk '{print $2","$3","int($4/1024)","int($5/1024)}'
    else
        echo "0,0,0,0"
        return 1
    fi
}

# 获取系统资源信息
get_system_resources() {
    # CPU使用率
    cores=$(nproc 2>/dev/null || grep -c processor /proc/cpuinfo)
    load=$(awk '{print $1}' /proc/loadavg)
    cpu_usage=$(awk -v c="$cores" -v l="$load" 'BEGIN{print int(l*100/c)}')
    
    # 内存使用
    mem_info=$(free -m | awk 'NR==2{print $3 * 100/$2","$3","$2}')
    
    # 温度检测
    temp_c=0
    for path in /sys/class/thermal/*/temp; do
        [ -f "$path" ] && {
            temp_c=$(($(cat "$path")/1000))
            break
        }
    done
    
    echo "${cpu_usage},${mem_info},${temp_c}"
}

# 记录监控数据
log_resources() {
    timestamp="$1"
    test_case="$2"
    iteration="$3"
    pid="$4"
    proc_stats="$5"
    sys_stats="$6"
    
    log_file="${LOG_DIR}/${test_case}_$(date +%Y%m%d).csv"
    
    if [ ! -f "$log_file" ]; then
        echo "timestamp,test_case,iteration,pid,proc_cpu(%),proc_mem(%),proc_rss(MB),proc_vsz(MB),sys_cpu(%),sys_mem_usage(%),sys_mem_used(MB),sys_mem_total(MB),cpu_temp(℃)" > "$log_file"
    fi
    
    echo "$timestamp,$test_case,$iteration,$pid,$proc_stats,$sys_stats" >> "$log_file"
}

# TC001测试（记录间隔=10次）
monitor_high_frequency_test() {
    echo "开始执行 TC001 测试（记录间隔：10次）"
    
    test_case="TC001"
    total_iterations=10000
    log_interval=10
    start_time=$(date +%s)
    
    i=1
    while [ $i -le $total_iterations ]; do
        if [ $((i % log_interval)) -eq 0 ]; then
            timestamp=$(date '+%Y-%m-%d %H:%M:%S')
            pid=$(get_app_pid)
            proc_stats=$(get_process_resources "$pid")
            sys_stats=$(get_system_resources)
            
            log_resources "$timestamp" "$test_case" "$i" "$pid" "$proc_stats" "$sys_stats"
            
            cpu=$(echo "$proc_stats" | cut -d',' -f1)
            mem=$(echo "$proc_stats" | cut -d',' -f3)
            echo "[$i/$total_iterations] CPU: ${cpu}% MEM: ${mem}MB"
        fi
        
        sleep 0.1
        i=$((i + 1))
    done
    
    duration=$(( $(date +%s) - start_time ))
    echo "测试完成，耗时: ${duration}秒"
}

# 主流程
main() {
    echo "掌纹识别系统监控脚本启动"
    get_system_info
    
    pid=$(get_app_pid)
    if [ -z "$pid" ]; then
        echo "错误: 未找到应用程序 $APP_NAME"
        exit 1
    fi
    
    monitor_high_frequency_test
}

main
```

## 06.CPU优化实践

### 6.1 CPU优化思路

优化CPU可以加快启动速度、增加打开页面速度，减少卡顿，有这么神奇吗？那这底层原理是什么呀？

UI界面渲染，行为交互，功能运算等等操作最终都会转换成为一条条机器指令，而这些机器指令是要依靠CPU去执行的。所以在面对同一功能时，如何让CPU以最短的时间去完成功能就是我们的首要目标。

当我们想要提升某些场景（如启动、打开页面、渲染动画等）的速度时，本质上就是降低 CPU 执行完这些场景指令的时间，这个时间简称为 CPU 时间。

程序所消耗 CPU 时间的计算公式：CPU 时间 ＝ 程序执行所需的时钟周期数 * 时钟周期时间，其中的 程序执行所需的时钟周期数 = 程序指令数 * 每条指令的平均时钟周期”

1. 程序执行所需的时钟周期数：CPU的所有操作都是以时钟周期为基础来计算的，每个时钟周期都会执行一个指令或完成一个操作。
2. 时钟周期时间：指CPU完成一次执行所需的时间，即：一个时钟周期的时间，它通常以纳秒（ns）或皮秒（ps）为单位来表示，时钟周期时间越短，CPU的运行速度就越快。
3. 程序指令数：程序代码编译成机器码指令后的指令数量。
4. 每条指令的平均时钟周期：指令执行完毕所消耗的平均时间周期，指令不同所需的时钟周期数也不同。

只要对上述的任何一项因子进行优化都可以达到目的，所以我们的优化方法论就是：①.减少程序指令数、②.降低每条指令的平均时钟周期、③.降低时钟周期的时间、④.其他优化方案
