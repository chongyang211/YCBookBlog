## 01.问题域定义

### 1.1 现象
- "CPU 不高，内存够用，用户却觉得卡"
- 启动慢、首屏空白、列表滚动一顿一顿
- 写入数据后界面响应变慢（fsync 阻塞）

### 1.2 度量准则
- 主线程 IO 时间占比
- 文件读写 P95 / P99 时长
- IO Wait（系统级）
- 存储引擎事务时长（SQLite / IndexedDB）

提纲：

## 05.求证实验 ⭐

## 06.优化策略

跨平台通用：
- 关键路径上的 IO 全部异步化
- 批量写入替代多次小写
- 写时复制 / WAL
- mmap 适用边界
- 数据结构选型（KV vs 关系型 vs 列存）

平台特化：
- Android：MMKV / DataStore / SharedPreferences 选型
- iOS：UserDefaults / Core Data / 文件 NSCoding
- Web：localStorage / IndexedDB / OPFS
- 嵌入式：FlashFS / 磨损均衡


## 07.实战案例

候选案例：
- 启动期 SharedPreferences 同步加载导致 1.2s 阻塞
- SQLite N+1 查询拖慢列表
- 大量小文件写入触发 fsync 风暴
