## 1.线程背景说明

### 1.1 多道程序设计

**从单道批处理到多道程序**。早期计算机是**单道批处理**——CPU 一次只执行一个程序，I/O 时 CPU 完全空闲。

```
时间线：
[====CPU运算====][--------I/O等待--------][====CPU运算====]
                  ↑ CPU 在此完全空闲，利用率极低
```

**多道程序设计**引入了**进程（Process）**概念——操作系统可以同时加载多个程序，CPU 在一个进程等待 I/O 时切换到另一个进程。
