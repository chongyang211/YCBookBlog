## 1.为何要浮点数

### 1.1 浮点数由来

计算机只有有限的位（32/64位），要表示的数却是无限的（实数连续统）。整数只能表示离散点，科学计算需要表示极大（`6.02×10²³`）和极小（`1.6×10⁻¹⁹`）的数。

**核心矛盾**：用有限的位表示无限精度的实数 → **必然有精度损失**。浮点数的设计就是在有限位数下，最大化可表示范围和精度。

## 2.IEEE754标准

IEEE754标准——所有语言的共同基础

1985 年制定，几乎所有现代 CPU 和语言都遵循。**Java float、C double、JS number、C++ float/double 底层完全一样。**

### 2.1 存储结构

```
单精度 float (32位):
┌─────┬──────────┬───────────────────────────┐
│ 符号 │  指数(8位) │       尾数(23位)           │
│ 1bit │  Exponent │       Mantissa            │
└─────┴──────────┴───────────────────────────┘

双精度 double (64位):
┌─────┬───────────┬────────────────────────────────────────────────────┐
│ 符号 │ 指数(11位) │                  尾数(52位)                        │
│ 1bit │  Exponent  │                  Mantissa                        │
└─────┴───────────┴────────────────────────────────────────────────────┘
```
