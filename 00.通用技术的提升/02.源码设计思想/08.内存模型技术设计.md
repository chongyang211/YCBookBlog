### 1.3 没有内存模型场景

```mermaid
sequenceDiagram
    participant T1 as 线程1
    participant Cache1 as CPU1缓存
    participant Memory as 主内存
    participant Cache2 as CPU2缓存
    participant T2 as 线程2
    
    Note over T1,T2: 没有内存模型的混乱场景
    
    T1->>Cache1: 写入 x = 1
    Note over Cache1: 数据在缓存中
    
    T2->>Cache2: 读取 x
    Cache2->>Memory: 从主内存读取
    Memory-->>Cache2: 返回 x = 0 (旧值)
    Cache2-->>T2: x = 0
    
    Note over T1,T2: 线程2看不到线程1的修改！
    
    T1->>Cache1: 写入 y = 2
    T1->>Memory: 延迟写回主内存
    
    T2->>Cache2: 读取 y
    Cache2->>Memory: 从主内存读取
    Memory-->>Cache2: 返回 y = 0 (还未更新)
    
    Note over T1,T2: 数据不一致，程序行为不可预测
```

### 2.2 线程私有和共享

| 特性 | 线程私有内存 | 线程共享内存 |
|------|-------------|-------------|
| **访问权限** | 仅当前线程可访问 | 所有线程都可访问 |
| **生命周期** | 与线程同生共死 | 与进程同生共死 |
| **数据安全** | 天然线程安全 | 需要同步机制 |
| **性能** | 访问速度快 | 可能存在竞争 |
| **内存大小** | 相对较小 | 相对较大 |
| **典型用途** | 方法调用、局部变量 | 对象实例、类信息 |
