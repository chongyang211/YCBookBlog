
# 1.写小说故事

## 列故事情节

关于爱，俄罗斯这部电影，根据这部作品，先拆解这部作品讲述了什么故事，模仿这部作品的故事情节，帮我仿写一部中国现代的作品。

1. 先帮我把作品梳理下，写了什么故事，主线是什么，作品内容拆解出来，对整个故事章节做概括等。
2. 帮我总结要仿写故事（要求是现代故事），仿写故事适当改一下，加入些当下元素。
3. 要求故事吸引人，精彩并且新颖，主题突出，加入冲突元素，突出人性色彩
4. 严格按照这个结构来写：1.故事基础定位（时代背景，核心场景，核心内核）；2.完整故事梗概（简短即可）；3.核心主线与叙事结构（主线/副线）；4.核心人物设定；5.剧情全概括（作品总框架与核心情节，简洁即可）；6.作品核心特色（作品核心特色与亮点）；7.写该小说推荐语（150字的/300字左右的）
5. 仿写的作品神似而行不似，避免被人发现抄袭的痕迹



## 列大纲

结合上面故事整体脉络和核心情节，给这部小说罗列大纲，主要情节，核心人物设定，主要脉络等。罗列整个所有章节内容：

1. 每个章节输出：第一列章节，第二列标题（必须是7个字），第三列核心情节，第四列心里刻画，第五列细节补充；以表格的形式展现；
2. 故事要有正能量，构思的故事前后要衔接上；
3. 提纲要详细，保证章节连贯性；
4. 要以表格的形式展现；
5. 标题必须是7个字；
6. 书籍大概是50万字以上，拆分至少要50个以上的章节，最多不超过120章节
7. 需要分卷，分卷核心内容，以及章节介绍

# 2.写出版书籍

## 必须要做操作

1. 必须先写整体大纲
2. 可以先写一篇文章，该篇文章一定要仔细揣摩，结构要新颖，起到模版的作用。后续其他文章按照这个模版来写！

## 写绪论介绍

1.结合这些内容，写一篇绪论，突出重点，为何要看该专栏，专栏的定位，写该专栏花费很多心血，寄望之类的
2.检查每篇文章的三级标题内容，如果太单薄，比如一句话，几句话的，就需要增加内容的厚度。让读起来可以由浅到深，有探索到得到结论的过程。
