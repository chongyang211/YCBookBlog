
# 写小说故事

## 列故事情节

天堂电影院，根据这部作品，先拆解这部作品讲述了什么故事，模仿这部作品的故事情节，帮我仿写一部中国现代的作品。

1. 先帮我把作品梳理下，写了什么故事，主线是什么，作品内容拆解出来，对整个故事章节做概括等。
2. 帮我总结要仿写故事（要求是现代故事），仿写故事适当改一下，加入些当下元素。
3. 要求故事吸引人，精彩并且新颖，主题突出，加入冲突元素，突出人性色彩
4. 严格按照这个结构来写：1.故事基础定位（时代背景，核心场景，核心内核）；2.完整故事梗概；3.核心主线与叙事结构（主线/副线）；4.核心人物设定；5.剧情全概括（作品总框架与分章节核心情节）；6.作品核心特色（作品核心特色与亮点）；7.写该小说推荐语（150字的/300字左右的）

## 列大纲

结合上面故事整体脉络和核心情节，给这部小说罗列大纲，主要情节，核心人物设定，主要脉络等。罗列整个所有章节内容：

1. 每个章节输出：第一列章节，第二列标题（必须是7个字），第三列核心情节，第四列心里刻画，第五列细节补充；以表格的形式展现；
2. 故事要有正能量，构思的故事前后要衔接上；
3. 提纲要详细，保证章节连贯性；
4. 要以表格的形式展现；
5. 标题必须是7个字；
6. 书籍大概是40万字以上，拆分至少要80个以上的章节，最多不超过120章节
7. 需要分卷，分卷核心内容，以及章节介绍

## 写故事

帮我继续写故事，要求如下

1. 故事开头要吸引人，故事结尾可以留悬念。故事前后要连贯，避免短句短语。
2. 写作风格带有古龙风，但避免太多短语，短句。要有文采，可以带些古诗词之类
3. 每个章节字数保证4000到6000字，不要超过6000字。字数必须达到要求！
4. 人物感情刻画要细腻，仅仅写我发的提纲章节

## 写序言

帮我写这部小说的序言，主要讲写这部小说的前因后果，想给人什么启发，具有什么写实意义

1. 写了个什么样的故事，可以描述的有吸引力，但不能剧透
2. 描述下自己写作的艰辛之路，反复揣摩
3. 这部作品可以跟人什么启示
4. 跟大多数作品一样，写序言，能把主人物刻画更细腻，具有写实意义


# 写推荐语

帮我写一下这部作品一些关键内容：

1. 帮我写个推荐语，大概200到300字之间，要求要有吸引力，不要剧透，用来推荐作品
2. 帮我总结下这个故事
3. 帮我整理出该作品的脉络
4. 帮我写一下故事中的主要人物和介绍，对人物角色分类
