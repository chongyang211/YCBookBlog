# 专栏笔记总结大全




## 4.2目标设立和管理

- 03.设置目标四要素：1.发自内心的；2.要有画面感；3.目标要具体；4.结果的考量
- 3.1 发自内心的：强调内心愿望驱动，源自内心的强烈需求，在你头脑中形成很具体的画面感，可能是个好目标
- 3.2 要有画面感：目标要足够清晰，在头脑中直接就能视觉化、具象化。
- 3.3 目标要具体：例如，将目标从“提高销售”具体化为“增加销售额10%”。避免模糊不清！
- 3.4 结果的考量：指定目标后，要写目标结果，一定要强调结果。
- 04.目标要层层递进：
- 4.1 目标会不断演变：目标缺乏——>模糊目标——>目标清晰
- 4.2 懂得设立小目标：时间周期为1-2周，既不会过于频繁，也能及时收效；稍微高于自己的能力。
- 4.3 短期长期目标:从时间维度，可以拟定 “短、中、长” 三阶段的计划。
